5f · technique

The same change to both sides

5a and 5b made numbers in which every subtraction, and every division by a number other than 0, has an answer. Most questions do not arrive that neatly. They arrive wrapped: which fraction, taken three times with five added, gives eleven less the fraction? This step gives a letter its job, a stand-in for the number asked for, and turns the slogan “do the same to both sides” into a licence. Some changes to both sides keep every answer and add none. Some quietly throw an answer away. Some let in an answer that was never there. Each is decided by a rule you already have: the swap axiom for the forward step, the twelve techniques for the way back. Then come isolating a letter, rearranging a rule with several letters, solving two samenesses together, and running all of it backwards to build a sameness with whatever answers you choose.

A sameness with an unknown in it is a condition, and its answers are the set it sifts. Going forward, doing the same thing to both sides is always a move, cited to the swap axiom; it keeps the answers when another change can undo it. Adding anything, and multiplying by anything other than 0, can be undone. Multiplying by what might be 0, dividing by it, and squaring cannot.

What this stands on, and where it goes

Stands on 0b (the axioms self-sameness and swap, the turn-about technique), 2b (sifting), 2a (the same-members axiom), 2e (pairs and products), 5c (the twelve techniques), 5d (anything-times-zero, cancel for times on ℚ, zero-product, two-negatives) and 5e (½ and r²). 5g clears fractions with these techs, 5h solves by factoring, 5i solves proportions, and 5·chem balances reactions as several samenesses that must all be true at once.

5f1A letter for an unknown number

Stands on 1e (placeholders) and 2b (the sift).

Until now every letter on a line has done one of two jobs. It has named something in hand (“let p be anything”, “call such a number b”), or it has been a placeholder bound by ∀, ∃ or a sift, naming nothing (1e, 2b). A question such as “which rational added to 3 gives 0?” can be written in the second way, as a sift: . The letter x there names nothing; 3 + x = 0 is a condition, 2b's statement with a gap, which is so of some rationals and fails of others. Writing such conditions, and asking which rationals pass, is so common that the letter gets a name for its job.

From here on, when a sameness or other condition is written with a letter, say x, in the place of a rational that is asked for, x is called an unknown. The rationals that make the condition true are its answers, and the set of them, , is its answer set. To solve the condition is to find its answer set, written so that its members can be read off.

So an unknown is a placeholder in a sift, and everything 1e said of placeholders is true here. Renaming it to another letter not in use changes nothing. And no line may carry it outside the sift as if it named something. An unknown is a variable, 4b’s word, held in a sift. A sameness with an unknown in it is called an equation; its answers are called its solutions, and its answer set its solution set. To solve an equation is to find its solution set. An equation whose unknown is only multiplied by numbers and added to, such as 3 + x = 0 or 2x + 1 = 7, is called linear. The solution set of 3 + x = 0 is {−3}. A member y of the sift has y ∈ ℚ and 3 + y = 0, and 5a's subtraction says the only such y is 0 − 3 = −3. So by the same-members axiom the sift is {−3}. Solution sets come in every size. That of x² = 5x is {0, 5}. That of x + 1 = x is ∅, since it would make 1 = 0 (add −x to both sides, which this step licenses below). That of x + x = 2x is all of ℚ (5e proved that every rational added to itself is twice itself). And that of x² = 2 is ∅ by 5e's no-fraction-squares-to-2.

5f2The cost of an orange

Stands on 5f1 and 0c (an argument rules out guesses).

0c said an argument is a relationship of statements that ends by ruling out the guesses that do not fit the techniques, and that an equation is one kind. Here is that kind, with numbers for guesses. At a fruit stand in Watsonville, three oranges and a lemon come to 240 cents, and the lemon was 30 cents. Let x be the price of one orange, in cents: 3x + 30 = 240.

Every price is a guess. Try 50: three of them and the lemon make 180, not 240, so 50 is ruled out. Try 80: that makes 270, also ruled out. Guessing one price at a time would never end, because there are as many guesses as rationals. The techs this step licenses below rule out every guess but one at once: the answer set of 3x + 30 = 240 is {70}. With the answer set read off, this argument is finished, and earns its end mark; before that, each sameness on the way only narrowed the guesses. An equation is an argument whose guesses are numbers: it rules out every number that does not balance it.

Notice what the equation does not rule out. It does not say whether the stand charged fairly, whether the receipt was added right, or what an orange will cost next week. It says only what the price must be if the statements are true. Guesses of those other kinds are ruled out by statistics, or by a walk to the stand to look.

5f3Two kinds of technique

Stands on 5f2, the swap and self-sameness axioms (0b) and 5c (the rules).

To rewrite is to replace a piece of one side by something that names the same rational: 3x + x by 4x, by spread on ℚ read backwards. That is the swap axiom with a rule or a technique as its sameness, and nothing happens to the other side because nothing has changed. A change to both sides does one thing to each side: add the same rational, or multiply by it. Why may it be done?

The oldest geometry book that has come down whole set three of these techs among the common notions it took as given before any proposition. Things the same as one thing are the same as each other. When equals are added to equals, the results are equal. And when equals are taken from equals, what remains is equal.

On this ladder they are not assumed. The first is the chain technique (0b). The other two are the swap axiom, with the self-sameness axiom to get started. Adding-keeps-answers technique: for rationals L, R and c, L = R exactly when L + c = R + c.

\text{assume } L = R @@ the rightward direction
L + c = L + c @@ the self-sameness axiom
L + c = \htmlClass{new}{R} + c @@ the swap axiom, at the right-hand L only
\text{assume } L + c = R + c @@ the leftward direction: the way back
(L + c) + \htmlClass{new}{(-c)} = (R + c) + (-c) @@ the self-sameness axiom, then the swap axiom, as above: add −c
L + (c + (-c)) = R + (c + (-c)) @@ regroup for plus on ℚ, on each side
L + 0 = R + 0 @@ negative on ℚ
\htmlClass{new}{L = R} @@ plus-zero on ℚ
L = R \;\Leftrightarrow\; L + c = R + c \quad \blacksquare @@ prove an if each way; ︿ ⇔

Notice the asymmetry. Going forward needed nothing about adding at all: by the swap axiom, the two changed sides are the same for any change whatever, doubling, squaring, taking the numerator. Going back is where the rules come in: −c exists (negative on ℚ) and undoes the change. Multiplying-keeps-answers technique: if c ≠ 0, then L = R exactly when Lc = Rc. Forward: the self-sameness axiom and the swap axiom, as in adding-keeps-answers. Back: that is 5d's cancel for times on ℚ, which multiplies by c⁻¹, and c⁻¹ exists exactly because c ≠ 0. ∎

5f4Same answers

Stands on 5f3 and 2a (double inclusion).

Now the step that turns these into a licence for conditions. Same-answers technique: if every rational x has φ(x) ⇔ ψ(x), then {x ∈ ℚ : φ(x)} = {x ∈ ℚ : ψ(x)}. Chase a member. y is in the first sift exactly when y ∈ ℚ and φ(y), exactly when (use the every) y ∈ ℚ and ψ(y), exactly when y is in the second. The same-members axiom closes it. ∎

From here on, a move from one condition on an unknown to another is licensed when the two have the same solution set.

This is a new job for 1g's word: there a licence said in which directions a technique may be used; here “licensed” is said of a move between conditions. Both stand.

Adding-keeps-answers says this, for each rational x. The sides L and R are each a name written with x in it, naming a rational once x is fixed. They are the same exactly when L + c and R + c are. And c may itself have x in it, since at each x it names a rational. So by same-answers, adding anything to both sides is licensed. Multiplying-keeps-answers says the same for multiplying by c, but only where c ≠ 0. If c has x in it and is 0 at some rational, the way back fails at that rational, and the solution set may grow. Here is the whole licence in one table.

to both sidesloses answers?gains answers?why
add any rational, or anything with x in itnonoAdding-keeps-answers: undone by adding its negative
multiply by a rational c ≠ 0nonoMultiplying-keeps-answers: undone by multiplying by c⁻¹
multiply by 0noyes, every rationalAnything-times-zero makes each side 0; cancel for times on ℚ needs c ≠ 0
multiply by something with x in itnoyes, where it is 0there it is multiplying by 0

Every move in the first column goes forward by the swap axiom. So nothing in it can lose an answer except dividing, which is multiplying by a reciprocal that may not exist. And everything that gains answers gains them for one reason: there is no way back.

5f5Isolating a letter: undo in reverse order

Stands on 5f4 and 5b (dividing is multiplying by the reciprocal).

To get x alone, read a side as a story of what was done to x, and undo the story from its end. In 3x + 5, x was multiplied by 3 and then 5 was added. The last thing done is the first undone: add −5, then multiply by the reciprocal of 3. It is the order of taking off shoes and socks: on go the socks and then the shoes; off come the shoes and then the socks. When x is on both sides, first gather it on one side by adding a piece with x in it, which adding-keeps-answers licenses like any other adding. The column ends with a check, and the mark ✓ there says only that the check came out right: it is a note to the reader and claims nothing new.

3x + 5 = 11 - x @@ the condition
3x + 5 \htmlClass{new}{+ x} = 11 - x \htmlClass{new}{+ x} @@ adding-keeps-answers: add x to both sides
(3 + 1)x + 5 = 11 + ((-x) + x) @@ rewrite: turn-about for plus on ℚ and regroup for plus on ℚ on the left; spread on ℚ turned about with times-one on ℚ; ﹀ − on the right
4x + 5 = 11 @@ rewrite: 3 + 1 = 4; negative on ℚ and plus-zero on ℚ
4x + 5 \htmlClass{new}{+ (-5)} = 11 \htmlClass{new}{+ (-5)} @@ adding-keeps-answers: add −5, undoing the last thing done to x
4x = 6 @@ rewrite: regroup for plus on ℚ, negative on ℚ, plus-zero on ℚ; 11 − 5 = 6 (5a's pair-is-the-difference)
\htmlClass{new}{\tfrac14}(4x) = \htmlClass{new}{\tfrac14}\cdot 6 @@ multiplying-keeps-answers: multiply by 1/4, which is not 0
x = \tfrac{3}{2} @@ rewrite: regroup for times on ℚ, reciprocal on ℚ, times-one on ℚ on the left; 6/4 = 3/2 by scaling with k = 2
3\cdot\tfrac32 + 5 = \tfrac{19}{2} = 11 - \tfrac32 \;\checkmark @@ check: put 3/2 in the place of x in the first line

So the solution set is {3/2}. Every move was licensed, so the last line has the same answers as the first, and the last line's answers can be read off. The check costs one line. With licensed techs it cannot fail, so if it does, a move was not licensed or a slip crept in while rewriting; either way you learn something.

Writing rather than “divide by 4” is deliberate. Dividing by 4 is multiplying by 4⁻¹ (5b's line), so they are one move; but writing the reciprocal makes the small print visible. You are multiplying by something, and multiplying-keeps-answers asks whether that something is 0.

5f6The gallery of illegal moves

Stands on 5f4, 5f5 and 5d (anything-times-zero, two-negatives, zero-product).

Each of these looks like an ordinary step. Each changes the solution set, and each breaks a line of the table above.

Dividing by something that might be 0. From x² = 5x, “divide both sides by x” gives x = 5. But x = 0 also works: 0 = 0. It was thrown away by the division, because at x = 0 the move multiplies by the reciprocal of 0, which 5d proved does not exist. The honest route never divides by a side that has x in it. Gather everything on one side, write it as a product, and let 5d's zero-product split the cases.

x^2 = 5x @@ the condition
x^2 \htmlClass{new}{+ (-(5x))} = 5x + (-(5x)) @@ adding-keeps-answers
x^2 - 5x = 0 @@ rewrite: ︿ −; negative on ℚ
\htmlClass{new}{x(x - 5)} = 0 @@ rewrite: x(x − 5) = xx + x(−5) = x² − 5x, by spread on ℚ, negative-out on ℚ and 5e's line for ², turned about
x = 0 \ \lor\ x - 5 = 0 @@ zero-product (5d)
x = 0 \ \lor\ x = 5 @@ adding-keeps-answers in the second case: add 5. The solution set is {0, 5}

Squaring both sides. From x + 1 = 3, squaring gives (x + 1)² = 9, which is true at x = 2. It is also true at x = −4, since (−4 + 1)² = (−3)² = 9 by two-negatives. Squaring goes forward by the swap axiom like anything else, but it cannot be undone. Knowing p² = b² does not tell you p = b, only that p = b or p = −b (5h shows why, with the difference of squares). So squaring is a forward tech only: square, solve, then check every answer in the original and throw out the strangers. The accepted name for such a stranger is an extraneous solution, from the Latin extraneus, “from outside”.

Multiplying by something that might be 0. From x = 4, multiply both sides by x − 1: x(x − 1) = 4(x − 1). Now x = 1 works too, since both sides are 0 there by anything-times-zero. Wherever the multiplier is 0, any two things become the same, and a stranger walks in.

Changing one term instead of a whole side. Multiplying 2x + 6 = 10 by ½ gives ½(2x + 6) = 5, which spread on ℚ spreads to x + 3 = 5. Writing x + 6 = 5 instead multiplied only one term of the sum. A change to both sides is done to each whole side. The spreading that follows rewrites, and it reaches every term.

Taking reciprocals term by term. From 1/x + 1/2 = 1/3, “take reciprocals” term by term to get x + 2 = 3, so x = 1. Check: 1/1 + 1/2 is 3/2, not 1/3. The reciprocal of a sum is not the sum of the reciprocals. Taking the reciprocal of each whole side is licensed where neither side is 0. (By 5b's reciprocal, a rational other than 0 has exactly one reciprocal, so p = b exactly when p⁻¹ = b⁻¹.) But first make each side a single fraction. The honest route: add −1/2 to both sides, 1/x = 1/3 − 1/2 = −1/6, and the reciprocals of the whole sides give x = −6.

5f7Rearranging a rule for one letter

Stands on 5f5.

An equation with several letters, such as m = s + wt, can be solved for one of them with the others kept fixed. Say a jar holds m coins after t weeks, having started with s coins and gained w coins each week. To solve for t, treat m, s and w as names of rationals in hand and t as the unknown. The techs are the same. The new thing is that you can no longer see whether a letter you want to multiply by the reciprocal of is 0. So you must ask, and say the answer on the line.

m = s + wt @@ coins in the jar after t weeks
m \htmlClass{new}{+ (-s)} = wt @@ adding-keeps-answers: add −s; on the right turn-about for plus on ℚ, regroup for plus on ℚ, negative on ℚ, plus-zero on ℚ
(m - s)\htmlClass{new}{w^{-1}} = t \quad (w \ne 0) @@ multiplying-keeps-answers: multiply by w⁻¹, licensed only if w ≠ 0; turn-about for times on ℚ, regroup for times on ℚ, reciprocal on ℚ, times-one on ℚ
t = \tfrac{m - s}{w} \quad (w \ne 0) @@ the turn-about technique; 5b's line for dividing

If w = 0, no coins are ever added, m = s every week, and the coins in the jar say nothing about how long you waited. The algebra refuses to multiply by the reciprocal of 0 for exactly the reason the story can't answer. A game that changes its score cards writes a score S from the old card as N = (9/5)S + 32 on the new one. Undo in reverse order: add −32, then multiply by 5/9, the reciprocal of 9/5. So S = (5/9)(N − 32), and an old 100 is a new 212. Is there a score that reads the same on both cards? Put S in the place of N: S = (9/5)S + 32, so (−4/5)S = 32 by adding-keeps-answers, and S = −40 by multiplying-keeps-answers with −5/4. Check: (9/5)(−40) + 32 = −72 + 32 = −40.

5f8Two equations, two unknowns

Stands on 5f5, 2e (the product ℚ × ℚ) and 2g (shorthand for sifts).

Two conditions on two unknowns, to be true together, ask for pairs.

From here on, when conditions φ(x, y) and ψ(x, y) on unknowns x and y are to be true together, their solution set is this:

It is 2g's shorthand for the sift of the product ℚ × ℚ (2e) by the pairs whose entries pass both. Conditions to be true together are called a system of equations, or a system of inequalities.

Two new techs join adding-keeps-answers and multiplying-keeps-answers. Substitution: if one condition says x = t, where t is written without x, then t may be put in the place of x in the other condition (the swap axiom). It may be put back again (the swap axiom with the turn-about technique), so the pair keeps its answers. Elimination: add one equation to another. Add-a-sameness technique: from L = R and L′ = R′, L + L′ = R + R′; and from L = R and L + L′ = R + R′, L′ = R′. Forward is the self-sameness axiom and then the swap axiom twice, once at each side; that is the second of the old common notions. Back: swap R for L in the sum (the swap axiom), so R + L′ = R + R′. Then adding-keeps-answers with −R, after turn-about for plus on ℚ, gives L′ = R′. ∎ So replacing one of the two equations by their sum keeps the pair's answers, and so does replacing one by itself multiplied by a rational other than 0 (multiplying-keeps-answers).

2x + 3y = 12,\quad x - y = 1 @@ two conditions on the pair (x, y)
x = \htmlClass{new}{y + 1} @@ adding-keeps-answers on the second: add y; regroup for plus on ℚ, negative on ℚ, plus-zero on ℚ, turn-about for plus on ℚ
2(\htmlClass{new}{y + 1}) + 3y = 12 @@ substitution: y + 1 in the place of x in the first
5y + 2 = 12 @@ rewrite: spread on ℚ, regroup for plus on ℚ, turn-about for plus on ℚ, and 2y + 3y = 5y by spread on ℚ turned about
y = 2,\quad x = 3 @@ adding-keeps-answers with −2, multiplying-keeps-answers with 1/5; then x = y + 1
2\cdot 3 + 3\cdot 2 = 12,\quad 3 - 2 = 1 \;\checkmark @@ check in both: the solution set is {(3, 2)}

Two other things can happen. Take x + y = 3 and 2x + 2y = 7. Multiply the first by −2 (multiplying-keeps-answers) and add it to the second (add-a-sameness): 0 = 1. Every move was licensed, so the pair has the answers of a pair containing 0 = 1, and 0 ≠ 1 is times-one on ℚ: the solution set is ∅. Change the 7 to a 6 and you get 0 = 0 instead, which every pair passes. The second equation said nothing the first did not, and the solution set is every pair with x + y = 3. In both cases the moves tell the truth.

5f10Running it backwards: building an equation

Stands on 5f1 to 5f8.

Every licensed tech keeps the solution set. So start from the answers and go the other way. Begin with x = −2, whose solution set is {−2}, and make licensed techs. Multiply by 3 to get 3x = −6, then add x + 1 to get 4x + 1 = x − 5. That is a respectable exercise, and its answer is −2 because you built it so. Every made-up question on this ladder was made this way. Making them yourself is the quickest way to stop seeing equations as puzzles: they are disguises, and you now know how a disguise is put on.

Illegal moves run backwards too, on purpose. To build an equation with exactly the answers 4 and 1, start from x = 4 and multiply both sides by x − 1. The stranger is now a guest you invited. To build one with no answers in ℚ at all, start from x² = 2 (5e's no-fraction-squares-to-2) and disguise it: add 3x to both sides. The picture lets you do all of this and watch the solution set at every step.

Who said it first

The common notions are Euclid’s, at the head of the Elements.

Euclid set three of these techs among the common notions he took as given before any proposition: things the same as one thing are the same as each other; when equals are added to equals the results are equal; and when equals are taken from equals what remains is equal.

Euclid, Elements I, Common Notions 1–3, after Heath (1908)

Accepted names

A stranger let in by squaring or by multiplying by something that might be 0 is called an extraneous solution.
