5·cb2 · newsflash

Classes of equal pairs

2e built sameness relations and their classes, and said in words that the classes chop a set into pieces, and that this is how mathematics makes new objects. This rung made new objects that way, twice: the integers are classes of pairs of numbers, the fractions classes of pairs of integers, and 5i's ratios a third time. This page goes back to 2e's theory with those examples in hand. The set of all the classes gets a name, the quotient set, and the integers and the fractions turn out to be quotient sets. The partition 2e described in words is proved, both ways. What 5a, 5b and 5c kept calling “honest” gets its general name, well defined, and a technique that says why it is exactly what a definition on classes needs. Then the same construction once more, with a different relation: the remainders on dividing by a fixed number, as classes, with adding carried over.

Choose what counts as the same; check it is a sameness relation; collect the classes into the quotient set. The class map turns the sameness relation into sameness itself. Define anything on classes by working on a member, and check that changing the member to an equivalent one changes nothing.

What this stands on, and where it goes

Stands on 2e (relations, sameness relations, classes, the classes-never-overlap technique), 2d (all the subsets), 4c (functions, rule-makes-a-function), 4i (division-with-remainder, one-split, divides-the-rest, even and odd), 5a, 5b and 5c (ℤ, ℚ and their honesty techniques) and 5i (ratios). Rung 8 builds numbers once more; rung 9 builds the full theory of functions.

What 2e built, and one technique it nearly had

2e's line: a sameness relation on a set A is a relation that is reflexive, symmetric and transitive, written x ∼ y. The class of x is [x] = {y ∈ A : y ∼ x}. And the classes-never-overlap technique says two classes that share a member are the same class. 5a's same-class and 5b's cross-multiplying each began with the same small step, done by hand for their own relation. Here it is once for every sameness relation. Same-class-same-relation technique: for a sameness relation ∼ on A, and x, y ∈ A, [x] = [y] exactly when x ∼ y.

\text{assume } x \sim y @@ the leftward direction first
x \in [x],\quad x \in [y] @@ reflexive, ︿ the class; the assumption, ︿ the class
\htmlClass{new}{[x] = [y]} @@ the classes-never-overlap technique: the classes share the member x
\text{assume } [x] = [y] @@ the rightward direction
y \in [y],\quad \text{so } y \in [x] @@ reflexive, ︿ the class; the swap axiom with the assumption, turned about
y \sim x,\quad \htmlClass{new}{x \sim y} @@ ﹀ the class; symmetric
[x] = [y] \;\Leftrightarrow\; x \sim y \quad \blacksquare @@ prove an if each way; ︿ ⇔

So [3, 5] = [0, 2] because 3 + 2 = 5 + 0 (5a), and 1/2 = 2/4 because 1 · 4 = 2 · 2 (5b). Both are same-class-same-relation with the relation of their page. And same-class-same-relation explains 2e's warning that [x] = [y] does not give x = y: it gives x ∼ y, and that is all.

The set of the classes

From here on, for a sameness relation ∼ on a set a, a/∼ names the set , the set of all the classes. Read it “a over ∼”; it is the quotient set of a by ∼. The slash here always has a relation after it, never a number, so it is not 5b's dividing.

It is a set: each class is a part of A, so a member of 𝒫(A) (2d), and A/∼ is sifted from that (2b). The name fits: the set is divided up into its classes, and each class is one member of the quotient. Now read 5a's and 5b's lines again.

5a's line for ℤ was {c ∈ 𝒫(ℕ × ℕ) : ∃p ∈ ℕ × ℕ (c = [p])}. That is the quotient line with ℕ × ℕ as the set, word for word, so ℤ = (ℕ × ℕ)/∼ by the same-members axiom. In the same way ℚ is the quotient of the fraction pairs by cross-multiplying.

From here on, the class map of ∼ is the function from a to a/∼ given by x ↦ [x] (4c's rule-makes-a-function: [x] ∈ a/∼ for each x ∈ a).

Two facts about it carry the whole construction. Every class is the class map's value at some member: that is what membership in A/∼ says. And two members have the same value exactly when they are equivalent: that is same-class-same-relation. So the class map turns equivalence into sameness. Things that were only “the same in the respect that matters” become, after the map, the same thing, and every tool of 0b (the swap axiom above all) applies to them. Every sameness relation arises this way. Same-value technique: for any function f : A → B, the relation “f(x) = f(y)” is a sameness relation on A. And every sameness relation ∼ on A is of this kind, with f its class map. The first part is the self-sameness axiom, the turn-about technique and the chain technique; the second is same-class-same-relation. ∎

The classes partition the set, proved

2e said in words that classes chop a set into pieces that do not overlap and together cover it. Here is the word with a line, and the proof, both ways.

From here on, a set P of subsets of a is a partition of a when three things are true. (i) Every member of P has a member. (ii) Every member of a is in some member of P. (iii) Two members of P that share a member are the same. The members of P are its pieces.

Classes-partition technique: for a sameness relation ∼ on A, A/∼ is a partition of A.

c \in a/\!\sim\ \Rightarrow\ c = [x] \text{ for some } x \in a @@ ﹀ the quotient; use the some
x \sim x,\ \text{so } x \in [x] = c @@ reflexive; ︿ the class; the swap axiom
\htmlClass{new}{\text{(i): every class has a member}} @@ show an example; prove an if; speak of everything
z \in a\ \Rightarrow\ z \in [z],\ \ [z] \in a/\!\sim @@ reflexive; ︿ the quotient with the witness z
\htmlClass{new}{\text{(ii): every member of } a \text{ is in a class}} @@ show an example; prove an if; speak of everything
c, c' \in a/\!\sim,\ \ w \in c \land w \in c' @@ assume two classes sharing w
c = [x],\ c' = [y],\ \ [x] = [y] @@ ﹀, use the somes; the classes-never-overlap technique
\htmlClass{new}{\text{(iii): } c = c'} \quad \blacksquare @@ the swap axiom; prove an if; speak of everything; join (i), (ii), (iii)

Part (iii) says pieces never partly overlap. Its other face follows with no new tech: if two classes are not the same, they share nothing. Suppose [x] ≠ [y] and w is in both. (iii) gives [x] = [y], a clash. Refute, so no w is in both, and [x] ∩ [y] = ∅ by 2b's one-empty-set. This direction is honest without rung 7, because it ends in a denial.

Pieces-make-classes technique: if P is a partition of A, then “x and y lie in one piece”, ∃p ∈ P (x ∈ p ∧ y ∈ p), is a sameness relation on A, and its quotient is P itself. Reflexive is (ii). Symmetric is 1c's turn-about for And inside the some. Transitive: suppose x and y lie in p, and y and z in p′. Then p and p′ share y, so p = p′ by (iii), and x and z lie in p. And the classes: take x in a piece p. A thing z is in [x] exactly when z and x lie in some piece p′. That p′ shares x with p, so p′ = p by (iii). So [x] = p, and every piece is a class, since by (i) it has a member to be the class of. ∎ So a sameness relation and a partition are two descriptions of one thing: classes-partition goes one way, pieces-make-classes the other.

Well defined

Every operation on this rung was defined by working on members: add the pairs entry by entry, multiply the fraction pairs numerator by numerator and denominator by denominator. And each time a technique had to check that the answer's class does not depend on the members picked (honest-adding on ℤ, honest-multiplying on ℤ, honest-swapping, honest-fractions, honest-negative, honest-positive). That check has a name.

From here on, a rule that takes each member x of a to a thing t(x) of a set B is well defined on the classes of ∼ when equivalent members go to the same thing. In marks: ∀x ∀y (x ∼ y ⇒ t(x) = t(y)). A rule from two members, x and y, to t(x, y) is well defined when changing either member to an equivalent one leaves t(x, y) unchanged.

Well-defined-rule technique: if the rule x ↦ t(x), with each t(x) ∈ B, is well defined on the classes of ∼, then {([x], t(x)) : x ∈ A} is a function from A/∼ to B, whose value at [x] is t(x).

f = \{([x], t(x)) : x \in a\} @@ 2g's shorthand: a sift of (a/∼) × B
c \in a/\!\sim\ \Rightarrow\ c = [x],\ \ (c, t(x)) \in f @@ use the some; the swap axiom: every input has an output
([x], t(x)) \in f,\ \ ([y], t(y)) \in f,\ \ [x] = [y] @@ assume two pairs with the same input (equal-pairs: equal left entries)
x \sim y @@ the same-class-same-relation technique
\htmlClass{new}{t(x) = t(y)} @@ well defined: no input has two outputs
f : a/\!\sim\ \to B,\quad f([x]) = t(x) \quad \blacksquare @@ ︿ 4c's line for a function; 4c's line for the value

With two inputs it is the same column, changing one member at a time and chaining the samenesses, exactly as 5a's honest-multiplying on ℤ did. So 5a's honest-adding on ℤ is the statement that (v, b), (c, d) ↦ [v + c, b + d] is well defined, and well-defined-rule turns it into + on ℤ. Here are rules on classes you have met, sorted.

The last row is new, and worth a column. Suppose (v, b) ∼ (c, d). Then v + d = b + c, so (v + b) + (c + d) = (v + d) + (b + c) = (b + c) + (b + c) = 2(b + c), by middle-swap and the swap axiom: an even number. If 2 divides v + b, then 2 divides c + d too, by 4i's divides-the-rest. If v + b is odd, c + d cannot be even (divides-the-rest would make v + b even, against even-or-odd), so it is odd. So “the sum of the entries is even” is well defined on ℤ, and it says which integers are even. [3, 5] has 3 + 5 = 8, and −2 is even; [2, 1] has 3, and 1 is odd. 4i's words reach the negatives, and well-defined-rule is the licence.

From here on, an integer is also called even when the sum of the entries of a member is even, and odd when it is odd. For a number n, the integer [n, 0] has sum n, so 4i's meaning for numbers is unchanged.

A great book on numbers, two centuries old, opens with a definition: when a number divides the difference of two others, call those two the same with respect to it. It then treats such numbers as one, and builds a whole arithmetic on the classes.

A third construction: remainders as classes

The same shape works with a relation of a different kind. Fix a number n other than 0. 4i's division-with-remainder and one-split give every number m exactly one remainder on dividing by n. So “the remainder of m by n” is a name. And the rule m ↦ the remainder of m by n is a function from ℕ to n = {0, 1, …, n − 1}, by rule-makes-a-function.

From here on, for a number n other than 0 and numbers a and b, a ∼ₙ b means: the remainder of a by n is the remainder of b by n. Read it “a and b leave the same remainder on dividing by n”. The low mark n is part of the mark.

By same-value, ∼ₙ is a sameness relation at once: it is “same value” for the remainder function. With n = 2 there are two classes, [0], the even numbers, and [1], the odd ones (4i's even-or-odd). With n = 3 there are three: [0] = {0, 3, 6, …}, [1] = {1, 4, 7, …}, [2] = {2, 5, 8, …}. The dots here only describe sets already built by the sift. In general: Classes-of-remainders technique: ℕ/∼ₙ has exactly n members, [0], [1], …, [n − 1], no two the same.

r \lt n \;\Rightarrow\; r = n \cdot 0 + r @@ times-zero, zero-plus: so the remainder of r by n is r itself (one-split)
r, r' \lt n,\ \ [r] = [r'] \;\Rightarrow\; r \sim_n r' \;\Rightarrow\; r = r' @@ same-class-same-relation; ﹀ ∼ₙ with the line above: different r, different classes
a = nq + r,\ r \lt n \;\Rightarrow\; a \sim_n r @@ division-with-remainder, the some used: both have remainder r
\phantom{a = nq + r,\ r \lt n} \;\Rightarrow\; [a] = [r] @@ same-class-same-relation: every class is the class of some r < n
r \mapsto [r] \text{ is a matching between } n \text{ and } \mathbb N/\!\sim_n \quad \blacksquare @@ 4j's line for a bijection; so ℕ/∼ₙ has n members

And adding carries over. Remainders-add technique: if m ∼ₙ m′ and b ∼ₙ b′, then m + b ∼ₙ m′ + b′.

a = nq + r,\ a' = nq' + r,\ \ r \lt n @@ division-with-remainder on a and a′; the given: one remainder r for both
b = ns + t,\ b' = ns' + t,\ \ t \lt n @@ likewise
r + t = nu + w,\ \ w \lt n @@ division-with-remainder on r + t
a + b = n(q + s) + (r + t) @@ the swap axiom; regroup for plus, turn-about for plus; spread for times over plus turned about
\phantom{a + b} = n((q + s) + u) + \htmlClass{new}{w} @@ the swap axiom with the line above; regroup for plus; spread for times over plus turned about
a' + b' = n((q' + s') + u) + \htmlClass{new}{w} @@ the same three lines with primes
a + b \sim_n a' + b' \quad \blacksquare @@ one-split: w < n is the remainder of both; ︿ ∼ₙ

From here on, for classes of ∼ₙ, [a] + [b] names [a + b]. Read it “[a] plus [b]”. The remainders-add technique, with well-defined-rule for two inputs, makes the name honest.

Times carries over in the same way. Remainders-multiply technique: if m ∼ₙ m′ and b ∼ₙ b′, then mb ∼ₙ m′b′.

a = nq + r,\ a' = nq' + r,\ \ r \lt n @@ division-with-remainder on a and a′; the given: one remainder r for both
b = ns + t,\ b' = ns' + t,\ \ t \lt n @@ likewise
rt = nu + w,\ \ w \lt n @@ division-with-remainder on rt
ab = n(nqs + qt + rs) + rt @@ spread for times over plus; turn-about and regroup for times; regroup for plus
\phantom{ab} = n((nqs + qt + rs) + u) + \htmlClass{new}{w} @@ the swap axiom with the line above; regroup for plus; spread for times over plus turned about
a'b' = n((nq's' + q't + rs') + u) + \htmlClass{new}{w} @@ the same three lines with primes
ab \sim_n a'b' \quad \blacksquare @@ one-split: w < n is the remainder of both; ︿ ∼ₙ

From here on, for classes of ∼ₙ, [a] · [b] names [a · b]. Read it “[a] times [b]”. The remainders-multiply technique, with well-defined-rule for two inputs, makes the name honest.

So + gains a further job, between classes of ∼ₙ. Between numbers it is still 4e's, and that is the + inside the bracket of [a + b].

With n = 2: [1] + [1] = [2] = [0], which is 4i's “odd plus odd is even” said of classes; [0] + [1] = [1]. With n = 3: [2] + [2] = [4] = [1], and [1] + [2] = [3] = [0]. Each class is named by its member below n, by classes-of-remainders, so a sum of classes is found by adding the names and taking the remainder. The construction is the one this rung began with, in a new setting: name things by members, count equivalent members as one, define on members, check well defined. 5a got an endless set of classes, ℤ; here the quotient has just n members.

Times and powers, on the clock

A clock face is ℕ/∼₁₂ with its hours renamed. Thirteen o'clock is one o'clock: [13] = [1]. Five hours after nine o'clock is two o'clock: [9] + [5] = [14] = [2]. So the classes of ∼ₙ can be pictured as the n hours of a clock with n hours on it, and adding classes is moving the hand round.

Times works on the clock as well. On a clock of 7 hours, [3] · [5] = [15] = [1]. Multiply the names below 7, then take the remainder. That is honest because times carries over: the remainders-multiply technique.

Powers come next, built as 4f built them: a start and a step. Power-carries-over technique: if m ∼ₙ b, then mᵏ ∼ₙ bᵏ for every number k.

a^0 = 1 = b^0,\ \ \text{so } a^0 \sim_n b^0 @@ power-zero, twice; reflexive: the base
\text{assume } a^k \sim_n b^k @@ the step: assumed for one k
a^{S(k)} = a^k \cdot a,\ \ b^{S(k)} = b^k \cdot b @@ the power-of-a-next technique, twice
\htmlClass{new}{a^{S(k)} \sim_n b^{S(k)}} \quad \blacksquare @@ the remainders-multiply technique, with the assumed line and a ∼ₙ b; the induction technique

From here on, for a class [a] of ∼ₙ and a number k, [a]ᵏ names [aᵏ]. The power-carries-over technique, with well-defined-rule, makes the name honest.

Now walk the powers of [3] round the clock of 7 hours. Each step multiplies the last class by [3], and only the names below 7 are ever needed.

On the clock that is [1]¹⁶ · [3]⁴ = [4]. The number 3¹⁰⁰ has 48 digits, and its remainder on dividing by 7 is 4.

Does every walk come back to [1]? Try [2] on the clock of 7 hours, and then on a clock of 6. Which hours does each walk visit?

Running it backwards

Given a partition, read off its relation, “lies in one piece with” (pieces-make-classes), and its classes are the pieces. Given a sameness relation, find a function it is “same value” for. The class map always works (same-value), and often a plainer one does, as the remainder function did for ∼ₙ. Given a rule on members, test it before you use it on classes. Change one member to an equivalent one and see whether the answer moves. One such change that moves it refutes well-definedness (1e's counterexample). A proof needs every change, one input at a time, as honest-multiplying on ℤ and remainders-add did. Given a new kind of number to build, run the rung's whole gesture: a set of names, a relation saying which names name one thing, the quotient, operations checked well defined. Found upward; written downward.

Who said it first

The book on numbers is Carl Friedrich Gauss’s.

Gauss opened his book on numbers with a definition: when a number divides the difference of two others, call those two congruent with respect to it. He then treated the congruent numbers as one, and built a whole arithmetic on the classes.

Gauss, Disquisitiones Arithmeticae (1801), §1–2; paraphrase

Accepted names

m ∼ₙ b is written m ≡ b (mod n), read “m is congruent to b modulo n”, and the arithmetic of its classes is modular arithmetic.
