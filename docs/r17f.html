17f · proof

exp Is Its Own Slope

The logarithm has slope one over the input. Rung 13's technique for the slope of a function run backwards turns that over. The slope of the exponential at a point is one over the logarithm’s slope at the matching point, which is the exponential itself. So exp grows, at every point, exactly as fast as its size. This step proves that, and then proves something stronger: exp is the only function that does so, up to a constant factor. Every function whose slope is a fixed multiple of itself is a constant times an exponential.

The exponential is its own slope, by inverse-slope. If a function is its own slope on an interval, then dividing it by the exponential leaves something with slope zero, so it is a constant times the exponential. If its slope is a fixed multiple of itself, it is its starting value times the exponential of that multiple of the input. The area under the exponential is the exponential, plus a constant. The exponential lies above its tangent line at zero.

17f2The Only One

Slope-equals-size technique: if f′(x) = f(x) at every x of an interval I, then f(x) = Ceˣ on I for some constant C.

g(x) = f(x)\,e^{-x} @@ a guess at what stays fixed
g'(x) = f'(x)e^{-x} - f(x)e^{-x} @@ product for slopes (13c), and (e⁻ˣ)′ = −e⁻ˣ
= f(x)e^{-x} - f(x)e^{-x} = 0 @@ f′ = f
g \text{ is a constant } C \text{ on } I @@ zero-slope-is-constant (14d)
\htmlClass{new}{f(x) = Ce^x} \quad \blacksquare @@ multiply by eˣ (adding-becomes-multiplying: e⁻ˣ · eˣ = 1)

Proportional-slope technique: if f′ = kf on an interval containing 0, then f(x) = f(0)ekx there. The proof is slope-equals-size's with e−kx in place of e⁻ˣ; at x = 0 the constant is f(0). An equation that says how a function's slope depends on the function, such as f′ = kf, has the accepted name differential equation, and f(0) is its initial value.
