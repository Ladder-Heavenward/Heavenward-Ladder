38e · proof

A countable line

The world the last step built was made of names. A language with a list of marks has only a list of names, so that world can be listed. That is a strange thing to learn. Take every statement in marks that is true of the line, the whole line of rung eight with its adding, multiplying and order. They have a world, and so they have a world whose points can be listed, though rung thirty five proved that the line cannot be. Take the axioms for sets, if they have a world at all. They have one that can be listed too, and inside it there is a set that the world itself says cannot be listed. Neither is a clash. A statement can speak only of the members of its world, and what can be listed from outside need not be listable from inside. The step also goes the other way. A collection with one endless world has worlds as large as any set you name, so no collection of statements pins down how many things its world holds.

A collection with a world has a world whose members can be listed, and if it has an endless world, it has worlds at least as large as any set. So the statements true of the line have a countable world, and a countable world of sets can say that a set cannot be listed.

38e1A world no larger than the names

Countable-world technique: if a collection of statements in a listed language has a world, it has a world whose members can be listed; and if it has an endless world, it has one that is endless and can be listed.

M \models G @@ given
G \text{ is clash-free} @@ the world-means-clash-free technique (38c2)
G^* \text{ and its world of names } M^* \text{ exist, with } M^* \models G @@ the full-growth and term-world techniques (38d)
\text{the terms with no placeholder, in a listed language with the names } c_0, c_1, \ldots \text{, can be listed} @@ finite strings of listed marks (35a)
\text{the members of } M^* \text{ are classes of those terms} @@ each class is picked out by the first term listed in it
\htmlClass{new}{\text{the members of } M^* \text{ can be listed}} @@ list the classes in the order of their first terms
\text{if } M \text{ is endless: } M \models \lambda_n \text{ for every } n @@ λₙ, “at least n members”, from 38d4
\htmlClass{new}{G \cup \{\lambda_1, \lambda_2, \ldots\} \text{ has a world that is endless and can be listed}} \quad \blacksquare @@ the same lines, run on the larger collection

38e2Worlds of every endless size

Bigger-world technique: if a collection of statements has an endless world, then for any set X it has a world with at least as many members as X.

\text{add a new name } c_u \text{ for each } u \in X \text{, and the statements } c_u \ne c_v \text{ for } u \ne v @@ a larger language, one that may not be listable
\text{a finite part names only } c_{u_1}, \ldots, c_{u_k} @@ finitely many statements, finitely many names
\text{the endless world of } G \text{, with } c_{u_1}, \ldots, c_{u_k} \text{ sent to different members} @@ an endless set has k different members
\text{every finite part has a world} @@ the other new names may mean anything
\text{the larger collection has a world } M' @@ the finite-parts technique, for a language lined up by a well-order
\htmlClass{new}{u \mapsto c_u^{M'} \text{ is one-to-one from } X \text{ into } |M'|} \quad \blacksquare @@ the statements c_u ≠ c_v: at least as many members as X (35d)

One line needs care. 38d’s growth lined the statements up in a list. A language with a name for every member of X cannot be listed when X cannot. Choice, by way of 6e’s well-ordering, lines its statements up in a well-order, and the rounds of the growth run along it, past ω where needed, as 29·cb3 ran the next-one gesture past the end of the run. So this technique spends choice, and the countable-world technique does not.

So a collection with an endless world never fixes the size of its world. N has as many members as there are names; the statements true in N have worlds as large as the line, and larger.

38e3The line, counted

Write R for the line of rung 8 as a world for the language with names 0 and 1, function marks + and ·, and a relation mark <. Let T be the collection of every statement of that language true in R. T has a world, R itself, so by the countable-world technique it has an endless world C whose members can be listed. Every statement true of the line is true in C.

Listed-line technique: a world of the true statements of the line whose members can be listed has a bounded set of members with no least upper bound among them.

C \models T,\ \ |C| = \{c_0, c_1, c_2, \ldots\} @@ the countable-world technique
\text{suppose every bounded set of members of } C \text{ has a least upper bound in } C @@ aiming to refute
\text{35b’s proof runs in } C \text{: from a list, nested closed stretches miss each listed member in turn} @@ 35b spends only order, the field rules and the least upper bound
\text{the least upper bound of their left ends is a member of } C \text{ on no place of the list} @@ 8c’s property, supposed for C
\bot @@ every member of C is some cₙ
\htmlClass{new}{\text{some bounded set of members of } C \text{ has no least upper bound in } C} \quad \blacksquare @@ refute

So 8c’s least upper bound is true of R and false of C, while every statement of the language is true in both. It is not one of those statements. A formula’s every runs over the members of its world. The least upper bound speaks of every bounded set of members, and no formula of this language can say “every set”. 38l asks what it costs to let one.

38e4A countable world of sets

The axioms for sets the ladder has laid down, those of rungs 2, 3 and 6 with 29·cb3’s Replace, are statements in the language with one mark ∈. The language is listed, so the list of axioms can be written as one listed collection, Z, with Sift and Replace as one axiom for each formula. 35c proved that a set has more parts than members, so Z reaches “the set of all parts of ω cannot be listed”.

Seen-from-outside technique: if the axioms for sets have a world, they have one whose members can be listed from outside, and in it a set that the world says cannot be listed.

M \models Z,\ \ |M| \text{ listed from outside} @@ the countable-world technique, if Z has a world at all
Z \vdash \neg\exists f\,(f \text{ matches } \omega \text{ onto } \mathcal P(\omega)) @@ 35c, written in the calculus
M \models \neg\exists f\,(f \text{ matches } \omega \text{ onto } \mathcal P(\omega)) @@ the true-everywhere technique (38c)
p = \text{the member of } M \text{ that } M \text{ takes for } \mathcal P(\omega);\ \ \text{its members in } M \text{ are among a listed set} @@ from outside, every member of M is on the list
g = \text{the outside listing of the members of } p \text{, a set of pairs} @@ built outside M, by 35a’s listing
\htmlClass{new}{g \text{ is not a member of } M} \quad \blacksquare @@ if it were, the third line would be false in M

Inside M, “cannot be listed” means: no member of M is a matching. The outside listing exists, and it is not in M. What a world can say is fixed by what is in it. Whether Z has a world at all is a question this rung comes back to in 38j.

The basement · there if you want it

The accepted names

The countable-world technique is the downward Löwenheim–Skolem theorem; the bigger-world technique is the upward Löwenheim–Skolem theorem, and with both, a theory with an infinite model has models of every infinite cardinality at least that of its language. The seen-from-outside technique is Skolem’s paradox, which is no paradox: countability is not absolute between models. The listed-line technique says that a countable model of the first-order theory of the real field is not Dedekind complete; the real algebraic numbers are one such model.

Who said it first

Leopold Löwenheim proved the first form in 1915, for one statement. Thoralf Skolem simplified and widened it in 1920 and 1922, and in his lecture of 1922 drew from it the countable model of set theory. The upward form was given by Alfred Tarski, with Robert Vaught, in the 1950s; Anatolii Maltsev had proved a form of it in 1936. Alfred Tarski showed around 1930 that the first-order statements true of the real field are the same as those true of the real algebraic numbers, and that a recipe can decide them.

A proof that is not allowed

“M is a world of the axioms of sets whose members can be listed. So M satisfies ‘every set can be listed’.” Not allowed: the listing of M is a set of pairs outside M, and a statement true in M speaks only of members of M. The axioms reach “𝒫(ω) cannot be listed”, so that statement is true in M, by the true-everywhere technique.
