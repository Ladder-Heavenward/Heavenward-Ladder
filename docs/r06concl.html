6·∎ · conclusion

You can pick without a rule

From any collection of sets, each with something in it, one object can hold a member of each, all at once. For finitely many you can pick by hand, and with a rule you can pick from endlessly many; without a rule, only an axiom says such a picking exists, and that axiom has to be chosen.

What the rung set out to show

The survey of rung 6 promised one member from every set of a collection, all at once, even with endlessly many sets and nothing to say which member to take. 6a defined a choosing function, laid down the choosing axiom, and showed rules that pick with no axiom: the left-shoes and least-chooses techniques. It also showed why socks have no rule.

6b proved the finite-choice technique by induction, one call per set, and turned it about into the only-the-infinite-fails technique. 6c described a world where the axiom is true and one where it is false, and worked by hand the heart of the sock world. This page puts the pieces in one place. It also says honestly which part of the claim is laid down and which is proved.

The claim, in full

From any collection of sets each with a member, one member of each can be picked at once: by hand when the collection is finite, by a rule when there is one, and otherwise the picking exists only by the choosing axiom, which can be neither proved nor refuted.

Let 𝒜 be a collection of sets, each non-empty.

A choosing function for 𝒜 is a function c : 𝒜 → ⋃𝒜 with c(A) ∈ A for every A ∈ 𝒜.

If a condition is so of exactly one member of each set in 𝒜, then 𝒜 has a choosing function, with no axiom.

If 𝒜 has n members for some number n, then 𝒜 has a choosing function, with no axiom.

So if 𝒜 has no choosing function, 𝒜 is infinite and has no rule.

The choosing axiom says every such 𝒜 has a choosing function. It is laid down, not proved, and it cannot be refuted from the other principles either.

The proof

The first part is 6a's left-shoes column with any rule in place of “is a left shoe”. A rule is a condition φ(A, x) that, in each set A of 𝒜, is so of exactly one member. Least-chooses is the same column with “x is the least member of A”.

c = \{(A, x) \in \mathcal A \times \textstyle\bigcup\mathcal A : x \in A \land \varphi(A, x)\} @@ Separation, written with 2g's shorthand
\text{let } A \in \mathcal A;\ \text{call } x \text{ with } x \in A \land \varphi(A, x) @@ the rule: at least one; use a some
x \in \textstyle\bigcup \mathcal A,\ \ \htmlClass{new}{(A, x) \in c} @@ 2c's line for ⋃, with A as the example; ︿ the sift: every input has an output
(A, x) \in c \land (A, y) \in c \;\Rightarrow\; x = y @@ ﹀ the sift twice; the rule: at most one. No input has two
c : \mathcal A \to \textstyle\bigcup\mathcal A,\quad c(A) \in A @@ ︿ 4c's line for a function; the value line, and the sift unpacked
\htmlClass{new}{c \text{ chooses for } \mathcal A} \quad \blacksquare @@ ︿; speak of everything. No axiom was used

The second part is 6b's finite-choice technique, proved by induction on the number of sets, one call per step. Turned about, it says where a choosing function can be missing.

\forall A \in \mathcal A\,(A \text{ non-empty}),\ \ \neg\exists c\,(c \text{ chooses for } \mathcal A) @@ given
\quad \text{assume } \exists n\,(\mathcal A \text{ has } n \text{ members});\ \text{call it } n @@ aiming to refute; use a some
\quad \exists c\,(c \text{ chooses for } \mathcal A) @@ the finite-choice technique (6b), used with n and 𝒜; carry an if through
\quad \bot @@ clash
\htmlClass{new}{\neg\exists n\,(\mathcal A \text{ has } n \text{ members})} \quad \blacksquare @@ refute: 𝒜 is infinite (6a's line)

And by the first part, a collection with no choosing function has no rule. Both conditions are needed: endlessly many pairs of shoes have a rule, and a few pairs of socks on the bed can be picked by hand.

The third part is the axiom itself. Endlessly many pairs of socks, 𝒦, in bijection with ℕ, are infinite and have no rule: whatever is so of one sock of a pair is so of the other.

\forall K \in \mathcal K\,(K \text{ non-empty}) @@ given: each pair holds a sock
\mathcal K \text{ is infinite, with no rule} @@ given: the socks of 6a, matched with ℕ
\htmlClass{new}{\exists c\,(c \text{ chooses for } \mathcal K)} \quad \blacksquare @@ the choosing axiom (6a)

A proof uses the line as it uses any some: “call such a function c”, a fresh name, and a last line that does not mention c. Nothing says which sock c takes from any pair. That is the whole difference from a rule.

The last part is why the third part is an axiom. 6c described it, as 3c described its world; the great constructions are beyond the ladder, and their pieces worked by hand are cited here.

\text{a world of the other principles where choice fails} @@ the 1963 world, described on 6c; its heart is the no-sock-picking technique, worked there line by line
\text{a world of the other principles where choice is true} @@ the world of described sets, 6c: take the member whose earliest description comes first
\htmlClass{new}{\text{no proof of choice, and no proof of its denial}} \quad \blacksquare @@ the world-building tech (3c), run both ways

So picking without a rule is a choice, like infinity on rung 3. The ladder makes it, as almost all of mathematics does, and says so wherever it is used.

  • 6·phys can a scale be perfectly in tune?: Sets beside the claim a different kind of “cannot”: one splitting into primes per number (4i) shows that no stack of pure fifths ever lands on a stack of octaves, so every tuning has to give something up.its line appears when you finish it.
  • 6·chem who gives up electrons?: A rule that picks, giving each bond's electrons to the atom that grasps harder and splitting them when no rule can pick, turns "who gives up electrons" into signed whole numbers that always add up to the charge.its line appears when you finish it.
  • 6·logi can every job get a driver?: A dispatcher's assignment is a choosing function on a finite list, so it needs no axiom. Fairness adds a real obstacle: a group of jobs with fewer drivers than jobs. Where the picks do not matter, a rule that picks must still be written down.its line appears when you finish it.

You can pick by hand, by a rule, or by an axiom you chose, and you know which is which. This is a first look at choosing, and you are just getting started.
