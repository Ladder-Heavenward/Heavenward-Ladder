14e · proof

Same Slopes, Same Shape Lifted

13d's lifting said that lifting a function by a constant changes no slope: a function and the same function lifted have the same slope at every input. Three steps of rung 13 then found functions with a given slope: the square for twice the input, the cube for three times the square. Each time they said that adding a constant gives another, and asked whether those are all. Run lifting backwards. If two functions have the same slope at every input of an interval, their difference has slope 0 there, and 14d's zero-slope-is-constant makes the difference a constant. So the answer to “what has this slope?” is one function and every lift of it, and nothing else, on an interval. That one sentence settles which motion a falling or braking body can have, and which curve a decay can follow.

Two functions with the same slope on an interval have a difference whose slope is 0 there. By zero-slope-is-constant the difference is a constant, so one is the other lifted.

14e1The Technique

Same-slopes technique: if f and g have slopes at every input of an interval I, and f′(x) = g′(x) for every x ∈ I, then for some real C, f(x) = g(x) + C for every x ∈ I.

d(x) = f(x) - g(x) @@ 10c's difference of functions
d'(x) = f'(x) - g'(x) = 0 \text{ for } x \in I @@ slopes-add and constant-factor for slopes (13d), with the constant −1
\htmlClass{new}{d \text{ is constant on } I} @@ zero-slope-is-constant (14d): the domain is an interval
\text{call it } C:\ f(x) = g(x) + C \quad \blacksquare @@ C = f(x₀) − g(x₀) for any one x₀ ∈ I

Every hypothesis is spent in zero-slope-is-constant. So the whole of rung 14 so far is under this one line. Zero-slope-is-constant needs average-slope, average-slope needs level-ends, level-ends needs flat-top and highest-and-lowest, and highest-and-lowest needs no-holes.

14e2Antiderivatives

From here on, F is an antiderivative of f on an interval I when F has a slope at every input of I and F′(x) = f(x) for every x ∈ I. Its accepted name is antiderivative; some books say primitive. The rule that names a constant for the family is written “+ C”. The mark is shorthand for the whole family: F + C names one member for each real C.

All-antiderivatives technique: if F is an antiderivative of f on an interval I, then the antiderivatives of f on I are exactly the functions F + C, one for each real C. Each F + C is one, by lifting. Any antiderivative G has G′ = f = F′ on I, so G = F + C by same-slopes. ∎

So 13d's, 13g's and 13h's question has its answer. Reading the power rule backwards gives the antiderivatives of a power:

\left(\tfrac{x^{n+1}}{n + 1}\right)' = x^n \text{ for every whole } n \ge 0 @@ power for slopes (13d) and constant-factor for slopes
x^n:\ \ \htmlClass{new}{\tfrac{x^{n+1}}{n + 1} + C} \text{ on } \mathbb{R} @@ all-antiderivatives: all of them
x^{-3}:\ \ -\tfrac{1}{2x^2} + C \text{ on } (0, \infty), \text{ and on } (-\infty, 0) @@ quotient for slopes (13f) for the slope of 1/x²; one interval at a time
x^{1/2}:\ \ \tfrac23 x^{3/2} + C \text{ on } (0, \infty) @@ fraction-power for slopes (13h): (x^(3/2))′ = (3/2)x^(1/2)
6x^2 - 4x + 5:\ \ 2x^3 - 2x^2 + 5x + C @@ slopes-add and constant-factor for slopes run backwards, term by term; check by polynomial-slope

The rule xⁿ⁺¹/(n + 1) breaks at one power. For n = −1 it asks to divide by 0. Nothing on this ladder so far has slope 1/x, and no power of x does.

The interval matters, as it did in zero-slope-is-constant. Take the domain ℝ without 0, and the function equal to −1/x + 1 for x > 0 and −1/x − 2 for x < 0. It has slope 1/x² at every input, the same as −1/x. It differs from −1/x by 1 on one side and by −2 on the other. There, the family needs one constant for each interval of the domain.

14e3One Motion, Not Many

Take as given a body falling near the ground with a constant acceleration −g. Its velocity is the slope of its height, y′ (14c), and its acceleration is the slope of its velocity, y″. Is the height ½gt² below the start the only one that fits? Here is the answer, with the slopes run twice.

y''(t) = -g \text{ for every } t,\ \ y(0) = y_0,\ \ y'(0) = v_0 @@ the acceleration, the start, the starting velocity
y'(t) = -gt + C_1 @@ all-antiderivatives: y′ is an antiderivative of the constant −g
C_1 = v_0 @@ at t = 0
y(t) = -\tfrac12 g t^2 + v_0 t + C_2 @@ all-antiderivatives again: an antiderivative of −gt + v₀
\htmlClass{new}{y(t) = y_0 + v_0 t - \tfrac12 g t^2} @@ C₂ = y₀ at t = 0: one motion, and no other

Two facts at one instant, the position and the velocity, pick one function out of the family. The acceleration fixes the shape, and each constant is a single lift. The same lines make a braking car's x = 25t − 2.5t², from x(0) = 0, v(0) = 25 m/s and an acceleration of −5 m/s², the only motion that fits. 13·phys held both in trust, and those flags are closed here.

14e4Decay Curves, Compared

Take as given a chemical that breaks down at a rate proportional to how much is left. Its concentration y(t), in mol/L, has slope y′ = −ky for a constant k > 0. Compare a curve from 0.0200 mol/L with one from 0.0100 mol/L. What does that rate alone say about them? Same-slopes does not apply directly, because the two curves have different slopes. But their ratio has slope 0.

y' = -ky,\ \ z' = -kz \text{ on an interval},\ \ z \ne 0 \text{ there} @@ two concentrations under one rate law
\left(\tfrac{y}{z}\right)' = \tfrac{y'z - yz'}{z^2} @@ quotient for slopes (13f)
= \tfrac{(-ky)z - y(-kz)}{z^2} = 0 @@ the law, twice; the two terms cancel
\htmlClass{new}{y = Cz},\ \ C = \tfrac{y(0)}{z(0)} @@ zero-slope-is-constant: the ratio is constant

So a curve from twice the start is twice the curve, at every instant: it halves in the same time. Which function decays this way has to wait for rung 17. But whatever it is, every first-order curve with this k is a multiple of it.

One of the inventors of the calculus, in a letter meant for the other, hid his method in an anagram of letters. He said only that it found the rates of any quantities joined by an equation, and the reverse: given the rates, the quantities.

14e6Running It Backwards

Handed a slope and asked for the function, run the slope rules backwards term by term, check by taking the slope, and add + C. Handed a value at one input, solve for C. Handed a second slope, do it twice and expect two constants. Handed a claim that two functions with the same slopes differ by a constant, check that the domain is an interval. Handed a formula that relates a function to its own slope, look for a ratio or a difference whose slope is 0. Found upward; written downward.
