27f · proof

The arrows a map only stretches

Most arrows are turned by a map as well as stretched. A few are only stretched: the map sends each of them along its own line. Find those arrows and the map becomes simple. In their directions it does nothing but stretch, and doing it a hundred times is stretching a hundred times. The determinant of the last step finds the stretches, as the roots of a polynomial.

An arrow that a grid only stretches, by some number, gives that number as a root of one polynomial built from the grid. Arrows stretched by different numbers are free, so a grid with n different stretches is plain stretching in the right directions.

What this stands on, and where it goes

Stands on 27e (the determinant), 27b (free arrows) and 25d (every polynomial has a root). 27g puts the grid into its own polynomial.

27f1Only stretched

Stands on 27e4.

An arrow v ≠ 0 is only stretched by a square grid A if Av = λv for some number λ, its stretch. Accepted name: v is an eigenvector of A, and λ its eigenvalue.

Stretch-test technique: λ is a stretch of A exactly when det(A − λI) = 0. As λ varies, det(A − λI) is a polynomial in λ of degree n, with (−1)ⁿλⁿ first.

Av = \lambda v,\ v \ne 0 \iff (A - \lambda I)v = 0,\ v \ne 0 @@ λv = λIv, and grids spread over sums (27d2)
\iff A - \lambda I \text{ loses more than } 0 @@ the definition of what it loses (27c1)
\iff A - \lambda I \text{ cannot be undone} @@ the undoable-group technique (27d3)
\iff \det(A - \lambda I) = 0 @@ the nonzero-det technique (27e4)
\det(A-\lambda I) = \textstyle\sum_\sigma \operatorname{sign}\sigma \prod_j (a_{\sigma(j)j} - \lambda\,[\sigma(j){=}j]) @@ the three-rules formula (27e2)
\htmlClass{new}{\text{a polynomial of degree } n,\ \text{first term } (-\lambda)^n} \quad \blacksquare @@ only σ = doing nothing gives n factors with λ

By the root technique of 25d, that polynomial has a root in ℂ. So every square grid has a stretch, and an arrow it only stretches, once complex numbers are allowed. The quarter turn of the plane has none on the real line: its stretches are i and −i.

27f2Different stretches, free arrows

Stands on 27f1 and 27b1.

Different-stretches technique: arrows only stretched by A, with stretches all different, are free.

v_1..v_k \text{ not free};\ v_j = c_1v_1 + \cdots + c_{j-1}v_{j-1},\ v_1..v_{j-1} \text{ free} @@ the spare-arrow technique (27b1), with the first such j
\lambda_jv_j = Av_j = c_1\lambda_1v_1 + \cdots + c_{j-1}\lambda_{j-1}v_{j-1} @@ apply A to the mix
\lambda_jv_j = c_1\lambda_jv_1 + \cdots + c_{j-1}\lambda_jv_{j-1} @@ stretch the mix by λⱼ
0 = c_1(\lambda_1 - \lambda_j)v_1 + \cdots + c_{j-1}(\lambda_{j-1} - \lambda_j)v_{j-1} @@ subtract
c_i(\lambda_i - \lambda_j) = 0 \Rightarrow \text{all } c_i = 0 \Rightarrow v_j = 0 @@ v₁..vⱼ₋₁ are free, and the stretches differ
\htmlClass{new}{v_1..v_k \text{ are free}} \quad \blacksquare @@ vⱼ ≠ 0, so the first line cannot happen

27f3Plain stretching, in the right directions

Stands on 27f2, 27d2 and 27d3.

Straighten-out technique: if A, n × n, has n free arrows v₁, …, vₙ that it only stretches, by λ₁, …, λₙ, and P is the grid with those columns, then A = P D P⁻¹, where D has λ₁, …, λₙ down its middle and 0 elsewhere; and Aᵏ = P Dᵏ P⁻¹ for every counting number k. In particular this holds when A has n different stretches.

AP = A[v_1 \cdots v_n] = [\lambda_1v_1 \cdots \lambda_nv_n] @@ the product-is-doing technique (27d2), column by column
[\lambda_1v_1 \cdots \lambda_nv_n] = PD @@ PD’s column j is P times λⱼeⱼ, which is λⱼvⱼ
P \text{ is undoable} @@ its columns are free, so it loses only 0 (27d3)
A = PDP^{-1} @@ multiply AP = PD by P⁻¹ on the right
A^k = PDP^{-1}PDP^{-1}\cdots PDP^{-1} = PD^kP^{-1} @@ each P⁻¹P in the middle is I
\htmlClass{new}{A^k = PD^kP^{-1},\ D^k \text{ has } \lambda_j^k \text{ down its middle}} \quad \blacksquare

Not every grid can be straightened out. The grid with rows (1, 1), (0, 1) slides the plane along the floor. Its only stretch is 1, and every arrow it only stretches lies on the floor, so there are not two free ones.

27f4Illegal moves

Stands on 27f1 to 27f3.

Av = \lambda v \text{ with } v = 0 \text{ makes } \lambda \text{ a stretch}\,? @@ every λ does that with v = 0; the arrow must not be 0
\text{the stretches of } A \text{ are its middle entries}\,? @@ only for a grid with 0 on one side of the middle; rows (0, 1), (1, 0) has middle 0, 0 and stretches 1, −1
\text{the stretches of } AB \text{ are products of stretches of } A \text{ and } B\,? @@ not in general; each arrow is only stretched by its own grid
\text{every real grid has a real stretch}\,? @@ the quarter turn has stretches i and −i only

The basement · there if you want it

The accepted names

An arrow a grid only stretches is an eigenvector, and its stretch is an eigenvalue. det(A − λI), as a polynomial in λ, is the characteristic polynomial (often written det(λI − A), which differs by the sign (−1)ⁿ). To straighten out A is to diagonalise it; D is a diagonal matrix, and A and D are similar. The slide with rows (1, 1), (0, 1) is a shear.

Who said it first

Euler studied the axes a spinning body turns about in the 1750s, and Joseph-Louis Lagrange found stretches of this kind in the motions of the planets. Augustin-Louis Cauchy proved in 1829 that a symmetric grid has real stretches. The word eigen, German for own, came from David Hilbert in 1904.
