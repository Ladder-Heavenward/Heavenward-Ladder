27f · proof

The Vectors a Map Only Stretches

Most vectors are turned by a map as well as stretched. A few are only stretched: the map sends each of them along its own line. Find those vectors and the map becomes simple. In their directions it does nothing but stretch, and doing it a hundred times is stretching a hundred times. The determinant of the last step finds the stretches, as the roots of a polynomial.

A vector that a grid only stretches, by some number, gives that number as a root of one polynomial built from the grid. Vectors stretched by different numbers are free, so a grid with n different stretches is plain stretching in the right directions.

27f1Only Stretched

A vector v ≠ 0 is only stretched by a square grid A if Av = λv for some number λ, its stretch. Accepted name: v is an eigenvector of A, and λ its eigenvalue.

Stretch-test technique: λ is a stretch of A exactly when det(A − λI) = 0. As λ varies, det(A − λI) is a polynomial in λ of degree n, with (−1)ⁿλⁿ first.

Av = \lambda v,\ v \ne 0 \iff (A - \lambda I)v = 0,\ v \ne 0 @@ λv = λIv, and grids spread over sums (27d2)
\iff A - \lambda I \text{ loses more than } 0 @@ ﹀ “loses” (27c1)
\iff A - \lambda I \text{ cannot be undone} @@ the undoable-group technique (27d3)
\iff \det(A - \lambda I) = 0 @@ the nonzero-det technique (27e4)
\det(A-\lambda I) = \textstyle\sum_\sigma \operatorname{sign}\sigma \prod_j (a_{\sigma(j)j} - \lambda\,[\sigma(j){=}j]) @@ the three-conditions formula (27e2)
\htmlClass{new}{\text{a polynomial of degree } n,\ \text{first term } (-\lambda)^n} \quad \blacksquare @@ only σ = doing nothing gives n factors with λ

By the root technique of 25d, that polynomial has a root in ℂ. So every square grid has a stretch, and a vector it only stretches, once complex numbers are allowed. The quarter turn of the plane has none on the real line: its stretches are i and −i.

27f2Different Stretches, Free Vectors

Different-stretches technique: vectors only stretched by A, with stretches all different, are free.

v_1..v_k \text{ not free};\ v_j = c_1v_1 + \cdots + c_{j-1}v_{j-1},\ v_1..v_{j-1} \text{ free} @@ the spare-vector technique (27b1), with the first such j
\lambda_jv_j = Av_j = c_1\lambda_1v_1 + \cdots + c_{j-1}\lambda_{j-1}v_{j-1} @@ apply A to the mix
\lambda_jv_j = c_1\lambda_jv_1 + \cdots + c_{j-1}\lambda_jv_{j-1} @@ stretch the mix by λⱼ
0 = c_1(\lambda_1 - \lambda_j)v_1 + \cdots + c_{j-1}(\lambda_{j-1} - \lambda_j)v_{j-1} @@ subtract
c_i(\lambda_i - \lambda_j) = 0 \Rightarrow \text{all } c_i = 0 \Rightarrow v_j = 0 @@ v₁..vⱼ₋₁ are free, and the stretches differ
\htmlClass{new}{v_1..v_k \text{ are free}} \quad \blacksquare @@ vⱼ ≠ 0, so the first line cannot happen

27f3Plain Stretching, in the Right Directions

Straighten-out technique: if A, n × n, has n free vectors v₁, …, vₙ that it only stretches, by λ₁, …, λₙ, and P is the grid with those columns, then A = P D P⁻¹, where D has λ₁, …, λₙ down its middle and 0 elsewhere; and Aᵏ = P Dᵏ P⁻¹ for every counting number k. In particular this holds when A has n different stretches.

AP = A[v_1 \cdots v_n] = [\lambda_1v_1 \cdots \lambda_nv_n] @@ the product-is-doing technique (27d2), column by column
[\lambda_1v_1 \cdots \lambda_nv_n] = PD @@ PD’s column j is P times λⱼeⱼ, which is λⱼvⱼ
P \text{ is undoable} @@ its columns are free, so it loses only 0 (27d3)
A = PDP^{-1} @@ multiply AP = PD by P⁻¹ on the right
A^k = PDP^{-1}PDP^{-1}\cdots PDP^{-1} = PD^kP^{-1} @@ each P⁻¹P in the middle is I
\htmlClass{new}{A^k = PD^kP^{-1},\ D^k \text{ has } \lambda_j^k \text{ down its middle}} \quad \blacksquare

Not every grid can be straightened out. The grid with rows (1, 1), (0, 1) slides the plane along the floor. Its only stretch is 1, and every vector it only stretches lies on the floor, so there are not two free ones.

27f4A Space That a Map Keeps

Let T be a straight map from V to itself. A space W inside V is kept by T when T(w) is in W for every w in W. Then T, used only on the vectors of W, is a straight map from W to itself: the map on W. What T loses is kept, and so is what T reaches. For any number λ, the vectors with Tv = λv, together with 0, form a kept space: the line through a vector that T only stretches is the smallest case.

Kept-space technique: take a basis of V whose first k vectors are a basis of W. Then W is kept by T exactly when the grid of T in that basis has 0 in every place below row k in its first k columns.

w_1..w_k,\ v_{k+1}..v_n \text{ a basis of } V @@ a basis of W, grown (27b3)
\text{column } j = \text{the numbers of } T(w_j),\ j \le k @@ the grid of T in the basis (27d4)
T(w_j) \in W \iff T(w_j) \text{ is a mix of } w_1..w_k @@ the w’s are a basis of W; a vector has one list (27b5)
\iff \text{column } j \text{ is } 0 \text{ below row } k @@ read the list
T(w_j) \in W \text{ for each } j \iff T(w) \in W \text{ for all } w @@ T keeps mixes (27c1)
\htmlClass{new}{W \text{ kept} \iff \text{the block is } 0} \quad \blacksquare @@ the lines above

The top left k × k corner of that grid is then the grid of the map on W. So a stretch of the map on W is a stretch of T, with the same vector. In the plane, the slide with rows (1, 1), (0, 1) keeps the floor, the lists (x, 0), and on the floor it changes nothing. It keeps no other line through 0, which is 27f3’s reason that it cannot be straightened out.

27f5Grids That Swap

Two square grids A and B swap when AB = BA. Let A, n × n, have n different stretches λ₁, …, λₙ, with vectors v₁, …, vₙ that it only stretches. They are a basis, by the different-stretches technique (27f2).

Swap technique: if AB = BA and A has n different stretches, then B only stretches each vᵢ, so one P straightens out both grids; and B is a polynomial in A.

Aw = \lambda_1 w,\ w = \textstyle\sum c_iv_i \Rightarrow \sum c_i(\lambda_i - \lambda_1)v_i = 0 @@ put the mix into Aw − λ₁w = 0
\Rightarrow c_i = 0 \text{ for } i \neq 1 \Rightarrow w = c_1v_1 @@ the vᵢ are free and the stretches differ
A(Bv_1) = B(Av_1) = \lambda_1(Bv_1) @@ AB = BA
\Rightarrow Bv_1 = \mu_1v_1 @@ the first two lines, with w = Bv₁; the same for each vᵢ
L_j(A) = \textstyle\prod_{k \neq j}(A - \lambda_kI)\,/\,(\lambda_j - \lambda_k) @@ a polynomial in A; (A − λₖI)vᵢ = (λᵢ − λₖ)vᵢ
L_j(A)v_j = v_j,\ \ L_j(A)v_i = 0 \text{ for } i \neq j @@ the factor k = i gives 0
\htmlClass{new}{B = \mu_1L_1(A) + \cdots + \mu_nL_n(A)} \quad \blacksquare @@ both sides send each vᵢ to μᵢvᵢ, and the vᵢ are a basis

With P the grid whose columns are the vᵢ, both P⁻¹AP and P⁻¹BP have 0 off the middle (27f3). The stretches μᵢ of B need not differ. The technique needs the n different stretches of A. Every grid swaps with I, and I has one stretch only, so there the technique says nothing, as it should: not every grid is a polynomial in I.

27f6AB and BA Have the Same Stretches

AB and BA are different grids in general (27d7). Their stretches are the same.

Swapped-product technique: for n × n grids A and B, a number is a stretch of AB exactly when it is a stretch of BA. In particular I − AB is undoable exactly when I − BA is.

ABv = \lambda v,\ v \neq 0,\ \lambda \neq 0 @@ a stretch of AB other than 0
Bv \neq 0 @@ if Bv = 0 then λv = A(Bv) = 0
BA(Bv) = B(ABv) = \lambda(Bv) @@ grouping-free (27d2): λ is a stretch of BA
\det(AB) = \det A\cdot\det B = \det(BA) @@ det-product (27e3)
0 \text{ is a stretch of } AB \iff 0 \text{ is a stretch of } BA @@ the stretch test (27f1) at λ = 0
\htmlClass{new}{AB \text{ and } BA \text{ have the same stretches}} \quad \blacksquare @@ and the same with A and B changed over

I − AB loses a vector other than 0 exactly when ABv = v for some v ≠ 0, that is, when 1 is a stretch of AB. So I − AB is undoable exactly when 1 is not a stretch of AB, and the technique passes that to BA. The undo can be written down: (I − BA)⁻¹ = I + B(I − AB)⁻¹A. Multiply out (I − BA)(I + B(I − AB)⁻¹A) = I − BA + B(I − AB)(I − AB)⁻¹A = I − BA + BA = I.

For grids that are not square the technique still holds for stretches other than 0, by its first three lines. It fails at 0: a column times a row is a square grid that loses vectors, while the row times the column is a single number.

27f7Flattening Onto One Space Along Another

A straight map E from V to itself is a flattening when doing it twice is doing it once: E(Ev) = Ev for every v.

Flattening technique: a flattening E leaves alone every vector it reaches, every vector is a reached vector plus a lost vector in exactly one way, and I − E is a flattening that reaches what E loses and loses what E reaches.

w = Ev \Rightarrow Ew = E(Ev) = Ev = w @@ E leaves alone what it reaches
E(Ev) = 0 \Rightarrow Ev = 0 @@ since E(Ev) = Ev
\text{lost and reached share only } 0 \text{ and build } V @@ the lost-meets-reached technique (27c3)
v = Ev + (v - Ev),\ \ E(v - Ev) = 0 @@ the one way to split v (27b4)
(I - E)(I - E) = I - 2E + EE = I - E @@ so I − E is a flattening
\htmlClass{new}{E + (I - E) = I,\ \ E(I - E) = 0} \quad \blacksquare @@ I − E sends v to its lost part

So E flattens V onto what it reaches, along what it loses. The other way round, if U and W are spaces inside V that share only 0 and build V, each v is u + w in one way (27b4), and v ↦ u is a flattening onto U along W. In the plane, E(x, y) = (x + y, 0) flattens onto the floor along the line of the lists (t, −t). It is not the flattening straight down, (x, y) ↦ (x, 0), which goes onto the same floor along the y-axis. A flattening is fixed by both of its spaces.

In a basis made of a basis of what E reaches, then a basis of what E loses, the grid of E has 1s and then 0s down its middle and 0 elsewhere. So a flattening can always be straightened out, and its stretches are 0 and 1 only.

27f8A Map That Keeps Every Space

The map v ↦ c·v, whose grid is c times I in every basis, keeps every space inside V. Nothing else does.

Keeps-all technique: a straight map T from V to itself that keeps every line through 0 is v ↦ c·v for one number c.

Tv = c_v\,v \text{ for each } v \neq 0 @@ T keeps the line through v
u, v \text{ free}:\ T(u + v) = c_{u+v}\,(u + v) @@ the line through u + v is kept too
T(u + v) = Tu + Tv = c_u\,u + c_v\,v @@ T keeps adding
(c_{u+v} - c_u)\,u + (c_{u+v} - c_v)\,v = 0 \Rightarrow c_u = c_v @@ u and v are free
v = t\cdot u \Rightarrow Tv = t\cdot Tu = c_u\,v @@ on one line the number is the same
\htmlClass{new}{T = c\,I} \quad \blacksquare @@ one number c serves every vector

A turn of the plane by a right angle keeps the plane and keeps {0}, and no line. A stretch of the plane by 2 along the floor and 3 along the wall keeps both of those lines and no other. The fewer spaces a map keeps, the less like a plain stretch it is. And c·I swaps with every grid, since (cI)B = cB = B(cI).

27f9Moves to Watch Out For

Av = \lambda v \text{ with } v = 0 \text{ makes } \lambda \text{ a stretch}\,? @@ <span class="vd vd-a">out of arrangement</span> every λ does that with v = 0; the vector must not be 0
\text{the stretches of } A \text{ are its middle entries}\,? @@ <span class="vd vd-p">outside the plan</span> only for a grid with 0 on one side of the middle; rows (0, 1), (1, 0) has middle 0, 0 and stretches 1, −1
\text{the stretches of } AB \text{ are products of stretches of } A \text{ and } B\,? @@ <span class="vd vd-p">outside the plan</span> not in general; each vector is only stretched by its own grid
\text{every real grid has a real stretch}\,? @@ <span class="vd vd-p">outside the plan</span> the quarter turn has stretches i and −i only
T \text{ keeps } W \Rightarrow T \text{ stretches some } w\,? @@ <span class="vd vd-p">outside the plan</span> a quarter turn keeps the whole plane and only stretches no vector of it but 0
AB = BA \Rightarrow B \text{ is a polynomial in } A\,? @@ <span class="vd vd-p">outside the plan</span> only when A has n different stretches: I swaps with every grid
ABv = \lambda v \Rightarrow BAv = \lambda v\,? @@ <span class="vd vd-p">outside the plan</span> the same stretches, other vectors: it is Bv that BA stretches by λ
EE = E \Rightarrow E = I \text{ or } E = 0\,? @@ <span class="vd vd-p">outside the plan</span> rows (1, 0), (0, 0) flatten the plane onto the first axis
\text{keeps both axes} \Rightarrow v \mapsto c\,v\,? @@ <span class="vd vd-p">outside the plan</span> rows (2, 0), (0, 3) keep both axes and not the line of (1, 1): every line is needed

The accepted names

A vector a grid only stretches is an eigenvector, and its stretch is an eigenvalue. det(A − λI), as a polynomial in λ, is the characteristic polynomial (often written det(λI − A), which differs by the sign (−1)ⁿ). To straighten out A is to diagonalise it; D is a diagonal matrix, and A and D are similar. The slide with rows (1, 1), (0, 1) is a shear. A space kept by a map is an invariant subspace, and the map on it is the restriction. Grids that swap commute, and grids straightened by one P are simultaneously diagonalizable. A flattening is a projection, onto its range along its null space; the grids E with EE = E are idempotent. The grids c times I are the scalar matrices.

Who said it first

Euler studied the axes a spinning body turns about in the 1750s, and Joseph-Louis Lagrange found stretches of this kind in the motions of the planets. Augustin-Louis Cauchy proved in 1829 that a symmetric grid has real stretches. The word eigen, German for own, came from David Hilbert in 1904.
