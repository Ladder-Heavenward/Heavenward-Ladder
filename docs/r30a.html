30a · proof

Not every set has a size

Rung fifteen measured the area under a curve by cutting the inputs into strips. That works for the curves of everyday life. It fails for a set as scattered as the fractions on the line, which sit in every strip and fill none of them. So this rung starts again with a plainer question: how long is a set? Cover the set with countably many intervals and add up their lengths. Do it as tightly as you can. The least total is the set’s outer size. It gives an interval its length, it never adds up to more than the pieces, and it does not change when the set slides along the line. Then comes a surprise. If the axiom of choice from rung six is true, there is a set inside one unit of the line that no size can measure at all. Not every set has a size, and the rest of the rung learns which ones do.

Outer size gives each interval its length, adds at most, and is kept by sliding. Yet once choice is allowed, some sets have no size that slides and adds over countably many pieces.

30a1How long is a set?

Take any set A of reals. A cover of A is a list of open intervals I₁, I₂, I₃, … whose union holds every point of A. The list may be finite or endless. Its total is ℓ(I₁) + ℓ(I₂) + ⋯, the sum of their lengths, which may be endless.

From here on, the outer size of A, written m*(A), is the greatest lower bound of the totals of all covers of A. It exists by 8c, since every total is at least 0. It may be ∞. Its accepted name is outer measure.

Cover-total technique: the outer size of an interval is its length.

(u - \varepsilon,\ v + \varepsilon) \text{ covers } [u, v] @@ one interval is a cover
m^*([u, v]) \le v - u + 2\varepsilon \text{ for every } \varepsilon > 0,\ \text{so } m^*([u, v]) \le v - u @@ outer size is a greatest lower bound (8c)
\text{take any cover } I_1, I_2, \ldots \text{ of } [u, v] @@ now the other way
s = \sup\{x \in [u, v] : [u, x] \text{ is covered by finitely many } I_k\} @@ u lies in some I_k, so the set is not empty (8c)
s \in I_j = (c, d) \text{ for some } j @@ s is in [u, v], and the Iₖ cover it
\text{some } x \in (c, s] \text{ has } [u, x] \text{ covered by finitely many} @@ else a number below s would be an upper bound (8c)
\text{add } I_j:\ [u, y] \text{ is covered for every } y < d,\ y \le v @@ so s ≥ min(d, v); as s < d, s = v
[u, v] \subseteq I_1 \cup \cdots \cup I_n \text{ for some } n @@ the same with y = v, which is below d
\ell(I_1) + \cdots + \ell(I_n) \ge v - u @@ chain the intervals from u to v: each starts before the last one ends
\htmlClass{new}{m^*([u, v]) = v - u} \quad \blacksquare @@ every cover totals at least v − u

The same holds for open and half-open intervals, which differ from [u, v] by two points: a point has outer size 0, since (x − ε, x + ε) covers it.

30a2Outer size adds at most

Outer-adds-at-most technique: the outer size of a union of countably many sets is at most the sum of their outer sizes.

A = A_1 \cup A_2 \cup \cdots,\ \ \varepsilon > 0 @@ if any m*(Aₙ) is ∞ there is nothing to prove
\text{cover } A_n \text{ by } I_{n,1}, I_{n,2}, \ldots \text{ with total } \le m^*(A_n) + \varepsilon/2^n @@ a greatest lower bound is approached (8c)
\text{all the } I_{n,k} \text{ together cover } A @@ countably many; picking a cover for each n is choice, countably often (6b)
m^*(A) \le \sum_n \big(m^*(A_n) + \varepsilon/2^n\big) = \sum_n m^*(A_n) + \varepsilon @@ geometric sum (15i)
\htmlClass{new}{m^*(A_1 \cup A_2 \cup \cdots) \le m^*(A_1) + m^*(A_2) + \cdots} \quad \blacksquare @@ ε was any positive number

So every countable set has outer size 0. The fractions are countable: list p/q in lowest terms with q ≥ 1 by levels, |p| + q = 1, then 2, then 3, and each level holds finitely many. So they have outer size 0, though they sit in every interval. A set can be everywhere and still take up no room.

And a bigger set never has a smaller outer size: a cover of B is a cover of every part of B.

30a3Sliding keeps the size

For a set A and a real t, A + t is the set of x + t for x in A: A slid along the line by t.

Shift-keeps technique: m*(A + t) = m*(A) for every set A and every real t.

I_1, I_2, \ldots \text{ covers } A \iff I_1 + t, I_2 + t, \ldots \text{ covers } A + t @@ slide every point by t
\ell(I_k + t) = \ell(I_k) @@ (c + t, d + t) has length d − c
\htmlClass{new}{m^*(A + t) = m^*(A)} \quad \blacksquare @@ the same totals, so the same least total

30a4A set with no size

What would a size on the line need? Give every set A of reals a number m(A), from 0 to ∞, so that intervals get their lengths, sliding keeps sizes, and size adds over countably many separate pieces. Separate pieces share no point.

Call two reals x and y kin when x − y is a fraction. Kin splits [0, 1] into boxes: each real sits in exactly one box with all its kin. There are more boxes than any list can hold.

No-size-set technique: if choice is true, some set in [0, 1] has no size that gives intervals their lengths, is kept by sliding, and adds over countably many separate pieces.

V = \text{one real from each box of kin in } [0, 1] @@ picking one from every box (6b): choice
q_1, q_2, q_3, \ldots \text{ lists the fractions in } [-1, 1] @@ countably many: list them by levels, as in 30a2
V + q_i,\ V + q_j \text{ separate when } i \ne j @@ v + qᵢ = w + qⱼ makes v and w kin, so v = w and qᵢ = qⱼ
[0, 1] \subseteq \bigcup_i (V + q_i) \subseteq [-1, 2] @@ x in [0, 1] is v + (x − v), with v its kin in V and x − v a fraction in [−1, 1]
1 \le \sum_i m(V + q_i) = \sum_i m(V) \le 3 @@ adds over separate pieces; sliding keeps size; a bigger set is not smaller
m(V) = 0 \Rightarrow \text{the sum is } 0 < 1;\ \ m(V) > 0 \Rightarrow \text{the sum is } \infty > 3 @@ the same number added endlessly
\htmlClass{new}{V \text{ has no such size}} \quad \blacksquare @@ both cases fail

Outer size gives V a number, of course. So outer size cannot add over every countable split into separate pieces. Something has to give. Either some sets are left without a size, or sizes stop adding. The ladder keeps adding, because chance will need it, and leaves some sets out.

The proof used choice to build V. 6d showed that choice can be laid down or refused. It is proved much higher up the ladder that refusing it leaves room for every set of reals to have a size, so V cannot be built without some choosing.

The basement · there if you want it

The accepted names

Outer size is Lebesgue outer measure, m*. The set V is a Vitali set. The kin relation is an equivalence relation, and its boxes are equivalence classes; V is a set of representatives. The fact that no size on every set of reals slides and adds over countably many pieces is the non-existence of a translation-invariant countably additive measure on all subsets of ℝ extending length.

Who said it first

Émile Borel measured sets by countable covers in 1898. Henri Lebesgue built outer measure in his thesis of 1902. Giuseppe Vitali found the set with no size in 1905, using choice. Robert Solovay showed in 1970 that without choice, assuming a further axiom about large sets, every set of reals can be measurable.

A proof that is not allowed

“[0, 1] is a union of its points. Each point has size 0. So [0, 1] has size 0 + 0 + ⋯ = 0.” Not allowed: [0, 1] has more points than any list holds, so it is not a union of countably many of them, and countable adding never applies.
