Working With the Gap

Rung 5 made room to undo. The letter in an equation is a set with a gap, the statement with a gap of 0a. This step shows how much can be learned from a process while the gap stays empty.

Leave the letter unfilled. The process still tells you what any filling would do.

5k1The Letter Stays Empty

A letter for an unknown number can be worked without being filled. If one orange costs c, then n oranges cost n · c. Double the price, and n · (2 · c) = 2 · (n · c): the cost doubles, whatever n and c are.

Nothing was filled in. The answer holds for every filling at once.

5k2Facts From an Opaque Process

A process can look closed and still give up a great deal. Multiply any number by the next one: n · (n + 1). One of n and n + 1 is even, so the product is even. No n was tried.

Factoring (5i) does the same: x² − 5x + 6 = (x − 2)(x − 3), so only 2 and 3 can make it zero. You learn every answer before you guess one.

Anexact, yet rigorous · the gap left open

A letter left unfilled still tells you what every filling does. It names no number, and it is right about all of them.

5k3What the Gap Keeps

The empty gap keeps the guess general. A filled gap gives one answer about one number. An empty one gives a rule about all of them, down the whole series, the way 5a’s lines hold.
