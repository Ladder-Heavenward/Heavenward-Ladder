40d · proof

Calls and the Stack

A program that multiplies in three places should not copy the multiply three times. A call jumps to one copy and comes back. Coming back needs somewhere to keep where it came from, and 39n’s pile is that place.

A call pushes where to come back; a return pops it. A function that calls itself is defining by repeating, run on a pile.

40d1Jump There, Come Back

Give the machine two more kinds. CALL f puts the address of the next line on the pile and jumps to f. RET takes the top address off the pile and jumps to it.

So the function is written once, and each call returns to its own caller, because each call left its own way back on top of the pile.

40d2Why a Pile

Calls nest: f calls g, and g returns before f does. Returns come in the reverse order of the calls, because a call cannot return until every call it made has returned. That is a pile’s order, last in and first out (39n1).

With a single cell for the way back, g’s call would overwrite f’s, and f would never get home.

40d3A Function That Calls Itself

fact(n): if n = 0, give 1; otherwise give n · fact(n − 1). This is 4d’s defining by repeating, a start and a step, written as a program that calls itself.

\text{fact}(3) \text{ calls fact}(2) \text{ calls fact}(1) \text{ calls fact}(0) @@ four ways back on the pile
\text{fact}(0) = 1 @@ the start; the pile begins to empty
\text{fact}(1) = 1,\ \text{fact}(2) = 2,\ \text{fact}(3) = 6 @@ each return multiplies
\htmlClass{new}{\text{fact}(3) = 6} \quad \blacksquare @@ the pile is empty again

40d4Each Call Its Own Names

Each call of fact has its own n: 3, then 2, then 1, then 0. If they shared one cell, fact(2) would overwrite the 3 that fact(3) still needs. So each call puts its names on the pile beside its way back, and a return takes them off.

Own-names technique: a call’s names live on the pile with its way back, so a call changes no name of any call that is waiting for it.

The accepted names

A function written once and called from many places is a subroutine. The pile is the call stack, the names a call puts on it make its stack frame, and a function that calls itself is recursive.
