39d · proof

No machine decides stopping

Rung three asked whether a program can run for ever, and found loops that stop, loops that come back, and loops that go on making something new, and it said nobody can always tell. Rung thirty seven ended with a search that finds every proof and never says when there is none, and it left the question of telling the two apart for here. Now the question can be asked exactly. Given the written table of a machine and an input, does the machine stop? The universal machine answers half of it: run the machine, and if it stops, say so. The other half is the trouble. This step proves that no machine answers the whole question for every machine and every input. The proof is the diagonal of the rung on sizes, run on machines instead of digits. A machine that could predict every machine is fed to a machine built to do the opposite of whatever it predicts, and that machine is fed its own table. The rung on switches built a box that says the opposite of itself and found it ticks like a clock. Here there is no clock to run. There is only the refusal: no such predictor exists.

The machines that stop on their inputs are listed by running them. No machine decides which ones stop: one that did would be fed a machine built to do the opposite of its prediction about itself. So the machines that never stop are not even listed.

39d1Stopping is listed

The stopping set H is the set of strings ⟨M⟩ # w such that M, started on w, stops. Its accepted name is the halting problem.

Stopping-listed technique: a machine lists the stopping set.

\text{on input } x\text{: }\allowbreak \text{check }\allowbreak \text{that } x = \langle M\rangle \# w @@ the table-code technique (39c1); if not, stop in no
\text{run U on } \langle M\rangle \# w @@ the universal technique (39c2)
\text{if }\allowbreak \text{U }\allowbreak \text{stops, }\allowbreak \text{stop }\allowbreak \text{in }\allowbreak \text{yes} @@ U stops exactly when M stops on w
\htmlClass{new}{\text{yes }}\allowbreak \htmlClass{new}{ \text{exactly }}\allowbreak \htmlClass{new}{ \text{on }}\allowbreak \htmlClass{new}{ \text{the }}\allowbreak \htmlClass{new}{ \text{members }}\allowbreak \htmlClass{new}{ \text{of } H} \quad \blacksquare @@ on the others it runs for ever, which a lister may

That is 37b’s proof-listing in a new coat, and it has the same flaw. While U runs, nothing tells whether it is nearly done or never will be. 3·comp caught loops that come back by remembering states; a machine whose tape keeps growing never comes back.

39d2No machine decides stopping

\text{run E on } \langle E\rangle @@ E has a code (39c1); feed E its own
E \text{ stops }\allowbreak \text{on } \langle E\rangle \iff D \text{ says }\allowbreak \text{no }\allowbreak \text{on } \langle E\rangle \# \langle E\rangle \iff E \text{ does }\allowbreak \text{not }\allowbreak \text{stop }\allowbreak \text{on } \langle E\rangle @@ the two lines above, with D right about every input
\htmlClass{new}{\bot;\ }\allowbreak \htmlClass{new}{ \text{no such } D} \quad \blacksquare @@ refute (1b)

Lay the machines down the side of a table and their codes along the top, and write in each place whether machine i stops on code j. D would be a machine that reads the whole table. E runs down the diagonal and takes the opposite at each place, so E’s row differs from every row, its own included. That is 35b’s unlisted real, with “stops” for a digit.

38g wired a not back into itself, and the box did not settle: so, then not so, a clock. E fed ⟨E⟩ is the same loop of predictions, “if it stops, it does not; if not, it does”, and a machine has no wire in which to oscillate. Its run is one run. What gives way is the supposition that D exists.

39d3Never stopping is not even listed

Not-stopping technique: no machine lists the strings ⟨M⟩ # w such that M never stops on w.

\text{a }\allowbreak \text{machine }\allowbreak \text{lists }\allowbreak \text{the }\allowbreak \text{never-stopping }\allowbreak \text{strings} @@ suppose it
\text{strings }\allowbreak \text{that }\allowbreak \text{are }\allowbreak \text{not }\allowbreak \text{of }\allowbreak \text{the }\allowbreak \text{form } \langle M\rangle \# w \text{ are }\allowbreak \text{decided} @@ the table-code technique; add them to the list
H \text{ and }\allowbreak \text{the }\allowbreak \text{strings }\allowbreak \text{outside } H \text{ are }\allowbreak \text{both }\allowbreak \text{listed} @@ the stopping-listed technique, and the line above
H \text{ is }\allowbreak \text{decided} @@ the both-sides technique (39a2)
\htmlClass{new}{\bot} \quad \blacksquare @@ the no-stop-decider technique

So the two halves are not alike. A machine that stops can always be shown to stop: run it, and the run is the evidence, a list of configurations anyone can check. A machine that never stops has, in general, no such evidence a machine could find. Some do: 3·comp’s loops that come back, and the falling-measure of 4l turned round. 39j collects a few kinds. No finite stock of kinds catches them all.

And a limit in time changes everything. “M stops on w within t steps” is decided: run U for t steps. The question that cannot be decided is the one with no t attached. 39h asks what happens when t is attached and the answer must come quickly.

The accepted names

The stopping set is the halting problem, written HALT or A_TM in many books; the no-stop-decider technique is the undecidability of the halting problem. The not-stopping technique says the complement of the halting problem is not Turing-recognizable. A machine with a free question about H is an oracle machine, and 39d.5.3 leads to the arithmetical hierarchy and Turing degrees.

Who said it first

Alan Turing proved in 1936 that no machine decides whether a machine ever prints a 0, the form his paper used; the form with stopping is from Martin Davis’s book of 1958, which gave it the name halting problem. Alonzo Church reached the same limit from the λ-calculus in 1936. John Lucas (1961) and Roger Penrose (1989, 1994) argued that minds outrun machines because a mind sees the truth of the diagonal statement; Hilary Putnam (1960) and many since replied that the argument assumes the mind knows its own system is clash-free.

A proof that is not allowed

“Let D run M on w. If M stops, D says yes. If M runs for a million steps without stopping, D says no.” Not allowed as a decider: some machine stops after a million and one steps, and D is wrong on it. Any fixed limit fails, and a limit that grows with M is a function, which 39·now shows no machine computes large enough.
