23b · proof

How wrong the match is

A matching polynomial agrees with its curve at one point. Away from that point it drifts off, and this step measures by how much. The answer looks just like the next term the polynomial left out, except that its slope is taken at some unknown point between where you started and where you are. You never learn that point. You do not need to: if you know how large that slope can be anywhere in between, you know how large the error can be. For the growth function, the sine and the cosine, the error shrinks to nothing however far you go, so those functions are their endless sums, everywhere.

The error of a matching polynomial is the next term it left out, with its slope taken at some point in between. A ceiling on that slope is a ceiling on the error. For the growth function, sine and cosine, the error heads to nothing at every input.

23b1The error is the next term, somewhere

Stands on 23a2, 14b (level ends, a level point between) and 13c (the product rule).

Write Rₙ(x) = f(x) − Tₙ(x) for what the match leaves over. Match-error technique: if f has n + 1 slopes on an interval holding w and x, then Rₙ(x) = f⁽ⁿ⁺¹⁾(c)(x − w)ⁿ⁺¹/(n + 1)! for some c between w and x. The trick is to slide the point of matching from w to x and watch the error.

g(t) = f(x) - \textstyle\sum_{k=0}^{n}\tfrac{f^{(k)}(t)}{k!}(x-t)^k - M(x-t)^{n+1} @@ the match made at t instead of a; M a number to choose
g(x) = 0;\ \ \text{choose } M \text{ so that } g(w) = 0 @@ at t = x every power of (x − t) is 0; at t = w this is Rₙ(x) − M(x − w)ⁿ⁺¹
g'(c) = 0 \text{ for some } c \text{ between } w \text{ and } x @@ level ends, a level point between (14b)
g'(t) = -\tfrac{f^{(n+1)}(t)}{n!}(x-t)^n + M(n+1)(x-t)^n @@ the product rule (13c) on each term; all but the last pair cancel in turn
M = \tfrac{f^{(n+1)}(c)}{(n+1)!} @@ g′(c) = 0, with x − c ≠ 0
\htmlClass{new}{R_n(x) = \tfrac{f^{(n+1)}(c)}{(n+1)!}(x-w)^{n+1}} \quad \blacksquare @@ g(w) = 0

With n = 0 this is 14c's mean value technique: f(x) − f(w) = f′(c)(x − w). The match-error technique is the mean value technique carried out to every order.

23b2A ceiling on the slope is a ceiling on the error

Stands on 23b1 and 22h2 (xⁿ/n! heads to 0).

Error-ceiling technique: if |f⁽ⁿ⁺¹⁾| ≤ K between w and x, then |Rₙ(x)| ≤ K|x − w|ⁿ⁺¹/(n + 1)!. That is 23b1 with c unknown and its slope bounded.

|\sin^{(k)}|,\ |\cos^{(k)}| \le 1 @@ every slope is ±sin or ±cos (21g)
|R_n(x)| \le \tfrac{|x|^{n+1}}{(n+1)!} \to 0 @@ the error ceiling, and 22h2
|(e^t)^{(n+1)}| = e^t \le e^{|x|} \text{ between } 0 \text{ and } x @@ exp climbs (17e)
|R_n(x)| \le e^{|x|}\tfrac{|x|^{n+1}}{(n+1)!} \to 0 @@ the same
\htmlClass{new}{e^x = \textstyle\sum_{k \ge 0} \tfrac{x^k}{k!},\ \ \sin x = \sum_{k \ge 0} \tfrac{(-1)^k x^{2k+1}}{(2k+1)!},\ \ \cos x = \sum_{k \ge 0} \tfrac{(-1)^k x^{2k}}{(2k)!}} \quad \blacksquare @@ for every real x: Tₙ(x) → f(x)

22j proved the first sum for x ≥ 0 by squeezing powers. This proves it for every x, and for sine and cosine too, from one technique. The sums settle in size, by 22e's ratio test, so their pieces may be taken in any order (22g).

23b3Where the error ceiling gives out

Stands on 23b1, 23a3 (the match for ln(1 + x)) and 22g1 (the bracket).

f^{(n+1)}(t) = \tfrac{(-1)^n\, n!}{(1+t)^{n+1}} @@ from 1/(1 + t), as in 23a3
|R_n(x)| = \tfrac{n!}{(n+1)!}\cdot\tfrac{x^{n+1}}{(1+c)^{n+1}} \le \tfrac{x^{n+1}}{n+1} @@ 0 ≤ c, so 1 + c ≥ 1
0 \le x \le 1 \Rightarrow |R_n(x)| \le \tfrac{1}{n+1} \to 0 @@ x^{n+1} ≤ 1
\htmlClass{new}{\ln(1+x) = x - \tfrac{x^2}{2} + \tfrac{x^3}{3} - \cdots \text{ for } 0 \le x \le 1} \quad \blacksquare @@ in particular ln 2 = 1 − ½ + ⅓ − ⋯, as 22g found by the harmonic gap

For x > 1 the pieces xⁿ/n do not head to 0, so the sum wanders (22d2), though ln(1 + x) is perfectly smooth there. For −1 < x < 0 the sum does reach ln(1 + x), but this ceiling is too rough to show it: c can sit near −1, where 1/(1 + c) is huge. 23c finds a better way to see how far a power sum reaches.

The basement · there if you want it

The accepted names

Rₙ is the remainder; the match-error technique is Taylor's theorem with the Lagrange form of the remainder; the error ceiling is the Taylor (Lagrange) error bound. The three endless sums are the Taylor series (Maclaurin series) of exp, sin and cos.

Who said it first

Brook Taylor gave the series in 1715 without an error. Joseph-Louis Lagrange gave this form of the remainder in 1797, and Augustin-Louis Cauchy gave others in the 1820s, with the first proofs that met this ladder's standard.
