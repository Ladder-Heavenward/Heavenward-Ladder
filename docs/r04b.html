4b · proof

The Smallest Inductive Set

By rung 3's axiom, some set is inductive, and nothing says what else such a set holds. This step throws the extra away. From an inductive set you have, it sifts the things that are in every inductive set. It proves that the result does not depend on which inductive set you started from, and gives it a mark of its own and a name for its members. Then it proves the facts that make it the right object. It is inductive itself, and it is a part of every inductive set. A stray set that is nobody's next is not in it. And different sets have different next ones.

Keep exactly what every inductive set holds. That set holds 0 and the next one after each of its members, it sits inside every inductive set, and anything that is not 0 and is nobody's next is thrown out of it. And the next-one gesture never sends different sets to the same place.

4b1Cargo, Again

The infinity axiom says some set is inductive: it holds 0, and whenever it holds a set it holds that set's next one. Use the some honestly and call such a set I. The named-sets-are-inductive technique put 0, 1, 2, 3, 4 in I, and S(4), and as far along the run as you care to write.

But I may hold other things. Example: if {1} is in I, then S({1}) is too, and S(S({1})). That is a chain of cargo, dragged along by the step part and never meeting the run. Another inductive set may carry no cargo, or different cargo.

So “every member of I” is not yet “every entry of the run”. A proof about the members of I would be a proof about whatever cargo I happens to carry.

4b4It Does Not Matter Which Inductive Set

Who is in it? Unpacking the sift gives both of these: y ∈ I, and y is in every inductive set. “y is in every inductive set” already gives “y ∈ I”, since I is an inductive set. So the members of the sift are exactly the things in every inductive set, and I has dropped out of the description.

Whichever-inductive-set technique: for any inductive set I, a thing is in the sift of I by “in every inductive set” exactly when it is in every inductive set.

Each direction is short.

Let y be anything. Suppose first that y is in the sift. Unpack the sift: y is in I, and y is in every inductive set. Keep the second half. That is φ(y).

Now drop that supposition, and suppose instead φ(y): y is in every inductive set. I is an inductive set, so y is in I. Join the two: y is in I, and y is in every inductive set. Pack the sift: y is in it.

Each way, the one gives the other. So y is in the sift exactly when φ(y). And y was anything.

4b5The Name ℕ

So suppose you and a friend each have an inductive set, I and I′, and each of you sifts. Your sifts have the same members: a thing is in yours exactly when it is in every inductive set, exactly when it is in your friend's. Chain the exactly-whens, and the same-members axiom says the sifts are the same set. It does not matter which inductive set you sifted from.

And the infinity axiom says there is an inductive set to sift from, so the some closes honestly. There is a set whose members are exactly the things in every inductive set, and its description mentions no particular I. There is only one such set, by same-members again.

4b7Inside Every Inductive Set

The earliest thing the name gives is what its description says.

Lies-below technique: every number is in every inductive set. That is to say, ℕ is a part of each of them.

The plan: take any number y, and show that y is in J.

Suppose J is inductive. Let y be anything, and suppose y is a number. Unpack membership-in-ℕ: y is in every inductive set. J is one of them, so y is in J.

Drop the supposition that y is a number. Whatever y is, if y is a number then y is in J. Pack ⊆: ℕ is a part of J.

4b80 Is a Number, and so Is Each Next

Now both parts of “inductive”, for ℕ itself. The base part first.

Zero-is-a-number technique: 0 is a number.

The plan: 0 is in every inductive set, since that is the base part of each of them.

Let J be anything, and suppose J is inductive. Unpack “inductive”: 0 is in J, and J holds the next one after each of its members. Keep the first half: 0 is in J.

Drop the supposition. J was anything, so 0 is in every inductive set. Pack membership-in-ℕ: 0 is a number.

The step part.

Next-of-a-number technique: if n is a number, so is the next one after n.

The plan: if n is in every inductive set, then so is S(n), because each of them carries n to S(n).

Suppose n is a number. Let J be anything, and suppose J is inductive. Unpack membership-in-ℕ on n: n is in every inductive set, so n is in J. Unpack “inductive” on J and keep its step part: J holds the next one after each of its members. Use it with n: S(n) is in J.

Drop the supposition about J. J was anything, so S(n) is in every inductive set. Pack membership-in-ℕ: S(n) is a number. Drop the supposition about n: if n is a number, so is S(n).

4b9The Smallest Inductive Set

Join zero-is-a-number with next-of-a-number (spoken of every n) and pack “inductive”: ℕ is inductive. Put that beside lies-below and you have this step's main technique.

Smallest-inductive-set technique: ℕ is inductive, and ℕ is a part of every inductive set. In marks: ℕ is inductive, and ℕ ⊆ J for every inductive set J.

Read “smallest” with care. It does not mean “has the fewest members”, since nothing on the ladder has yet said what fewer means. It means: a part of every other inductive set.

And there is only one smallest. Suppose K is inductive and a part of every inductive set. Then K ⊆ ℕ, since ℕ is one of the inductive sets K is a part of. And ℕ ⊆ K, by the lies-below technique with K for J. So K = ℕ by the double-inclusion technique. The step's title names exactly one set.

Now run the named-sets-are-inductive technique with ℕ in the place of the inductive set. It says that 0, 1, 2, 3, 4 are numbers, and S(4), and S(S(4)), as far as you write. Everything on the run you can name is in ℕ. What is not obvious yet is the other part, that ℕ holds nothing else, and that is where the cargo goes.

4b10A Stray: Nobody's Next

Take the cargo {1}. To show {1} is not a number, you need an inductive set that leaves it out: then {1} fails membership-in-ℕ's every, by the counterexample technique. The natural candidate is I with {1} sifted away, {x ∈ I : x ≠ {1}}. Its base part is true, since 0 ≠ {1} (0 has no members and {1} has the member 1). Its step part needs this: the next one after something is never {1}. That is so, and here is why.

Suppose S(x) = {1}, aiming to refute it. Each set is in its own next, so x is in S(x). Swap S(x) for {1}: x is in {1}. The only member of {1} is 1, so x = 1.

Now look at 0. 1 is {0}, so 0 is in 1. And 1 is a part of its next, S(1). So 0 is in S(1). Swap 1 back for x, then S(x) for {1}: 0 is in {1}. So 0 = 1.

But 1 names S(0), and a next is never empty, so 1 ≠ 0. Turn it about: 0 ≠ 1. That clashes with 0 = 1. Refute the supposition: S(x) ≠ {1}, whatever x is.

4b11Sifting the Stray Away

The plan: build an inductive set that leaves {1} out. Then the lies-below technique does the rest.

Now the sifted set is inductive. Base: 0 ∈ I and 0 ≠ {1}, join, pack the sift. Step: let x be anything, and suppose x is in the sift. Then x ∈ I, so S(x) ∈ I (I's step part). And S(x) ≠ {1} (shown above), so S(x) is in the sift. So {x ∈ I : x ≠ {1}} is an inductive set, and {1} is not in it. The lies-below technique says ℕ is a part of it. If {1} were a number, it would be in the sift, so {1} ≠ {1}, which clashes with the self-sameness axiom. Refute: {1} ∉ ℕ.

4b12The Strays Technique

Nothing about {1} was used but these facts: it is not 0, and it is nobody's next. Any set with both properties can be sifted away in the same way, leaving an inductive set behind, so no such set is a number.

Strays technique: a set that is not 0 and is nobody's next one is not a number. In marks: if c ≠ 0 and S(x) ≠ c for every set x, then c ∉ ℕ.

The same argument, with {2} or {{1}} for {1}, shows each of them is a stray.

The next one after a stray is a different story. S({1}) is somebody's next, namely {1}'s. So sifting S({1}) away from an inductive set that holds {1} breaks the step part at {1}. Showing S({1}) is not a number is easiest with a technique 4c proves by induction: every number is 0 or the next one after a number. The rest of every cargo chain goes then.

The picture lets you watch the start of a chain voted out and the rest survive.

4b13Different Sets Have Different Next Ones

3c proved that the next one is never the set you started from (never-its-own-next) and never empty (next-never-empty). 3d held a third fact in trust, and this step proves it, so that foreclosure completes.

Different-nexts technique: two different sets never have the same next one. Say it the way it is used: if S(x) = S(y), then x = y.

The proof is about membership, not about “taking S off both sides”, which is not a tech. The plan: get “x ∈ y or x = y” and “y ∈ x or y = x”, then take the cases.

Suppose S(x) = S(y). Each set is in its own next, so x is in S(x). Swap S(x) for S(y): x is in S(y). By next-membership, x is in y, or x is y. The same moves, turned about, give: y is in x, or y is x.

Now reason by cases. If x is y, that is the goal. If x is in y, look at the other pair of options. If y is x, turn it about: x is y. If y is in x, then x is in y and y is in x. That is a loop, and the no-loop technique forbids loops. The clash permits everything, x = y too.

Every case reaches x = y. Drop the supposition: if S(x) = S(y), then x = y.

From here on, the statement “S is one-to-one” means this. Different sets have different next ones.

4b14An Endless Collection, by the Old Mark

The different-nexts technique says S is one-to-one, for every set, not only numbers, and it leans on foundation through no-loop. 4c gives another proof for numbers that uses induction instead and never touches foundation. That proof needs the technique that every member of a number is also a part of it, which is itself an induction, so it waits for 4c.

Read the techniques together for numbers. Every number has a next one that is a number (next-of-a-number). Different numbers have different next ones (different-nexts). And 0 is nobody's next (next-never-empty).

That is exactly the old mark of an endless collection, which 3d described in words. ℕ can be matched, member for member, each number with its next one, with a part of itself that leaves 0 out. 4d makes that matching an object.

4b16Running It Backwards

Wanting “t is a number”, you pack membership-in-ℕ: let J be any inductive set, and show t ∈ J. For an entry you can name, that is the named-sets-are-inductive technique's argument run inside any J, or zero-is-a-number and next-of-a-number used over and over.

Wanting “t is not a number”, you want an inductive set that leaves t out. For a stray, the sift of I by x ≠ t is that set, once you have shown t ≠ 0 and S(x) ≠ t for every set x.

Wanting x = y from S(x) = S(y), you cite different-nexts.

Wanting “K = ℕ”, you show K ⊆ ℕ and ℕ ⊆ K. For ℕ ⊆ K, showing K inductive and citing lies-below is usually the quickest road. Found upward; written downward.

Who said it first

The founder who came to the numbers by this sift, and whose mark of an endless collection this step proves, is Richard Dedekind.

Dedekind's way to the numbers was this sift. Given a system and a step, he called a part of the system a chain when the step never leads out of it, and he took the chain of a starting element to be what is common to every chain that holds that element. The counting numbers are the chain of the start under the next-one step.

Dedekind, Was sind und was sollen die Zahlen? (1888), §37, §44 and §71–73, trans. Beman, 1901

Accepted names

A collection that can be matched with a part of itself that leaves something out is called Dedekind-infinite. That S is one-to-one is often written as an axiom, one of the Peano axioms.
