40g · proof

Loop Invariants

40f gave techniques for steps, rows and choices, but not for loops. A loop may turn any number of times, so its technique must hold after every turn at once. This step finds that technique in a statement the loop keeps.

Find what each turn keeps. It holds at the start, it survives every turn, and when the test fails it gives the goal. A whole number that falls each turn makes the loop stop.

40g1What a Loop Keeps

While technique: from {I ∧ B} c {I}, write {I} while B do c {I ∧ ¬B}.

I is the invariant. If I holds before a turn and the test B passes, the body leaves I holding again. So I holds at the top of every turn, by induction on the number of turns (4c). When the loop ends it ends because B failed, so I ∧ ¬B holds.

40g2Multiplying by Adding, Proved

39j3’s program, in shapes: p ← 0; k ← K; while k ≠ 0: p ← p + x; k ← k − 1. The invariant is p + kx = Kx.

p = 0,\ k = K:\ 0 + Kx = Kx @@ it holds at the start
(p + x) + (k - 1)x = p + kx = Kx @@ one turn keeps it, by backwards-assignment through the body
k = 0:\ p + 0 \cdot x = Kx @@ the test fails, so k is 0
\htmlClass{new}{p = Kx} \quad \blacksquare @@ the loop multiplies

40g3And It Stops

The while technique says nothing about stopping. For that, a whole number must fall each turn. Here it is k: it falls by 1 each turn, and the loop ends when it reaches 0. This is 40e’s falling-measure technique, with each turn counted as a call.

A falling measure with an invariant gives the whole promise: the loop stops, and when it stops the goal holds.
