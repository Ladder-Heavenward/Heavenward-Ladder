14g · technique

The bend and sketching

14d read the sign of the slope across an interval and learned whether the function climbs. Read the sign of the slope of the slope the same way, and 14d says whether the slope climbs. A function whose slope keeps climbing turns its tangent line more and more steeply up as it goes, so it bends up. It lies above each of its tangent lines, and each of its chords lies above it. 13k asked which way a function bends away from its tangent lines. 13j checked on one example that the slope at an input lies between the slopes of the chords on either side. Both are one technique, and average-slope proves it in two lines. Then the signs of the slope and of the slope of the slope together give the shape of a graph from a handful of numbers.

A positive slope of the slope makes the slope climb. Then a chord’s slope, being the slope at some input between its ends, is below the slopes to its right and above those to its left. So the graph lies above its tangent lines and below its chords.

14g1Bending up and bending down

Stands on 14c (average-slope), 14d (slope-sign-order) and 13k (the tangent line).

From here on, f bends up on an interval I when, for any two inputs a < b of I, every x with a < x < b has f(x) below the chord from a to b. That is, f(x) < f(a) + m(x − a), with m the chord's slope. f bends down on I when every such f(x) is above the chord. Their accepted names are concave up and concave down; some books say convex and concave. An input c is an inflection point of f when f is continuous at c, and for some reach δ, f bends one way on (c − δ, c) and the other way on (c, c + δ). Its accepted name is point of inflection.

Bends-up technique: if f has a slope at every input of an interval I and f′ is increasing on I, then f bends up on I. And for every p in I, f(x) > f(p) + f′(p)(x − p) for every x ≠ p in I: the graph lies above each tangent line. With f′ decreasing, f bends down and lies below each tangent line.

g(x) = f(x) - f(a) - f'(a)(x - a) @@ the gap above the tangent line at a (13k)
g(a) = 0,\ \ g'(x) = f'(x) - f'(a) @@ slopes-add, slope-of-a-line
x \lt a:\ g'(x) \lt 0;\ \ x \gt a:\ g'(x) \gt 0 @@ f′ increasing
g \text{ decreasing up to } a,\ \text{increasing after} @@ slope-sign-order (14d) on each side, ends included
\htmlClass{new}{g(x) \gt 0 \text{ for } x \ne a} @@ g(a) = 0 is the least value, reached only at a
  
a \lt x \lt b:\ \ \tfrac{f(x) - f(a)}{x - a} = f'(\xi_1),\ \ a \lt \xi_1 \lt x @@ average-slope (14c) on [a, x]
\tfrac{f(b) - f(x)}{b - x} = f'(\xi_2),\ \ x \lt \xi_2 \lt b @@ average-slope on [x, b]
\htmlClass{new}{\tfrac{f(x) - f(a)}{x - a} \lt f'(x) \lt \tfrac{f(b) - f(x)}{b - x}} @@ f′ increasing and ξ₁ < x < ξ₂
f(x) \lt f(a) + m(x - a) \quad \blacksquare @@ the left chord is less steep than the whole chord, whose slope m is a weighted middle of the two (8g's order on fractions)

The middle line is 13j's check, proved: the slope at an input lies between the slopes of the chords on either side. For a function that bends down, the order turns about. With 14d's slope-sign-order, the second slope decides: f″ > 0 on I makes f′ increasing, so f bends up; f″ < 0 makes it bend down.

f(x) = \sqrt{2x + 1},\ \ f'(x) = (2x + 1)^{-1/2} @@ 13j: chain for slopes with root-slope
f''(x) = -(2x + 1)^{-3/2} \lt 0 \text{ for } x \gt -\tfrac12 @@ chain for slopes again: f bends down
\tfrac12 \gt f'(4) = \tfrac13 \gt \tfrac14 @@ bends-up, turned about: the left chord (0 to 4) is steeper than the slope, the right chord (4 to 12) less steep

And 13k's question has its answer. 1 + x/2, the linearization of √(1 + x) at 0, lies above √(1 + x) everywhere else, because √(1 + x) bends down. The error of a linearization has the sign of f″.

14g2Where the bend turns

Stands on 14g1 and 13d (the second slope).

If f″ is negative just left of c and positive just right, f bends down then up, so c is an inflection point. x³ at 0 is the plainest: f″ = 6x changes sign at 0. But f″(c) = 0 is not enough. x⁴ has f″(0) = 0 and f″ = 12x² ≥ 0 on both sides. So x⁴ bends up on all of ℝ (its slope 4x³ is increasing, by odd-powers-keep-order) and has no inflection point.

f(x) = x^3 - 3x^2 - 9x + 5 @@ a polynomial
f'(x) = 3(x - 3)(x + 1),\ \ f''(x) = 6(x - 1) @@ polynomial-slope twice
f'' \lt 0 \text{ on } (-\infty, 1),\ \ f'' \gt 0 \text{ on } (1, \infty) @@ bends down, then up
\text{inflection point } 1,\ f(1) = -6 @@ the sign of f″ changes there
\text{top } -1 \text{ (value } 10),\ \ \text{bottom } 3 \text{ (value } -22) @@ second-test: f″(−1) = −12, f″(3) = 12

Every cubic has exactly one inflection point, at the zero of its f″, which is linear. And it is halfway between the cubic's top and bottom when it has them, since f″'s zero is the middle of f′'s two zeros.

14g3Sketching, by the numbers

Stands on 14g2 and 14f (the first test).

The steps, in order. Find where f is defined. Find its zeros, where it is easy. Find f′, factor it, and read its sign between the critical points: tops, bottoms and where f climbs or falls. Find f″ and read its sign: where f bends up or down, and the inflection points. Read what f does for inputs of large size: for a polynomial the leading term decides (9g's leading-term). Mark the points, then join them obeying every sign.

f(x) = \tfrac{x}{1 + x^2} @@ defined on ℝ; zero only at 0; f(−x) = −f(x)
f'(x) = \tfrac{1 - x^2}{(1 + x^2)^2} @@ quotient for slopes: bottom at −1 (value −½), top at 1 (value ½), as 12c found by hand
f''(x) = \tfrac{2x(x^2 - 3)}{(1 + x^2)^3} @@ quotient for slopes and chain for slopes; sign of 2x(x − √3)(x + √3)
\text{inflection points } -\sqrt3,\ 0,\ \sqrt3 @@ f″ changes sign at each: −, +, −, + from the left
|x| \text{ large}:\ |f(x)| \le \tfrac{1}{|x|} @@ |x|/(1 + x²) < |x|/x²: it heads to 0 at both ends

Read backwards, the same rules sketch f′ from f. Where f climbs, f′ is above 0. At a top or bottom with a slope, f′ is 0. Where f bends up, f′ is climbing. At an inflection point, f′ has a top or a bottom. So reading a graph of f′ gives the tops and bottoms of f at its zeros, and the inflection points of f at its own tops and bottoms.

14g4Bends of a solution set

Stands on 14g3 and 13l (slopes of both sides).

13l found slopes on a branch of a solution set from the equation itself. The second slope comes the same way. Take the branch of x² + 4y² = 8 through (2, 1). There 2x + 8y·y′ = 0, so y′ = −x/(4y), which is 0 where x = 0: a level tangent, at (0, ±√2). Take the slope of y′ = −x/(4y) by quotient for slopes, with y′ substituted: y″ = −(4y − 4xy′)/(16y²) = −(4y² + x²)/(16y³) = −8/(16y³) = −1/(2y³). On the upper branch y > 0, so y″ < 0: it bends down, and (0, √2) is a top. Where y = 0 the slope formula divides by 0, and the branch has no slope there.

The first textbook of the calculus gave a whole section to the points where a curve changes its bending. It found them where the second difference of the ordinate vanishes or becomes infinite.

Who said it first

L'Hôpital's book gave a whole section to the points where a curve changes its bending, and found them where the second difference of the ordinate vanishes or becomes infinite.

L'Hôpital, Analyse des infiniment petits (1696), section 4; paraphrase

The four colour proof of 1976 is Kenneth Appel’s and Wolfgang Haken’s; its accepted name is the four colour theorem.

Accepted names: bending up is concave up and bending down is concave down; which way a function bends is its concavity.
