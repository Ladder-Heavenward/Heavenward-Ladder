7b · proof

Finite cases need no either-way

Is any of 4, 9, 15 and 21 prime? Look: 4 is two twos, 9 is two threes, 15 is three fives, and 21 is three sevens. None is. The look settled the question, and no principle was needed to say that one side or the other is true: the check proved one side. This step makes that exact. It gives “settled” a line, and shows that the joining words keep statements settled. Then it proves, by induction on the number of members, that over a set you can count, a condition you can check at each member gives a some and an every you can check too. So the either-way principle says nothing new about finitely many checkable cases. Its whole weight falls where the cases never end.

Look at every member, one at a time. With finitely many, the looking ends, and the last look settles the some and the every. With endlessly many, it never ends.

7b1Settled, made exact

1f used “settled” for a statement whose row you can find by looking. 4h gave the word a line for sets of numbers, and 4k for parts of a set. Here is the line for statements and conditions, which the others are cases of.

From here on, a statement P is settled when P ∨ ¬P has been proved by a constructive column: one that does not cite either-way. A condition φ is settled on a set X when this has been proved that way:

Its accepted name is decidable, and from here on the ladder uses it: a decidable statement, a condition decidable on a set.

7b2The stock, and joining decidable pieces

4h's line for a decidable set of numbers is ∀n ∈ ℕ (n ∈ X ∨ n ∉ X), and 4k's for a decidable part is ∀x ∈ X (x ∈ s ∨ x ∉ s). Both are statements about a set. Before this rung the only way to have one was a constructive column, so they fit this line. (7d answers what becomes of those two statements once either-way is a technique. This step's word keeps marking the ors earned without the either-way principle.) The ladder already owns a stock of decidable conditions. There are sameness and order of numbers (settled-order) and of rationals (settled-order on ℚ), and “d divides n” (settled-divides). There is “p is prime” (4j, by divisor-not-past and bounded-some), and sameness inside a finite set (finite-is-settled). Decidable statements combine. Settled-join technique: if P and Q are decidable, so are ¬P, P ∧ Q, P ∨ Q and P ⇒ Q.

P \lor \neg P,\quad Q \lor \neg Q @@ given: both decidable
\text{case } P:\ \neg\neg P,\ \ \htmlClass{new}{\neg P \lor \neg\neg P};\quad \text{case } \neg P:\ \neg P \lor \neg\neg P @@ not-not-in (1b); add an option. ¬P is decidable
\text{case } P,\, Q:\ P \land Q;\quad \text{case } \neg P:\ \neg(P \land Q);\quad \text{case } \neg Q:\ \neg(P \land Q) @@ join; or assume P ∧ Q, keep a part, clash, refute. Then add an option
\text{case } P \text{ or } Q:\ P \lor Q;\quad \text{case } \neg P,\, \neg Q:\ \neg(P \lor Q) @@ add an option; neither (1c), the direction from ¬P ∧ ¬Q
\text{case } \neg P \text{ or } Q:\ P \Rightarrow Q;\quad \text{case } P,\, \neg Q:\ \neg(P \Rightarrow Q) @@ free-if (1d); or assume the if, carry through, clash, refute
\text{each of the four is decidable} \quad \blacksquare @@ add an option in every case; reason by cases on the two given ors

So any statement built with the joining words from decidable pieces is decidable. The techs for checking it are the table's: find the row of each piece, and work outward, as 1e did, except that now every step cites a tech. What settled-join does not reach is every and some. For those, the number of cases matters.

7b3A some over a set you can count

Finite-search technique: if Y has n members and φ is decidable on Y, then ∃x ∈ Y φ(x) is decidable. The proof is an induction on n, in 4c's shape, with the condition fixed and the set allowed to vary. The statement ψ(n) to carry up, the column's first line, says this for every set with n members on which φ is decidable: the some over it is decidable.

\psi(n):\ \forall a\,\big(a \text{ has } n \text{ members} \land \varphi \text{ decidable on } a \;\Rightarrow\; \exists x \in a\,\varphi(x) \lor \neg\exists x \in a\,\varphi(x)\big) @@ name the condition first (4c)
\textbf{base.}\ \text{let } a \text{ have } 0 \text{ members} @@ let a be anything; assume
\quad x \in a \Rightarrow x\text{'s partner} \in 0 = \varnothing,\ \bot @@ the matching (4k); the empty-set technique; clash
\quad \neg\exists x \in a\,\varphi(x) @@ assume a some, call it, the line above, refute
\quad \htmlClass{new}{\text{the or, for } a} @@ add an option, on the right
\begin{aligned}&\textbf{step.}\ \text{assume } \psi(n)\\ &\quad ;\ \text{let } a \text{ have } S(n) \text{ members},\\ &\quad \ \varphi \text{ decidable on } a\end{aligned} @@ the induction hypothesis; let a be anything; assume
\quad \text{call } b \in a \text{ the partner of } n @@ n ∈ S(n) by in-its-next (3b); the matching
\quad a \setminus \{b\} \text{ has } n \text{ members};\ \ \varphi \text{ decidable on } a \setminus \{b\} @@ lead-one-out (4k); a ∖ {b} ⊆ a, so use the every
\quad \exists x \in a \setminus \{b\}\,\varphi(x) \lor \neg\exists x \in a \setminus \{b\}\,\varphi(x) @@ ψ(n), used with a ∖ {b}
\quad \varphi(b) \lor \neg\varphi(b) @@ φ decidable on a; b ∈ a
\quad \text{case } \varphi(b):\ \exists x \in a\,\varphi(x) @@ show an example: b
\quad \text{case } \neg\varphi(b),\ \text{some } x \in a \setminus \{b\}:\ \exists x \in a\,\varphi(x) @@ call it; it is in a (﹀ ∖); show an example
\quad \text{case } \neg\varphi(b),\ \neg\exists x \in a \setminus \{b\}\,\varphi(x): @@ the last case
\qquad \text{assume } x \in a \land \varphi(x);\ \ x = b \lor x \ne b @@ aiming to refute; finite-is-settled (4k): sameness in a finite set is decidable
\qquad x = b:\ \varphi(b),\ \bot;\quad x \ne b:\ x \in a \setminus \{b\},\ \bot @@ the swap axiom, clash; ︿ ∖, show an example, clash
\quad \neg\exists x \in a\,\varphi(x) @@ cases; refute; the call closes
\quad \htmlClass{new}{\text{the or, for } a} @@ add an option in each case; reason by cases
\forall n \in \mathbb N\ \psi(n) \quad \blacksquare @@ prove an if; speak of everything; the induction technique (4c)

No line cites either-way. Every case split comes from a given or: φ decidable on the set, the induction hypothesis, and finite-is-settled for sameness inside a finite set. Unfold the induction for a set with four members and you get exactly the look at {4, 9, 15, 21}. One member is led out at each step and checked, and the result for the rest is carried along. The finite-search technique is the look, written once for every number of members.

7b4An every over a set you can count

The every comes from the some. The finite-search technique: if Y has n members and φ is decidable on Y, then ∀x ∈ Y φ(x) is decidable.

\neg\varphi \text{ is decidable on } a @@ settled-join, at each member
\exists x \in a\,\neg\varphi(x) \lor \neg\exists x \in a\,\neg\varphi(x) @@ finite-search's some, with ¬φ in the place of φ
\text{case } \exists x \in a\,\neg\varphi(x):\ \neg\forall x \in a\,\varphi(x) @@ the counterexample technique (2b): a counterexample
\text{case } \neg\exists x \in a\,\neg\varphi(x):\ \forall x \in a\,\neg\neg\varphi(x) @@ the not-some technique (2b)
\quad \text{let } x \in a:\ \varphi(x) \lor \neg\varphi(x),\ \neg\neg\varphi(x),\ \text{so } \varphi(x) @@ φ decidable; the remaining-option technique (1c)
\quad \forall x \in a\,\varphi(x) @@ speak of everything
\htmlClass{new}{\forall x \in a\,\varphi(x) \lor \neg\forall x \in a\,\varphi(x)} \quad \blacksquare @@ add an option in each case; reason by cases

So over a set with n members, a decidable condition gives a decidable some and a decidable every. By settled-join, everything you can build from those with the joining words is decidable too. The either-way principle, for such statements, is a technique with a constructive column. It says nothing new about them.

7b5What “finite” has to mean here

Both hypotheses of finite-search matter, and neither can be dropped. The set must have n members for some number n, in 4k's sense: matched with n. And the condition must be decidable at each member. Here is a set that looks small and fails the first. It needs a name.

From here on, for a statement P, ⟦P⟧ names the set {x ∈ 1 : P}, a part of 1 = {0}. Read it “the mark of P”. Here “mark” is said of a set; 0a's mark, a written sign such as ∈ or ∎, keeps its meaning, and what the word is said of says which.

Take any statement P. The only possible member of ⟦P⟧ is 0. Is it finite? If P, it has 1 member; if ¬P, it has 0. If nobody can settle P, nobody can match ⟦P⟧ with any number, and finite-search does not apply to it. That is why “every part of a finite set has a number of members” is not a technique of rung 4: 4k counted the decidable parts only. The trouble did not come from a large set. It came from an undecided condition, P, hidden inside the description of a small one.

So the precise moral is this. Where every case can be checked, and there are n of them, the either-way principle is not needed. Its content lies in two places: in an every or a some whose cases never end, and in conditions that nobody can check at all. On the ladder the second kind, when it is about mathematics, usually turns out to hide the first kind inside it. The statement P above might be the even-sum guess.

7b6Searches over numbers

4j's bounded-some was a case of finite-search that arrived early. The numbers up to m are the members of S(m), and S(m) is matched with itself, so it has S(m) members. Finite-search then gives bounded-some's “a bounded some of a decidable condition is decidable”. 4j used bounded-some to settle “d divides n”, by searching the k up to n, and “p is prime”, by searching the divisors up to p. Here is one more worked check. Is every number below 10 a sum of at most four squares, in 5f's sense of square, r · r?

0 = 0^2,\ \ 1 = 1^2,\ \ 2 = 1^2 + 1^2,\ \ 3 = 1^2 + 1^2 + 1^2 @@ each a case of the condition: show an example
4 = 2^2,\ \ 5 = 2^2 + 1^2,\ \ 6 = 2^2 + 1^2 + 1^2,\ \ 7 = 2^2 + 1^2 + 1^2 + 1^2 @@ the condition is decidable at each: the squares to try are bounded
8 = 2^2 + 2^2,\ \ 9 = 3^2 @@ the last case
\begin{aligned}&\htmlClass{new}{\forall n \lt 10\ (n \text{ is a sum of at most four }}\\ &\quad \htmlClass{new}{\text{squares})}\end{aligned} @@ finite-search's every: the look ended, and every case passed

The same statement over all of ℕ is true too: the four-squares technique, proved in 1770, lets you write any number as a sum of at most four squares. But that every was settled by a proof, not a look. No look over ℕ ever ends.

7b7When the cases never end

An every over an endless set can still be settled, in three ways. A proof can settle it true. The four-squares technique did so, 4j's even-or-odd settled “every number is even or odd”, and 4j's endless-primes settled that every list of primes misses a prime. A single counterexample can settle it false. 4j's “n · n + n + 41 is always prime” fails at n = 40, since 40 · 40 + 40 + 41 = 41 · 41. Or neither may be known.

The even-sum guess is the standing example of the third. Each case, “n is a sum of two primes”, is decidable: the primes to try are bounded by n, so bounded-some decides it. Checking has gone very far. Every even number from 4 up to 4 · 10¹⁸ has been checked and found to pass (2014). By finite-search, that bounded statement is decidable, and true. The endless one is not known to be decidable. Looking can only ever refute it, by finding a failure, and no failure has turned up; and nobody has a proof. So whether “some even number above 2 is not a sum of two primes” is true or not is beyond every check anyone can finish. The picture's right panel runs the look as far as you like and shows it never reaching the end.

This is where 7c comes in. The either-way principle says that one side is true anyway. On this ladder that is not an extra axiom: 7c proves it from the choosing axiom.

7b9Running it backwards

Wanting a some or an every over a finite set, check that the condition is decidable at each member and that the set has a number of members, then cite finite-search. Settled-join gives decidable conditions from decidable pieces. Then the or is earned, with no either-way principle. Wanting to know why a question resists, look for the endless every or some inside it, or for an undecided condition hiding in a small set's description. Handed a case split in a proof, ask where its or came from. If it came from finite-search, settled-order, finite-is-settled or a given, the proof is still constructive. Found upward; written downward.

Who said it first

The four-squares technique is Joseph-Louis Lagrange’s (1770). The even-sum guess is Christian Goldbach’s, from a letter to Leonhard Euler (1742). The check to 4 · 10¹⁸ is by Tomás Oliveira e Silva, Siegfried Herzog and Silvio Pardi (2014). Endless-primes is Euclid’s. The moral about finite collections is L. E. J. Brouwer’s.

Brouwer's point was this step's moral: the laws of logic were learned on finite collections, where every member can be inspected and they are safe; carried over to the endless, they become an article of faith.

Brouwer, “De onbetrouwbaarheid der logische principes”, Tijdschrift voor Wijsbegeerte 2 (1908)

Accepted names

The four-squares technique is Lagrange’s four-square theorem. The even-sum guess is Goldbach’s conjecture. The either-way principle is the law of excluded middle.
