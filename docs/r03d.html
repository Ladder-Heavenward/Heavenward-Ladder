3d · proof

Inductive Sets and the Axiom of Infinity

3c gave you the next one, and with it a run of sets that never stops: 0, 1, 2, 3, 4, the next one after 4, and on. Each entry is a set you could write out. What you cannot write out is the whole run, and this step says exactly why: any set you finish writing is missing the next one after some member. It gives the property that the whole run would have, holding 0 and never running out of next ones, the name inductive, and proves that the obvious candidates fail it. Then it lays down the one axiom of this rung, that some set is inductive. It shows what follows, a set that holds every entry of the run; and what does not, that the set holds nothing else.

A set is inductive when 0 is in it and the next one after any member is in it too. No set you can finish writing is inductive; the axiom says one exists anyway; and every entry of the run, as far as you care to name, is in every inductive set.

3d1A Set That Runs Out

Try to gather the run into a set. Gather what you have named: . It holds 0. It holds the next one after 0, which is 1, and after 1, and after 2, and after 3: those are 1, 2, 3, 4, all members. But the next one after 4 is S(4), and S(4) is not a member of J. Here is the proof, and it is the proof that every attempt to write the run out as a finished set fails.

4 is in S(4), by in-its-next. Suppose, until we drop it, that S(4) is in J. Every member of J is in 4 or is 4: 4 is the member furthest along, and 0, 1, 2 and 3 are all members of 4. So S(4) is in 4, or S(4) is 4. Take the cases.

If S(4) is 4, that clashes with never-its-own-next. If S(4) is in 4, then 4 is in S(4) and S(4) is in 4: each is inside the other. The no-loop technique says there is no such loop, so that clashes too. Both cases clash. So the supposition is refuted: S(4) is not in J.

3d2Where the Work Was Done

Nothing about 4 in particular was used except that it is the member furthest along. Write out any set of entries of the run, and the same argument, with the furthest member in place of 4, shows that its next one is missing. A set you can finish writing runs out at the member built last.

So the tools can iterate S as far as you like, one step at a time. They can never hold the whole iteration at once. That one thing is what 3d6's axiom gives: a single set that holds the whole run.

The long way was chosen because it works for any set of entries. For J itself there is a shortcut: J = S(4), so S(4) ∉ J is just no-self-membership.

Notice too what J did right. It held 0, and for every member but the last it held the next one. The failure was a single witness, and that is how such failures are always shown: by 2b's counterexample technique, an example that breaks the every.

3d3Inductive

Say the property in words: the set holds 0, and whenever it holds a set it holds that set's next one. In marks:

From here on, “I is inductive” means:

“Inductive” is a statement with a gap: so or not so of the set put in it.

The left part, , is called the base part. The right part is called the step part. The step part is an every around an if. In words: for any thing at all, if it is in I, then so is its next one.

Read the step part with 2b's care. It is not “the next one after each listed member is in I”, which you could check member by member. It is an every, over everything. It is used by use-an-every and made by speak-of-everything.

To show a set is inductive you must argue about an arbitrary member. To show a set is not inductive you need only a witness, as J's argument gave.

3d4Cargo

From here on, cargo means: anything an inductive set holds that is not an entry of the run.

Notice what the definition of inductive leaves out. It does not say that I holds only entries of the run. Example: an inductive set may hold {1}. Then, to stay inductive, it must hold S({1}), S(S({1})), and so on: another chain running alongside the run and never meeting it. S({1}) is {1, {1}}, and 3c13 showed it is not one of the named sets.

The definition tolerates cargo, and the axiom below says nothing about it. Rung 4's opening job is to get rid of it.

3d5Sets Tested Against the Definition

Some sets against the definition, each decided by a witness or a short argument. ∅ fails the base part: 0 ∉ ∅.

The set 4 = {0, 1, 2, 3} passes the base part. It fails the step part at 3: S(3) = 4, and 4 ∉ 4, by the no-self-membership technique.

The set J fails at 4. A set holding {1} and S({1}) but not S(S({1})) fails at S({1}), whatever else it holds.

None of the four sets just tested can be mended by adding the missing member. Example: add 4 to the set 4 and you have J, which fails at 4. The member added becomes the new furthest one, and its next one is missing in turn. You are not adding members; you are chasing a thing that recedes a step each time you reach for it.

3d6The Axiom

Every argument on this rung is a run of lines you can finish writing, and it names only the sets you write. So the ladder asks for the one thing the tools cannot make, a set that holds 0 and never runs out of next ones. It asks for it by an axiom.

Some set holds 0 and never runs out of next ones. That is the whole axiom. Like 2d1's empty-set axiom, it does not build. It asserts that a set with a property exists. Using it is a move like any use of a some, done honestly: a fresh name, and nothing assumed about the set beyond the property. (The empty-set axiom now follows from it: sift an inductive set by “is not itself”, as 2e10 does. Some books drop the empty-set axiom for that reason. The ladder keeps both lines, because 2e's point, that the tools make nothing from nothing, was worth a line of its own.)

3d7Every Named Set Is in Every Inductive Set

Here is the earliest thing that follows from the axiom.

Named-sets-are-inductive technique: every entry of the run you can name is in every inductive set. The proof is carry-through, over and over.

Let I be inductive. Unpack the word: 0 is in I, and for every x, if x is in I then S(x) is in I. Keep the left part: 0 is in I. Use the every with 0: if 0 is in I, then S(0) is in I. Carry the if through, and S(0) is in I. That is 1, so 1 is in I. Use the every with 1 and carry through, and 2 is in I. With 2, and then with 3, the same two moves give 3 and then 4.

And the lines do not stop at 4. Use the every with 4 and carry through, and S(4) ∈ I; again, and S(S(4)) ∈ I. Whatever entry of the run you reach by writing S enough times, the argument reaches it too, with a use-an-every and a carry-through at each step. That is the sense in which an inductive set holds the whole run. The holding is not by a line that says “every entry”, since the ladder has no name yet for the run as a whole. It is by an argument that can be stretched to any entry you name. Rung 4 gives the run a name and turns this argument into a line that says it outright.

3d8What Follows, and What Does Not

What follows from it is an object. With I in hand you may sift from it (2e), gather it with other sets, pair it, and take all its subsets. And you may quantify over its members: “every member of I” and “some member of I” are now statements the techs of 2b can use. Everything endless that the ladder builds later is sifted or paired out of this one set. The counting numbers, as a set, are rung 4's sift of it. The axiom is the only line on the ladder that asserts an endless collection, and it is a short line.

“The numbers” do not follow from the axiom. The set it asserts may carry cargo, and different inductive sets may carry different cargo, so “every member of I” is not yet “every number”.

Induction does not follow from it either: the principle that what is so at 0 and passes from each entry to the next is so for every entry. That is a technique of rung 4, and the cargo is exactly what has to be sifted away before it can be proved.

Nor does the axiom come with a reason. Why should an inductive set exist? The axiom does not say, and 3f shows that nothing earlier on the ladder can say either: the axiom is a choice.

3d9Matched With a Part of Itself

An old definition of an endless collection: one that can be matched, member for member, with a part of itself that is not the whole.

An early writer tried to prove that an endless set exists. He took “everything I could ever think of” as a set, and matched each thought with the thought “I am thinking of that”. The ladder refuses the move: “everything I could think of” is a sift with no set to sift from (2e), and there is no set of everything (3a·f).

The author of the first list of axioms for sets, early in the century before this one, saw that no such proof could work, and listed infinity as an axiom. The set he asked for was built with his own next-one rule, the {x} of the second line of 3c's moves-to-check table, in place of S(x). The ladder uses 3c's S, and both choices come to the same thing.

The definition of an endless collection is worth keeping, because it does not mention counting at all, and the run has the property it names. Match each entry of the run with its next one: 0 with 1, 1 with 2, 2 with 3, and so on.

Every entry is matched with something, its next one. Different entries are matched with different things: that different sets have different nexts is held in trust here, until 4b proves it. And the things matched to leave out 0, since 0 is nobody’s next (the next-never-empty technique). So the run is matched, entry for entry, with a part of itself that misses 0.

The slides try the same matching on the set 4, member by member. Whether any set you can finish writing could do it is answered on 4k, where matching is built. The ladder does not need this fact yet. It is here because it is the oldest clear statement of what “endless” means.

Anexact, yet rigorous · the universe, gathering

Picture the universe as a list of what is where, at each moment. Now count the entries. Cut space into the smallest pieces physics can speak of, and time into the smallest ticks. Each piece of space at each tick is a cell.

The cells of the visible universe, right now, number about a one followed by 185 zeros. That count comes to an end, and it can be estimated. But the count does not stay put. Each tick adds a fresh layer of cells, and space itself keeps growing. There is always a next tick. That is 3c's run again: a start, a next, and no last.

No moment holds the whole run. Every count anyone makes comes to an end. The rule for the next cell can be written down, and the finished collection never turns up. The world can describe an endless collection, but it never hands you one finished; the axiom is where you take the finished collection anyway.

Every count of the cells that will ever be made is finite. Then what would it mean for all of them to be one object?

3d11Running It Backwards

Wanting “I is not inductive”, you look for a witness: either 0 ∉ I, or a member x of I with S(x) ∉ I. Then use the counterexample technique on the step part. For any set you can write out, the witness is the member furthest along the run, and the argument for J is the model.

Wanting “I is inductive”, the shape is fixed by the definition. Prove 0 ∈ I, then “let x be anything; suppose x ∈ I; … so S(x) ∈ I”, speak of everything, join.

Wanting “t ∈ I” for a named entry t and an inductive I, you run the named-sets-are-inductive argument as far as t: use the every, carry through, at each step.

Wanting an inductive set at all, there is no source but the axiom, used by use-a-some with a fresh name. Found upward; written downward.

Who said it first

The founder with the realm of thoughts, and the matching definition of an endless collection, is Richard Dedekind. The author of the first list of axioms for sets, who listed infinity as an axiom with the next-one rule x to {x}, is Ernst Zermelo (1908); the ladder’s S is John von Neumann’s. The oldest view of the endless as a process is Aristotle’s.

Dedekind wanted the existence of an endless collection proved rather than assumed. His argument took as a set the whole realm of his own possible thoughts, and pointed out that each thought s gives rise to a further thought, “s can be an object of my thought”, which differs from s; so the realm is matched with a part of itself that leaves something out, which was his own definition of an endless collection: one that can be matched, member for member, with a part of itself that is not the whole.

Dedekind, Was sind und was sollen die Zahlen? (1888), §64 and §66, trans. Beman, 1901

Accepted names

A collection that can be matched, member for member, with a part of itself that is not the whole is called Dedekind-infinite.
