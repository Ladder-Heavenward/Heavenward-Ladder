When Are Two Things Truly the Same?

When are two things truly the same? The call back before this page kept two answers side by side: one thing with two names, and two things matched in exactly one way that keeps what matters. Mathematicians work with the second all day and write the first, and the gap between them is filled by a habit: whatever is true of one is true of the other, as long as it was said properly. Between 2006 and 2013 a group of mathematicians took the habit at its word. Start from the typed programs of the last step, where a statement is a type and a proof is a term. Make sameness a type too: for two members of a type, a type whose members are the ways the two are the same. Read those ways as the paths of rung thirty four, from one point to another, and the ways of being the same can be run in a row and run backwards, exactly as loops were. Then lay down one more axiom, that the ways two types are the same are exactly the matchings between them. Matched becomes equal, and the habit becomes a rule of the calculus. This page builds the sameness type, counts its members for small types, and computes the loops of the circle inside it, a result of 2012.

In a type theory, the sameness of two members is a type whose members are the ways they are the same, read as paths; they run in a row and backwards, and any one carries every statement about the first to one about the second. The univalence axiom says the ways two types are the same are exactly their matchings, so a two-member type is the same as itself in two ways, and a type with more members in as many ways as it has shuffles. The circle, built from a point and a loop, has the whole numbers as its loops, computed inside the calculus.

47·now.1Sameness as a Type

Add to 47j’s calculus a type x = y for any two members x, y of a type A, and one term refl_x : x = x. A member p : x = y is a way x and y are the same. The one rule for using a way says: to build something from every way p : x = y, for every x and y, it is enough to build it for refl. 0b’s self-sameness is refl, and the rule is how 0b’s swap becomes a term.

Carry-along technique: from a way p : x = y and a member of P(x), the rule builds a member of P(y), for every type family P.

P : A \to \text{types},\ \ p : x = y,\ \ t : P(x) @@ a family of statements, a way, and a proof about a
\text{to build } P(x) \to P(y) \text{ for every } p @@ the goal
\text{for } p = \mathrm{refl}_x:\ \ \lambda t.\,t : P(x) \to P(x) @@ enough, by the one rule
\htmlClass{new}{\text{carry}_P(p) : P(x) \to P(y)} \quad \blacksquare @@ the swap axiom of 0b, as a program

The same rule builds p · q : x = z from p : x = y and q : y = z, and p⁻¹ : y = x, each by building it for refl. The ways at a point, x = x, then make a group up to sameness of ways, as 34g2’s loops did. Picture each type as a space, each member as a point and each way as a path, and every rule of the calculus is true of paths. That reading is the field’s name for itself.

47·now.2Matched Means Equal

Types are themselves members of a type of types. So for types A and B there is a type A = B. There is also the type A ≃ B of matchings, pairs of terms f : A → B and g : B → A undoing each other up to ways. By the one rule, every way A = B gives a matching: carry along it in the family X ↦ X. The univalence axiom lays down that this map from A = B to A ≃ B is itself a matching. It is earned from above: without it, the calculus cannot prove that two matched types are the same, and every statement must be carried across a matching by hand, the habit the axiom turns into a rule.

Way-count technique: with the univalence axiom, a type with n members is the same as itself in exactly n! ways.

(A = A) \cong (A \simeq A) @@ the univalence axiom
A \simeq A \text{ for } A \text{ with } n \text{ members} = \text{the matchings of } A \text{ with itself} @@ the shuffles of n things (19a)
\text{their number is } n! @@ 4k’s product rule: n places for the first, n − 1 for the next, …
\text{two members: } 2! = 2,\ \ \text{three: } 3! = 6 @@ the do-nothing way and the swap; S₃
\htmlClass{new}{\text{refl is not the only way } A = A \text{ once } n \ge 2} \quad \blacksquare @@ the swap is a second

That breaks a rule sets keep. In rung 2’s sets, two sets are equal or not, and there is nothing more to say: one way at most. The calculus without the axiom has a world where every x = y has at most one member. In 1994 a second world was found, built from categories in which every arrow can be undone (47a2), where x = x can have many; so “at most one way” cannot be proved in the calculus, and the axiom chooses the second kind. The two-member type has two ways to be itself, and a proof that uses the swap way carries a statement about true and false to the statement with true and false exchanged.

47·now.3The Circle, Computed

Build a type S by two terms: a point base : S and a way loop : base = base, with the rule that to build something over S it is enough to say where base goes and where loop goes. That is the circle of 34g, made of one point and one path, with nothing about the line or about cos and sin.

Circle-ways technique: in the calculus with univalence, the ways base = base are matched with the whole numbers, loop going to 1 and running ways in a row going to adding.

\text{over } S:\ \ \text{base} \mapsto \mathbb Z,\ \ \text{loop} \mapsto (n \mapsto n + 1) @@ the rule for S; n ↦ n + 1 is a matching of ℤ, so by univalence a way ℤ = ℤ
\text{code}(p) = \text{carry}(p)(0) \in \mathbb Z \text{ for } p : \text{base} = \text{base} @@ carry 0 along p: 34g3’s lift of a loop from 0, read at its end
\text{code}(\text{loop} \cdot \text{loop} \cdot \text{loop}^{-1}) = 0 + 1 + 1 - 1 = 1 @@ carrying along a row is carrying each in turn
\text{decode}(n) = \text{loop}^n @@ run loop n times, backwards for n below 0
\text{code} \circ \text{decode} = \mathrm{id},\ \ \text{decode} \circ \text{code} = \mathrm{id} \text{ up to ways} @@ by the rule for S, and the one rule; held in trust here, done in full in 2013
\htmlClass{new}{(\text{base} = \text{base}) \cong \mathbb Z} @@ 34g4, now a program

The proof is 34g’s, with the unrolling of the circle onto the line replaced by a family of types over the circle. The line’s endless copies of each arc became the one type ℤ, carried round by adding 1. Univalence is where it runs: without it, n ↦ n + 1 could not be a way ℤ = ℤ, and nothing would turn as the loop goes round. Since 2013 the loops of spheres in more dimensions have been computed the same way, some of them by machine checkers of the kind 38·now described.

47·now.4What Is Settled, and What Is Not

Settled: the calculus with univalence has a world built from sets, found in 2006–2009, so it is clash-free if set theory with enough large sets is (38c). Settled since 2015–2018: a variant, cubical, in which univalence is no longer only laid down but computes, so a term built with it still runs to an answer, as 47j’s terms do. A book written by the group in 2013 laid the field out, and machine checkers of 38·now carry large libraries in it.

Not settled: whether mathematics should be written this way. A theory in which matched things are equal fits the practice of this rung; it does not fit rung 2’s sets, where {1, 2} and {3, 4} are matched and unequal. Each world of the calculus is one witness, and 38j’s no-self-certificate technique says neither side can certify itself from inside. Whether the calculus can hold every higher kind of sameness, ways between ways between ways without end, in a form a machine can check is a question being worked on now.

\text{rung 2’s sets: } \{1, 2\} \ne \{3, 4\},\ \text{at most one way } x = y @@ sameness is membership
\text{univalence: } \mathrm{Bool} = \mathrm{Bool} \text{ in } 2 \text{ ways} @@ sameness is matching
\htmlClass{new}{\text{both clash-free if set theory with large sets is}} \quad \blacksquare @@ a world of the calculus is built from sets

The accepted names

The calculus is homotopy type theory; x = y is the identity type, refl reflexivity, and the one rule is path induction, the J eliminator. The carry-along technique is transport. A ≃ B is the type of equivalences, and the univalence axiom says idtoeqv : (A = B) → (A ≃ B) is an equivalence. The circle type is a higher inductive type, and the circle-ways technique is π₁(S¹) = ℤ, by the encode–decode method. The rule that every two proofs of x = y are equal is uniqueness of identity proofs, or axiom K. The world built from sets is the simplicial set model; cubical type theory gives univalence computational content.

Who said it first

Per Martin-Löf introduced identity types in the 1970s. Martin Hofmann and Thomas Streicher showed in 1994 that uniqueness of identity proofs is not provable, with a model in groupoids. Steve Awodey and Michael Warren, and Vladimir Voevodsky independently, read identity types as paths in 2005–2006; Voevodsky formulated univalence around 2009 and built the simplicial set model, published with Chris Kapulkin and Peter LeFanu Lumsdaine. The special year at the Institute for Advanced Study in 2012–13 produced the book Homotopy Type Theory: Univalent Foundations of Mathematics (2013). Michael Shulman and Daniel Licata computed the loops of the circle in 2012–13. Cyril Cohen, Thierry Coquand, Simon Huber and Anders Mörtberg gave cubical type theory in 2015, published 2018.

A proof that is not allowed

“A matching of A with B gives a way A = B, so every statement about A is true of B, including that A is the set {1, 2}.” Not allowed: inside the calculus, “A is the set {1, 2}” is not a statement about types; there are no members of members to speak of. Carrying is only along families the calculus can write, and that is why univalence is clash-free with it, and clashes with rung 2’s sets.
