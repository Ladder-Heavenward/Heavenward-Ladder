23f · proof

The Function That Refuses Its Series

So far every smooth function tried has been rebuilt by its endless matching polynomial, at least near the point. It is natural to think that must always happen: if a function has every slope at a point, surely those slopes say everything. This step builds a function that says nothing at the point. It is so flat there that its height and every one of its slopes are zero, so its matching sum is zero everywhere. Yet the function itself is not zero anywhere else. Its sum reaches everywhere and is right only at the one point it started from. Being smooth is one thing. Being rebuilt from one point is another, and stronger.

One smooth function has height zero and every slope zero at a point, but is not zero anywhere else. Its matching sum is zero and settles everywhere, and is wrong everywhere but the point. Smooth does not mean rebuilt from a point.

23f1A Function Flatter Than Any Power

Let f(x) = e^(−1/x²) for x ≠ 0, and f(0) = 0. Near 0, 1/x² is huge, so f is tiny. How tiny is the point.

\tfrac{f(x)}{x^m} = \tfrac{t^m}{e^{t^2}} \text{ in size},\ t = \tfrac{1}{|x|} @@ for x ≠ 0; m any whole number ≥ 0
\tfrac{t^m}{e^{t^2}} \le \tfrac{t^m}{e^{t}} \text{ for } t \ge 1 @@ t² ≥ t, and exp climbs
\tfrac{t^m}{e^t} \to 0 \text{ as } t \text{ passes every bound} @@ powers ≪ exponentials (22k2), with b = e
\htmlClass{new}{\tfrac{f(x)}{x^m} \to 0 \text{ as } x \to 0, \text{ for every } m} \quad \blacksquare @@ x → 0 sends t past every bound

So f(x) shrinks faster than x, than x², than x¹⁰⁰⁰, as x heads to 0. No power is flat enough to keep up.

23f2Every Slope at 0 Is 0

Flat-point technique: f is smooth, and f⁽ⁿ⁾(0) = 0 for every n.

x \ne 0:\ f'(x) = \tfrac{2}{x^3}e^{-1/x^2} @@ the chain rule (13e)
x \ne 0:\ f^{(n)}(x) = P_n\big(\tfrac1x\big)\,e^{-1/x^2},\ P_n \text{ a polynomial} @@ by induction (4h): the product and chain rules keep the shape
f^{(n)}(0) = 0 \Rightarrow \tfrac{f^{(n)}(h) - f^{(n)}(0)}{h} = \tfrac1h P_n\big(\tfrac1h\big) e^{-1/h^2} @@ ﹀ the slope at 0 (13a)
\tfrac1h P_n\big(\tfrac1h\big) e^{-1/h^2} \to 0 @@ a sum of terms f(h)/hᵐ, each heading to 0 (23f1)
\htmlClass{new}{f^{(n+1)}(0) = 0 \text{ for every } n} \quad \blacksquare @@ induction from f(0) = 0

23f3Smooth Is Not Rebuilt From a Point

T_n(x) = \textstyle\sum_{k=0}^{n} \tfrac{f^{(k)}(0)}{k!}x^k = 0 @@ every coefficient is 0 (23f2)
\text{the matching sum is } 0 \text{ and reaches everywhere} @@ every piece is 0
f(x) > 0 \text{ for every } x \ne 0 @@ exp is positive (17e)
\htmlClass{new}{\text{the matching sum of } f \text{ at } 0 \text{ equals } f \text{ only at } 0} \quad \blacksquare @@ the lines above

Two consequences. First, no power sum about 0 has total f near 0: by 23e3 its coefficients would be f's slopes over factorials, all 0. Second, adding f to any function changes it everywhere except at 0, and changes no slope at 0. Infinitely many smooth functions share every slope at a point.

From here on, f is rebuilt from w when some power sum about w with reach above 0 has total f(x) for every x near enough to w. Accepted name: f is analytic at w.

eˣ, sin, cos and polynomials are rebuilt from every point. ln(1 + x) and 1/(1 + x²) are rebuilt from 0, within reach 1. e^(−1/x²) is smooth at 0 and is not rebuilt from 0. The survey's claim, that a smooth function is rebuilt from one point, holds for the functions this ladder has met so far and fails for this one. Smooth asks for every slope. Rebuilt asks for the slopes to tell the whole story.

The cellar · there if you want it

The accepted names

A function rebuilt from w is analytic at w; one rebuilt from every point of an interval is real analytic there. Smooth functions that vanish outside an interval, built from e^(−1/x²), are bump functions. The flat-point technique shows e^(−1/x²) is smooth but not analytic at 0.

Who said it first

Joseph-Louis Lagrange built his calculus in 1797 on the belief that every function is its power series. Augustin-Louis Cauchy gave e^(−1/x²) as a counterexample in 1823. In 23f.4.5, the book is Lagrange's Théorie des fonctions analytiques and the lectures are Cauchy's Résumé of 1823; the rule of higher slopes in 14f.4.4 is Maclaurin's.
