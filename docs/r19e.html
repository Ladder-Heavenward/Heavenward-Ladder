19e · proof

Parity of Shuffles

Every shuffle can be made from swaps, in many ways and with many lengths. [2 3 1] takes two swaps, or four, or ten; never three, never five. This step proves that each shuffle is either even or odd, once and for all. The proof counts something the swaps cannot hide: the pairs that are out of order.

Every shuffle is a string of swaps. Doing one more swap changes the number of pairs out of order by an odd number. So every string for a shuffle has the parity of that number, and the even shuffles are half of Sₙ.

19e1Every Shuffle Is a String of Swaps

Swaps-build-every-shuffle technique: every shuffle of {1, …, n} is e or a string of swaps. Put n back in its place with one swap; what is left moves only 1 to n − 1.

n = 1:\ \ \text{the only shuffle is } e @@ the base
\sigma(n) = n:\ \ \sigma \text{ shuffles } \{1, \ldots, n - 1\} @@ the induction hypothesis gives its swaps
\sigma(n) = m \ne n:\ \ s_{mn}\sigma(n) = n @@ do σ, then swap m and n
s_{mn}\sigma = t_1 \cdots t_k \Rightarrow \htmlClass{new}{\sigma = s_{mn}t_1 \cdots t_k} \quad \blacksquare @@ a swap is its own inverse (19b4); induction on n (4f)
  
[2\ 3\ 1]:\ \ s_{13}[2\ 3\ 1] = [2\ 1\ 3] = s_{12} @@ σ(3) = 1: swap 1 and 3 after it
[2\ 3\ 1] = s_{13}s_{12} @@ check: 1 ↦ 2 ↦ 2, 2 ↦ 1 ↦ 3, 3 ↦ 3 ↦ 1

19e2Pairs Out of Order

From here on, a pair of places i < j is out of order in a shuffle σ when σ(i) > σ(j): in the list, the bigger number comes first. Write N(σ) for the number of pairs out of order. Its accepted name is the number of inversions.

e has no pair out of order. [2 3 1] has two: 2 before 1, and 3 before 1. s₁₃ = [3 2 1] has all three. N(σ) counts how far the list is from sorted, one wrong pair at a time.

19e3One Swap Changes the Count by an Odd Number

Doing a swap sᵢⱼ first, then σ, gives σsᵢⱼ, whose list is σ’s list with the entries in places i and j exchanged.

Swap-is-odd technique: exchanging two entries of a list changes the number of pairs out of order by an odd number.

\text{neighbours } k, k + 1:\ \ \text{only the pair } (k, k + 1) \text{ changes} @@ every other place sees the same two numbers on the same side
N \text{ changes by } \pm 1 @@ that one pair turns from in order to out, or back
\text{places } i \lt j:\ \ (j - i) + (j - i - 1) \text{ neighbour exchanges} @@ walk the entry at i right to j, then the other back left to i
2(j - i) - 1 \text{ is odd} \Rightarrow \htmlClass{new}{N \text{ changes by an odd number}} \quad \blacksquare @@ a sum of an odd count of ±1’s is odd (4j)

19e4Even and Odd, Once and for All

Parity technique: every string of swaps for a shuffle σ is even in length when N(σ) is even, and odd when N(σ) is odd.

\sigma = t_1 t_2 \cdots t_m,\ \ \text{each } t \text{ a swap} @@ any string
e,\ \ t_1,\ \ t_1t_2,\ \ \ldots,\ \ t_1 \cdots t_m @@ build σ one swap at a time, each done first
N(e) = 0,\ \ \text{each step changes } N \text{ by an odd number} @@ swap-is-odd
\htmlClass{new}{N(\sigma) \text{ and } m \text{ are both even or both odd}} \quad \blacksquare @@ after m odd changes from 0, N has the parity of m (4j)

From here on, a shuffle is even when it is a string of an even number of swaps, and odd otherwise. The even shuffles of {1, …, n} are written Aₙ. e is even, with no swaps.

Half-are-even technique: for n ≥ 2, Aₙ is a part-group of Sₙ with n!/2 members. Strings of even length joined give even length, and a string reversed undoes it (19c3), so the part-group test passes. The odd shuffles are exactly the copy s₁₂Aₙ, so Sₙ is two copies of Aₙ.

19e5A Puzzle That Cannot Be Solved

A tray holds 15 numbered tiles and one gap, in a 4 by 4 grid. A move slides a tile next to the gap into it: a swap of that tile with the gap. Start with the tiles in order and the gap in the corner. Can you end with only 14 and 15 exchanged, and the gap back in the corner?

Colour the grid like a chessboard. Each move takes the gap to a square of the other colour. To end in the corner it started in, the gap makes an even number of moves: an even number of swaps of 16 things. But 14 and 15 exchanged, all else home, is one swap: odd. No sequence of moves can do it.

m \text{ moves, gap back home} \Rightarrow m \text{ even} @@ the gap changes colour each move
\text{the result is a string of } m \text{ swaps: even} @@ parity
s_{14\,15} \text{ is odd} \Rightarrow \htmlClass{new}{\text{unreachable}} \quad \blacksquare @@ one swap

The accepted names

N(σ) is the number of inversions; the parity of a shuffle is its sign, +1 for even and −1 for odd, written sgn σ. Aₙ is the alternating group. A shuffle moving three things round a loop is a 3-cycle.

Who said it first

In 19e.4.5, the puzzle is the fifteen puzzle, made by Noyes Chapman in the 1870s and promoted by Sam Loyd, who claimed later to have offered $1000 for the 14–15 solution. The proof is by William Woolsey Johnson and William Edward Story, American Journal of Mathematics (1879).
