23j · technique

A list stored in one function

A list of numbers goes on forever, and a function is one thing. This step stores a whole list in one function. Each number of the list sits in front of a power, and the endless power sum is the function. Inside its reach the function can be handled like any other: added, multiplied, split into simpler pieces. Then the list is read back from the coefficients, which the function alone decides. Done to the rabbit counts, this turns a rule that builds each count from the two before into a formula that gives any count at once. And multiplying two such functions combines two lists exactly the way counting combines choices, so a counting question becomes a question about the number in front of one power.

Put the numbers of a list in front of the powers, and the list becomes one function. Work on the function, then read the list back off it. Multiplying the functions counts the ways to combine choices.

23j1Storing a list

From here on, the storing function of a list u₀, u₁, u₂, … is the power sum A(x) = Σ uₖxᵏ, wherever it settles. Accepted name: the generating function.

Read-back technique: if the storing function of a list has reach above 0, the function alone gives back the list, uₖ = A⁽ᵏ⁾(0)/k!; so two lists whose storing functions agree near 0 are the same list. That is 23e3's smooth-sum technique, used as a filing system.

1, 1, 1, \ldots:\ \ \textstyle\sum x^k = \tfrac{1}{1-x}\ \ (|x| < 1) @@ the geometric sum (15i)
1, r, r^2, \ldots:\ \ \textstyle\sum r^k x^k = \tfrac{1}{1-rx}\ \ (|x| < 1/|r|) @@ the same, with rx in place of x
1, 2, 3, \ldots:\ \ \textstyle\sum (k+1)x^k = \tfrac{1}{(1-x)^2} @@ the slope of 1/(1 − x), term by term (23e3)
0, u_0, u_1, \ldots:\ \ x\,A(x) @@ times x moves every number one place on
\htmlClass{new}{u_1, u_2, u_3, \ldots:\ \ \tfrac{A(x) - u_0}{x}} \quad \blacksquare @@ take off the first number and divide by x: every number moves one place back

A list obeys a rule. Its storing function then obeys an equation. Solve the equation for the function, which is one unknown instead of endlessly many, and read the list back. The next footing does it to the rabbit counts.

23j2The rabbit counts in closed form

The rabbit counts F₀, F₁, F₂, … = 0, 1, 1, 2, 3, 5, 8, 13, … start at 0 and 1, and each is the sum of the two before (9·cb4). Write φ = (1 + √5)/2, the ratio 21·bio met in the sunflower, and ψ = (1 − √5)/2. Both are roots of t² = t + 1.

Rabbit closed-form technique: Fₙ = (φⁿ − ψⁿ)/√5 for every n. Store the list, turn the rule into an equation, solve it, and read back.

F_n \le 2^n,\ \text{so } G(x) = \textstyle\sum F_k x^k \text{ settles for } |x| < \tfrac12 @@ induction (4c): Fₙ₊₂ ≤ 2ⁿ⁺¹ + 2ⁿ < 2ⁿ⁺²; comparison with Σ(2|x|)ᵏ (22e1)
G(x) - xG(x) - x^2G(x) = F_0 + (F_1 - F_0)x + \textstyle\sum_{k \ge 2}(F_k - F_{k-1} - F_{k-2})x^k @@ sums that settle add piece by piece (22d4); line up equal powers
G(x)(1 - x - x^2) = x @@ F₀ = 0, F₁ = 1, and the rule makes every later bracket 0
1 - x - x^2 = (1 - \varphi x)(1 - \psi x) @@ φ + ψ = 1 and φψ = −1 (8i)
G(x) = \tfrac{x}{(1-\varphi x)(1-\psi x)} = \tfrac{1}{\sqrt5}\Big(\tfrac{1}{1-\varphi x} - \tfrac{1}{1-\psi x}\Big) @@ partial fractions (17k): φ − ψ = √5
= \textstyle\sum \tfrac{\varphi^k - \psi^k}{\sqrt5}\,x^k @@ two geometric sums (23j1), for |x| < ½
\htmlClass{new}{F_n = \tfrac{\varphi^n - \psi^n}{\sqrt5}} \quad \blacksquare @@ read back (23j1): two storing functions agree near 0

Whole numbers come out of square roots of 5. Since ψ ≈ −0.618, ψⁿ/√5 is under ½ in size and shrinks fast, so Fₙ is the whole number nearest φⁿ/√5. F₂₀ = 6765, and φ²⁰/√5 = 6765.00003. The ratio Fₙ₊₁/Fₙ heads to φ, which is why neighbouring rabbit counts appeared in 21·bio's spirals.

The storing function also gives totals. G(0.1) = 0.1/(1 − 0.1 − 0.01) = 10/89 = 0.11235955…, and Σ Fₖ/10ᵏ is that number: its digits start 1, 1, 2, 3, 5, 8 before the carries blur them. The reach of G is 1/φ ≈ 0.618, where 1 − x − x² is first 0.

23j3Counting by multiplying

23h4's product technique, read for storing functions: inside both reaches, A(x)B(x) = Σ cₙxⁿ with cₙ = u₀vₙ + u₁vₙ₋₁ + ⋯ + uₙv₀. The number in front of xⁿ collects every way to split n into a part from A and a part from B.

A(x)B(x) = \lim_N \Big(\textstyle\sum_{j \le N} u_j x^j\Big)\Big(\sum_{k \le N} v_k x^k\Big) @@ limits multiply (10c)
\textstyle\sum_{j, k \le N} |u_j v_k x^{j+k}| \le \Big(\sum |u_j x^j|\Big)\Big(\sum |v_k x^k|\Big) @@ inside both reaches each settles in size (23c2)
\text{every product } u_j v_k x^{j+k}, \text{ in one list, settles in size} @@ its running totals climb under that ceiling (22a2)
\text{any order of that list has the same total} @@ 22g3
\htmlClass{new}{A(x)B(x) = \textstyle\sum_n \Big(\sum_{j=0}^{n} u_j v_{n-j}\Big)x^n} \quad \blacksquare @@ taken square by square it gives AB; taken by j + k = n it gives Σcₙxⁿ
  
(1+x)^m (1+x)^n = (1+x)^{m+n} @@ powers add
\textstyle\sum_j \binom{m}{j}\binom{n}{r-j} = \binom{m+n}{r} @@ the choose numbers stand in front of the powers of 1 + x (4k); the product technique on xʳ
\tfrac{1}{(1-x)(1-x^5)(1-x^{10})} = \Big(\textstyle\sum x^a\Big)\Big(\sum x^{5b}\Big)\Big(\sum x^{10c}\Big) @@ three geometric sums, |x| < 1
\htmlClass{new}{\text{the number in front of } x^n \text{ counts the } (a, b, c) \text{ with } a + 5b + 10c = n} \quad \blacksquare @@ each product x^(a + 5b + 10c) adds 1 to its power

The first line counts committees. Three people chosen from 5 legislators from Oregon and 4 from Washington can hold 0, 1, 2 or 3 Oregonians, and 1·4 + 5·6 + 10·4 + 10·1 = 84 = 9·8·7/6. The second counts change: 10 cents is made from pennies, nickels and dimes in 4 ways (ten pennies, five pennies and a nickel, two nickels, one dime), and the number in front of x¹⁰ is 4.

The basement · there if you want it

The accepted names

The storing function is the generating function (in full, the ordinary generating function). Read-back is the uniqueness of power series coefficients. The product technique is the Cauchy product of two series. The rabbit closed form is Binet's formula, and φ is the golden ratio. The committee count is Vandermonde's identity. Counting change by multiplying sums is the first example of counting partitions.

Who said it first

Abraham de Moivre stored lists in functions to solve rules like the rabbit rule in the 1720s, and found the closed form for the rabbit counts; Daniel Bernoulli found it too (1728), and Jacques Binet found it again in 1843, which is how it got his name. Leonhard Euler counted partitions by multiplying sums (1740s, in his Introductio of 1748). Pierre-Simon Laplace named them fonctions génératrices in 1812. The committee count is in Zhu Shijie's Jade Mirror of the Four Unknowns (1303), and Alexandre-Théophile Vandermonde published it in 1772.
