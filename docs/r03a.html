3a · proof

The next one

Rung 2 built the empty set, then the set holding only the empty set, then the set holding both of those, each from the one before by the same move: gather the set alone, and merge the set with that gathering. This step gives the move a mark and proves what the result is: it has every member the old set had and another besides, the old set itself. Then it does what the ladder has put off since the ground floor. It gives the earliest sets of the run the names everyone writes, 0, 1, 2, 3 and 4, by lines of the usual shape. It proves for each that it is the set of exactly the ones named before it. Along the way it proves that the next one is never the set you started from and never the empty set, which is why the run never stops and never loops. And it shows how to run the move backwards.

To take the next one after a set, keep everything in it and add the set itself as a new member. The names 0, 1, 2, 3, 4 belong to the earliest sets this makes from the empty set, and each of them is the set of those named before it.

What this stands on, and where it goes

Stands on 2a (listing, same-members, ⊆, the double-inclusion technique), 2b (∅, the techniques empty-set and one-empty-set), 2c (gather, ⋃, ∪, the merge-membership technique) and 2f (the techniques no-self-membership, not-its-own-gathering, no-loop). 3b uses S to say what “never runs out” means; 3c builds a world around these sets; rung 4 proves that different sets have different next ones, defines adding by repeating S, and proves that 1 + 3 is 4.

3a1The move, as a mark

Stands on 2c (gather, merge, ∪).

Say it in words, to begin with. You have a set x. Gather it alone: {x}, the set whose only member is x (2c's gather axiom, with x in both places). Now merge x with {x}: consider both as one set. The result has whatever x had in it, together with x itself as a new member. That is the move. Its mark:

Example: done to ∅, the move gives ∅ ∪ {∅} = {∅}. Done to {∅}, it gives {∅, {∅}}, the set rung 2 built.

From here on, means: . Read it “the next one after x”, or “the successor of x”.

Feeding a move its own output, again and again, is iterating the move. Iterate S from ∅: ∅, then S(∅), then S(S(∅)), and on. Each entry is one use of S on the entry before. Nothing in the move ever says stop, so the run it makes has no last step.

3a2Two jobs for the letter S

Stands on 3a1 (S), 0b (the swap axiom) and 0a (a name in a gap).

The letter S already names 0b's swap axiom, and this step cites it often. That name stays. When you read “the swap axiom”, the axiom is meant. When you read S(x), the mark is meant. From here on, S followed by a bracket, as in S(x), is also this mark.

Compare 0a's P(a). Both brackets hold a name, but P(a) is a statement and S(x) names a set.

3a3Who is in the next one

Stands on 3a1 (S), 2c (merge-membership) and 2a3 (the listing line).

Does the set exist? Yes, by axioms in hand: there is {x} by gather, {x, {x}} by gather again, and ⋃{x, {x}} by merge. 2c’s line for ∪ says that merge is what x ∪ {x} means.

Who the members of S(x) are is this rung's first technique, and every proof on this rung leans on it.

Next-membership technique: a thing is in the next one after x exactly when it is in x, or is x.

Here is why. To be in S(x) is to be in x ∪ {x}, since that is what the mark means. To be in a merge of two sets is to be in one or the other, by the merge-membership technique. So a thing is in S(x) exactly when it is in x or in {x}. To be in {x} is to be x, by 2a's listing line. Chain the exactly-whens: a thing is in S(x) exactly when it is in x, or is x.

3a4Every set is in its next one

Stands on 3a3 (next-membership), 1c (add an option) and 2a9 (⊆).

A pair of consequences come at once. They say that the move really does keep the old set and add it.

In-its-next technique: every set is a member of its next one, and a part of it.

First, x is in S(x). x is x, by the self-sameness axiom. So “x is in x, or x is x” is true: add an option. The first option, x is in x, is false, and that is fine. Adding an option only needs one side to be true, and the side “x is x” is. By next-membership, that or-statement is just what it takes for x to be in S(x).

Second, x is a part of S(x). Let y be anything, and suppose y is in x, until we drop it. Then y is in x or y is x: add an option. So y is in S(x), by next-membership. Drop the supposition: whatever y is, if y is in x, then y is in S(x). That is what x ⊆ S(x) means. Join the two halves, and the technique is earned.

Read the shape of the second half. It is 2a's shape for ⊆: an every around an if. Inside it the only work is “add an option” and next-membership. You will argue in that shape again and again on this rung.

3a5Names

Stands on 3a1 (S) and 0a (a name).

Here is the line the ladder has waited for. From the ground floor to this step, no numeral has appeared in any statement, and no number word has been said of anything. Nothing had been built for them to name. Now there are things to name. The run starts at ∅, and each entry is the next one after the entry before. The ladder names the earliest entries with the marks everyone writes, and it does so by the same kind of line it used for every other mark:

From here on, names ;   names ;   names ;   names ;   names . Read them “zero, one, two, three, four”. From here on these words and marks may be used for these sets, and for nothing else.

Pause on what the line says and what it does not say. It says that 0 is a name of a particular set, the one with no members. This is the first time 0 is used as a number, and not only as the empty set it names. And it says that 1, 2, 3 and 4 are names of particular sets, each made from the last by S. It does not say what “three” means in a sentence like “three cats sat on the wall”. That is a matter of matching the cats against the members of the set called 3, and that matching is built on rung 4.

Until then, a numeral on this ladder is a name of a set, and a number word is the way to say that name aloud, exactly as a letter standing alone has been a name since 0a. On 1f the marks 0 and 1 stood for false and true in a table. Here the same marks are names of sets. The two jobs never clash, and 4·comp shows why.

Nothing beyond 4 has a name yet. The next one after 4 is written S(4), and it is a perfectly good set with a perfectly good name. Shorter names for S(4) and the entries after it are given on rung 4, when there is a reason to want them.

Naming these sets 0, 1, 2, … is a choice, not a discovery. The choice used here was made about a hundred years ago, and it is the one everyone uses today: each entry of the run is the set of the entries before it.

3a6One and two, member by member

Stands on 3a5 (the names), 3a3 (next-membership) and 2a7 (same-members).

Now the pattern, proved for the named sets. Start with 1. Its members, by the next-membership technique, are the members of 0 together with 0 itself. And 0 has no members. So 1 has exactly the member 0.

That was the plan. Now say it in full. A thing is in 1 exactly when it is in 0 or is 0, since 1 names S(0). Nothing is in 0, since 0 names ∅. So the option “it is in 0” is refuted, and the or comes down to “it is 0”: a thing is in 1 exactly when it is 0. By the listing line, that is exactly when it is in {0}. So 1 and {0} have the same members, whatever thing you test. By the same-members axiom, 1 = {0}.

Then 2, whose members are the members of 1 together with 1, that is, 0 and 1.

A thing is in 2 exactly when it is in 1 or is 1, by next-membership. Being in 1 is being 0, as just shown. So a thing is in 2 exactly when it is 0 or is 1. By the listing line, that is exactly when it is in {0, 1}. Same members, so 2 = {0, 1}.

3a9Never its own next, never empty

Stands on 3a4 (in-its-next), 2f7 (no-self-membership) and 2b (the empty-set technique).

Are the names names of different sets? They had better be, or the run has stopped somewhere and merely looks as though it goes on. A pair of techniques settle it, and they may be used for any set, not only the named ones.

Never-its-own-next technique: no set is its own next one.

Next-never-empty technique: the next one after any set is never the empty set.

Try the first on 1. 1 ∈ S(1), and S(1) is 2. So if 2 were 1, then 1 ∈ 1, which no set is.

The reasons are short. Take any set x. By in-its-next, x is in S(x). Suppose, until we drop it, that S(x) = x. Swap x in for S(x), by the swap axiom, and x is in x. But no set is a member of itself, by the no-self-membership technique. That clashes, so the supposition is refuted: S(x) ≠ x.

Now suppose instead that S(x) = ∅. Again x is in S(x), so by the swap axiom x is in ∅. But nothing is in ∅, by the empty-set technique. Clash again, so S(x) ≠ ∅.

3a10The names differ, each from each

Stands on 3a9 and 2a7 (same-members, read backwards).

So 1 ≠ 0, by next-never-empty with x = 0. And 2 ≠ 1, 3 ≠ 2, 4 ≠ 3 and S(4) ≠ 4, by never-its-own-next each time.

For names further apart, use no-self-membership on the smaller name instead of on the larger. Example: 0 ∈ 2 and 0 ∉ 0, so 0 ≠ 2. The rule behind it: if some member of one set is not a member of the other, the sets differ, by the same-members axiom read backwards.

In general, whenever m ∈ n you have m ≠ n, since m ∉ m. And each named set is a member of each later one. The names name different sets, each from each, and the next one after 4 is yet another. There is no last.

The next-never-empty technique says more than it seems to. It says that 0 is nobody's next: no set x has S(x) = 0. The run has a start that nothing leads to. Rung 4 adds the companion technique, that different sets have different nexts. That needs 2f's no-loop technique, and its proof is where foundation is really needed.

3a11Running S backwards

Stands on 3a7 (3 = {0, 1, 2}) and 2c (⋃).

A move you cannot undo is only partly understood. Given 3 = {0, 1, 2}, how do you recover the set it is the next one of? It is the member added last, 2. But “added last” is a fact about how 3 was built, not something a tool reads off the set. Here is the tool that does it. To run S backwards on a set, take ⋃ of that set. Example: start with 3 and tip out every member of 3, together.

Since 3 = {0, 1, 2}, a thing is in ⋃3 exactly when it is in 0, in 1, or in 2, by 2c's line for ⋃. Nothing is in 0, so that option drops out. To be in 1 is to be 0. To be in 2 is to be 0 or 1. So a thing is in ⋃3 exactly when it is 0, or 0, or 1. Saying 0 twice adds nothing, so: exactly when it is 0 or 1. That is being in {0, 1}, which is 2. Same members, so ⋃3 = 2.

3a12Where merging back fails

Stands on 3a11 (merging back).

Why does merging back work? Every member of 3 is also a subset of 3. So tipping the members out produces nothing that was not already in the largest of them, 2.

For a set with a member that is not a subset of it, merging does not undo S. Take x = {1}. Then S(x) = {1, {1}}, and ⋃S(x) = ⋃{1, {1}} = 1 ∪ {1} = {0, 1}. That is 2, not {1}.

The member 1 is not a subset of {1}: 0 ∈ 1 but 0 ∉ {1}. That is where merging back fails.

The picture's right panel lets you try it. Merge 0 and you get ⋃∅ = ∅ (2c), which is 0 again: the start of the run, which is nobody's next, hands you itself.

3a13S on sets outside the run

Stands on 3a10 (the names differ) and 2f9 (not-its-own-gathering).

S is a move on any set, not only on the named ones. Take x = {1} again: S({1}) = {1, {1}}, as 3a12 computed, a set with two members, 1 and {1}.

Is S({1}) one of the named sets? No. {1} ∈ S({1}), and {1} is not a member of any of 0, 1, 2, 3, 4. Their members are named sets, and {1} is none of them. For instance, {1} ≠ 1, by the not-its-own-gathering technique.

The next one after a set outside the run stays outside it, by the same reasons each time; this step argues only the one.

3b will call sets like {1}, S({1}), S(S({1})) cargo: an endless chain of their own, running alongside the named run and never meeting it.

3a15Running it backwards, in general

Stands on 3a1 to 3a13.

Wanting y ∈ S(x), you want “y is in x, or y is x”. So you prove one side and add an option, then cite next-membership, as with 0 ∈ 1, where the side 0 = 0 is the one proved.

Wanting S(x) = {…} for a listed set, you chase a member. Unpack S by next-membership, rewrite each option by what you know of x's members, pack the listing, and close with same-members. The arguments for 1 and 2 are the model.

Wanting S(x) ≠ something, you look for a member of one side that is not in the other. In-its-next hands you x ∈ S(x) as the thing to try before anything else. Never-its-own-next and next-never-empty are the commonest cases, cited by name.

Wanting the set x of which a given set is the next one, you merge. Then check afterwards that S of what you got is the set you were given, since merging only undoes S for sets whose members are subsets. Found upward; written downward.

Who said it first

The founder who called numbers free creations is Richard Dedekind; the choice that each entry is the set of the entries before it is John von Neumann’s (1923). The gathering-alone successor, x to {x}, is Ernst Zermelo’s. The early algebra of logic is George Boole’s.

Dedekind opened his book on what numbers are with the demand that, in a science, nothing capable of proof should be accepted without proof; and he described numbers as free creations of the human mind rather than things found in nature. The choice of which sets to call 0, 1, 2, … is such a creation. John von Neumann made this choice early in the century before this one, and it is the one in use today: each entry of the run is the set of the entries before it.

Dedekind, Was sind und was sollen die Zahlen? (1888), preface, trans. Beman, 1901; von Neumann, “Zur Einführung der transfiniten Zahlen”, 1923

Accepted names

The sets 0, 1, 2, … built this way are the von Neumann natural numbers, or von Neumann ordinals.
