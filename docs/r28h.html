28h · proof

Double Integrals

Rung 15 measured the area under a curve by trapping it between thin boxes from below and from above. A function of two inputs stands over a patch of ground, like snow lying on a field, and the question is how much there is in total. The same trap works with columns instead of strips. This step builds the total over a rectangle, proves that every continuous function has one, and then proves something rung 15 never needed: you can add up row by row or column by column and get the same total.

A continuous function on a rectangle has exactly one total between every lower and every upper column sum. It equals the total taken in strips along y and then along x, and also in the other order.

28h1Columns From Below and Above

Let R be the rectangle a ≤ x ≤ b, c ≤ y ≤ d, and f bounded on R. Cut [a, b] at a = x₀ < … < xp = b and [c, d] at c = y₀ < … < yq = d. This cuts R into small boxes Rij of area (xi − xi−1)(yj − yj−1). On each box take mij, the inf of f there, and Mij, the sup.

\(L(f, P) = \sum_{i,j} m_{ij}\,|R_{ij}|, \qquad U(f, P) = \sum_{i,j} M_{ij}\,|R_{ij}|.\)

Every lower column sum is below every upper one: 15b’s proof runs word for word, since adding a cut only splits boxes. f is integrable on R when exactly one number A lies between every L and every U, and A is written ∬R f. With f ≥ 0, it is the volume under the graph.

Rectangle-total technique: if f is continuous on R, then f is integrable on R.

\text{for every } \varepsilon > 0 \text{ some } \delta: |x - x'| < \delta \Rightarrow |f(x) - f(x')| < \varepsilon @@ the evenly-continuous technique (15f), whose proof by halving traps (12e) runs on R with quarters
\text{boxes of width less than } \delta/2 \text{ each way} \Rightarrow M_{ij} - m_{ij} \le \varepsilon @@ two points of one box are less than δ apart; the highest-and-lowest technique (12c), carried the same way
U(f,P) - L(f,P) \le \varepsilon \textstyle\sum |R_{ij}| = \varepsilon\,|R| @@ add over the boxes
\htmlClass{new}{f \text{ is integrable on } R} \quad \blacksquare @@ the gap between some L and U is as small as we like, so at most one number fits; one does, by the no-gaps property (15c)

28h2Either Order

Hold x still and total along y: F(x) = ∫cd f(x, y) dy. That is a function of x, and its total along x is a total of totals.

Either-order technique: if f is continuous on R, then ∬R f = ∫ab (∫cd f(x, y) dy) dx = ∫cd (∫ab f(x, y) dx) dy.

F(x) = \textstyle\int_c^d f(x,y)\,dy \text{ exists for each } x @@ y ↦ f(x, y) is continuous (28a1), so integrable (15f)
|F(x) - F(x')| \le \varepsilon\,(d - c) \text{ when } |x - x'| < \delta @@ evenly continuous f (28h1), and the smaller-function-smaller-area technique (15e)
F \text{ is continuous, so } \textstyle\int_a^b F \text{ exists} @@ the line above; 15f
m_{ij}(y_j - y_{j-1}) \le \textstyle\int_{y_{j-1}}^{y_j} f(x,y)\,dy \le M_{ij}(y_j - y_{j-1}) \text{ for } x \text{ in } [x_{i-1}, x_i] @@ 15e, on one box
\textstyle\sum_j m_{ij}\Delta y_j \le F(x) \le \sum_j M_{ij}\Delta y_j \text{ there} @@ the interval-cut-in-two technique (15e), over the j’s
L(f,P) \le \textstyle\int_a^b F \le U(f,P) @@ 15e again, over the i’s
\htmlClass{new}{\textstyle\int_a^b F = \iint_R f} \quad \blacksquare @@ exactly one number lies between every L and U (28h1); the other order runs the same lines with x and y swapped

Worked once: ∬ over [0, 2] × [0, 1] of xy² is ∫₀² x (∫₀¹ y² dy) dx = ∫₀² x/3 dx = 2/3. In the other order, ∫₀¹ y² (∫₀² x dx) dy = ∫₀¹ 2y² dy = 2/3.

\iint_R f g = (\iint_R f)(\iint_R g)\,? @@ totals add, they do not multiply; only f(x)g(y) splits this way

The accepted names

The total over a rectangle is the double integral, ∬R f dA, built here from Darboux sums. A total of totals is an iterated integral. The either-order technique is Fubini’s theorem, in the form for continuous functions.

Who said it first

Euler computed double integrals as iterated integrals in 1769. Cauchy noticed in 1814 that the two orders can give different answers for badly behaved functions. Camille Jordan built the double integral on rectangles carefully in 1892. Guido Fubini proved the general theorem for Lebesgue integrals in 1907, and Leonida Tonelli the companion for positive functions in 1909.
