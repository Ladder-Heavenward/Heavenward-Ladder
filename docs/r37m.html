37m · technique

Numbering formulas by hand

Formulas as numbers is easy to say and slow to do. This step does it by hand, with the table of marks from the step on codes. A short formula gets a number with nine digits, and a short proof a number with more digits than there are atoms in the sky. Reading a code back is factoring, and it goes the same way every time: divide by two as often as it goes, then by three, and so on, and the counts are the marks. Not every number is the code of a formula, and checking which ones are is a small recipe of its own. Then a second way of numbering, older and thriftier: the diagonal listing of pairs from the rung on sizes turns two numbers into one with nothing but adding and multiplying, and it can be undone by hand too. The step ends where the numbers stop being practical, which is almost at once, and that is the point: the codes are there to be reasoned about, not written out.

Code a string by prime powers from the table of marks, and read it back by dividing out each prime in turn. A number codes a formula when its primes run in order with no gap and the string read back is a formula. Pairs go into one number by the diagonal listing, and come back out by a square root.

The table of 37g1: 0 is 1, S is 2, + is 3, · is 4, = is 5, ¬ is 6, ∧ is 7, ∨ is 8, ⇒ is 9, ∀ is 10, ∃ is 11, the brackets are 12 and 13, ⊥ is 14, and xₖ is 15 + k. The kth mark of the string becomes the power of the kth prime.

37m2Reading a code back

Code-reading technique: to read a code, divide by 2 as often as it goes, then by 3, then by 5, and on through the primes in order; the counts are the numbers of the marks, in order, and the string ends at the first prime that does not divide.

532\,445\,760 = 2^6 \cdot 8\,319\,465 @@ halve six times; 8 319 465 is odd
8\,319\,465 = 3^2 \cdot 924\,385 @@ divide by 3 twice; 9 + 2 + 4 + 3 + 8 + 5 = 31 is not a multiple of 3
924\,385 = 5 \cdot 184\,877 @@ once by 5
184\,877 = 7^5 \cdot 11 @@ five times by 7, then 11 once, then nothing is left
6, 2, 1, 5, 1 @@ the counts, prime by prime
\htmlClass{new}{\neg\ S\ 0\ =\ 0} \quad \blacksquare @@ the table, read backwards

The proof that this always works is the one-prime-list technique of 4j: the number has exactly one prime list, and the counts are its powers.

37m3Which numbers are codes

Not every number is the code of a formula. A recipe sorts them.

Code-test technique: a number is the code of a formula exactly when it is at least 2, its primes are the first k primes with none skipped, each power is the number of a mark, and the string read back is built as 37a1 builds formulas.

12 = 2^2 \cdot 3 \to S\ 0 @@ a code of a string, a term, not a formula
10 = 2 \cdot 5 @@ 3 is skipped: no string has this code
2^{12} \cdot 3^1 \cdot 5^{13} \to (\ 0\ ) @@ a string, and no formula: brackets go only around a joining word, a sum or a product
\htmlClass{new}{2430 = 2 \cdot 3^5 \cdot 5 \to 0 = 0,\ \text{a formula and a statement}} \quad \blacksquare @@ 37g1’s first code

Each test stops: factoring a number stops, the marks are checked one by one, and 37a’s one-reading technique gives a recipe that parses the string. So “x is the code of a formula” is settled, the shape of fact 37h needed.

37m4Pairs in one number

35a listed the pairs of numbers by diagonals: (0, 0); (0, 1), (1, 0) in some order; then the pairs that add to 2; and so on. Count along that listing and each pair gets one number with adding and multiplying alone.

Pair-code technique: the pair (x, y) gets the number ⟨x, y⟩ = (x + y)(x + y + 1)/2 + y, and each number is the code of exactly one pair.

\text{the pairs with } x + y < w \text{ number } 1 + 2 + \cdots + w = w(w + 1)/2 @@ 4k’s sum of the first w numbers
\text{on the diagonal } x + y = w \text{, the pair } (w - y, y) \text{ is the } y\text{th} @@ count from y = 0
\langle 3, 5 \rangle = 8 \cdot 9 / 2 + 5 = 41 @@ w = 8
41:\ \ 36 \le 41 < 45 \text{, so } w = 8,\ y = 41 - 36 = 5,\ x = 8 - 5 = 3 @@ the largest w with w(w + 1)/2 at most 41, by a square root (8f)
\htmlClass{new}{\langle x, y \rangle \text{ is a matching of the pairs with the numbers}} \quad \blacksquare @@ every number lands on one diagonal, at one place

The pair code grows like the square of the larger entry, not like a power. Lists go in by pairing again: ⟨t₀, ⟨t₁, ⟨t₂, 0⟩⟩⟩. A code made this way stays small enough to write for a while longer than a prime code does.

The basement · there if you want it

The accepted names

Prime-power coding is Gödel numbering; the pair code is Cantor’s pairing function, and nested pairs code finite sequences. The code-test technique says the set of Gödel numbers of formulas is primitive recursive.

Who said it first

Georg Cantor’s listing of pairs by diagonals is from his work on countable sets in the 1870s, and the formula for the pair code is often credited to him. Kurt Gödel used prime powers in 1931. Many textbooks now code by pairs or by strings in base 2 instead, since only the existence of a recipe matters for the argument.

A proof that is not allowed

“532 445 760 is divisible by 2 six times, so its first mark is ¬, and its code tells us ¬ comes first in every formula.” Not allowed: the code tells the first mark of this one string. The rest of the number tells the rest of the string, and another number another string.
