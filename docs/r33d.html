33d · proof

Sums Along a Wandering Path

A trader who holds H(t) shares while the price wanders by dB wins Σ H dB. Since the wandering path has no slope, this sum is not a slope-integral; it must be built anew, with each stake fixed before the move it bets on, as in 30k’s fair games. And the chain technique changes: because (dB)² adds up to dt, a function of the path gains half its second slope as drift. This step builds the sum, finds the new chain technique, and solves the statement that grows prices.

Σ H(tₖ)(B(tₖ₊₁) − B(tₖ)), with H(tₖ) fixed by the path up to tₖ, settles as the cuts shrink; the result is a fair game. f(B(t)) = f(B(0)) + ∫ f′(B) dB + ½ ∫ f″(B) dt. A price with dS = μS dt + σS dB is S(0) e^((μ − σ²/2)t + σB(t)).

33d1Stakes Fixed Before the Move

\textstyle\sum_k H(t_k)\big(B(t_{k+1}) - B(t_k)\big) @@ stake fixed at tₖ, before the move
E\big[H(t_k)\,\Delta B_k\big] = E\big[H(t_k)\big]\cdot 0 = 0 @@ the move ignores the past (33c1)
E\Big[\big(\textstyle\sum H\,\Delta B\big)^2\Big] = E \textstyle\sum H(t_k)^2\,\Delta t_k @@ cross terms average 0
\htmlClass{new}{\textstyle\int_0^t H\,dB \text{ settles; } E \int H\,dB = 0,\ \ E\big(\int H\,dB\big)^2 = E\int H^2\,dt} @@ a fair game (30k)

Wandering-sum technique: if each stake H(t) is fixed by the path up to t, the sums Σ H(tₖ)ΔBₖ settle as the cuts shrink; the result has average 0, average square E ∫ H² dt, and is a fair game in t. No system of stakes beats it, as in 30k.

33d2The Chain Technique With a Wanderer

f(B + \Delta B) - f(B) = f^{\prime}(B)\,\Delta B + \tfrac12 f^{\prime\prime}(B)\,(\Delta B)^2 + \ldots @@ the hugging polynomial (28l)
\textstyle\sum (\Delta B)^2 \to t @@ square sum (33c3)
f(B(t)) = f(B(0)) + \textstyle\int_0^t f^{\prime}(B)\,dB + \tfrac12\int_0^t f^{\prime\prime}(B)\,ds @@ the second term no longer vanishes
\htmlClass{new}{B(t)^2 = 2\textstyle\int_0^t B\,dB + t} @@ f = x²: the slope-integral would miss the t

Wandering-chain technique: for f with continuous second slope, f(B(t)) − f(B(0)) = ∫ f′(B) dB + ½ ∫ f″(B) ds; the half second slope is the drift the wandering adds. With f = x², B² − t is a fair game, as Sₙ² − n was in 30n.

33d3Growing Prices

\text{try } S = S(0)\,e^{X},\ X = at + \sigma B @@ a wandering in the exponent
dS = S\,dX + \tfrac12 S\,(dX)^2 = S\big(a\,dt + \sigma\,dB\big) + \tfrac12\sigma^2 S\,dt @@ the wandering chain, with (dB)² = dt
a + \tfrac12\sigma^2 = \mu \Rightarrow a = \mu - \tfrac12\sigma^2 @@ match the drift
\htmlClass{new}{S(t) = S(0)\,e^{(\mu - \sigma^2/2)t + \sigma B(t)}} @@ the typical price grows at μ − σ²/2, slower than μ

A price whose returns wander with spread width σ grows, typically, at μ − σ²/2: the wandering costs half its square in growth. This price is the one 33·then’s price statement was written for, and the price-to-heat technique turns it back into heat.

Accepted names

The wandering sum is the Itô integral; its average square is the Itô isometry; the wandering chain is Itô’s lemma or Itô’s formula. dS = μS dt + σS dB is a stochastic differential equation, its answer geometric Brownian motion, the model of the Black-Scholes price.

Who said it first

Kiyosi Itô built the sum in 1944 and the formula in 1951. Fischer Black, Myron Scholes and Robert Merton priced options with it in 1973; Scholes and Merton shared the 1997 Nobel Prize in Economics.
