24f · technique

Separating the variables

The proof steps of this rung promise that a tame rule with a start has one solution. They do not hand you a formula for it. This step finds formulas for a large family of rules by hand: the rules whose slope is a piece that depends only on the input times a piece that depends only on the height. Put everything about the height on one side and everything about the input on the other, take the area of each side, and the two areas must agree. The answer is checked by putting it back into the rule, and when the rule is tame that check also proves it is the only answer. One warning comes with the method. To part the two sides you divide by the height piece, and where that piece is zero you have divided by nothing. The flat solutions that live there are lost, unless you look for them on purpose.

When the slope is an input piece times a height piece, part them and take the area of each side. Check the answer by putting it back. Look on purpose for the flat solutions where the height piece is zero, because parting the sides loses them.

24f1Parting the letters

A rule parts when its slope is an input piece times a height piece: y′ = g(x)h(y). y′ = xy² parts, with g(x) = x and h(y) = y². y′ = x + y does not.

Side-by-side technique: let g be continuous on an interval holding x₀, and h continuous and never 0 on an interval K holding y₀; then a function y with values in K solves y′ = g(x)h(y), y(x₀) = y₀ exactly when ∫ from y₀ to y(x) of ds/h(s) equals ∫ from x₀ to x of g(t) dt, at every x. Write H(y) for the left area and G(x) for the right one.

H'(y) = \tfrac{1}{h(y)} \text{ on } K,\ \ G'(x) = g(x) @@ the slope of an area is the height (16b)
y' = g(x)h(y) \Rightarrow \big(H(y(x))\big)' = \tfrac{y'(x)}{h(y(x))} = g(x) = G'(x) @@ the chain rule (13e); h(y(x)) ≠ 0, since y stays in K
H(y(x)) - G(x) \text{ is constant, and } 0 \text{ at } x_0 @@ same slopes (14e); H(y₀) = 0 = G(x₀)
H(y(x)) = G(x) \Rightarrow \tfrac{y'(x)}{h(y(x))} = g(x) \Rightarrow y' = g(x)h(y) @@ back again: slopes of both sides; 1/h never 0, so H has an undoing with a slope (13e)
\htmlClass{new}{y' = g(x)h(y),\ y(x_0) = y_0 \iff H(y(x)) = G(x)} \quad \blacksquare @@ both ways
  
h(y) = y^2 \ne 0 \text{ on } K = (0, \infty),\ \ y_0 = 1 \in K @@ the technique applies
\int_1^{y} \tfrac{ds}{s^2} = 1 - \tfrac1y,\ \ \int_0^x t\,dt = \tfrac{x^2}{2} @@ evaluating by antiderivatives (16c)
1 - \tfrac1y = \tfrac{x^2}{2} \Rightarrow y = \tfrac{2}{2 - x^2} @@ the side-by-side technique; solve for y
\htmlClass{new}{y = \tfrac{2}{2 - x^2} \text{ on } -\sqrt2 < x < \sqrt2} \quad \blacksquare @@ the interval holding 0 where y stays in K

The hand shorthand is dy/h(y) = g(x) dx, then an area sign on each side. It works because dy/dx behaves as one mark through the chain rule (13e); the technique above is what licenses it. The solution runs off at ±√2, as 24e's y′ = y² did at 1: parting the letters can find a run-off that the existence technique could only warn of.

24f2Put it back

A formula found by hand can carry a slip. The cure is the definition of a solution itself.

Put-back technique: if a formula y has a slope at every x of an interval I holding x₀, makes y′ = F(x, y) true at every x of I, and has y(x₀) = y₀, it is a solution on I; and if F is tame on every rectangle, every solution with the same start agrees with it wherever both live.

y \text{ is a solution on } I \text{ with the start } (x_0, y_0) @@ ︿ “solution”, “start” (24a1, 24a2)
z \text{ another solution, } x_1 \text{ in both intervals} @@ any other solution, from the same start
y, z \text{ are bounded on the stretch from } x_0 \text{ to } x_1 @@ continuous on a closed interval (12b): both stay in one rectangle
|y(x) - z(x)| \le 0 \cdot e^{L|x - x_0|} = 0 @@ the drift technique (24d3) on that rectangle, with equal starts
\htmlClass{new}{z = y \text{ wherever both live}} \quad \blacksquare @@ every x₁ in both intervals
  
y' = \tfrac{4x}{(2 - x^2)^2},\ \ xy^2 = x \cdot \tfrac{4}{(2 - x^2)^2} @@ the chain rule; the rule's right side
y' = xy^2 \text{ at every } x \text{ in } (-\sqrt2, \sqrt2),\ \ y(0) = 1 @@ the rule and the start hold
|xy^2 - xz^2| = |x|\,|y + z|\,|y - z| \le 2pB\,|y - z| \text{ when } |x| \le p,\ |y|, |z| \le B @@ tame on every rectangle, with L = 2pB
\htmlClass{new}{y = \tfrac{2}{2 - x^2} \text{ is the one solution from } (0, 1)} \quad \blacksquare @@ the put-back technique

For a rule that parts, tameness is easy to test: if g is continuous and h has a continuous slope, then on a rectangle |g| has a ceiling and so does |h′| (12b), and the mean value technique (14c) gives an L. Putting back takes a minute and catches every slip of sign and every lost constant.

24f3The solutions a separation loses

The side-by-side technique asks for h(y) ≠ 0. Where h(c) = 0, the flat line y = c has slope 0, and so does g(x)h(c). So the flat line solves the rule, and the technique, having divided by h(y), never meets it.

Resting-line technique: if h(c) = 0, the flat line y = c solves y′ = g(x)h(y); and if the rule is tame on every rectangle, no solution that starts off the line c ever touches it. So a solution from a start between two neighbouring zeros of h stays strictly between them, and there the division was honest.

y = c \Rightarrow y' = 0 = g(x)h(c) @@ flat; h(c) = 0: the line is a solution
y(x_1) = c \text{ for some } x_1 @@ suppose a solution touches the line
y \text{ and the line } c \text{ share the start } (x_1, c) @@ both are solutions through it
y = c \text{ wherever } y \text{ lives, so } y(x_0) = c @@ the put-back technique (24f2), from (x₁, c)
\htmlClass{new}{y(x_0) \ne c \Rightarrow y(x) \ne c \text{ at every } x} \quad \blacksquare @@ turned about; with in-between values (12a), y stays on one side
  
h(y) = 1 - y^2 = 0 \text{ at } y = \pm1 @@ two resting lines, lost by parting
-1 < y(x) < 1 \text{ at every } x @@ the resting-line technique: the start 0 lies between them, and 1 − y² is tame
\int_0^y \tfrac{ds}{1 - s^2} = \tfrac12 \ln\tfrac{1+y}{1-y} = x @@ split into straight factors (17k); the side-by-side technique
\htmlClass{new}{y = \tfrac{e^{2x} - 1}{e^{2x} + 1} \text{ on the whole line}} \quad \blacksquare @@ solve for y; it heads to 1 and never reaches it

Written with a constant, the family is y = (Ae^(2x) − 1)/(Ae^(2x) + 1) with A > 0. A = 0 gives the line −1 back, by luck. No A gives the line 1. Which flat lines a formula happens to hold depends on how its constant was written, so never trust the formula to hold them: find the zeros of h and list their lines separately.

Without tameness the second half fails. 24e1's y′ = √|y| has h(0) = 0, and its solutions rest on the line 0 and leave it whenever they like. There the side-by-side technique finds each growing piece, and the flat piece, but not where one hands over to the other.

The basement · there if you want it

The accepted names

Parting the letters is separation of variables, and a rule that parts is a separable equation. The put-back technique is checking by substitution, with uniqueness from the Picard–Lindelöf theorem. A resting line is an equilibrium (or constant, or stationary) solution. The draining rule is Torricelli's law. The rule in the converse standing question is the standard example that a rule need not be Lipschitz for its solutions to stay apart; the sharp test, that the area of 1/h must pass every ceiling as y heads to c, is Osgood's condition.

Who said it first

Gottfried Leibniz found the method in 1691, in a letter to Christiaan Huygens. Johann Bernoulli gave it the name "separation of the indeterminates" in 1694. William Osgood proved his condition in 1898.
