41b · proof

Other Machines, the Same Reach

In the same year that the tape machine was described, two other answers to the question of what a recipe is were already on the table. One started from rung four’s recursion. Take a few functions too simple to doubt, and allow three ways of making new functions from old: putting one inside another, recursion, and a search for the first number that works. The other threw numbers away altogether. It has one kind of thing, a function, and one move, feeding a function its input, and it builds the numbers themselves out of functions that repeat. The three look nothing alike. A tape has cells, a recursion has equations, a calculus of functions has only brackets. This step proves that they reach exactly the same functions. That is the second kind of evidence for the thesis. It also pays something held in trust since the rung before: every recipe that always stops can be written as a formula of arithmetic, so 38h’s formula for “this number codes a proof” is now built, not assumed.

Functions built from zero, next and picking, by putting inside, recursion and search, are exactly the functions tape machines compute, and one search is always enough. Their graphs are search formulas, which closes 38h’s flag. A calculus with one move, feeding a function its input, reaches the same functions.

41b1Functions Built From a Few

The start functions are zero, Z(x) = 0, next, S(x) = x + 1, and the picks, Pᵢ(x₁, …, xₖ) = xᵢ. Three ways make new functions from old. Putting inside: h(x) = f(g₁(x), …, gₘ(x)). Recursion, 4d’s technique with a parameter: h(x, 0) = f(x) and h(x, y + 1) = g(x, y, h(x, y)). Search: h(x) is the least y with f(x, y) = 0, when there is one and f(x, z) has a value for each z below it; otherwise h(x) has no value.

A function made from the start functions by these three ways is built. Made without search it is built without search, and it has a value at every input, by induction on the building. With search it may have none: the least y with y + x + 1 = 0 never comes. One example first: adding is built without search, add(x, 0) = P₁(x) and add(x, y + 1) = S(add(x, y)), which is 4f’s adding line by line.

Built-runs technique: every built function is computed by a tape machine.

41b2Every Machine Is Built, With One Search

Now the other way. Code a configuration u q v as one number: the tape as a numeral in base |Γ|, and the state and the head’s place beside it, packed by 38m’s pair code. Call the code of the start configuration on input x start(e, x), where e codes the table. This e is not 17e's number e.

One-search technique: for every tape machine with code e there are functions next, start and out, built without search, such that the machine’s output on x is out(run(e, x, y)), where y is the least number of steps after which the state is a stop state.

So the tape machine and the built functions reach the same functions, by the built-runs and one-search techniques together. And something more: however many searches a built function used, one search is enough, with everything else built without search. The searches of a big building are folded into the one search for the moment the machine stops.

41b338h’s Flag, Closed

38h1 held in trust that “y is the code of a proof of the statement with code x” is a formula of arithmetic of the right shape, and 38h2 the same for Sub. Both are recipes that always stop. The one-search technique turns every such recipe into arithmetic.

41b4A Calculus of Functions

The third answer has only functions. Its terms are placeholders x, y, …; λx.M, the function that sends x to M; and (M N), M fed N. Its one move is feeding: (λx.M) N may be rewritten as M with N put in for x, renaming bound placeholders so that none is caught. A term no feeding move applies to is finished. Numbers are not given. They are built: the numeral of n is the term that does a function n times, n̄ = λf.λx. f(f(⋯ f(x))), with n copies of f.

Numeral-iterator technique: the term λn.λf.λx. f(n f x) turns the numeral of n into the numeral of n + 1, by feeding alone.

\bar 1 = \lambda g.\lambda y.\, g\,y @@ do g once
(\lambda n.\lambda f.\lambda x.\, f(n\,f\,x))\ \bar 1 \to \lambda f.\lambda x.\, f(\bar 1\,f\,x) @@ feed: put 1̄ in for n
\bar 1\,f\,x = (\lambda g.\lambda y.\, g\,y)\,f\,x \to (\lambda y.\, f\,y)\,x \to f\,x @@ feed twice
\htmlClass{new}{\lambda f.\lambda x.\, f(f\,x) = \bar 2} \quad \blacksquare @@ do f twice

Adding is λm.λn.λf.λx. m f (n f x): do f n times, then m times more. Recursion and search are harder. They need a term that feeds itself to itself, as 38h’s diagonal fed a formula its own code; 41b.6.2 asks for one.

Equal-reach technique: a function on numbers is reached by feeding exactly when a tape machine computes it. One way: each start function and each of the three ways of 41b1 has a term, so every built function does. The other way: a term is a string, a feeding move is a rewrite of a string, and a machine can apply the leftmost move again and again, stopping at a finished term. That the leftmost order finds the finished term whenever any order does is held in trust here; the cellar names it.

The cellar · there if you want it

The accepted names

The start functions are the initial functions (zero, successor, projections); putting inside is composition; the search is minimization, the μ-operator. Functions built without search are the primitive recursive functions, and built functions are the partial recursive, or μ-recursive, functions. The one-search technique is Kleene’s normal form theorem, with Kleene’s T predicate. The search-graph technique is the representability of recursive functions in PA, through Σ₁ definitions. The calculus of functions is the λ-calculus; feeding is β-reduction, renaming is α-conversion, a finished term is in normal form, and the numerals are Church numerals. That the leftmost order reaches the normal form whenever one exists is the standardization theorem (Curry and Feys, 1958). Y is the fixed-point combinator. The function d of 41b.6.3, made concrete, is close to the Ackermann function, total and computable but not primitive recursive.

Who said it first

Thoralf Skolem (1923) built arithmetic from recursion; Kurt Gödel used the primitive recursive functions in 1931 and, after a suggestion of Jacques Herbrand, defined general recursive functions in 1934. Stephen Kleene added the μ-operator and proved the normal form theorem in 1936. Alonzo Church published the λ-calculus in 1936, and Kleene showed that the λ-definable functions are the recursive ones. Alan Turing showed in 1937 that λ-definable and machine-computable are the same. Wilhelm Ackermann gave his function in 1928.

A proof that is not allowed

“Every built function has a value at every input, since each of the three ways makes a function from functions.” Not allowed: it is true of putting inside and of recursion, by induction on the building, and false for search. The least y with y + x + 1 = 0 has no value anywhere.
