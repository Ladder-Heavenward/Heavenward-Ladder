41b · proof

Trees

A graph in one piece with no cycle is the thriftiest way to join a set of dots: take away any link and it falls in two, add any link and a cycle appears. These graphs are called trees, and they are everywhere the ladder has already been: the proofs of rung 38 were drawn as trees, the chances of rung 30 branched as trees, and a family is drawn as one. This step proves that a tree on n dots always has exactly one link fewer than it has dots, that any two of three plain conditions force the third, and that every graph in one piece holds a tree that reaches all its dots. Then it counts the trees on n named dots. The answer is n multiplied by itself n − 2 times, a count so clean that it was guessed from small cases long before it was proved. The proof here codes each tree as a list of n − 2 numbers, and decodes it back.

A tree is in one piece with no cycle. It has at least two ends, and exactly one link fewer than dots. Any two of in one piece, no cycle, and one link fewer than dots give the third. Every graph in one piece holds a tree through all its dots. The trees on n named dots match the lists of n − 2 names, so there are n to the n − 2.

41b1Ends and Links

A tree is a graph in one piece with no cycle. An end of a graph is a dot with exactly one link.

Tree-ends technique: a tree with at least two dots has at least two ends. Take a path of greatest length, v₀, …, vₖ. A neighbour of v₀ other than v₁ would lie on the path, closing a cycle, or off it, making a longer path. So v₀ is an end, and so is vₖ.

Links-of-a-tree technique: a tree with n dots has n − 1 links.

n = 1:\ 0 \text{ links} @@ one dot, and a link needs two
T \text{ a tree with } n + 1 \ge 2 \text{ dots; } v \text{ an end of it} @@ the tree-ends technique
T - v \text{ is in one piece and has no cycle} @@ a path through v would need two links at v; taking a dot away makes no cycle
T - v \text{ has } n - 1 \text{ links} @@ induction on n (4c)
\htmlClass{new}{T \text{ has } (n - 1) + 1 = n \text{ links}} \quad \blacksquare @@ v took one link with it

A tree with n dots and links counts d(v) has Σ d(v) = 2n − 2, by the ends-count technique. So the average count is below 2, which is the tree-ends technique again, from the other side.

41b2Any Two of Three

Any-two-of-three technique: for a graph with n dots, any two of these give the third: it is in one piece; it has no cycle; it has n − 1 links.

\text{one piece and no cycle} \Rightarrow n - 1 \text{ links} @@ the links-of-a-tree technique
\text{no cycle, } c \text{ pieces} \Rightarrow \text{each piece a tree, } n - c \text{ links in all} @@ links-of-a-tree in each piece; the dots add up to n
\text{no cycle and } n - 1 \text{ links} \Rightarrow c = 1 @@ n − c = n − 1
\text{one piece, } n - 1 \text{ links, a cycle} \Rightarrow \text{drop a link of the cycle; still one piece} @@ a walk that used the link goes round the rest of the cycle
\text{drop links of cycles until none is left: a tree with fewer than } n - 1 \text{ links} @@ each drop keeps one piece
\htmlClass{new}{\bot:\ \text{one piece and } n - 1 \text{ links} \Rightarrow \text{no cycle}} \quad \blacksquare @@ against the links-of-a-tree technique

One more way to say tree: a graph is a tree exactly when each two of its dots are joined by exactly one path. Two paths from u to w that part and meet again close a cycle; and a cycle gives two paths between any two of its dots. So a tree is the graph where the walk-to-path technique of 41a has only one answer.

41b3A Tree Inside Every Graph

A spanning tree of a graph G is a tree whose dots are all the dots of G and whose links are links of G.

Spanning-tree technique: every graph in one piece has a spanning tree.

H := G @@ the state of a recipe (4l): a graph in one piece on the dots of G
\text{while } H \text{ has a cycle, drop one link of it} @@ the move; H stays in one piece (41b2)
\text{the number of links falls at every move} @@ so every run stops (the falling-measure technique, 4l)
\htmlClass{new}{\text{at the stop } H \text{ is in one piece with no cycle: a spanning tree}} \quad \blacksquare @@ the stop test

Which links to drop is free, and the trees that come out differ. When links have costs, a cheapest spanning tree is a question with an answer, and a greedy recipe finds it. 41k asks why greed is safe there and not elsewhere.

41b4Counting the Trees

On the dots {1, 2, …, n}, with n ≥ 2, the leaf code of a tree is a list of n − 2 numbers made this way: take away the end with the smallest name, write down the name of its one neighbour, and repeat until two dots are left.

\text{links } \{1,4\}, \{2,4\}, \{3,4\}, \{4,5\}, \{5,6\} @@ a tree on six dots
\text{ends } 1, 2, 3, 6;\ \text{take } 1,\ \text{write } 4 @@ the smallest end
\text{take } 2,\ \text{write } 4;\ \ \text{take } 3,\ \text{write } 4 @@ again
\text{now } 4 \text{ is an end; ends } 4, 6;\ \text{take } 4,\ \text{write } 5 @@ two dots, 5 and 6, are left
\htmlClass{new}{\text{leaf code } (4, 4, 4, 5)} \quad \blacksquare @@ n − 2 = 4 numbers

Leaf-code technique: the leaf code is a matching between the trees on n named dots and the lists of n − 2 names; so there are nⁿ⁻² such trees. A dot appears in the code one time fewer than its count of links, since it is written once for each neighbour taken away before it, and ends never appear. So from the code alone the first end taken is known: the smallest name not in the code. Join it to the code’s first entry, strike both, and go on; the last two dots left are joined. That rebuilds the tree, and only that tree, from the code, and every list rebuilds some tree. A matching (9c) between the trees and the nⁿ⁻² lists of 4k’s counted-functions technique.

For n = 4 that gives 16 trees: 12 paths, the 4!/2 ways to put four names along a line, and 4 stars, one for each choice of the centre. n = 2, 3, 4, 5 give 1, 3, 16, 125.

The accepted names

Ends are leaves. A graph with no cycle is a forest. The tree-ends technique and the any-two-of-three technique are the basic characterizations of trees; the count nⁿ⁻² is Cayley's formula, and the leaf code is the Prüfer code.

Who said it first

Gustav Kirchhoff used spanning trees in 1847 to solve electrical networks. Arthur Cayley counted trees in 1857 for the calculus and in 1874 for chemistry, and stated nⁿ⁻² in 1889; Carl Wilhelm Borchardt had a determinant formula equivalent to it in 1860. Heinz Prüfer gave the code in 1918.

A proof that is not allowed

“A tree has n − 1 links: start with one dot and add the others one at a time, each with one link to what is there.” Not allowed as it stands: it shows that the trees built that way have n − 1 links, but not that every tree can be built that way. The missing step is the tree-ends technique, which takes a tree apart in the reverse order.
