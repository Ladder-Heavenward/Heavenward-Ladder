33i · technique

Solving on a Grid by Hand

Most rods are not uniform, most plates are not rectangles, and most starts have no tidy series. Then the rule is solved on a grid. Lay marks along the rod a fixed gap apart, and tick the clock in fixed steps. At each mark, replace the second slope by what three neighbouring heights say about it, and step forward: the new temperature is the old one plus a little of what the neighbours say. It is arithmetic, and a hand can do the first few steps. The danger is in the size of the clock’s tick. Too long a tick and the arithmetic does something no rod could do: a wobble from mark to mark, too small to see, doubles and triples at every step until the numbers fill the page. The step finds the exact tick at which that starts, for heat and for a string, and the reason for each. The string’s condition was found first, in the paper that named the problem, and it says something plain: the grid must be able to hear everything the string can.

Three neighbouring heights give the second slope with an error that shrinks like the square of the gap. Stepping heat forward is safe exactly when the new value is an average of old ones, which needs the tick to be at most half the gap squared over κ. A string’s grid must reach at least as far each tick as the wave does, and a still plate on a grid is the average of its four neighbours.

33i1The Second Slope From Three Heights

Lay marks a gap h apart. What do three heights y(x − h), y(x), y(x + h) say about y″(x)?

33i2Stepping Heat, and the Tick That Breaks It

Put marks x_j = jh along a rod and ticks t_n = nk. Write U_j^n for the grid’s temperature at mark j and tick n. Replace u_t by (U_j^(n+1) − U_j^n)/k, as 24i stepped forward, and u_xx by the three-point quotient. With r = κk/h²:

\(U_j^{n+1} = rU_{j-1}^n + (1 - 2r)\,U_j^n + rU_{j+1}^n.\)

Grid-average technique: if r ≤ ½, each new value is an average of three old ones, so the grid’s greatest value never grows and its least never falls. Zigzag technique: if r > ½, the start U_j = (−1)ʲε is multiplied by 1 − 4r at every tick, and since |1 − 4r| > 1 it passes every bound, however small ε is.

r \le \tfrac12 \Rightarrow r \ge 0,\ 1 - 2r \ge 0,\ r + (1 - 2r) + r = 1 @@ three weights, none below 0, adding to 1
\htmlClass{new}{\min U^n \le U_j^{n+1} \le \max U^n} @@ an average lies between its least and greatest part: 33b1’s technique, on the grid
U_j^n = (-1)^j\varepsilon \Rightarrow U_j^{n+1} = \big(r(-1) + (1 - 2r) + r(-1)\big)(-1)^j\varepsilon @@ both neighbours have the other sign
U_j^{n+1} = (1 - 4r)\,U_j^n @@ the zigzag keeps its shape and changes size
\htmlClass{new}{r > \tfrac12 \Rightarrow |1 - 4r| > 1 \Rightarrow |U^n| = |1 - 4r|^n\varepsilon \to \infty} \quad \blacksquare @@ powers of a number past 1 pass every bound
  
U^0 = (0,\ 0,\ 0,\ 100,\ 0,\ 0,\ 0) @@ a hot mark in the middle, ends at 0
r = \tfrac12:\ \ U^1 = (0, 0, 50, 0, 50, 0, 0),\ \ U^2 = (0, 25, 0, 50, 0, 25, 0) @@ each value is the average of its two neighbours
r = 1:\ \ U^1 = (0, 0, 100, -100, 100, 0, 0) @@ the middle mark falls 100 below freezing
\htmlClass{new}{r = 1:\ \ U^2 = (0, 100, -200, 300, -200, 100, 0)} \quad \blacksquare @@ a zigzag; its middle triples in size from the first tick to the second

For a copper rod with marks a centimetre apart, the tick must be at most h²/(2κ) = 0.0001/(2 × 0.000116) ≈ 0.43 seconds. Halve the gap and the tick must quarter. Fine grids for heat are slow, which is 24i’s stiffness again: the zigzag is the fastest-fading shape of the rod, and it sets the tick for all of them.

33i3A String on a Grid Must Hear the Wave

Do the same for the string. Replace y_tt by the three-point quotient in time too. With σ = ck/h,

\(Y_j^{n+1} = 2Y_j^n - Y_j^{n-1} + \sigma^2\big(Y_{j+1}^n - 2Y_j^n + Y_{j-1}^n\big).\)

Grid-reach technique: if σ > 1, the grid’s answers cannot head to the string’s answer for every start, however fine the grid; and the zigzag grows.

Y_j^n \text{ uses only the start at marks } j - n, \ldots, j + n @@ each tick reaches one mark further each way
\text{the grid at } (x, t) \text{ uses the start within } \tfrac{t}{k}h = \tfrac{ct}{\sigma} \text{ of } x @@ n = t/k ticks, each reaching h
\text{the string at } (x, t) \text{ uses the start within } ct \text{ of } x @@ the two-waves technique (33c2)
\sigma > 1:\ \text{change the start only where } \tfrac{ct}{\sigma} < |s - x| < ct @@ the string’s answer at (x, t) changes; the grid’s does not
\htmlClass{new}{\text{the grid cannot follow both starts}} \quad \blacksquare @@ a list that heads to one value cannot head to two

The zigzag tells the same story in numbers. Put Y_j^n = gⁿ(−1)ʲ into the step. Then g + 1/g = 2 − 4σ². When σ ≤ 1 the right side lies in [−2, 2], and g turns without growing. When σ > 1 it is below −2, and one root g is below −1: the zigzag grows. So the condition is σ = ck/h ≤ 1. In one tick the wave travels ck, and the grid’s news travels h. The grid must hear everything the string can.

33i4A Still Plate on a Grid

Put marks on a plate a gap h apart both ways. The three-point quotient in x plus the one in y makes Δu ≈ 0 into one line: the grid value at each inside mark is the average of its four neighbours. This is the circle-average technique on the smallest circle the grid has.

Four-neighbour technique: the grid still state on a plate takes its greatest and least values on the edge, and is fixed by the edge. An inside mark at the grid’s greatest value is the average of four values none greater, so all four equal it; walking outward from there, mark by mark, the greatest value reaches an edge mark.

h = \tfrac13:\ \ \text{inside marks } (\tfrac13, \tfrac23),\ (\tfrac23, \tfrac23),\ (\tfrac13, \tfrac13),\ (\tfrac23, \tfrac13) @@ the top edge at 100, the others at 0
\text{top marks } P,\ \text{bottom marks } Q @@ the plate is the same flipped left to right, and so is the edge
4P = 100 + P + Q + 0,\ \ 4Q = P + Q + 0 + 0 @@ each is the average of its four neighbours
Q = \tfrac{P}{3},\ \ \tfrac83P = 100 @@ from the second line, then the first
\htmlClass{new}{P = 37.5,\ \ Q = 12.5} \quad \blacksquare @@ the warm-edge series gives 38.07 and 11.93
Anexact, yet rigorous · the cloud, on a grid

21a gave every value that uses π a width, because no decimal holds π. A grid answer has a width too, set by its gap. The second-quotient technique says the error in each quotient is about h² times a fourth slope. For the plate at h = 1/3, the grid is off by 0.57 at the marks. Halve the gap and the error falls to about a quarter.

A grid answer is a dot inside a width, and the width is found by halving the gap.

So a grid answer is reported with its width, and the width is found by running the grid twice. Two runs at h and h/2 that agree to the first figure say the first figure is earned. Two runs that do not agree say the grid is too coarse, however many figures it prints.

A forecast of the soil’s temperature at the Puyallup research farm is run on a grid with marks every 5 cm and again with marks every 2.5 cm. The two forecasts for 30 cm down differ by 0.8 °C. How wide a width would you report, and which run would you print?

The accepted names

The three-point quotient is the central second difference, and the method is finite differences. The heat step is the explicit (forward Euler, FTCS) scheme, r is the mesh ratio, and r ≤ ½ is its stability condition; testing with zigzags and other waves on the grid is von Neumann stability analysis. σ = ck/h is the Courant number, and σ ≤ 1 is the Courant–Friedrichs–Lewy (CFL) condition. The four-neighbour average is the five-point Laplacian. Halving the gap to find the width is a convergence study; using the two runs to cancel the h² error is Richardson extrapolation.

Who said it first

Lewis Fry Richardson solved Laplace’s equation on a grid by hand in 1910, and in 1922 forecast the weather over central Europe by hand, with a grid and a clock, getting a pressure change a hundred times too large. Richard Courant, Kurt Friedrichs and Hans Lewy proved in 1928 that the grid must reach as far as the wave, in a paper meant for proofs, not computers. John von Neumann tested stability with waves on the grid at Los Alamos in the 1940s, and Phyllis Nicolson and John Crank built a heat step with no tick limit in 1947.
