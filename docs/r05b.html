5b · proof

Integers as pairs

The counting numbers cannot take away more than they have: no number added to 3 gives 0. This step proves that, then packs the missing answer into a name. It is the first time the ladder meets a question its numbers cannot answer, and the first time it builds new numbers to answer one. An integer is one of 2g’s classes: pairs of numbers, sorted by a sameness built from 4f’s adding alone. Adding and multiplying are 4f’s and 4g’s lines, run on a member of each class, with a proof that the member chosen does not matter. Then the counting numbers sit inside, every integer gets a negative, rung 4’s techniques carry over, and every subtraction has an answer.

Write the missing amount as a pair, the amount to be reached first and the starting amount second. Count two pairs as one when the first of each added to the second of the other gives the same number. Work on any member of a class, and check that the class of the answer stays put.

Now the gap this rung is about. Counting numbers cannot take away more than they have.

Rung 4 can add any two numbers. Running adding backwards is another matter. Ask for a number x with 3 + x = 0. Since 3 names S(2), the next-on-the-left technique for plus turns 3 + x into S(2 + x), a next one, and 3b's next-never-empty technique says a next one is never 0. The same argument works for any number other than 0. Call it the gap-in-ℕ technique: for every number k other than 0, no number x has k + x = 0.

\text{let } a \in \mathbb N,\ \ a \ne 0;\ \ \text{assume } \exists x \in \mathbb N\,(a + x = 0) @@ aiming to refute
\text{call such a number } x:\ \ a + x = 0 @@ use the some
a = S(m) \text{ for a number } m @@ the zero-or-a-next technique; a ≠ 0, so the other option (the remaining-option technique); use the some
\htmlClass{new}{S(m)} + x = 0 @@ the swap axiom
\htmlClass{new}{S(m + x)} = 0 @@ the next-on-the-left technique for plus, with the chain technique
S(m + x) \ne 0 @@ the next-never-empty technique
\bot @@ clash
\neg\exists x \in \mathbb N\,(a + x = 0) \quad \blacksquare @@ close the somes; refute

More generally, 4h's at-most-is-adding technique says that b + x = k has an answer exactly when b ≤ k, and 4f's cancel for plus says there is then only one. So “what must be added to 3 to make 5?” has the answer 2. And “what must be added to 5 to make 3?” has none. An answer x would make 5 ≤ 3 by at-most-is-adding, and any-two-compare forbids that alongside 3 < 5. Taking away works in ℕ only when there is enough to take.

5b2Naming the answer by the question

Stands on 5b1 and 2g (pairs, the product ℕ × ℕ).

Here is the move this whole rung makes, twice. If the answer is missing, let the question stand in for it. The pair (5, 3) will stand for “what must be added to 3 to make 5”, and the pair (3, 5) for “what must be added to 5 to make 3”. Read the pair (k, b) as “k less b”: the amount to reach first, the starting amount second. Pairs of numbers exist (2g's product ℕ × ℕ), so every question of this kind is now an object.

But many pairs ask for the same amount. (3, 5), (0, 2) and (10, 12) each ask for whatever must be added to a number to land 2 short of it. They must make one new number, not three. When do two pairs ask for the same amount? Saying “k less b is c less d” seems to need the taking-away that is missing. The way round is to see what the sameness says when both amounts do exist.

b + e = a,\ \ \ d + e = c @@ suppose the one number e answers both questions
a + d = (b + e) + d @@ the swap axiom, with the first sameness
\phantom{a + d} = b + (e + d) @@ the regroup technique for plus
\phantom{a + d} = b + (\htmlClass{new}{d + e}) @@ the turn-about technique for plus, inside
\phantom{a + d} = \htmlClass{new}{b + c} @@ the swap axiom, with the second sameness

The last line mentions only adding. It makes sense for every two pairs, whether or not the amounts exist, so it can be the definition. (And it is the right one. Where both amounts do exist, k + d = b + c forces them to be the same, by cancel for plus. A question below asks for the column.)

5b3The cross-sum

Stands on 5b2 and 2g (relations).

The column in 5b2 used only adding. Two pairs ask the same question when the first of each added to the second of the other gives one number.

From here on, for pairs of numbers (a, b) and (c, d), the first line means the second:

Read it “(a, b) is equivalent to (c, d)”. It is the relation on ℕ × ℕ that goes with this statement: the sift of (ℕ × ℕ) × (ℕ × ℕ) by it (2g's word relation).

Read it as a cross-sum: the first of each pair added to the second of the other. (3, 5) ∼ (0, 2), since 3 + 2 = 5 + 0. (3, 5) and (2, 0) are not equivalent, since 3 + 0 is 3 and 5 + 2 is 7, and 3 ≠ 7. 2g kept the mark ∼ for a sameness relation, and the next technique earns it.

5b4Swapping the middle

Stands on 4f (regroup and turn-about for plus) and 4g (the same for times).

Proofs on this rung keep rearranging four things added in two pairs. One technique does it once and for all. Middle-swap technique: (x + y) + (u + w) = (x + u) + (y + w). The two middle terms trade places.

(x + y) + (u + w) = x + (y + (u + w)) @@ the regroup technique for plus
\phantom{(x + y) + (u + w)} = x + ((y + u) + w) @@ the regroup technique for plus inside, turned about
\phantom{(x + y) + (u + w)} = x + ((\htmlClass{new}{u + y}) + w) @@ the turn-about technique for plus, inside
\phantom{(x + y) + (u + w)} = x + (u + (y + w)) @@ the regroup technique for plus, inside
\phantom{(x + y) + (u + w)} = (x + u) + (y + w) \quad \blacksquare @@ the regroup technique for plus, turned about

The column uses only regroup for plus and turn-about for plus. So the same column runs wherever those two techniques are in hand. Put regroup for times and turn-about for times in place of regroup for plus and turn-about for plus, and the same column proves this. It is cited as middle-swap (for ·).

5b6An equivalence

Stands on 5b3, 5b4, 4f (cancel for plus) and 2g (sameness relations).

Now the same-difference technique: the relation ∼ on ℕ × ℕ is reflexive, symmetric and transitive. Reflexive: k + b = b + k is turn-about for plus, so (k, b) ∼ (k, b). Symmetric: from k + d = b + c, the turn-about technique gives b + c = k + d. Turn-about for plus on each side then gives c + b = d + k, which is (c, d) ∼ (k, b). Transitive is the one that needs work, and it is where rung 4's cancelling comes in.

a + d = b + c,\ \ \ c + f = d + e @@ given (a, b) ∼ (c, d) and (c, d) ∼ (e, f); ﹀ ∼
(a + d) + (c + f) = (b + c) + (d + e) @@ the swap axiom: the same thing added to each side, then each side swapped by a given line
(a + d) + (\htmlClass{new}{f + c}) = (b + c) + (\htmlClass{new}{e + d}) @@ the turn-about technique for plus, inside, on each side
(\htmlClass{new}{a + f}) + (d + c) = (\htmlClass{new}{b + e}) + (c + d) @@ the middle-swap technique, on each side
(a + f) + (\htmlClass{new}{c + d}) = (b + e) + \htmlClass{keep}{(c + d)} @@ the turn-about technique for plus, inside, on the left
\htmlClass{new}{a + f = b + e} @@ the cancel technique for plus: c + d is taken off both sides
(a, b) \sim (e, f) \quad \blacksquare @@ ︿ ∼

So ∼ is a sameness relation, and all of 2g applies: the classes, and the classes-never-overlap technique, that two classes sharing a member are one class.

5b7The integers

Stands on 5b6 and 2g (classes, the classes-never-overlap technique).

Now the classes. An integer is a whole class of pairs that ask the same question.

From here on, is short for , 2g's class of the pair (a, b): the set of pairs (c, d) in ℕ × ℕ with (c, d) ∼ (a, b).

Same-class technique: [k, b] = [c, d] exactly when k + d = b + c.

(a, b) \in [a, b] @@ ∼ is reflexive (same-difference); ︿ the class
\text{assume } (a, b) \sim (c, d):\ \ (a, b) \in [c, d] @@ ︿ the class
\qquad [a, b] = [c, d] @@ the classes-never-overlap technique: the two classes share the member (a, b)
\text{assume } [a, b] = [c, d]:\ \ (a, b) \in [c, d] @@ the swap axiom, with the first line
\qquad (a, b) \sim (c, d) @@ ﹀ the class
[a, b] = [c, d] \;\Leftrightarrow\; \htmlClass{new}{a + d = b + c} \quad \blacksquare @@ prove an if each way; ︿ ⇔; ﹀ ∼

From here on, names the set of all the classes of ∼:

Its members are the integers. Read it “Z”, or “the integers”; the letter is for the German Zahlen, numbers.

It is a set: each class is a part of ℕ × ℕ, so a member of 𝒫(ℕ × ℕ) (2f), and ℤ is sifted from that. Every integer is [k, b] for some pair, and a pair in it is a member of the integer, or, in 2g's word, a representative. [3, 5], [0, 2] and [10, 12] are one integer, by same-class. A pair is never itself an integer: an integer is the whole class.

An older way of building the integers defined “plus m” as the relation that n + m bears to n, for every number n. It defined “minus m” as the relation that n bears to n + m. A relation is a statement that names a set of pairs. So its “plus 2” is exactly the class of (2, 0) in this step: the pairs (2, 0), (3, 1), (4, 2) and so on.

5b8Adding classes

Stands on 5b7 and 5b4 (middle-swap).

To add two integers, add a member of each, entry by entry, and check the class of the answer does not depend on the members.

Where the amounts exist, adding them is easy to read off. Suppose b + e = k and d + e′ = c. Then (b + d) + (e + e′) = (b + e) + (d + e′) = k + c, by middle-swap. So the sum of the two missing amounts is what must be added to b + d to make k + c. So the sum of the pairs (k, b) and (c, d) should be (k + c, b + d). Before that can be a definition on classes, it must not matter which members were used. Honest-adding technique on ℤ: if (k, b) ∼ (k′, b′) and (c, d) ∼ (c′, d′), then (k + c, b + d) ∼ (k′ + c′, b′ + d′).

a + b' = b + a',\ \ \ c + d' = d + c' @@ given; ﹀ ∼
(a + b') + (c + d') = (b + a') + (d + c') @@ the swap axiom, as in same-difference
(\htmlClass{new}{a + c}) + (\htmlClass{new}{b' + d'}) = (\htmlClass{new}{b + d}) + (\htmlClass{new}{a' + c'}) @@ the middle-swap technique, on each side
(a + c,\ b + d) \sim (a' + c',\ b' + d') \quad \blacksquare @@ ︿ ∼: first of each plus second of the other

From here on, for integers x and y, names , where (a, b) is any member of x and (c, d) any member of y. Read it “x plus y”. The honest-adding technique on ℤ, with same-class, makes the name honest: every choice of members gives the same class.

So + now has two jobs, adding numbers and adding integers. What stands on each side says which is meant, and the counting numbers' own sums will turn out to agree (the ℕ-inside-ℤ technique below). Check: [3, 5] + [4, 1] = [7, 6]. Swap [3, 5] for its member (0, 2): [0, 2] + [4, 1] = [4, 3], and (7, 6) ∼ (4, 3) since 7 + 3 = 6 + 4. The pair changed; its class did not.

5b9What a product must ask

Stands on 5b8 and 4g (spread for times over plus).

Multiplying is harder to guess, so guess it where the amounts exist. Suppose k = b + e and c = d + e′, so that (k, b) asks for e and (c, d) asks for e′. The product should ask for ee′. Spread the products out with spread for times over plus:

a = b + e,\ \ \ c = d + e' @@ suppose both amounts exist
ac = bd + be' + ed + ee' @@ the swap axiom; spread for times over plus with turn-about for times, spreading each way; regroup for plus
ad + bc = bd + ed + bd + be' @@ the swap axiom; spread for times over plus with turn-about for times, and spread for times over plus; regroup for plus
ac + bd = (ad + bc) + \htmlClass{new}{ee'} @@ the same products on each side, by regroup for plus, turn-about for plus and middle-swap, with ee′ left over

So the pair (kc + bd, kd + bc) asks for exactly ee′, the product of the two amounts. That pair uses only adding and multiplying of numbers, so it can be written for any two pairs. Honest-multiplying technique on ℤ: if (k, b) ∼ (k′, b′) and (c, d) ∼ (c′, d′), then (kc + bd, kd + bc) ∼ (k′c′ + b′d′, k′d′ + b′c′). Change one member at a time.

5b11The counting numbers inside

Stands on 5b8, 5b10, 5b7 (same-class) and 4k (bijection).

ℕ-inside-ℤ technique: for numbers m and n, [m, 0] = [n, 0] exactly when m = n; [m, 0] + [n, 0] = [m + n, 0]; and [m, 0] · [n, 0] = [mn, 0].

[m, 0] = [n, 0] \;\Leftrightarrow\; m + 0 = 0 + n \;\Leftrightarrow\; \htmlClass{new}{m = n} @@ the same-class technique; plus-zero and zero-plus
[m, 0] + [n, 0] = [m + n,\ 0 + 0] = [\htmlClass{new}{m + n}, 0] @@ ﹀ + on ℤ; plus-zero
[m, 0] \cdot [n, 0] = [mn + 0 \cdot 0,\ m \cdot 0 + 0 \cdot n] = [\htmlClass{new}{mn}, 0] \quad \blacksquare @@ ﹀ · on ℤ; times-zero, zero-times, plus-zero, zero-plus

From here on, where an integer is meant, a number n names the integer [n, 0]. So, as integers, 0 names [0, 0], 1 names [1, 0], 2 names [2, 0], and so on. By the ℕ-inside-ℤ technique, sameness, sums and products come out the same whichever reading is taken, so no line of rung 4 changes its meaning.

The rule n ↦ [n, 0] is a matching, in 4k's word, between ℕ and the part of ℤ made of the classes [n, 0]. It carries + to + and · to ·. “ℕ sits inside ℤ” means exactly that, and the naming line lets you forget the difference safely.

5b13Negatives

Stands on 5b12 and 5b7 (same-class).

Swapping the entries of a pair turns its question around. The negative of an integer is the class of its pairs, swapped.

(k, b) asks what takes b to k, and (b, k) what takes k to b. Honest-swapping technique: if (k, b) ∼ (k′, b′) then (b, k) ∼ (b′, k′). Unpack: k + b′ = b + k′. Turn it about (the turn-about technique): b + k′ = k + b′, and that is (b, k) ∼ (b′, k′), packed. ∎

From here on, for an integer x, names , where (a, b) is any member of x. Read it “negative x”, or “minus x”. The honest-swapping technique makes the name honest.

So −2, the negative of the integer 2, is −[2, 0] = [0, 2], and member-with-a-0 now reads: every integer is n or −n for exactly one number n. −0 = [0, 0] = 0. And −(−x) = x, since swapping twice gives the pair back. Note what −x is: the negative of x, whatever x is. −(−2) is 2. Whether an integer is above or below 0 is a question about order, and order on the new numbers is 5d's. The negative −x is also called the additive inverse of x.

5b15Taking away

Stands on 5b13, 5b14 and 5b11 (the naming line).

Subtracting is adding the negative, and now every subtraction has exactly one answer.

From here on, for integers x and y, names . Read it “x minus y”; it is the difference of x and y, and forming it is subtracting y from x.

First, the pairs were what they claimed to be. Pair-is-the-difference technique: for numbers k and b, k − b = [k, b].

a - b = [a, 0] + (-[b, 0]) @@ the naming line; ﹀ −
\phantom{a - b} = [a, 0] + [0, b] @@ ﹀ the negative
\phantom{a - b} = [a + 0,\ 0 + b] @@ ﹀ + on ℤ
\phantom{a - b} = [\htmlClass{new}{a, b}] \quad \blacksquare @@ plus-zero, zero-plus

So (3, 5) was “3 less 5” all along: 3 − 5 = [3, 5] = [0, 2] = −2. And where taking away already worked in ℕ, the new subtraction agrees with it. If k = b + c then k − b = [k, b] = [c, 0] = c, by same-class. So 4·stat's b − a, allowed there only when a ≤ b, is this subtraction, and that flag is closed. Now the technique the rung is named for, its first part. Subtraction technique: for any integers x and y, y + (x − y) = x; and if y + z = x, then z = x − y.

So 3 + x = 0, the question 5b1 began with, has exactly one answer among the integers: 0 − 3 = [0, 3] = −3. Check it forward: [3, 0] + [0, 3] = [3, 3] = 0, by same-class. Every question “what must be added to y to make x?” has one answer, and the counting numbers' answers, where they had them, are among them.

Anexact, yet rigorous · the ledger, balanced

Look in the jar for −1 cookie and you will not find one. Counted as things, the negative numbers are not there, and neither is taking away: every jar holds 0 cookies or more. As an arrangement of things, a negative number does not exist.

As a series, it does. At noon there was one cookie on the plate, and at one o’clock there were none. Whoever ate the last cookie took one away, and nothing left on the plate is that taking. It lives between two counts, a before and an after, and that is exactly what this rung’s pairs hold: (0, 1) asks what takes 1 to 0, and its class is −1. The moment a cookie goes, a series has broken out, and a difference of cookies exists along it. Write it in 1a’s ledger and the books balance to the cookie: one before, −1 for the eating, 0 after.

A negative number is not a thing you can count; it is the entry that balances the books between two counts, and it exists only along a series.

And once a difference exists, so does a question about it: one cookie gone, over how long? A change counted against the series it happens along is already, quietly, a rate.

Someone eats the cookie you were saving, and buys one to put back before you notice. The jar ends where it began, and the integer for the whole stretch is 0. Did nothing happen?

5b17Running it backwards

Stands on 5b1 to 5b15.

Given a question b + x = k, write its answer down at once: the class [k, b], and member-with-a-0 gives its name. Given an integer, find members with any entries you like above its member with a 0. Add the same number to both entries (same-class, with regroup for plus and turn-about for plus). Given a sum and one of its parts, subtract (subtraction). Wanting to show two classes are one, cross-add (same-class). Wanting to show an operation honest, change one member and cross-add the two answers. Then use middle-swap until the given sameness can be swapped in. Wanting a technique for integers, unpack to members, use rung 4's technique on the entries, and pack. Found upward; written downward.

Who said it first

Russell defined the integer “plus m” as the relation that n + m bears to n, for every number n, and “minus m” as the relation that n bears to n + m. A relation is a set of pairs, so his “plus 2” is exactly the class of (2, 0) in this step: the pairs (2, 0), (3, 1), (4, 2) and so on.

Russell, Introduction to Mathematical Philosophy (1919), ch. VII

Accepted names: the turn-about techniques are the commutative laws, the regroup techniques the associative laws, and spread the distributive law. The carry-over technique says that ℤ keeps them.
