34l · technique

Forms Find the Same Holes

A form with no slope whose total round a loop is not 0 finds a hole without seeing it (29·cb28). Count such forms, treating two as the same when they differ by a slope of a function, and a second count of holes appears, made of calculus rather than triangles. The two counts agree: on a closed smooth space, the forms find exactly as many holes as the chains. This step builds the form count, matches it with chains by totals, and counts the holes of the plane with a point removed and of the ring surface.

Hᵏ_form = (forms with dω = 0) counted up to slopes dη; it is a space because dd = 0. Totals pair forms with chains: ∫_c ω, unchanged by adding a slope or an edge, by the boundary technique. On a closed smooth space the pairing matches, and dim Hᵏ_form = rₖ.

34l1Forms Counted Up to Slopes

\omega = \dfrac{-y\,dx + x\,dy}{x^2 + y^2},\ \ d\omega = 0 @@ the turning form
\textstyle\oint_{\text{circle}} \omega = 2\pi \ne 0 @@ so ω is no slope (29·cb28)
d\omega^{\prime} = 0 \Rightarrow \omega^{\prime} - \tfrac{c}{2\pi}\omega = dg,\ \ c = \oint \omega^{\prime} @@ subtract the right multiple; the rest has total 0 round every loop
\htmlClass{new}{H^1_{\text{form}} \text{ is one direction, spanned by } \omega} @@ one hole, as H₁ = ℤ

Form-count technique: Hᵏ_form is the forms with no slope, counted as the same when they differ by a slope; since d(dη) = 0, slopes are among them, and the rest count holes. On a star-shaped region H¹_form = 0 (29·cb28).

34l2Totals Pair Forms With Chains

\textstyle\int_c (\omega + d\eta) = \int_c \omega + \int_{\partial c} \eta = \int_c \omega @@ c has no edge (29·cb28 boundary)
\textstyle\int_{c + \partial b} \omega = \int_c \omega + \int_b d\omega = \int_c \omega @@ ω has no slope
\text{so each form class gives a reading of each hole} @@ well defined both ways
\htmlClass{new}{\text{on a closed smooth space, these readings are all readings, each from one class}} @@ the matching

Form-chain technique: on a closed smooth space, totals ∫_c ω match the form count Hᵏ_form with the readings of the chain holes Hₖ, one to one; so dim Hᵏ_form = rₖ, the number of whole-number directions in Hₖ.

34l3The Ring Surface by Forms

d\theta_1,\ d\theta_2:\ \text{no slope, and no function } \theta \text{ on the whole ring} @@ each angle jumps by 2π
\textstyle\oint_{\text{ring}} d\theta_1 = 2\pi,\ \ \oint_{\text{tube}} d\theta_1 = 0 @@ each finds its own hole
d\theta_1\,d\theta_2:\ \text{total } 4\pi^2 \ne 0,\ \text{so no slope of a 1-form} @@ the 2-hole
\htmlClass{new}{\dim H^0, H^1, H^2 = 1, 2, 1 = r_0, r_1, r_2} @@ as the chains counted (34j3)

On the ring surface the two angle forms find its two 1-holes, and their product finds the 2-hole; calculus and triangles count the same holes. In physics the same count says when a field with no swirl still has no potential.

Accepted names

The form count is de Rham cohomology; forms with dω = 0 are closed, slopes are exact. The matching by totals is de Rham’s theorem. The turning form is the angle form dθ; the physics is the Aharonov-Bohm effect and multi-valued potentials.

Who said it first

Georges de Rham proved the matching in his thesis of 1931, settling a guess of Élie Cartan; Poincaré had asked the question in 1895.
