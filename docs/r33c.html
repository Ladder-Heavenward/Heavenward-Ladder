33c · proof

The Wandering Path

A grain of pollen in water jitters without rest, knocked by molecules too small to see. Make 30n’s coin walk with ever smaller steps, ever faster, keeping the spread in time fixed, and the walk becomes a path that is unbroken yet turns at every instant. Its chance of being near x at time t is the spreading bell of 33b, so heat is the average of many wanderers. This step builds the wandering path, finds the heat statement inside it, and shows that it has no slope anywhere.

B(0) = 0; B(t) − B(s) is a bell with average 0 and spread t − s, independent of the path before s; the path is unbroken. Over a short time h, B moves about √h, far more than h: so it has no slope, and the squares of its moves add up to the time taken.

33c1From a Walk to a Path

\text{after time } t:\ t/h \text{ steps, average square distance } (t/h)\cdot h = t @@ root-n (30n1)
\text{as } h \to 0:\ B(t) \text{ is a bell with spread } t @@ many small independent steps (30j)
B(t) - B(s) \text{ is independent of the path up to } s @@ later coins ignore earlier ones
\htmlClass{new}{\text{the limit path is unbroken, with } E\,B(t) = 0,\ E\,B(t)^2 = t} @@ the wandering path

Wandering technique: there is a random path B, unbroken, with B(0) = 0, whose move from s to t is a bell with average 0 and spread t − s, independent of everything before s; it is the limit of coin walks with steps √h every h seconds.

33c2Heat Is an Average of Wanderers

x + B(2\kappa t) \text{ has the bell } \Phi \text{ of spread } 2\kappa t @@ the spreading bell (33b3)
u(x, t) = \textstyle\int \Phi(x - y, t)\,f(y)\,dy @@ average over where the wanderer lands
u_t = \kappa u_{xx},\ \ u(x, 0) = f(x) @@ Φ solves the heat statement
\htmlClass{new}{\text{temperature at } x = \text{the average start-temperature seen by wanderers leaving } x} @@ heat is wandering

Average-heat technique: u(x, t) = E f(x + B(2κt)) solves u_t = κu_xx with start f; each grain of heat wanders, and the temperature is the average of where the wanderers came from.

33c3No Slope Anywhere

B(t + h) - B(t) \approx \sqrt h \cdot \text{a bell of spread } 1 @@ move of size about √h
\dfrac{B(t + h) - B(t)}{h} \approx \dfrac{1}{\sqrt h} \to \infty @@ no slope
\textstyle\sum_k \big(B(t_{k+1}) - B(t_k)\big)^2,\ \ \text{average } \sum (t_{k+1} - t_k) = t @@ spread of each square is 2(Δt)², shrinking
\htmlClass{new}{\text{squares of moves add up to } t;\ \text{for a path with a slope they add up to } 0} @@ the wanderer’s clock

Square-sum technique: over finer and finer cuts of [0, t], the sum of the squared moves of B settles at t; a path with a bounded slope gives 0. So B has, with chance 1, no slope at any time.

  1. 33c3.1understandWhy do the squares of the wanderer’s moves add up to the time, and why does that rule out a slope?

Accepted names

The wandering path is Brownian motion or the Wiener process; the walk-to-path limit is Donsker’s theorem. The square sum is the quadratic variation, [B]_t = t. The average-heat formula is a case of the Feynman-Kac formula.

Who said it first

Robert Brown saw the jitter in 1827. Louis Bachelier used the path for prices in 1900 and Albert Einstein for molecules in 1905; Norbert Wiener built it rigorously in 1923, and Paley, Wiener and Zygmund proved in 1933 that it has no slope anywhere.
