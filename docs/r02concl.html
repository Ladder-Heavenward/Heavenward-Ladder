A Collection Is Nothing but Its Members

A collection is fixed by who is in it, and by nothing else. Describe its members two different ways and you have named one set twice.

The conclusion · the rung's claim, in full, and its proof

This page opens once every question on 2f all the subsets is ticked. The claim below is proved from the steps of this rung, so it waits for them.

What the rung set out to show

The survey of rung 2 promised that a set is fixed entirely by what is in it, and that a short list of tools, each saying exactly what the members of its result are, builds sets from sets. 2c gave the mark ∈, the same-members axiom, ⊆, and the double-inclusion technique. 2d gave the sift axiom, the one empty set (laid down by 2c1's empty-set axiom), and the outsider-set technique.

2e gave gather and merge, with ∪ and ∩ and their techniques. 2f gave all the subsets. This page puts the claim in one place. A set is the same as another exactly when they have the same members, so a condition on members can fix at most one set. And the outsider set shows that a condition, with nothing to sift from, may fix none.

The claim, in full

A set is nothing but its members: two sets are the same exactly when they have the same members, so a condition on members fixes at most one set.

Let u and v be sets.

Then u = v exactly when, for every x, x ∈ u exactly when x ∈ v.

So if, for every x, x is in a set c exactly when φ(x), and x is in a set d exactly when φ(x), then c = d.

In particular the order of a list counts for nothing: {p, q} = {q, p}.

But a condition need not fix any set: no set has as its members exactly the things that are not members of themselves.

Sifted inside a set you have, the same condition does fix a set.

The Proof

The leftward arrow of the first part is the same-members axiom, laid down on 2c and not proved. The rightward way is the swap axiom, used twice.

Rows hold u = v. Let x be any member of u: by the swap axiom, write v where u stood, and x is in v. Back at the margin: every member of u is in v.

Now let x be any member of v. Turn the sameness about: v = u. By the swap axiom, x is in u. Back at the margin: every member of v is in u. Use both everys on any x and join the two ifs: x is in u exactly when x is in v. Nothing was said about x, so this is true for every x.

So rows that hold u = v reach the same members, and the same-members axiom runs the other way. Each gives the other, and the first part stands. Writing that as one exactly-when, with an if made each way, is 3a’s output.

The second part is the first part put to work. Two sets that pass the same membership test have the same members, and so they are one set.

Rows hold that, for every x, x is in c exactly when φ(x), and x is in d exactly when φ(x). Let x be anything. Use each every with x: x is in c exactly when φ(x), and, turned about, φ(x) exactly when x is in d. Chain them: x is in c exactly when x is in d. Nothing was said about x, so that is true for every x. By the same-members axiom, c = d.

The one-empty-set technique of 2d is the same idea at work: two sets with no members are one set. It is why every tool's membership line names exactly one set, and why the tool's result may be called “the” set.

The third part shows what “nothing else” means. A list written in another order passes the same test, so it names the same set.

By the gather axiom, x is in {p, q} exactly when x = p or x = q. Likewise, x is in {q, p} exactly when x = q or x = p. By 1f's turn-about technique, “x = q or x = p” says exactly what “x = p or x = q” says. Chain them: x is in {q, p} exactly when x = p or x = q. That is true for every x. So both sets pass the one test “x = p or x = q”. By the second part, {p, q} = {q, p}.

The last part marks the edge. A condition fixes at most one set; it need not fix one at all. Sifting inside a set you have is what makes the difference.

Take a set a you have. By the sift axiom, sifting a by x ∉ x gives a set: its members are the members of a that are not members of themselves. So, inside a, the condition fixes a set. But with nothing to sift from, the outsider-set technique of 2d says that no set has as its members exactly the things that are not members of themselves.

So the claim has its edge marked. A set is fixed by its members, and a tool that names its members names one set. A condition with no set to sift from may name none, and the outsider set is the witness.

Anexact, yet rigorous · two sizes of truth, again; loose, then locked

2c brought back 2b's two sizes: a set is nothing but its members, and no member is the set. The crew of a boat is tired, or every sailor in it is tired: two claims of different size. 2e added loose, then locked: things are gathered loosely under a rule, and then the gathering locks into a stable form.

This claim is the lock. However the members were gathered, and in whatever order, the set they make is fixed by who they are, and it is a thing of a different size from any one of them. Take a member out and the lock gives a different set.

A collection is nothing but its members, and you can now say exactly what that means. You are just getting started with collections.
