13k · technique

The tangent line and the nearby line

13a defined the tangent line: the linear function through a point of the graph with the slope there. This step makes it a tool. First the line itself, written from the point, with the displacement pattern on both sides. It takes three moves, always in the same order, and then the same moves run backwards. Then comes the discovery that makes it useful. Near the point the tangent line and the function are nearly the same, in a sense this step makes exact. So the line's easy arithmetic can stand in for the function's hard arithmetic. That is how you find the square root of 4.1, or 1.01 to the tenth power, by hand, and how much you are off by. Last, the slope function drawn as a graph of its own.

Read the point, take the slope at the point, and write the line: the rise from the point is the slope times the run from the point. For an input nearby, read the line instead of the function. Know that the error, divided by the step, goes to 0 in the limit.

13k1A linear function written from a point

Say it in words first. A linear function has the same chord slope between any two of its inputs (9e's same-ratio). Take the linear function with slope m through (x₀, y₀), and a pair (x, y) with x ≠ x₀. The function holds the pair exactly when the change of output from y₀, divided by the change of input from x₀, is m.

\dfrac{y - y_0}{x - x_0} = m \quad (x \ne x_0) @@ same-ratio: the chord slope from the point is m
\htmlClass{new}{y - y_0 = m\,(x - x_0)} @@ multiply both sides by x − x₀ (multiplying-keeps-answers, 5g): licensed where x − x₀ ≠ 0
x = x_0:\ \ 0 = m \cdot 0 @@ the point itself now passes too: anything-times-zero

5g's licence table said that multiplying by something with x in it gains the answers where it is 0. Here that gain is wanted: the fraction form had a hole at the very point it was built from, and the multiplied form mends it, changing nothing at any other x. So the multiplied form is the one to keep. Look at its brackets: y − y₀ and x − x₀. This is the displacement pattern of 5i and 8h, once for the output and once for the input. Read the line as: how far up from the point equals m times how far across from the point. It never needs the start b at all.

13k2The tangent line in three moves

The function supplies the two ingredients: the point, y₀ = f(x₀), and the slope, m = f′(x₀). Three moves, always in this order: read the point, take the slope at the point, write the line.

x^2 \text{ at } 3:\ \ y_0 = 9 @@ read the point
f'(x) = 2x,\ \ f'(3) = \htmlClass{new}{6} @@ the slope function (slope-of-x²), then the input: a number, not a formula
y - \htmlClass{keep}{9} = \htmlClass{new}{6}\,(x - \htmlClass{keep}{3}) @@ write the line from the point; tidied, y = 6x − 9
\tfrac1x \text{ at } 2:\ \ y_0 = \tfrac12,\ \ f'(2) = -\tfrac14 @@ slope-of-one-over-x
y - \tfrac12 = -\tfrac14\,(x - 2) @@ the tangent line: it falls, as the chords near 2 do
(2x - 1)^3 \text{ at } 1:\ \ y_0 = 1,\ \ r_0 = 1 @@ a chain: name the inside r = 2x − 1 (13j)
f'(1) = 3 \cdot 1^2 \cdot 2 = \htmlClass{new}{6},\ \ y - 1 = 6\,(x - 1) @@ chain for slopes; then the line

The tempting slip is leaving x in the slope. Write f′(x) = 2x in place of f′(3), and you get y − 9 = 2x(x − 3). That is y = 2x² − 6x + 9: a polynomial of degree 2, not a linear function. The mischief is that it does have the pair (3, 9), and its slope at 3 is 4 · 3 − 6 = 6. It has the point and the slope, and it is not a line. Put x₀ into the slope before writing the line.

Two more slips. A tangent line need not meet the graph only once. x³'s tangent line at 1 is 3x − 2, and x³ − (3x − 2) = (x − 1)²(x + 2), so it meets the graph again at −2. What is special at the point is the squared factor (x − 1)², the displacement pattern squared. And where there is no slope there is no tangent line. |x| at 0 has slopes −1 and 1 from the two sides (13f), so the three moves stop at the second. Every linear function through (0, 0) with slope between −1 and 1 stays on or below the graph of |x| and meets it only at 0. So “meets it without crossing” cannot be the definition either. The definition is the slope.

13k3Running it backwards: where does it touch?

A tangent line carries exactly two facts about the function: its value at the point and its slope there. Say y − 5 = 3(x − 2) is f's tangent line at 2. Then you know f(2) = 5 and f′(2) = 3, and nothing else. Two functions can share a tangent line at a point and differ everywhere else.

Given a line, where does it touch? Say y = 4x − 4 is a tangent line of x². The slope must match, so 2x₀ = 4 and x₀ = 2. Matching slope is not enough: the line must also have the pair (2, 4), and it does, since 4 · 2 − 4 = 4. Always check both. The linear function y = 4x has the right slope and misses the point.

\text{tangent line at } x_0:\ \ y = x_0^2 + 2x_0(x - x_0) = 2x_0 x - x_0^2 @@ the three moves with the input left as an unknown
-3 = 2x_0 \cdot 1 - x_0^2 @@ demand the pair (1, −3): substitute for the expression
x_0^2 - 2x_0 - 3 = 0 @@ adding-keeps-answers
(x_0 - 3)(x_0 + 1) = 0 \;\Rightarrow\; x_0 = \htmlClass{new}{3} \lor x_0 = \htmlClass{new}{-1} @@ 5i's sum-and-product, then zero-product
y = 6x - 9 \quad\text{and}\quad y = -2x - 1 @@ two tangent lines, one for each touching point

13k4The nearby line

Now the tool. Read the tangent line at x₀ + h instead of the function: there x − x₀ = h, so the line's value is f(x₀) + f′(x₀)h. Read it as: the value here, plus the slope here times the step. Reading the line instead of the function is called linear approximation, and the nearby line is called the linearization of f at x₀.

From here on, in this step, take f with a slope at x₀ and a change h. L(x₀ + h) names f(x₀) + f′(x₀) · h, the tangent line's value at x₀ + h. E(h) names f(x₀ + h) − L(x₀ + h), the linearization's error: the true value less the line's.

How near is “nearby”? Not “small for one h”; 13g taught that size for one h decides nothing. The exact statement is about the error divided by h.

Nearby-line-error technique: the tangent line's error shrinks faster than the step, and it is the only line through the point whose error does. Precisely: if f has a slope at x₀, then E(h)/h → 0 as h → 0. And suppose some real m has (f(x₀ + h) − f(x₀) − mh)/h → 0. Then f has a slope at x₀ and it is m.

\dfrac{E(h)}{h} = \dfrac{f(x_0 + h) - f(x_0) - f'(x_0)h}{h} @@ the line for E, and L's line
= \htmlClass{new}{\dfrac{f(x_0 + h) - f(x_0)}{h} - f'(x_0)} \quad (h \ne 0) @@ spread on ℝ with h⁻¹, reciprocal on ℝ: the chord slope less the slope
\to f'(x_0) - f'(x_0) = \htmlClass{keep}{0} @@ 13a's line, limits-subtract (10c) with a constant
\text{conversely:}\ \ \dfrac{f(x_0 + h) - f(x_0)}{h} = \dfrac{f(x_0 + h) - f(x_0) - mh}{h} + m @@ add and take away m (negative on ℝ, plus-zero on ℝ)
\to 0 + m = m \quad \blacksquare @@ limits-add: so the chord slopes have the limit m; f′(x₀) = m by 13a's line and one-limit

So having a slope at x₀ is the same as having a linear function through the point whose error shrinks faster than the step. That linear function is the tangent line. Every other linear function through the point has an error that, divided by h, heads to the difference of the slopes, not to 0.

For a polynomial, 13g's polynomial-chord makes the error visible. p(x₀ + h) = p(x₀) + b₁h + b₂h² + ⋯, with b₁ = p′(x₀), so E(h) = b₂h² + b₃h³ + ⋯: exactly the cells with two or more h's. For x² the error is h², exactly; for x³ it is 3x₀h² + h³.

13k5Estimates by hand

The trick is to pick x₀ where you know everything, a perfect square or the number 1, and let h be the small awkward part.

\sqrt{x},\ \ x_0 = 4,\ \ h = 0.1 @@ a base you can do in your head
f(4) = 2,\ \ f'(4) = \dfrac{1}{2\sqrt4} = \tfrac14 @@ slope-of-√
L(4.1) = 2 + \tfrac14 \cdot 0.1 = \htmlClass{new}{2.025} @@ the value here plus the slope here times the step
2.025^2 = 4.100625 @@ the check by squaring: just over 4.1, so the estimate is a little too big
x^{10},\ \ x_0 = 1,\ \ h = 0.01:\ \ L(1.01) = 1 + 10 \cdot 0.01 = \htmlClass{new}{1.1} @@ every power of 1 is 1; power for slopes gives the slope 10
(1 + h)^{10} = 1 + 10h + 45h^2 + 120h^3 + \cdots @@ two-term-power read in ℝ: the coefficients are row 10 of 4k's table
= 1 + 0.1 + \htmlClass{keep}{0.0045 + 0.00012 + \cdots} @@ with h = 0.01: the error is the cells with two or more h's

√4.1 ≈ 2.02485, so the first estimate is off by about 0.00015, found with a quarter and a tenth. And 1.01¹⁰ ≈ 1.10462: the linearization kept the first two terms, and what it dropped is how wrong it is.

For the root, the error has an exact form. By the conjugate (8i), √(x₀ + h) − √x₀ = h/(√(x₀ + h) + √x₀), so

Root's-nearby-line technique: for x₀ > 0 and every h ≠ 0 with x₀ + h ≥ 0, the linearization of √ at x₀ gives more than √(x₀ + h). The error above is h · h over a positive real, with a minus sign in front: negative for every such h, by square-never-negative and zero-product. So 2.025 had to come out too big, and so does every such estimate of a root, whichever way h goes.

13k6How wrong, and which way

For x² the error is h² exactly. Halve the step and the error quarters; cut the step by ten and the error drops by a hundred. For √x from 4: a step of 0.4 gives 2.1 against √4.4 ≈ 2.09762, an error of about 0.0024. A step of 0.04 gives 2.01 against √4.04 ≈ 2.00998, an error of about 0.000025. Ten times smaller step, roughly a hundred times smaller error, as the h · h in root's-nearby-line's top predicts.

Which way the error goes depends on how the graph bends away from its tangent line. For √ it is always too big (root's-nearby-line). For x¹⁰ from 1 with h > 0 it is too small, since every dropped term of two-term-power is positive (1.1 against 1.10462). Telling the two kinds of bend apart by a second slope is rung 14's business.

And the method fails if you go too far. From 4, the linearization says √8 is about 2 + ¼ · 4 = 3, but 3² = 9. Choose a nearer base: from 9, the line gives 3 − ⅙ = 17/6 ≈ 2.8333, against √8 ≈ 2.8284. The skill is choosing x₀: close to where you want to be, and where you know both the value and the slope.

The linearization's rise is usually written dy = f′(x₀) dx, with dx the step and dy the rise along the tangent line, and called the differential. This ladder keeps 13e's ruling that dy and dx name nothing alone, and writes the same rise as f′(x₀) · h.

13k7The slope function as its own graph

Move the point along the graph and the tangent line swings. Record its slope at every input and draw those pairs: that is the graph of f′, 13a's derivative, a function of its own (9e's graph is the function's pairs). For x² it is the linear function 2x: below the x-axis left of 0, 0 at 0, above it right of 0. Where the slope function is 0, the tangent line is level: a linear function with step 0, in 9e's word.

Slope-sign-near technique: near an input where the slope is positive, the function is higher just to the right and lower just to the left. Precisely: if f′(x₀) > 0, then for some reach r, f(x₀ + h) > f(x₀) for 0 < h < r, and f(x₀ + h) < f(x₀) for −r < h < 0. If f′(x₀) < 0, the same is true with the two orders turned about. The chord slopes head to f′(x₀) > 0. So by 10b's sign-kept-near they are positive on a neighbourhood of 0 of some reach r. And the change f(x₀ + h) − f(x₀) is the chord slope times h. So where the chord slope is positive, the change has the sign of h (8g's sign-of-a-product).

Slope-sign-near is about one input and its near neighbours. It does not say that f climbs on a whole interval where f′ is positive; that is rung 14's technique. Two more readings of the slope function, from 13d. Lifting f (lifting) leaves its slope function where it was. Displacing the input (displaced-slopes) displaces the slope function's pairs by the same amount.

Who said it first

4k’s table is Pascal’s triangle. The scientist of question 13k.4.4 is Robert Hooke, and the spring law is Hooke’s law.

Accepted names: the linearization’s rise f′(x₀) · h is the differential, dy = f′(x₀) dx. Reading the tangent line instead of the function is linear approximation, and the nearby line is the linearization.
