35g · technique

Countable or not, by hand

The proof steps of this rung settled a handful of sets: the fractions and the algebraic reals can be listed, the line and the parts of the counting numbers cannot. Most sets that turn up in practice are settled by one of two moves, done by hand. To list a set, give each member a height, a counting number, with only finitely many members at each height, and list height by height. To show a set cannot be listed, find inside it a copy of the endless strings of zeros and ones: a way of sending each such string to a different member. When a set has both a way into the line and such a copy inside it, it has the size of the line exactly. This step gives the three moves and runs them on a row of sets: the finite strings of a keyboard, the finite parts of the counting numbers, the ways to shuffle the counting numbers, the circles in the plane, and the reals that use only two digits. The hard part is never the proof. It is seeing which move fits.

Countable: find a height with finitely many members at each height. Not countable: send the endless strings of zeros and ones one-to-one into the set. The size of the line: both a way into the line and a copy of the strings.

35g1Listing by height

35a4 listed the algebraic reals by giving each polynomial a height. The move works on any set.

Height-listing technique: if each member of A is given a height in ℕ, and only finitely many members share each height, then A is countable.

H_k = \{x \in A : x \text{ has height } k\} \text{ is finite} @@ given; with a list of its own, its entries in a fixed order
\text{list } H_0, \text{ then } H_1, \text{ then } H_2, \ldots @@ one finite run after another, the empty ones skipped
\text{every } x \in A \text{ has some height } k,\ \text{so it is reached in } H_k @@ it comes after the finitely many members of lower height
\htmlClass{new}{A \text{ is countable}} \quad \blacksquare @@ a list, or A is empty
  
\text{a string of length } n \text{ from a keyboard of } 100 \text{ keys: height } n @@ 100ⁿ strings of each length (counted-functions, 4k9)
\text{every program, every recipe, every book ever printed is such a string} @@ so the programs are countable
\text{a finite part } s \subseteq \mathbb N \mapsto \textstyle\sum_{j \in s} 2^j @@ the part read as the 1s of a numeral in base 2 (4i)
\{0, 2, 3\} \mapsto 1 + 4 + 8 = 13,\ \ \varnothing \mapsto 0 @@ different parts, different numerals
\htmlClass{new}{\text{the finite parts of } \mathbb N \text{ are matched with } \mathbb N} \quad \blacksquare @@ every number has one numeral in base 2: a matching, no height needed

The second run beats a height. When a set can be read off as the numerals of the counting numbers, the matching is written in one line. When it cannot, a height is the fallback, and the thinning technique turns the list into a matching.

35g2A copy of the bits

An endless string of 0s and 1s is a function from ℕ to 2. Write 2^ℕ for the set of them; 4k10 matched it with 𝒫(ℕ), and 35c2 showed that no list holds it.

Copy-of-the-bits technique: if 2^ℕ goes one-to-one into A, then A cannot be listed. A list of A would give a list of the strings sent into it: keep the entries that are images, and read each back through the one-to-one map.

b \mapsto \{\,n : b(n) = 1\,\} \cup \{\,\text{every odd number}\} @@ into the endless parts of ℕ: each image holds every odd number, so it is endless
b \mapsto 0.e_0e_1\cdots,\ e_n = 3 \text{ if } b(n) = 0,\ 7 \text{ if } b(n) = 1 @@ into the reals written with 3s and 7s only; no 9s, so different strings give different reals (8·cb5)
b \mapsto \sigma_b,\ \ \sigma_b \text{ swaps } 2n \text{ and } 2n + 1 \text{ when } b(n) = 1 @@ into the shuffles of ℕ: each σ_b is a matching of ℕ with itself, and different b give different σ_b
\htmlClass{new}{\text{none of the three sets can be listed}} \quad \blacksquare @@ the copy-of-the-bits technique, three times

The endless parts of ℕ cannot be listed, though the finite parts can. Removing the finite ones from 𝒫(ℕ) removes a countable set, as 35b3 said it would, and leaves a set that still cannot be listed.

35g3The size of the line, by hand

Line-sized-by-hand technique: if A goes one-to-one into ℝ, and 2^ℕ goes one-to-one into A, then A has the size of the line. The first map gives |A| ≤ |ℝ|. The second gives |𝒫(ℕ)| ≤ |A|. The line-size technique (35e2) and the two-one-way technique (35d1) finish it.

\text{circles with fraction centre and fraction radius: height } h = \text{the height of the three fractions} @@ countable: three fractions name the circle; each fraction’s height is |z| + q; finitely many below each h
\text{all circles in the plane} \to \mathbb R^3 \to \mathbb R @@ centre and radius, one-to-one; the plane-as-line technique twice (35e2)
\text{radius } 0.e_0e_1\cdots \text{ in 3s and 7s, centre } (0, 0) @@ a copy of the bits among the circles
\htmlClass{new}{\text{the circles have the size of the line}} @@ the line-sized-by-hand technique
\text{the functions from } \mathbb N \text{ to } \mathbb N \to \mathcal P(\mathbb N \times \mathbb N) \to \mathcal P(\mathbb N) @@ a function is its pairs (9a); carry parts through the pair-listing matching
\htmlClass{new}{|\{f : \mathbb N \to \mathbb N\}| = 2^{\aleph_0}} \quad \blacksquare @@ the functions to 2 sit among them

So ℵ₀^ℵ₀ = 2^ℵ₀: more choices at each place give no larger size than two. The shuffles of ℕ, the circles of the plane, the endless walks on a grid of streets, the reals with two digits: each lands on the line’s size once both maps are written.

The basement · there if you want it

The accepted names

The height-listing technique is the usual proof that a set is countable by an enumeration by rank. 2^ℕ is Cantor space. The line-sized-by-hand technique is the standard way of showing a set has the cardinality of the continuum, through Cantor–Schröder–Bernstein. A shuffle of ℕ is a permutation, and the shuffles form the infinite symmetric group. ℵ₀^ℵ₀ = 2^ℵ₀ is the usual identity of cardinal arithmetic. Reals whose digits a program prints are computable reals; the reason the diagonal of 35g.5.5 is not one is the undecidability of the halting problem.

Who said it first

Georg Cantor listed rationals and algebraic numbers by height, and introduced the dust of the next step in 1883. The countability of the computable reals, and the diagonal against them, are in Alan Turing’s paper of 1936, which began from the question of which reals a machine can write out. Émile Borel had raised the same doubt about reals with no description in 1927.

A proof that is not allowed

“Give each real in [0, 1) the height n, where n is the place of its first 7. Each height then holds the reals with their first 7 there, and the list runs height by height.” Not allowed: each height holds endlessly many reals, so “list Hₙ” is not one finite run, and reals with no 7 get no height at all.
