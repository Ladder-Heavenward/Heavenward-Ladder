35g · technique

Points as the Shapes of Orders

Sizes forget order: ω, ω + 1 and ω·ω all have size ℵ₀ (35e). The points of the run past the endless (29·cb3) remember it. Every order in which each nonempty part has a first member matches exactly one point, so the points are the shapes such orders can take. Their arithmetic is the arithmetic of laying orders end to end, and it does not turn about: one before the endless run is swallowed, one after it is not. This step matches orders with points, adds and multiplies points, and writes every countable point up to a far one in a normal form.

If every nonempty part of an order has a first member, the order matches one point and no other. α + β lays β after α; α·β lays β copies of α. 1 + ω = ω but ω + 1 > ω; 2·ω = ω but ω·2 = ω + ω. Every point below a far point ε₀ is ω^(β₁)·c₁ + ⋯ + ω^(βₖ)·cₖ with falling βs.

35g1Every Good Order Has a Point

\text{each member } x \mapsto \text{the point matching the members below } x @@ by the falling run, on the members (29·cb3)
\text{two matchings would differ first at some least member} @@ impossible: both match the same members below
\{0, 2, 4, \ldots\} \cup \{1, 3, 5, \ldots\}, \text{ evens first} @@ an order of the counting numbers
\htmlClass{new}{\text{its point is } \omega + \omega} @@ a run, then a second run

Shape technique: every order in which each nonempty part has a first member matches exactly one point of the run, by a matching that keeps order; the point is the order’s shape. So countably many members can take uncountably many shapes, one for each countable point below ω₁ (35f).

35g2Laying Orders End to End

1 + \omega:\ \ \star, 0, 1, 2, \ldots \text{ has shape } \omega @@ a run with one in front is a run
\omega + 1:\ \ 0, 1, 2, \ldots, \star \text{ has a last member} @@ ω has none, so ω + 1 ≠ ω
2\cdot\omega = \omega \text{ copies of } 2:\ \ (0,0),(0,1),(1,0),(1,1),\ldots = \omega @@ pairs, one after another
\htmlClass{new}{\omega\cdot 2 = 2 \text{ copies of } \omega = \omega + \omega \ne \omega} @@ the order of the factors matters

Laid-order technique: α + β is α followed by β, and α·β is β copies of α in a row; both are good orders, so both are points. Neither turns about, though the two sides always have the same size (35e).

35g3A Normal Form

\omega^2 = \omega\cdot\omega,\ \ \omega^{\omega} = \text{the least point past every } \omega^n @@ powers by laying, and by limits
\alpha = \omega^{\beta_1}c_1 + \cdots + \omega^{\beta_k}c_k,\ \ \beta_1 > \cdots > \beta_k @@ like digits in base ω
\varepsilon_0 = \text{the least point past } \omega,\ \omega^{\omega},\ \omega^{\omega^{\omega}}, \ldots @@ every point below it has a form whose exponents are smaller
\htmlClass{new}{\omega\cdot 3 + 5 < \omega^2 < \omega^{\omega} < \varepsilon_0,\ \text{all of size } \aleph_0} @@ the base-bump labels live here (29·cb3)

Base-ω technique: every point above 0 is written in exactly one way as ω^(β₁)·c₁ + ⋯ + ω^(βₖ)·cₖ with falling exponents and whole-number cs; comparing two points compares their leading terms, as digits do. Below ε₀ the exponents are themselves smaller points, so the form can be written out to the end.

The cellar · there if you want it

Accepted names

Points of the run are ordinals; an order whose parts have first members is a well-order, and its point is its order type. The sums and products are ordinal arithmetic; the base-ω form is the Cantor normal form; ε₀ is the first epsilon number.

Who said it first

Georg Cantor built ordinal arithmetic and the normal form between 1883 and 1897; John von Neumann made each ordinal the set of those below it in 1923.
