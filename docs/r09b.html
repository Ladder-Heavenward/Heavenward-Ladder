9b · proof

Composing, and Brackets Don't Matter

Give a function's output to another function, and you have made a third: do one, then the other. This step gives that gesture its mark and proves three things about it. The order matters: doing one function and then another is usually not doing them the other way round. Brackets do not matter: in a chain of three, joining the first two and then the third is the same function as joining the last two first. And there is a function that changes nothing, which leaves any chain it joins unchanged. Each proof is a few lines of 9a's equal-functions: same inputs, same values, same function.

Chaining is one function after another: the first one’s output is the second one’s input. Both bracketings of a chain send each input through the same functions in the same order, so they are one function.

9b1Doing One, Then the Other

In words: if f takes A into B, and g takes B into C, then “do f, then do g to the result” takes A into C. It is a set of pairs like any function, and it gets a mark.

From here on, for f : A → B and g : B → C, g ∘ f names {(a, g(f(a))) : a ∈ A}, 2i's shorthand for a sift of A × C. Read it “g after f”. It is the composite of g and f, and forming it is composing. The ring is an operator, a statement with two gaps, and its result is a function.

Composite-is-a-function technique: for f : A → B and g : B → C, g ∘ f : A → C, and (g ∘ f)(x) = g(f(x)) for every x ∈ A. For each x, f(x) ∈ B by 4d, so g(f(x)) ∈ C by 4d again. Rule-makes-a-function (4d) says the set of pairs {(x, g(f(x))) : x ∈ A} is a function from A to C with value g(f(x)) at x. ∎ Exactly one output, twice over: x has one f(x), and f(x) has one g(f(x)).

Notice the order of writing. g ∘ f is written with g first and done second, because f is the one standing next to the input in g(f(x)). Read the ring as “after”, and it always comes out right. The two functions need not match exactly where they meet. If f : A → B, g : D → C and every output of f is in D, then f : A → D by 9a's codomain, and g ∘ f makes sense. Take k : [0, ∞) → ℝ given by k(x) = √x (8f) and f : ℝ → ℝ given by f(x) = x² + 1. Every output of f is at least 1 (square-never-negative). So f : ℝ → [0, ∞), and (k ∘ f)(x) = √(x² + 1) for every real x. But f ∘ k needs only k's outputs to be reals, which they are: (f ∘ k)(x) = (√x)² + 1 = x + 1, for x ≥ 0 only. Two orders, two formulas, two domains.

9b2The Order Matters

Composing-order-matters technique: there are functions f, g : ℝ → ℝ with g ∘ f ≠ f ∘ g. A counterexample does it (4e's shape):

f(x) = x + 1,\ \ g(x) = x^2 @@ two functions ℝ → ℝ, by rule-makes-a-function
(g \circ f)(2) = g(f(2)) = g(3) = 9 @@ composite-is-a-function; f first, then g
(f \circ g)(2) = f(g(2)) = f(4) = 5 @@ composite-is-a-function; g first, then f
9 \ne 5 @@ numbers compare (any-two-compare), read in ℝ by 8d's naming line
\htmlClass{new}{g \circ f \ne f \circ g} \quad \blacksquare @@ equal-functions: if they were the same, the swap axiom would give 9 = 5

Putting on socks and then shoes is not putting on shoes and then socks. Almost any two functions chosen at random show it, and on small sets too. On {cat, dog}, let f swap the two and let g send both to cat. Then g ∘ f sends both to cat, and f ∘ g sends both to dog. Sometimes the order does not matter. Adding 2 and adding 3 commute. So do x ↦ x² and x ↦ x³, since (x³)² = x⁶ = (x²)³ by power-of-a-power (8f). But commuting is a fact about particular pairs, never a technique of composing.

9b3Brackets in a Chain Don’t Matter

A chain of functions is a run of them, each feeding the next. Functions in a chain run in a row, as samenesses did on 0b7. 6e's chain, a part of a partly ordered set in which any two compare, keeps its meaning; what the word is said of says which.

In words: in a chain of three, it does not matter which two you join first. You may join g to f and then put h on the outside. Or you may join h to g and then put f inside. Both send each input through f, then g, then h. Regroup technique for composing: for f : A → B, g : B → C and h : C → D, h ∘ (g ∘ f) = (h ∘ g) ∘ f. Both are functions from A to D by composite-is-a-function, so equal-functions needs only their values.

\text{let } a \in A \text{ be anything} @@ 2b: speak of every input by speaking of any
\big(h \circ (g \circ f)\big)(a) = h\big(\htmlClass{new}{(g \circ f)(a)}\big) @@ composite-is-a-function, with g ∘ f as the inside function
\phantom{\big(h \circ (g \circ f)\big)(a)} = h\big(\htmlClass{new}{g(f(a))}\big) @@ composite-is-a-function again, inside
\phantom{\big(h \circ (g \circ f)\big)(a)} = \htmlClass{new}{(h \circ g)}\big(f(a)\big) @@ composite-is-a-function read right to left, with f(a) as the input
\phantom{\big(h \circ (g \circ f)\big)(a)} = \htmlClass{new}{\big((h \circ g) \circ f\big)}(a) @@ composite-is-a-function read right to left once more
\htmlClass{keep}{h \circ (g \circ f) = (h \circ g) \circ f} \quad \blacksquare @@ same domain A, same value at every a: equal-functions

Look at the middle two lines: composite-is-a-function was used backwards, to put brackets in rather than take them out. A sameness can be read either way, so a definition licenses travel in both directions. That is the manipulating move in miniature. And now the brackets can go, as 4f let them go for sums of three. This is what 4f called associative.

From here on, h ∘ g ∘ f may be written without brackets. It names h ∘ (g ∘ f), and by the regroup technique for composing the same function as (h ∘ g) ∘ f, so either reading may be used. Longer chains are regrouped by regroup for composing step by step.

Its value at x is h(g(f(x))): read the chain from right to left, and that is the order the functions act.

9b4The Function That Changes Nothing

From here on, for a set A, id_A names {(a, a) : a ∈ A}. Read it “the identity on A”. It is also called the identity function on A. By rule-makes-a-function it is a function from A to A, with id_A(a) = a. The low mark A is 4f's low mark carrying a letter: it records which set.

Do-nothing-map technique: for f : A → B, f ∘ id_A = f and id_B ∘ f = f. Both sides are functions from A to B. And (f ∘ id_A)(x) = f(id_A(x)) = f(x), and (id_B ∘ f)(x) = id_B(f(x)) = f(x), by composite-is-a-function and the identity's value. Equal-functions. ∎ The two identities differ when A and B differ: on the right of f it is A's, on the left it is B's. Either way, the identity does nothing in a chain. One-unit technique: if u : A → A has u ∘ v = v for every v : A → A, then u = id_A. Take v = id_A: then u = u ∘ id_A = id_A, by identity and then the hypothesis. ∎

“Unit” here is 1f's word, as in its units technique, where ⊤ and ⊥ are the units of ∧ and ∨: a do-nothing for an operation. 5j's unit, a standard amount for measuring, keeps its meaning.

So ∘ behaves like 4f's adding in two of its techniques and unlike it in the third. It regroups (regroup for composing, like regroup for plus). It has a do-nothing (identity, like plus-zero). And it does not commute (composing-order-matters, unlike turn-about for plus). Rung 19 studies collections of functions that compose, undo and include doing nothing. Every one of them inherits regroup for composing from this step for free.

9b6Running It Backwards

Wanting a composite: check each output of the inside is an input of the outside, then read off g(f(x)). Wanting to show two chains are the same: equal-functions, with composite-is-a-function unpacked on each side until the values meet. Regroup for composing regroups along the way. Wanting a refutation of a commuting claim: one input where the two orders part. Wanting a function to be an identity: show its value at each x is x. Found upward; written downward.

Who said it first

Dedekind described the composite this way: when one transformation carries a system into a second system, and another carries the second onward, there results a transformation of the first system, compounded of the two, which gives each element the transform of its transform.

Dedekind, Was sind und was sollen die Zahlen? (1888), §25; in English as The Nature and Meaning of Numbers, trans. W. W. Beman (1901)

Accepted names: composing is not commutative (composing-order-matters); composing is associative (the regroup technique for composing); the identity is the identity function.
