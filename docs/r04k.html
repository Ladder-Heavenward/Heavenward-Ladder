4k · technique

Counting Choices

3c said that “three cats sat on the wall” is a matter of matching the cats with the members of the set named 3, and left the matching to this rung. 4c's cellar told the story of the horses and granted the facts about leading a horse out of the barn. This step builds the matching, says what it means for a set to have a given number of members, and proves those facts. Then the techs of counting: separate piles add, choices made in stages multiply. Then a mark for adding up a list, and the sum of every number from 0 up to a given one. Then how fast the subsets of a set pile up, and arrangements and factorials. Last, how many ways there are to choose a few things from many, the table those numbers make, and why they are the numbers that appear when a power of a sum is multiplied out.

To count a set, match it with a number. Separate piles add; choices made in stages multiply. To count the parts of a given size, ask of one member whether it is in or out, and add the two answers. That is the table's rule, and it is also how a power of a sum multiplies out.

4k1Matched With

Pair the cats off with the members of 3, one cat to each member, no cat used twice and no member left over. That is all that “there are three cats” means, and here it is as a line.

From here on, a matching between sets X and Y is a set m ⊆ X × Y such that every member of X is paired by m with exactly one member of Y. And every member of Y must be paired by m with exactly one member of X. X is matched with Y when there is a matching between them.

Example: {(Gomez, 0), (Finn, 1)} is a matching between {Gomez, Finn} and 2: each pet has exactly one partner in 2, and each of 0 and 1 has exactly one pet.

A matching is a function from X to Y (4d), so m(x) is the partner of x. Since the definition reads the same from either side, the pairs turned about make a matching between Y and X.

Three short checks follow from the line. Every set is matched with itself, by {(x, x) : x ∈ X}.

Turn-about technique for matchings: if X is matched with Y, then Y is matched with X. You know this one: if every child has a chair and every chair a child, the chairs are matched with the children too.

Chain technique for matchings: if X is matched with Y and Y with Z, then X is matched with Z. The matching is x ↦ m′(m(x)), by rule-makes-a-function.

4k2Having n Members

From here on, for a number n, the statement “X has n members” means X is matched with n, and n is then the number of members of X. A set is finite when it has n members for some number n.

Example: since 3 = {0, 1, 2}, the pets {Serena, Murphy, Gomez} have 3 members by the matching {(Serena, 0), (Murphy, 1), (Gomez, 2)}, given that they are three different pets.

A fruit stand has a row of apples, a row of peaches and a row of pears. Lay them side by side: every apple has one peach and one pear beside it, and nothing is left over. The rows match (4k1), and nobody has counted. 3c built a pile out of nothing: 0, then the next, and the next, seven times over. It holds no fruit, and the rows match it too. Sift the stand’s collection of parts (2g) by “is matched with that pile” (2e’s sift), and the apples, the peaches and the pears all come out, with every mixed handful that matches. A number is what is left when everything but how many has been taken away. That fruitless pile is the one the ladder calls 7.

The sift needed the stand to pour from. Every collection anywhere that matches the pile cannot be gathered into one set: anything at all sits in some such collection, so merging them would give a set of everything, and 2e showed there is none. So the ladder keeps the one standard pile, 7 itself, and every collection of seven is matched against it, wherever it sits.

This completes a foreclosure from 2d3. A set with n members is matched with n, and the matching is its list: one entry for each number before n. So every finite set can be listed and checked member by member, one case to an entry.

4k3Leading One Out, Bringing One In

Now the facts the horses of 4c's cellar needed. Lead-one-out technique: if X has S(n) members and w ∈ X, then X ∖ {w} has n members.

Example: {Gomez, Finn, Serena} has 3 members, so {Gomez, Finn, Serena} ∖ {Finn} = {Gomez, Serena} has 2.

Plan: take the matching with S(n), and give w's partner to the member paired with n.

f \text{ a matching between } X \text{ and } S(n);\ \ w \in X,\ \ f(w) = k @@ given
c \text{ the partner of } n \text{ in } X @@ f pairs n with exactly one member of X
g(u) = f(u) \text{ when } f(u) \ne n,\ \ g(u) = k \text{ when } f(u) = n @@ a rule on X ∖ {w}, by cases on a settled statement (settled-order)
g(u) \lt n @@ f(u) < S(n), f(u) ≠ n; and f(u) = n means u = c ≠ w, so k ≠ n: next-membership
v \lt n:\ \ v = k \text{ has } c;\ \ v \ne k \text{ has its } f\text{-partner} @@ c ≠ w since f(w) = k ≠ n; the f-partner of v is not w, since f(w) = k ≠ v
g(u) = g(u') \Rightarrow u = u' @@ cases on f(u) = n and f(u′) = n (settled-order); a mixed case makes f(u′) = k = f(w), so u′ = w: clash
\htmlClass{new}{X ∖ \{w\} \text{ has } n \text{ members}} \quad \blacksquare @@ g's pairs are a matching between X ∖ {w} and n

(When f(w) = n, the second case never arises and g is f with w's pair removed. When f(w) < n, the member that was paired with n takes w's old partner.)

The other way is easier. Bring-one-in technique: if X has n members and x ∉ X, then X ∪ {x} has S(n) members, by f ∪ {(x, n)}. For n ∉ n, so no member of X was paired with n; and x ∉ X, so x has only its new pair.

4k4One Count

One-count technique: if X has n members and has n′ members, then n = n′. You already trust this. Count the chairs twice, in any order, and you get the same number.

Plan: by turn-about for matchings and chain for matchings, n is matched with n′. So it is enough to prove, by induction on n, that n matched with m gives n = m.

If n = 0, a member of m would need a partner in 0, so m = 0. If S(n) is matched with m, then m has a member, so m = S(m′) by zero-or-a-next. Then S(n) has S(m′) members. Lead-one-out with w = n says S(n) ∖ {n}, which is n (next-membership, no-self-membership), has m′ members. The hypothesis gives n = m′, and so S(n) = m.

The horses' facts are now techniques, so the flag 4c's cellar opened is closed. A herd with S(S(n)) members, with a horse led out, has S(n) members (lead-one-out), and the flaw stays exactly where 4c's cellar found it, at n = 0.

One more technique, quiet but essential. Finite-is-settled technique: if X has n members, then any two members of X are the same or not: x = y ∨ x ≠ y.

For f(x) = f(y) ∨ f(x) ≠ f(y) by settled-order. The first gives x = y, since each member of n has one partner. The second gives x ≠ y, since x = y would make f(x) = f(y). So X = (X ∖ {w}) ∪ {w} for w ∈ X, by chasing a member, and every case split in this step about members of a finite set is licensed.

Two last things about finite sets of numbers, which 4h left to this step. Greatest-member technique: a finite set of numbers with a member has a greatest member.

Plan: induct on its number of members. Lead out one member x (lead-one-out). If nothing is left, x is greatest. Otherwise the rest has a greatest member g, and the larger of x and g (any-two-compare) is greatest.

And ℕ is not finite, since it has no greatest member (n < S(n)). 3d's mark of an endless collection is the other side of this: ℕ is matched with the part ℕ ∖ {0} by 4d's function s.

4k5Separate Piles Add

Separate-piles technique: if A has p members, B has b members, and A ∩ B = ∅, then A ∪ B has p + b members. Its accepted name is in the cellar. You know this one: three cats and two dogs, with nobody both, are five pets.

Example: {Gomez, Finn} and {Serena} share no member, so {Gomez, Finn, Serena} has 2 + 1 = 3.

Plan: induct on b, leading a member out of B and bringing it back into the union.

\qquad A \cup B' \text{ has } a + b @@ the hypothesis: A ∩ B′ = ∅ still
\qquad y \notin A \cup B',\ \ A \cup B = (A \cup B') \cup \{y\} @@ A ∩ B = ∅; finite-is-settled on B
\qquad A \cup B \text{ has } S(a + b) = \htmlClass{new}{a + S(b)} @@ the bring-one-in technique; plus-a-next

4k6Choices in Stages Multiply

Now stages. Three shirts and four pairs of trousers: for each shirt, a row of four outfits; three rows of four. The same is true when the second choice depends on the first, provided the number of second choices does not.

Stages-multiply technique: if X has p members and, for each x ∈ X, a set Yₓ has b members, then the set of pairs (x, y) with x ∈ X and y ∈ Yₓ has p · b members. Its accepted name is in the cellar. You already do this when you dress. Three shirts and two pairs of trousers make six outfits.

Plan: induct on the number of members of X. Lead one member out, and add its row of b pairs by separate-piles.

T_X = \{(x, y) : x \in X,\ y \in Y_x\} @@ the pairs; each Y_x a part of one set Z, so T_X is a sift of X × Z
a = 0:\ \ X = \varnothing,\ \ T_X = \varnothing,\ \ 0 \cdot b = 0 @@ zero-times
X \text{ has } S(a):\ \ x_0 \text{ the partner of } a,\ \ X' = X ∖ \{x_0\} \text{ has } a @@ the lead-one-out technique
\qquad T_X = T_{X'} \cup (\{x_0\} \times Y_{x_0}),\ \ \text{no pair in both} @@ finite-is-settled on X; first entries differ (equal-pairs)
\qquad T_{X'} \text{ has } a \cdot b;\ \ \{x_0\} \times Y_{x_0} \text{ has } b @@ the hypothesis; (x₀, y) ↦ y is a matching
\qquad T_X \text{ has } a \cdot b + b = \htmlClass{new}{S(a) \cdot b} @@ the separate-piles technique; next-on-the-left for times
\forall a\ (\dots) \quad \blacksquare @@ the induction technique

With every Yₓ the same Y, the pairs are X × Y: a set with p members times a set with b members has p · b members. That is why 2h called p × b a product, and why 2i's grids have p · b cells.

Ask every time: is this a choice made and then another (multiply), or one pile or else another (add)? Three shirts and four trousers make 3 · 4 = 12 outfits; three shirts or else two sweaters make 3 + 2 = 5 choices of top.

4k7Adding up a List

4k8The Doubled Sum

Now the sum 0 + 1 + ⋯ + n. Write it forwards, and under it backwards: under 0 stands n, under 1 the number before n, and so on. Every column adds to n, and there are n + 1 columns, so the two rows together make n · (n + 1). That is the idea.

The proof is an induction, and it needs no taking away and no taking a part of anything: the technique is stated doubled. Doubled-sum technique: twice the sum 0 + 1 + ⋯ + n is n times n + 1.

2 \cdot \sum_{i \le 0} i = 2 \cdot (0 + 0) = 0 = 0 \cdot 1 @@ sum-of-none, sum-one-more; times-zero, zero-times: the base
\text{assume } 2 \cdot \sum_{i \le n} i = n \cdot (n + 1) @@ the step opens
\qquad 2 \cdot \sum_{i \le S(n)} i = 2 \cdot \Big(\sum_{i \le n} i + S(n)\Big) @@ sum-one-more
\qquad \phantom{2 \cdot \sum_{i \le S(n)} i} = \htmlClass{keep}{2 \cdot \sum_{i \le n} i} + 2 \cdot S(n) @@ spread for times over plus
\qquad \phantom{2 \cdot \sum_{i \le S(n)} i} = \htmlClass{new}{n \cdot S(n)} + 2 \cdot S(n) @@ the hypothesis, with plus-one
\qquad \phantom{2 \cdot \sum_{i \le S(n)} i} = (n + 2) \cdot S(n) @@ spread for times over plus turned about, with turn-about for times
\qquad \phantom{2 \cdot \sum_{i \le S(n)} i} = \htmlClass{new}{S(n) \cdot (S(n) + 1)} @@ n + 2 = S(S(n)) = S(n) + 1 (plus-a-next, plus-one); turn-about for times
\forall n\;\Big(2 \cdot \sum_{i \le n} i = n \cdot (n + 1)\Big) \quad \blacksquare @@ the induction technique

Example: 2 · (0 + 1 + ⋯ + 100) = 100 · 101 = 10100. And 0 + 1 + ⋯ + 4 = 10, since 2 · 10 = 4 · 5. The 0 adds nothing, so this is also the sum from 1.

And the sum itself is named by 4j's words. First, n · (n + 1) is even. If n is even this is divides-a-multiple. If n = 2 · d + 1 then n + 1 = 2 · (d + 1), and divides-a-multiple again. Then doubled-sum is the split n · (n + 1) = 2 · (0 + 1 + ⋯ + n) + 0. So 0 + 1 + ⋯ + n is the quotient of n · (n + 1) by 2, and one-split makes it the only one.

A story is told of a schoolboy who was set, with his class, the adding up of a long run of numbers. He laid his slate down with the answer almost as soon as the task was given.

4k9Counting Functions

Counted-functions technique: if X has n members and Y has m members, then the set of functions from X to Y (a sift of 𝒫(X × Y)) has mⁿ members.

Example: from {Gomez, Finn} to {cat, owl} there are 2² = 4 functions: both cat, both owl, Gomez cat and Finn owl, Gomez owl and Finn cat.

Plan: induct on n. With n = 0 there is exactly one function, the empty one, and (power-zero).

With S(n), lead out x₀ (lead-one-out), so X′ = X ∖ {x₀} has n members. A function on X is a function on X′ together with a value at x₀. They are matched by f ↦ (f on X′, f(x₀)), and back by (g, y) ↦ g ∪ {(x₀, y)} (finite-is-settled on X). Stages-multiply counts the pairs, by power-of-a-next.

4k10How Fast the Subsets Pile Up

2g built the subsets by keep or drop, and the split “cat ∈ s or cat ∉ s” needed the part s to be settled. So the honest count is of the parts that are.

From here on, for a part s of a set X, the statement “s is settled” means:

This is 4h's word “settled”, said now of a part of any set: for a part of ℕ it is 4h's line, and said of a statement the word keeps 1f's meaning.

Settled-parts technique: a set with n members has 2ⁿ settled parts.

Example: {Gomez, Finn} has 2² = 4 settled parts: ∅, {Gomez}, {Finn} and {Gomez, Finn}.

Plan: match the settled parts of X with the functions from X to 2 = {0, 1}, and count the functions.

A part s goes to its keep-or-drop function, which gives 1 at x when x ∈ s and 0 when x ∉ s (a rule by cases on a settled statement). A function h goes back to the part {x ∈ X : h(x) = 1}, which is settled by settled-order. Counted-functions counts the functions: 2ⁿ.

Every listed part of a finite set is settled, by finite-is-settled. Rung 7 makes every part settled, and then 𝒫(X) itself has 2ⁿ members.

4k11Arrangements and Factorials

From here on, names f(n), where f is fixed by counted-recursion with start f(0) = 1 and step f(S(n)) = S(n) · f(n). Read it “n factorial”.

Example: 1! = 1, 2! = 2, 3! = 6, 4! = 24, 5! = 120, and by 10, 10! = 3628800.

The start is 1 for the reason 4g gave for power-zero: an empty product is the do-nothing of multiplying.

From here on, an arrangement of a set X with n members is a matching between n and X: the member paired with 0 stands first, the member paired with 1 next, and so on.

Arrangements technique: a set with n members has n! arrangements. You have met this lining up: the first place has n people to choose from, the next one fewer, and so on.

Plan: induct on n. Choose who stands at the last place, then arrange the rest.

\begin{aligned}&n = 0:\ \ \text{one arrangement,}\\ &\quad\text{the empty matching};\ \ 0! = 1\end{aligned} @@ counted-recursion's start
X \text{ has } S(n):\ \ \text{who stands at place } n?\ \ S(n) \text{ choices} @@ X has S(n) members
\qquad \text{then arrange } X ∖ \{x\} \text{ on the places of } n:\ \ n! \text{ ways} @@ the lead-one-out technique; the hypothesis
\qquad f \mapsto (f(n),\ f \text{ on } n) \text{ is a matching} @@ back: (x, g) ↦ g ∪ {(n, x)}
\qquad S(n) \cdot n! = \htmlClass{new}{S(n)!} \quad \blacksquare @@ the stages-multiply technique; counted-recursion's step; the induction technique

Stopping after the first few places works the same way. Gold, silver and bronze among 8 runners: 8 · 7 · 6 = 336 ways, by stages-multiply twice; and arranging the other 5 afterwards, 336 · 5! = 40320 = 8!.

The accepted name for an arrangement is a permutation, from the Latin permutare, “to change thoroughly”.

4k12The Choosing Table

From 5 people, how many committees of 2? A committee has no order: {Zoe, Randy} is {Randy, Zoe}. Counted with order there are 5 · 4 = 20 pairs, and each committee was counted twice, once in each order: 20 = 10 · 2. So 10 committees.

The number of k-member parts of a set with n members could be defined that way. But there is a cleaner start: ask about one member at a time, which gives a table.

From here on, (read “n choose k”) names the entry at k of row n of the table fixed by recursion and counted-recursion as follows. Row 0 has 1 at 0 and 0 everywhere else. In each next row, the entry at 0 is 1, and the entry at S(k) is the entry at k plus the entry at S(k) of the row before. This is the choosing table.

Here a row is a function from ℕ to ℕ and its entries are its values. 1e's rows of a table, 2h's entries of a pair and 4i's entries of a list keep their meanings.

(The rows are functions from ℕ to ℕ, members of a sift of 𝒫(ℕ × ℕ). Recursion takes each row to the next, and counted-recursion builds each next row.)

The defining lines are techniques. Choose-edges technique: every row starts with 1, and row 0 is 1 followed by 0s. In marks: and .

And the table's own step, the row-step technique: an entry after the start of a row is the entry above it plus the one before that.

Two short inductions give the choose-ends technique: past the end of row n every entry is 0, and the last entry of row n is 1. In marks, the first when n < k:

4k13Choosing Counts Parts

Now the meaning. Choosing-counts-parts technique: a set with n members has exactly parts with k members.

Example: {Gomez, Finn, Serena} has 3 choose 2 = 3 parts with 2 members: {Gomez, Finn}, {Gomez, Serena} and {Finn, Serena}.

4k14The Product Identity

Now the product identity, which says that counting with order counts each choice a fixed number of times. Arrange all k + j members of a set and call the first k places the chosen part. Each k-member part turns up once for every arrangement of itself and every arrangement of the j left behind.

Product-identity technique: choosing k of k + j things, then arranging the k chosen and the j left, counts every arrangement of all k + j once.

Plan: induct on n = k + j, splitting the table entry by row-step.

\varphi(n):\ \forall k\,\forall j\ \big(k + j = n \Rightarrow \tbinom{n}{k} \cdot k! \cdot j! = n!\big) @@ the condition
n = 0:\ \ k = j = 0,\ \ 1 \cdot 1 \cdot 1 = 1 = 0! @@ a sum is 0 only when both are (zero-or-a-next, plus-a-next, next-never-empty); choose-edges
k = 0:\ \ \tbinom{S(n)}{0} \cdot 0! \cdot S(n)! = S(n)! @@ choose-edges; counted-recursion's start; one-changes-nothing. And j = 0 the same, by choose-ends
k = S(k'),\ \ j = S(j'):\ \ k' + j = n = k + j' @@ next-on-the-left for plus, plus-a-next; different-nexts
\qquad \tbinom{S(n)}{k} \cdot k! \cdot j! = \tbinom{n}{k'} \cdot k! \cdot j! + \tbinom{n}{k} \cdot k! \cdot j! @@ row-step; spread for times over plus (with turn-about for times)
\qquad \phantom{=} = \big(\tbinom{n}{k'} \cdot k'! \cdot j!\big) \cdot k + \big(\tbinom{n}{k} \cdot k! \cdot j'!\big) \cdot j @@ counted-recursion's step for k! and j!; regroup for times, turn-about for times
\qquad \phantom{=} = n! \cdot k + n! \cdot j = n! \cdot S(n) = \htmlClass{new}{S(n)!} @@ the hypothesis, twice; spread for times over plus; k + j = S(n); turn-about for times and counted-recursion's step
\forall n\;\varphi(n) \quad \blacksquare @@ the induction technique

Three consequences. Choosing the k who serve is choosing the j who don't:

4k15A Sum Raised to a Power

4g warned that (p + b)² is not p² + b². Here is what it is, for every power.

Example: multiply out (p + b) · (p + b) · (p + b) by spread for times over plus. Each term comes from choosing p or b in each bracket, a word like p·p·b or b·p·b, and there are 2³ = 8 words. The words with one b are p·p·b, p·b·p, b·p·p, one for each choice of the bracket that gives b. That is words, and each is p² · b by turn-about for times and regroup for times. So (p + b)³ = p³ + 3 · p² · b + 3 · p · b² + b³, with row 3 as the counts.

Two-term-power technique: row n of the table gives the counts of the terms when a sum of two numbers is raised to the n.

(The j exists by at-most-is-adding, since k ≤ n, and there is one by cancel for plus.)

Plan: induct on n, moving terms of sums about. It needs three techniques about Σ, each a short induction on the length, step by regroup for plus, turn-about for plus or spread for times over plus.

Termwise technique: sums add term by term. Factor-out technique: a factor of every term comes out of the sum. First-term-off technique: a sum of S(n) terms is its first term plus the sum of the rest. In marks, in that order:

Anexact, yet rigorous · counting

Random things in a crowd make smooth, steady patterns, and counting is the first tool that shows the pattern. Toss 4 coins. Which coins land heads is a choice of some of the 4, so the ways to get k heads number 4 choose k: 1, 4, 6, 4, 1, out of 16 ways in all. The counts pile up in the middle. 6 of the 16 ways give two heads, and 14 of the 16 give one, two or three. You cannot say what 4 coins will do. You can say the shape of the pile.

The spread is part of the answer, not noise around it.

A leaf falling at random lands anywhere; a thousand leaves land in a pile with a definite shape. The pile is the counting done for you.

Toss 10 coins. How many of the 1024 ways give between 3 and 7 heads? What does the answer say about where 10 coins usually land?

4k17Running It Backwards

Given a count, find the question's numbers.

Example: if 15 pairs can be formed from a group, how many are in it? Call the number m + 1. The pairs counted with order number (m + 1) · m, each pair twice, so (m + 1) · m = 2 · 15 = 30. The two neighbouring numbers whose product is 30 are 6 and 5: there are 6.

In (p + b)⁷, which terms have count 35? Row 7 is 1, 7, 21, 35, 35, 21, 7, 1: two of them, p⁴ · b³ and p³ · b⁴, the same choice read from either end.

Wanting the number of members of a set, find a matching with a number, or split the set into separate piles (separate-piles) or into stages (stages-multiply). Wanting to show two counts agree, match the two sets, as choosing-counts-parts matched the parts with Zoe to the parts of the rest. Found upward; written downward.

How many, in marks alone

Before any number is built, every, some and = can already say “at least two”, “at most one” and “exactly one”. At least two A: two letters, and a line saying that they do not name one thing; without that line the two letters may both name the same apple. At most one A: any two A are one thing. Exactly one: both at once, which is 2b’s cellar ∃!.

Each further count needs one more letter and one more clash of names, so “exactly n” for every n is an endless family of lines, one per number. The matching of this step replaces the family by one statement, “X is matched with n”, with the number doing the counting.

Accepted names

A matching is also called a one-to-one correspondence, or a bijection. Separate-piles is the addition principle, and stages-multiply the multiplication principle. An arrangement is a permutation, and a part with k members picked from n is a combination. The choosing table is Pascal's triangle, after the look of its rows when they are set out evenly under each other; triangle is a geometry word, and the ladder has not built geometry yet, but the name stands. The two-term-power technique is the binomial theorem: a two-term sum is a binomial, and the entries of the table, which stand in front of the terms of its powers, are the binomial coefficients.
