12a · proof

The Intermediate Value Technique

A function continuous on a closed interval, below 0 at the left end and above 0 at the right end, is 0 somewhere between. This step lays down the words the statement needs. It reads 11a's interval form of continuity as one promise. It proves that a continuous function keeps its sign near an input. Then it proves the technique by the least upper bound of the inputs where the function is still below 0, every line cited. Then 0 stops being special: any value between the two end values is taken. Last, what the technique does not say.

Gather the inputs where the function is still below 0, and take their least upper bound. Above 0 there would put a gathered input inside a window where the function is above 0. Below 0 there would gather an input past the bound. So the function is 0 at the bound.

12a1Words for the Statement

8g wrote [c, d] for the reals from c to d with both ends kept and (c, d) for the reals strictly between. This rung leans on the difference, so the two get names.

From here on, for reals c < d, 8g's interval [c, d] is called a closed interval, and 8g's (c, d) is called an open interval. A closed interval keeps both its ends; an open interval keeps neither. In [c, d] the entries are reals with c < d. It is 8g's interval, never 5b's class [m, n] of a pair of numbers, and what stands inside says which. On this ladder “closed interval” means [c, d] with both ends reals; [c, ∞) is not one.

A reuse, said out loud: square brackets have had jobs before. 2h's [x] and 5b's [m, n] name classes, and in a line of working a bracket groups. 8g gave [c, d] its interval meaning and this step keeps it; the older jobs keep theirs elsewhere. The sign of which job is meant: two reals c < d with a comma between, where a set of reals is wanted, is the interval.

So [1, 2] is closed and (1, 2) is open, and [1, 2) is neither: it keeps one end. Take a function continuous on [v, w], in 11a's interval form. It is continuous at every input strictly between v and w, continuous from the right at v, and continuous from the left at w. That is 11f's demand of no discontinuity on the whole interval, with the ends asked only from the inside.

From here on, for a function f whose outputs are reals, a zero of f is an input c of f with f(c) = 0. It is 9g's word for polynomials, said now of any such function. It is also called a root of f, or a solution of the equation f(x) = 0.

Reuses, said out loud. The word zero has named the number 0 since 3c, and a zero of a polynomial since 9g. The number keeps its name, and “a zero of f” always has “of f” after it and names an input. The word root has named 8f's √u and ⁿ√u. A root of f is an input where f is 0. The two uses agree where they meet, since √u is the root of x ↦ x² − u that is not negative.

The technique, in words: a function continuous on a closed interval, with a negative value at the left end and a positive value at the right end, has a zero strictly between them. Its accepted name is the intermediate value theorem. It was first proved in a paper of 1817.

The 1817 paper objects that the usual proof borrows a truth from geometry: that a continuous line passing from below another to above it must meet it. That is a fact about lines used to prove a fact about functions. The order of the sciences, it argues, runs the other way. The fact about functions should be proved first, from the nature of quantity alone.

12a2Continuity on [v, w], Read as One Promise

The interval form has three kinds of input, and a proof that has to visit all three every time gets long. One technique folds them into a single promise about the inputs of the interval.

Closed-interval-continuity technique: continuity on a closed interval is one promise, made alike at every input, ends included. Precisely: let f be continuous on [v, w], and take c ∈ [v, w] and ε > 0. Then there is δ > 0 such that every x ∈ [v, w] with |x − c| < δ has |f(x) − f(c)| < ε.

\text{let } c \in [v, w];\ \ \text{let } \varepsilon \gt 0 @@ speak of everything, twice
v \le c \le w @@ 8g's line for [v, w]
c = v \;\lor\; v \lt c \lt w \;\lor\; c = w @@ three-way-order on ℝ (8b) on v and c, and on c and w: rung 7's either-way principle
\text{case } v \lt c \lt w:\ \ \text{call } \delta:\ \forall x \in \operatorname{dom} f\ (|x - c| \lt \delta \Rightarrow |f(x) - f(c)| \lt \varepsilon) @@ continuous at c (the interval form), unpacked by continuity-unpacked (11a)
\qquad x \in [v, w] \Rightarrow x \in \operatorname{dom} f @@ [v, w] is an interval of inputs: the promise is kept on it
\text{case } c = v:\ \ \text{call } \delta:\ \htmlClass{new}{v \le x \lt v + \delta} \Rightarrow |f(x) - f(v)| \lt \varepsilon @@ continuous from the right at v: continuity-unpacked side by side (11a)
\qquad x \in [v, w] \land |x - v| \lt \delta \;\Rightarrow\; v \le x \lt v + \delta @@ x ≥ v since x ∈ [v, w]; x − v < δ by unpack-the-bars (8h)
\text{case } c = w:\ \ \text{the same column, from the left} @@ continuous from the left at w: w − δ < x ≤ w
\forall x \in [v, w]\ (|x - c| \lt \delta \Rightarrow |f(x) - f(c)| \lt \varepsilon) \quad \blacksquare @@ reasoning by cases; show an example of δ; speak of everything

The end cases are the reason for 11a's care. At the left end, nothing to its left is asked about, because nothing to its left is in the interval. Closed-interval-continuity is the only place in this step where the three kinds of input are told apart; every later column cites closed-interval-continuity and treats every member of the interval alike.

12a3The Sign Is Kept Near an Input

10b's sign-kept-near said that a limit that is positive makes the outputs positive near the input. Continuity puts the value in the limit's place and lets the input in.

Sign-kept-near-an-input technique: if f is continuous on [v, w], c ∈ [v, w] and f(c) > 0, then there is δ > 0 with f(x) > 0 for every x ∈ [v, w] with |x − c| < δ. Likewise, if f(c) < 0, there is δ > 0 with f(x) < 0 for those x.

\varepsilon = \htmlClass{new}{f(c)} \gt 0 @@ challenge with the value itself
\text{call } \delta:\ x \in [v, w] \land |x - c| \lt \delta \Rightarrow |f(x) - f(c)| \lt f(c) @@ closed-interval-continuity
-f(c) \lt f(x) - f(c) @@ unpack-the-bars (8h): the lower half of the unpacked bars
0 \lt \htmlClass{new}{f(x)} \quad \blacksquare @@ add f(c) to both sides: order-and-arithmetic-agree (8d). For f(c) < 0 take ε = −f(c) and use the upper half

10b said rung 12 would lean on sign-kept-near; this is the lean. With ε = f(c) the band around f(c) reaches down exactly to 0, and continuity keeps every nearby output inside the band, so above 0.

12a4The Proof, Every Line Cited

In-between-value technique (the intermediate value theorem): if f is continuous on [v, w] and f(v) < 0 < f(w), then f has a zero c with v < c < w. In marks: f(v) < 0 < f(w) ⇒ ∃c (v < c < w ∧ f(c) = 0).

v \in A @@ v ∈ [v, w], and f(v) < 0: ︿ the sift
\forall x \in A\ (x \le w) @@ ﹀ x ∈ [v, w]: w is an upper bound of A (8c's line)
\htmlClass{new}{\sigma = \sup A} @@ no-holes (8c): A has a member and an upper bound. The one line that needs rung 8's no-holes

f(x) \lt 0, \text{ so } x \in A @@ the window; ︿ the sift

\exists c\ (v \lt c \lt w \;\land\; f(c) = 0) \quad \blacksquare @@ show an example: c = σ

Notice where each hypothesis was spent. No-holes made σ exist, at one marked line. Continuity entered only through sign-kept-near-an-input, which made each wrong case impossible. Above 0 at σ would keep the function above 0 on a window around σ, and “least” puts a member of A in that window. Below 0 at σ would keep the function below 0 a little past σ, and then A would reach past its own upper bound. The closed interval made the values at both ends exist, and kept σ among the inputs. It let sign-kept-near-an-input work at σ even when σ might have been an end. And rung 7's either-way principle entered three times: the three-way split of f(σ), the turn from “not an upper bound” to “a member beyond”, and the splits inside closed-interval-continuity.

Notice too which zero you found. Every member of A is at most σ, so to the right of σ the function is never below 0. σ is the last input at which the function comes up from below 0. A function with several zeros has σ at one of them, and the technique does not say which. A different set finds the first zero instead: the inputs x such that f is below 0 at every input of [v, w] up to x. The picture has both.

12a5Any Value Between

0 is not special. Move the target, and the technique applies to any height between the two end values.

In-between-value technique, general form: any height between the two end values is taken. Precisely: let f be continuous on [v, w]. Let y be a real between f(v) and f(w), that is f(v) < y < f(w) or f(w) < y < f(v). Then f(c) = y for some c with v < c < w.

\text{case } f(v) \lt y \lt f(w):\ \ g(x) = \htmlClass{new}{f(x) - y} @@ 10c's f − g with the constant y: a function on dom f
g \text{ continuous on } [v, w] @@ continuous-sums (11b) with the constant y (lines-are-continuous), side by side at the ends
g(v) = f(v) - y \lt 0 \lt f(w) - y = g(w) @@ order-and-arithmetic-agree: α < β exactly when β − α is positive
\text{call } c:\ v \lt c \lt w,\ \ g(c) = 0 @@ the in-between-value technique, applied to g
f(c) = y @@ add y to both sides of f(c) − y = 0 (adding-keeps-answers read in ℝ)
\text{case } f(w) \lt y \lt f(v):\ \ h(x) = \htmlClass{new}{y - f(x)} @@ continuous-sums and constant-factor: continuous on [v, w]; h(v) < 0 < h(w); in-between-value gives h(c) = 0, so f(c) = y. ∎

In words: a function continuous on a closed interval takes every value between its two end values. Its curve, a set of pairs, has a pair at every height between the heights of its first and last pairs. It does not skip.

Anexact, yet rigorous · the middle of a change, proved

6·chem, 10·bio and 11·chem met a principle of the second kind of care: things do not jump between states, they pass through a middle. 11·chem measured the slush at 0 °C. This step proves the mathematical side of it. A continuous change from below 0 to above 0 passes through 0. It cannot get from one side to the other without a middle.

A continuous change has a middle, even when no one catches it there.

The proof does not say where the middle is. It says only that the middle is there, and that is enough to go looking. Where a change does jump, as the step u does, the technique is silent. Continuity is the promise that no jump happens.

At 6 a.m. the air in Redding is 58 °F, and at 2 p.m. it is 97 °F. Was there a moment when it was exactly 80 °F? Could any thermometer show you that moment?

12a6What the Technique Does Not Say

It does not say where, and it does not say how many. q(x) = x³ − 3x + 1 on [−2, 2] has q(−2) = −1 and q(2) = 3. The technique promises one zero, and q has three, near −1.88, 0.35 and 1.53. Equal signs at the two ends promise nothing either way. x² − ¼ on [−1, 1] is positive at both ends and has two zeros. x² + 1 is positive at both ends and has none.

It needs both of its words. Without continuity: take u(x) − ½, with 11a's step u. It is −½ at −1 and ½ at 1, continuous at every input but 0, and never 0: the step skips over it. Without the whole closed interval: 1/x is −1 at −1 and 1 at 1. But [−1, 1] is not an interval of its inputs, because 0 is not an input. 1/x is continuous, and it skips 0 at its discontinuity.

And it does not run backwards. Let f(x) = x for x ∈ [0, 1] and f(x) = x − 1 for x ∈ (1, 2]. Then f(0) = 0 and f(2) = 1, and every value between is taken, already on [0, 1]. But from the left f heads to 1 at 1 and from the right to 0: a jump (11f), so f is not continuous on [0, 2]. Taking every value between the end values does not make a function continuous.

12a8Running It Backwards

Handed an equation and asked whether it has an answer, move everything to one side to get f(x) = 0. Look for two inputs whose values have opposite signs. Check that f is continuous on the closed interval between them. Then the technique says yes, with an answer between. Handed a value to reach, check that it lies between two values already reached. Handed a supposed counterexample, find which hypothesis it lacks: a discontinuity, a missing end, or values of the same sign. Found upward; written downward.

Who said it first

The paper of 1817 is Bernard Bolzano’s, published in Prague, and the in-between-value technique is also called Bolzano’s theorem. The pamphlet of question 12a.4.4 is the same paper.

Bolzano objects that the usual proof borrows a truth from geometry, that a continuous line passing from below another to above it must meet it. That is a fact about lines used to prove a fact about functions, and he argues that the order of the sciences runs the other way: the fact about functions should be proved first, from the nature of quantity alone.
