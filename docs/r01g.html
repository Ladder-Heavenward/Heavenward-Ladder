Too Many Rows

The tables of 1e settle a statement by trying every way its letters can come out. That is exact, and it is slow. This step shows why the ladder stops writing tables once the list of 1f is in hand.

Each new letter doubles the rows. A technique does in one line what a table does row by row.

1g1Each New Letter Doubles the Table

A table needs one row for every way the letters can come out, and each new letter doubles that. One letter gives two rows: true, or false. Two letters give four. Three give eight, and four give sixteen.

Every row has to be worked by hand. A statement built from a handful of short statements already asks for more rows than anyone wants to fill in.

1g2Stringing and Nesting Add More

Stringing steps together brings their letters together, so the rows multiply. Nesting one operator inside another adds a column, and every column has to be worked in every row.

A proof of any length strings and nests all the time. A table for the whole of it would be far too much work to get through.

1g3A Technique Does It in One Line

A rewrite by hand settles in one line what a table settles row by row. The not-through techniques, pushing a not inward through an and or an or, were checked once by their tables. From then on you rewrite with them and cite them, and no row is written.

This is safe because the tables agree with the techniques (1e). A move the list allows never takes a row that holds to a row that fails.

1g4What a Table Still Does

The table does not go away. It is where a technique was checked, and it is where you go back when a rewrite looks wrong. But the work is done with techniques, the way “it is raining” is said without counting drops.

Anexact, yet rigorous · the technique that packs the rows

A technique packs every row of its table into one line. It counts no rows, and it holds in every one.
