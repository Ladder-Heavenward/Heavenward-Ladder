Dividing With Several Letters

Is x²y + xy² + y² in the ideal (xy − 1, y² − 1)? In one letter, divide and look at the remainder (44c). In several letters, division works but the remainder depends on the order of the divisors, so a nonzero remainder proves nothing. A good set of makers, one whose tops make the ideal of all tops, gives one remainder whatever the order. Such sets can be built by a finite procedure, and they test membership, solve systems, and remove letters. This step divides, builds a good set, and removes a letter from a curve.

Order the terms (x before y, then by powers). Divide f by f₁, …, fₖ: cancel any top divisible by a divisor’s top. A good set G for I has the tops of G making all tops of I; then the remainder is one, and it is 0 exactly when f ∈ I. Remove letters: with t first, the members of a good set free of t make I ∩ F[x, y]. From x = t², y = t³: y² − x³.

45h1A Remainder That Depends on the Order

\text{divide by } xy - 1 \text{ first, then } y^2 - 1:\ \text{remainder } x + y + 1 @@ cancel tops while you can
\text{divide by } y^2 - 1 \text{ first, then } xy - 1:\ \text{remainder } 2x + 1 @@ another remainder
(x + y + 1) - (2x + 1) = y - x @@ their difference is in the ideal
\htmlClass{new}{\text{a nonzero remainder does not prove } f \notin I} @@ these makers are not good

Many-letter division technique: f = q₁f₁ + ⋯ + qₖfₖ + r, with no term of r divisible by any top; but r can change with the order of the divisors.

45h2A Good Set of Makers

\text{tops of } G \text{ make the ideal of all tops of } I @@ the condition
\text{then the remainder on dividing by } G \text{ is one, whatever the order} @@ two remainders differ by a member with no reducible term
f \in I \iff \text{remainder} = 0 @@ membership
\htmlClass{new}{\text{build } G:\ \text{add the remainder of each pair’s cancelling combination, until all are } 0} @@ stops, since rising chains of top ideals stop (45a)

Good-set technique: every ideal has a finite good set of makers, built by repeatedly adding the remainders of the cancelling combinations of pairs; dividing by it gives one remainder, which is 0 exactly for members of the ideal.

45h3Removing a Letter

I = (x - t^2,\ y - t^3) \text{ in } F[t, x, y] @@ t before x and y
y^2 - x^3 = (y - t^3)(y + t^3) - (x - t^2)(x^2 + xt^2 + t^4) @@ a member free of t
I \cap F[x, y] = (y^2 - x^3) @@ from a good set with t first
\htmlClass{new}{\text{the curve traced by } (t^2, t^3) \text{ is } y^2 = x^3} @@ the sharp curve (45f3)

Remove-a-letter technique: with the letters to be removed ordered first, the members of a good set that are free of them make the ideal of all members free of them; so the equations of a traced curve can be found by machine.

Accepted names

A good set is a Gröbner basis; the procedure is Buchberger’s algorithm, and the cancelling combinations are S-polynomials; removing letters is elimination theory. The order is a monomial order, here lexicographic.

Who said it first

Bruno Buchberger built the procedure in his thesis of 1965 and named it after his adviser Wolfgang Gröbner. Heisuke Hironaka found the same idea in 1964 for power series.
