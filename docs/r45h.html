45h · proof

Agreement by Lottery

45g counted machines. In a network anyone may join, one person can run a thousand machines, and counting fails. This step replaces votes with work, and certainty with a chance that grows as close to 1 as you wait for.

Win the right to write by finding a rare number; follow the chain with the most work. An attacker behind by z blocks catches up with chance (q/p)ᶻ.

45h1Win the Right to Write

To add a block of entries, a machine must find a number that, mixed with the block by a scrambling function, lands below a target. No better way is known than trying numbers one by one. So the chance of winning is in proportion to the tries made, which is to say to the work done.

Votes become work: a thousand machines win no more often than the same total work in one.

45h2Follow the Most Work

Each block names the block before it, so blocks form a chain. Every machine follows the chain with the most work in it. To change a block deep in the chain, an attacker must redo that block and every block after it, while everyone else keeps adding.

45h3Final Only by Chance

Let the honest machines do a fraction p of all work, with p > 1/2, and an attacker the rest, q = 1 − p. Each new block is honest with chance p. The attacker’s gap shrinks by 1 with chance q and grows by 1 with chance p.

Catch-up technique: an attacker z blocks behind ever draws level with chance (q/p)ᶻ.

Let h(z) be that chance. Then h(0) = 1, and h(z) = q·h(z − 1) + p·h(z + 1). The function (q/p)ᶻ meets both, since q(q/p)ᶻ⁻¹ + p(q/p)ᶻ⁺¹ = (q/p)ᶻ(p + q) = (q/p)ᶻ. It also goes to 0 as z grows, as a chance of catching up from far behind must. So a block z deep is final with chance 1 − (q/p)ᶻ, near 1 and never equal to it.

45h4Back to Quorums

Where the members are known, the lottery is not needed. Methods that keep a list of members return to 45g’s two-thirds quorums, and a block is final as soon as a quorum signs it.

The accepted names

This is proof of work, and following the chain with most work is Nakamoto consensus. A list of blocks each naming the one before is a blockchain. Methods with known members and two-thirds quorums include Tendermint. The catch-up technique is the gambler’s ruin.
