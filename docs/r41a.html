41a · proof

Machines With a Tape

Rung four said what a recipe for answers is made of: a state, a start, a stop test, a move and an output. It never said what a move is allowed to do, and so it never said which recipes there are. Rung thirty eight built a machine that follows a list, from switches, and counted its steps. That machine is real, and it is messy: it has a memory of a fixed size, an adder, a counter, and a list of instructions that are themselves numbers. This step strips it down until nothing is left but what a recipe needs. A long strip of cells, each holding one mark. A head that sees one cell. A short table that says, for what the head sees and the state the machine is in, what to write, which way to step, and which state to go to. That is all. It looks too weak to do anything. The step shows it computes, decides and lists, that more strips add no reach, and then it names the guess the whole rung stands on: that whatever a person could compute by following rules, such a machine computes too. That guess is not proved. It is a thesis, and this step says why it cannot be anything more, and why it is believed.

A tape machine reads one cell, writes one mark, steps one cell, and changes state by a finite table. Each configuration has one next. Such machines compute functions, decide sets and list sets, and a set is decided exactly when it and its outside are both listed. Many tapes do no more than one. The thesis says these machines compute whatever a recipe computes.

41a1A Tape and a Table

7·then met a rulebook machine on a strip of 0s and 1s. Here it gets any marks, an input and an output. A tape machine has a finite set Γ of marks, among them the blank ⊔, and a finite set of states, among them a start state and the stop states. Its table δ gives, for each state that is not a stop state and each mark, three things: a mark to write, a step L or R, and a next state. The tape is a row of cells endless to the right, each holding one mark, all blank but finitely many.

A configuration is the whole situation at one moment: the state, the tape, and the cell the head is on. Write it u q v: the tape reads uv, the machine is in state q, and the head is on the first mark of v. The input w is written at the left, the rest blank, the head on the first cell, the state the start. This is 4l’s recipe made exact. The state of 4l is the configuration. The stop test asks whether the state is a stop state, which is settled by looking. The move is one row of the table. The output is what the tape holds at the stop.

One-next technique: a configuration whose state is not a stop state has exactly one next configuration, and finding it means looking at one cell.

u\,q\,s\,v,\ \allowbreak \ q \text{ not }\allowbreak \text{a }\allowbreak \text{stop }\allowbreak \text{state} @@ the head reads the mark s
\delta(q, s) = (s', \text{R}, q') \text{ is }\allowbreak \text{one }\allowbreak \text{entry} @@ δ is a function (4d2): one value for each pair
u\,q\,s\,v \to u\,s'\,q'\,v @@ write s′, step right, take state q′; v blank means one more blank cell
u\,r\,q\,s\,v \to u\,q'\,r\,s'\,v \text{ for }\allowbreak \text{a }\allowbreak \text{step }\allowbreak \text{L} @@ on the first cell a step L stays put
\htmlClass{new}{\text{one }}\allowbreak \htmlClass{new}{ \text{next }}\allowbreak \htmlClass{new}{ \text{configuration, }}\allowbreak \htmlClass{new}{ \text{from }}\allowbreak \htmlClass{new}{ \text{the }}\allowbreak \htmlClass{new}{ \text{pair } (q, s) \text{ alone}} \quad \blacksquare @@ nothing else of the tape is read

So a run is 4l’s run: run(0) is the start configuration, and run(n + 1) is the next of run(n) until a stop state comes. One example first, adding 1 to a number written in twos (4i). State r walks right to the first blank, then turns into c. In state c a 1 becomes 0 with a step left, and a 0 or a blank becomes 1, and the machine stops.

r\,1011 \to 1\,r\,011 \to 10\,r\,11 \to 101\,r\,1 \to 1011\,r\,\sqcup @@ state r on 0 or 1: write it back, step R
1011\,r\,\sqcup \to 101\,c\,1\sqcup @@ on the blank: step L, take c
101\,c\,1 \to 10\,c\,10 \to 1\,c\,000 @@ c on 1: write 0, step L; the carry moves left
\htmlClass{new}{1\,c\,000 \to 1100,\ }\allowbreak \htmlClass{new}{ \text{stopped}} \quad \blacksquare @@ c on 0: write 1, stop; eleven plus one is twelve

Eight steps for four digits. The count grows with the length of the input, as 39k’s counts did. What the table cannot do is look at two far cells at once: everything it learns, it learns by walking.

41a2Computing, Deciding, Listing

A machine computes a function f on strings when, started on any input w, it stops with f(w) on the tape. Give a machine two stop states, yes and no. It decides a set A of strings when it stops on every input, in yes exactly on the members of A. It lists A when it stops in yes exactly on the members of A; on other strings it may stop in no, or never stop at all.

Reuse, said out loud. 7c called a statement decidable when a constructive column proves it or its denial. From here on a set of strings is decidable when some tape machine decides it. The new meaning fits the old: for each input the run of the machine is a column, step by step, that reaches one answer. Where the two might part, the page says which it means.

Both-sides technique: a set is decided by a machine exactly when the set and the strings outside it are both listed.

M \text{ decides } A @@ suppose it
M \text{ lists } A;\ \allowbreak \ M \text{ with }\allowbreak \text{yes }\allowbreak \text{and }\allowbreak \text{no }\allowbreak \text{swapped }\allowbreak \text{lists }\allowbreak \text{the }\allowbreak \text{outside} @@ M stops on every input
M_1 \text{ lists } A,\ \allowbreak \ M_2 \text{ lists }\allowbreak \text{the }\allowbreak \text{outside} @@ now suppose the other way
\text{run } M_1, M_2 \text{ on } w \text{ in }\allowbreak \text{turns, }\allowbreak \text{one }\allowbreak \text{step }\allowbreak \text{each} @@ two tapes, one each; 41a3 makes them one
w \in A \text{ or } w \notin A,\ \allowbreak \text{so }\allowbreak \text{one }\allowbreak \text{of }\allowbreak \text{them }\allowbreak \text{stops} @@ either-way, on a string and a set (7e)
\htmlClass{new}{\text{answer }}\allowbreak \htmlClass{new}{ \text{yes }}\allowbreak \htmlClass{new}{ \text{if } M_1 \text{ stopped }}\allowbreak \htmlClass{new}{ \text{in }}\allowbreak \htmlClass{new}{ \text{yes, }}\allowbreak \htmlClass{new}{ \text{else }}\allowbreak \htmlClass{new}{ \text{no}} \quad \blacksquare @@ the run stops on every w, and is right

The proof does not say how long to wait. It says only that the wait ends. That is the gap between listing and deciding: a lister that has not stopped tells you nothing yet. 38b’s proof-listing technique gave a lister of what a collection reaches. Whether a decider can be built from it is 41e’s question.

41a3More Tapes, No More Reach

A machine with k tapes has k heads and a table that reads k marks at once. It is easier to program: the turn-taking of 41a2 wants one tape for each machine. It computes nothing new.

Tracks technique: for every machine with k tapes there is a machine with one tape that computes the same function, and if the first takes t steps on an input of length n, the second takes at most about t(n + t) steps.

\text{one }\allowbreak \text{cell }\allowbreak \text{of }\allowbreak \text{the }\allowbreak \text{new }\allowbreak \text{tape }\allowbreak \text{holds }\allowbreak \text{a }\allowbreak \text{column }\allowbreak \text{of } k \text{ marks, }\allowbreak \text{each }\allowbreak \text{with }\allowbreak \text{a }\allowbreak \text{head }\allowbreak \text{flag }\allowbreak \text{or }\allowbreak \text{not} @@ the marks are the lists of k old marks and flags: still a finite set
\text{a }\allowbreak \text{sweep }\allowbreak \text{right }\allowbreak \text{reads }\allowbreak \text{the } k \text{ flagged }\allowbreak \text{marks }\allowbreak \text{into }\allowbreak \text{the }\allowbreak \text{state} @@ finitely many lists of k marks: finitely many states
\text{a }\allowbreak \text{sweep }\allowbreak \text{left }\allowbreak \text{writes }\allowbreak \text{and }\allowbreak \text{moves }\allowbreak \text{each }\allowbreak \text{flag} @@ one row of the old table
\text{after } t \text{ old }\allowbreak \text{steps }\allowbreak \text{no }\allowbreak \text{head }\allowbreak \text{is }\allowbreak \text{past }\allowbreak \text{cell } n + t @@ each step moves a head one cell
\htmlClass{new}{\text{each }}\allowbreak \htmlClass{new}{ \text{old }}\allowbreak \htmlClass{new}{ \text{step }}\allowbreak \htmlClass{new}{ \text{costs }}\allowbreak \htmlClass{new}{ \text{at }}\allowbreak \htmlClass{new}{ \text{most }}\allowbreak \htmlClass{new}{ \text{about } 2(n + t) \text{ new }}\allowbreak \htmlClass{new}{ \text{steps}} \quad \blacksquare @@ two sweeps over the used stretch

So a machine that takes n² steps on k tapes takes about n⁴ on one. 39k’s growth families matter here: the slowdown squares the count, and a count that was a power of n stays a power of n. The same kind of argument gives a tape endless both ways, more marks, or a head that may stay put, and none of them reaches further. 41h leans on this when it says that fast does not depend on which machine.

41a4A Thesis, Not a Technique

Here is the claim the rung needs. Whatever a person can compute by following a finite list of rules, with pencil and paper and no insight, some tape machine computes. It is called a thesis. It cannot be a technique, because one side of it, following a list of rules, was never made exact: 4l named the five parts of a recipe and never said which moves are allowed. If it were made exact, the exact version would be a new definition, and the thesis would be the claim that the definition caught the loose word.

Two kinds of evidence hold it up. The first is an analysis of a person computing. They are in one of finitely many states of mind. They look at a bounded patch of paper and change a bounded patch. They shift their attention a bounded distance. Each such step is a few rows of a table, and the tracks technique packs the paper into a tape. The second is what 41b finds: every other exact try at the word, made by people working apart, reaches exactly the same functions.

Anexact, yet rigorous · loose, then locked

The word recipe was gathered loose: gcd, counting on, writing in twos, the proof-check of 38b, all called recipes because they felt alike. The tape machine locks it. From here on “a recipe computes f” is said to mean “a tape machine computes f”, and it is the lock, not the loose word, that the proofs of this rung use.

Lock the word before you prove anything about it, and say which side of the lock each claim is on.

Unlocking runs the steps backward, and here it cannot be done. The lock does not prove it caught every loose recipe. No one has found a recipe it missed in ninety years, and no count of such years would prove it.

A spreadsheet in Sacramento recalculates a budget whenever a cell changes. Is that a recipe in 4l’s sense? Which of its parts would you need to lock before a tape machine could be said to do the same?

Without the thesis nothing on this rung breaks as mathematics. What breaks is what it means. 41d proves that no tape machine decides which tape machines stop. Only with the thesis does that become: no recipe at all does.

The cellar · there if you want it

The accepted names

A tape machine is a Turing machine; its table is the transition function, a configuration is an instantaneous description, and the stop states are halting states, accepting and rejecting. A function a machine computes is computable, or recursive, and a set a machine decides is decidable or recursive. A set a machine lists is recognizable, or recursively enumerable, or computably enumerable, the name 38·now2 used. The both-sides technique is often stated as: a set is decidable exactly when it and its complement are recognizable. A machine with k tapes is a multitape Turing machine, and the tracks technique says it is simulated with quadratic slowdown. The thesis is the Church–Turing thesis.

Who said it first

Alan Turing described the machine in “On computable numbers, with an application to the Entscheidungsproblem”, written in 1936 and published in 1936 and 1937. His machine stood for a person computing, then called a computer, and his analysis of that person’s states of mind is the first kind of evidence in 41a4. Emil Post described a nearly identical scheme in 1936, independently. Alonzo Church proposed in 1936 that the functions of his λ-calculus (41b) are exactly the effectively calculable ones; Stephen Kleene named the claim Church’s thesis in 1952. Kurt Gödel doubted the earlier proposals and was persuaded by Turing’s analysis. Robin Gandy (1980) asked which physical machines the thesis covers. The view that minds outrun machines was argued by John Lucas (1961) and Roger Penrose (1989).

A proof that is not allowed

“Every recipe anyone has written has been turned into a tape machine. So every recipe is a tape machine.” Not allowed as a proof: it is induction under the small case, a list of cases, and a list of cases is evidence for a law, not a proof of a technique. That is why it is called a thesis, and why 41a4 keeps it apart from the techniques.
