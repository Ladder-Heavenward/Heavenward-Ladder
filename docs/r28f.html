28f · proof

When an Equation Fixes a Function

Step 13l took slopes of curves given by equations, like a circle, by assuming that near a point the curve was the graph of some function. That assumption was held in trust. This step pays it. If an equation ties two quantities together, and the equation really cares about the second one at a point, then near that point the equation fixes the second as a function of the first. The proof builds a map that keeps the first quantity and reports the equation, and undoes it with the last step.

If F(x, y) = 0 at a point, and the slope of F along y is not 0 there, then near that point the equation has exactly one answer y = g(x), and g is smoothly sloped with g′ = −Fx/Fy.

28f1Keep x, Report the Equation

Let F(x, y) be smoothly sloped near (w, b), with F(w, b) = 0 and Fy(w, b) ≠ 0. Build the map that keeps x and reports how far the equation is from holding:

\(G(x, y) = \big(x,\ F(x, y)\big).\)

Fixed-by-an-equation technique: there are an interval I around w and an interval J around b such that for each x in I exactly one y in J has F(x, y) = 0. Calling it g(x), g is smoothly sloped on I.

DG(w,b) = \begin{pmatrix} 1 & 0 \\ F_x & F_y \end{pmatrix},\ \ \det DG(w,b) = F_y(w,b) \ne 0 @@ the slope-grid technique (28b2); the determinant of a stair grid is the product down the middle (27k)
G \text{ has a smoothly sloped undoing } H \text{ near } G(w,b) = (w, 0) @@ the local-undo and undo-slope techniques (28e)
G(x, y) = (x, 0) \iff F(x, y) = 0 @@ the first place of G is x itself
H(x, 0) = (x, g(x)) \text{ for } x \text{ near } w @@ H undoes G, and G keeps the first place
\htmlClass{new}{F(x, g(x)) = 0, \text{ one } y \text{ near } b \text{ for each } x, \ g \text{ smoothly sloped}} \quad \blacksquare @@ g is the second place of H(x, 0), a chain of smoothly sloped maps (28c2)

28f2The Slope of the Fixed Function

Implicit-slope technique: where F(x, g(x)) = 0 and Fy ≠ 0, g′(x) = −Fx(x, g(x)) / Fy(x, g(x)).

\tfrac{d}{dx} F(x, g(x)) = F_x \cdot 1 + F_y \cdot g'(x) @@ the roads-add technique (28c3), roads x and y = g(x); g has a slope by 28f1
\tfrac{d}{dx} F(x, g(x)) = 0 @@ F(x, g(x)) = 0 for every x near w: the constant-has-slope-0 technique (13d)
\htmlClass{new}{g'(x) = -\dfrac{F_x(x, g(x))}{F_y(x, g(x))}} \quad \blacksquare @@ F_y ≠ 0 near (w, b), by continuity (28a1)

For the circle x² + y² = 25 at (3, 4): Fx = 6, Fy = 8, so g′(3) = −3/4. That is 18·cb13’s circle-slope technique, minus the run over the rise, now with its assumption earned. At (5, 0) Fy = 0, the circle stands straight up, and no function of x describes it there.

With m equations in m unknowns y and any number of inputs x, the same lines run with grids: if the grid of slopes of F along the y’s is undoable, the equations fix the y’s as smoothly sloped functions of the x’s, and Dg = −(DyF)⁻¹ DxF.

The accepted names

The fixed-by-an-equation technique is the implicit function theorem; g is the function defined implicitly by F(x, y) = 0. The grid DyF is a partial Jacobian matrix.

Who said it first

Newton and Leibniz took slopes of curves given by equations in the 1670s and 1680s. Cauchy proved an implicit function theorem for power series in 1831, and Ulisse Dini proved the real version in 1876 to 1878. The several-variable form with matrices was set out by Edouard Goursat in 1903.
