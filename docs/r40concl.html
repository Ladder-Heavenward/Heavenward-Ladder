40·∎ · conclusion

Some Questions No Machine Can Answer

Tape machines reach what every exact account of a recipe reaches, and one runs them all. No machine decides stopping, nor any property of what machines do, nor what arithmetic reaches. Decided questions have costs: more time decides more, every NP set reduces to satisfiable statements, and coins err at a rate fixed in advance.

The conclusion · the rung's claim, in full, and its proof

This page opens once every question on 40i is ticked. The claim below is proved from the steps of this rung, so it waits for them.

What the rung set out to show

The survey of rung 40 asked what a recipe is, and what recipes cannot do. No tape machine decides which tape machines stop on which inputs, and none decides any property of what machines do that some machines have and others lack; among the questions that are decided, for every power of n some are decided in a larger power and in none smaller. That “tape machine” means “recipe” is the thesis of 40a’s green box, loose, then locked: evidence holds it up, and no proof does.

40a built the tape machine and locked the word. 40b showed three other accounts reach the same functions. 40c coded machines and built one that runs them all. 40d showed stopping listed and not decided, and 40e carried that everywhere. 40f made machines read their own code. 40g found what machines with less memory miss. 40h counted time and room; 40i added coins, with the green box laws with a known exception rate. This page puts the claim together.

The claim, in full

Each configuration of a tape machine that is not stopped has exactly one next configuration, and a set of strings is decided by a tape machine exactly when it and its outside are both listed. The functions computed by tape machines, with any number of tapes, are exactly the built functions with one search, exactly the functions reached by feeding terms, and exactly the functions whose graphs are search formulas of arithmetic. There is one tape machine U that, on the code of any machine M followed by any input w, stops exactly when M stops on w, with the same output.

The set of pairs ⟨M⟩ # w such that M stops on w is listed and not decided, and its outside is not listed. For every property of the functions machines compute that some machines have and some lack, no machine decides which codes have it; no machine decides which statements PA reaches. For every machine T reading a code and a string there is a machine R that on any w does what T does on ⟨R⟩ # w. The sets checked by machines with no memory can be pumped, and the strings of square length are not such a set; a machine confined to r cells has its stopping decided.

Whether a set is fast does not depend on the number of tapes; every set in NP fast-reduces to the satisfiable statements and is decided within 2 to a power of n steps; for each k some set is decided in a power of n steps and in no nᵏ steps; and every set in BPP is in PSPACE, with the chance of error of a coin machine brought below any number fixed in advance by repetition.

So the rung’s claim holds: a tape machine’s reach is the reach of every exact account of a recipe, one machine runs them all, and no machine decides stopping or anything carried from it; among decided questions, more time decides more. Held in trust: the step from listed to undecided for whole-number equations, named in 40e. Not proved and not provable as a technique: the thesis, which turns “no tape machine” into “no recipe”.
