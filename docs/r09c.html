9c · proof

One-to-One, Onto, Bijection

A function makes two promises about its inputs: each has at least one output, and none has two. Ask the same two questions about the outputs and you get the two words of this step. One-to-one: no output is used twice. Onto: every allowed output is used. A function keeping both is a bijection, and 4k already had a name for it, a matching. Then the question rung 9 keeps asking: what survives a chain? One-to-ones compose to a one-to-one, ontos to an onto, and a chain can tell you something about its links even when you cannot see them.

One-to-one is “at most one input per output”; onto is “at least one”. Both together pair the two sets off with nobody left over on either side.

9c1The Two Promises, Asked of Outputs

A function f : A → B promises, for each input, at least one output and at most one. Turn the questions around. Does each member of B come from at least one input? Does each come from at most one? Neither is promised, and each is worth a name.

From here on, f : A → B is one-to-one when ∀x₁ ∈ A ∀x₂ ∈ A (f(x₁) = f(x₂) ⇒ x₁ = x₂): no output is used twice. f is onto B, or onto, when ∀b ∈ B ∃x ∈ A (f(x) = b): every member of B is used. f is a bijection from A to B when it is one-to-one and onto B.

The low marks in x₁ and x₂ are 3f's: two names, which may or may not name the same input. 4b's line for “S is one-to-one” had exactly this shape, for the next-one gesture on all sets. This line extends the word to every function, and agrees with 4b's wherever both apply. The form with denials, x₁ ≠ x₂ ⇒ f(x₁) ≠ f(x₂), is the same promise turned about. From the line above, 1d's turn-and-deny gives it. From it, 7e's turn-and-deny turned back gives the line back. Two-forms-of-one-to-one technique: f is one-to-one exactly when x₁ ≠ x₂ ⇒ f(x₁) ≠ f(x₂) for all inputs x₁ and x₂. The line above is the form to work with, because it ends in an equation you can reach by moves.

A bijection keeps all four promises: it pairs A and B off with nobody left over on either side. That is 4k's matching. Matchings-are-bijections technique: m is a matching between X and Y exactly when m : X → Y is a bijection. 4k's line asks three things. m ⊆ X × Y. Every member of X is paired with exactly one member of Y. And every member of Y is paired with exactly one member of X. The first two parts are m : X → Y (9a's one-output). The last part is at least one, which is onto, and at most one: (x, y), (x′, y) ∈ m ⇒ x = x′, which with m(x) = y = m(x′) is one-to-one. ∎ 4k's accepted name is now earned: from here on, “matching” and “bijection” are two names for one thing. Every count on 4k, “X has n members”, is a statement that a bijection exists.

By 9a's pairs-fix-the-inputs, onto B says exactly ran f = B. The range is always a part of B, and onto says B is a part of the range. So onto depends on the codomain you chose, and the pairs alone cannot settle it. Every function is onto its range, by codomain. One-to-one does not depend on the codomain at all: it speaks only of pairs.

9c2Examples, With Witnesses

Squaring, s(x) = x², from ℝ to ℝ, is neither. Not one-to-one: s(2) = s(−2) = 4 and 2 ≠ −2. Not onto ℝ: −1 is no output, since every square is at least 0 (square-never-negative). Change only the codomain, s : ℝ → [0, ∞), and it becomes onto, since every real u ≥ 0 is √u squared (square-root). It is still not one-to-one. Change the domain too, s : [0, ∞) → [0, ∞), and it is a bijection. It is onto as before, and one-to-one because two reals that are not negative with the same square are the same (one-root). Same formula, three functions, three answers. That is not pedantry: it is the lever 9d pulls to make the square root.

2a_1 + 1 = 2a_2 + 1 @@ one-to-one: assume equal outputs
2a_1 = 2a_2 @@ adding-keeps-answers (5g, read in ℝ by 8g): add −1 to both sides
\htmlClass{new}{a_1 = a_2} @@ multiplying-keeps-answers: multiply both sides by ½, not 0
b \in \mathbb R;\ \ a = \tfrac{b - 1}{2} @@ onto: let b be anything; name a candidate by undoing the function
2 \cdot \tfrac{b-1}{2} + 1 = (b - 1) + 1 = \htmlClass{new}{b} @@ check: reciprocal on ℝ, then negative on ℝ and plus-zero on ℝ; show an example

Onto proofs are usually like that: run the function backwards to guess the input, then run it forwards to check. One-to-one proofs start from two equal outputs and cancel. And one more example from rung 4. 4d's s : ℕ → ℕ, n ↦ S(n), is one-to-one (4b's different-nexts) and not onto ℕ, because 0 is no number's next one (next-never-empty). A set that can be matched one-to-one into a part of itself that leaves something out: that was the old mark of the endless, in 3d's words, and it now has its exact form.

And from 5·cb2: the class map of a sameness relation ∼ on a set w, x ↦ [x], is onto w/∼, since every class is [x] for some x by the line for w/∼. Class-map technique: the class map is onto w/∼, and it is one-to-one exactly when x ∼ y is true only for x = y. One-to-one says [x] = [y] ⇒ x = y, and by same-class-same-relation, [x] = [y] is x ∼ y. ∎ So for 5b's ∼ on pairs of numbers the class map is onto ℤ and very far from one-to-one: (0, 0) and (1, 1) go to the same integer. 5·cb2 said every class is a value in words; this is the word.

9c3What Survives a Chain

One-to-ones-compose technique: if f : A → B and g : B → C are one-to-one, so is g ∘ f. Ontos-compose technique: if f is onto B and g is onto C, then g ∘ f is onto C.

(g \circ f)(a_1) = (g \circ f)(a_2) @@ one-to-ones-compose: assume equal outputs of the chain
g(f(a_1)) = g(f(a_2)) @@ composite-is-a-function (9b), each side
f(a_1) = f(a_2) @@ g is one-to-one, at the inputs f(a₁), f(a₂)
\htmlClass{new}{a_1 = a_2} @@ f is one-to-one; prove an if; speak of everything
c \in C;\ \ \text{call } b \in B,\ g(b) = c @@ ontos-compose: let c be anything; g onto C, use the some
\text{call } a \in A,\ f(a) = b @@ f onto B, use the some
(g \circ f)(a) = g(f(a)) = g(b) = \htmlClass{new}{c} \quad \blacksquare @@ composite-is-a-function; the swap axiom; show an example; the calls close

So bijections compose to a bijection (the bijections-compose technique, the two joined). That is 4k's chain for matchings (matchings join) seen again. The chain can also be read the other way. One-to-one-inside technique: if g ∘ f is one-to-one, then f is. If f(x₁) = f(x₂), apply g to both sides (the swap axiom). That is (g ∘ f)(x₁) = (g ∘ f)(x₂), so x₁ = x₂. Onto-outside technique: if g ∘ f is onto C, then g is. For c ∈ C, call x with g(f(x)) = c; then f(x) is an input of g with output c. ∎ One-to-one can also be said without members: f : A → B is one-to-one exactly when f can be cancelled on the left, so that f ∘ u = f ∘ v gives u = v. If f is one-to-one, f(u(t)) = f(v(t)) gives u(t) = v(t) at every t. If f cancels, let u and v send the one member of {1} to x₁ and to x₂: when f(x₁) = f(x₂), f ∘ u = f ∘ v, so u = v and x₁ = x₂. ∎ The other halves fail, and one small example kills both. Let A = C = {1} and B = {1, 2}, with f(1) = 1 and g sending both 1 and 2 to 1. Then g ∘ f is {(1, 1)}, the identity on {1}, a bijection. Yet g is not one-to-one (g(1) = g(2), 1 ≠ 2), and f is not onto B (2 is missed).

9b left a question open: when may you cancel in a chain? Now it has an answer. Cancel-on-the-outside technique: if g is one-to-one and g ∘ f = g ∘ h, with f, h : A → B, then f = h. At each x, g(f(x)) = g(h(x)) by composite-is-a-function and the swap axiom. So f(x) = h(x), and equal-functions. Cancel-on-the-inside technique: if f : A → B is onto B and g ∘ f = h ∘ f, with g, h : B → C, then g = h. For b ∈ B, call x with f(x) = b. Then g(b) = g(f(x)) = h(f(x)) = h(b), and equal-functions. ∎ 9b's cancel was outside the plan because g sent everything to 0: about as far from one-to-one as a function gets.

9c5Running It Backwards

Wanting one-to-one: assume two equal outputs, cancel down to equal inputs. Wanting not one-to-one: two different inputs, one output. Wanting onto: let b be anything, undo the function to guess an input, check it forwards. Wanting not onto: one member of B no input reaches, with the reason it cannot be reached (a sign, a size, a parity). Wanting a fact about a link from a fact about a chain: one-to-one-inside for the inside, onto-outside for the outside. Found upward; written downward.

Who said it first

The old mark of the endless, a set matched one-to-one into a part of itself that leaves something out, is Dedekind’s.

Dedekind called a transformation of a system “similar”, his word for one-to-one, when different elements always have different transforms; and he called a system infinite when it is similar to a proper part of itself.

Dedekind, Was sind und was sollen die Zahlen? (1888), §26 and §64; in English as The Nature and Meaning of Numbers, trans. W. W. Beman (1901)

Accepted names: a one-to-one function is also called injective (from the Latin for “thrown in”), or an injection; an onto function is called surjective, or a surjection; and a bijection is also called bijective.
