30k · proof

No system beats a fair game

Gamblers have always hunted for a system: bet more after a loss, stop when ahead, wait for a streak to break. This step proves that in a fair game no such system works, as long as it must stop within some fixed time. A fair game is one where, whatever has happened so far, your fortune after the next round averages what it is now. From that, your average fortune never changes. Stopping at a moment you choose, using only what has already happened, does not change it either. And betting more or less as you go does not change it. The same reasoning answers a question about ruin: start with some dollars, bet one at a time on a fair coin, and stop when you reach a target or go broke. The chance of reaching the target is simply your start over your target.

In a fair game the average fortune never changes. Stopping by a rule that looks only at the past, within a fixed time, keeps it, so no system that stops in time can beat the game, and a fair walk reaches its target with chance start over target.

30k1A fair game

Stands on 30f2, 30f3, 30g1.

Let X₀, X₁, X₂, … be a gambler’s fortune after each round. In this step each Xₙ takes finitely many values, so the history up to round n, the values of X₀, …, Xₙ, is one of finitely many lists. Histories of chance 0 are left out.

From here on, the game is fair when, for every n and every history h up to round n, the average of Xₙ₊₁ given h is the present fortune:

E(Xₙ₊₁ | h) = Σ x P(Xₙ₊₁ = x | h) = Xₙ on h.

Its accepted name is a martingale. A fair coin, betting a dollar a round on heads, is a fair game: Xₙ₊₁ = Xₙ + 1 or Xₙ − 1, each with chance 1/2, whatever came before.

Fair-stays-fair technique: in a fair game, E Xₙ = E X₀ for every n.

E\,X_{n+1} = \sum_h E(X_{n+1} \mid h)\,P(h) @@ whole-chance (30f3) over the histories h up to round n, for averages
= \sum_h X_n(h)\,P(h) = E\,X_n @@ the game is fair; step-total (30g1)
\htmlClass{new}{E\,X_n = E\,X_0} \quad \blacksquare @@ induction on n

30k2Stopping does not help

Stands on 30k1.

From here on, a stopping rule T is a round number chosen by looking only at the past: whether T = n is decided by the history up to round n. It is bounded when T ≤ N always, for one fixed N. “Stop the first time you are 3 ahead, or at round 100” is a bounded stopping rule. “Stop the round before the biggest loss” is not a stopping rule at all, since it looks ahead. Its accepted name is a stopping time.

Stopping-keeps technique: if T is a bounded stopping rule in a fair game, E XT = E X₀.

X_T = X_0 + \sum_{n=0}^{N-1} (X_{n+1} - X_n)\,1_{\{T > n\}} @@ the steps taken before stopping; T ≤ N
\{T > n\} \text{ is decided by the history } h \text{ up to round } n @@ a stopping rule looks only at the past
E\big((X_{n+1} - X_n)\,1_{\{T > n\}}\big) = \sum_{h:\,T > n} \big(E(X_{n+1} \mid h) - X_n(h)\big)P(h) = 0 @@ whole-chance; the game is fair
\htmlClass{new}{E\,X_T = E\,X_0} \quad \blacksquare @@ average-adds (30g1), over finitely many n

30k3No system

Stands on 30k1, 30k2.

A system chooses the stake Hₙ for round n from the history up to round n − 1, with |Hₙ| ≤ K for one fixed K. Its winnings after n rounds are Wₙ = H₁(X₁ − X₀) + ⋯ + Hₙ(Xₙ − Xₙ₋₁).

No-system technique: in a fair game, every system with a bounded stopping rule has average winnings 0.

E\big(W_{n+1} - W_n \mid h\big) = H_{n+1}(h)\big(E(X_{n+1} \mid h) - X_n(h)\big) = 0 @@ the stake is fixed by h; the game is fair
W_0 = 0,\ \ W_0, W_1, \ldots \text{ is a fair game} @@ given the history of X, which fixes the Wₖ
\htmlClass{new}{E\,W_T = 0} \quad \blacksquare @@ stopping-keeps (30k2)

Doubling after each loss seems to beat this: the first win covers every loss and gains the first stake. It needs stakes with no ceiling and a stopping time with no bound, and both are illegal here. With a ceiling on stakes, a long run of losses ruins the doubler often enough to bring the average back to 0.

30k4The chance of ruin

Stands on 30k2, 30d3, 22i.

Start with k dollars, 0 < k < N. Bet one dollar a round on a fair coin. Stop at T, the first round your fortune is 0 or N.

Ruin-chance technique: the chance of reaching N before 0 is k/N.

P(T > mN) \le (1 - 2^{-N})^m \to 0 @@ each block of N rounds ends the game if all are heads; blocks are independent
\min(T, n) \text{ is a bounded stopping rule} @@ stop at T, or at n, whichever is first
E\,X_{\min(T, n)} = k @@ stopping-keeps (30k2)
X_{\min(T, n)} \to X_T \text{ with chance } 1,\ \ 0 \le X_{\min(T, n)} \le N @@ T is finite with chance 1; a fence N
E\,X_T = k @@ fenced-limit (30d3)
N \cdot P(X_T = N) + 0 \cdot P(X_T = 0) = k @@ X_T is 0 or N
\htmlClass{new}{P(\text{reach } N \text{ before } 0) = k/N} \quad \blacksquare @@ the line above

Start with 90 dollars and aim for 100 on a fair coin, and you win 9 times in 10, a small gain each time. The 1 time in 10 you lose all 90. On average you gain 0.

The basement · there if you want it

The accepted names

A fair game is a martingale, and the history up to round n is its filtration. A stopping rule is a stopping time. The stopping-keeps technique is the optional stopping theorem, here for bounded stopping times. A system is a predictable process, and its winnings are the martingale transform, a discrete stochastic integral. Doubling after each loss is the martingale betting system, from which the word comes. The ruin-chance is the gambler’s ruin.

Who said it first

Blaise Pascal and Pierre de Fermat posed the gambler’s ruin in 1656, and Christiaan Huygens published it in 1657. Paul Lévy studied fair games in the 1930s. Jean Ville named them martingales in 1939, after the betting system. Joseph Doob built the theory, with optional stopping, in 1940 and in his book of 1953.

A proof that is not allowed

“Stop the first time you are 1 ahead. The walk is sure to get there, so E X_T = 1, which beats the fair game.” Not allowed: T has no bound, and the fortunes before T have no fence below, so the fenced limit does not apply. The average time to get there is endless.
