11a · proof

Continuity

Rung 10 asked where a function is headed at an input and refused to look at the input itself. This step looks. A function is continuous at an input when its limit there exists and is its value: it lands where it was headed. The step lays the definition down and unpacks it into the challenge game, with nothing left out. It gives the definition forms for one side, for a set of inputs and for an interval. And it names the graph of a function on an interval a curve. Then it finds the first continuous functions, and three ways to fail, the last of which fails at every real there is.

Ask three questions at the input: is there a value, is there a limit, are they the same? Three yeses, and the function is continuous there; then the game can be played with the input included, and every limit there is found by substituting.

11a1Headed, and where it is

10a's line lim_{x→w} f(x) = L says where f is headed at w: for every gap ε around L, some reach δ around w keeps every input other than w inside the gap. The value at w played no part; 10a's agreeing-near made that a technique. Put the value back in, as the target, and you have this rung's idea.

From here on, let f be a function whose inputs and outputs are reals, and let w be an input of f with f defined near w. Then f is continuous at w when lim_{x→w} f(x) = f(w). Read it “f is continuous at w”, or “f lands where it was headed at w”. When w is such an input and f is not continuous at w, f is discontinuous at w.

The line asks three things at once, and each can fail on its own. First, w is an input, so f(w) names a real. Second, f has a limit at w. Third, that limit is f(w). The line is 10a's limit line with L replaced by f(w). By 10b's one-limit, the limit is then the one limit f has at w, and 10b's name may be used: the limit of f at w is its value.

Take the three functions of the survey, each at 1. x² heads to 1 (square-limit) and its value is 1: continuous. 9a's H(x) = (x² − 1)/(x − 1), on every real but 1, heads to 2 (agreeing-near with x + 1, line-limit). But 1 is not an input, so the line says nothing at 1: continuity is asked only at inputs. Call H₃ the function that agrees with H off 1 and has the value 3 at 1 (7d's cases). It heads to 2, its value is 3, and 2 ≠ 3: discontinuous at 1.

11a2Unpacked: nothing left out

The game reading is simpler than the limit's. Continuity-unpacked technique: for f defined near w with w an input, f is continuous at w exactly when ∀ε > 0 ∃δ > 0 : ∀x ∈ dom f (|x − w| < δ ⇒ |f(x) − f(w)| < ε). The “0 <” of 10a's line is gone. It is not needed, because at x = w the distance |f(w) − f(w)| is 0, which is less than every positive ε. The input w now passes the test instead of being excused from it.

\text{let } \varepsilon \gt 0 @@ speak of everything
\text{call } \delta:\ 0 \lt |x - w| \lt \delta \Rightarrow |f(x) - \htmlClass{keep}{f(w)}| \lt \varepsilon @@ the definition: 10a's line with L = f(w); use the every, then the some
\text{let } x \in \operatorname{dom} f;\ \text{assume } \htmlClass{new}{|x - w| \lt \delta} @@ the promise to be proved, with no 0 <
x = w \;\lor\; x \ne w @@ three-way-order on ℝ (8b): a split on sameness of reals, licensed by rung 7's either-way principle
\text{case } x = w:\ |f(x) - f(w)| = |f(w) - f(w)| = 0 \lt \varepsilon @@ the swap axiom; negative on ℝ; |0| = 0 (8h)
\text{case } x \ne w:\ 0 \lt |x - w| \lt \delta \Rightarrow |f(x) - f(w)| \lt \varepsilon @@ |p| = 0 only at 0 (8h), so |x − w| > 0; the promise
|f(x) - f(w)| \lt \varepsilon \quad \blacksquare @@ reasoning by cases; prove an if; speak of everything

Leftward needs nothing: if every input within δ of w lands within ε of f(w), then every input within δ other than w does too (keep right part of the and in “0 < |x − w| ∧ |x − w| < δ”). So the two lines say the same thing, and from here on either may be cited as the definition. The rightward column is the only place this step splits on “x is w or it is not”; for reals that split is rung 7's, through three-way-order on ℝ.

What the unpacked form forbids is exactly what the limit forgave. For H₃ at 1 the target is now the band around the value 3. Challenge with ε = ½. Whatever reach δ is answered, take an input x ≠ 1 within min(δ, ¼) of 1: its output is x + 1, between 1.75 and 2.25, more than ¾ away from 3. It escapes. The input 1 itself passes, and its neighbours all fail: the stray value has moved the target away from where the function was headed.

11a3Substituting is the definition, read left to right

Rung 10 kept saying that this rung would name the functions for which a limit is found by substituting. Here they are. For a function continuous at w, the limit is the value, and the value is found by putting w in: lim_{x→w} f(x) = f(w). 10c's substitution, read with this step's line, says every polynomial is continuous at every real; 11d proves it a second way, by the degree. 10f's first move, “substitute”, is licensed exactly where the function is continuous. The rest of 10f's kit (factor and cancel, the conjugate, the squeeze) is what you do where it is not.

The first continuous functions come directly from 10a. Lines-are-continuous technique: for reals m and b, x ↦ mx + b is continuous at every real w. Line-limit gives lim_{x→w} (mx + b) = mw + b, which is the value at w. ∎ So a constant is continuous everywhere (m = 0), and so is x ↦ x (m = 1, b = 0). By the same reading, x² is continuous at every real (square-limit: the limit at w is w²). And 1/x is continuous at every input, that is at every w ≠ 0 (one-over-x-limit: the limit at w is 1/w).

\lim_{x \to 2} (3x + 1) = 7 = 3 \cdot 2 + 1 @@ line-limit; the value at 2: continuous at 2 (lines-are-continuous)
\lim_{x \to -3} x^2 = 9 = (-3)^2 @@ square-limit; the value: continuous at −3
\lim_{x \to \frac12} \tfrac1x = 2 = \tfrac{1}{1/2} @@ one-over-x-limit, since ½ ≠ 0; the value: continuous at ½

11a4From one side

√x has no inputs below 0, so it is not defined near 0, and the definition does not apply at 0. 10e's one-sided limits give the line that does.

From here on, for f with w an input and f defined just right of w, f is continuous from the right at w when lim_{x→w⁺} f(x) = f(w); and for f with w an input and f defined just left of w, f is continuous from the left at w when lim_{x→w⁻} f(x) = f(w).

Continuous-both-ways technique: for f defined near w with w an input, f is continuous at w exactly when it is continuous from the left and from the right at w. 10e's two-sides-agree with L = f(w). ∎ The unpacked form works side by side: continuity-unpacked's column with the half-window w ≤ x < w + δ (from the right) or w − δ < x ≤ w (from the left) in place of the window |x − w| < δ.

Root-is-continuous technique: √ is continuous at every w > 0, and continuous from the right at 0. For w > 0, 10f's root-limit with c = 0 gives lim_{x→w} √x = √w. At 0, 10e's root-at-0 gives lim_{x→0⁺} √x = 0 = √0. ∎

11a5On a set, on an interval, and the word curve

One input at a time is the definition; most statements are about many inputs at once.

From here on, for a set A of inputs of f, f is continuous on A when it is continuous at every member of A. Some intervals of inputs contain one of their ends, as [c, d], [c, ∞) or (c, d] do (8g). On such an interval I, continuity at that end is asked only from the side inside I. So f is continuous on I when it is continuous at every member of I that is not an end, continuous from the right at a left end that belongs to I, and continuous from the left at a right end that belongs to I. And f is continuous, with no set named, when its domain is an interval or is made of several intervals, and f is continuous on each of them.

So x², every linear function and every constant are continuous on ℝ. √ is continuous on [0, ∞) by root-is-continuous, and so is continuous. 1/x has the domain (−∞, 0) ∪ (0, ∞), two intervals. It is continuous on each by one-over-x-limit, and so 1/x is continuous, although nothing is said, or askable, at 0. The interval form is the one rung 12 needs: there, “continuous on [c, d]” will mean exactly this line.

The title of this rung uses a word that now gets its job.

From here on, a curve is the graph of a function on an interval: the set of pairs (x, f(x)) for x in an interval I of inputs, 9e's graph of f kept to I (9d's f|_I). No geometry is meant. A curve is a set of pairs of reals, drawn in 9e's plane, and nothing about its shape is claimed or used.

“Where a curve is headed is where it is” is then this step's definition at every input of the interval: the limit is the value.

11a6Three ways to fail

A jump at an input. Let u(x) = 0 for x < 0 and u(x) = 1 for x ≥ 0 (7d's cases). On the left of 0, u agrees with the constant 0, so its limit from the left is 0; on the right, with the constant 1 (agreeing-near side by side, line-limit). The two sides differ, so u has no limit at 0 (two-sides-differ): the second demand fails, and u is discontinuous at 0. It is continuous from the right at 0, since u(0) = 1. At every w ≠ 0, u agrees with a constant on the neighbourhood of w of reach |w|, so it is continuous there (agreeing-near, lines-are-continuous). So u is continuous on (−∞, 0) and on [0, ∞), but not on ℝ, its domain, and it is not continuous.

Compare 10e's |x|/x, which is −1 on the left of 0 and 1 on the right, and has no value at 0. Its domain is (−∞, 0) ∪ (0, ∞), and it is continuous on each piece. So |x|/x is continuous, in this step's sense, and u is not. The picture of |x|/x has a gap at 0 all the same. 11f names such a place a break, and is careful to say that a break may sit at a real that is not an input.

A stray value. H₃ above: an input, a limit, and the two different. The third demand fails. 11f mends it, by changing one value.

Everywhere. Nowhere-continuous technique: 9a's q, 1 at fractions and 0 at irrationals, is continuous at no real. q is defined near every real (its domain is ℝ), and 10d's heads-nowhere says it has no limit at any real. The second demand fails at every w. ∎

And one input only. Continuous-at-one-point technique: the function x ↦ x · q(x) is continuous at 0, and discontinuous at every w ≠ 0. At 0, 10d showed lim_{x→0} x · q(x) = 0, and the value is 0 · q(0) = 0 (anything-times-zero read in ℝ). At w ≠ 0, a refutation:

\text{assume } x \cdot q(x) \text{ continuous at } w \ne 0 @@ to refute
\varepsilon = \tfrac{|w|}{4};\ \ \text{call } \delta;\ \ \htmlClass{new}{\delta' = \min(\delta, \tfrac{|w|}{2})} @@ continuity-unpacked; lesser-below-both: δ′ positive and at most each
\text{a fraction } r,\ w \lt r \lt w + \delta' @@ fraction-between between w and w + δ′ (8e)
\text{an irrational } t,\ r \lt t \lt w + \delta' @@ t = r + √2/n with √2/n < w + δ′ − r, by everyday-counting-passes (as 10d did)
|r| \ge |w| - |r - w| \gt \tfrac{|w|}{2} @@ the reverse form of triangle (8h); |r − w| < |w|/2
r \cdot q(r) = r,\ \ t \cdot q(t) = 0 @@ q(r) = 1, q(t) = 0 (9a)
|r - V| \lt \varepsilon \land |0 - V| \lt \varepsilon,\ \ V = w\,q(w) @@ both inputs are within δ of w: continuity-unpacked's promise twice
2\varepsilon = \tfrac{|w|}{2} \lt |r| = |r - 0| @@ the two outputs are more than 2ε apart
\bot;\ \ \neg(\text{continuous at } w) \quad \blacksquare @@ 10b's two-targets with targets r and 0 and the point V; refute

A function continuous at exactly one real. If you think of continuity as “drawn without lifting the pen”, this function is a warning: no pen draws it near 0, and yet at 0 it lands where it was headed. Continuity is a fact about one input at a time. What it says about a whole interval is rung 12's question.

11a8Running it backwards

Handed a function and an input, ask the three questions in order; the first “no” names what fails. Handed a limit at an input where the function is continuous, write the value. Handed a value and a continuity claim, the claim tells you the limit: if f is continuous at 4 and heads to −2 there, then f(4) = −2. Handed a function at the edge of its domain, use the one-sided line and say so. Handed a set or an interval, check each input, and at an end that belongs to the interval only the inside side. Found upward; written downward.
