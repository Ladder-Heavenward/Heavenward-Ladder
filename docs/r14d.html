14d · proof

Zero slope means flat

A speedometer that reads 0 all afternoon means the car has not moved. Rung 13 could not prove it. Every rule there was about one input, and a slope of 0 at each input, one at a time, says nothing about two inputs apart. 14c's average-slope says that the change between any two inputs is a slope times the step. The slope is one the function really has between them. If every slope is 0, every change is 0. If every slope is positive, every change in the direction of the step is positive. So the sign of the slope across a whole interval decides how the values compare, which is the question 13k and 13l left for this rung.

Take any two inputs in the interval. Average-slope says the change between them is a slope, at some input between, times the step. If the slope is 0 everywhere, the change is 0. If the slope is positive everywhere, the change is positive.

14d1Zero slope everywhere

Zero-slope-is-constant technique: if f has slope 0 at every input of an open interval I, then f is constant on I. Likewise if f is continuous on [α, β] and has slope 0 at every input of (α, β), then f is constant on [α, β].

x, y \in I,\ \ x \lt y @@ any two inputs; for x = y there is nothing to prove
f \text{ continuous on } [x, y] @@ slope-means-no-gap (13b) at each input: [x, y] lies in I, since I is an interval (8g)
\text{call } c,\ x \lt c \lt y:\ f(y) - f(x) = f'(c)(y - x) @@ average-slope (14c)
f(y) - f(x) = 0 \cdot (y - x) = 0 @@ f′(c) = 0, since c ∈ I
\htmlClass{new}{f(x) = f(y)} \quad \blacksquare @@ for every pair: f has one value on I

Where each hypothesis was spent: the slope at every input, in slope-means-no-gap and at c; the interval, in the second line. The interval matters. Let f(x) = 0 for x < 0 and f(x) = 1 for x > 0, with 0 left out of the domain. Every input has a neighbourhood on which f is constant. So f has slope 0 at every input of its domain (slopes-decided-near, constant-has-slope-0), and f is not constant. [−1, 1] does not lie in the domain, and the second line fails.

Throw a ball straight up. Its velocity v is the slope of its height x (14c), and its acceleration is the slope of its velocity, v′. At the top, the highest point, v = 0 (flat-top, 14a). Suppose the acceleration were 0 at every instant from the top on. Then v′ = 0 on an interval makes v constant, so v stays at its value at the top, 0. And then v = x′ = 0 makes the height constant: the ball would hang there. Zero-slope-is-constant twice. 13·phys held this step in trust, and that flag is closed here.

14d2The sign of the slope decides the order

Slope-sign-order technique: if f is continuous on an interval and has a positive slope at every input inside it, then f is increasing on the interval. If every slope inside is negative, f is decreasing. If every slope inside is at least 0, then x < y gives f(x) ≤ f(y).

x \lt y \text{ in the interval} @@ any two
\text{call } c,\ x \lt c \lt y:\ f(y) - f(x) = f'(c)(y - x) @@ average-slope on [x, y]: f is continuous there, and c is inside the interval
f'(c) \gt 0,\ \ y - x \gt 0 @@ the hypothesis; x < y
\htmlClass{new}{f(x) \lt f(y)} @@ sign-of-a-product (8g): a product of positives is positive
\text{negative slopes: } f(y) - f(x) \lt 0;\ \ \text{slopes} \ge 0:\ f(y) - f(x) \ge 0 \quad \blacksquare @@ the same line, with 8g's signs of products

This is 13l's keeping order, proved from the slope. A function whose every slope inside is at least 0 is called non-decreasing. One whose every slope is at most 0 is called non-increasing. A function that is one or the other on an interval is called monotone there.

The ends may be included: the technique asks for continuity on the interval and slopes only inside. So x³ − 3x, whose slope 3(x − 1)(x + 1) is negative on (−1, 1), is decreasing on the closed interval [−1, 1], ends and all.

Slope-sign-order does not run backwards. x³ is increasing on ℝ (9e's odd-powers-keep-order) and its slope at 0 is 0. What does run backwards is the weaker form. If f is increasing on an open interval and has a slope at c, then f′(c) ≥ 0. Were it negative, 13k's slope-sign-near would find f(c + h) < f(c) for some h > 0, against increasing. So an increasing function has slopes at least 0, and may have slope 0 at some inputs. A few such inputs do no harm.

Positive-but-finitely technique: if f is continuous on an interval, and its slope is positive at every input inside but finitely many, where it is 0, then f is increasing on the interval. The finitely many inputs cut the interval into stretches. On each stretch, with its ends, slope-sign-order makes f increasing. And take x < y in different stretches: the values climb from stretch to stretch through the cut points in between (three-way-order on ℝ, chained). ∎ For x³ there is one cut, at 0.

14d3What the order buys

g(x) = x^3 - 3x + 2,\ \ g(1) = 0 @@ to prove x³ ≥ 3x − 2 for every x ≥ 1
g'(x) = 3x^2 - 3 = 3(x - 1)(x + 1) \gt 0 \text{ for } x \gt 1 @@ polynomial-slope; 8g's sign-of-a-product
g \text{ increasing on } [1, \infty) @@ slope-sign-order: continuous there (polynomials-are-continuous), positive slopes inside
x \ge 1 \;\Rightarrow\; g(x) \ge g(1) = 0 @@ so x³ ≥ 3x − 2, with equality only at 1
  
f(x) = x^5 + x,\ \ f'(x) = 5x^4 + 1 \ge 1 @@ polynomial-slope; square-never-negative
f \text{ increasing on } \mathbb{R} @@ slope-sign-order
g \text{ runs } f \text{ backwards};\ \ f(1) = 2 @@ 13l: one-to-one, so g exists on f's outputs
g'(2) = \tfrac{1}{f'(1)} = \htmlClass{new}{\tfrac16} @@ inverse-slope (13l): the order it asked for is now proved from the slope
  
x^5 + 3x - 7:\ \ \text{slope } 5x^4 + 3 \gt 0 @@ increasing on ℝ, so one-to-one: at most one zero
f(1) = -3 \lt 0 \lt 31 = f(2) @@ in-between-value: at least one

14b counted zeros with level-ends. Slope-sign-order gives the same count by a different road, and gives the order of the values too.

An old thought experiment asks you to picture a ball on a smooth, level floor, with every obstacle taken away. Nothing would speed it up and nothing would slow it. So it would go on at the same speed for as long as the floor went on.

14d5Running it backwards

Handed a claim that a function never changes, show its slope is 0 at every input of an interval. Handed an inequality f(x) ≥ g(x) for x ≥ w, look at the gap f − g. Check it is at least 0 at w, and that its slope is at least 0 after w. Handed a question about where a function climbs, factor its slope and read its sign between the critical points. Handed a function that seems to break zero-slope-is-constant or slope-sign-order, look at its domain: it is not an interval. Found upward; written downward.

Who said it first

Galileo asked his reader to picture a ball on a smooth, level floor, with every obstacle taken away: nothing would speed it up and nothing would slow it, so it would go on at the same speed for as long as the floor went on.

Galileo, Two New Sciences (1638), Third and Fourth Days; paraphrase

The old teaching of the closer is Aristotle’s. The first law of motion is from Isaac Newton’s Principia (1687).
