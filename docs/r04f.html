4f · proof

Adding

The ground floor said that a thing is the same as itself. Everything since has been building the means to say, and prove, that one and three make four. This step does it. First it defines adding by repeating the next-one gesture, with 4d's technique doing the work. Adding 0 changes nothing, and adding the next one after a number is taking the next one after what adding that number gave. Then it unfolds one plus three, name by name, until four stands at the foot of the column. Then it proves the techniques of adding, each by induction. The order of the numbers added does not matter. The brackets do not matter. And a number added to both sides of a sameness can be taken away again.

To add one number to another, start at the first and take the next one once for each step from 0 up to the second. Written as a start and a step: a number plus 0 is that number, and a number plus the next one after a second number is the next one after their sum.

4f1Adding, in Words

To add three to one, start at one and take the next one, and again, and again: two, three, four.

That is the whole idea, and the trouble with it is “and again, and again”. It does not say when to stop unless you already know how adding three goes, which is the very thing being defined.

The way out is the one 4d built. Say what adding does when nothing is added, and say how adding the next one after b relates to adding b:

  • Adding 0 to p gives p.
  • Adding the next one after b to p gives the next one after (p with b added).

For a fixed p, that is a start, p, and a step, the next-one technique. And 4d's recursion technique says a start and a step fix exactly one function on the numbers.

Example: adding 2 to 5. Adding 0 to 5 gives 5. Adding 1, the next one after 0, gives the next one after 5, which is 6. Adding 2, the next one after 1, gives the next one after 6, which is 7.

4f2The Definition

Fix a number p. Use recursion with A = ℕ, start p, and step s (4d's function n ↦ S(n)). It gives exactly one function from ℕ to ℕ. That function has the value p at 0 and, at each S(n), the next one after its value at n.

That function goes with p, and a different p gives a different function. So its name must carry the number it starts at. 3f's low mark does that.

From here on, a low mark may be a letter as well as a numeral: is a name that carries a, as carried k.

Example: f₃ starts at 3. So f₃(0) = 3, f₃(1) = S(f₃(0)) = 4, and 3 + 1 names f₃(1).

A schoolteacher of the century before last wrote a textbook of arithmetic in which adding is defined by exactly this pair of lines. Every technique of adding and multiplying is proved from them by induction. It seems nobody had done so before. A generation later another writer put the same pair of lines at the head of his arithmetic.

4f3Three Techniques From the Definition

The name is honest because recursion says exactly one function fits. What the line gives you to cite are its two defining lines and a third line, each a technique.

  • Plus-zero technique: adding 0 changes nothing. In marks: p + 0 = p. You know this one: put nothing more on the pile, and the pile is the same.
  • Plus-a-next technique: adding the next one after b gives the next one after the sum with b. In marks: p + S(b) = S(p + b).
  • Sums-are-numbers technique: the sum of two numbers is a number.

Example: 5 + 0 = 5, by plus-zero. 5 + S(0) = S(5 + 0), by plus-a-next.

4f4One Plus Three Is Four

Here it is. Each line makes one move. It unpacks a name into the next one of the name before, or uses plus-a-next or plus-zero, or packs a name back.

The chain convention of 4d is in force. Each line beginning with = says that 1 + 3 is the same as what follows, by the chain technique with the line before it.

4f5Adding One Is Taking the Next One

The line 3 + 1 = 4 needs only a short column, because adding 1 is a short story every time.

Plus-one technique: adding one is taking the next one. In marks: for every number n, n + 1 = S(n). You did this on your fingers before you could write: one more is the next number.

Plan: unpack 1 into S(0), use plus-a-next, then plus-zero.

n + 1 = n + \htmlClass{new}{S(0)} @@ 1 names S(0)
\phantom{n + 1} = S(n + 0) @@ the plus-a-next technique
\phantom{n + 1} = \htmlClass{new}{S(n)} \quad \blacksquare @@ the plus-zero technique, inside

From here on, may be written for , and the other way about: the plus-one technique says they name the same number. It is not a new mark; it is a proved sameness, and writing one for the other is a move cited to the swap axiom.

So 3 + 1 = S(3) = 4. The step of every induction may be written “from n to n + 1”, as it is usually written.

4d's doubling function gets its shorter description too: d(n) = n + n, for every number n, by induction.

4f6Zero on the Left

Plus-zero says p + 0 = p. It does not say 0 + p = p. That is a different statement, with 0 on the other side, and it needs its own proof.

Every technique we now take for granted has to be earned, just as when the ladder adopted the equal sign. 0b had to build the turning about of a sameness, and 4a to prove it. Here the same care is owed to adding. This is the earliest technique of adding, and the earliest induction of the arithmetic.

Zero-plus technique: 0 added to a number, on the left, gives that number. In marks: 0 + p = p.

Example: 0 + 1 = 0 + S(0) = S(0 + 0) = S(0) = 1.

Plan: induct on the number. The base is plus-zero with 0. The step uses plus-a-next and the hypothesis.

\varphi(a):\ \ 0 + a = a @@ the condition, with its gap at a
0 + 0 = 0 @@ the plus-zero technique, with a = 0: the base
\text{let } a \in \mathbb N;\ \ \text{assume } 0 + a = a @@ the step opens: the induction hypothesis
\qquad 0 + S(a) = S(0 + a) @@ the plus-a-next technique
\qquad \phantom{0 + S(a)} = S(\htmlClass{keep}{a}) @@ the hypothesis, inside (the swap axiom)
\htmlClass{new}{\forall a \in \mathbb N\;\; 0 + a = a} \quad \blacksquare @@ prove an if; speak of everything; the induction technique

4f7The Next One on the Left

Plus-a-next moves the next-one gesture out of the right-hand number. Its partner moves it out of the left.

Next-on-the-left technique for plus: adding to the next one after a number gives the next one after the sum. In marks: S(p) + b = S(p + b).

Example: S(2) + 1 = 3 + 1 = 4, and S(2 + 1) = S(3) = 4.

Plan: keep the left-hand number fixed and induct on b, the number plus-a-next can act on.

\text{let } a \in \mathbb N;\ \ \varphi(b):\ S(a) + b = S(a + b) @@ a kept fixed; the gap at b
S(a) + 0 = S(a) = S(a + 0) @@ plus-zero; plus-zero inside, turned about: the base
\text{let } b \in \mathbb N;\ \ \text{assume } S(a) + b = S(a + b) @@ the step opens
\qquad S(a) + S(b) = S(S(a) + b) @@ the plus-a-next technique
\qquad \phantom{S(a) + S(b)} = S(\htmlClass{keep}{S(a + b)}) @@ the hypothesis, inside
\qquad \phantom{S(a) + S(b)} = S(\htmlClass{new}{a + S(b)}) @@ the plus-a-next technique inside, turned about
\htmlClass{new}{\forall b \in \mathbb N\;\; S(a) + b = S(a + b)} \quad \blacksquare @@ the induction technique; a was any number

4f8The Order Does Not Matter

With zero-plus and next-on-the-left for plus in hand, the order of the numbers added does not matter.

Turn-about technique for plus: a sum is the same in either order. In marks: p + b = b + p. The accepted word for this is commutative, from the Latin commutare, “to exchange”. You already know it. Three apples and two apples make the same as two apples and three.

Example: 1 + 3 = 4, as 4f4 unfolded, and 3 + 1 = 4, as 4f5 gave.

Plan: keep p fixed and induct on b. The base needs zero-plus. The step needs next-on-the-left.

\text{let } a \in \mathbb N;\ \ \varphi(b):\ a + b = b + a @@ a kept fixed
a + 0 = a = 0 + a @@ the plus-zero technique; the zero-plus technique, turned about: the base
\text{let } b \in \mathbb N;\ \ \text{assume } a + b = b + a @@ the step opens
\qquad a + S(b) = S(a + b) @@ the plus-a-next technique
\qquad \phantom{a + S(b)} = S(\htmlClass{keep}{b + a}) @@ the hypothesis, inside
\qquad \phantom{a + S(b)} = \htmlClass{new}{S(b) + a} @@ the next-on-the-left technique for plus, turned about
\htmlClass{new}{\forall b \in \mathbb N\;\; a + b = b + a} \quad \blacksquare @@ the induction technique; a was any number

Look at what the base needed: zero-plus. Try to prove turn-about for plus without proving zero-plus before it. The base is 0 + p = p, which is zero-plus, so you would be proving it inside turn-about for plus anyway.

Techniques come in a pecking order, and finding which earlier technique a proof needs is most of the work.

4f9The Brackets Do Not Matter

Next, the brackets. Regroup technique for plus: in a sum of three numbers, which pair is added first does not change the sum. In marks: (p + b) + c = p + (b + c).

Example: (1 + 1) + 2 = 2 + 2 = 4, and 1 + (1 + 2) = 1 + 3 = 4.

Plan: keep the first two numbers fixed and induct on the third, where plus-a-next acts.

\text{let } a, b \in \mathbb N;\ \ \varphi(c):\ (a + b) + c = a + (b + c) @@ a and b kept fixed
(a + b) + 0 = a + b = a + (b + 0) @@ the plus-zero technique; plus-zero inside, turned about: the base
\text{let } c \in \mathbb N;\ \ \text{assume } (a + b) + c = a + (b + c) @@ the step opens

4f10Taking Away Again

Last, cancelling. Cancel technique for plus: if sums agree after adding the same number, they agreed before. In marks: p + c = b + c ⇒ p = b.

Example: if p + 2 = 5 + 2, then p = 5.

Plan: keep p and b fixed and induct on c. The step is where 4b's different-nexts comes in: different numbers have different next ones, so sameness of the next ones carries back to sameness of the numbers.

\text{let } a, b \in \mathbb N;\ \ \varphi(c):\ a + c = b + c \Rightarrow a = b @@ a and b kept fixed
a + 0 = b + 0 \Rightarrow a = b @@ plus-zero on each side; the techniques turn-about and chain; prove an if: the base
\text{let } c \in \mathbb N;\ \ \text{assume } \varphi(c) @@ the step opens
\qquad \text{assume } a + S(c) = b + S(c) @@ aiming at φ(S(c))
\qquad S(a + c) = S(b + c) @@ the plus-a-next technique, on each side
\qquad a + c = b + c @@ the different-nexts technique
\qquad \htmlClass{new}{a = b} @@ carry the hypothesis through
\htmlClass{new}{\forall c \in \mathbb N\;\; (a + c = b + c \Rightarrow a = b)} \quad \blacksquare @@ prove an if; speak of everything; the induction technique

With turn-about for plus, cancelling works on the left as well: c + p = c + b gives p + c = b + c, and so p = b. These techniques have accepted names, given in the cellar.

4f12Running It Backwards

Given a sum, unfold. Unpack the right-hand name, use plus-a-next, and repeat until plus-zero applies. Then pack the names.

Given a result and a number added, ask what the other must be. Which b has 1 + b = 4? Unfolding 1 + 3 shows that 3 does.

Is it the only one? Suppose 1 + b = 4 and 1 + b′ = 4. Then 1 + b = 1 + b′, so b + 1 = b′ + 1 by turn-about for plus, and b = b′ by cancel for plus. So exactly one number takes 1 to 4, and it is 3.

That is the question a later mark will answer in general. On this rung it is answered case by case: find the number, and cite cancel for plus for “no other”.

Wanting a technique, you find the earlier techniques its step needs, and prove those before it. Then induct on the right-hand letter, because that is where plus-a-next can act. Found upward; written downward.

Who said it first

The schoolteacher, in Stettin, is Hermann Grassmann; the writer a generation later is Giuseppe Peano. The author of the whole book is Edmund Landau, and the younger mathematician with the simpler proof is László Kalmár.

Hermann Grassmann, a schoolteacher in Stettin, wrote a textbook of arithmetic in which adding is defined by exactly this pair of lines and every technique of adding and multiplying is proved from them by induction. It seems nobody had done so before. Peano, a generation later, put the same pair of lines at the head of his arithmetic.

Grassmann, Lehrbuch der Arithmetik für höhere Lehranstalten (1861); Peano, Arithmetices principia (1889)

Edmund Landau wrote a whole book that builds the numbers and their techniques in this style, technique by technique, and told the students who read it to forget the arithmetic they had learned at school, since they had not really learned it. In his preface he records that, at the last minute, László Kalmár showed him a much simpler proof that adding exists, and that he used it.

Landau, Grundlagen der Analysis (1930), the prefaces

Accepted names

Turn-about for plus is the commutative law of addition; regroup for plus, the associative law; cancel for plus, the cancellation law.
