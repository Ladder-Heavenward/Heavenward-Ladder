40e · proof

Recursion Is Induction

40d ran fact. This step proves it right, and proves that it stops, with rung 4’s tools and nothing new.

To prove a function that calls itself, assume it right on smaller inputs: that is induction. To prove it stops, find a whole number that falls at every call.

40e1Right on Every Input

Claim: fact(n) = n! for every whole number n. The proof is induction on n (4c).

\text{fact}(0) = 1 = 0! @@ the start case, by the program
\text{suppose fact}(k) = k! @@ the case of any k
\text{fact}(k + 1) = (k + 1) \cdot \text{fact}(k) = (k + 1) \cdot k! = (k + 1)! @@ the program’s step, then the supposition
\htmlClass{new}{\text{fact}(n) = n! \text{ for every } n} \quad \blacksquare @@ induction

The program’s start case is the proof’s start case, and the program’s call is the proof’s step. A recursive program and its induction have the same shape.

40e2It Stops

Each call of fact is on n − 1, a smaller whole number. A falling run of whole numbers cannot go on for ever, since the set of its values would have no least member, and 4h says every non-empty set of whole numbers has one.

Falling-measure technique: if each call is on an input whose whole-number measure is smaller than the caller’s, then every run of calls stops.

40e3When the Measure Is Not the Input

gcd(a, b): if b = 0, give a; otherwise give gcd(b, r), where r is the remainder of a by b. The input is a pair, and the measure is b. It falls because a remainder is less than its divisor (4j).

It is right because a and b have exactly the same common divisors as b and r: a = qb + r, so whatever divides b and r divides a, and whatever divides a and b divides r = a − qb. So the greatest one is the same, and gcd(a, 0) = a is the start.

40e4A Function With No Measure Known

Not every function that calls itself stops. f(n) = f(n) never does. For some functions nobody knows a measure: g(n) calls g(n/2) when n is even and g(3n + 1) when n is odd, and stops at 1. Whether it stops for every n is an old open question.

So the falling-measure technique is a tool to use, not a test to run. Rung 41 shows that no machine can find such a measure for every program.

40e5Moves to Watch Out For

\text{assume fact}(n) \text{ right to prove fact}(n) \text{ right}\,? @@ <span class="vd vd-s">out of sequence</span> circular: assume it only on smaller inputs
\text{the input itself must fall}\,? @@ <span class="vd vd-p">outside the plan</span> any whole-number measure will do, as b does for gcd
\text{a falling run of fractions stops}\,? @@ <span class="vd vd-p">outside the plan</span> 1, 1/2, 1/4, … falls for ever; the measure must be a whole number

The accepted names

Proving a recursive function by induction over its calls is structural induction. A falling whole-number measure is a variant, or ranking function, and proving that a program stops is a termination proof. The halve-or-triple function is the Collatz problem. (Its open status was not revisited for this page.)
