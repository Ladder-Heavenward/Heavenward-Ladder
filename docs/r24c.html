24c · proof

A Map That Shrinks Has One Fixed Point

On rung 22 you saw that a statement which pulls every two numbers closer together, fed its own answers, settles at the one number it leaves alone. This step makes the same idea work for functions. To do that you need a way to say how far apart two functions are, and the simplest is the largest gap between their graphs. With that distance, a list of functions that crowds together settles everywhere at once, onto a function with no breaks. And a map that takes functions to functions, and pulls every two of them closer by a fixed fraction, has exactly one function it leaves alone. Repeated integration will turn out to be such a map.

Measure the distance between two functions by the largest gap between them. Lists of functions that crowd in that distance settle everywhere at once. A map on functions that pulls every two closer by a fixed fraction has exactly one function it leaves alone.

24c1The Largest Gap

From here on, for functions f and g continuous on [u, v], ‖f − g‖ is the largest value of |f(x) − g(x)| on [u, v]. It exists by 12c, since |f − g| is continuous there. Read it "the largest gap between f and g". Accepted name: the sup norm, or uniform distance.

\|f - g\| \ge 0, \text{ and } \|f - g\| = 0 \Leftrightarrow f = g @@ every gap is 0 exactly when the largest is
\|f - g\| = \|g - f\| @@ |f(x) − g(x)| = |g(x) − f(x)|
|f(x) - h(x)| \le |f(x) - g(x)| + |g(x) - h(x)| \le \|f - g\| + \|g - h\| @@ the triangle technique (8h), at each x
\htmlClass{new}{\|f - h\| \le \|f - g\| + \|g - h\|} \quad \blacksquare @@ the bound holds at the x where the left side is largest

And settling everywhere at once is settling in this distance: fₙ settles everywhere at once to f on [u, v] exactly when ‖fₙ − f‖ heads to 0. The "one N for every x" of 23d2 is one N for the largest gap.

24c2Crowding Functions Settle

Function-crowd technique: if continuous fₙ on [u, v] crowd in the largest gap, meaning for every ε > 0 some N makes ‖fₘ − fₙ‖ < ε for all m, n ≥ N, then they settle everywhere at once to a continuous f. The line of reals has no holes, and neither does this space of functions.

|f_m(x) - f_n(x)| \le \|f_m - f_n\| @@ each gap is at most the largest
f_n(x) \text{ crowds, so settles; call its limit } f(x) @@ the crowd technique (22c2), at each x
n \ge N:\ |f_n(x) - f_m(x)| < \varepsilon \text{ for every } m \ge N \text{ and every } x @@ the crowding, with one N
n \ge N:\ |f_n(x) - f(x)| \le \varepsilon \text{ for every } x @@ let m grow: limits keep ≤ (10b)
f_n \to f \text{ everywhere at once} @@ one N for every x
\htmlClass{new}{f \text{ is continuous on } [u, v]} \quad \blacksquare @@ kept continuity (23d3)

One more fact for the next steps. If every fₙ takes values in a closed interval [c, d], so does f, since limits keep ≤ and ≥.

24c3A Map That Shrinks

Let D be the continuous functions on [u, v] with values in [c, d], and T a map that sends each f in D to a function Tf in D.

Shrinking-map technique: if ‖Tf − Tg‖ ≤ k‖f − g‖ for all f, g in D and one k < 1, then exactly one f in D has Tf = f; and from any start f₀ in D, fₙ₊₁ = Tfₙ settles everywhere at once to it. It is 22h3 again, with the largest gap in place of the distance between numbers.

\|f_{n+1} - f_n\| \le k^n \|f_1 - f_0\| @@ apply the shrink n times
\|f_m - f_n\| \le \tfrac{k^n}{1-k}\|f_1 - f_0\| \ \ (m > n) @@ add the steps (24c1's triangle); the geometric sum (15i)
f_n \to f \text{ everywhere at once},\ f \in D @@ the function-crowd technique (24c2)
\|Tf - f\| \le \|Tf - Tf_n\| + \|f_{n+1} - f\| \le k\|f - f_n\| + \|f_{n+1} - f\| \to 0 @@ Tfₙ = fₙ₊₁
Tg = g,\ Tf = f \Rightarrow \|f - g\| \le k\|f - g\| \Rightarrow f = g @@ k < 1
\htmlClass{new}{\text{exactly one } f \in D \text{ with } Tf = f, \text{ and } T^n f_0 \to f} \quad \blacksquare @@ the lines above

The proof also says how fast: after n rounds you are within kⁿ/(1 − k) times the first step of the answer. Each round wins a fixed share of the remaining distance.

24c4One Width for a Whole Family

A continuous function on [u, v] has one width δ for each ε, serving every pair of inputs (15f). From here on, a family of functions on [u, v] shares one width when, for every ε > 0, one δ > 0 serves every pair of inputs and every function of the family: |s − t| < δ gives |f(s) − f(t)| < ε, whichever f.

The powers x, x², x³, … on [0, 1] do not share one. Each is continuous, and all lie between 0 and 1. But near 1 they climb more and more steeply: xⁿ falls from 1 to ½ over a stretch that shrinks to nothing as n grows. No δ serves ε = ½ for all of them.

Shared-width technique: if continuous fₙ on [u, v] settle everywhere at once, they share one width.

\|f_n - f\| \lt \varepsilon \text{ for } n \ge N @@ they settle everywhere at once, to a continuous f (24c1, 23d)
|s - t| \lt \delta_0 \Rightarrow |f(s) - f(t)| \lt \varepsilon @@ f is uniformly continuous (15f)
\begin{aligned}|f_n(s) - f_n(t)| &\le |f_n(s) - f(s)|\\ &\quad + |f(s) - f(t)|\\ &\quad + |f(t) - f_n(t)| \lt 3\varepsilon\end{aligned} @@ for n ≥ N and |s − t| < δ₀: the triangle technique, twice
|s - t| \lt \delta_n \Rightarrow |f_n(s) - f_n(t)| \lt \varepsilon @@ for each n below N, on its own (15f)
\htmlClass{new}{\delta = \min(\delta_0, \delta_1, \ldots, \delta_{N-1}) \text{ serves all}} \quad \blacksquare @@ finitely many widths have a least one

So the powers of x cannot settle everywhere at once on [0, 1], and now there are two reasons: their limit is not continuous (23d), and they share no width. The next footing runs the technique the other way round, as far as it will go.

24c5A Settling Thread Out of a Bounded Family

Every sequence of numbers with a floor and a ceiling has a thread that settles (22b). For functions one bound is not enough: every thread of x, x², x³, … on [0, 1] heads to the same broken limit, so none settles everywhere at once. One bound and one shared width are enough.

Thread-of-functions technique: if |fₙ(x)| ≤ M for every n and every x in [u, v], and the fₙ share one width, then some thread of the fₙ settles everywhere at once on [u, v].

First a thread is found that settles at each halving point of [u, v]: the ends, the middle, the quarters, the eighths, and on, laid end to end in one list p₁, p₂, p₃, ….

f_n(p_1) \text{ has a thread that settles} @@ the numbers fₙ(p₁) lie between −M and M: the halving technique for sequences (22b)
\text{a thread of that thread settles at } p_2 @@ the same; and it still settles at p₁ (the thread technique, 22b)
\text{and so on: thread } j \text{ settles at } p_1, \ldots, p_j @@ each a thread of the one before
g_k = \text{the } k\text{th function of thread } k @@ go down the diagonal
\htmlClass{new}{g_k(p_j) \text{ settles, for every } j} \quad \blacksquare @@ from the jth on, the gₖ are a thread of thread j

No one thread of the list was good enough, since each was only good for finitely many points. The diagonal takes a little of every thread and is good for all of them. Now the shared width spreads the settling from the halving points to every point.

|s - t| \lt \delta \Rightarrow |g_k(s) - g_k(t)| \lt \varepsilon @@ the shared width, for every k
p_1, \ldots, p_J \text{ come within } \delta \text{ of every } x @@ far enough down the list to hold a whole set of halving points closer than δ
|g_k(p_j) - g_m(p_j)| \lt \varepsilon \text{ for } k, m \ge K @@ settle-crowd (22c) at each of p₁, …, p_J; K is the largest of the J
\begin{aligned}|g_k(x) - g_m(x)| &\le |g_k(x) - g_k(p_j)|\\ &\quad + |g_k(p_j) - g_m(p_j)|\\ &\quad + |g_m(p_j) - g_m(x)| \lt 3\varepsilon\end{aligned} @@ with pⱼ within δ of x
\htmlClass{new}{\|g_k - g_m\| \le 3\varepsilon:\ g_k \text{ settles at once}} \quad \blacksquare @@ the function-crowd technique (24c2)

With 24c4 this closes a circle. A sequence that settles everywhere at once is bounded and shares one width. A sequence that is bounded and shares one width has a thread that settles everywhere at once. On the line the same circle was: settling sequences are bounded, and bounded sequences have settling threads.

24c6Climbing Functions Settle at Every Point

The powers xⁿ on [0, 1] share no width, yet they do settle at every point. They are increasing functions. For increasing functions the shared width can be dropped, at a price: the thread settles point by point, and not always at once.

Climbing-thread technique: if each fₙ is increasing on [u, v], with values in [0, 1], then some thread of the fₙ settles at every point of [u, v], and its limit is increasing.

Take the diagonal thread gₖ of 24c5. It needed only the bound to settle at every halving point pⱼ. Call its limit there cⱼ. An increasing function g jumps at x when its values just left of x and just right of x stay a fixed distance apart; where it does not jump, it is continuous.

p_i \le p_j \Rightarrow c_i \le c_j @@ each gₖ is increasing, and limits keep ≤
g(x) = \sup\{c_j : p_j \le x\} @@ no-holes (8c); g is increasing, with values in [0, 1], and g(pⱼ) = cⱼ
p_i \lt x \lt p_j:\ \ g_k(p_i) \le g_k(x) \le g_k(p_j) @@ gₖ is increasing
c_i - \varepsilon \lt g_k(x) \lt c_j + \varepsilon \text{ for } k \text{ large} @@ the ends settle, at cᵢ and cⱼ
\htmlClass{new}{g \text{ continuous at } x \Rightarrow g_k(x) \to g(x)} \quad \blacksquare @@ halving points close to x on both sides have cᵢ and cⱼ within ε of g(x)

That leaves the points where g jumps. There may be endlessly many, but they can be put in one list, and then the diagonal handles them.

\text{at most } m \text{ jumps are above } 1/m @@ g climbs from at least 0 to at most 1, so its jumps add to at most 1
q_1, q_2, q_3, \ldots:\ \text{every jump of } g @@ lay those finite lists end to end, for m = 1, 2, 3, …
\text{a thread of } g_k \text{ settles at every } q_i @@ down the diagonal again (24c5): the values are bounded
\htmlClass{new}{\text{it settles at every point of } [u, v]} \quad \blacksquare @@ off the jumps by the first half, since it is a thread of gₖ (22b)

The limit is increasing, since limits keep ≤. It need not be continuous: for xⁿ it is 0 below 1 and 1 at 1. So the settling is not always at once (23d). Climbing bought a thread without any shared width, and the price was the largest gap.

24c7A Solution When F Is Only Continuous

The area form (24b) turned y′ = F(x, y) with y(x₀) = y₀ into y(x) = y₀ + ∫ from x₀ to x of F(t, y(t)) dt. Is there always a y that fits? The thread-of-functions technique (24c5) finds one, and it asks little of F.

Say F has one width on a rectangle R when, for every ε > 0, some δ > 0 gives |F(x, y) − F(s, t)| < ε for all points of R with |x − s| < δ and |y − t| < δ. Let R be the rectangle |x − x₀| ≤ α, |y − y₀| ≤ b.

Broken-line technique: if F has one width on R and |F| ≤ M there, and 0 < h ≤ α with hM ≤ b, then y′ = F(x, y), y(x₀) = y₀ has a solution on [x₀, x₀ + h]. The same holds to the left of x₀.

Cut [x₀, x₀ + h] into n equal pieces at x₀ < x₁ < ⋯ < xₙ. The broken line fₙ starts at y₀ and, on each piece from xᵢ to xᵢ₊₁, is straight with the slope F(xᵢ, fₙ(xᵢ)): it reads the slope at the start of the piece and keeps it to the end.

|f_n(s) - f_n(t)| \le M\,|s - t| @@ every piece has a slope of size at most M
|f_n(x) - y_0| \le Mh \le b @@ so the broken line stays in R, and the next slope can be read
\text{one bound, and one shared width} @@ |fₙ| ≤ |y₀| + b; and δ = ε/M serves every fₙ
\htmlClass{new}{\text{a thread of } f_n \text{ settles at once, to } f} \quad \blacksquare @@ the thread-of-functions technique (24c5); f is continuous (23d)

Now see how nearly a broken line fits the area form. On the piece from xᵢ, write Δₙ(t) = F(xᵢ, fₙ(xᵢ)) − F(t, fₙ(t)): the slope the line uses, less the slope the statement asks for at t.

f_n(x) = y_0 + \textstyle\int_{x_0}^{x} F(t, f_n(t))\,dt + \int_{x_0}^{x} \Delta_n(t)\,dt @@ area-is-a-change (16c), piece by piece
|\Delta_n(t)| \lt \varepsilon \text{ for } n \text{ large} @@ |t − xᵢ| ≤ h/n and |fₙ(t) − fₙ(xᵢ)| ≤ Mh/n: the one width of F
|F(t, f_n(t)) - F(t, f(t))| \lt \varepsilon @@ along the thread, for n large: ‖fₙ − f‖ < δ, and the one width of F again
\text{both areas move by at most } h\varepsilon @@ smaller function, smaller area (15e)
\htmlClass{new}{f(x) = y_0 + \textstyle\int_{x_0}^{x} F(t, f(t))\,dt} \quad \blacksquare @@ let n grow along the thread; so f is a solution (24b)

Read the technique closely: a solution, not the solution. The thread was picked, and another thread may head somewhere else. Take y′ = √|y| with y(0) = 0. Here F has one width on every rectangle, since |√|y| − √|t|| ≤ √|y − t|. And y = 0 fits, and so does y = x²/4 for x ≥ 0: its slope is x/2, which is √(x²/4). Continuity of F buys a solution. It does not buy only one.

The accepted names

The largest gap is the supremum (uniform, or infinity) norm, written ‖·‖∞. The function-crowd technique says the space C[u, v] of continuous functions is complete in that norm (a Banach space). The shrinking-map technique is the contraction mapping principle, or the Banach fixed-point theorem. A family that shares one width is equicontinuous. The thread-of-functions technique is Arzelà’s and Ascoli’s; going down the diagonal is the diagonal argument. The climbing-thread technique is Helly’s, on selection. The broken-line technique is Peano’s, on existence; the broken lines are Euler’s.

Who said it first

Stefan Banach proved the principle in general in his 1920 thesis, published in 1922; Picard's and Lindelöf's existence proofs had used the same idea for statements on rates thirty years earlier. Maurice Fréchet, in 1906, first treated functions as points of a space with a distance.
