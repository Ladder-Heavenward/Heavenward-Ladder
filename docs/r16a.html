16a · proof

The area function

Rung 15 gave each integrable function on each closed interval one number. Keep the left end still and let the right end move, and those numbers become a function: the area so far, as a function of where the edge has reached. This step defines it, settles a letter clash it causes, and proves the first fact about it. The area function never jumps, even when the function under it does. A bound on the height is a bound on how fast the area can change.

The area function measures the area from a fixed start out to a moving edge. It splits at any point, taken in any order. If the height never passes a bound, the area between two edges is at most that bound times the distance between them. So the area function never jumps.

16a1A stand-in letter

In ∫ₚ^q f(x) dx, the letter x names no number. 15c's sums use the values of f on each piece. The integral is one number made from all of them. x only says which slot of f is being run through. Writing ∫ₚ^q f(t) dt or ∫ₚ^q f(z) dz says the same thing and names the same number. The letter can be swapped for any letter not already in use.

From here on, the letter after d in an integral is a stand-in letter: it names no number outside the integral. Its accepted name is the variable of integration, or the dummy variable.

That matters as soon as an end of the integral is itself a letter. In ∫ₛˣ f(x) dx the one letter x would be asked to do two jobs. It would be the fixed right end, and it would also run from s up to that end. 0a's rule is that a name names one thing at a time, so the inside letter is changed: ∫ₛˣ f(t) dt.

16a2The area function

From here on, if f is integrable on every closed interval inside an interval I, and s is in I, the area function of f from s is the function F on I with F(x) = ∫ₛˣ f(t) dt. F is a name, for a function, and F(x) packs the integral from s to x. Its accepted name is an integral function, or an accumulation function. It is sometimes also named the indefinite integral, a name 16c gives to something else.

For x > s this is rung 15's area, counted negative where f is below the axis. For x = s it is 0. For x < s it is −∫ₓˢ f(t) dt, by 15e's convention. To work with it across all three cases, interval-cut-in-two is needed in every order.

Split-in-any-order technique: if f is integrable on every closed interval inside I, then for any p, q, r in I, ∫ₚ^q f = ∫ₚ^r f + ∫ᵣ^q f.

\text{swap } p, q:\ \text{both sides change sign} @@ 15e's convention on each of the three integrals; so take p ≤ q
p = q:\ \ 0 = \textstyle\int_p^r f + \int_r^p f @@ 15e's convention, both ways round
p \lt r \lt q:\ \text{interval-cut-in-two as it stands} @@ interval-cut-in-two (15e); parts-integrable for the pieces
r \lt p \lt q:\ \textstyle\int_r^q = \int_r^p + \int_p^q,\ \text{so } \int_p^q = \int_p^r + \int_r^q @@ interval-cut-in-two on [r, q]; then 15e's convention for ∫ᵣᵖ
p \lt q \lt r:\ \textstyle\int_p^r = \int_p^q + \int_q^r,\ \text{so } \int_p^q = \int_p^r + \int_r^q @@ interval-cut-in-two on [p, r]; then the convention for ∫_q^r
r = p \text{ or } r = q:\ \text{one term is } 0 \quad \blacksquare @@ ∫ₚᵖ f = 0

So F(y) − F(x) = ∫ₓʸ f(t) dt for any x and y in I, whichever is larger and wherever s sits. The change in the area function between two points is the integral between them, and nothing else.

16a3A bound on the height bounds the change

Area-bound technique: if f is integrable on [p, q] and |f(t)| ≤ M for every t there, then |∫ₚ^q f| ≤ M(q − p).

-M \le f(t) \le M \text{ on } [p, q] @@ unpack-the-bars (8h)
-M(q - p) \le \textstyle\int_p^q f \le M(q - p) @@ smaller-function-smaller-area (15e), its second form, with m = −M
|\textstyle\int_p^q f| \le M(q - p) \quad \blacksquare @@ unpack-the-bars

Area-never-jumps technique: if f is integrable on [b₁, b₂] and s is in [b₁, b₂], the area function F of f from s is continuous on [b₁, b₂]. In fact, if |f| ≤ M there, |F(y) − F(x)| ≤ M|y − x| for all x and y in [b₁, b₂].

\text{some } M \text{ has } |f(t)| \le M \text{ on } [b_1, b_2] @@ 15c: integrable means bounded, then unpack-the-bars
x \lt y:\ \ F(y) - F(x) = \textstyle\int_x^y f(t)\,dt @@ split-in-any-order
|F(y) - F(x)| \le M(y - x) @@ area-bound on [x, y]; parts-integrable
\text{fix } x, \varepsilon \gt 0;\ \ \delta = \tfrac{\varepsilon}{M + 1} @@ M + 1 > 0, so δ > 0
|y - x| \lt \delta \Rightarrow |F(y) - F(x)| \le M|y - x| \lt (M + 1)\delta = \varepsilon @@ the bound, either order; order-and-arithmetic-agree
\htmlClass{new}{F \text{ is continuous at every } x \text{ of } [b_1, b_2]} \quad \blacksquare @@ 11a's line; from one side at b₁ and b₂

The bound M is one number for the whole interval, so a single δ serves every x at once: the area function is even uniformly continuous, in 15f's sense. And nothing was asked of f but an area. f may jump; F cannot.

16a4Three area functions

f(t) = k:\ \ F(x) = \textstyle\int_s^x k\,dt = k(x - s) @@ 15c: a constant's sums are all k(x − s); for x < s the convention
f(t) = t,\ s = 0,\ x \ge 0:\ \ F(x) = \tfrac{x^2}{2} @@ 15d with b = x
f(t) = t^2,\ s = 0,\ x \ge 0:\ \ F(x) = \tfrac{x^3}{3} @@ 15i's area-under-a-power with k = 2
f = u \text{ on } [-1, 1],\ s = 0:\ \ F(x) = \begin{cases} 0 & x \le 0 \\ x & x \gt 0 \end{cases} @@ x > 0: u = 1 on [0, x]; x < 0: F(x) = −∫ₓ⁰ u, and on [x, 0] u is 0 but at 0, so the upper sums' last piece shrinks (everyday-counting-passes)

The step u jumps at 0; its area function from 0 does not. It has a joint at 0, the shape of 13f's joints: arriving at the same height, leaving at a different rate. Going from f to F has made things smoother: a jump has become a joint.

Who said it first

Mathematical quantities, Newton wrote, are not made of very small parts, but described by a continued motion: lines by the motion of points, surfaces by the motion of lines, and so on, as they are actually generated in nature and seen in the motion of bodies.

Newton, Tractatus de quadratura curvarum (1704), introduction; paraphrase

In 16a.4.4, the sweeping line is Newton’s; the sum of strips, ∫, is Leibniz’s.
