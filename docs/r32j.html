32j · technique

Turning rate rules into algebra

Rung 24 solved rules that tie a function to its slopes, and rung 26 finished the swinging spring with a brake. Those rules were solved by guessing a shape and checking it. When the push on the spring repeats, or when the push is any signal at all, there is a better way. A slope of a turning is the same turning times a number. So a rule made of slopes, fed a turning, gives back the same turning times a number, and solving the rule is one division. Split the push into turnings, divide each one by its own number, and add them up again: that is the answer. This step does it for a spring pushed by a repeating force, where one speed of the push can ring the spring far harder than the others, and then for a circuit fed any signal at all, where the number to divide by, for each frequency, describes the circuit completely.

For a repeating solution, each slope multiplies the nth coefficient by i n, so a rule with constant coefficients becomes one division for each speed. A spring pushed by a repeating force answers each speed of the push separately, and the speed nearest its own is amplified most. On the whole line, a slope multiplies the transform by two π i times the frequency, and the rule divides the transform of the input by one function of the frequency.

32j1A rate rule becomes one division per speed

Let f repeat every 2π, and look for a y that repeats every 2π, with two continuous slopes, and obeys y″ + by′ + cy = f, for fixed real b and c.

Rate-to-algebra technique: a repeating solution of y″ + by′ + cy = f has coefficients cₙ(y) = cₙ(f) / (c − n² + ibn); so when no c − n² + ibn is 0, there is exactly one repeating solution.

c_n(y') = in\,c_n(y),\ \ c_n(y'') = (in)^2c_n(y) = -n^2c_n(y) @@ the corner-and-jump technique (32h3), twice
(-n^2 + ibn + c)\,c_n(y) = c_n(f) @@ coefficients add (32a2), so the rule holds speed by speed
c_n(y) = \tfrac{c_n(f)}{c - n^2 + ibn} @@ when the bottom is not 0
\text{two repeating solutions have the same coefficients} @@ the last line names no choice
\htmlClass{new}{\text{exactly one repeating solution}} \quad \blacksquare @@ a function is fixed by its coefficients (32b3); the divided list has a settling sum of squares, and gives a solution

The bottom is 0 only when b = 0 and c = n² for some whole n: a spring with no brake whose own speed matches a speed of the push. Then that speed of the push must be absent, or no repeating solution exists. The rule of 24h, y″ = −n²y, is the case f = 0 at that speed.

32j2A spring pushed by a repeating force

A spring with own speed ω₀ and a light brake β obeys y″ + 2βy′ + ω₀²y = f. Every solution is the repeating one plus a decaying turn (the decaying-turn technique, 26·cb24), so after a while only the repeating one is left.

Driven-response technique: a braked spring answers each speed n of a repeating push separately, with its push scaled by 1/√((ω₀² − n²)² + 4β²n²); the speed nearest ω₀ is scaled the most.

c_n(y) = \tfrac{c_n(f)}{\omega_0^2 - n^2 + 2i\beta n} @@ the rate-to-algebra technique (32j1)
|\omega_0^2 - n^2 + 2i\beta n| = \sqrt{(\omega_0^2 - n^2)^2 + 4\beta^2n^2} @@ the size of a complex number (25c)
\htmlClass{new}{|c_n(y)| = \tfrac{|c_n(f)|}{\sqrt{(\omega_0^2 - n^2)^2 + 4\beta^2n^2}}} \quad \blacksquare @@ the size of a quotient (25c)
  
f = q,\ \ \omega_0 = 3.02,\ \ \beta = 0.05 @@ the square wave of 32h1: amounts 4/(πn) at odd n
n = 1:\ \ \tfrac{1.273}{\sqrt{(9.12 - 1)^2 + 0.01}} \approx 0.157 @@ the push’s largest speed, far from ω₀
n = 3:\ \ \tfrac{0.424}{\sqrt{(9.12 - 9)^2 + 0.09}} \approx 1.31 @@ the push’s third speed, next to ω₀
n = 5:\ \ \approx 0.016,\ \ n = 7:\ \ \approx 0.005 @@ far again
\htmlClass{new}{\text{the spring swings mostly at speed } 3} \quad \blacksquare @@ eight times the first speed’s swing

So a push that flips once a turn rings a spring tuned to three times that speed, as a child on a swing can be pushed every third swing. The push’s third speed holds a third of the amount of its first, and the spring makes it the loudest by far.

32j3Any signal, and the transfer function

A signal on the whole line need not repeat. The same move works with transforms in place of coefficients.

Transfer technique: if y and f have finite total sizes, with y′ too, and y′ + ky = f with k > 0, then ŷ(ξ) = f̂(ξ) / (k + 2πiξ); the rule divides every frequency of the input by its own number.

\widehat{y'} = 2\pi i\xi\,\hat y @@ the slope-to-frequency technique (32f1)
(2\pi i\xi + k)\,\hat y(\xi) = \hat f(\xi) @@ transforms add
\htmlClass{new}{\hat y(\xi) = H(\xi)\,\hat f(\xi),\ \ H(\xi) = \tfrac{1}{k + 2\pi i\xi}} \quad \blacksquare @@ k + 2πiξ is never 0 for k > 0

H is the transfer function: the gain-per-turning number of 32i2, for every frequency at once. A circuit of a resistor R and a capacitor C, fed a voltage f, has a charge voltage y with y′ + ky = kf, where k = 1/(RC), so its gain is |kH(ξ)|. With R = 1 kΩ and C = 1 μF, k = 1000 per second. At 50 Hz the gain is 1/√(1 + (2π × 50/1000)²) ≈ 0.954; at 1000 Hz it is 1/√(1 + 4π²) ≈ 0.157. The circuit passes low tones and cuts high ones.

The basement · there if you want it

The accepted names

The rate-to-algebra technique is the Fourier method for linear ordinary differential equations with constant coefficients, and the repeating solution the steady-state (or periodic) solution; the decaying part is the transient. The driven-response technique gives the amplitude response of a forced, damped harmonic oscillator, and the peak near ω₀ is resonance. H(ξ) is the transfer function, or frequency response, of a linear time-invariant system; the RC circuit is a first-order low-pass filter, with cut-off frequency 1/(2πRC), about 159 Hz in the example.

Who said it first

Fourier invented the method in 1807 for heat in a ring. Oliver Heaviside turned rate rules into algebra in the 1880s with his operational calculus, writing p for the slope and dividing by it, to the scandal of mathematicians, and was vindicated by the transforms of the next decades. Hendrik Bode and Harry Nyquist made the transfer function the language of feedback design at Bell Labs in the 1930s.

A proof that is not allowed

“Write y′ + ky = f as (D + k)y = f, where D is the slope; divide: y = f/(D + k).” Not allowed: D is not a number, and there is nothing to divide by. The transfer technique does the same division honestly, at each frequency, where D has become the number 2πiξ.
