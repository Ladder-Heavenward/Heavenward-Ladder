16f · technique

The Table Run Backwards

Every slope rung 13 found is, read the other way, an antiderivative. Rung 13 built a table. It holds the slope of a constant, of a whole power, of a fractional power, of a sum, of a constant times a function, and of a function of a straight line. This step turns the table round, so that an integral can be looked up instead of worked out. It also checks every entry the one way that never fails, by taking the slope of the answer. Two warnings come with the table. An antiderivative is only promised on an interval, so a gap in the domain lets the constant change across the gap. And one entry is missing: no power has slope one over the input.

Read rung 13’s slopes backwards. The undone power is the power one higher, divided by that higher power, plus any constant, for every fractional power but negative one. Sums and constant factors pass through. Check by taking the slope. Pin down the constant with one known value.

16f1The Table

\textstyle\int k\,dx = kx + C @@ constant-has-slope-0, slope-of-a-line (13a): (kx)′ = k
\textstyle\int x^n\,dx = \tfrac{x^{n+1}}{n+1} + C,\ \ n = 0, 1, 2, \ldots @@ power for slopes (13d), constant-factor for slopes
\textstyle\int x^{-n}\,dx = \tfrac{x^{1-n}}{1-n} + C,\ \ n = 2, 3, \ldots,\ x \gt 0 \text{ or } x \lt 0 @@ negative-powers (13f)
\textstyle\int x^{p/q}\,dx = \tfrac{x^{p/q + 1}}{p/q + 1} + C,\ \ \tfrac pq \ne -1,\ x \gt 0 @@ fraction-power for slopes (13h)
\textstyle\int (f + g) = \int f + \int g,\ \ \int kf = k\int f @@ slopes-add, constant-factor for slopes (13d): antiderivatives-add-and-scale below
\textstyle\int f(kx + m)\,dx = \tfrac1k F(kx + m) + C,\ \ k \ne 0 @@ straight-inside (16d)

Antiderivatives-add-and-scale technique: if F and G are antiderivatives of f and g on an interval I, and k is real, then F + G is an antiderivative of f + g, and kF one of kf, on I. The proof is one line each: (F + G)′ = F′ + G′ by slopes-add, and (kF)′ = kF′ by constant-factor for slopes.

From here on, to check an antiderivative is to take the slope of the answer and compare it with the integrand. Its accepted name is checking by differentiation. It never fails, because taking slopes is a fixed procedure and finding antiderivatives is not.

\textstyle\int (4x^3 - 6x + 7)\,dx = x^4 - 3x^2 + 7x + C @@ antiderivatives-add-and-scale; power for slopes backwards three times. Check: 4x³ − 6x + 7
\textstyle\int \tfrac{dx}{\sqrt{x}} = \int x^{-1/2}\,dx = 2x^{1/2} + C,\ x \gt 0 @@ fraction-power for slopes with p/q = −½. Check: 2 · ½x^{−1/2}
\textstyle\int (5 - 2x)^4\,dx = -\tfrac{(5 - 2x)^5}{10} + C @@ straight-inside with k = −2. Check: −5(5 − 2x)⁴(−2)/10
\textstyle\int \tfrac{x^3 + 1}{x^2}\,dx = \int (x + x^{-2})\,dx = \tfrac{x^2}{2} - \tfrac1x + C,\ x \gt 0 @@ split the fraction first (rung 3's division); negative-powers

16f2One Value Pins the Constant

From here on, a demand G′ = f on an interval together with one value G(x₀) = y₀ is called an initial value problem; the value is its initial condition.

5 = 1 - 2 + C,\ \ C = 6 @@ the condition
G(x) = x^3 - 2x + 6 @@ the only answer on ℝ, by all-antiderivatives

16f3A Gap in the Domain

G(x) = -\tfrac1x \ (x \lt 0),\ \ G(x) = -\tfrac1x + 1 \ (x \gt 0) @@ defined on both sides of 0, not at 0
G'(x) = x^{-2} \text{ at every } x \ne 0 @@ negative-powers on each side
G \ne -\tfrac1x + C \text{ for any one } C @@ all-antiderivatives is about one interval; the domain here is two

So "∫ x⁻² dx = −1/x + C" is true on x > 0 and on x < 0, each with its own C. Most books write one C and leave the interval to the reader.

16f4The Missing Entry

The power line, with n = 1, would give ∫ x⁻¹ dx = x⁰/0. That is no function. The table has no entry for 1/x, and none can be added from powers.

No-power-for-1/x technique: there is no real c and rational r with (c xʳ)′ = 1/x for every x > 0.

\text{suppose } c\,r\,x^{r-1} = x^{-1} \text{ for every } x \gt 0 @@ for contradiction (7e); fraction-power for slopes for the slope
c\,r\,x^r = 1 \text{ for every } x \gt 0 @@ multiply by x
x = 1:\ \ c\,r = 1 @@ 1ʳ = 1
x^r = 1 \text{ for every } x \gt 0;\ \ x = 2:\ \ 2^{p/q} = 1,\ \text{so } 2^p = 1 @@ r = p/q; raise to the q-th power (13h)
p = 0,\ r = 0,\ c\,r = 0 \ne 1;\ \ \bot \quad \blacksquare @@ 2ᵖ > 1 for p ≥ 1 and < 1 for p ≤ −1 (8d, 4g); then refute

Yet 1/x is continuous on x > 0, so antiderivative-exists hands it an antiderivative there: its area function from 1, ∫₁ˣ dt/t. That function exists, has slope 1/x, and is not c xʳ for any c and r. It is not in the table. That gap stays open until rung 17, which names this function.

16f.4.4seamTwo of the first workers in the calculus hoped that every integral of a fraction of polynomials could be written with the functions they knew. In 1835 it was proved that some integrals of functions built only from powers and roots cannot be written that way. The area function A is one. It cannot be written with powers and roots, nor with any of the other standard functions of calculus. Antiderivative-exists says it exists all the same.
