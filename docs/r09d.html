9d · proof

Running backwards

Turn every pair of a function around: left entry and right entry exchanged. You always get a set of pairs. You get a function exactly when the original was a bijection, because the two promises the turned pairs must keep are the two promises 9c asked of outputs. When you do, it undoes the original from either side, and nothing else does. When you don't, keep part of the inputs, so that no output is used twice. That last move is how 8f's square root becomes a function in its own right: it is squaring, kept to the reals that are not negative, run backwards.

The inverse is the function’s pairs, swapped. It is a function exactly when each output is used exactly once, and then it takes every output back to the input it came from.

9d1The pairs, swapped

Stands on 9a3 (dom and ran), 2g (the short form) and 5b (the high −1).

From here on, for f : A → B, f⁻¹ names {(b, a) : (a, b) ∈ f}, the set of f's pairs with their entries swapped: 2g's shorthand for a sift of B × A. Read it “f inverse”. The high −1 here is one mark, not a reciprocal and not a power. 5b's a⁻¹ (and 8d's) names the reciprocal of a number, and f⁻¹ names a set of swapped pairs. What stands before the mark says which. Here the mark is an operator with one gap, for a function, and its result is a set of pairs.

5b made the same point about its own mark: there the high −1 was one mark and not 4f's power, because 4f's high place holds numbers. Here it is one mark again, with a third meaning. So f⁻¹(x) is never 1/f(x); a test below shows how far apart they are.

Swapped-pairs technique: (x, y) ∈ f ⇔ (y, x) ∈ f⁻¹. This is the sixth principle of the rung, and the proof is a short unpacking:

(a, b) \in f \Rightarrow (b, a) \in f^{-1} @@ rightward: 2g's shorthand, show an example with the pair (a, b)
(b, a) \in f^{-1}:\ \ \text{call } (a', b') \in f,\ (b, a) = (b', a') @@ leftward: ﹀ the shorthand; use the some
b = b',\ \ a = a' @@ equal-pairs (2e): equal pairs, equal parts
\htmlClass{new}{(a, b) \in f} \quad \blacksquare @@ the swap axiom twice, on (a′, b′) ∈ f; the call closes

Read swapped-pairs as a dictionary between f and f⁻¹: whatever f says, f⁻¹ says with its entries swapped. At once, domains-trade-places technique: dom f⁻¹ = ran f and ran f⁻¹ = dom f. A left entry of f⁻¹ is a right entry of f, and back. The rung does not call this swap anything but a swap. Rung 20 returns to the swapped pairs (20·cb9), with tools this ladder has not built yet.

9d2When the swapped pairs are a function

Stands on 9d1, 9a2 (the two promises) and 9c1 (one-to-one, onto).

f⁻¹ is always a set of pairs. Is it a function from B to A? By 9a it must keep two promises, about its inputs, which are B's members. Each b must be the left entry of at least one swapped pair, and of at most one. By swapped-pairs those are promises about f's outputs. Swapped-pairs-function technique: for f : A → B, f⁻¹ : B → A exactly when f is one-to-one and onto B.

f^{-1} \subseteq B \times A @@ always: f ⊆ A × B, then swapped-pairs
\forall b \in B\ \exists a\ ((b, a) \in f^{-1}) @@ f⁻¹'s first promise: every input has an output
\;\Leftrightarrow\; \forall b \in B\ \exists a\ ((a, b) \in f) \;\Leftrightarrow\; \htmlClass{new}{f \text{ onto } B} @@ swapped-pairs inside the some; 4c's line: (a, b) ∈ f is f(a) = b
(b, a), (b, a') \in f^{-1} \Rightarrow a = a' @@ f⁻¹'s second promise: no input has two
\;\Leftrightarrow\; (f(a) = b = f(a') \Rightarrow a = a') @@ swapped-pairs on both pairs; 4c's line
\;\Leftrightarrow\; \htmlClass{new}{f \text{ one-to-one}} \quad \blacksquare @@ 9c's line

That is the fifth principle's second sentence. The swapped pairs form a function exactly when each b appears in exactly one of f's pairs. Onto gives at least one; one-to-one gives at most one. Neither can be dropped. If f misses some b, f⁻¹ has nothing to say there. If f uses some b twice, f⁻¹ would have to say two things.

There-and-back technique: if f : A → B is a bijection, then f⁻¹(f(x)) = x for every x ∈ A, and f(f⁻¹(y)) = y for every y ∈ B; that is, f⁻¹ ∘ f = id_A and f ∘ f⁻¹ = id_B. When f is a bijection, f⁻¹ is called the inverse function of f, and f is called invertible.

(a, \htmlClass{keep}{f(a)}) \in f @@ 4c's line for f(a)
(\htmlClass{new}{f(a), a}) \in f^{-1} @@ swapped-pairs
f^{-1}(f(a)) = a @@ 4c's line for f⁻¹, a function by swapped-pairs-function
(b, f^{-1}(b)) \in f^{-1},\ \text{so } (f^{-1}(b), b) \in f @@ the other way: 4c's line, then swapped-pairs leftward
f(f^{-1}(b)) = b @@ 4c's line for f
f^{-1} \circ f = \mathrm{id}_A,\ \ f \circ f^{-1} = \mathrm{id}_B \quad \blacksquare @@ composite-is-a-function and the identity's value; equal-functions

9d3A function can be run backwards exactly when it is a bijection

Stands on 9d2, 9b (composing, identity) and 1g (the word inverse).

From here on, a function g : B → A undoes f : A → B on both sides when g ∘ f = id_A and f ∘ g = id_B. Then g is called an inverse of f, and f can be run backwards.

The word inverse now has a third use. 1g's inverse of an if, ¬P ⇒ ¬Q, and 5b's reading of a⁻¹, “a inverse”, keep theirs. Said of a function, an inverse is a function that undoes it.

Running-backwards technique: f : A → B can be run backwards exactly when it is a bijection; and then its only inverse is f⁻¹. Suppose g undoes f on both sides. g ∘ f = id_A is one-to-one, so f is (9c's one-to-one-inside). f ∘ g = id_B is onto B, so f is (onto-outside). If f is a bijection, f⁻¹ undoes it, by swapped-pairs-function and there-and-back. And any inverse g is f⁻¹:

g = g \circ \mathrm{id}_B @@ identity (9b), right side
\phantom{g} = g \circ (\htmlClass{new}{f \circ f^{-1}}) @@ there-and-back: id_B = f ∘ f⁻¹, read right to left
\phantom{g} = (\htmlClass{new}{g \circ f}) \circ f^{-1} @@ regroup for composing (9b): brackets don't matter
\phantom{g} = \htmlClass{new}{\mathrm{id}_A} \circ f^{-1} @@ g undoes f: g ∘ f = id_A
\phantom{g} = \htmlClass{keep}{f^{-1}} \quad \blacksquare @@ identity, left side

Every technique of 9b was used once: the identity on each side, and brackets in a chain. Notice the column used only g ∘ f = id_A. So for a bijection one side is enough: anything that undoes it from the left is f⁻¹. Two more come free. Inverse-is-a-bijection technique: if f is a bijection, so is f⁻¹, and (f⁻¹)⁻¹ = f. By there-and-back, f undoes f⁻¹ on both sides, so running-backwards applies to f⁻¹ with f as its only inverse. Socks-and-shoes technique: if f : A → B and g : B → C are bijections, (g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹. By regroup for composing, there-and-back and identity, (f⁻¹ ∘ g⁻¹) ∘ (g ∘ f) = f⁻¹ ∘ (g⁻¹ ∘ g) ∘ f = f⁻¹ ∘ f = id_A. The other side goes likewise, and running-backwards's uniqueness does the rest. You put on socks, then shoes; you take off shoes, then socks.

9d4Keeping part of the inputs

Stands on 9d3, 8f3 (√) and 8h (absolute value).

When f uses an output twice, no inverse exists. But a part of the inputs on which no output repeats can be kept, and that part's function can be run backwards.

From here on, for f : A → B and a part D ⊆ A, f|_D names {(a, f(a)) : a ∈ D}. Read it “f restricted to D”, or “f kept to D”. By rule-makes-a-function it is a function from D to B, and f|_D(a) = f(a) for every a ∈ D.

The bar with a low D after it is part of this mark: it is not 8h's |a|, with a bar on each side, nor 4i's ∣ standing between two numbers.

Restricting can make a function one-to-one. Cutting the codomain down to the range makes it onto (9a's codomain). Together they make a bijection that can be run backwards. The one that matters most is squaring. Let s : ℝ → ℝ, s(x) = x². It sends 2 and −2 both to 4, so it has no inverse. Keep the reals that are not negative.

Root-undoes-square technique: s|_[0, ∞), taken from [0, ∞) to [0, ∞), is a bijection, and its inverse is the function x ↦ √x on [0, ∞).

q = s|_{[0, \infty)} : [0, \infty) \to [0, \infty) @@ the restriction; q(x) = x² ≥ 0 by square-never-negative, so the codomain may be cut (codomain)
q(a_1) = q(a_2),\ a_1, a_2 \ge 0 \Rightarrow a_1 = a_2 @@ one-to-one: one-root (8f), two reals not negative with one square
b \ge 0 \Rightarrow q(\sqrt b) = (\sqrt b)^2 = b @@ onto: square-root and 8f's line for √: √b ≥ 0 and √b · √b = b
q \text{ is a bijection};\ \ q^{-1}(b) = a \text{ with } a \ge 0,\ a^2 = b @@ swapped-pairs-function: q⁻¹ is a function; swapped-pairs
\htmlClass{new}{q^{-1}(b) = \sqrt b} \quad \blacksquare @@ 8f's line: √b names the one real a ≥ 0 with a² = b

So 8f's √ was this inverse all along, and its being never negative is the choice of which inputs to keep. Keep (−∞, 0] instead and the inverse is b ↦ −√b: a perfectly good function, just not the one the mark names. Now 8h's size-squared reads differently. √(x²) = |x|, not x, because √ ∘ s, on all of ℝ, is not q⁻¹ ∘ q. s is not the kept function, and −3 goes to 9 and back to 3. The other order is clean. s(√x) = x for every x ≥ 0, which is q ∘ q⁻¹ = id_[0, ∞) by there-and-back.

The same goes for every root. For an odd number n, x ↦ xⁿ is a bijection of ℝ, and its inverse is ⁿ√, extended to negatives by 8i's line; nothing need be kept aside. For an even n, keep [0, ∞), as for squares. And some functions are their own inverses. r(x) = 1/x on ℝ ∖ {0} has r(r(x)) = x (reciprocal read in ℝ). So r ∘ r = id and r⁻¹ = r by running-backwards.

Finally, the trap the mark sets. With f(x) = 2x + 3 on ℝ, the inverse undoes the doubling and the adding in the reverse order: f⁻¹(x) = (x − 3)/2. Test at 5: f(5) = 13, and f⁻¹(13) = 5, as there-and-back demands. But 1/f(13) = 1/29, which undoes nothing. The high −1 on a function is the swap, never the reciprocal.

9d6Running it backwards

Stands on 9d1 to 9d4.

Wanting f⁻¹ as a function: check one-to-one and onto. Or exhibit a g that undoes f on both sides (running-backwards), and then g is f⁻¹. Wanting a value f⁻¹(y): find the one x with f(x) = y. Wanting an inverse of a function that repeats outputs: choose a part of the inputs where it does not, and restrict. Then cut the codomain to the range, and invert. Wanting to check a claimed inverse: compose both ways and compare with the identities. Found upward; written downward.
