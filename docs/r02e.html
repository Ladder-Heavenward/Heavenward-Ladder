2e · proof

Gather and merge

Sifting picks members out of a set you have. This step puts members together. Gathering takes things and makes the set with exactly those members, which is where the listed sets of 2c finally come to exist. Merging takes a set of sets and tips them out together. Between them they give the mark everyone has seen, read “union”. The ladder brings that mark in with a line that says to consider the set before the sign and the set after it as one set. Alongside it comes the set of common members, which is a sift and needs no new tool. Then the techniques. Each of them is a technique of 1f's rulebook wearing set clothes, name for name. The backward direction of not-through for and, which 1f withheld, is withheld here too, in the same place, for the same reason.

Gather things into a set; tip sets together; keep what they share by sifting. Each tool is fixed by its membership line, and the membership line is a joining word, so the techniques of the joining words are the techniques of the tools.

2e2Gathering one thing, and gathering sets

Nothing says p and q must differ. Gather p with itself and you get {p, p}. By 2c's worked proof (1f's say-it-again technique inside the or) that is the set written {p}, whose only member is p. So the set whose only member is a given thing exists, and so does the set whose members are given things p and q.

A set with exactly one member is called a singleton. {p} and {cat} are singletons.

Gather applies to anything you have, sets included. {∅} exists, since ∅ does. {∅} is not empty: ∅ ∈ {∅}, by the self-sameness axiom and the membership line. Gather {∅} with ∅ and you have {∅, {∅}}. Rung 3 will take this road a long way. Without it, two things you have could never be put into one set, and no listed set, not even {cat, dog}, would exist.

Gathering is the reason a set can be “a thing in its own right”, as the rung 2 survey put it. The things Ann and Ben are people; {Ann, Ben} is a set, a further thing. It can be gathered in its turn: {{Ann, Ben}, Cal} has as members a set and a person.

2e3Merge

Now a set s whose members are sets. Tip them all out onto the table and gather up everything that fell: that is the merge of s. A thing is in the merge exactly when it is in some member of s.

From here on, means: the set of everything that is in any member of s:

The mark ⋃s is a name: it names one set, the merge of s. Without it, sets of sets could never be tipped out together, and the cats of two rooms could not become one set of cats.

An example:

The dog, in both sets, is tipped out and is in the result, and being in it again is nothing. To use a membership in a merge you use a some: “call the member it is in y”. To make one you show an example: name the member it is in. Here is the owl's membership, argued in words:

{dog, owl} is listed in {{cat, dog}, {dog, owl}}, as the later item. So it is a member of that set. The owl is listed in {dog, owl}. So the owl is a member of {dog, owl}. Join the two: {dog, owl} is a member of the outer set, and the owl is in it.

So some member of the outer set has the owl in it. That is showing an example, and the example is {dog, owl}. Pack the merge: the owl is in ⋃{{cat, dog}, {dog, owl}}.

2e6Why merge-membership holds

The plan: an exactly-when wants an if each way. The forward if uses the merge (call the member y); the backward if makes one (show an example).

Here is why, one direction at a time. Let x be any member of d ∪ b: a fresh case. Unpack ∪: x is in ⋃{d, b}. Unpack the merge: some member of {d, b} has x in it. Use the some: call that member y. By the listing, y is d or y is b.

Now work each option. If y is d, then x is in d, by the swap axiom. Add an option: x is in d or in b. If y is b, the same steps give x is in b, then add an option. Either way, x is in d or in b, said once. That row does not mention y, so it comes out of y’s case. The case of x used nothing about x but that it is in d ∪ b, so, back at the margin, every member of d ∪ b is in d or in b.

Now the other way. Let x be any thing in d or in b: a fresh case. Work each option. If x is in d: d is listed in {d, b}, so d is a member of {d, b} with x in it. That is an example, so x is in ⋃{d, b}. If x is in b, the same steps run with b as the example. Either way, x is in ⋃{d, b}, which is d ∪ b. Back at the margin: every thing in d or in b is in d ∪ b. Use both everys on any x, and join the two ifs: x is in d ∪ b exactly when x is in d or in b.

2e7Lists of any length

From here on the merge-membership technique is cited and the merge behind it forgotten, as the mark intends. And the listed sets of any length now exist. That closes the flag 2c opened when it read {cat, dog} as “once we have it”.

From here on, a longer list between braces names the union of its earlier part with the gathering of its last item.

For example, {p, q, r} is {p, q} ∪ {r}. Its members are p, q, r, by merge-membership and the listing line. And so on: each longer list is a union of a shorter one with a gathering. So 2c's reading of a listing as an or across the list is a technique for every length.

2e9A small zoo

Take d the fliers and b the mammals in a small zoo: d = {owl, bat}, b = {cat, dog, bat}. Then d ∪ b = {owl, bat, cat, dog}; d ∩ b = {bat}; b ∖ d = {cat, dog}; d ∖ b = {owl}. Each is read off its membership line. Read one: bat is in d ∩ b, because bat is in d, and bat passes “is in b”.

Notice that there is no “everything not in d”. That would be a sift from a set of everything, and there is no such set: that is held in trust here, and 3a·f proves it. “Not in d” is always “in some c you have, and not in d”, c ∖ d.

2e11Chasing a member: turn-about and absorb

Here is the turn-about technique for ∪, argued in words. It is the first of the techniques the step promised, and the shape to copy for all of them.

Let x be anything. By merge-membership, x is in d ∪ b exactly when x is in d or in b. By 1f's turn-about technique, that says exactly what “x is in b or in d” says. By merge-membership again, that is exactly when x is in b ∪ d. Chain the exactly-whens: x is in d ∪ b exactly when x is in b ∪ d.

Nothing was assumed about x, so this is true for everything. By the same-members axiom, d ∪ b = b ∪ d.

The absorb technique looks surprising for sets and is nothing once the joining words show. One example first: with d = {owl, bat} and b = {cat, dog, bat}, d ∩ b = {bat}, and d ∪ {bat} is d again. Now for any sets:

Let x be anything. By merge-membership, x is in d ∪ (d ∩ b) exactly when x is in d, or x is in d ∩ b. Unpack ∩: x is in d, or x is in d and in b. By 1f's absorb technique, that is exactly when x is in d. This is true for everything, so by the same-members axiom, d ∪ (d ∩ b) = d.

2e12Spreading, and the shape called chasing a member

And the spread technique for and over or, which is the one you will use most. It runs as a chain of exactly-whens, each from the one before:

Let x be anything. Unpack ∩: x is in d ∩ (b ∪ c) exactly when x is in d and in b ∪ c. By merge-membership, that is exactly when x is in d, and in b or in c. By 1f's spread technique, that is exactly when x is in d and in b, or x is in d and in c. Pack ∩ in each part: x is in d ∩ b, or x is in d ∩ c. By merge-membership, that is exactly when x is in (d ∩ b) ∪ (d ∩ c).

This is true for everything, so by same-members, d ∩ (b ∪ c) = (d ∩ b) ∪ (d ∩ c).

Check it in the zoo, with c = {owl, cat}: b ∪ c = {cat, dog, bat, owl}, so d ∩ (b ∪ c) = {owl, bat}. And d ∩ b = {bat}, d ∩ c = {owl}, whose union is {owl, bat} too.

Call this shape chasing a member: a thing x, and a chain of exactly-whens from one membership to the other. Because every link is an exactly-when, the chain runs both ways at once, and the same-members axiom closes it. The slides do not-through for ∪ and the units technique.

2e13The cup lifted out, and poured back

2c's cup comes back. Let C be the set of molecules in the cup's place. The cupful is a sift of the Sound, so it is an intersection: cupful = Sound ∩ C. A body of water is nothing but its molecules, as a set is nothing but its members. So whatever a cup does to water is something done to a set.

Merge the cupful with the Sound while it is still in the Sound, and nothing changes. That is the absorb technique:

Lift the cup out, and the Sound left behind is Sound ∖ cupful. Pour it back, and the merge gives the Sound again:

That last line needs one thing more than it seems to. To place a molecule of the Sound on the left side, you must say which part of the merge it is in: in the cup, or not. That is the either-way split, which this rung grants only for settled statements, as the next section says. For molecules it is settled: each one is in the cup or it is not.

Sets do not move. The trip and the return are a story told across three sets, and the marks follow the story exactly.

2e14The licence column, honestly

1f marked which techniques it licensed both ways for any statement, and which only forward or only backward before rung 7. The set techniques inherit the licence column exactly. Not-through for or is both ways, so this is a sameness of sets:

Not-through for and runs only the licensed way: from ¬P ∨ ¬Q you may get ¬(P ∧ Q), and not back. So from x ∈ (c ∖ d) ∪ (c ∖ b) you may get x ∈ c ∖ (d ∩ b), and this inclusion is a technique:

The other inclusion would need, from “x is not in both d and b”, that x is not in d or x is not in b. No tech on this ladder yet gives it. For sets whose members you can list, membership is settled, 1f's word, and the technique may be used both ways, checked by looking; the picture's world is a listed world.

2e15Loose, then locked

Anexact, yet rigorous · loose, then locked

Things get made in two steps. First comes a loose gathering under a rule. Sand settling into a layer is one; snow drifting against a wall is another. Then the gathering locks: snow falls loose, then freezes into a crust. This step does the same. Gather and merge pull members together under a rule: these two, or the members of each set here. Then the result is locked, by the same-members axiom. The set is fixed by its members, whatever order they were gathered in.

Describe both steps: what was gathered, under what rule, and what locked it.

Unlocking runs the steps backward. Take a member out, and the lock gives a different set.

Snow has slush, half-way between drift and ice. Is there a set half-way between {p} and {p, q}?

2e17Running it backwards

Wanting x ∈ d ∪ b, you want x ∈ d or x ∈ b and the merge-membership technique; so prove a side, or reason by cases on an or you have. Wanting x ∈ d ∩ b, you want both, and join. Wanting x ∈ ⋃s, you want a member of s that x is in, shown. Wanting a sameness of sets built from ∪, ∩, ∖, chase a member. Unpack both sides into joining words and look for the 1f technique that carries one to the other. If the technique you need is licensed only in the other direction, you have found a claim that is an inclusion and not a sameness. Wanting d ⊆ b from a sameness such as d ∪ b = b, let x be any member of d, add an option, pack merge-membership, and swap across the sameness. The slides run that inclusion, and its converse, which is where the absorb technique does real work.

Other ways the same marks are written

Mathematics writes some of these marks in more than one way, by subject and by century. Each one below means what the mark in this step means; know them on sight.

  • Sets with no member in common, d ∩ b = ∅, are called disjoint; in probability, events that are disjoint are called mutually exclusive.
  • The complement is also written d′ or with a bar over d; in probability, u is called the sample space. The complement is always taken inside a named u; without one there is nothing to take it in.
  • d ∖ b is also written d − b. The picture of overlapping rings for these tools is called a Venn diagram.
  • \bigcap s needs s to have a member, so that there is a set to sift from; \bigcap \varnothing is never written.

Accepted names

In the books the techniques of this step are laws of the algebra of sets: turn-about is the commutative law, regroup the associative law, say-it-again idempotence, absorb absorption, spread the distributive laws, and not-through De Morgan’s laws. The gather axiom is the axiom of pairing; the merge axiom, the axiom of union.
