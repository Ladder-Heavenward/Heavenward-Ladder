2e · proof

Sifting, and a Set to Start From

2d said what a set is and when sets are the same. This step builds. The tool is sifting: from a set you have and a condition, the set of those members that pass. It is the tool everyone uses when they write “the set of all things such that…”. The small print in it is that the sifting happens inside a set you already have, and that is what keeps the whole subject from falling over. The step also notices that a tool which makes sets from sets makes nothing from nothing. So it lays down the axiom that there is a set, and sifts from it the set with no members. That turns out to be the same set whichever set you began with. At the end it shows the outsider-set argument: what happens when you sift from nothing, set out in rows as far as rows can take it; 3a finishes it.

To pick out members, name the set you are picking from and the condition they must pass. Sifting keeps or drops; it never adds. Sift with a condition nothing passes and you have the empty set, the only set with no members.

2e1Picking Things Out, in Plain Words

This step is about picking things out. You do it all day. From the clothes in a drawer, you pick the clean ones. From the people in a class, you pick the ones who walk to school. Each time you need a collection you already have. You also need a test that each member passes or fails. What comes out is the members that pass.

Or take the cats. Tibbles and Mittens are among the cats in this room, and the cats in this room are among all the cats in the world. Sift the cats in the room by “is mine”, and you have Tibbles and Mittens: my cats. You made no cat. You kept two.

A kitchen sieve does the same. Pour in the flour, and the lumps stay behind. A sieve never makes flour. It only keeps some of what you poured in. A sieve is this step's tool, and the step calls it sifting.

Sifting keeps the members of a set you already have that pass a test, and it never adds anything.

The marks look harder than the idea. Here is one:

It is read “the set of x in u such that x can fly”. The braces mean a set, as on 2d. The x is a blank that runs through the members of u, one at a time. The colon is read “such that”. After it comes the test.

Let u be {cat, dog, owl}. The test runs on each member in turn. The cat can't fly, so it is dropped. The dog can't fly, so it is dropped too. The owl can fly, so it is kept. The result is {owl}.

2e2A Condition

The step writes the test as φ(x), with a Greek letter, phi: the first Greek letter on the ladder. That letter means “some test, any test at all”. It works like a blank on a form: φ(x) is the test with x written in the blank.

0a had statements with a gap: “… is asleep”, written P(x) with the gap shown. Put a name in the gap and you have a statement. When such a statement-with-a-gap is used to pick things out, the ladder calls it a condition. Examples: “x can fly”, “x is red”, “x ∈ b”, “x ≠ cat”, “∃y (y is a child of x)”. A condition is built from nothing but rung 1's joining words, 0b's =, 2d's ∈, and everyday words. It says of the thing in its gap something that is so or not so. Rung 1 wrote statements with gaps as P, Q, R. A condition that is to be any condition whatever is the one the sifting tool accepts. For it the ladder uses a letter from another alphabet, so that it is never confused with a particular statement:

From here on, (the Greek letter phi, in its small form) stands for any condition: a statement with a gap. is that condition with x in its gap.

For example, if φ(x) is “x can fly”, then φ(owl) is “owl can fly”, which is so, and φ(cat) is “cat can fly”, which is not. Back to the rule: nothing is assumed about φ except that, for each thing put in its gap, the result is a statement. The letter x in φ(x) is a placeholder in 2b's sense: it names nothing and may be renamed.

2e3The Empty Set, in Plain Words

Now a strange case. Sift with a test nothing passes, such as “is not itself”. Everything is itself, so nothing is kept. You are left with a set that has no members. It is called the empty set.

Is there only one empty set? An empty cup and an empty bucket are different things, because each is made of something besides what is inside it. A set is made of nothing but its members (2d). So any empty set has the same members as any other, which is none, and they are the same set.

Why did 2d1 lay down an axiom that the empty set exists? Because sifting needs a set to pour in. With nothing in the sieve, nothing comes out. The empty-set axiom puts one set in hand, and 2e9 writes it in marks. Any other set would sift down to it too, with “is not itself”.

2e4Why a Sieve Needs a Bowl

Last, the step asks why a sieve needs a bowl. Imagine you could sift from nothing: “the set of every thing that passes the test”, with no set to pour from. It sounds harmless. Try the test “does not list itself”. Picture a library catalogue that lists every catalogue that does not list itself.

Does that catalogue list itself? Say yes, and follow where it leads. Then say no, and follow that.

The step runs that question in rows in footing 2e14, and 3a finishes it. Then it shows what changes when the sifting happens inside a set you have. Now the same ideas again, with the care that turns them into arguments.

2e5The Sift Tool

Here is the tool, in words: from a set u and a condition φ, the set of those members of u of which φ is true. In marks:

From here on, means: the set whose members are exactly the members of u that pass φ:

Read the colon as “such that”: “the set of x in u such that φ of x”. The x before the colon is the placeholder, and it runs through u. The condition after the colon has that same letter in its gap.

The sift axiom says the sifted set exists. The “from here on” line says who its members are. The mark {x ∈ u : φ(x)} is a name: it names the one set the sift picks out. By 2d's same-members axiom, only one set has those members. Without the sift axiom, no condition could pick anything out: “the cats in this room that are mine” would be words with no set behind them.

A thing is in the sifted set exactly when it is in u and passes. That is an and. To use a membership in a sifted set, keep either part. To make one, join.

2e6The Fliers Among Cat, Dog and Owl

The fliers among cat, dog and owl, with the facts about flying laid down as given, since the ladder cannot watch an owl.

Given: the cat cannot fly, the dog cannot fly, and the owl can fly. The sift axiom gives this set; call it fliers:

Is the owl in fliers? The owl is the owl, by the self-sameness axiom, so add an option and pack the listing: the owl is in {cat, dog, owl}. The owl can fly: keep that part of the given. Join the two, and pack the sift:

Is the cat in fliers? Put cat ∈ fliers in a row beside the givens. Unpack the sift and keep the right part: the cat can fly. That clashes with the given: ⊥. So rows that hold cat ∈ fliers equal ⊥: the cat cannot stand in fliers. The same steps run for the dog: unpack, keep the right part, the dog can fly, clash. Writing the denial, , is a box’s output, and 3a earns it.

So fliers has owl as a member, and cat and dog cannot stand in it. By 2d's listing line and the same-members axiom, fliers = {owl}: the slides finish that. The habit to take from this: a sift is used by unpacking its membership into an and, and made by joining.

2e7Sifts Worth Knowing by Sight

Some sifts worth knowing by sight:

A condition everything passes gives the set back, since x = x is the self-sameness axiom for any x.

A sift can run on a set whose members are sets: {s ∈ b : cat ∈ s} picks out the members of b that have cat in them.

A sift can mention other sets you have: {x ∈ u : x ∈ v} is the members u and v share, and 2f gives it a mark.

What a condition may not do is mention the set being built, since that set is not yet in hand.

2e8Sifting Never Adds

Sift-is-part technique: whatever the condition, the sifted set is part of the set you sifted. This is the technique to cite when someone expects a sift to produce something that was not there to keep.

The plan: wanting the sift ⊆ u, the last step packs ⊆; before it is an every of a kind; so set in the case of any member of the sift.

Let u be any set and φ any condition. Let y be any member of the sift, a fresh name with this said of it:

Unpack the sift: y ∈ u and φ(y). Keep the left part: y ∈ u.

The case used nothing about y but that it is in the sift, so, back at the margin, every member of the sift is in u. Pack the mark: .

2d's cup of seawater was a sift all along. The cup takes exactly the molecules of the Sound that are in a certain place: cupful = {x ∈ Sound : x is in the cup}. So the sift-is-part technique gives cupful ⊆ Sound with no further work. A cup is a sift: it keeps what passes, and what it keeps was already there.

So {x ∈ {cat, dog} : x can fly} is not {owl}, whatever the owl can do. No flier was in {cat, dog} to keep, so nothing passes, and the result is a set with no members at all. Which raises the question of what that set is, and whether there is such a thing.

2e9A Set to Start From

Look at what the tool needs. Sifting takes a set in. Every tool of this rung does: 2f's gather takes things you have, its merge takes a set of sets, 2g's tool takes a set. The tools make sets from sets, and with nothing in hand they make nothing. The techs of rung 1 never produce an object either; they reason about objects you have. And 2d's listing only writes a set you have. So without 2d1, nothing would say that there is any set at all. Mathematics does not pretend otherwise. 2d1 laid down an axiom that does not build but simply asserts. In marks:

From here on, “the empty-set axiom” is this axiom, in these marks.

It is the smallest start there could be: one set, with nothing in it. Some books lay down instead only that some set exists, and sift the empty set out of it, as 2e10 does for any set. With sifting in hand, the two come to the same thing. The ladder starts from the empty one, because it is the first thing the rung needs. (Rung 3 will lay down an axiom that asserts another set exists, a particular and endless one.)

2e10Every Set Sifts to the Empty Set

Empty-sift technique: any set, sifted by “is not itself”, gives a set with no members. The argument:

Let u be any set at all, with nothing else said of it. Sift u by the condition “is not itself”, and call the result e: .

Let y be any member of e: a fresh case, with y ∈ e said of it. Unpack the sift: y ∈ u and y ≠ y. Keep the right part, and unpack ≠: y is not y. But y = y, by the self-sameness axiom. That clashes: ⊥. The case closes.

The case of any member of e closes, so nothing can stand in e. That is what this rung means by a set with no members: a row that puts anything in it equals ⊥. The empty-set axiom hands the same thing over as a given, in its own marks; writing it out as a denial for e is 3a’s work:

u was any set, so this holds for every set.

This makes no new set appear: the empty-set axiom already gave one. It shows that every set leads down to a set with no members, by one sift. 2e11 shows that it is always the same one.

2e11The Only Set With No Members

One-empty-set technique: two sets with no members are the same set.

The argument that they are the same uses the tech “when nothing is true, everything is permitted”, and it is the standard use of that tech. Nothing can stand in e. So a case that sets in a member of e closes at once, and once a case equals ⊥, everything is permitted inside it: you may say that the member is in e′, for as long as the case is open.

Here it is. Rows hold that e and e′ have no members: a row that puts anything in either equals ⊥. Aim at the double-inclusion technique.

Let x be any member of e. Nothing can stand in e, so the case equals ⊥. Everything is permitted, so x ∈ e′. The case used nothing about x but x ∈ e, so, back at the margin, every member of e is in e′: e ⊆ e′. The line x ∈ e′ stays in the case; only the every comes out, and an every of a kind over no members is all double inclusion asks for. The same steps, with e and e′ exchanged, give e′ ⊆ e.

Join the two inclusions. The double-inclusion technique then gives e = e′.

2e12A Name for the Empty Set

There is a set with no members, and no other. So it may be given a name of its own:

From here on, means: the set with no members. Read it “the empty set”.

Empty-set technique: nothing is a member of the empty set. In marks, .

The empty-set technique is the empty-set argument of footing 2e10, read for ∅; the one-empty-set technique is why “the” is the right word. Every argument that mentions ∅ uses them, in one of two ways. Either “x ∉ ∅, so a row that holds x ∈ ∅ equals ⊥”, or “this set has no members, so it is ∅”. In particular {x ∈ u : φ(x)} = ∅ exactly when no member of u passes φ; the slides prove the fliers among {cat, dog} come to ∅ that way.

A word on the mark. It is a letter from the Danish and Norwegian alphabet, chosen by a group of French mathematicians who wrote under one shared pen name. One of them said he had taken it from the Norwegian he knew. It is not the Greek letter phi, which stands for a condition in this step, and it is not a mark from any later rung. Treat it as the mark its line makes it: a name, for one set.

2e13The Illegal Sift

Here is the sift that looks most harmless and is not allowed: “the set of all cats”. It is written {x : x is a cat}, with nothing after the x to sift from. The sift axiom says nothing of it, and no tool of the rung builds it. If you want the cats, you must say which set's cats: the cats among the animals in the zoo, {x ∈ z : x is a cat}. Saying which set's cats seems pedantic in life. In mathematics it is the difference between a subject that stands and a subject that falls, and the argument that shows it is short enough to run in full.

2e14The Outsider Set

Early in the century before this one, a logician had completed a foundation for arithmetic. Its rules allowed a set to be formed from any condition at all, with no set to sift from. A younger logician wrote to him with a question. Take the condition “x ∉ x”, is not a member of itself. Most sets pass it: {cat} is not a member of {cat}, since its only member is a cat. The old rules allow the set r of all things that pass. Is r a member of itself?

Outsider-set technique: no set has as its members exactly the things that are not members of themselves. Rows set it up here, and it is held in trust until 3a17 earns it.

Here is how far rows go, with the techs of rung 1 and 2a and nothing else.

Rows hold that there is such a set. Use the some: call it r, a fresh name. So for every x, x ∈ r exactly when x ∉ x. Use that every on r itself: .

Now set in the case r ∈ r. Keep the rightward direction and carry it through: r ∉ r. Unpack ∉: that clashes, ⊥. The case r ∈ r closes: it cannot stand.

Rows can go no further. To use the leftward direction, a row needs r ∉ r at the margin, and that is the denial of the case that closed. Writing that denial is a box’s output. With it, the leftward direction gives r ∈ r, which clashes with r ∉ r, and the ⊥ does not mention r, so it comes out of r’s case.

3a17 takes those last moves with a box, and the rows that hold the outsider set then equal ⊥: .

Look at what the argument does not do. It never asks “is r in r, or not?” and splits into cases; that would be 1f’s either-way, which this ladder does not grant for a statement like this. It closes the case r ∈ r, and 3a will turn that closing into a denial and carry the other direction through on it. Both sides of the final clash are earned. The outsider-set argument needs nothing that the ladder withholds, only the box that 3a brings.

2e15The Sift Inside a Set

Now set the outsider-set technique beside the sift tool. The old rules said: for any condition, there is the set of all things that pass. With the condition x ∉ x that gives exactly the r whose rows equal ⊥, once 3a17 finishes them. So the old rules prove ⊥, and when nothing is true, everything is permitted: every statement, so and not so alike. The author of the foundation, with great generosity, wrote back that the argument had shaken the ground he meant to build on.

All the water on Earth is the top of 2d's cup chain: every body of water in it is part of it. But its members are molecules, not sets. A set of everything has no such top to sift from.

The sift axiom says instead: for any condition and any set u you have, there is the set of members of u that pass. Run the same sift inside a set:

From here on, a small letter written low after a name, as in rᵤ, makes a new name that recalls the first. It claims nothing.

So rᵤ = {x ∈ u : x ∉ x} is the outsider set made inside u. In rows, the case rᵤ ∈ rᵤ closes just as before. The second clash would need rᵤ ∈ u for free, and inside u that is not given. So, once 3a17 finishes the argument, the clash refutes rᵤ ∈ u instead: the set you sifted from does not contain its own outsider set. Nothing totally false; a technique. 3a·f runs that version, and draws from it that there is no set of all sets.

The accepted word for what the outsider set did to the old rules is paradox, from the Greek for “contrary to expectation”.

2e17Running It Backwards

Wanting y ∈ {x ∈ u : φ(x)}, you know the step before is y ∈ u ∧ φ(y), so you want both of those, and join. Wanting to show y ∈ {x ∈ u : φ(x)} cannot stand, you put the membership in a row, unpack it, and need a clash with either part: either you have y ∉ u, or you have ¬φ(y). Wanting s = ∅, you have two routes. You can show s has no members, that is, any case of a member of s closes, and cite the one-empty-set technique. Or you can show inclusions each way. The direction ∅ ⊆ s is free by everything-permitted (held in trust here; 2g writes it out), and the direction s ⊆ ∅ is the real work. Found from the goal back; written from the givens forward.

Other ways the same marks are written

Mathematics writes some of these marks in more than one way, by subject and by century. Each one below means what the mark in this step means; know them on sight.

  • {x ∈ u : φ(x)} is also written with a bar, {x ∈ u ∣ φ(x)}. Either form is set-builder notation.
  • \varnothing is also written {}.

Who said it first

The logician whose foundation fell is Gottlob Frege; the younger logician who wrote to him, in 1902, is Bertrand Russell. The author of the ancestor list of axioms, who assumed an empty set outright, is Ernst Zermelo (1908). The French group with the shared pen name is Bourbaki; the member who chose ∅ from the Norwegian he knew is André Weil.

Accepted names

The outsider-set technique is Russell’s paradox; the outsider set is the Russell set. The old unrestricted rule is unrestricted comprehension. The sift axiom is the axiom of separation, or of subsets.
