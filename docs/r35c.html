35c · proof

More Parts Than Members

Rung 2 gathered all the parts of a set into one set, and asked a question it could not yet answer: can the parts of a set be matched, one each, with its members? Rung 4 counted them for a finite set, two to the power of the count, always more. This step answers for every set, finite or not. Take any way of handing each member a part. Collect the members that are not in the part they were handed. That collection is a part too, and no member was handed it, because each member disagrees with it about itself. So the parts always outrun the members. Each member goes to the part that holds only it, so the members never outrun the parts. Every set is smaller than its set of parts. Then the parts of the parts are larger still, and so on without end: there is no largest size. And if there were a set of everything, its parts would be things too, and would fit inside it. They cannot, so there is no such set, which rung 2 found another way.

Hand each member of a set a part. The members that are not in their own part make a part no member was handed. So no function from a set onto its parts exists, the set is smaller than its parts, and sizes climb for ever.

35c1No Map Reaches Every Part

2g6 asked whether the parts of a set can all be matched, one each, with its members, and left the question to later. 9a4 answered it for ℕ with parts read as functions to 2 (4k10 matched a part with its keep-or-drop function). The difference here is that the set is any set at all, and the parts are used directly.

Parts-outrun technique: for every set A and every function f from A to 𝒫(A), some part of A is f(x) for no x in A.

f : A \to \mathcal P(A) @@ any function handing each member a part
D = \{x \in A : x \notin f(x)\} @@ a sift of A (2e): the members not in their own part
D \in \mathcal P(A) @@ a sift of A is a part of A (2g)
x \in A;\ \ \text{assume } \htmlClass{new}{D = f(x)} @@ to refute: D is handed to x
x \in D \iff x \notin f(x) \iff x \notin D @@ the sift’s condition, then the swap axiom with D = f(x)
\bot @@ a statement exactly when its own denial: either case clashes (7e)
\htmlClass{keep}{D \ne f(x) \text{ for every } x \in A} \quad \blacksquare @@ refute; x was anything

Each member x goes to {x}, and different members go to different parts. So A goes one-to-one into 𝒫(A), and no function from A onto 𝒫(A) exists. The parts never fit the members, and the members always fit the parts. For A = ∅, the only function from ∅ is the empty one, and it misses 𝒫(∅)’s one member, ∅. For A = {cat, dog}, four parts and two members. For A = ℕ, this is 9a4 again.

35c2Smaller, and Smaller Than

From here on, |A| ≤ |B| says that A goes one-to-one into B, and |A| < |B| says that |A| ≤ |B| and A and B are not matched. Read them “A is no bigger than B” and “A is smaller than B”. Like |A| = |B|, these are statements about maps, and the bars name no new object. For finite sets they agree with counting: n goes one-to-one into m exactly when n ≤ m: one way by 4h’s at-most-is-a-part, the other by 8·cb5’s pigeonhole technique.

Smaller-than-its-parts technique: every set is smaller than its set of parts: |A| < |𝒫(A)|. The map x ↦ {x} gives |A| ≤ |𝒫(A)|. A matching would be a function from A onto 𝒫(A), and the parts-outrun technique says there is none.

s \in \mathcal P(\mathbb N) \mapsto 0.e_0e_1e_2\cdots,\ \ e_n = 5 \text{ if } n \in s,\ 4 \text{ if not} @@ a decimal with no 9s (8·cb5), one for each part
\text{different parts give different reals} @@ they differ at some n, so at one digit, and a decimal with no endless 9s is one real’s only one
|\mathcal P(\mathbb N)| \le |\mathbb R| @@ a one-to-one map
\mathcal P(\mathbb N) \text{ countable} \Rightarrow \text{its image in } [0, 1) \text{ countable} @@ a list of parts gives a list of their reals
\htmlClass{new}{\text{the image would hold its own diagonal}} \quad \blacksquare @@ the unlisted-real technique (35b1) builds a real of 4s and 5s, which is the real of a part

The two proofs are one move. 35b’s diagonal changed the nth digit of the nth entry; the parts-outrun technique asks the nth member whether it is in the nth part, and answers the other way.

35c3No Largest Size

No-largest-size technique: for every set there is a larger one. 𝒫(A) is larger than A, 𝒫(𝒫(A)) is larger than 𝒫(A), and the climb never stops. From ℕ: |ℕ| < |𝒫(ℕ)| < |𝒫(𝒫(ℕ))| < ⋯. Each storey is a size, and none is the last.

\text{assume } U \text{ holds every thing} @@ to refute
x \in U \text{ a set} \Rightarrow x \subseteq U @@ each member of x is a thing, so it is in U
f(x) = x \text{ if } x \text{ is a set},\ \ f(x) = \varnothing \text{ if not} @@ a function from U to 𝒫(U), by cases (7e)
s \in \mathcal P(U) \Rightarrow s \in U,\ \ f(s) = s @@ a part of U is a set, and a thing, so it is in U
f \text{ is onto } \mathcal P(U) @@ every part is a value of f
\htmlClass{new}{\text{no set holds every thing}} \quad \blacksquare @@ a clash with the parts-outrun technique; refute

The D of this f, for the sets in U, is {x : x ∉ x}: the sift of the sets not members of themselves, 2e’s sift, which showed there is no set of everything. The size argument and the old sift are one argument. The climb of sizes has no top, and the reason is the reason there is no set of all sets.

The cellar · there if you want it

The accepted names

The parts-outrun technique and the smaller-than-its-parts technique are Cantor’s theorem: |A| < |𝒫(A)|. The set D is the diagonal set. |A| ≤ |B| is the order on cardinalities, and |A| < |B| strict inequality of cardinalities. The run on a set of every set is Cantor’s paradox; its D is Russell’s set.

Who said it first

Georg Cantor proved in 1891 that a set of functions to two values is larger than the set they are defined on, which is the result for every set, and drew from it that there is no largest size. He had met the paradox of a set of all sets by 1899, in letters to Dedekind. Bertrand Russell found his set in 1901 by running Cantor’s argument on the set of all sets. David Hilbert said in 1925 that no one shall drive us out of the paradise Cantor created. Henri Poincaré, among the critics, held that the actual infinite does not exist, and is quoted, from a report of uncertain source, as calling the theory a disease from which mathematics would recover.

A proof that is not allowed

“A has n members and 𝒫(A) has 2ⁿ, and 2ⁿ > n for every n (4k). So |A| < |𝒫(A)| for every set.” Not allowed for every set: the count needs A to have n members for some number n, and for an endless set no n fits. The parts-outrun proof counts nothing.
