24e · proof

When the Future Is Not Fixed

The last step needed the statement to be tame, and it promised a solution only for a while. Both limits are real. This step shows two statements that break them. In the first, the slope is the square root of the height, which is not tame near zero: a quantity resting at zero may stay there forever, or start to grow at any moment it likes, and the statement cannot tell which. In the second, the slope is the square of the height, which is tame on every bounded stretch but grows so fast that the solution climbs past every ceiling in a finite time and stops existing. A statement on rates fixes the future only when it is tame, and only for as long as the solution stays in bounds.

A statement that is not tame can let one start have endlessly many futures. A statement that is tame only on bounded stretches can send its solution past every ceiling in a finite time. A statement fixes the future when it is tame, and only while the solution stays bounded.

24e1One Start, Endlessly Many Futures

Many-futures technique: y′ = √|y| with y(0) = 0 has a different solution for every c ≥ 0: y = 0 for x ≤ c, and y = (x − c)²/4 for x ≥ c. And y = 0 everywhere solves it too.

x > c:\ y = \tfrac{(x-c)^2}{4},\ y' = \tfrac{x-c}{2} = \sqrt{y} @@ the chain technique; x − c > 0, so √y = (x − c)/2
x < c:\ y = 0,\ y' = 0 = \sqrt{0} @@ flat
x = c:\ \text{both sides have slope } 0 @@ (x − c)/2 → 0 from the right; 0 from the left (10e)
\htmlClass{new}{\text{each } c \ge 0 \text{ gives a solution with } y(0) = 0} \quad \blacksquare @@ the lines above

So 24d's promise of exactly one fails. Which hypothesis is missing? √|y| is continuous, but not tame near 0: (√|y| − 0)/(y − 0) = 1/√y passes every ceiling as y heads to 0. No L can do. Water draining through a hole in a tank obeys a statement of this shape, with the height falling at a rate in proportion to its square root. Run time backwards from an empty tank and the statement cannot say when it emptied.

24e2A Solution That Runs Off

Run-off technique: y′ = y² with y(0) = 1 has the solution y = 1/(1 − x) on x < 1, and no solution reaches x = 1. The statement is tame on every bounded rectangle, yet the solution passes every ceiling as x heads to 1.

y = \tfrac{1}{1-x},\ y' = \tfrac{1}{(1-x)^2} = y^2,\ y(0) = 1 @@ the chain technique
|y^2 - z^2| = |y + z|\,|y - z| \le 2B|y - z| \text{ when } |y|, |z| \le B @@ tame on every rectangle, with L = 2B
\text{a solution from } (0, 1) \text{ agrees with } \tfrac{1}{1-x} \text{ while both exist} @@ the drift technique (24d3), with equal starts
\tfrac{1}{1-x} \to \infty \text{ as } x \to 1^- @@ the bottom heads to 0
\htmlClass{new}{\text{no solution from } (0, 1) \text{ exists on } [0, 1]} \quad \blacksquare @@ it would have to be continuous at 1, hence bounded near 1

Why did 24d not see this coming? Its h shrank as the rectangle grew: hM ≤ β and hL < 1 with M = (1 + β)² and L = 2(1 + β). Each step forward is shorter than the one before, and the steps add up to less than 1. A tame rate fixes the future only for as long as the solution stays in bounds.

The accepted names

The many-futures statement is a standard example of non-uniqueness for a non-Lipschitz equation (Peano's example); the run-off is finite-time blow-up. A solution that cannot be continued past a point has a maximal interval of existence. The draining statement is Torricelli's law.

Who said it first

Giuseppe Peano gave statements with many solutions from one start in 1890, the year he proved that continuity alone gives at least one. Evangelista Torricelli found the draining statement in 1643. In 24e.4.5, the mathematician is Pierre-Simon Laplace (A Philosophical Essay on Probabilities, 1814), and the philosopher John D. Norton (2003); the shape is Norton's dome.
