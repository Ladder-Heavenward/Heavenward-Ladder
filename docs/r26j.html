One Function, Carried Further

The series 1 + z + z² + ⋯ stops making sense at the unit circle, yet 1/(1 − z) goes on happily everywhere but z = 1. Is 1/(1 − z) the series “carried further”, or just a different function that happens to agree inside? This step proves that a function with a complex slope is fixed everywhere on a connected region by its values on any small piece, so there is only one way to carry it further. Then it finds the catch: carried round a hole, as the logarithm is, a function can come back changed.

A nonzero function with a complex slope has only isolated zeros: near a zero its series starts with some cₖzᵏ, and that term wins. So two such functions agreeing on a small disc agree on the whole connected region. Carrying a function along a path is then unique, but carrying it round a hole, as log z, can add 2πi.

26j1Zeros Stand Alone

Lone-zero technique: if f has a complex slope on a disc round z₀, f(z₀) = 0, and f is not 0 everywhere near z₀, then f has no other zero in some smaller disc round z₀.

f(z) = \sum_{n \ge k} c_n (z - z_0)^n,\ c_k \ne 0 @@ its series (26g), first nonzero term k
f(z) = (z - z_0)^k\,g(z),\ \ g(z_0) = c_k \ne 0 @@ pull out the power
g \text{ is continuous, so } g \ne 0 \text{ near } z_0 @@ a nonzero value stays nonzero nearby
\htmlClass{new}{f(z) \ne 0 \text{ for } 0 < |z - z_0| < \delta} \quad \blacksquare @@ a product of two nonzero numbers

26j2Agreeing on a Piece Means Agreeing Everywhere

One-way technique: if f and g have complex slopes on a connected open region and agree on a small disc inside it, they agree on the whole region.

h = f - g;\ A = \{z: h \text{ is } 0 \text{ near } z\} @@ where h vanishes on a whole disc
A \text{ is open, and not empty} @@ the small disc
\text{a limit point of } A \text{ is a crowded zero, so it is in } A @@ the lone-zero technique, turned round
\htmlClass{new}{A \text{ is open and closed in a connected region: } A \text{ is all of it}} \quad \blacksquare @@ connected: no split into two open parts

So 1/(1 − z) is the only function with a complex slope off z = 1 that matches 1 + z + z² + ⋯ inside the disc. Carrying a function further, along any path, can be done in at most one way. 26n’s factorial past the count is such a carrying-further.

26j3Carried Round a Hole

\log z = \ln r + i\theta \text{ near } z = 1,\ \theta \text{ near } 0 @@ 26c
\text{carry along } z = e^{it},\ t \text{ from } 0 \text{ to } 2\pi @@ continuously, one way at each step
\theta \text{ rises from } 0 \text{ to } 2\pi @@ the value moves with it
\htmlClass{new}{\text{back at } z = 1:\ \log 1 = 2\pi i} @@ not where it started

Along a path the carrying is unique, but round a hole it can return changed: log z gains 2πi each time round 0, √z changes sign. The path’s way round the hole decides the value, which is why 26e’s loop integrals of 1/z give 2πi.

Accepted names

The one-way technique is the identity theorem; carrying further is analytic continuation; a value that changes round a hole makes a multivalued function with a branch point, and the surface it lives on is a Riemann surface.

Who said it first

Karl Weierstrass built functions by carrying power series from disc to disc in the 1840s and after; Riemann’s 1851 thesis gave the surfaces on which such functions take one value.
