17d · proof

ln Reaches Every Height

17b showed that ln rises with a slope that shrinks toward 0. A function like that might level off below a ceiling, as one less one over the input does. ln does not. Log-of-a-power turns the logarithm of two being at least a half into the logarithm of each power of two being at least half that power, which passes every bound, and rung 12’s intermediate value technique fills in every height between. So each real number is the log of exactly one positive number, and ln can be run backwards. And for all that, it rises more slowly than any power of the input, however small.

The logarithms of the powers of two climb without bound, and those of their reciprocals fall without bound. In-between-value, general form, and log-rises make the logarithm pair the positive numbers one to one with all the reals. Log-bounds at a half-power shows the logarithm falls behind every positive power.

17d1No Ceiling, No Floor

Log-unbounded technique: for every M there are x with ln x > M and x with ln x < −M. As x → ∞, ln x → ∞; as x → 0⁺, ln x → −∞.

\ln 2 \ge \tfrac12 @@ log-bounds (17a) at x = 2
\ln 2^n = n\ln 2 \ge \tfrac{n}{2},\ \ \ln 2^{-n} = -n\ln 2 \le -\tfrac{n}{2} @@ log-of-a-power (17c) with r = n and r = −n
n \gt 2M \Rightarrow \ln 2^n \gt M,\ \ \ln 2^{-n} \lt -M @@ counting-passes-any-real (8e) finds such an n
x \gt 2^n \Rightarrow \ln x \gt \ln 2^n \gt M @@ log-rises: ln rises
\htmlClass{new}{0 \lt x \lt 2^{-n} \Rightarrow \ln x \lt -M} \quad \blacksquare @@ log-rises again; these are the two limits, as 10f and 10e read limits far out and at a side

16i met the same fact in another dress: the harmonic sums 1 + ½ + ⅓ + … grow past every bound. The upper sums of 1/t on [1, n + 1] with unit pieces are exactly those sums, so 1 + ½ + … + 1/n > ln(n + 1). The endless sum 1 + ½ + ⅓ + ⋯ has the accepted name the harmonic series, a name from music: a string sounds overtones by vibrating in halves, thirds and quarters.

17d2Every Height, Once

Log-onto-ℝ technique: for every real c there is exactly one x > 0 with ln x = c. So ln is a bijection from (0, ∞) to ℝ, and its inverse is a continuous function from ℝ to (0, ∞).

\text{take } n \text{ with } \tfrac{n}{2} \gt |c| @@ as in log-unbounded
\ln 2^{-n} \lt c \lt \ln 2^n @@ log-unbounded's lines
\ln \text{ is continuous on } [2^{-n}, 2^n] @@ slope-means-no-gap (13b): it has a slope there (slope-of-log)
\text{some } x \in (2^{-n}, 2^n) \text{ has } \ln x = c @@ in-between-value, general form (12a)
\text{no second } x' \ne x \text{ has } \ln x' = c @@ log-rises: ln x < ln x′ or ln x′ < ln x
\htmlClass{new}{\ln : (0, \infty) \to \mathbb{R} \text{ is a bijection}} @@ onto by in-between-value, general form, one to one by log-rises
\text{its inverse exists and is continuous} \quad \blacksquare @@ swapped-pairs-function (9d); inverse-is-continuous (13l)

One mathematician of the late 1800s said that the whole numbers are the gift of God, and that everything else in arithmetic is human work. He argued that a number or a function proved to exist, without a way given to find it in finitely many steps, has not been shown to exist at all.

17d3Slower Than Any Power

Log-loses-to-powers technique: for every rational p > 0, ln x / xᵖ → 0 as x → ∞.

\ln u \le u - 1 \lt u \text{ for } u \gt 0 @@ log-bounds (17a)
u = x^{p/2}:\ \ \tfrac{p}{2}\ln x \lt x^{p/2} @@ log-of-a-power
x \gt 1:\ \ 0 \lt \tfrac{\ln x}{x^p} \lt \tfrac{2}{p}\,x^{-p/2} @@ divide by (p/2)xᵖ > 0; log-rises gives ln x > 0
x^{-p/2} \to 0 @@ below ε once x > ε^(−2/p): positive powers rise (8i)
\htmlClass{new}{\tfrac{\ln x}{x^p} \to 0} \quad \blacksquare @@ squeeze (10d)
  
\ln x \gt 10 \text{ for } x \gt 2^{20} \approx 1.05 \times 10^6 @@ log-unbounded's line with M = 10; 2²⁰ is enough, not the least
\tfrac{\ln x}{\sqrt x} \to 0 @@ log-loses-to-powers with p = ½
x \ln x \to 0 \text{ as } x \to 0^+ @@ x = 1/u: x ln x = −(ln u)/u, and u → ∞; log-loses-to-powers with p = 1
\ln x = 3:\ \ x \in (2^4, 2^5) @@ ln 2⁴ ≈ 2.77 < 3 < 3.47 ≈ ln 2⁵; in-between-value, general form, then halve the interval as often as you like

Who said it first

Kronecker said that the whole numbers are the gift of God and that everything else in arithmetic is human work, and that a number or a function proved to exist, without a way given to find it in finitely many steps, has not been shown to exist at all.

Leopold Kronecker, as reported by Heinrich Weber (1893); paraphrase

Accepted names: the endless sum 1 + ½ + ⅓ + ⋯ is the harmonic series.
