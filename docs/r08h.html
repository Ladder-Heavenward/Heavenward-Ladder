8h · technique

Absolute Value and Distance on the Line

Absolute value throws away a real's sign and keeps its size. That sounds like bookkeeping, but it is the tool that turns “near” into something you can calculate with. “This number is within a tenth of 3” becomes a statement about a distance, and from there an interval, a bound, a chain of inequalities. This step defines it as a split into two cases, and defines distance on the line with it. It proves the techniques by cases on signs, including the inequality that keeps an old geometric name. Then it makes your hands fast at unpacking bars, solving with them, and bounding.

The absolute value of a difference is how far apart two reals are. “Less than some distance” fences a real into the stretch of the line within that distance of another; and a detour through a third real is never shorter.

8h1The Definition, and What It Measures

From here on, for a real p, |p| names p if 0 ≤ p, and −p if p < 0. Read it “the absolute value of p”, or “the size of p”.

The bars of |p| are a new mark, one bar on each side. 4j's ∣, “divides”, a single bar standing between two numbers, keeps its meaning. The bars are an operator with one gap, and the result is a real.

It is 7e's definition by cases, on a statement three-way-order on ℝ settles either way. So |5| = 5, |−5| = −(−5) = 5, |0| = 0. In the second case the size is not a negative real. It is the negative of a negative, which is positive (order-and-arithmetic-agree). So |p| ≥ 0 always, and |p| = 0 only when p = 0. Every proof about |p| inherits the two cases.

From here on, for reals p and q, the distance between p and q on the line is |p − q|. Distance is defined here for the line only. It says how far apart two reals are in the line's order, and nothing of shape is meant. Distance between places in the plane waits for rung 18.

|p| is then the distance from p to 0. And |p − q| = |q − p| (the size-of-a-negative technique below), so distance does not care which end you start from. The expression that matters most is |x − x₀|, and it deserves its name:

From here on, for a real x₀ kept fixed (3f's low mark: x₀ is a name like any other), x − x₀ is the displacement of x from x₀. It is 5i's displacement pattern, without its square. Its size |x − x₀| is the distance from x₀ to x.

8h2The Techniques, by Cases on Signs

Each of these is proved by splitting on the signs of the reals inside the bars (three-way-order on ℝ), then using the twelve techniques. Size-of-a-negative technique: |−p| = |p|. If 0 < p, then −p < 0 and |−p| = −(−p) = p = |p|. If p = 0 both are 0. If p < 0, then 0 < −p and |−p| = −p = |p|. ∎ Size-of-a-product technique: |pq| = |p| |q|, by the four sign cases and signs-come-out, two-negatives. Size-squared technique: |p|² = p², and √(p²) = |p|. |p|² is p² or (−p)², and two-negatives makes them equal. Then |p| ≥ 0 and squares to p², so it is √(p²) by one-root. So √(x²) is x only for x ≥ 0. Sandwich technique: −|p| ≤ p ≤ |p|. Unpack-the-bars technique: for d ≥ 0, |p| ≤ d ⇔ −d ≤ p ≤ d, and |p| < d ⇔ −d < p < d.

|a| \lt d @@ the claim to unpack, rightward
0 \le a:\ \ |a| = a,\ \text{so } -d \lt 0 \le a \lt d @@ the first case; −d < 0 since d > 0 here (0 ≤ |a| < d)
a \lt 0:\ \ -a \lt d,\ \text{so } -d \lt a \lt 0 \lt d @@ the second case; negative-reverses-order (8g) on −a < d, times −1
\htmlClass{new}{-d \lt a \lt d} @@ the two cases give one double inequality
-d \lt a \lt d \Rightarrow |a| \lt d \quad \blacksquare @@ leftward: |a| is a or −a, and negative-reverses-order turns −d < a into −a < d

Absolute value passes through multiplying (size-of-a-product). It does not pass through adding, and what you get instead is the most used inequality there is.

The oldest geometry book that has come down whole proves that any two sides of a triangle together are longer than the third. An old commentator reports that some philosophers mocked the proof. Even a donkey, they said, knows it, since it walks straight to its hay rather than round by two sides.

8h3The Triangle Inequality

Triangle technique: |p + q| ≤ |p| + |q|. It keeps its traditional name, from the geometry of rung 18; here it is about sizes on the line and nothing else. Proved by cases on signs:

case|p + q|compared with |p| + |q|
0 ≤ p, 0 ≤ qp + q (positive-sum on ℝ: not negative)equal: |p| + |q| = p + q
p < 0, q < 0−p − q (p + q negative; negative-of-a-sum)equal: |p| + |q| = −p − q
0 ≤ p, q < 0, 0 ≤ p + qp + qp + q < p − q = |p| + |q|, since q < 0 < −q (keep-order for plus on ℚ)
0 ≤ p, q < 0, p + q < 0−p − q−p − q ≤ p − q = |p| + |q|, since −p ≤ 0 ≤ p
p < 0 ≤ qthe two rows above, with p and q exchangedTurn-about for plus on ℝ

Every case gives ≤, so the triangle technique is proved. ∎ The two sides are equal exactly when p and q are not of opposite signs. A shorter road uses the sandwich. Add −|p| ≤ p ≤ |p| and −|q| ≤ q ≤ |q| part by part (same-direction-add), to get −(|p| + |q|) ≤ p + q ≤ |p| + |q|. Then pack it up with unpack-the-bars. In distance form, put p = x − y and q = y − z: |x − z| ≤ |x − y| + |y − z|. Going from x to z by way of y is never shorter than going straight. Run it backwards and you get the reverse form: |p| = |(p − q) + q| ≤ |p − q| + |q|. So |p| − |q| ≤ |p − q|: two sizes cannot differ by more than the reals do.

8h4|x − m| < d is a stretch of the line around m

|x − m| < d is the stretch of the line within d of m. Put the displacement into unpack-the-bars:

|x - a| \lt d @@ x is less than d from a
-d \lt x - a \lt d @@ unpack-the-bars, with x − a in place of a
\htmlClass{new}{a - d \lt x \lt a + d} @@ add a to all three parts (keep-order for plus on ℚ)
x \in (a - d,\ a + d) @@ an interval (8g): a in the middle, d on each side

So |x − 3| < ½ is (5/2, 7/2). With ≤ the ends come in: [m − d, m + d]. With > you get the outside, two pieces: x < m − d or x > m + d. Run it backwards. Every interval (c, e) with c < e is such a stretch, with middle (c + e)/2 and reach (e − c)/2 on each side. So (1, 7) is |x − 4| < 3, and (−5, −2) is |x + 7/2| < 3/2. Notice x + 7/2 is the displacement x − (−7/2): a plus sign inside means the middle is negative.

8h5Solving With Bars

The method is always the same: unpack the bars into cases, or into a double inequality, then use 8g's techs.

|2x - 3| = 5 @@ 2x − 3 is 5 from 0
2x - 3 = 5 \;\lor\; 2x - 3 = -5 @@ the two reals at distance 5 from 0 (the definition, both cases)
\htmlClass{new}{x = 4 \;\lor\; x = -1} @@ solve each (5g)
|3 - 2x| \le 7 @@ within 7 of 0
-7 \le 3 - 2x \le 7 \;\to\; -10 \le -2x \le 4 @@ unpack-the-bars; add −3 to all three parts
\htmlClass{new}{-2 \le x \le 5} @@ multiply by −½: both ends turn (negative-reverses-order), and the parts swap places

An outside inequality splits in two and stays split. |x + 1| > 2 means x + 1 > 2 or x + 1 < −2, so x > 1 or x < −3. Writing it as one chain, −2 > x + 1 > 2, is a classic slip: it says a real is below −2 and above 2 at once. And sometimes distances beat algebra. |x − 1| = |x + 3| asks for the real as far from 1 as from −3: the one halfway, x = −1.

With two sets of bars, find where each inside is 0. Those reals cut the line into stretches, and in each stretch every bar comes off with a known sign. Solve |x − 1| + |x + 2| = 5:

x \lt -2:\ \ -(x - 1) - (x + 2) = 5 @@ both insides negative: each bar is minus its inside
-2x - 1 = 5,\ \ \htmlClass{new}{x = -3} @@ and −3 < −2: in the stretch, so kept
-2 \le x \lt 1:\ \ -(x - 1) + (x + 2) = 5 @@ the first inside negative, the second not
3 = 5 @@ never: no answers in this stretch
1 \le x:\ \ (x - 1) + (x + 2) = 5 @@ both insides not negative
2x + 1 = 5,\ \ \htmlClass{new}{x = 2} @@ and 2 ≥ 1: kept

In distances: |x − 1| + |x + 2| is the distance from x to 1 plus the distance to −2. Anywhere between them the total is just the gap, 3. You must step outside by 1 on either side to make it 5. Hence −3 and 2, and the middle stretch's “3 = 5” is the algebra saying the same. Bars also give 8b's greater and lesser in one line each: max(p, q) = (p + q + |p − q|)/2 and min(p, q) = (p + q − |p − q|)/2. Start halfway and go half the distance up, or down. (Check by the two cases of three-way-order on ℝ.)

8h6Bounding: Tame the Far Factor

Suppose x is within 1 of 3 and you want to know how far x² is from 9. Factor the gap, bound the factor you do not control, and keep the one you do:

|x^2 - 9| = |x - 3|\,|x + 3| @@ difference-of-squares (5i), then size-of-a-product
|x - 3| \lt 1 \;\Rightarrow\; 2 \lt x \lt 4 @@ agree to stay within 1 of 3; the stretch
5 \lt x + 3 \lt 7,\ \text{so } \htmlClass{new}{|x + 3| \lt 7} @@ add 3 to all three parts; unpack-the-bars, since −7 < 5
|x^2 - 9| \le 7\,|x - 3| @@ order-and-arithmetic-agree's second part, with |x − 3| ≥ 0 (equal when x = 3)

So if x is within 1/100 of 3, x² is within 7/100 of 9. Running it backwards is the useful direction. To get x² within 7/1000 of 9, it is enough to have x within 1/1000 of 3, which is also within 1 of 3.

8h7Moves to Watch Out For

|a + b| = |a| + |b|\,? @@ <span class="vd vd-p">outside the plan</span> a = −2, b = 3: 1 against 5. Only ≤ is true (triangle)
|a - b| = |a| - |b|\,? @@ <span class="vd vd-p">outside the plan</span> a = 1, b = 4: 3 against −3. A distance is never negative
|x| \lt 3,\ \text{so } x \lt 3\,? @@ <span class="vd vd-l">legal, with a cost</span> true but half: x = −10 passes x < 3 and fails |x| < 3. Unpack to −3 < x < 3
|-x| = x\,? @@ <span class="vd vd-p">outside the plan</span> only when x ≥ 0; in general |−x| = |x| (size-of-a-negative)
|x - 2| = 5,\ \text{so } x - 2 = 5\,? @@ <span class="vd vd-p">outside the plan</span> loses x = −3: two reals are 5 from any real
\sqrt{x^2} = x\,? @@ <span class="vd vd-p">outside the plan</span> √(x²) = |x| (size-squared): for x = −3 it is 3

8h8Running It Backwards

Handed an interval, write it as |x − middle| < reach. Handed answers −2 and 5 to |kx + b| = c, find the middle, 3/2, and the reach, 7/2. Then write |x − 3/2| = 7/2, and scale. Wanting |something| small, factor out the displacement you control and bound the rest. Found upward; written downward.
