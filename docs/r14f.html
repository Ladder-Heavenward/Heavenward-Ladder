14f · technique

Crest and trough

14a's flat-top found the critical points. It said nothing about which are tops, which are bottoms and which are neither. 14d's slope-sign-order says that the sign of the slope across an interval decides whether the function climbs or falls there. Put a critical point between two such intervals. If the function climbs up to it and falls after, it is a top. If it falls to it and climbs after, a bottom. If it climbs on both sides, or falls on both, neither. That is the first test. The second reads the same thing from one number. Say the slope is 0 at an input and the slope of the slope is positive there. Then the slope itself is climbing through 0, so it is negative just before and positive just after. That is the first test's bottom.

Read the sign of the slope just left and just right of a critical point: up then down is a top, down then up a bottom, the same on both sides neither. If the slope is 0 there and the slope of the slope is positive, the slope climbs through 0, which is down then up.

14f1The first test

First-test technique: let f be continuous on an open interval around c, with a slope at every input of it except perhaps c. If, for some reach δ, f′ > 0 on (c − δ, c) and f′ < 0 on (c, c + δ), then f has a top at c. If f′ < 0 on the left and f′ > 0 on the right, a bottom. If f′ has one sign on both sides, neither.

f \text{ increasing on } [c - \delta, c] @@ slope-sign-order (14d): continuous there, positive slopes inside
c - \delta \lt x \lt c \;\Rightarrow\; f(x) \lt f(c) @@ increasing, at x and c
f \text{ decreasing on } [c, c + \delta] @@ slope-sign-order: negative slopes inside
c \lt x \lt c + \delta \;\Rightarrow\; f(x) \lt f(c) @@ decreasing, at c and x
\htmlClass{new}{f \text{ has a top at } c} @@ f(x) ≤ f(c) on the neighbourhood of reach δ
  
f' \gt 0 \text{ on both sides} @@ the case of one sign
f \text{ increasing on } [c - \delta, c + \delta] @@ slope-sign-order on each half, chained through c (as in positive-but-finitely)
f(c - h) \lt f(c) \lt f(c + h) \text{ for } 0 \lt h \lt \delta @@ so every neighbourhood holds a lower and a higher value: neither ∎

Its accepted name is the first derivative test. The top it finds is strict: every other input near c has a smaller value. It needs no slope at c, so it works at a sharp bend, where flat-top cannot. 14a's x² − 2|x| has slope 2x + 2 on (−1, 0), positive. It has slope 2x − 2 on (0, 1), negative. So it has a top at 0, where it has no slope. The first test is also what shows that 13·econ's level place at 387 jars is a bottom, and that flag is closed.

To use it, factor f′ and read its sign between neighbouring critical points. For a polynomial the sign cannot change between two neighbouring zeros of f′. That is in-between-value, since f′ is continuous. So one test input in each stretch gives the sign of the whole stretch.

f(x) = x^3 - 6x^2 + 9x + 1 @@ a polynomial
f'(x) = 3x^2 - 12x + 9 = 3(x - 1)(x - 3) @@ polynomial-slope; critical points 1 and 3
x \lt 1:\ + \quad 1 \lt x \lt 3:\ - \quad x \gt 3:\ + @@ signs of products (8g), or test inputs 0, 2, 4
\text{top at } 1,\ f(1) = 5;\ \ \text{bottom at } 3,\ f(3) = 1 @@ first-test at each
  
f(x) = x^4 - 4x^3,\ \ f'(x) = 4x^2(x - 3) @@ critical points 0 and 3
x \lt 0:\ - \quad 0 \lt x \lt 3:\ - \quad x \gt 3:\ + @@ x² ≥ 0 does not change sign at 0
0:\ \text{neither};\ \ 3:\ \text{bottom},\ f(3) = -27 @@ first-test: the sign is the same on both sides of 0

14f2The second test

Second-test technique: if f′(c) = 0 and f″(c) > 0, then f has a bottom at c. If f′(c) = 0 and f″(c) < 0, a top.

f''(c) \text{ exists, so } f' \text{ is defined near } c @@ 13a: a slope of f′ at c needs f′ on a neighbourhood
\text{call } r:\ f'(c + h) \gt f'(c) = 0 \text{ for } 0 \lt h \lt r @@ slope-sign-near (13k), for the function f′, whose slope at c is positive
f'(c + h) \lt 0 \text{ for } -r \lt h \lt 0 @@ slope-sign-near, its second half
f \text{ continuous near } c @@ slope-means-no-gap: f has a slope at every input near c
\htmlClass{new}{f \text{ has a bottom at } c} \quad \blacksquare @@ first-test: negative on the left, positive on the right

Its accepted name is the second derivative test. Check it on the sign table above: f″(x) = 6x − 12, so f″(1) = −6, a top, and f″(3) = 6, a bottom. It agrees.

The second test is silent when f″(c) = 0. At 0, x⁴ has a bottom, −x⁴ a top, and x³ neither, and all three have f′(0) = 0 and f″(0) = 0. Then go back to the first test. And x⁴ − 4x³ at 0 has f″(0) = 0 too, while at 3 it has f″(3) = 108 − 72 = 36 > 0, a bottom, as the signs said.

14f3From a top to the top

A top is greatest among its neighbours. 14a's candidates finds the greatest value on a closed interval by comparing candidates. On an interval that is not closed there is no highest-and-lowest, but one critical point can be enough.

One-critical-point technique: let f be continuous on an interval I with a slope at every input inside. Suppose the slope is 0 at exactly one input c inside, and f′ is continuous inside I. If c is a bottom, then f(c) is the least value of f on I. If c is a top, it is the greatest. The slope has no zero on the part of I left of c, and it is continuous there. So by in-between-value it has one sign there. It must be negative: if it were positive, f would climb up to c, and c would not be a bottom (slope-sign-order). Likewise it is positive right of c. So f is decreasing up to c and increasing after it (slope-sign-order), and f(c) is below every other value. ∎ Every polynomial's slope is continuous.

f(x) = x + \tfrac{4}{x} \text{ on } (0, \infty) @@ no closed interval, so no highest-and-lowest
f'(x) = 1 - \tfrac{4}{x^2} = \tfrac{(x - 2)(x + 2)}{x^2} @@ quotient for slopes, slopes-add; continuous on (0, ∞)
\text{zero only at } 2;\ \ f''(2) = \tfrac{8}{8} = 1 \gt 0 @@ f″(x) = 8/x³; second-test: a bottom
\htmlClass{new}{x + \tfrac4x \ge 4 \text{ on } (0, \infty)} @@ one-critical-point: the least value, f(2) = 4

8g's questions compared the halfway mean of two positive reals with the square root of their product. The same comparison falls out here. For x > 0, x and 4/x have the product 4. Their halfway mean is never less than 2, the square root of their product.

14f5Running it backwards

Handed a function and asked for its tops and bottoms, find f′ and factor it. List the critical points, and read the sign in each stretch. Or, where f′(c) = 0, compute f″(c) and use its sign, falling back to the signs if it is 0. Handed a sign table, read the tops and bottoms off it without the function. Handed tops and bottoms and asked for a polynomial, write f′ as a product with those zeros and sign changes, then find f by 14e. Found upward; written downward.

14f.4.4seam When the second slope at c is zero, a textbook of 1742 looked further: take slopes of slopes until one is not zero at c. If the first such is an odd one, c is neither; if an even one, c is a bottom or a top as it is positive or negative.
