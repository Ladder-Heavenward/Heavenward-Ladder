24h · technique

The Two Model Equations

Two rules on rates turn up everywhere, and this step solves them for good. The first says a quantity changes at a rate in proportion to its distance from a resting value: a drink warming toward the room, savings growing with interest while a fixed sum is drawn out. The second says the rate at which the slope changes is in proportion to the height, with the sign turned round: a weight on a spring, a small swing, anything pulled back toward the middle harder the further it strays. The first is fixed by one starting value. The second needs two, a height and a slope, and its solutions swing forever at one steady pace. Its proof of only one answer uses an energy that never changes. Then the step takes on every rule of the second order whose numbers in front are constant, by trying a growth function and asking which growth rates fit. When the rates that fit are real, the step finds every solution and proves there are no others. When they are not real, the method is held in trust for a later rung.

Steady growth toward or away from a resting value is fixed by one start. Steady swinging is fixed by a height and a slope, and an energy that never changes proves it. Second-order rules with constant numbers in front are solved by trying growth functions, whenever the growth rates that fit are real.

24h1Steady Growth, Toward or Away From Rest

Shift-to-rest technique: for any real k ≠ 0 and any A, the rule y′ = k(y − A) with y(x₀) = y₀ has exactly one solution on the whole line, y = A + (y₀ − A)e^(k(x − x₀)); when k < 0 every solution heads to A, and when k > 0 every solution but the flat line A leaves it.

z = y - A \Rightarrow z' = y' = k(y - A) = kz @@ A is constant, with slope 0
z(x_0) = y_0 - A @@ the start, shifted
z = (y_0 - A)e^{k(x - x_0)} \text{ exactly} @@ the own-rate technique (24a3)
\htmlClass{new}{y = A + (y_0 - A)e^{k(x - x_0)}} \quad \blacksquare @@ shift back; e^{k(x − x₀)} heads to 0 when k < 0, and passes every ceiling when k > 0
  
T(0) = 4,\ \ T' = k(T - 30) @@ °C and minutes; a kitchen in Sacramento at 30 °C
T = 30 - 26e^{kt} @@ the shift-to-rest technique
T(10) = 12 \Rightarrow e^{10k} = \tfrac{18}{26},\ \ k = \tfrac{1}{10}\ln\tfrac{9}{13} \approx -0.0368 @@ one reading fixes k
\htmlClass{new}{T = 25 \text{ when } t = \tfrac{\ln(5/26)}{k} \approx 44.8 \text{ minutes}} \quad \blacksquare @@ e^{kt} = 5/26; put back: T′ = −26ke^{kt} = k(T − 30)

The rule is straight in y and it parts, so 24f and 24g both solve it. The shift is shorter. The sign of k decides everything about the far future: a resting value that pulls, or one that pushes.

24h2Steady Swinging

A second-order rule speaks of y″, so a start for it is two numbers at one input: a height y(x₀) = A and a slope y′(x₀) = B.

Steady-swing technique: for any n > 0, the rule y″ = −n²y with y(x₀) = A, y′(x₀) = B has exactly one solution on the whole line, y = A cos(n(x − x₀)) + (B/n) sin(n(x − x₀)), and every solution repeats every 2π/n.

y' = -nA\sin(n(x - x_0)) + B\cos(n(x - x_0)),\ \ y'' = -n^2 y @@ the trig chain (21l), twice
y(x_0) = A,\ \ y'(x_0) = B @@ sin 0 = 0, cos 0 = 1: there is one
z \text{ another solution with the same start};\ w = z - y @@ w″ = −n²w, w(x₀) = 0, w′(x₀) = 0
E = w'^2 + n^2w^2,\ \ E' = 2w'w'' + 2n^2ww' = 2w'(w'' + n^2w) = 0 @@ the chain rule; the rule for w
E = E(x_0) = 0 @@ zero slope means flat (14d)
\htmlClass{new}{w = 0, \text{ so } z = y \text{ on the whole line}} \quad \blacksquare @@ squares that add to 0 are each 0

Why not cite 24d? 24d speaks of one function and its first slope. A second-order rule is two first-order rules at once, one for y and one for y′, and the largest gap between pairs of functions is not built here. The energy does the job directly, as it did on 21g for n = 1. For every solution, y′² + n²y² stays at its starting value B² + n²A², so the swing never grows or dies: its height stays within √(A² + B²/n²) and reaches it.

y = \cos 2x + \tfrac22 \sin 2x = \cos 2x + \sin 2x @@ the steady-swing technique, n = 2
y'' = -4\cos 2x - 4\sin 2x = -4y,\ \ y(0) = 1,\ \ y'(0) = 2 @@ put back
\htmlClass{new}{\text{period } \pi,\ \text{height at most } \sqrt{1 + 1} = \sqrt2} \quad \blacksquare @@ 2π/n; y′² + 4y² = 8 at every x

24h3Trying a Growth

Take a rule y″ + by′ + cy = 0 with constant numbers b and c. Try y = e^(rx): its slopes are re^(rx) and r²e^(rx), so the rule becomes (r² + br + c)e^(rx) = 0. Since e^(rx) is never 0, the try works exactly when r² + br + c = 0. Call this the trial equation of the rule.

Tried-growth technique: if the trial equation r² + br + c = 0 has real roots r₁ and r₂, every solution of y″ + by′ + cy = 0 is C₁e^(r₁x) + C₂e^(r₂x) when r₁ ≠ r₂, and (C₁ + C₂x)e^(rx) when r₁ = r₂ = r; and a height and a slope at one input pick C₁ and C₂ exactly.

r_1 + r_2 = -b,\ \ r_1r_2 = c @@ r² + br + c = (r − r₁)(r − r₂): multiply out
w = y' - r_2y \Rightarrow w' - r_1w = y'' - (r_1 + r_2)y' + r_1r_2y = y'' + by' + cy = 0 @@ the rule, split into two first-order rules
w = (B - r_2A)\,e^{r_1(x - x_0)} \text{ exactly} @@ the own-rate technique (24a3); w(x₀) = B − r₂A
y' - r_2y = w,\ \ y(x_0) = A \text{ has exactly one solution} @@ the multiplying-factor technique (24g1)
(e^{-r_2x}y)' = (B - r_2A)\,e^{-r_1x_0}\,e^{(r_1 - r_2)x} @@ the factor e^{−r₂x}
\htmlClass{new}{y = C_1e^{r_1x} + C_2e^{r_2x}\ (r_1 \ne r_2),\ \ y = (C_1 + C_2x)e^{rx}\ (r_1 = r_2)} \quad \blacksquare @@ take the area (16c): e^{(r₁ − r₂)x} if r₁ ≠ r₂, x if they are equal
  
r^2 + 3r + 2 = (r + 1)(r + 2) = 0 \Rightarrow r = -1, -2 @@ the trial equation
y = C_1e^{-x} + C_2e^{-2x},\ \ C_1 + C_2 = 1,\ \ -C_1 - 2C_2 = 0 @@ the height and the slope at 0
\htmlClass{new}{y = 2e^{-x} - e^{-2x}} \quad \blacksquare @@ C₁ = 2, C₂ = −1; put back: (2 − 6 + 4)e^{−x} + (−4 + 6 − 2)e^{−2x} = 0

That rule is a heavy door closer: pushed open and let go, the door creeps shut without swinging past. With b = 2 and c = 1 the trial equation has the one root −1, and y = (1 + x)e^(−x) is the closer set exactly at the edge of swinging.

When b² < 4c the trial equation has no real root. y″ + y = 0 is such a rule, and the steady-swing technique solved it with cos and sin, not with growth functions. For every rule of this kind with b ≠ 0, the step from the trial equation to all solutions is held in trust. 26·cb24 pays it, once growth functions are carried past the real line.

The accepted names

The shift-to-rest rule is Newton's law of cooling in the kitchen and a linear first-order equation with constant coefficients in general. The steady swing is simple harmonic motion, and its rule the harmonic oscillator; the flat energy is conservation of energy. The trial equation is the characteristic equation (or auxiliary equation), and the tried-growth technique solves linear homogeneous equations with constant coefficients. The heavy door closer is overdamped, and the closer at the edge is critically damped. Splitting the rule into w = y′ − r₂y is factoring the differential operator.

Who said it first

Isaac Newton stated his law of cooling in 1701. Robert Hooke stated in 1678 that a spring's pull is in proportion to its stretch, which gives the steady-swing rule. Leonhard Euler solved rules with constant numbers in front by trying growth functions in 1743, and Jean le Rond d'Alembert found the extra x for a repeated root at about the same time.
