40f · proof

A Program’s Promise

A program makes a promise. Start it where P holds, and if it stops, Q holds. This step writes the promise as a statement, and gives the rules that earn it, one shape at a time.

{P} c {Q}: if P before, then Q after. Assignment reads backwards: to have Q after x ← e, have Q with e in x’s place before.

40f1The Triple

{P} c {Q} says: for every state in which P holds, if c runs and stops, then Q holds in the state after. It is an every around an if (2b10). P is the condition before and Q the condition after. For example, {x = 2} x ← x + 1 {x = 3}.

The triple says nothing about whether c stops. Stopping is proved apart, by 40e’s measure.

40f2Assignment, Read Backwards

Backwards-assignment technique: {Q[e/x]} x ← e {Q}, where Q[e/x] is Q with e put in every gap marked x.

The rule runs backwards because x after the step holds what e held before (40c2). So whatever Q says of x afterwards, Q[e/x] said of e beforehand. For example, to have y > 3 after y ← x + 1, have x + 1 > 3 before, which is x > 2.

40f3Sequence and Choice

Sequence technique: from {P} c₁ {R} and {R} c₂ {Q}, write {P} c₁; c₂ {Q}.

Choice technique: from {P ∧ B} c₁ {Q} and {P ∧ ¬B} c₂ {Q}, write {P} if B then c₁ else c₂ {Q}.

The first chains two promises through the middle condition R, as 1d chains ifs. The second is reason by cases (1c7): B holds or it does not, and the branch technique of 40b1 runs the right one.

40f4Stronger Before, Weaker After

Consequence technique: if P′ ⇒ P, {P} c {Q} and Q ⇒ Q′, then {P′} c {Q′}.

Worked: show {x > 5} y ← x + 1 {y > 3}. Backwards-assignment gives {x + 1 > 3} y ← x + 1 {y > 3}. And x > 5 gives x + 1 > 3. So consequence gives the triple. A promise may always be asked of a stronger start, and may always be weakened at the end.

The accepted names

A triple {P} c {Q} is a Hoare triple, P is its precondition and Q its postcondition, and a triple that says nothing about stopping states partial correctness. Reading assignment backwards leads to the weakest precondition. The rules of this step and the next form Floyd–Hoare logic.
