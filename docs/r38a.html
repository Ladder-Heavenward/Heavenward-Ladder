38a · proof

A language for mathematics

Since the first rung you have written statements in marks, and the ladder never once said exactly which strings of marks count as statements. Rung four made a proof an object, a list of lines, but the statements on those lines were taken as they came. That was enough while the only question was whether a proof was right. It is not enough for the questions of this rung, which ask about every proof at once, and about every world a statement could be true in. So the statements themselves become objects. A language is a short list of marks. Its terms and its formulas are built from the marks by repeating a few steps, the way rung four built the numbers. A world for the language gives each mark a meaning, and then truth in that world is defined, one way of building at a time. The same statement can be true in one world and false in another, and that difference is the tool the whole rung works with.

A language is a list of marks. Its formulas are built by recursion and read in exactly one way. A world gives each mark a meaning, and truth in the world is defined by the same recursion, so two matched worlds make the same statements true.

38a1Marks, terms and formulas

A language is a list of marks of three kinds. Names, each standing for one thing. Function marks, each with a number of places, each making a thing from that many things. Relation marks, each with a number of places, each saying something of that many things. Every language also shares the placeholders x₀, x₁, x₂, … of 2b, the mark =, the joining words ¬, ∧, ∨, ⇒, the totally false ⊥, the turned A and E, and brackets.

The language of arithmetic has one name, 0, one function mark with one place, S, and two with two places, + and ·. The language of sets has one relation mark with two places, ∈, and nothing else.

Terms are built by 4d’s recursion. Every placeholder and every name is a term. If f has n places and t₁, …, tₙ are terms, then f(t₁, …, tₙ) is a term; t + s is shorthand for +(t, s). Formulas are built the same way. t = s, R(t₁, …, tₙ) and ⊥ are formulas. If φ and ψ are formulas and x is a placeholder, then ¬φ, (φ ∧ ψ), (φ ∨ ψ), (φ ⇒ ψ), ∀x φ and ∃x φ are formulas. Nothing else is.

One-reading technique: every formula is built in exactly one way.

\text{every term and formula has as many left brackets as right} @@ induction on the building (4c): each step adds one of each, or none
\text{a starting piece of a formula never has more right brackets than left} @@ the same induction, one building step at a time
\text{a starting piece of } (\varphi \land \psi) \text{, shorter than it, has more left than right} @@ the outer bracket is still open
(\varphi \land \psi) = (\varphi' \lor \psi') \text{ with } \varphi \text{ shorter than } \varphi' @@ suppose two readings part at the first inner formula
\varphi \text{ is a starting piece of } \varphi' \text{ with equal brackets, and not all of it} @@ the first line, on φ
\bot @@ against the second and third lines, on φ′: a shorter starting piece of φ′ that is itself a formula either begins with a bracket and so has more left than right, or is an atom, a ¬, a turned A or a turned E, read the same way one mark further in
\htmlClass{new}{\varphi = \varphi',\ \text{the joining word is the same},\ \psi = \psi'} \quad \blacksquare @@ the same lines for every other way of building

So a formula is not just a string. It is a string with one history, and anything defined “one way of building at a time” is defined once. 4d’s recursion technique needs exactly that: each thing made in one way only. The rest of the rung defines truth, codes and proofs by such recursions.

An every or a some binds its placeholder, as in 2b. A placeholder that is not bound where it stands is free there. A formula with no free placeholder is a statement. x₀ + 0 = x₀ is a formula; ∀x₀ (x₀ + 0 = x₀) is a statement.

38a2A world for the language

3d’s layers, 6d’s sock world and 29c’s disc plane were worlds described in words. Here a world is an object. A world M for a language is a set |M| with at least one member, and a meaning for each mark: a member of |M| for each name, a function from lists of n members to members for each function mark with n places, and a relation, a set of lists of n members (2g), for each relation mark with n places. Its accepted name is a structure, from the Latin structura, a building.

The world N has the numbers of rung 4 as its members, 0 for 0, the next one for S, and rung 4’s adding and multiplying for + and ·. The integers of rung 5, with S(x) = x + 1, are another world for the same language. So is the set {0, 1} with S swapping 0 and 1, and x + y and x · y both read as 0 always.

An assignment s gives each placeholder a member of |M|. The value of a term is found by recursion: a placeholder x takes s(x); a name takes its member; f(t₁, …, tₙ) takes the meaning of f at the values of t₁, …, tₙ.

M = N,\ \ s(x_0) = 3 @@ the world of rung 4, and an assignment
\text{value of } 0 = 0,\ \ \text{value of } S(0) = 1,\ \ \text{value of } S(S(0)) = 2 @@ a name, then S twice: the next one
\text{value of } x_0 = 3 @@ the assignment
\htmlClass{new}{\text{value of } S(S(0)) + x_0 = 2 + 3 = 5} \quad \blacksquare @@ the meaning of + at the two values (4f)

In the world {0, 1} the same term, with s(x₀) = 1, has the value 0: S(S(0)) is 0 there, and + gives 0 whatever it is fed. The term is the same string. Its value belongs to the world.

38a3True in a world

Truth in M is defined by recursion on formulas, under an assignment s. t = t′ is true when the two values are the same member. R(t₁, …, tₙ) is true when the list of values is in R’s relation. ⊥ is never true. ¬, ∧, ∨ and ⇒ follow 1e’s tables. ∀x φ is true when φ is true under every assignment that agrees with s except perhaps at x. ∃x φ is true when φ is true under some such assignment.

This is 1e’s tables with one row for each assignment, and 2b’s every and some read over the members of M. The every clause speaks of every member, and there may be endlessly many. So truth in N is defined, and it is not computed: no recipe checks every number. 4j’s bounded-some technique settles only the somes and everys kept below a bound.

Free-places technique: whether a formula is true in a world under an assignment depends only on what the assignment gives its free placeholders.

s,\ s' \text{ agree on the free placeholders of } \varphi @@ given
\text{a term's value uses only the placeholders written in it} @@ induction on the term (38a1)
\varphi \text{ an atom: both values the same, so the same truth} @@ the clause for = and for R
\varphi = \neg\psi,\ (\psi \land \chi), \ldots: \text{ the parts have no other free placeholders} @@ induction on the building; 1e’s tables
\varphi = \forall x\,\psi:\ s,\ s' \text{ changed at } x \text{ still agree on the free placeholders of } \psi @@ ψ’s free placeholders are φ’s, and perhaps x
\htmlClass{new}{s \text{ and } s' \text{ make } \varphi \text{ true together, or neither does}} \quad \blacksquare @@ the some case is the same

A statement has no free placeholders, so every assignment gives it the same truth. From here on, M ⊨ φ, read “φ is true in M”, means φ is true there under any assignment. On the ladder each statement is true in M or not, by rung 7’s either-way principle: its every clauses run over a set that may be endless.

N \models \forall x_0\,(x_0 = 0 \lor \exists x_1\,(x_0 = S(x_1))) @@ every number is 0 or a next (the zero-or-a-next technique, 4c)
\text{in the integers: } {-5} = S(-6) @@ every integer is a next there
\htmlClass{new}{N \models \neg\exists x_0\,(S(x_0) = 0),\ \ \text{and in the integers } \exists x_0\,(S(x_0) = 0) \text{ is true}} \quad \blacksquare @@ 0 is nobody’s next in N (4b); 0 = S(−1) in the integers

38a4Same statements, different worlds

A collection G of statements is true in M when each of its members is. Then M is a world of G. And G ⊨ φ, read “G makes φ true everywhere”, means: φ is true in every world of G.

A matching h from |M| onto |M′| (9c) carries the marks when h sends each name’s member to its member in M′, h(f(u₁, …)) = f′(h(u₁), …) for each function mark, and a list is in R exactly when its image is in R′.

Matching-worlds technique: if a matching carries every mark of M to M′, then every statement true in M is true in M′, and every statement false in M is false in M′.

\text{value}^{M'}_{h\circ s}(t) = h(\text{value}^M_s(t)) @@ induction on the term: h carries names and function marks
\varphi \text{ an atom: } M \models \varphi[s] \iff M' \models \varphi[h \circ s] @@ h is one-to-one for =, and carries R
\varphi = \forall x\,\psi:\ \text{each member of } M' \text{ is } h(u) \text{ for one } u @@ h is onto, so changing h∘s at x runs over every member of M′
\text{the joining words and some go through by the same induction} @@ 38a3’s clauses
\htmlClass{new}{M \models \varphi \iff M' \models \varphi \text{ for every statement } \varphi} \quad \blacksquare @@ a statement needs no assignment (the free-places technique)

So statements cannot tell matched worlds apart. They can often tell unmatched ones apart: N and the integers differ on ∃x₀ (S(x₀) = 0). Whether they always can is a question 38e answers, and the answer is no.

The accepted names

The language is a signature or vocabulary; its marks are constant, function and relation symbols, each with an arity. The terms and formulas are the well-formed terms and formulas of first-order logic; first-order because every and some range over members only, never over sets of them. The one-reading technique is unique readability. Free and bound placeholders are free and bound variables; a formula with no free variable is a sentence. A world is a structure or interpretation; its set is the domain or universe. The definition of truth is the Tarskian satisfaction relation, M ⊨ φ[s]. The free-places technique is the coincidence lemma; the matching-worlds technique is the isomorphism lemma, and a matching that carries the marks is an isomorphism. G ⊨ φ is logical consequence, and a world of G is a model of G.

Who said it first

Gottlob Frege wrote the first full language of every and some in his Begriffsschrift (1879). Charles Sanders Peirce and Ernst Schröder wrote quantifiers in algebra in the 1880s. Leopold Löwenheim worked with first-order formulas in 1915, and David Hilbert and Wilhelm Ackermann set first-order logic apart as a system in their book of 1928. Alfred Tarski defined truth in a formal language in a Polish monograph of 1933, translated into German in 1935; his definition by recursion, with one clause for each way of building, is the one on this page.

A proof that is not allowed

“0 is nobody’s next, by 4b. So ∃x₀ (S(x₀) = 0) is false.” Not allowed as it stands: 4b’s technique is about the numbers, so it shows that the statement is false in N. In the integers it is true. A statement is false in a world, never false with no world named.
