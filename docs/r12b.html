12b · proof

Bounded on a Closed Interval

A function continuous on a closed interval cannot run off without end: some real is at least as large as the size of every output. This step gives “bounded” its line, and shows that both words of the hypothesis are needed. Then it proves the technique by the least upper bound of the inputs up to which the function is bounded. Continuity is spent at exactly one input, the least upper bound itself. Then a bound you can compute by hand, for a polynomial, and a warning that the technique does not run backwards.

Gather the inputs up to which the function is bounded, and take their least upper bound. Continuity there, challenged with a gap of 1, carries a bound a little past it. Since nothing gathered is past the bound, the bound must be the right end.

12b1Bounded, Said Exactly

8c said what an upper bound of a set of reals is. A function's outputs on a set of inputs are a set of reals, and the words carry over.

From here on, take a function f whose outputs are reals, and a set A of its inputs. f is bounded above on A when some real K has f(x) ≤ K for every x ∈ A. f is bounded below on A when some real k has k ≤ f(x) for every x ∈ A. And f is bounded on A when some real K has |f(x)| ≤ K for every x ∈ A. Such a K, or k, is called a bound.

A reuse, said out loud: 8c said upper bound, bounded above and lower bound of a set of reals. Said of a function on A, the words mean the old words said of one particular set: f's values {f(x) : x ∈ A} (2i's shorthand). f is bounded above on A exactly when that set is bounded above in 8c's sense. So the old meaning still applies, to sets, and the new one comes to the same thing. 10f's “passes every bound” uses bound for any real, as here.

Bounded-both-ways technique: f is bounded on A exactly when it is bounded above on A and bounded below on A.

|f(x)| \le K \;\Rightarrow\; -K \le f(x) \le K @@ unpack-the-bars (8h): rightward, with K above and −K below
k \le f(x) \le K_1 @@ leftward: the two bounds, for every x ∈ A
f(x) \le K_1 \le |K_1| \le \htmlClass{new}{\max(|k|, |K_1|)} @@ sandwich's sandwich; 8b's max is at least each
-f(x) \le -k \le |k| \le \max(|k|, |K_1|) @@ negative-reverses-order turns k ≤ f(x) about; sandwich; max
|f(x)| \le \max(|k|, |K_1|) \quad \blacksquare @@ unpack-the-bars packs the two lines (|f(x)| is f(x) or −f(x), 8h)

So x² − 4x on [0, 5] is bounded. Completing the square (8i), x² − 4x = (x − 2)² − 4. For x ∈ [0, 5] the displacement x − 2 lies in [−2, 3], so (x − 2)² ≤ 9 (size-squared, powers-keep-order). So −4 ≤ x² − 4x ≤ 5. A bound is 5. 1/x on [1, ∞) is bounded too: 0 < 1/x ≤ 1 there (positive-reciprocal on ℚ read in ℝ).

12b2Both Words Are Needed

The technique of this step, in words: a function continuous on a closed interval is bounded there. Take away either word and it fails.

Take away “closed”. 1/x is continuous on (0, 1], which keeps its right end and not its left. It is not bounded there: by 10f, 1/x passes every bound as x → 0⁺, so for any K some input x ∈ (0, 1] has 1/x > K. The end that was left out is where it escapes. And x itself is continuous on [0, ∞), which is not a closed interval on this ladder, and passes every real (8e's counting-passes-any-real).

Take away “continuous”. Let f(x) = 1/x for 0 < x ≤ 1 and f(0) = 0 (7e's cases). Now every input of the closed interval [0, 1] has a value, and f still passes every bound near 0. It is not continuous from the right at 0: 11f's infinite discontinuity, at an input. A single discontinuity is enough.

And the technique does not run backwards. 11a's step u is bounded on [−1, 1] (its outputs are 0 and 1) and not continuous there. 11f's ⌊x⌋ is bounded on [0, 3] with three jumps. 9a's q is bounded everywhere and continuous nowhere. Bounded is cheap. What is not cheap is bounded because continuous.

12b3The Proof, Every Line Cited

Bounded-on-a-closed-interval technique: if f is continuous on [v, w], then f is bounded on [v, w]. The idea is to walk the bound along the interval. At v, the bound |f(v)| does for the inputs up to v. Continuity at any input carries a bound a little further. But “a little further, again and again” is not a proof: the steps might shrink and pile up short of w. So instead of walking, take the least upper bound of everywhere the walk could get to, and walk once from there.

B = \{x \in [v, w] : \exists K\ \forall t \in [v, w]\ (t \le x \Rightarrow |f(t)| \le K)\} @@ Separation (2e): the inputs up to which f is bounded. B ⊆ [v, w] by sift-is-part
v \in B @@ K = |f(v)|: the only t ∈ [v, w] with t ≤ v is v itself (at-most-is-a-partial-order on ℝ's antisymmetry, 8a)
\forall x \in B\ (x \le w) @@ w is an upper bound of B
\htmlClass{new}{\sigma = \sup B} @@ no-holes (8c): B has a member and an upper bound. The one no-holes line
v \le \sigma \le w @@ v ∈ B and σ an upper bound; σ least and w an upper bound
  
\text{call } \delta:\ t \in [v, w] \land |t - \sigma| \lt \delta \Rightarrow |f(t) - f(\sigma)| \lt \htmlClass{new}{1} @@ closed-interval-continuity (12a) at σ, challenged with ε = 1
\qquad \Rightarrow |f(t)| \lt |f(\sigma)| + 1 @@ triangle (8h): |f(t)| ≤ |f(t) − f(σ)| + |f(σ)|; order-and-arithmetic-agree
\text{call } x \in B \text{ with } \sigma - \delta \lt x \le \sigma @@ σ − δ is not an upper bound, since σ is the least: not-every bounded, negated-if forward, three-way-order on ℝ; σ is an upper bound
\text{call } K:\ \forall t \in [v, w]\ (t \le x \Rightarrow |f(t)| \le K) @@ ﹀ x ∈ B; use a some
x' = \min(\sigma + \tfrac{\delta}{2},\ w),\ \ \ K' = \htmlClass{new}{\max(K,\ |f(\sigma)| + 1)} @@ 8b's min and max: a little past σ, and a bound for both stretches
  
\text{let } t \in [v, w],\ t \le x' @@ to show |f(t)| ≤ K′
t \le x \;\lor\; x \lt t @@ three-way-order on ℝ
\text{case } t \le x:\ \ |f(t)| \le K \le K' @@ the bound up to x; 8b's max, by its two cases, is at least each
\text{case } x \lt t:\ \ \sigma - \delta \lt x \lt t \le x' \le \sigma + \tfrac{\delta}{2} @@ chain the order (at-most-is-a-partial-order on ℝ); lesser-below-both for x′
\qquad |t - \sigma| \lt \delta, \text{ so } |f(t)| \lt |f(\sigma)| + 1 \le K' @@ unpack-the-bars packs; the window's line; max
x' \in B @@ x′ ∈ [v, w] (σ ≤ x′ ≤ w, as min is one of the two), with the bound K′: ︿ the sift
  
x' \le \sigma @@ σ is an upper bound of B
\min(\sigma + \tfrac{\delta}{2},\ w) \ne \sigma + \tfrac{\delta}{2} @@ σ + δ/2 > σ ≥ x′: three-way-order on ℝ
x' = w @@ min is one of the two (8b's line by cases): the remaining-option technique
w \le \sigma \le w,\ \ \text{so } \htmlClass{new}{\sigma = w} @@ the two lines above; at-most-is-a-partial-order on ℝ's antisymmetry
w \in B @@ x′ = w and x′ ∈ B (the swap axiom)
\exists K\ \forall t \in [v, w]\ (|f(t)| \le K) \quad \blacksquare @@ ﹀ w ∈ B: every t ∈ [v, w] has t ≤ w

Notice what the proof did not need: a supposition. It never says “suppose f is not bounded”. It carries the bound past σ. It finds that the only way to be past σ and still at most σ is to have reached b, and so lands on b. No-holes was spent at one line, σ = sup B. Continuity was spent at one input, σ: the window of reach δ around σ, with gap 1. Rung 7's either-way principle was spent in the splits by three-way-order on ℝ and in not-every. The closed interval put its left end in B to begin with, and its right end in the interval to end with.

Notice too why the walk would not do. Start at the left end and carry the bound as far as continuity at your current input allows, halfway across the window, and repeat. Take a function with an infinite discontinuity at the right end, such as 1/(1 − x) on [0, 1) with the value 0 at 1. Each window is smaller than the last, and the walk piles up at 1 without arriving. The proof does not walk. It goes directly to σ, and at σ the window has a fixed reach δ, whatever happened before. For that function σ = 1, and at 1 there is no window at all. The one input where the proof spends continuity is the one input where continuity fails.

12b4A Bound by Hand, for a Polynomial

Bounded-on-a-closed-interval says a bound exists. It does not hand you one. For a polynomial, the triangle inequality does.

Polynomial-bound technique: for p(x) = Σ_{k≤n} u_k x^k and a closed interval [v, w], let R = max(|v|, |w|). Then |p(x)| ≤ Σ_{k≤n} |u_k| R^k for every x ∈ [v, w].

x \in [v, w] \;\Rightarrow\; |x| \le R @@ v ≤ x ≤ w: if x ≥ 0, |x| = x ≤ w ≤ |w|; if x < 0, |x| = −x ≤ −v ≤ |v| (negative-reverses-order, sandwich); max
|x^k| = |x|^k \le R^k @@ size-of-a-product by induction on k; powers-keep-order (8f) when |x| < R, the swap axiom when |x| = R; power-zero when k = 0
\Big|\sum_{k\le n} u_k x^k\Big| \le \sum_{k\le n} |u_k x^k| @@ triangle, by induction on n with sum-one-more (9g's Σ with real terms)
\le \sum_{k\le n} |u_k|\,\htmlClass{new}{R^k} \quad \blacksquare @@ size-of-a-product; keep-order for times on ℚ read in ℝ, term by term (same-direction-add for the sum)
  
p(x) = x^3 - 3x + 1 \text{ on } [-2, 2]:\ \ R = 2 @@ R = max(|−2|, |2|)
|p(x)| \le 2^3 + 3 \cdot 2 + 1 = \htmlClass{new}{15} @@ polynomial-bound. The values actually stay between −1 and 3 (12c finds them)
q(x) = 2x^3 - x + 5 \text{ on } [-1, 3]:\ \ R = 3 @@ R = max(1, 3)
|q(x)| \le 2 \cdot 27 + 3 + 5 = 62 @@ polynomial-bound. The values actually stay between 4 and 56

Polynomial-bound's bound is honest and usually generous: it lets every term take its largest size at once, with all signs agreeing, which rarely happens. Generous is fine. A bound only has to be above; 12c asks for the least one.

12b6Running It Backwards

Handed a function said to be bounded on a closed interval, look for one of three things. Continuity on the whole interval: then bounded-on-a-closed-interval. A formula you can bound by hand: polynomial-bound, or completing the square. Or a discontinuity where it escapes: then it may not be bounded. Handed a function that runs off without end on an interval, ask which word is missing: an end left out, or a discontinuity. Found upward; written downward.

Who said it first

Weierstrass, lecturing in Berlin, taught that a function continuous on a closed interval is bounded there and reaches its highest and lowest values. His students wrote it down from the lectures; much of it he never published himself.

Weierstrass, Berlin lectures on the theory of functions (1861 onward), as recorded by his students; paraphrase

Question 12b.4.4’s covering argument is the Heine–Borel theorem. Eduard Heine never stated it; Émile Borel proved a version in 1895; Pierre Cousin had another the same year; Henri Lebesgue sharpened it.

Accepted names: bounded-on-a-closed-interval is the boundedness theorem, and is often stated as the first half of the extreme value theorem.
