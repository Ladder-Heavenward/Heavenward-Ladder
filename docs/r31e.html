31e · proof

Quadratic Forms

A two-slot reading fed the same vector twice gives a number that grows like a square: two times one place squared, plus the two places multiplied, plus another square. Such readings measure the energy of a stretched frame, the bend of a surface at a flat point, and the spread of a cloud of data in each direction. Read along the axes of the last step, every one of them is a plain sum of squares, each with its own stretch in front. Some of those stretches are above zero, some below and some exactly zero. A change of measuring directions can change the numbers, but it can never change how many are positive, how many negative and how many zero. That count decides everything: whether the reading is above zero for every vector but zero, whether a surface has a bottom, a top or a saddle. Rung twenty eight’s test for flat points used a determinant without saying why. Here is why.

A quadratic form is xᵀAx with A symmetric. Along A’s axes it is a sum of the stretches times squares. No change of measuring directions changes how many of those numbers are positive, negative or zero. A form is positive for every vector but zero exactly when every stretch is above zero, and 28l’s test for flat points is this count for the grid of second slopes.

31e1A Sum of Squares, Along the Axes

From here on, a quadratic form on lists of n real numbers is q(x) = xᵀAx, with A a symmetric grid: 27h2’s two-slot reading B(x, y) = xᵀAy, fed x in both slots. Any grid G gives the same q as the symmetric ½(G + Gᵀ), so nothing is lost by asking for A symmetric. Its academy name, quadratic, from the Latin quadratus, squared, is the one this lesson picks up.

Axes-form technique: if A = QDQᵀ as in 31d3 and y = Qᵀx, then q(x) = λ₁y₁² + ⋯ + λₙyₙ²: read along A’s axes, a quadratic form is a sum of squares with the stretches in front.

31e2The Signs Cannot Be Changed

Sign-count technique: however q is written as c₁z₁² + ⋯ + cₙzₙ² with z = Tx and T undoable, the number of cₖ above 0, the number below 0, and the number equal to 0 are always the same.

q = \textstyle\sum c_kz_k^2 = \sum d_kw_k^2,\ \ z = Tx,\ w = T'x @@ two such ways, T and T′ undoable
p = \#\{c_k > 0\},\ \ p' = \#\{d_k > 0\},\ \text{suppose } p > p' @@ to be refuted
U = \{x : z_k = 0 \text{ unless } c_k > 0\},\ \ \dim U = p @@ the vectors where q uses only its positive part; T is undoable
U' = \{x : w_k = 0 \text{ when } d_k > 0\},\ \ \dim U' = n - p' @@ lost plus reached (27c2): p′ samenesses, free
\dim U + \dim U' > n \Rightarrow \text{some } x \ne 0 \text{ in both} @@ a free list from each would be too long for the space (27b2)
q(x) > 0 \text{ and } q(x) \le 0 @@ in U, q is a sum of positive multiples of squares, not all 0; in U′ every term is at most 0
\htmlClass{new}{p = p'} \quad \blacksquare @@ ⊥; and p′ > p is refuted the same way. The zero count is n minus the rank of A, which T does not change

31e3Positive for Every Vector

From here on, q is positive definite when q(x) > 0 for every x ≠ 0. The dot’s form x₁² + ⋯ + xₙ² is one, and so is every product’s ⟨x, x⟩ on lists: a product is a positive definite form with its two-slot reading kept.

Form-test technique: q is positive definite exactly when every stretch of A is above 0. For n = 2, with A having rows (p, s) and (s, r), that is exactly when p > 0 and pr − s² > 0.

q(x) = \textstyle\sum \lambda_ky_k^2,\ \ x \ne 0 \iff y \ne 0 @@ the axes-form technique; Q is undoable
\text{all } \lambda_k > 0 \Rightarrow q(x) > 0;\ \ \lambda_j \le 0 \Rightarrow q(Qe_j) = \lambda_j \le 0 @@ both ways
p x_1^2 + 2s\,x_1x_2 + r x_2^2 = p\big(x_1 + \tfrac{s}{p}x_2\big)^2 + \tfrac{pr - s^2}{p}\,x_2^2 @@ completing the square (8i), for p ≠ 0
\htmlClass{new}{q \text{ positive definite} \iff p > 0,\ pr - s^2 > 0} \quad \blacksquare @@ the sign-count technique: two positive numbers in front, in this way as in every way; p = 0 gives q(e₁) = 0

31e4The Test for Flat Points, Explained

Hug-axes technique: at a flat point with continuous second slopes, if every stretch of H is above 0 the point is a bottom, if every one is below 0 a top, and if H has stretches of both signs a saddle; in two variables this is 28l2’s grid test.

\tfrac12 h^{\mathsf T}Hh \ge \tfrac12\lambda_{\min}|h|^2 @@ the axes-form technique: Σλₖyₖ² ≥ λmin Σyₖ², and |y| = |h| since Q keeps lengths (27m1)
f(p + h) - f(p) \ge |h|^2\big(\tfrac12\lambda_{\min} - |E(h)|/|h|^2\big) > 0 @@ all λ > 0, for |h| small enough (28l1)
H e_j = \lambda_je_j,\ \lambda_j < 0 \Rightarrow f(p + te_j) - f(p) = \tfrac12\lambda_jt^2 + E(te_j) < 0 @@ for t small: down along that axis
\htmlClass{new}{\text{both signs} \Rightarrow \text{up along one axis, down along another}} \quad \blacksquare @@ a saddle; in two variables, D = λ₁λ₂ and A > 0 picks both positive (31e3)
  
f(x, y) = x^2 + 3xy + y^2,\ \ H = \begin{pmatrix} 2 & 3 \\ 3 & 2\end{pmatrix} @@ flat at (0, 0)
\lambda = 5 \text{ along } (1, 1),\ \ \lambda = -1 \text{ along } (1, -1) @@ the stretch-test technique (27f1)
\htmlClass{new}{f(t, t) = 5t^2,\ \ f(t, -t) = -t^2} \quad \blacksquare @@ up along one axis, down along the other: D = −5 < 0

31e5Corner Determinants, for Any Size

For two inputs the form test read p > 0 and pr − s² > 0 (31e3): two determinants, of the top-left corner of size 1 and of the whole grid. For a symmetric grid A of n rows, write Dₖ for the determinant of its top-left corner of k rows and k columns.

Corner-determinants technique: a real symmetric A is positive definite exactly when D₁ > 0, D₂ > 0, …, Dₙ > 0.

q \text{ positive definite} \Rightarrow \text{so is } q \text{ on the first } k \text{ places} @@ feed q the lists whose last n − k places are 0: that is the form of the corner
D_k = \text{the product of the corner's stretches} \gt 0 @@ each is above 0 (31e3); the determinant is their product, by A = QDQᵀ and det-product (31d3, 27e)
\text{now let every } D_k \gt 0;\ \text{the corner of } n - 1 \text{ rows is positive definite} @@ induction on n (4c)
D_n \gt 0:\ \text{evenly many stretches are below } 0 @@ the stretches of A: their product is above 0
\text{if two are: } u, v \text{ at right angles},\ w = au + bv \text{ with last place } 0 @@ one condition on two numbers a, b leaves a w ≠ 0
q(w) = a^2\lambda + b^2\mu \lt 0,\ \text{yet } q(w) \gt 0 \text{ by the corner} @@ along the axes (31e1); w lives in the first n − 1 places
\begin{aligned}&\htmlClass{new}{\text{no stretch is below } 0 \text{ or } 0:}\\ &\quad \htmlClass{new}{A \text{ is positive definite}} \quad \blacksquare\end{aligned} @@ Dₙ ≠ 0; then the form test (31e3)

Try rows (2, −1, 0), (−1, 2, −1), (0, −1, 2). The corners give 2, 3 and 4: positive definite, and no stretch was found. The test costs one run of row moves, which finds every Dₖ on the way (27k).

Only top-left corners with the sign > count. Rows (0, 0) and (0, −1) have D₁ = 0 and D₂ = 0, and the form is −y²: asking Dₖ ≥ 0 proves nothing.

31e6A Positive Grid Is P on Its Side Times P

A positive number is a square, and of a number that is not 0. Positive definite grids are squares in the same way, with one factor laid on its side.

Side-square technique: a real symmetric A is positive definite exactly when A = PᵀP for some square P that can be undone. P can be taken to be a staircase with numbers above 0 down its middle, and there is only one such staircase.

x^{\mathsf T}P^{\mathsf T}Px = |Px|^2 \gt 0 \text{ for } x \ne 0 @@ P can be undone, so Px ≠ 0: PᵀP is positive definite
A = QDQ^{\mathsf T},\ \ P = \sqrt{D}\,Q^{\mathsf T} @@ the other way: the stretches in D are above 0 (31d3, 31e3), so take their roots
P^{\mathsf T}P = Q\sqrt{D}\sqrt{D}\,Q^{\mathsf T} = A @@ a diagonal grid is its own flip
P = WR \Rightarrow A = R^{\mathsf T}W^{\mathsf T}WR = R^{\mathsf T}R @@ column-straightening (31c2): W has right-angled columns, R is a staircase with numbers above 0 down its middle
\htmlClass{new}{A = P^{\mathsf T}P = R^{\mathsf T}R} \quad \blacksquare @@ and RᵀR = SᵀS makes SR⁻¹ a staircase and a length-keeper at once: the identity

For rows (4, 2) and (2, 5), the staircase R has rows (2, 1) and (0, 2): RᵀR has rows (4, 2) and (2, 1 + 4). It is found a row at a time, with one square root for each row.

This is the product-grid technique (31a6) read backwards. A positive definite grid is the grid of a product, and P is a change of basis that makes the product the plain dot: ⟨x, y⟩ = (Py)ᵀ(Px). Every product on lists is the dot, seen through some P.

31e7The One Root of a Positive Map

A number that is not below 0 has exactly one root that is not below 0. Call a symmetric map never-negative when ⟨Af, f⟩ ≥ 0 for every f: all its stretches are at least 0 (31f names AᵀA as one; here they are met on their own).

One-square-root technique: a never-negative symmetric map A has exactly one never-negative symmetric S with S² = A. Write it √A.

A = QDQ^{\mathsf T},\ \ S = Q\sqrt{D}\,Q^{\mathsf T}:\ \ S^2 = A @@ QᵀQ = I (31d3); the roots of the stretches are real, since none is below 0
\text{let } T \text{ be another: } T^2 = A,\ Tv = tv,\ t \ge 0 @@ T has a right-angled basis of such v (31d3)
Av = T(Tv) = t^2v @@ so v lies in the space that A stretches by λ = t², and t = √λ
\text{on that space } T \text{ is } \sqrt{\lambda} \text{ times the identity} @@ the stretched vectors of T that lie in it build it; T is √λ on each
\htmlClass{new}{T = S} \quad \blacksquare @@ S is √λ times the identity on the same space, for every λ

Without "never-negative" there are many roots. The identity of the plane has the roots I and −I, every mirror, and the half turn. With it there is one, as for numbers.

√A swaps with everything A swaps with: it is A’s own axes with new stretches. For rows (2, 1) and (1, 2), the stretches are 1 and 3 along (1, −1) and (1, 1), and √A has rows ½(√3 + 1, √3 − 1) and ½(√3 − 1, √3 + 1).

31e8A Stretch, Then a Turn

Every turning number but 0 is a size times a number of size 1, z = eiθ · r, in one way only (26a). Grids split the same way.

Stretch-then-turn technique: every real square grid A that can be undone is A = UP, with P positive definite and symmetric and U a length-keeper, in one way only: P = √(AᵀA) and U = AP⁻¹.

A^{\mathsf T}A \text{ is symmetric and positive definite} @@ xᵀAᵀAx = |Ax|² > 0 for x ≠ 0 (31f1 will meet it again)
P = \sqrt{A^{\mathsf T}A},\ \ U = AP^{-1} @@ the one-square-root technique (31e7); P can be undone, since its stretches are above 0
U^{\mathsf T}U = P^{-1}A^{\mathsf T}A\,P^{-1} = P^{-1}P^2P^{-1} = I @@ P is symmetric, and so is P⁻¹: U is a length-keeper (27m)
A = U'P' \Rightarrow A^{\mathsf T}A = P'U'^{\mathsf T}U'P' = P'^2 @@ any other such pair
\htmlClass{new}{P' = \sqrt{A^{\mathsf T}A} = P,\ \ U' = U} \quad \blacksquare @@ only one root (31e7)

Read A = UP from the right, as maps are. First P stretches space along right-angled axes, by factors above 0. Then U turns it, or mirrors it, with no change of shape. Every undoable straight map is those two moves. A square of clay pushed through A is first squeezed along P’s axes and then carried round.

For rows (0, −2) and (1, 0): AᵀA has rows (1, 0) and (0, 4), so P has rows (1, 0) and (0, 2), and U = AP⁻¹ has rows (0, −1) and (1, 0), the quarter turn. Stretch the second place by 2, then turn. The determinant splits as well: det A = det U · det P, a sign times a size.

31e9An Order on Symmetric Maps

Numbers compare. Do maps? For symmetric maps A and B on one product space, write A ≤ B when B − A is never-negative (31e7): ⟨Af, f⟩ ≤ ⟨Bf, f⟩ for every f.

Map-order technique: A ≤ A; A ≤ B and B ≤ C give A ≤ C; A ≤ B and B ≤ A give A = B; A ≤ B gives CᵀAC ≤ CᵀBC for every grid C; and if A is positive definite and A ≤ B, then B⁻¹ ≤ A⁻¹.

\langle (C - A)f, f\rangle = \langle (C - B)f, f\rangle + \langle (B - A)f, f\rangle \ge 0 @@ so ≤ chains
A \le B \le A \Rightarrow \langle (B - A)f, f\rangle = 0 \text{ for all } f @@ B − A is symmetric with every stretch 0, so it is 0 (31d3)
x^{\mathsf T}C^{\mathsf T}(B - A)\,Cx = (Cx)^{\mathsf T}(B - A)(Cx) \ge 0 @@ so CᵀAC ≤ CᵀBC
I \le M \text{ for } M = RBR,\ \ R = (\sqrt{A})^{-1} @@ the line above with C = R, since RAR = I (31e7)
M^{-1} \le I @@ every stretch of M is at least 1, so every stretch of M⁻¹ is at most 1
\htmlClass{new}{B^{-1} = R\,M^{-1}R \le R\,I\,R = A^{-1}} \quad \blacksquare @@ the third line again, with C = R

Two things the order of numbers has, this one lacks. Not every pair compares: the grids with rows (1, 0), (0, 0) and (0, 0), (0, 1) differ by a grid with stretches 1 and −1, so neither is ≤ the other. And squaring does not keep it. Let A have rows (1, 1), (1, 1) and B have rows (2, 1), (1, 1). Then B − A has rows (1, 0), (0, 0), never-negative, so A ≤ B. But B² − A² has rows (3, 1), (1, 0), with determinant −1: one stretch is below 0.

So A ≤ B says B is at least as large along every direction at once, which is more than any one number can say.

The accepted names

A quadratic form is xᵀAx; the axes-form technique is its diagonalization by the principal axis theorem. The sign-count technique is Sylvester’s law of inertia, here an accepted name for a proved result, not a measured one, and the three counts are its inertia; the positive count minus the negative count is the signature. Positive definite, negative definite, indefinite and semidefinite name the sign patterns. The test with p > 0 and pr − s² > 0, carried to n variables with the corner determinants, is Sylvester’s criterion. H is the Hessian matrix, and the hug-axes technique is the second-derivative test in n variables. The corner determinants are the leading principal minors; the corner-determinants technique is Sylvester’s criterion. A = RᵀR with R a staircase is the Cholesky factorization. Never-negative symmetric maps are positive semidefinite; √A is the positive square root. A = UP is the polar decomposition. This is the Loewner order.

Who said it first

Carl Friedrich Gauss studied forms in two variables with whole-number coefficients in 1801. James Joseph Sylvester stated the law of inertia in 1852, and Carl Jacobi had proved it earlier without publishing; Sylvester also coined the word “matrix” in 1850. Joseph-Louis Lagrange gave the test for a bottom of a function of two variables in the 1760s, and Otto Hesse’s name went on the grid of second slopes in the 1840s.

A proof that is not allowed

“Along the x-axis f = x² rises and along the y-axis f = y² rises, so f = x² + 3xy + y² has a bottom at 0.” Not allowed: rising along two directions says nothing about the others. Along (1, −1) it falls, as its stretch −1 shows.
