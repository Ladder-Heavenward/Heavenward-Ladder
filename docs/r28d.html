28d · proof

Does the Order of the Knobs Matter?

A partial slope is a function too, so it has partial slopes of its own. Take the slope along x, then take the slope of that along y. Or go the other way: along y first, then along x. On a smooth hillside it seems the order should not matter. This step proves that it does not matter when the second slopes change continuously. Then it finds a function where the two orders give different numbers, so the condition is not there for show.

If both mixed second partial slopes are continuous at a point, they are equal there. Without that, they can differ.

28d1Second Slopes, in Two Orders

Write fxy for the slope along y of fx: first the x knob, then the y knob. Write fyx for the other order. These are the mixed second partial slopes. For f(x, y) = x³y² + sin(xy):

f_x = 3x^2y^2 + y\cos(xy),\ \ f_y = 2x^3y + x\cos(xy) @@ the one-knob technique (28a2), the trig-chain technique (21l)
f_{xy} = 6x^2y + \cos(xy) - xy\sin(xy) @@ the slope of f_x along y: product technique (13c)
f_{yx} = 6x^2y + \cos(xy) - xy\sin(xy) @@ the slope of f_y along x: the same techniques
\htmlClass{new}{f_{xy} = f_{yx} \text{ here}} \quad \blacksquare @@ the two lines above

The agreement looks like luck. The next footing shows it is not.

28d2The Order Does Not Matter

Swap-knobs technique: if fx, fy and fxy, fyx exist near (a, b), and fxy and fyx are continuous at (a, b), then fxy(a, b) = fyx(a, b).

The proof looks at one number, the corner sum of a small rectangle, and reads it two ways.

\(\Delta = f(a+h, b+k) - f(a+h, b) - f(a, b+k) + f(a, b)\)

u(x) = f(x, b+k) - f(x, b),\ \ \Delta = u(a+h) - u(a) @@ group by the first input
\Delta = u'(a+sh)\,h = [f_x(a+sh, b+k) - f_x(a+sh, b)]\,h @@ the average-slope technique (14c), 0 < s < 1
\Delta = f_{xy}(a+sh,\, b+tk)\,hk @@ 14c again, along y for f_x, 0 < t < 1
\Delta = f_{yx}(a+s'h,\, b+t'k)\,hk @@ the same two lines, grouping by the second input first
f_{xy}(a+sh, b+tk) = f_{yx}(a+s'h, b+t'k) \ \ (hk \ne 0) @@ divide both by hk
\htmlClass{new}{f_{xy}(a,b) = f_{yx}(a,b)} \quad \blacksquare @@ let h, k → 0: both points head to (a, b), and both are continuous there (28a1)

So for a smoothly sloped function whose second slopes are smooth too, the order of the knobs never matters, and with n inputs the same holds for every pair.

28d3When the Order Matters

Order-matters technique: there is a function whose mixed second slopes at a point exist and differ.

f(x,y) = \frac{xy(x^2 - y^2)}{x^2 + y^2},\ \ f(0,0) = 0 @@ the example
f_x(0, y) = \lim_{h\to0}\frac{f(h,y) - f(0,y)}{h} = \lim_{h\to 0} \frac{y(h^2 - y^2)}{h^2 + y^2} = -y @@ 28a2; f(0, y) = 0
f_y(x, 0) = \lim_{k\to0}\frac{f(x,k) - f(x,0)}{k} = \lim_{k\to 0} \frac{x(x^2 - k^2)}{x^2 + k^2} = x @@ the same, along y
f_{xy}(0,0) = \tfrac{d}{dy}(-y) = -1,\ \ f_{yx}(0,0) = \tfrac{d}{dx}(x) = 1 @@ the slope-of-a-line technique (13a)
\htmlClass{new}{f_{xy}(0,0) \ne f_{yx}(0,0)} \quad \blacksquare @@ −1 ≠ 1

The swap-knobs technique is not broken: here the mixed slopes are not continuous at (0, 0). The demand did real work.

The accepted names

The swap-knobs technique is the symmetry of second derivatives, called Schwarz’s theorem or Clairaut’s theorem. fxy is also written ∂²f/∂y∂x; books disagree about which order that notation means, so the ladder writes the order out in words when it matters.

Who said it first

Euler claimed the symmetry in 1734, and Alexis Clairaut used it in 1740, both without a full proof. Hermann Amandus Schwarz gave a correct proof in 1873. The counterexample above was published by Giuseppe Peano in 1884, after several faulty proofs had appeared in textbooks.

In 28d.4.5, the mathematician of 1734 is Euler. The careful proof of 1873 is Hermann Amandus Schwarz’s. The young editor is Giuseppe Peano, whose notes to Angelo Genocchi’s calculus of 1884 also carry the catch of 14c.4.5.
