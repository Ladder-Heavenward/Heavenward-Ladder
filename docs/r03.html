Rung 3 · theory

Learning to keep going

Rung 2 ended with a run of sets built from nothing: the empty set, then the set whose only member is the empty set, then the set holding both of those. Each was made from the one before by the same gesture, and the gesture can always be made again. This rung is about that run. It gives the gesture a name and a mark, and it gives the earliest sets of the run names of their own. Then it asks the question the run forces. The gesture never stops; so can everything it ever produces be gathered into a set, a thing you can have and reason about as a whole? No tool of rung 2 can do it. The ladder lays down an axiom instead: there is such a set. And the last page of the rung explains the surprise: the axiom is a genuine choice. There is a world in which every principle of rungs 0 to 2 is true and no such set exists.

You already sense a run like this. Every day follows the one before, and you never expect to reach the last one. A world that goes on past any day you can name is the world you live in. This rung is just the way mathematics writes that sense down, so it can be reasoned about.

The rung has two goals. The first is the gesture that makes the next set, done again and again. The rung learns enough about it to see each set in the run as the set of the ones before it, and that is where counting will come from. The second is to accept the whole run as one set. Nothing earlier can build it, so the rung asks for it outright, and 3c shows that the asking is a choice.

Take a set, and merge it with the set whose only member is that set: the result is the next one. The next one always exists and is always new, so the run never ends. To speak of the whole run at once you must ask for a set that holds the start and never runs out of next ones. Every set you can write out runs out at the member built last.

Still in midair

The proof is still held in trust on this rung. Its statements can be collected and paired now, but its lines cannot yet be counted, and nothing can yet be said about every proof at once. That needs the counting numbers and induction, which rung 4 builds. So we argue in plain words, and some questions ask for an argument before every piece of it is built.

A run that never stops

2g closed by writing, in braces, the sets that can be made from the empty set alone:

Each was made from the one before by one move: gather the set alone, and merge the set with that gathering, so that the result has every member the old set had and the old set itself besides (3a1). Do it to ∅, and then do it to what you get:

Do it again, and again: 3a1 calls that iterating the move. Every tool used is one of rung 2's, gather and merge, so each step is licensed, and nothing ever stops you taking the next step.

Nothing stops you, and nothing ever lands you where you have been. The result always has the old set as a member and is never the old set again, nor the empty set; 3a9 proves both. The run, read from its start, goes on without end, each entry made from the entry before by a rule you could hand to anyone.

3a gives the gesture its mark, and says exactly which set it makes and who that set's members are. It proves what was just said: the result holds the old set, it is never the old set, and it is never empty. Then it does something the ladder has been waiting for since the ground floor. It gives the earliest entries of the run names. They are the names everyone writes, and the words everyone says for them. What 3a adds is that on this ladder each of them is a name of a particular set. Each is brought in by a line of the usual shape, “from here on, this mark names this set”. 1f met the same marks as an early algebra of logic used them, as marks fixed by tables; 3a is where they become names of things. Once named, the entries show a pattern that will carry the whole of rung 4: each entry of the run is the set of all the entries before it.

Why not just keep going?

Because mathematics wants to say things about all of them. Not “this entry, and the next, and the next”, which is a way of speaking about each entry in its turn. Rather “every entry of the run has such and such a property”, and “there is an entry of the run with such and such a property”. Rung 1 gave the ladder the words for that: every and some, with their techs. But the techs of every and some speak about the members of a set. To say “every entry of the run” and have it mean something a proof can use, the entries of the run must be the members of a set. Not a heap of sets: a set, one object, that has each of them in it.

Rung 2's tools cannot build it. Each tool takes sets you have and hands back a set, so whatever you make and then stop at is a set you could write out in braces. Any such set has a member made last, and the next entry after that one is missing from it: 3b1 proves it. It runs out.

3b turns that into a definition. Call a set inductive when it holds the start of the run and, whenever it holds a set, it also holds that set's next one. An inductive set never runs out. What was just said is that no set you can write out is inductive. The whole run, taken as one object, would be inductive. So the question “can the whole run be a set?” is the question “is there an inductive set?”, and the answer cannot come from the tools.

The axiom

So the ladder asks for it outright. The axiom of infinity says: some set is inductive. Like the axiom of rung 2 that said “there is a set”, it does not build and it does not say which; it asserts. 3b lays it down and draws at once what follows from it. Whatever entry of the run you name, that entry is in every inductive set, so an inductive set holds the whole run. It may hold other things too. The axiom says there is a set that never runs out of next ones, not a set that holds only the run. An inductive set may carry cargo. Rung 4's first job is to sift the cargo away and keep exactly what every inductive set has in common.

This is the only place on the ladder where an endless collection is asked for. Everything endless that comes later, the counting numbers as a set, the fractions as a set, the points of a line, is made from this set with rung 2's tools. The axiom is a small line, and a great deal stands on it. The accepted word for endless is infinite, from the Latin infinitus, “without end”.

One founder of the subject tried to prove that an endless collection exists, from the realm of his own thoughts. The argument is lovely, and it is the move 2b forbids, as 3b9 tells. The author of the first list of axioms for sets listed infinity as an axiom instead. This ladder does the same, and 3b says in plain words why the honest course is to ask rather than to pretend to prove.

Chosen, not discovered

“The tools cannot build it” is a strong claim. It means that no proof from the earlier principles can exist. It is settled by the world-building move of 2f13, which showed that foundation does not follow from the other axioms. 3c runs the same argument for infinity.

The world is built in layers: the bottom layer is empty, and each layer above is all the subsets of the layer below (3c3). Every principle of rungs 0 to 2 is true inside it, and no set in it is inductive, since an inductive set would hold the whole run, and the run steps down a layer at each membership until the layers run out. A world where everything earlier is true and the axiom is false: so the axiom is not a technique of what came before. You may take it or leave it, and mathematics has done both.

The oldest view on record was that the infinite exists only in the manner of a process that can always be continued, never as a finished whole that is all present at once. A quantity can be exceeded without end, it said, but there is no completed endless thing.

For most of the history of the subject that was the settled view. The axiom of infinity is the point at which the ladder, with most of modern mathematics, departs from it. Leave the axiom out and you keep every entry of the run, each in its turn, with every rule for making the next. You lose only the right to treat the run as a thing. Take it, and the run is a set like any other, which you can sift, pair, take the subsets of, and quantify over. The ladder takes it, and says so as a decision rather than a discovery.

The same founder also said, in the same preface, that numbers are free creations of the human mind. They serve as a means of grasping the differences among things more easily and sharply.

What you can do because you know this

At the end of the rung you can name the gesture and run it, forwards and backwards, on any set. You can name the earliest entries of the run and write each one out in braces, and you know that each is the set of the entries before it. You can say exactly what “never runs out” means as a condition on a set, test a set against it, and show by a witness when a set fails it. You have an axiom that rung 2 did not. You know what it asserts, what it does not assert, and why it has to be an axiom rather than a technique. Above all you can now speak of the whole endless run at once as the members of a set. That is what rung 4 needs in order to prove that the counting numbers are an object, that induction works, and that the ladder's earliest sum comes out as it should.

That is one endless set, and the first. There are more kinds of endless than anyone has finished counting, and you are just getting started.

Who said it first

The founder who asked what numbers are and what they are for is Richard Dedekind. The author of the first list of axioms for sets, who listed infinity as an axiom, is Ernst Zermelo (1908). The oldest view of the infinite as a process is Aristotle’s. The early algebra of logic whose marks 1f used is George Boole’s.

Richard Dedekind, in the little book in which he asked what numbers are and what they are for, wrote in its preface that in a science nothing that is capable of proof ought to be accepted without proof; and he wanted the existence of an endless collection proved rather than assumed. His attempted proof took as a set the whole realm of his own possible thoughts, and argued that each thought gives rise to a further thought about it, without end.

Dedekind, Was sind und was sollen die Zahlen? (1888), preface and §66, in W. W. Beman's translation, Essays on the Theory of Numbers, 1901

Aristotle taught that the infinite exists only in the manner of a process that can always be continued, never as a finished whole that is all present at once; a quantity can be exceeded without end, he said, but there is no completed endless thing.

Aristotle, Physics III.6–7

Dedekind also said, in the same preface, that numbers are free creations of the human mind, serving as a means of grasping the differences among things more easily and sharply.

Dedekind, Was sind und was sollen die Zahlen? (1888), preface, trans. Beman, 1901

Accepted names

An endless collection is called infinite. The infinite as a process that can always be continued is called the potential infinite; the endless thing taken as a whole, the actual infinite.
