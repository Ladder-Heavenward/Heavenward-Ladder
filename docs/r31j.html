31j · proof

Readings That Reach the Whole Space

In a complete product space every bounded reading is a product with one vector (31i). Most spaces with a size have no product: the highest height on continuous functions comes from none (31g). Do they still have enough readings to tell their vectors apart? They do. A reading known on a small space can be stretched to the whole space without growing its size, one new direction at a time. This step stretches a reading by one direction, then to everything, and reads the size of every vector off a reading.

If φ is straight on a space M inside X and φ ≤ p there, with p a size, then φ stretches to a straight Φ on all of X with Φ ≤ p. One new direction z needs one number c = Φ(z), squeezed between two bounds that never cross. Then each f ≠ 0 has a reading of size 1 with Φ(f) = ‖f‖.

31j1One New Direction

\Phi(m + tz) = \varphi(m) + tc @@ only c = Φ(z) is free
\text{need } \varphi(m) - p(m - z) \le c \le p(m^{\prime} + z) - \varphi(m^{\prime}) @@ for all m, m′ in M; t = ±1, then stretch
\varphi(m) + \varphi(m^{\prime}) = \varphi(m + m^{\prime}) \le p(m - z) + p(m^{\prime} + z) @@ straight, then the triangle
\htmlClass{new}{\text{every left bound} \le \text{every right bound: a } c \text{ fits}} @@ the highest of the left, by 8c

One-step technique: if φ ≤ p on M and z is outside M, there is a number c so that φ(m) + tc ≤ p(m + tz) for all m in M and all t; the bounds on c come in two families, and each of the first is below each of the second.

31j2Every Direction

\text{finitely many new directions: one step each} @@ enough in dimension n
\text{endlessly many: take the largest stretch, by choice} @@ as the sets of 30a were chosen
\text{a largest stretch that missed some } z \text{ could take one more step} @@ so it misses none
\htmlClass{new}{\Phi \le p \text{ on all of } X,\ \ \Phi = \varphi \text{ on } M} @@ nothing grew

Stretch technique: every straight reading on M bounded by a size p stretches to a straight reading on the whole space, still bounded by p. With p = C‖ · ‖, a bounded reading stretches with the same bound.

31j3Enough Readings

M = \{tf\},\ \varphi(tf) = t\|f\| @@ a reading on one line
\Phi(g) \le \|g\| \text{ for all } g,\ \ \Phi(f) = \|f\| @@ stretch it
\|f\| = \max \{\Phi(f) : \|\Phi\| \le 1\} @@ the size is a highest reading
\htmlClass{new}{\text{on bounded lists: a reading that gives every settling list its limit}} @@ a limit for lists that do not settle

Every space with a size has enough bounded readings to tell any two vectors apart, and the size of each vector is its highest reading of size 1. On bounded lists, the reading that stretches “the limit” gives every bounded list a kind of average, though no one can write one down.

31j4Moves to Watch Out For

Each line below is a move that looks right and is not. The tag says what kind of mistake it is; the words say which footing catches it.

\text{the stretch is unique}\,? @@ <span class="vd vd-c">outside the collect</span> many c can fit; the stretch is seldom unique (31j1)
\varphi(m) - p(m + z) \le c\,? @@ <span class="vd vd-a">out of arrangement</span> the left bound uses p(m − z): take t = −1 (31j1)
\text{stretching may grow the bound}\,? @@ <span class="vd vd-l">legal, with a cost</span> Φ ≤ p everywhere, the same p (31j2)
\text{endlessly many directions need no choice}\,? @@ <span class="vd vd-s">out of sequence</span> the largest stretch is taken by choice (31j2)
\text{every reading is a product with a vector}\,? @@ <span class="vd vd-p">outside the plan</span> only in a complete product space (31i); here the size comes from no product (31j3)

Accepted names

This is the Hahn-Banach theorem; p is a sublinear functional or seminorm, the bounded readings form the dual space X*. The largest stretch is taken by Zorn’s lemma; the reading on bounded lists is a Banach limit.

Who said it first

Hans Hahn (1927) and Stefan Banach (1929) proved the stretch, Banach in his Théorie des opérations linéaires of 1932 with the limits named after him.
