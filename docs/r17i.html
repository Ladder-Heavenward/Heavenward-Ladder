17i · technique

Slopes of e and ln

Two new entries in the table, the exponential and the logarithm, multiply what rung 13’s rules and rung 16’s techniques can reach. The chain rule now takes the exponential and the logarithm of anything. Taking the logarithm first turns a product of many factors into a sum, and a power with the input in its exponent into something the rules can touch. Every quotient whose top is the slope of its bottom has a log for its antiderivative. And parts, with the logarithm or the exponential as one factor, finishes what 16e began.

The exponential of a function has slope the function’s slope times itself. The logarithm of a function has slope the function’s slope over the function. For a positive function, its slope is itself times the slope of its logarithm. The area under a function’s slope over the function is the logarithm of its size, plus a constant. Parts undoes the logarithm, and the input times the exponential. Any power falls behind any number above one raised to the input.

17i1Taking ln First

Log-slope technique: if f > 0 and f has a slope at x, then (ln f)′ = f′/f, so f′ = f · (ln f)′. If f ≠ 0, (ln|f|)′ = f′/f. It is chain for slopes with slope-of-log, or area-under-1/x for |f|. Its accepted name is logarithmic differentiation.

f(x) = x^x = e^{x\ln x},\ \ x \gt 0 @@ ﹀ pˣ (17g); neither real-power for slopes nor slope-of-pˣ applies
\ln f = x\ln x @@ real-exponent
\tfrac{f'}{f} = \ln x + x\cdot\tfrac1x = \ln x + 1 @@ log-slope on the left; product for slopes on the right
f'(x) = x^x(\ln x + 1) @@ multiply by f
f' = 0 \iff \ln x = -1 \iff x = e^{-1} \approx 0.3679 @@ f > 0; first-test: f′ goes from − to +
\min x^x = e^{-1/e} \approx 0.6922 @@ a least value, at x = 1/e
  
f(x) = \tfrac{x^2 e^x}{x + 1},\ \ x \gt 0 @@ every factor positive
\ln f = 2\ln x + x - \ln(x + 1) @@ log-of-a-product, log-of-a-quotient, log-of-a-power
f' = f\Big(\tfrac2x + 1 - \tfrac{1}{x + 1}\Big) @@ log-slope, term by term

17i2Quotients That Are Slopes Over Values

Area-under-g′/g technique: on an interval where g has a continuous slope and g ≠ 0, ∫ g′(x)/g(x) dx = ln|g(x)| + C. The slope of the right side is g′/g by area-under-1/x and chain for slopes; all-antiderivatives does the rest.

\textstyle\int \tfrac{2x}{x^2 + 1}\,dx = \ln(x^2 + 1) + C @@ g = x² + 1 > 0
\textstyle\int \tfrac{e^x}{e^x + 2}\,dx = \ln(e^x + 2) + C @@ g = eˣ + 2
\textstyle\int \tfrac{dx}{x\ln x} = \ln|\ln x| + C,\ \ x \gt 0,\ x \ne 1 @@ g = ln x, g′ = 1/x
\textstyle\int \tfrac{\ln x}{x}\,dx = \tfrac12(\ln x)^2 + C @@ substitution for areas with r = ln x; not area-under-g′/g, though it looks like it

17i3Exponentials Outrun Powers

Exponentials-pass-powers technique: for every real r and every b > 1, xʳ/bˣ → 0 as x → ∞. So bˣ eventually passes every polynomial, and stays past it.

\ln\tfrac{x^r}{b^x} = r\ln x - x\ln b = x\Big(r\cdot\tfrac{\ln x}{x} - \ln b\Big) @@ real-exponent (17g), log-of-a-quotient; x > 0
\tfrac{\ln x}{x} \to 0 @@ log-loses-to-powers (17d) with p = 1
r\cdot\tfrac{\ln x}{x} - \ln b \to -\ln b \lt 0 @@ rung 10's limits; ln b > 0 since b > 1 (log-rises)
\ln\tfrac{x^r}{b^x} \to -\infty,\ \ \htmlClass{new}{\tfrac{x^r}{b^x} \to 0} @@ x times something below −½ ln b, for x large; then exp heads to 0 (17e)
|q(x)| \le \big(|u_0| + \cdots + |u_n|\big)x^n \text{ for } x \ge 1 \quad \blacksquare @@ q of degree n: each xᵏ ≤ xⁿ when x ≥ 1 (powers-keep-order); so q(x)/bˣ → 0 too
  
1.01^x \text{ against } x^{100} @@ at x = 1 the first is larger; at x = 2 it is far smaller
x\ln 1.01 = 100\ln x \text{ near } x \approx 117{,}300 @@ the second crossing, by halving; past it, 1.01ˣ stays ahead (exponentials-pass-powers)
xe^{-x} \to 0,\ \ x^3 e^{-x} \to 0 @@ the limits that make ∫₀^∞ xⁿe⁻ˣ dx work by parts

So any steady percentage growth, however small, ends ahead of any polynomial growth, however steep. Before that it can lag for a long time.

17i5What a Person Can Notice

A scientist of 1860 took an earlier finding: the least change in a stimulus a person can notice is a fixed fraction of the stimulus. He wrote it as a relation between small changes, dS = k dI / I, and integrated it. So the strength of a sensation grows as the logarithm of the stimulus.

Who said it first

Fechner took Weber’s finding, that the least change in a stimulus a person can notice is a fixed fraction of the stimulus, wrote it as a relation between small changes, dS = k dI / I, and integrated it, so that the strength of a sensation grows as the logarithm of the stimulus.

Gustav Fechner, Elemente der Psychophysik (1860); paraphrase

The noticing fraction is Ernst Weber’s; in 17i.4.4, the one who found powers is S. S. Stevens. Their accepted names are the Weber–Fechner law and Stevens’s power law.
