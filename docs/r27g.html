27g · proof

A Matrix Obeys Its Own Polynomial

The stretch test gave each square grid a polynomial: the determinant of the grid minus a number down its middle. Now put the grid itself into that polynomial, with its powers in place of the powers of the number. The answer is the grid of zeros, every time. This step proves it with a way of undoing a grid that uses only determinants of smaller grids, and then finds the smallest polynomial a grid obeys.

Put a square grid into its own stretch-test polynomial and the result is the zero grid. Every polynomial the grid obeys is a multiple of the smallest one it obeys.

27g1A Grid Turned on Its Side

The grid Aᵀ has the rows of A as its columns: (Aᵀ)ᵢⱼ = aⱼᵢ. Accepted name: the transpose.

Side-turn technique: det Aᵀ = det A. So every technique for columns holds for rows: swapping two rows changes the sign, and adding a stretch of one row to another changes nothing.

\det A^{\mathsf T} = \textstyle\sum_\sigma \operatorname{sign}\sigma\ a_{1\sigma(1)}\cdots a_{n\sigma(n)} @@ the three-conditions formula (27e2) for Aᵀ
a_{1\sigma(1)}\cdots a_{n\sigma(n)} = a_{\tau(1)1}\cdots a_{\tau(n)n},\ \tau = \sigma^{-1} @@ the same n factors, in another order
\operatorname{sign}\sigma^{-1} = \operatorname{sign}\sigma @@ σ σ⁻¹ does nothing, which is even (19e)
\htmlClass{new}{\det A^{\mathsf T} = \textstyle\sum_\tau \operatorname{sign}\tau \prod_j a_{\tau(j)j} = \det A} \quad \blacksquare @@ σ ↦ σ⁻¹ runs through every shuffle once

27g2Undoing by Smaller Determinants

Strike row i and column j from A and take the determinant of what is left, times (−1)^{i+j}. Call it Cᵢⱼ, the stand-in for place i, j. Let the stand-in grid S have Cᵢⱼ in place j, i: the stand-ins, turned on their side.

Stand-in technique: S A = (det A) I. So when det A ≠ 0, A⁻¹ = S / det A.

\det A = \textstyle\sum_i a_{ij}\,\det(A \text{ with column } j \text{ replaced by } e_i) @@ column j = Σ aᵢⱼeᵢ; straight in column j (27e1)
\det(A \text{ with column } j = e_i) = (-1)^{i+j}\det(\text{strike row } i,\ \text{column } j) = C_{ij} @@ move column j to the front and row i to the top by neighbour swaps (27e1, 27g1); then only shuffles fixing 1 count (27e2)
\textstyle\sum_i C_{ij}\,a_{ik} = \det(A \text{ with column } j \text{ replaced by column } k) @@ the same two lines, with column k’s entries
= \det A \text{ if } k = j,\ \ 0 \text{ if } k \ne j @@ flat: column k then appears twice
\htmlClass{new}{(SA)_{jk} = \textstyle\sum_i C_{ij}a_{ik} = \det A\cdot[j{=}k]} \quad \blacksquare @@ ﹀ S, ﹀ the product (27d2)

27g3The Grid in Its Own Polynomial

Own-polynomial technique: if p(λ) = det(A − λI) = c₀ + c₁λ + ⋯ + cₙλⁿ, then p(A) = c₀I + c₁A + ⋯ + cₙAⁿ is the zero grid.

S(\lambda)\,(A - \lambda I) = p(\lambda)\,I \text{ for every } \lambda @@ the stand-in technique (27g2), for A − λI
S(\lambda) = B_0 + B_1\lambda + \cdots + B_{n-1}\lambda^{n-1} @@ each stand-in is a determinant of a grid with at most n − 1 entries holding λ
B_0A = c_0I,\ \ B_kA - B_{k-1} = c_kI\ (1 \le k \le n-1),\ \ -B_{n-1} = c_nI @@ the two sides agree for every λ, so place by place their coefficients agree (9g)
\textstyle\sum_k c_kA^k = B_0A + \sum_{k=1}^{n-1}(B_kA^{k+1} - B_{k-1}A^k) - B_{n-1}A^n @@ multiply line k on the right by Aᵏ, and add
\htmlClass{new}{p(A) = 0} \quad \blacksquare @@ every term cancels with the next: the sum telescopes

The tempting proof puts λ = A into det(A − λI) and gets det(A − A) = det 0 = 0. It is not allowed: p(A) is a grid, while det(A − λI) with a grid in place of λ is not even written down sensibly. The stand-in grids are what make the substitution honest.

27g4The Smallest Polynomial It Obeys

Least-obeyed technique: among the polynomials q with first coefficient 1 and q(A) = 0 there is one of least degree, m. Every polynomial q with q(A) = 0 is a multiple of m, and every stretch of A is a root of m.

p(A) = 0 \Rightarrow \text{some polynomial is obeyed} @@ the own-polynomial technique (27g3); divide by (−1)ⁿ to make its first coefficient 1
m = \text{one of least degree} @@ the counting numbers have a least member (3)
q = s\,m + r,\ \deg r < \deg m @@ long division (9g)
r(A) = q(A) - s(A)\,m(A) = 0 @@ powers of A commute, so (sm)(A) = s(A)m(A)
\Rightarrow r = 0 @@ a nonzero r, scaled to first coefficient 1, would be obeyed with smaller degree
Av = \lambda v \Rightarrow 0 = m(A)v = m(\lambda)v \Rightarrow m(\lambda) = 0 @@ Aᵏv = λᵏv; v ≠ 0
\htmlClass{new}{m \text{ divides every obeyed } q;\ \text{every stretch is a root of } m} \quad \blacksquare

27g5A Grid Some Power of Which Is 0

The grid N with rows (0, 1), (0, 0) is not 0, and NN is 0 (27d7). A square grid N fades out when some power of it is the zero grid.

Fades-out technique: if N is n × n and Nᵏ = 0 for some k, then the only stretch of N is 0, already Nⁿ = 0, and I − N is undoable with (I − N)⁻¹ = I + N + ⋯ + Nᵏ⁻¹.

Nv = \lambda v,\ v \neq 0 \Rightarrow N^kv = \lambda^kv = 0 \Rightarrow \lambda = 0 @@ use N again and again; v ≠ 0
\det(N - \lambda I) = (-\lambda)^n @@ degree n with (−1)ⁿλⁿ first (27f1), and its only root in ℂ is 0 (25d)
(-1)^nN^n = 0 @@ the own-polynomial technique (27g3)
(I - N)(I + N + \cdots + N^{k-1}) = I - N^k @@ multiply out; the middle terms cancel in pairs
\htmlClass{new}{(I - N)^{-1} = I + N + \cdots + N^{k-1}} \quad \blacksquare @@ since Nᵏ = 0; and Nⁿ = 0 by the third line

So a grid that fades out at all has faded out by its n-th power. A staircase with 0 down its middle fades out: each power pushes its entries one more place up from the middle. Taking the slope is such a map on the polynomials of degree at most 3. In the basis 1, x, x², x³ it sends each power to a number times the one before, and four slopes in a row give 0.

The undo of I − N is rung 22’s endless sum 1 + x + x² + ⋯ for 1/(1 − x), with the grid in place of x. Here the sum stops by itself.

27g6A Real Grid That Squares to −I

The quarter turn of the plane, with rows (0, −1), (1, 0), done twice is the half turn, −I. Which real grids J have JJ = −I?

Quarter-turn technique: if J is a real n × n grid with JJ = −I, then n is even, and in some basis v₁, Jv₁, …, vₘ, Jvₘ the grid of J is made of quarter turns down its middle and 0 elsewhere.

(\det J)^2 = \det(JJ) = \det(-I) = (-1)^n @@ det-product (27e3); a real square is not negative, so n is even
Jv = c\,v,\ v \neq 0 \Rightarrow -v = c^2v @@ no real c has c² = −1: v and Jv are free
W \text{ kept by } J,\ v \notin W,\ av + bJv \in W @@ suppose a mix of v and Jv falls in W
\Rightarrow aJv - bv \in W @@ apply J: W is kept, and J(Jv) = −v
\Rightarrow (a^2 + b^2)\,v \in W \Rightarrow a = b = 0 @@ a times the first, less b times the second
\htmlClass{new}{v_1, Jv_1, \ldots, v_m, Jv_m \text{ a basis}} \quad \blacksquare @@ grow W two vectors at a time, from W = {0}

In that basis J sends vᵢ to Jvᵢ and Jvᵢ to −vᵢ. So its grid has the quarter turn with rows (0, −1), (1, 0) in each 2 × 2 block down the middle. Every real grid that squares to −I is the same map as this one, read in another basis (27d4). Over ℂ the question is different: there i times I squares to −I in every size, odd sizes too. The proof used the reals at two places, and both were the fact that a real square is not negative.

27g7Moves to Watch Out For

p(A) = \det(A - A\,I) = 0\,? @@ <span class="vd vd-a">out of arrangement</span> a grid is not put in for a number inside a determinant; the stand-in proof is needed
p(A) = 0 \Rightarrow p \text{ is the smallest obeyed polynomial}\,? @@ <span class="vd vd-p">outside the plan</span> I obeys λ − 1, of degree 1, while its stretch polynomial is (1 − λ)ⁿ
C_{ij} = \det(\text{strike row } i,\ \text{column } j)\,? @@ <span class="vd vd-p">outside the plan</span> the sign (−1)^{i+j} is part of it
SA = I\,? @@ <span class="vd vd-p">outside the plan</span> SA = (det A) I; divide by det A, and only when it is not 0
NN = 0 \Rightarrow N = 0\,? @@ <span class="vd vd-p">outside the plan</span> rows (0, 1), (0, 0)
JJ = -I \text{ for a real } 3 \times 3 \text{ grid}\,? @@ <span class="vd vd-p">outside the plan</span> (det J)² would be −1: the size must be even

The cellar · there if you want it

The accepted names

The grid turned on its side is the transpose. A stand-in Cᵢⱼ is a cofactor, the determinant inside it a minor, and S is the adjugate (or classical adjoint), adj A. Writing det A as Σ aᵢⱼCᵢⱼ is cofactor (or Laplace) expansion. The own-polynomial technique is the Cayley–Hamilton theorem; the smallest obeyed polynomial is the minimal polynomial. A grid that fades out is nilpotent.

Who said it first

Pierre-Simon Laplace gave the expansion by smaller determinants in 1772. Arthur Cayley stated the own-polynomial technique in 1858 and checked it for 2 × 2 and 3 × 3 grids; William Rowan Hamilton had a case of it for quaternions. Ferdinand Georg Frobenius proved it in general in 1878, and also introduced the minimal polynomial.

The words quoted in 27g.4.5 are Cayley’s, from his memoir on the theory of matrices of 1858; the proof of 1878 is Frobenius’s.
