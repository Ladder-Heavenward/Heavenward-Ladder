16c · proof

Evaluating by Antiderivatives

16b showed that the slope of the area function of an unbroken function is the function itself. Any other function with that slope will do as well, and rung 14 says two such functions differ by a constant. That gives the area between two ends as the change in that other function between them, with no sums. This step proves it twice. The first proof is three lines from 16b and rung 14. The second skips 16b altogether. On each piece of a partition, rung 14’s mean value technique puts the other function’s change at the height somewhere on the piece times the piece’s width. So its total change sits between every lower sum and every upper sum. The second proof asks less of the function. Then the step turns the technique on rung 15's hard-won areas, and gets each in one line.

If a function’s slope is the height on a closed interval, and the height has an integral there, then the area is that function’s value at the right end less its value at the left. Proof one: the area function and that function differ by a constant. Proof two: average-slope on each piece, the changes add up by collapsing-sum, and the total lies between the lower and upper sums of every partition.

16c1The Second Fundamental Technique, From the First

Area-is-a-change technique (the fundamental theorem of calculus, second part): if f is continuous on [p, q] and G is an antiderivative of f on [p, q], then ∫ₚ^q f(x) dx = G(q) − G(p).

F(x) = \textstyle\int_p^x f(t)\,dt \text{ is an antiderivative of } f \text{ on } [p, q] @@ antiderivative-exists (16b)
F = G + C \text{ for some real } C @@ all-antiderivatives (14e)
0 = F(p) = G(p) + C,\ \ C = -G(p) @@ ∫ₐᵃ f = 0 (15e)
\htmlClass{new}{\textstyle\int_p^q f = F(q) = G(q) - G(p)} \quad \blacksquare @@ the same line at q

From here on, G(x)|ₚ^q, also written [G(x)]ₚ^q, means G(q) − G(p). The bar is an operator: carried out on G, it produces that number. Its accepted name is the fundamental theorem of calculus, second part, or the evaluation theorem.

16c2The Same, From the Boxes

Change-for-any-integrable technique: if f is integrable on [p, q], and G is continuous on [p, q] with G′(x) = f(x) for every x in (p, q), then ∫ₚ^q f(x) dx = G(q) − G(p).

\text{take any partition } P:\ p = x_0 \lt x_1 \lt \cdots \lt x_n = q @@ 15a
\text{on each piece, some } t_i \in (x_{i-1}, x_i):\ G(x_i) - G(x_{i-1}) = G'(t_i)\,\Delta x_i @@ average-slope (14c): G is continuous on the piece and has a slope inside it
= f(t_i)\,\Delta x_i,\ \ m_i\,\Delta x_i \le f(t_i)\,\Delta x_i \le M_i\,\Delta x_i @@ G′ = f inside; mᵢ ≤ f(tᵢ) ≤ Mᵢ (15a); Δxᵢ > 0
\textstyle\sum_{i=1}^{n} \big(G(x_i) - G(x_{i-1})\big) = G(q) - G(p) @@ collapsing-sum (15g)
L(f, P) \le G(q) - G(p) \le U(f, P) @@ add the n lines (sum-one-more, induction)
\text{this is true for every } P @@ P was any partition
\htmlClass{new}{\textstyle\int_p^q f = G(q) - G(p)} \quad \blacksquare @@ exactly-one-between (15c): f is integrable, and the number sits between every L and every U

Nothing here asked f to be continuous, and nothing asked for 16b. It asked for G's slope to be f at every point inside, and for f to have an area, 15c1’s lower and upper integrals meeting. The second of those is not automatic, as the seam question below asks you to weigh.

In 1881 a function was described with a slope at every point, its slope never more than a fixed bound. Yet the slope is so broken up, on a set of points spread through every stretch, that 15c's sums for it never close in on any number.

16c3The Indefinite Integral

From here on, ∫ f(x) dx = G(x) + C is written with no ends on the ∫. It says that the antiderivatives of f on the interval in view are exactly the functions G + C, one for each real C (all-antiderivatives). Its accepted name is the indefinite integral of f; C is the constant of integration. 15c's ∫ᵤᵛ is then called the definite integral.

The two are different kinds of thing. ∫ₚ^q f(x) dx is one number. ∫ f(x) dx is a whole family of functions. Area-is-a-change is the bridge: pick any member G of the family, and the number is G(q) − G(p); the C cancels.

16c4Rung 15's Areas, in One Line Each

\textstyle\int_0^1 x\,dx = \tfrac{x^2}{2}\Big|_0^1 = \tfrac12 @@ (x²/2)′ = x (power for slopes, constant-factor for slopes); area-is-a-change. 15d took a whole step
\textstyle\int_0^b x^k\,dx = \tfrac{x^{k+1}}{k+1}\Big|_0^b = \tfrac{b^{k+1}}{k+1} @@ power for slopes; area-is-a-change. 15i's area-under-a-power, with its ratio cut
\textstyle\int_1^3 \tfrac{dV}{V^2} = -\tfrac1V\Big|_1^3 = \tfrac23 @@ negative-powers (13f): (−V⁻¹)′ = V⁻²; area-is-a-change. The same lines on [p, q] with 0 < p < q give 1/p − 1/q: the inverse-square-area technique, with no collapse
\textstyle\int_1^4 \sqrt{x}\,dx = \tfrac23 x^{3/2}\Big|_1^4 = \tfrac23(8 - 1) = \tfrac{14}{3} @@ fraction-power for slopes (13h): (x^{3/2})′ = (3/2)x^{1/2}
\textstyle\int_1^2 (3x^2 - 4x + 1)\,dx = (x^3 - 2x^2 + x)\Big|_1^2 = 2 - 0 = 2 @@ polynomial-slope (13d)

Each line is the same two moves: name a function with the right slope, then subtract. The hard part has moved. Rung 15's hard part was a sum; now it is finding G.

The inverse-square-area technique of 15·chem4 said that for 0 < p < q, ∫ₚ^q dx/x² = 1/p − 1/q. The third line above reaches it on any such [p, q] with no collapse. −1/x has slope x⁻² there (negative-powers, 13f). 1/x² is continuous there, since p > 0. So area-is-a-change gives (−1/q) − (−1/p).

16c.4.4seamThe function of 1881 has a slope everywhere, bounded, and that slope has no area in rung 15's sense. So change-for-any-integrable cannot be used on it. In 1902 a new integral was built, under which every bounded slope has an area and area-is-a-change is true again. Others said rung 15's integral was the right one, and the slope of 1881 a monster.

Who said it first

Volterra described a function with a slope at every point, its slope never more than a fixed bound, and yet the slope so broken up, on a set of points spread through every stretch, that Riemann’s sums for it never close in on any number.

Volterra, Sui principii del calcolo integrale (1881); paraphrase

The new integral of 1902 is Henri Lebesgue’s. 15i’s ratio cut is Fermat’s, from around 1640.
