18c · proof

Lines

18b made the segment between two points: the points some fraction of the way, for fractions from zero to one. Let the fraction run over all the reals and the segment becomes a line. This step gives a line two descriptions, a point with a direction, and an equation fixing a weighted sum of the two coordinates, and proves they give the same sets. Then the facts the old geometry took as postulates come out as techniques: one line through two points, and one parallel through a point off a line. The nearest point of a line is found by the right-triangle technique.

The points reached from a start by any multiple of a direction are the points whose dot with the direction turned a quarter is the same as the start’s. Two lines meet once exactly when they are not parallel, which a cross product of their weights can test. Two lines are perpendicular when their slopes multiply to negative one. The distance from a point to a line is how far the point misses the line’s equation, divided by the length of the line’s weights.

18c1Two descriptions

From here on, for a point P and a displacement v ≠ 0, the line through P with direction v is {P + tv : t ∈ ℝ}. Its accepted names: v is a direction vector, and X = P + tv is the line's parametric form. For reals A, B, C with (A, B) ≠ (0, 0), the set {(x, y) : Ax + By = C} is the line with equation Ax + By = C, and n = (A, B) is a normal of it.

Two-descriptions-agree technique: the line through P with direction v is the set {X : n · X = n · P}, where n = (−v₂, v₁). Conversely, the set Ax + By = C is the line through any of its points with direction (−B, A), and it has points.

n \cdot v = -v_2v_1 + v_1v_2 = 0 @@ n ⊥ v, and n ≠ 0 since v ≠ 0
X = P + tv \Rightarrow n \cdot X = n \cdot P + t\,(n \cdot v) = n \cdot P @@ the dot technique
n \cdot (X - P) = 0:\ \ w = X - P,\ \ s = \tfrac{w \cdot v}{|v|^2},\ \ z = w - sv @@ the other way: try to write w as a multiple of v
z \cdot v = 0,\ \ z \cdot n = 0 @@ the choice of s; and w · n = 0, v · n = 0
z_1v_1 + z_2v_2 = 0,\ \ -z_1v_2 + z_2v_1 = 0 \Rightarrow z_1|v|^2 = 0,\ z_2|v|^2 = 0 @@ times v₁ and −v₂, add; then times v₂ and v₁, add
z = 0,\ \ X = P + sv @@ |v|² ≠ 0; so X is on the line
B \ne 0:\ (0, \tfrac CB);\ \ B = 0:\ (\tfrac CA, 0) \quad \blacksquare @@ a point of ax + by = C; with v = (−B, A), n = (A, B) up to sign

The third to sixth lines also prove a fact used again: in the plane, a displacement perpendicular to a non-zero n is a multiple of any one displacement perpendicular to n.

18c2One line through two points

Line-through-two-points technique: through two different points P and Q there is exactly one line: the line through P with direction Q − P.

P + 0(Q - P) = P,\ \ P + 1(Q - P) = Q @@ the line through P with direction Q − P holds both
\text{a line } n \cdot X = c \text{ holding } P, Q \Rightarrow n \cdot (Q - P) = 0 @@ subtract the two equations (adding-keeps-answers)
\Rightarrow n \text{ is a multiple of } (-(q_2 - p_2),\ q_1 - p_1) @@ the fact above, with the roles of n and v exchanged
\begin{aligned}&\htmlClass{new}{\text{its equation is } n \cdot X = n \cdot P,\text{ the same set}}\\ &\quad \blacksquare\end{aligned} @@ multiplying-keeps-answers: a multiple of an equation has the same answers

If B ≠ 0, Ax + By = C is y = (−A/B)x + C/B: the graph of 9e's linear function, with slope m = −A/B. A direction (v₁, v₂) with v₁ ≠ 0 has slope v₂/v₁, so the line through (x₁, y₁) and (x₂, y₂) with x₁ ≠ x₂ has slope (y₂ − y₁)/(x₂ − x₁), as rung 13 found. If B = 0 the line is x = C/A, which is vertical and has no slope; it fails 9e's column test, so it is the graph of no function.

18c3Lines that meet, and lines that do not

From here on, two different lines are parallel when they have no point in common. Its accepted name is the same.

Two-lines-meet technique: let A₁x + B₁y = C₁ and A₂x + B₂y = C₂ be lines, and D = A₁B₂ − A₂B₁. If D ≠ 0 they have exactly one common point, x = (C₁B₂ − C₂B₁)/D, y = (A₁C₂ − A₂C₁)/D. If D = 0, their normals are multiples, and the lines are the same or parallel.

B_2(A_1x + B_1y) - B_1(A_2x + B_2y) = B_2C_1 - B_1C_2 @@ multiplying-keeps-answers and adding-keeps-answers (5g): any common point satisfies this
Dx = C_1B_2 - C_2B_1,\ \ Dy = A_1C_2 - A_2C_1 @@ likewise with A₂ and A₁
D \ne 0:\ \text{one candidate, and it satisfies both} @@ substitute back; so exactly one point
D = 0:\ \ (A_2, B_2) \cdot (-B_1, A_1) = 0 @@ so (A₂, B₂) is a multiple of (A₁, B₁), by the fact under two-descriptions-agree
(A_2, B_2) = k(A_1, B_1):\ \ C_2 = kC_1 \text{ same line; else no common point} \quad \blacksquare @@ a common point would give C₂ = kC₁

Parallel-through-a-point technique: for a line ℓ: Ax + By = C and a point P = (p₁, p₂) not on ℓ, exactly one line through P is parallel to ℓ: Ax + By = Ap₁ + Bp₂.

Ap_1 + Bp_2 \ne C @@ P is not on ℓ
Ax + By = Ap_1 + Bp_2 \text{ holds } P,\ \text{has } D = 0,\ \text{differs from } \ell @@ so by two-lines-meet it is parallel to ℓ
\text{another line through } P \text{ with } D = 0 \text{ has normal } k(A, B) @@ two-lines-meet; through P forces the same equation, by multiplying-keeps-answers
\begin{aligned}&\htmlClass{new}{\text{every other line through } P \text{ has } D \ne 0 \text{ and }}\\ &\quad \htmlClass{new}{\text{meets } \ell} \quad \blacksquare\end{aligned} @@ two-lines-meet

A textbook of 1795 put the fifth postulate of the old geometry in this form, as an axiom. On this ladder it is not an axiom. It is a technique about ℝ².

18c4Perpendicular lines, and the nearest point

Perpendicular-lines technique: the lines A₁x + B₁y = C₁ and A₂x + B₂y = C₂ have perpendicular directions exactly when A₁A₂ + B₁B₂ = 0. If neither is vertical, with slopes m₁ and m₂, that is m₁m₂ = −1. The directions are (−B₁, A₁) and (−B₂, A₂), whose dot product is B₁B₂ + A₁A₂; with slopes the directions are (1, m₁) and (1, m₂), with dot product 1 + m₁m₂.

Nearest-point technique: for a point P₀ = (x₀, y₀) and a line ℓ: Ax + By = C with n = (A, B), the point F = P₀ − ((n · P₀ − C)/|n|²) n is on ℓ, P₀ − F is perpendicular to ℓ, F is the one nearest point of ℓ to P₀, and d(P₀, F) = |Ax₀ + By₀ − C|/√(A² + B²).

n \cdot F = n \cdot P_0 - (n \cdot P_0 - C) = C @@ the dot technique; so F is on ℓ
P_0 - F = \tfrac{n \cdot P_0 - C}{|n|^2}\,n \perp (X - F) \text{ for } X \in \ell @@ n · (X − F) = C − C = 0
d(P_0, X)^2 = d(P_0, F)^2 + d(F, X)^2 \ge d(P_0, F)^2 @@ right-triangle; equal only when X = F (distance-laws)
\htmlClass{new}{d(P_0, F) = \tfrac{|n \cdot P_0 - C|}{|n|}} \quad \blacksquare @@ distance-laws: |tn| = |t| |n|

F has the accepted name the foot of the perpendicular. The distance from a point to a line means d(P₀, F).

Who said it first

The old geometry is Euclid's, in his Elements of about 300 BCE, and its first and fifth postulates are in Book I. The textbook of 1795 is John Playfair's.

Euclid's fifth postulate asks that, if a straight line falling on two straight lines makes the inner angles on one side together less than two right angles, then the two lines, if extended without end, meet on that side.

Euclid, Elements, Book I, postulate 5 (about 300 BCE); paraphrase

In 18c.4.4, the mathematician of 1733 is Saccheri, the one of 1829 is Lobachevsky, and the one of 1832 is Bolyai.

Accepted names: parallel-through-a-point is Playfair's axiom; the fifth postulate of the old geometry is Euclid's fifth postulate.
