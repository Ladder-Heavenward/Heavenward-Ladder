12c · proof

The Highest-and-Lowest Technique

12b showed that a function continuous on a closed interval has its outputs below some bound. So they have a least upper bound. This step asks whether some input reaches it, or whether the outputs only creep up on it the way the fractions creep up on the square root of 2. For a function continuous on a closed interval, some input reaches it. The proof is a refutation with an invented function. If the top were never reached, the reciprocal of the gap below the top would be continuous on the whole interval. So 12b would bound it, and that bound would give a smaller top. The least value comes from turning the function upside down.

If the top is never reached, then one over the gap below the top is continuous, so it is bounded. Then every output stays a fixed amount below the top, so the top was not the least upper bound: totally false. So some input reaches the top.

12c1Greatest and Least, Said Exactly

4h gave the words greatest and least for numbers, and 5d and 8a carried them to fractions and reals. Said of a function's outputs:

From here on, take a function f whose outputs are reals, and a set A of its inputs. f reaches its greatest value on A at c when c ∈ A and f(x) ≤ f(c) for every x ∈ A. Then f(c) is the greatest value of f on A. Likewise f reaches its least value on A at d when d ∈ A and f(d) ≤ f(x) for every x ∈ A, and f(d) is the least value. A greatest value is called a maximum and a least value a minimum, and either is called an extreme value. On the whole domain they are the absolute maximum and minimum.

The greatest value is one real; the inputs that reach it may be many. Two inputs c and c′ that both reach it have f(c) ≤ f(c′) and f(c′) ≤ f(c), so f(c) = f(c′) (at-most-is-a-partial-order on ℝ's antisymmetry): “the greatest value” is a name.

From here on, for f and A as above, sup_A f names sup{f(x) : x ∈ A}, when there is one. That is the least upper bound of f's set of values on A (2h's shorthand, a set of reals, 8c's line). And inf_A f names its greatest lower bound, when there is one. Read them “the sup of f on A” and “the inf of f on A”. When A is clear from the step, they are written sup f and inf f. Both marks are names: each names one real.

Reuses, said out loud. 8c's sup S names the least upper bound of a set S of reals, and still does. sup_A f is that same sup, taken of one set, f's values on A. So it is a new way of writing an old thing, not a new idea. 4h gave greatest and least to numbers, and 6e's least member to partial orders. Here they are said of a function's values, with the input that gives the value named too. In this step the letter M names sup f: it is not 8·phys's upright M for mega, nor the M of 9g's leading-term.

Greatest-is-reached technique: f reaches its greatest value on A at c exactly when sup_A f exists and equals f(c), with c ∈ A. Rightward: f(c) is an upper bound of the values, and any upper bound β has f(c) ≤ β because f(c) is a value; so f(c) is the least upper bound. Leftward: every value is at most the sup, which is f(c). ∎ Likewise the least value is the inf, reached.

So the question of this step is a question about sup f: it exists for a function bounded above (no-holes), and the technique says whether it is a value.

12c2Bounded Is Not Reaching

Without both words of the hypothesis, the sup can exist and not be reached.

Leave out an end: x on [0, 1) is continuous and bounded, and its sup is 1. Every value is below 1. And nothing below 1 is an upper bound: for c < 1, the middle (c + 1)/2 is an input above c (5f's another-between read in ℝ). So 1 is the sup and no input reaches it. On (0, 1), x has neither a greatest nor a least value.

Put in a discontinuity: let f(x) = x for 0 ≤ x < 1 and f(1) = 0, on the closed interval [0, 1]. The sup is still 1 and still not reached. One discontinuity at the end is enough to lose the top.

Leave out an end and the bound too: 1/x on (0, 1] reaches its least value 1 at 1 and has no greatest value, since it passes every bound (10f). And off any closed interval: x²/(1 + x²) on ℝ creeps up on 1 and never gets there, because 1 − x²/(1 + x²) = 1/(1 + x²) is positive.

12c3The Proof, Every Line Cited

Highest-and-lowest technique (the extreme value theorem): if f is continuous on [v, w], then f reaches a greatest value on [v, w] and a least value on [v, w]. In marks: ∃c ∈ [v, w] ∀x ∈ [v, w] (f(x) ≤ f(c)) and ∃d ∈ [v, w] ∀x ∈ [v, w] (f(d) ≤ f(x)).

f \text{ bounded above on } [v, w] @@ bounded-on-a-closed-interval (12b), then bounded-both-ways
V = \{f(x) : x \in [v, w]\} @@ 2h's shorthand: a set of reals with the member f(v) and an upper bound
\htmlClass{new}{M = \sup_{[v,w]} f = \sup V} @@ no-holes (8c)
\forall x \in [v, w]\ (f(x) \le M) @@ M is an upper bound of V
  
\text{suppose } \neg\exists c \in [v, w]\ (f(c) = M) @@ a supposition for contradiction (7e)
\forall x \in [v, w]\ (f(x) \ne M) @@ not-some (2b), bounded
\forall x \in [v, w]\ (f(x) \lt M) @@ the line above and f(x) ≤ M: 8a's line for <
g(x) = \htmlClass{new}{\frac{1}{M - f(x)}} @@ 10c's quotient of the constant 1 by M − f: every bottom on [v, w] is positive (order-and-arithmetic-agree)
g \text{ continuous on } [v, w] @@ continuous-sums for M − f; continuous-quotients, since the bottom's value is not 0 at any input of [v, w]; side by side at the ends (11b)
\text{call } K:\ \forall x \in [v, w]\ (g(x) \le K) @@ bounded-on-a-closed-interval (12b) again, for g, then bounded-both-ways
0 \lt g(v) \le K @@ the reciprocal of a positive real is positive (positive-reciprocal on ℚ read in ℝ)
\tfrac1K \le M - f(x) @@ reciprocals of positives turn the order about (positive-reciprocal on ℚ read in ℝ); the reciprocal of g(x) is M − f(x) (reciprocal on ℝ)
f(x) \le \htmlClass{new}{M - \tfrac1K} \text{ for every } x \in [v, w] @@ order-and-arithmetic-agree: add f(x) − 1/K to both sides
M - \tfrac1K \text{ is an upper bound of } V,\ \ M - \tfrac1K \lt M @@ 8c's line; 1/K is positive
M \le M - \tfrac1K;\ \ \bot @@ M is the least upper bound; three-way-order on ℝ
\exists c \in [v, w]\ (f(c) = M) @@ refute gives ¬¬; not-not-out (7d), rung 7's either-way principle
\forall x \in [v, w]\ (f(x) \le f(c)) @@ the swap axiom in the line M is an upper bound: f reaches its greatest value at c
  
h(x) = \htmlClass{new}{-f(x)} \text{ is continuous on } [v, w] @@ constant-factor (11b) with the constant −1
\text{call } d:\ \forall x \in [v, w]\ (-f(x) \le -f(d)) @@ the greatest value of h, by the column above
\forall x \in [v, w]\ (f(d) \le f(x)) \quad \blacksquare @@ negative-reverses-order (8g): multiply by −1, and the order turns about

Where each hypothesis was spent. No-holes: at M = sup V, and inside both uses of bounded-on-a-closed-interval, each with its own least upper bound. Continuity: inside bounded-on-a-closed-interval for f, and again in making g continuous. That is the heart of the trick. The supposition “never reached” is exactly what keeps g's bottom away from 0, so it is what makes g continuous. The closed interval: inside both uses of bounded-on-a-closed-interval. And rung 7's either-way principle: the proof is by contradiction proper. It never says where the greatest value is reached. It shows that “nowhere” is totally false, and the last step from ¬¬∃c to ∃c is not-not-out. That is honest: the technique gives no recipe for finding c, and constructive mathematicians do not accept it in this form.

Watch the trick fail where the technique fails. For x on [0, 1), M = 1 and nothing reaches it, so the supposition is true and g(x) = 1/(1 − x) is continuous on [0, 1). But [0, 1) is not closed, bounded-on-a-closed-interval cannot be cited, and indeed g passes every bound as x → 1⁻. The column breaks at the line that calls K.

One well-known calculus book gathers this technique, 12a’s and 12b’s into a chapter of their own. It states them, uses them, and keeps the proofs back until the next chapter. They cannot be proved from the rules of arithmetic and order alone: each needs the least upper bound.

The Technique's accepted name carries the name of a teacher who taught it in his Berlin lectures of the 1860s. The mathematician of 12a's 1817 paper had a proof in a manuscript of the 1830s that was not published until 1930.

12c4By Hand: Where the Top and Bottom Are

Highest-and-lowest promises a greatest and a least value. For some functions you can find them by hand, by writing the gap to a claimed top or bottom as something whose sign you know.

x^2 - 2x = (x - 1)^2 - 1 @@ completing the square (8i)
(x - 1)^2 \ge 0, \text{ with } 0 \text{ only at } 1 @@ square-never-negative (8f): least value −1, reached at 1
x \in [-1, 2] \;\Rightarrow\; |x - 1| \le 2 @@ −2 ≤ x − 1 ≤ 1, unpack-the-bars
(x - 1)^2 \le 4, \text{ with } 4 \text{ only at } x = -1 @@ size-squared and powers-keep-order (8f); |x − 1| = 2 only at −1 inside [−1, 2]
\text{greatest } \htmlClass{new}{3} \text{ at } -1,\ \ \text{least } \htmlClass{new}{-1} \text{ at } 1 @@ the two extreme values of x² − 2x on [−1, 2]
  
p(x) = x^3 - 3x + 1 \text{ on } [-2, 2] @@ 12b's polynomial-bound bounded its size by 15
p(x) - 3 = (x + 1)^2 (x - 2) @@ factor (9g): −1 is a zero of p − 3, twice; expand to check by 5i's grid
x \le 2 \;\Rightarrow\; p(x) - 3 \le 0 @@ a square (square-never-negative) times a factor at most 0: 8g's sign-of-a-product, or 0
p(x) + 1 = (x - 1)^2 (x + 2) \ge 0 \text{ on } [-2, 2] @@ the same, with the factor x + 2 ≥ 0
\text{greatest } 3 \text{ at } -1 \text{ and } 2;\ \ \text{least } -1 \text{ at } -2 \text{ and } 1 @@ each extreme value reached at two inputs: the gap is 0 there
  
\tfrac12 - \tfrac{x}{1 + x^2} = \tfrac{(1 - x)^2}{2(1 + x^2)} @@ one bottom (5h's fractions-of-rationals, read in ℝ); square-of-a-difference
\ge 0, \text{ with } 0 \text{ only at } x = 1 @@ square-never-negative on the top; the bottom is positive
\tfrac{x}{1 + x^2} \text{ on } [0, 3]:\ \text{greatest } \tfrac12 \text{ at } 1,\ \text{least } 0 \text{ at } 0 @@ the top as above; at 0 the value is 0 and every value on [0, 3] is at least 0

Highest-and-lowest does not find these. It says they are there, which is what makes a search for them sensible. Rung 14 starts from this technique and gives a way to narrow the search.

12c6Running It Backwards

Handed a function on a closed interval and asked whether it has a greatest value, check continuity on the whole interval. Then yes, by highest-and-lowest. Handed a claimed greatest value M, check that the gap M − f(x) is never negative and is 0 somewhere: a square, a product of factors with known signs, a single bottom. Handed a function that never reaches its sup, find the missing word: an end left out, or a discontinuity. Found upward; written downward.

Who said it first

Spivak gathers this technique, 12a's and 12b's into a chapter he calls “Three Hard Theorems”, states them, uses them, and keeps the proofs back until the next chapter, because they cannot be proved from the rules of arithmetic and order alone: each needs the least upper bound property.

Spivak, Calculus, chs. 7–8

The Berlin teacher is Karl Weierstrass; the manuscript of the 1830s is Bernard Bolzano’s. In question 12c.4.4, the mathematician of 1851 is Bernhard Riemann, the claim is Dirichlet’s principle, the example of 1870 is Weierstrass’s, and the rescue of 1900 is David Hilbert’s.

Accepted names: the highest-and-lowest technique is the extreme value theorem (Weierstrass’s); sup and inf are the supremum and infimum.
