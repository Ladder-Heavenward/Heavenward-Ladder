39k · technique

Reductions by hand

The tableau technique said that every question with short certificates turns into one question: can this statement built from letters be made true? It said so for every question at once, which makes it hard to see. This step does one turning by hand, from statements to maps. A map here is only dots and links between them, and the question is whether the dots can be given three colours so that no link joins two dots of one colour. It looks like a question about drawing. It holds every statement inside it. The step builds the pieces: a triangle of three dots that names the colours true, false and spare; a pair of linked dots for each letter, which must take true and false between them; and a small piece of six dots for each or, which can be coloured only if one of its inputs is true. Then it joins them, counts the dots, and runs the reduction backwards, reading a true row off a colouring. Every piece is checked by trying all its cases, and every count is a power of the statement’s length.

A statement in clauses of three becomes a map: a triangle for the colours, a linked pair for each letter, and a six-dot piece for each clause, coloured only if one of its letters is true. The map has three colours exactly when the statement has a true row, and the map is built fast.

39k1Clauses of three

A clause is an or of letters and nots of letters, like ¬x ∨ y ∨ z. The tableau technique wrote its statement as an and of clauses. Clauses of any length can be cut to clauses of exactly three, with new letters.

Clause-split technique: a ∨ b ∨ c ∨ d has a true row exactly when (a ∨ b ∨ z) ∧ (¬z ∨ c ∨ d) does, for a new letter z.

A clause with k letters becomes k − 2 clauses of three, with k − 3 new letters. A clause of one or two letters is padded by repeating one: x ∨ y becomes x ∨ y ∨ y. So the statements in clauses of three are NP-complete too, and they are the starting point below.

39k2A palette, and a pair for each letter

A map here is a finite set of dots and a set of links, each joining two dots. A three-colouring gives each dot one of three colours so that no link joins two dots of one colour. 34m coloured a knot’s strands with three colours under a different rule; here the rule is only that linked dots differ.

Palette technique: in a three-colouring of a triangle T, F, B, with a dot x and a dot x̄ linked to each other and both linked to B, the dots x and x̄ take the colours of T and F, one each.

T, F, B \text{ pairwise }\allowbreak \text{linked: }\allowbreak \text{three }\allowbreak \text{different }\allowbreak \text{colours} @@ name the colours after them: true, false, spare
x, \bar x \text{ both }\allowbreak \text{linked }\allowbreak \text{to } B\text{: }\allowbreak \text{neither }\allowbreak \text{is }\allowbreak \text{spare} @@ a link joins different colours
x \text{ linked }\allowbreak \text{to } \bar x\text{: }\allowbreak \text{they }\allowbreak \text{differ} @@ the same rule
\htmlClass{new}{\{x, \bar x\} \text{ coloured }}\allowbreak \htmlClass{new}{ \text{true }}\allowbreak \htmlClass{new}{ \text{and }}\allowbreak \htmlClass{new}{ \text{false}} \quad \blacksquare @@ the only two colours left

So each colouring reads off a row of 1e’s table: x is true when its dot is coloured like T. And every row is read off some colouring of this much of the map. What is left is to make a clause cost something.

39k3A piece for each or

Take two input dots a and b. Add three dots u, v, o, with links a–u, b–v, u–v, u–o, v–o. Call it an or-piece with output o.

Or-piece technique: if a and b are both coloured false, o is coloured false; if either is coloured true, the colouring can be finished with o coloured true.

a, b \text{ false} \Rightarrow u, v \ne \text{false},\ \allowbreak u \ne v\text{: } \{u, v\} = \{\text{true}, \text{spare}\} @@ u is linked to a, v to b, and u to v
o \text{ linked }\allowbreak \text{to } u \text{ and } v \Rightarrow o = \text{false} @@ the one colour left
a \text{ true} \Rightarrow u = \text{false},\ \allowbreak v = \text{spare},\ \allowbreak o = \text{true} @@ u ≠ a; v ≠ b, since b is true or false; u ≠ v; o ≠ u, v
a \text{ false},\ \allowbreak b \text{ true} \Rightarrow u = \text{spare},\ \allowbreak v = \text{false},\ \allowbreak o = \text{true} @@ u ≠ a, v ≠ b, u ≠ v, o ≠ u, v
\htmlClass{new}{\text{both }}\allowbreak \htmlClass{new}{ \text{false: } o \text{ false; }}\allowbreak \htmlClass{new}{ \text{either }}\allowbreak \htmlClass{new}{ \text{true: } o \text{ true }}\allowbreak \htmlClass{new}{ \text{is }}\allowbreak \htmlClass{new}{ \text{possible}} \quad \blacksquare @@ every case of the two inputs

The finishings must be chosen with care, and that is the point of doing it by hand: with a true, the choice u spare and v true is allowed when b is false, and it forces o false. Some finishing gives o true, and that is all the piece needs. So in every case with a true input, some finishing gives o = true, and with both inputs false, o is forced false.

A clause a ∨ b ∨ c gets two or-pieces in a row: o₁ from a and b, then o₂ from o₁ and c, and o₂ is linked to F and to B, so it must be true. If a, b and c are all false, o₁ is false, then o₂ is false, against its links. If any is true, the pieces can be finished. A script that tries all 3⁶ colourings of the six new dots for each of the eight rows agrees.

So three-colouring is NP-complete: satisfiability fast-reduces to it, and its certificate is a colouring. With two colours the question is fast, by walking the map; the reduction needs the spare colour in every piece.

The basement · there if you want it

The accepted names

A statement in clauses is in conjunctive normal form, CNF; with clauses of three it is 3-SAT, or 3-CNF-SAT. A map of dots and links is a graph, with vertices and edges; three-colouring is graph 3-colourability, written 3-COL. The palette is the base triangle, and the or-piece is the OR gadget of the standard reduction. The question of 39k.6.4 is about counting complexity, the class #P; counting the three-colourings of a graph is #P-complete, while the knot count of 34m is a determinant in disguise.

Who said it first

Richard Karp (1972) listed chromatic number among his 21 NP-complete problems; Michael Garey, David Johnson and Larry Stockmeyer (1976) proved three-colouring NP-complete even for maps that can be drawn on a plane without crossing links. The four colour theorem of 1976 says four colours always suffice for such maps, so for them only three is a question. Leslie Valiant (1979) defined #P.

A proof that is not allowed

“In the or-piece, a is true, so u is spare, so v is true, so o is false: the piece fails.” Not allowed: the piece asks only that some finishing colours o true. Choosing v badly shows one finishing fails, not every one. With a true, take u false and v spare, and o is true.
