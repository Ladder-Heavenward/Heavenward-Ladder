The same as itself, again

The ground floor began with one kind of sameness. A thing is the same as itself, and if two names name one thing, whatever is true of one is true of the other. Everything since has been built on that, and the swap it allows is the most used move on the ladder. This rung has used another kind all along: matched things, the same up to a matching, and pinned down by their arrows only that far. The two kinds are not rivals. Matched things are not one thing, and the swap does not run between them. But a statement that speaks only through arrows does run across a matching, and those are the only statements a universal property can see. Rung three met the question this answers and left it open on purpose. Two runs of sets both started from nothing and both went on forever, and each called its fourth member three. One three had three members and the other had one. Which is three? Both runs have the property the recursion of rung four needs, and that property pins a run down up to exactly one matching. So each is three, in its run, and nothing a statement about counting says can tell them apart.

Rung 0’s sameness is one thing, named twice, and the swap runs across it for every statement. A matching makes two things the same for every statement made of arrows, and only for those. The two runs of rung 3 each have rung 4’s recursion as a universal property, so exactly one matching keeps 0 and next between them; one three has three members and the other one, and that fact is not a statement about counting.

44·cb0.1Two samenesses

0b laid down self-sameness and the swap axiom: from x = y and P(x), P(y), for every statement P. x = y says one thing has two names. A ≅ B, from 44a3, says an undoable arrow runs from A to B. The two are different statements. The sets {1, 2} and {3, 4} are matched in Set, and 1 ∈ {1, 2} is true while 1 ∈ {3, 4} is false: the swap does not run across a matching.

What does run is what speaks only through arrows. 37a4’s matching-worlds technique carried every statement of a language across a matching that carries its marks. In a category the marks are the arrows.

Arrow-counts-kept technique: if A and B are matched, then for every thing X the arrows from X into A are matched with the arrows from X into B, and those out of A with those out of B.

f : A \to B \text{ undone by } g @@ given (44a3)
u \mapsto f \circ u : C(X, A) \to C(X, B),\ \ v \mapsto g \circ v \text{ back} @@ run f after, or g after
g \circ (f \circ u) = u,\ \ f \circ (g \circ v) = v @@ brackets free, then g ∘ f = id_A, f ∘ g = id_B
\htmlClass{new}{C(X, A) \cong C(X, B) \text{ in } \mathbf{Set}} \quad \blacksquare @@ and the arrows out the same way, running g and f before

So counts of arrows are kept. ℤ/6 and S₃ have six members each, matched in Set. From ℤ × ℤ, 44i2 counted 18 maps into S₃, and into ℤ/6 there are 36, one for each pair of members, since ℤ/6 is turn-about. So they are not matched in Grp. Rung 0’s sameness tells everything; a matching tells exactly what arrows can see.

44·cb0.2Counting runs

Call a counting run a set N with a member z and a function s : N → N. A map of counting runs from (N, z, s) to (M, y, t) is a function f : N → M with f(z) = y and f ∘ s = t ∘ f. These are a category. 4d’s recursion technique says that for ℕ, with 0 and next, and any run (A, u, g), exactly one f has f(0) = u and f(S(n)) = g(f(n)). In the words of 44d, ℕ has exactly one arrow to every counting run: it is the first counting run.

Two runs from 3b.4.4. The next-one run of 3b: z = ∅ and s(x) = x ∪ {x}. The gathering run: z = ∅ and s(x) = {x}, cut down to the smallest set holding ∅ and closed under gathering. Its next is one-to-one, since {x} = {y} gives x = y, and ∅ is no {x}. 4d14 found that one-to-one is exactly what definition by repeating needs, and the rest of 4d’s proof used only that, that z is no next, and smallness. So the gathering run has the property too.

First-run technique: any two counting runs with the recursion property are matched by exactly one map that keeps the start and the next.

(N, z, s),\ (M, y, t) \text{ both with exactly one arrow to every counting run} @@ the recursion property, for each
f : N \to M,\ \ f' : M \to N @@ each has its one arrow to the other
f' \circ f : N \to N \text{ keeps } z \text{ and } s,\ \text{and so does } \mathrm{id}_N @@ composites of maps of runs are maps of runs
f' \circ f = \mathrm{id}_N,\ \ f \circ f' = \mathrm{id}_M @@ exactly one arrow from N to itself, and from M to itself
\htmlClass{new}{N \cong M \text{ by exactly one map of runs}} \quad \blacksquare @@ 44d2’s one-matching technique, turned round

Run it on the two threes. f(∅) = ∅. f({∅}) = {∅}. f({∅, {∅}}) = {{∅}}. f({∅, {∅}, {∅, {∅}}}) = {{{∅}}}. So 3 = {0, 1, 2} in the one run goes to 3 = {2} in the other, and nowhere else: exactly one matching, forced at every step.

44·cb0.3Which is three

Adding and multiplying are built by 4d’s recursion from 0 and next alone (4f, 4g), so the matching of the two runs carries them too. Every statement in the language of 0, next, + and · that is true of one run is true of the other, by 37a4’s matching-worlds technique. That is the whole of arithmetic, and none of it tells the two runs apart.

1 ∈ 3 is true in the next-one run, since 3 = {0, 1, 2}, and false in the gathering run, since 3 = {2} and 1 is not 2. 1 ∈ 3 is a statement in the language of sets, not of counting, and the matching does not carry ∈. So it is not a fact about three.

So the question “which set is three?” has a structure answer. Three is the place after the place after the place after the start, in the first counting run. Each run is one witness that such a run exists, and any two witnesses are matched in exactly one way. A numeral names a place in the first counting run, pinned down by arrows; the set that sits there in a given build is the build’s business. Rung 0’s sameness is not given up. It still says a thing is itself. It is joined by the sameness that matters for things known only by a property: matched in exactly one way that keeps the property.

1 + 2 = 3 \text{ in both runs} @@ 4f’s adding, carried by the matching (matching-worlds, 37a4)
1 \in 3 \text{ in one run},\ \ 1 \notin 3 \text{ in the other} @@ ∈ is not a mark of counting, and the matching does not carry it
\htmlClass{new}{\text{a statement true in one run and false in the other speaks of the build, not of the numbers}} \quad \blacksquare @@ a statement of counting is carried

The basement · there if you want it

The accepted names

A counting run is a pointed set with an endomorphism, or an algebra for the functor X ↦ 1 + X; the first counting run is the initial such algebra, the natural numbers object, and the recursion technique is its universal property. The arrow-counts-kept technique says isomorphisms induce bijections of hom-sets. The answer that a numeral names a position in any structure with the property is structuralism in the philosophy of mathematics, in its ante rem form when the structure is taken to exist apart from its builds.

Who said it first

Ernst Zermelo’s numerals of 1908 are ∅, {∅}, {{∅}}; John von Neumann’s of 1923 are the run of 3b. Paul Benacerraf’s “What numbers could not be” (1965) argued that since both work, a number is neither, and that numbers are not objects at all. Richard Dedekind’s Was sind und was sollen die Zahlen? (1888) proved that any two simply infinite systems are isomorphic and said the numbers are what they share. William Lawvere defined the natural numbers object in 1964. Stewart Shapiro and Michael Resnik developed structuralism in the 1980s and 1990s.

A proof that is not allowed

“Von Neumann’s 3 has three members and is three. Zermelo’s 3 has one member, so it is not three.” Not allowed: “has three members” uses matching with a set of three already in hand, which is 4’s counting, and Zermelo’s 3 is matched with von Neumann’s 3 as places, not as sets. The statement about members speaks of the build; it is true of one build and false of the other, which is the call back’s point.
