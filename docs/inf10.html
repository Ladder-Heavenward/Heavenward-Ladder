What Is a Generating Function the Shadow Of?

What is a generating function the shadow of? Rung 23 stored a list of counts as one function and read the counts back. For structures built on labels, such as orders, trees and groupings, the counts come from something richer: a function that gives, for each finite set of labels, the set of structures on it, and carries every relabelling along. That function is a map of categories, and counting forgets everything but the sizes. Sum, product and putting one kind inside another become the same operations on the storing functions. Rooted trees solve one equation, and the nn−2 trees of rung 42 fall out of counting doubly rooted trees two ways. Two kinds can share a shadow without being the same kind, as orders and shuffles do. The theory dates from 1981; in 2009 a single book collected the dictionary from constructions to how fast counts grow.

A kind F gives a set F[U] for each finite set U and a matching F[σ] for each matching σ : U → V, keeping running in a row. Its shadow is F(x) = Σ fₙ xⁿ/n!, fₙ = |F[{1, …, n}]|. Product: (F · G)(x) = F(x) G(x). Substitution: (F ∘ G)(x) = F(G(x)). Orders 1/(1 − x), sets eˣ, shuffles = sets of cycles. Rooted trees T(x) = x eT(x). Doubly rooted trees and functions [n] → [n] are both nⁿ, so trees number nⁿ⁻².

inf10.1Kinds of Structure

Let B be the category whose things are finite sets and whose arrows are matchings, one-to-one and onto. A kind of structure F is a map of categories from B to sets: a set F[U] of structures on each U, and for each matching σ : U → V a function F[σ] that relabels each structure on U as one on V, with F[τ ∘ σ] = F[τ] ∘ F[σ]. Orders: L[U] is the ways to line U up. Sets: E[U] has one member, U itself. Cycles: C[U] is the ways to seat U round a table.

Size-only technique: for a kind F, the number of structures on U depends only on the size of U.

|U| = |V| \Rightarrow \text{some matching } \sigma : U \to V @@ two finite sets of one size
\sigma^{-1} \circ \sigma = \mathrm{id}_U \Rightarrow F[\sigma^{-1}] \circ F[\sigma] = F[\mathrm{id}_U] = \mathrm{id} @@ F keeps running in a row and the do-nothing
F[\sigma] \text{ is undoable} @@ and the other way round, the same (47a3)
\htmlClass{new}{|F[U]| = |F[V]|} \quad \blacksquare @@ an undoable function matches two sets

So fₙ = |F[{1, …, n}]| is the count: n! orders, 1 set, (n − 1)! cycles for n ≥ 1. The labels are let go; the arrows that relabel carry what matters.

inf10.2The Shadow, and Products

Store a kind’s counts with factorials: F(x) = Σ fₙ xⁿ/n!. Orders give Σ xⁿ = 1/(1 − x); sets give Σ xⁿ/n! = eˣ. By 23j1’s read-back technique the function gives the counts back.

A structure of the product kind F · G on U is a split of U into two parts, with an F-structure on the first and a G-structure on the second.

Product-shadow technique: the shadow of F · G is F(x) G(x).

(F \cdot G)_n = \textstyle\sum_{k} \binom{n}{k} f_k\, g_{n-k} @@ choose the first part’s k labels (4h), then a structure on each part
\tfrac{(F \cdot G)_n}{n!} = \textstyle\sum_k \tfrac{f_k}{k!} \cdot \tfrac{g_{n-k}}{(n-k)!} @@ divide by n!: C(n, k)/n! = 1/(k!(n − k)!)
\textstyle\sum_k \tfrac{f_k}{k!} \tfrac{g_{n-k}}{(n-k)!} = [x^n]\, F(x) G(x) @@ multiplying two stored lists
\htmlClass{new}{(F \cdot G)(x) = F(x)\,G(x)} \quad \blacksquare @@ the factorials are what make products of kinds products of functions

inf10.3A Kind Inside a Kind

A structure of F ∘ G on U is a grouping of U into blocks, a G-structure on each block, and an F-structure on the set of blocks. Its shadow is F(G(x)), told here; the proof sums the product technique over the number of blocks.

Shuffles-are-cycles technique: every shuffle of U is one set of cycles, so S = E ∘ C, and the shadow gives n! shuffles.

C(x) = \textstyle\sum_{n \ge 1} (n-1)!\, \tfrac{x^n}{n!} = \sum_{n \ge 1} \tfrac{x^n}{n} = -\log(1 - x) @@ cycles; the series of 23
E(C(x)) = e^{-\log(1-x)} = \tfrac{1}{1 - x} @@ a set of cycles
\tfrac{1}{1-x} = \textstyle\sum n!\,\tfrac{x^n}{n!} @@ read back
\htmlClass{new}{|S[n]| = n!} \quad \blacksquare @@ follow each label to where the shuffle sends it until it returns: one cycle

inf10.4Same Shadow, Different Kind

Orders and shuffles both have n! structures on n labels, so L(x) = S(x) = 1/(1 − x). Are the kinds the same, matched in a way that every relabelling respects?

Not-the-same-kind technique: for n ≥ 2 there is no matching of L[U] with S[U] that commutes with every relabelling.

\text{the do-nothing shuffle is fixed by every relabelling } \sigma @@ relabelling a shuffle π gives σπσ⁻¹, and σ id σ⁻¹ = id
\text{a relabelling that moves a label fixes no order} @@ it changes who is first somewhere
\text{a matching that commutes would send a fixed shuffle to a fixed order} @@ φ(σ·π) = σ·φ(π)
\htmlClass{new}{\text{no such matching}} \quad \blacksquare @@ no order is fixed by a σ ≠ id

That is 47c3’s V and V* again: matched by counting, not naturally. The shadow keeps the counts and lets the relabelling arrows go; the kind keeps them.

inf10.5Trees Counted Two Ways

A rooted tree is a root with a set of rooted trees hanging from it: T = X · (E ∘ T), where X is the kind with one structure on a single label. So T(x) = x eT(x), and its counts are 1, 2, 9, 64, …, which is nn−1; the general read-back is held in trust.

Two-ways technique: the doubly rooted trees on n labels, trees with an ordered pair of marked dots, are as many as the functions from {1, …, n} to itself, nⁿ; so there are nⁿ⁻² trees.

\text{doubly rooted tree} = \text{the path from mark to mark, with rooted trees hanging} = L \circ T @@ an order of the path’s dots, a tree on each
\text{function } [n] \to [n] = \text{cycles of returning dots, with rooted trees hanging} = S \circ T @@ follow f from each dot until it repeats
L(T(x)) = S(T(x)) = \tfrac{1}{1 - T(x)} @@ same shadow for L and S, put inside T
n^2 \cdot \#\text{trees} = n^{n} \Rightarrow \htmlClass{new}{\#\text{trees} = n^{n-2}} \quad \blacksquare @@ any tree, with any two marks

42b4 matched trees with codes. This count needs only the shadow: L and S are different kinds, but inside T their shadows agree, and that is enough to count. For n = 4: 16 trees and 256 functions.

A short history · told from more than one side

How we got here

Counting trees on n labelled dots, nⁿ⁻², was stated in 1889 after an earlier proof in 1860.

In 1981 a mathematician made it one theory: a kind of structure is a map of categories from finite sets with matchings to sets, and the storing function is its shadow. The same paper gave the proof of nⁿ⁻² by doubly rooted trees and functions.

In 2009 two authors published a book collecting the dictionary from constructions to storing functions, and from the storing functions’ behaviour near their nearest trouble point to how fast the counts grow.

The accepted names

A kind of structure is a combinatorial species; B is the category of finite sets and bijections; the shadow is the exponential generating function; F ∘ G is composition or substitution of species. L, E, C and S are the species of linear orders, sets, cycles and permutations. Groupings counted 1, 1, 2, 5, 15, 52 are the Bell numbers. The two-ways technique is Joyal’s proof of Cayley’s formula. Unlabelled counting uses the cycle index (Pólya theory). The 2009 book is Analytic Combinatorics.

Who said it first

Carl Wilhelm Borchardt (1860) and Arthur Cayley (1889), the count of trees. André Joyal, “Une théorie combinatoire des séries formelles” (1981). Philippe Flajolet and Robert Sedgewick, Analytic Combinatorics (2009).
