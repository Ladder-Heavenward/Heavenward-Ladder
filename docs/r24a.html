24a · proof

A Rule and a Start

Many laws of nature do not say what a quantity is. They say how fast it changes, given where it is now. A bank balance grows at a rate set by the balance. A cup of tea cools at a rate set by how much hotter it is than the room. A rule like that, together with where things start, is a question whose answer is a whole function. This step says exactly what counts as an answer, and settles the simplest case completely: when a quantity grows at a rate equal to itself and starts at one, the only answer is the growth function of the seventeenth rung.

A rule on rates ties a function to its own slope. With a starting value it becomes one question, whose answer is a function. A function that grows at a rate equal to itself and starts at one can only be the growth function.

24a1Rules on Rates

From here on, a rate rule is an equation that ties an unknown function y of x to its slopes, such as y′ = y, y′ = x − y² or y″ = −y. A solution on an open interval I is a function with the slopes the rule mentions at every x in I, making the equation true at every x in I. Accepted name: a differential equation, and its solution.

The order of the rule is the highest slope in it: y′ = x − y² is first order, y″ = −y is second order. Most of this rung is about first-order rules written y′ = F(x, y), where F gives the slope from the place.

y = Ce^{-x^2/2} \Rightarrow y' = -x\,Ce^{-x^2/2} @@ the chain rule (13e)
y' = -xy \text{ at every } x @@ the line above, with y = Ce^{−x²/2}
\htmlClass{new}{y = Ce^{-x^2/2} \text{ solves } y' = -xy \text{ on the whole line, for every } C} \quad \blacksquare @@ ︿ “solution”

A rule alone usually has many solutions: here, one for each C. The rule says how things change, and nothing yet says where they are.

24a2A Rule and a Start

From here on, a start for a first-order rule is a pair (x₀, y₀), and a solution with the start is one with y(x₀) = y₀. The rule and its start together are one question. Accepted name: an initial value problem.

For y′ = −xy the start (0, 3) picks C = 3, since y(0) = C. So among the solutions above, exactly one has that start. But that is only among those. Could some other function, not of that form, also solve the rule from that start? Showing that none can is the hard half of every question on this rung.

Every question about a rule and a start has two halves. Is there a solution? Is there only one? A rule that answers both, for every start, fixes the future from the present. The rest of this rung finds which rules do.

24a3Growth at Its Own Rate

Own-rate technique: for any real k and start (x₀, A), the rule y′ = ky has exactly one solution on the whole line: y = Ae^(k(x − x₀)). Divide any solution by the claimed one and its slope comes out 0.

y = Ae^{k(x-x_0)} \Rightarrow y' = kAe^{k(x-x_0)} = ky,\ \ y(x_0) = A @@ exp′ = exp and the chain rule: there is one
z \text{ solves } z' = kz,\ z(x_0) = A;\ \ g(x) = z(x)e^{-k(x-x_0)} @@ any solution at all, on an interval I holding x₀
g' = z'e^{-k(x-x_0)} - kz\,e^{-k(x-x_0)} = (kz - kz)e^{-k(x-x_0)} = 0 @@ the product rule (13c); z′ = kz
g \text{ is constant on } I,\ g(x_0) = A @@ zero slope means flat (14d)
\htmlClass{new}{z = Ae^{k(x-x_0)} \text{ on } I} \quad \blacksquare @@ multiply by e^{k(x − x₀)}, which is never 0

With k = 1 and the start (0, 1): the only function that grows at a rate equal to itself and starts at 1 is eˣ. Rung 17 built exp; this says nothing else could have done the job. Every quantity that grows or shrinks at a rate in proportion to itself, with nothing else acting on it, is a growth function, and its start and k fix it entirely.

The accepted names

A rate rule is an ordinary differential equation (ODE); a rule and a start is an initial value problem; the order is the order of the equation. The own-rate technique is the uniqueness of exponential growth, the simplest case of the existence and uniqueness theorem proved on 24d.

Who said it first

Isaac Newton wrote rules on rates ("fluxional equations") in 1671, and Gottfried Leibniz and the Bernoulli brothers solved many in the 1690s. Leonhard Euler organized the subject in the 1760s. Augustin-Louis Cauchy, in the 1820s, was the first to ask whether a solution must exist and be unique, and to prove it.
