47b · proof

Maps Between Categories

Rung thirty four took a space and made a group from it, the group of its loops, and a continuous map between spaces gave a map between their groups. Then it used that to tell the circle from a disc: their groups differ, so no same-shape map joins them. The argument worked because the loops kept track of the maps, not only of the spaces. This step names that kind of thing. A map between categories sends each thing to a thing and each arrow to an arrow, and keeps running in a row and doing nothing. Loops are one. Forgetting is another: a group has a set of members, and a map that keeps products is a function. Freeing runs the other way: a set of letters gives the group of words in them, and a function between sets of letters gives a map between the groups, letter by letter. And some maps turn the arrows round, as the readings of a space of vectors do. Each of them carries matched things to matched things, and that one fact is what made rung thirty four’s argument work.

A map between categories sends things to things and arrows to arrows, keeping running in a row and doing nothing. The loop group is one; forgetting a group to its members and freeing a set into words are two more; readings of vectors turn arrows round. A map between categories carries matched things to matched things, so if their values differ, the things were never matched.

47b1Loops, as a Map of Categories

Let C and D be categories. A map F from C to D, written F : C → D, gives each thing A of C a thing F(A) of D, and each arrow f : A → B an arrow F(f) : F(A) → F(B), so that F(g ∘ f) = F(g) ∘ F(f) and F(id_A) = id_F(A). Its accepted name is a functor; the ladder says “map of categories”.

Pointed spaces, a space X with a chosen point x₀, and continuous maps that send the chosen point to the chosen point, are a category Top⋆. 34g2 gave each the loop group π₁(X, x₀) and each map f the product-keeping f∗[γ] = [f ∘ γ]. (g ∘ f)∗[γ] = [(g ∘ f) ∘ γ] = [g ∘ (f ∘ γ)] = g∗(f∗[γ]) by 9b’s brackets, and (id)∗[γ] = [γ]. So π₁ : Top⋆ → Grp is a map of categories.

Matched-to-matched technique: a map of categories carries an undoable arrow to an undoable arrow, so it carries matched things to matched things.

f : A \to B \text{ undone by } g @@ given: g ∘ f = id_A and f ∘ g = id_B
F(g) \circ F(f) = F(g \circ f) = F(\mathrm{id}_A) = \mathrm{id}_{F(A)} @@ F keeps running in a row, then doing nothing
F(f) \circ F(g) = \mathrm{id}_{F(B)} @@ the same two lines the other way round
\htmlClass{new}{A \cong B \Rightarrow F(A) \cong F(B)} \quad \blacksquare @@ F(g) undoes F(f)

Read it as 4e’s contrapositive: if F(A) and F(B) are not matched, A and B are not. The circle has loop group ℤ, by 34g4; a disc, ball or plane has the group with one member, by 34g1. ℤ and a group of one member are not matched, so the circle is the same shape as none of them. That was 34g’s argument. The technique says why it worked: only the two rules of a map of categories were used.

47b2Forgetting and Freeing

Forgetting: U : Grp → Set sends a group to its set of members and a product-keeping map to the same function, with the products forgotten. The two rules hold because ∘ and id in Grp were already the functions’ ∘ and id. The same forgetting runs from Vect, Top and every category of sets with something added.

Freeing: F : Set → Grp sends a set S to the free group F(S) on the letters S, 34i1’s reduced words. A function h : S → T should give a map F(h) : F(S) → F(T). There is an obvious one: write h(s) for each letter s, and h(s)⁻¹ for each s⁻¹. That it is a map, and that the two rules hold, is the presented-map technique of 34i2 with no relations.

Letter-by-letter technique: a function h from S to T gives exactly one product-keeping map F(h) from the free group on S to the free group on T sending each letter s to h(s), and F(k ∘ h) = F(k) ∘ F(h).

F(S) = \langle S \mid \ \rangle @@ the free group is the group named by its letters and no relations (34i2)
\text{exactly one product-keeping } F(S) \to F(T) \text{ with } s \mapsto h(s) @@ the presented-map technique: there are no relations to check
F(k) \circ F(h) \text{ keeps products and sends } s \mapsto k(h(s)) @@ product-keeping after product-keeping
F(k \circ h) \text{ keeps products and sends } s \mapsto k(h(s)) @@ the definition of F(k ∘ h)
\htmlClass{new}{F(k \circ h) = F(k) \circ F(h),\ \ F(\mathrm{id}_S) = \mathrm{id}_{F(S)}} \quad \blacksquare @@ “exactly one”: two maps that agree on the letters are one map

The same goes for spaces of vectors. The free space on S over k is the set of functions from S to k that are 0 at all but finitely many members, added and stretched entry by entry, with the functions that are 1 at one member and 0 elsewhere as a basis (27b). A function between sets sends basis to basis, and 27d1’s columns technique makes it a linear map. Freeing builds the most general thing with given members; forgetting throws the structure away. 47f shows the two are tied together.

47b3Arrows Turned Round

Some constructions send an arrow A → B to an arrow back, from the value at B to the value at A. 27h1’s readings are one. A linear f : V → W gives f* : W* → V*, f*(r) = r ∘ f: a reading of W, taken after f, is a reading of V. The sets of parts are another, read as 34b2 read continuity: a function f : X → Y gives f⁻¹ from the parts of Y to the parts of X, B ↦ the members sent into B.

The turned-round category C^op has the things of C, and one arrow B → A for each arrow A → B of C, with running in a row done in the other order. A map that turns arrows round is a map of categories C^op → D. Its accepted name is a contravariant functor.

Turned-round technique: readings turn arrows round, and running two maps in a row turns into running their readings in the other order: (g ∘ f)* = f* ∘ g*.

f : U \to V,\ g : V \to W,\ r \in W^* @@ linear maps, and a reading of W
\htmlClass{new}{(g \circ f)^* = f^* \circ g^*,\ \ \mathrm{id}_V^{\,*} = \mathrm{id}_{V^*}} \quad \blacksquare @@ 27h1’s turn-round technique

That is 19c1’s socks and shoes again, (h g)⁻¹ = g⁻¹ h⁻¹, at the level of whole maps. Undoing in a group and taking readings both turn the order round, and both are maps from a category turned round.

The accepted names

A map of categories is a functor; one that turns arrows round is a contravariant functor, a functor from the opposite category C^op. The loop group is the fundamental group functor π₁ : Top∗ → Grp. Forgetting is a forgetful functor and freeing a free functor. The matched-to-matched technique says that functors preserve isomorphisms; applied to a functor whose values are numbers, sets or groups, it says that those values are invariants.

Who said it first

Samuel Eilenberg and Saunders Mac Lane named functors in 1945, taking the word from Rudolf Carnap’s Logical Syntax of Language (1934), where it meant something else. Henri Poincaré introduced the fundamental group in Analysis Situs (1895), and used it to tell spaces apart a generation before anyone said it was a functor.

A proof that is not allowed

“The circle and the plane with its centre taken out have the same loop group ℤ, so they are the same shape.” Not allowed: the matched-to-matched technique runs one way. Equal values say nothing. Here the conclusion is false as well: the circle is closed and bounded and the plane with a point out is not, so they differ in 34d’s finitely-many-suffice property, which a same-shape map keeps.
