19b · proof

One identity, one inverse each

19a’s definition said “there is a member e” and “each a has a member a⁻¹”. It never said there was only one. This step proves there is only one way to do nothing, and only one way to undo each move. From those two facts come the rest: cancelling, exactly one answer to every equation that asks what a member must be combined with, and powers that add.

If two members both do nothing, combining them shows they are the same member. If one member undoes from the left and another from the right, regrouping shows they are the same member. So a member can be cancelled from the left of both sides, and an equation asking what to combine with has one answer: combine with the undoer first.

19b1One way to do nothing

Stands on 19a4 (the definition of a group).

Suppose two members both do nothing. Combine them. The first does nothing, so the result is the second. The second does nothing, so the result is the first. So they are the same member.

One-identity technique: a group has exactly one member that does nothing.

e, e' \text{ both do nothing} @@ suppose
ee' = e' @@ e does nothing
ee' = e @@ e′ does nothing
\htmlClass{new}{e = e'} \quad \blacksquare @@ the chain technique for =, through ee′

So “the identity” is a name for one member, and 19a was entitled to say “the”.

19b2One way to undo

Stands on 19b1 and 19a3 (regroup).

Suppose b undoes a from the left and c undoes a from the right. Put a between them, as b(ac). Read it one way and it is b, since ac is e. Regroup and read it the other way, and it is c, since ba is e. So b and c are the same.

One-inverse technique: each member of a group has exactly one inverse. Even an undo from one side only is the inverse.

ba = e,\ \ ac = e @@ suppose
b = be = b(ac) @@ e does nothing; ac = e
b(ac) = (ba)c = ec = c @@ regroup; ba = e
\htmlClass{new}{b = c} \quad \blacksquare @@ chain for =

19b3Cancelling, and one answer

Stands on 19b2.

Cancel technique: in a group, ab = ac gives b = c, and ba = ca gives b = c. Combine both sides with a⁻¹, on the side where a is.

One-answer technique: ax = b has exactly one answer x = a⁻¹b, and xa = b has exactly one answer x = ba⁻¹.

ab = ac \Rightarrow a^{-1}(ab) = a^{-1}(ac) @@ combine both sides on the left with a⁻¹ (one operation, one output)
(a^{-1}a)b = (a^{-1}a)c \Rightarrow \htmlClass{new}{b = c} @@ regroup; a⁻¹a = e
a(a^{-1}b) = (aa^{-1})b = b @@ so x = a⁻¹b is an answer
ax = b = ay \Rightarrow \htmlClass{new}{x = y} \quad \blacksquare @@ cancel: there is no other

Write out a small group’s table, every product in its place. Row a lists ax for every x. By one-answer, every member b appears in row a exactly once. Every row and every column of a group’s table holds each member exactly once.

rx = s_{12} \Rightarrow x = r^{-1}s_{12} = r^2 s_{12} @@ r⁻¹ = r², since r³ = e (19b2)
r^2 s_{12}:\ 1 \mapsto 2 \mapsto 1,\ \ 2 \mapsto 1 \mapsto 3,\ \ 3 \mapsto 3 \mapsto 2 @@ so x = [1 3 2] = s₂₃

19b4Undoing the undo

Stands on 19b2.

a⁻¹ is a move too, so it has an inverse. a undoes it, from both sides: aa⁻¹ = a⁻¹a = e is exactly what that means. By one-inverse, a is the only member that does.

Undo-the-undo technique: (a⁻¹)⁻¹ = a, and e⁻¹ = e.

a^{-1}a = e = aa^{-1} @@ ﹀ a⁻¹
\htmlClass{new}{(a^{-1})^{-1} = a} @@ one-inverse: a undoes a⁻¹ from both sides
ee = e \Rightarrow \htmlClass{new}{e^{-1} = e} \quad \blacksquare @@ e does nothing; one-inverse

19b5Powers, and how soon a move comes back

Stands on 19b3, 4b (definition by induction) and 4e (induction).

From here on, for a in a group and n in ℕ, a⁰ = e and aⁿ⁺¹ = aⁿa, by 4b; and a⁻ⁿ = (a⁻¹)ⁿ. aⁿ is a combined with itself n times.

Powers technique: for all whole numbers m and n, aᵐaⁿ = aᵐ⁺ⁿ. For m, n in ℕ it is induction on n. When one of them is negative, the a’s and a⁻¹’s next to each other cancel in pairs, and what is left is the sum.

a^m a^0 = a^m e = a^m = a^{m+0} @@ n = 0
a^m a^{n+1} = a^m (a^n a) = (a^m a^n) a @@ ﹀ aⁿ⁺¹; regroup
= a^{m+n} a = a^{m+n+1} @@ the induction hypothesis; ︿ aᵐ⁺ⁿ⁺¹
\htmlClass{new}{a^m a^n = a^{m+n}} \quad \blacksquare @@ induction on n (4e)

From here on, if some n ≥ 1 has aⁿ = e, the least such n is the order of a: the fewest times a must be done before it does nothing. In S₃, r has order 3 and s₁₂ has order 2. In ℤ under +, 1 has no order: 1 + 1 + ⋯ + 1 is never 0.

Order-exists technique: in a finite group every member has an order. The powers e, a, a², … cannot all differ, so some aⁱ = aʲ with i < j. Cancel aⁱ, and a^(j − i) = e.

The accepted names

A table in which each row and each column holds each member once is a Latin square. A set with an operation whose table is a Latin square with an identity is a loop. The order of a member is also called its period.

Who said it first

In 19b.4.5, the old book is Euclid's Elements, Book VII, definition 2: “a number is a multitude composed of units”. The engineer is Simon Stevin, in L'Arithmétique (1585).
