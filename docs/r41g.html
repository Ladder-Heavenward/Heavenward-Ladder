41g · proof

Smaller Machines

The tape machine can do everything a recipe can, and so it inherits every refusal: no machine decides what tape machines do. Take some of its power away, and the refusals go away too. A machine that may not write, and may only read from left to right, is a ticket reader or a lock on a door: it can check a pattern, and every question about it can be answered. Give it a pile of marks it can add to and take from the top, and it can check brackets nested without end. Give it a tape no longer than its input, and it can check more again. Each kind of machine answers to a kind of grammar, and the kinds sit one inside the next, a ladder of machines. This step proves the walls between the first rungs of that ladder with one shape of argument, used twice: a long enough string must pass through some state, or some placeholder, twice, and the loop between can be run again as often as you like. Then it shows that every machine below the tape machine stops, so the refusals of this rung begin exactly at the top.

A machine that only reads checks a pattern, and patterns join by and, or and not. In a long string it repeats a state, so the loop can be pumped. A stack machine’s grammar repeats a placeholder, so two loops can be pumped together. Every machine with bounded room stops or is caught looping, so all the families below the tape machine are decided.

41g1A Machine That Only Reads

12·comp built a machine with no memory: finitely many states, a start, some accepting states, and a table that moves from state to state on each letter. It is a tape machine that never writes and always steps right, and stops at the first blank. A set of strings it checks is called a pattern; its accepted name is a regular language. The tables of 1e work on patterns.

Joined-machines technique: if machines with no memory check A and B, then machines with no memory check A and B, A or B, and the strings not in A.

So whether a pattern machine accepts any string at all is decided: look for an accepting state the start can reach, a search through finitely many states. Whether two pattern machines check the same set is decided too: the set where they differ is a pattern, by the technique, and it is empty or not. Every question 41e found undecidable for tape machines is decided for these.

41g2Pumping a Loop

Pumping technique: if a machine with no memory with q states checks L, then every member w of L with at least q letters can be cut as w = xyz, with y not empty and xy at most q letters long, so that xyⁱz is in L for every i ≥ 0.

w = w_1 w_2 \cdots w_m \in L,\ \allowbreak \ m \ge q @@ given
\text{states } s_0, s_1, \dots, s_q \text{ after } 0, 1, \dots, q \text{ letters} @@ q + 1 states named, q states in all
s_j = s_k \text{ for }\allowbreak \text{some } j \lt k \le q @@ pigeonhole (8·cb5)
x = w_1 \cdots w_j,\ \allowbreak \ y = w_{j+1} \cdots w_k,\ \allowbreak \ z = \text{the rest} @@ y takes the machine from s_j back to s_j

41g3A Stack, and Two Loops at Once

A stack machine is a machine with no memory that also keeps a stack: a pile of marks it may add to, or take from, at the top only. It checks the balanced brackets of 12·comp: push at each opening bracket, pop at each closing one, fail if the stack is empty when a pop is needed, and accept when it is empty at the end. Its sets are exactly the sets of strings made by 12·comp’s second family, the grammars with one placeholder on the left of each rule; that is named here and its proof is in the cellar.

Two-loop technique: if a grammar of the second family has p placeholders, and no right side is longer than b ≥ 2, then every string w that the grammar makes and that is longer than bᵖ can be cut as w = uvxyz, with v and y not both empty, so that uvⁱxyⁱz is made by it for every i ≥ 0.

41g4The Ladder of Machines

Each family of 12·comp has its machine: no memory for the first, a stack for the second, a tape no longer than the input for the third, a tape machine for the fourth. The fourth family’s sets are exactly the listed sets. The third’s are below the decided sets.

Bounded-room technique: if a tape machine never uses more than r cells, then whether it stops is decided: it stops within q · r · mʳ steps, or never, where q is its count of states and m its count of marks.

\text{a }\allowbreak \text{configuration }\allowbreak \text{is }\allowbreak \text{a }\allowbreak \text{state, }\allowbreak \text{a }\allowbreak \text{head }\allowbreak \text{place, }\allowbreak \text{and }\allowbreak \text{the } r \text{ cells} @@ 41a1
\text{at most } q \cdot r \cdot m^r \text{ configurations} @@ stages-multiply (4k)
\text{a }\allowbreak \text{run }\allowbreak \text{longer }\allowbreak \text{than }\allowbreak \text{that }\allowbreak \text{repeats }\allowbreak \text{a }\allowbreak \text{configuration} @@ pigeonhole
\text{from }\allowbreak \text{a }\allowbreak \text{repeated }\allowbreak \text{configuration }\allowbreak \text{the }\allowbreak \text{run }\allowbreak \text{repeats }\allowbreak \text{for }\allowbreak \text{ever} @@ the back-again technique (3·comp), with the one-next technique
\htmlClass{new}{\text{run } q \cdot r \cdot m^r \text{ steps: }}\allowbreak \htmlClass{new}{ \text{stopped, }}\allowbreak \htmlClass{new}{ \text{or }}\allowbreak \htmlClass{new}{ \text{never }}\allowbreak \htmlClass{new}{ \text{will}} \quad \blacksquare @@ a decider

A stack machine is not bounded in room, but its stack can be shown never to need to grow past a bound fixed by the grammar for a given input, so it too is decided. So every family below the fourth is decided, and the walls are proper: aⁿbⁿ is in the second family and no pattern (12·comp’s wall, or the pumping technique), aⁿbⁿcⁿ in the third and not the second, and the stopping set in the fourth and not decided. The refusals of 41d live only at the top rung of this ladder.

Standing questions

Harder questions that rely on your own making. The step is complete without them; the rung's angel wings need them.

41g.6.1buildnumbers written in twosBuild a machine with no memory that checks the numerals in twos of the multiples of 5, as a table with its states as remainders. Then build the pair machine for “a multiple of 5 and of 3”, and count its states.

41g.6.3converseShow that every member of L with at least one letter can be pumped, with q = 1. Then prove that L is no pattern, by joining it with a pattern and using the joined-machines technique. What does this say about the pumping technique run backwards?
41g.6.4seamthe rat the cat the dog chased bit ranOne view holds that a language like English needs at least a stack, since its statements nest without end: the rat the cat bit ran; the rat the cat the dog chased bit ran. Another holds that no speaker follows more than two or three nestings, so a machine with no memory, and a large one, describes what people actually say. Which family is English in? Can the question be settled by counting what people say, and if not, by what?

The cellar · there if you want it

The accepted names

A machine with no memory is a deterministic finite automaton, and a pattern is a regular language. The joined-machines technique is the product construction, and the closure of regular languages under intersection, union and complement. The pumping technique is the pumping lemma for regular languages, and the two-loop technique the pumping lemma for context-free languages. A stack machine is a pushdown automaton; its languages are the context-free languages. A tape machine bounded by its input is a linear bounded automaton, for the context-sensitive languages. The ladder of families is the Chomsky hierarchy.

Who said it first

Michael Rabin and Dana Scott (1959) proved the pumping lemma for regular languages in its first form. Yehoshua Bar-Hillel, Micha Perles and Eli Shamir (1961) proved the lemma for context-free languages. Noam Chomsky (1956, 1959) set out the hierarchy, and Marcel-Paul Schützenberger (1963) and Chomsky showed that pushdown automata check exactly the context-free languages. Sige-Yuki Kuroda (1964) matched linear bounded automata with the third family. The centre-embedding of 41g.6.4 was discussed by George Miller and Chomsky (1963).

A proof that is not allowed

“aⁿbⁿ is no pattern: take w to be q a’s and then q b’s, and cut it as x and z empty, y all of w. Then y twice over is not in the set.” Not allowed: the cut must have xy at most q long, and here it is 2q. The machine chooses the cut, and the proof must work for every cut it could choose; for that w every allowed y is made of a’s, and that is what the proof uses.
