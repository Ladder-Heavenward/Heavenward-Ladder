10e · proof

From the Left and From the Right

A neighbourhood of an input has two halves: the inputs just below and the inputs just above. Sometimes a function does one thing on one side and another on the other: the size of a number over the number is negative one left of 0 and one right of it. Sometimes a function only has one side: the square root has no inputs below 0. This step plays the game on one half at a time and gives each half its mark. Then it proves the fifth principle: a function has a limit at an input exactly when both one-sided limits exist and agree. Then it settles what rung 9 could only describe: near 0, one over the input has no limit from either side.

Play the game with half the window. Win on the left and on the right with one value, and the least of the two reaches wins the whole game; get two values, and there is no limit.

10e1Half a Window

10a's neighbourhood of w of reach δ is two intervals, (w − δ, w) and (w, w + δ). Each half gets its own game: the same challenge, the same promise, but only the inputs on one side are asked to keep it. For that, a function need only have inputs on that side.

From here on, let f be a function whose inputs and outputs are reals, defined just right of w: some interval (w, w + r) with r > 0 is a part of dom f. Then lim_{x→w⁺} f(x) = L means: ∀ε > 0 ∃δ > 0 : ∀x ∈ dom f (w < x < w + δ ⇒ |f(x) − L| < ε). Read it “the limit of f(x) as x heads to w from the right is L”, or “from above”. The small high + after w is part of the mark x → w⁺: it is not a power, not a sign of a number, and w⁺ names no real. It says only that the inputs come from the right of w, the greater side.

From here on, let f be defined just left of w: some interval (w − r, w) with r > 0 is a part of dom f. Then lim_{x→w⁻} f(x) = L means: ∀ε > 0 ∃δ > 0 : ∀x ∈ dom f (w − δ < x < w ⇒ |f(x) − L| < ε). Read it “the limit of f(x) as x heads to w from the left is L”, or “from below”. The small high − after w is part of the mark x → w⁻: it is not 5b's negative, not 5c's reciprocal mark, not 9d's inverse, and w⁻ names no real. It says only that the inputs come from the left of w, the lesser side.

Both are called one-sided limits; 10a's is two-sided when the difference matters. 10b's proof works side by side: One-side-one-value technique: a function has at most one limit from the right at w, and at most one from the left. One-limit's column, with the input w + δ/2 (from the right) or w − δ/2 (from the left). ∎ So lim_{x→w⁺} f(x) and lim_{x→w⁻} f(x) name the one-sided limits when they exist, as 10b's line licensed for two sides, and name nothing when they do not. Agreeing-near's column works side by side as well: two functions that agree on (w, w + r) have the same limits from the right.

10e2The Two Sides Agree

Two-sides-agree technique: for f defined near w, lim_{x→w} f(x) = L exactly when lim_{x→w⁻} f(x) = L and lim_{x→w⁺} f(x) = L. One way is free: a promise for the whole neighbourhood is a promise for each half. The other way needs the least of two reaches.

From here on, in this step, δ⁻ and δ⁺ name answers on the left and on the right of w, and L⁻ and L⁺ name limits from the left and from the right. The high mark is part of the name, as it is part of the marks w⁻ and w⁺, and is not a power or a sign.

\text{let } \varepsilon \gt 0;\ \text{call } \delta \text{ for the two-sided line} @@ use the every, then the some
a \lt x \lt a + \delta \;\Rightarrow\; 0 \lt |x - a| \lt \delta @@ x − a is positive, so |x − a| = x − a (8h's line), and it is not 0
\phantom{a \lt x} \Rightarrow\; |f(x) - L| \lt \varepsilon @@ the two-sided promise
\lim_{x \to w^+} f(x) = L,\ \text{and likewise} \lim_{x \to w^-} f(x) = L @@ the same δ serves each side; on the left, |x − w| = w − x
  
\text{let } \varepsilon \gt 0;\ \text{call } \delta^- \text{ for the left},\ \delta^+ \text{ for the right} @@ both one-sided lines at the gap ε (the names δ⁻, δ⁺ by the line above)
\delta = \htmlClass{new}{\min(\delta^-, \delta^+)};\ \ \text{assume } 0 \lt |x - a| \lt \delta @@ the least of the two
x \lt a \;\lor\; a \lt x @@ |x − a| > 0 gives x ≠ a; three-way-order on ℝ (8b)
\text{case } x \lt a:\ \ a - \delta^- \lt x \lt a \Rightarrow |f(x) - L| \lt \varepsilon @@ |x − a| = a − x < δ ≤ δ⁻; the left promise
\text{case } a \lt x:\ \ a \lt x \lt a + \delta^+ \Rightarrow |f(x) - L| \lt \varepsilon @@ x − a < δ ≤ δ⁺; the right promise
|f(x) - L| \lt \varepsilon;\ \ \htmlClass{keep}{\lim_{x \to w} f(x) = L} \quad \blacksquare @@ reasoning by cases; prove an if; speak of everything

Two-sides-differ technique: if lim_{x→w⁻} f(x) = L⁻ and lim_{x→w⁺} f(x) = L⁺ with L⁻ ≠ L⁺, then f has no limit at w. Suppose lim_{x→w} f(x) = L. Two-sides-agree gives L as a limit from each side; one-side-one-value gives L⁻ = L = L⁺; clash. Refute. ∎ No either-way principle is needed: it ends in a denial.

10e3Sides That Disagree

The plainest jump is s(x) = |x|/x, on ℝ ∖ {0}. For x > 0, |x| = x, so s(x) = 1; for x < 0, |x| = −x, so s(x) = −1 (8h's line, by cases). On the right of 0, s agrees with the constant 1, so its limit from the right is 1 (agreeing-near side by side, line-limit with m = 0); on the left, −1. Two-sides-differ: s has no limit at 0. The value at 0 never entered: s has none.

\tfrac{x^2 + x}{|x|} = \tfrac{x\,(x + 1)}{|x|} @@ factor the top (spread on ℚ backwards); the bottom changes its formula at 0
x \gt 0:\ \ |x| = x,\ \ \tfrac{x(x + 1)}{x} = x + 1 \to \htmlClass{new}{1} @@ cancel x ≠ 0; line-limit from the right
x \lt 0:\ \ |x| = -x,\ \ \tfrac{x(x + 1)}{-x} = -(x + 1) \to \htmlClass{new}{-1} @@ negative-out on ℚ, cancel; line-limit from the left
1 \ne -1:\ \ \text{no limit at } 0 @@ two-sides-differ

And sides that agree, around a stray value. Let f(x) = x² for x < 1, f(x) = 2x − 1 for x > 1, and f(1) = 5 (7e's cases). From the left f agrees with x², which heads to 1 at 1 (square-limit); from the right with 2x − 1, which heads to 1 (line-limit). The two sides agree, so two-sides-agree gives lim_{x→1} f(x) = 1, though f(1) = 5. Two formulas glued at a point have a limit there exactly when the two formulas head to the same value. What f does at the point is a separate matter, rung 11's.

10e4Only One Side

√x is defined on [0, ∞): no input is left of 0, so √x is not defined near 0 and 10a's line does not apply there at all. Its right side does. Root-at-0 technique: lim_{x→0⁺} √x = 0. Given ε, answer δ = ε²: for 0 < x < ε², √x < √(ε²) = ε, by powers-keep-order turned back (8f) and √(ε²) = ε for ε > 0. ∎ Here the answer is the square of the challenge, not a multiple of it: near 0 the root climbs fast, so the inputs must come very near. At ε = 0.1 the answer is 0.01; at ε = 0.001 it is 0.000001.

Now the function rung 9 left hanging. 9e said that near 0 the outputs of 1/x pass any bound, and that this was all that could be said without rung 10's words. Here are the first of those words. No-side-at-0 technique: 1/x has no limit from the right at 0, and none from the left.

\lim_{x \to 0^+} \tfrac1x = L @@ assume, to refute
\varepsilon = 1;\ \ \text{call } \delta @@ challenge with 1
x = \htmlClass{new}{\min\!\big(\tfrac{\delta}{2}, \tfrac{1}{|L| + 2}\big)} @@ positive (lesser-below-both); and 0 < x < δ
\tfrac1x \ge |L| + 2 @@ x ≤ 1/(|L| + 2), and positive-reciprocal on ℚ turns the order
\big|\tfrac1x - L\big| \ge \tfrac1x - |L| \ge 2 \gt 1 @@ the reverse form of triangle; order-and-arithmetic-agree
|\tfrac1x - L| \lt 1 \quad \bot @@ the promise at x, against the line above
\neg \lim_{x \to 0^+} \tfrac1x = L \quad \blacksquare @@ refute; every L. From the left, the same with x = −min(δ/2, 1/(|L| + 2))

The challenger's input is the lesser of two: half your reach, to land in your window, and 1/(|L| + 2), to land far enough in that 1/x clears any target around L. Every claimed L loses. 10f gives the outputs' behaviour its own phrase, “passes every bound”, so that it can be said without pretending to be a limit. 10f also names the usual shorthand that writes it as a limit equal to ∞, and why that is not a limit.

10e5The Techniques, Side by Side

Every technique of 10b, 10c and 10d was proved by a column whose only use of the neighbourhood was “take an input in it” and “take the least of the reaches”. Both work on a half-window. Sides-too technique: One-limit (as one-side-one-value), limits-add, limits-subtract, limits-multiply, constant-factor, power-limit, away-from-zero, reciprocal-limit, limits-divide and the squeeze (10d's squeeze-for-sides) are true with x → w⁺ in place of x → w, and likewise with x → w⁻. In each column, the window 0 < |x − w| < δ becomes the half-window w < x < w + δ (or w − δ < x < w), and nothing else changes. ∎ So one-sided limits are computed exactly as two-sided ones are.

\lim_{x \to 0^+} \tfrac{\sqrt x + x}{1 + \sqrt x} @@ √x is defined only on [0, ∞): only the right side exists
\sqrt x \to 0,\ \ x \to 0 \ \text{ from the right} @@ root-at-0; line-limit, side by side
\text{top} \to 0 + 0 = 0,\ \ \text{bottom} \to 1 + 0 = 1 @@ sides-too: limits-add from the right
\lim_{x \to 0^+} \tfrac{\sqrt x + x}{1 + \sqrt x} = \tfrac01 = \htmlClass{keep}{0} @@ sides-too: limits-divide from the right, the bottom heading to 1, not 0

A worked case where both sides exist but use different techniques: let g(x) = √x for x ≥ 0 and g(x) = x² + x for x < 0 (7e's cases). From the right g agrees with √x, which heads to 0 (root-at-0); from the left with x² + x, which heads to 0 (substitution, side by side). The sides agree, and g is defined near 0, so two-sides-agree gives lim_{x→0} g(x) = 0. Here the value g(0) = √0 = 0 happens to match. Change the left piece to x² + 1 and the left limit becomes 1: two-sides-differ, no limit at 0. The work is always the same: name the formula each side uses, take each side's limit with the techniques, compare.

The limits from the two sides are also called the left-hand and right-hand limits, and at a jump they are its two values. A jump at w is a pair of one-sided limits that disagree; its size is |L⁺ − L⁻|. For |x|/x at 0 the size is 2. 10b's two-targets is the reason no single value can stand in for both: any target of half-width at most 1 misses one side's outputs.

10e6Illegal Moves

\lim_{x \to 0} \sqrt{x} = 0\,? @@ √x is not defined near 0: no input on the left. Only the right-hand line applies

10e7Running It Backwards

Handed a function given in pieces, or with an absolute value in it, find where the formula changes, and play each side with the formula that side uses. Handed a claimed limit, check both sides; one side that disagrees, or has no limit, refutes it. Handed a function defined on one side only, use the one-sided line and say so. Found upward; written downward.

Who said it first

In 10e.4.4, the paper of 1807 is Joseph Fourier’s; the critic is Joseph-Louis Lagrange; the proof of 1829 is Peter Gustav Lejeune Dirichlet’s.

Accepted names: the sides-too technique is the limit laws for one-sided limits; two-sides-agree is the criterion for a limit by one-sided limits.
