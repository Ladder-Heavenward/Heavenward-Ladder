Compact Symmetric Maps

A symmetric map of n directions has a right-angled basis it only stretches (31d). With endlessly many directions the promise can fail: some symmetric maps stretch no vector at all. It comes back for maps that squeeze: maps that send every bounded list to one with a settling sub-list. Such a map has stretches that shrink to 0, and its stretched vectors fill the space. This step defines the squeezing maps, proves the largest stretch is reached, and finds the waves sin kx as the axes of undoing a second slope.

A bounded map K is compact if every bounded list fₙ has a sub-list with Kfₙ settling. If K is compact and symmetric on a complete product space, there is a right-angled list of vectors it stretches by λ₁, λ₂, … → 0, and every f is Σ⟨f, eₖ⟩eₖ plus what K loses.

31k1Maps That Squeeze

I e_k = e_k,\ \ \|e_j - e_k\| = \sqrt2 @@ the identity: no sub-list settles
K c = (c_1, \tfrac12 c_2, \tfrac13 c_3, \ldots) @@ each place shrunk by its number
\|Kc - K_n c\| \le \tfrac{1}{n+1}\|c\|,\ \ K_n \text{ keeps the first } n @@ K is near maps of finite dimension
\htmlClass{new}{K \text{ is compact; } I \text{ is not}} @@ bounded lists in n directions have settling sub-lists (22)

Compact technique: a bounded map is compact when it sends every bounded list to a list with a settling sub-list; every limit of maps of finite dimension is compact, and on endlessly many directions the identity is not.

31k2The Largest Stretch Is Reached

\|K\| = \sup_{\|f\| = 1} |\langle Kf, f\rangle| @@ for symmetric maps: split ⟨K(f + g), f + g⟩ as in 27h
\langle Kf_n, f_n\rangle \to \lambda = \pm\|K\|,\ \ \|f_n\| = 1 @@ a list that nearly reaches it
\|Kf_n - \lambda f_n\|^2 \le 2\lambda^2 - 2\lambda\langle Kf_n, f_n\rangle \to 0 @@ multiply out
\htmlClass{new}{Kf_n \text{ settles at } g \Rightarrow f_n \to g/\lambda,\ \ Kg = \lambda g} @@ compactness gives the limit

Square-axes technique: a compact symmetric map on a complete product space stretches some vector by ±‖K‖; repeating at right angles to the vectors found gives a right-angled list e₁, e₂, … with stretches λₖ → 0, and Kf = Σλₖ⟨f, eₖ⟩eₖ for every f. It is 31d’s technique, in endlessly many directions.

31k3Undoing a Second Slope

Kf = u,\ \ Kf(x) = \textstyle\int_0^\pi G(x, y) f(y)\,dy @@ K undoes −u″ with the ends held
G(x, y) = G(y, x) @@ K is symmetric
K \sin kx = \dfrac{\sin kx}{k^2} @@ since −(sin kx / k²)″ = sin kx
\htmlClass{new}{\text{stretches } 1, \tfrac14, \tfrac19, \ldots \to 0;\ \ \text{axes } \sin kx} @@ the waves of a held string

Undoing a second slope with held ends is a compact symmetric map, and its axes are the waves sin kx, so every function on [0, π] is a sum of them. The same technique, for other rate statements, gives the shapes of drums and the energy levels of atoms.

Accepted names

A compact map is a compact operator, a symmetric one self-adjoint; this is the spectral theorem for compact self-adjoint operators, or the Hilbert-Schmidt theorem. G is a Green’s function, and −u″ with held ends is a Sturm-Liouville problem.

Who said it first

David Hilbert (1904 to 1910) and Erhard Schmidt (1907) found the axes of symmetric integral maps; Frigyes Riesz set out compact maps in 1918.
