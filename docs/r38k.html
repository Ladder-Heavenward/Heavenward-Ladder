Truth Cannot Be Defined Inside

Provability from the axioms of arithmetic turned out to be a formula of arithmetic. What about truth? A truth formula would be a formula that is true of the code of a statement exactly when the statement is true of the numbers. The definition of truth on this rung, one clause for each way of building, looks as if it could be written in arithmetic, the way the checks of a proof were. It cannot. Feed the diagonal the denial of a truth formula, and it returns a statement reached as equivalent to “I am not true”: the statement of the first rung, which says of itself that it is not so, now in marks of arithmetic. In the numbers, that statement would be true exactly when it is false. So no formula of arithmetic defines truth in arithmetic. Truth can be defined one level up, in the language of sets, and the same argument then shows that truth for sets needs a level above that. As a gift, the step gives a second road to the last two steps: provability is defined inside, truth is not, so they are not the same.

No formula of arithmetic is true of exactly the codes of the true statements of arithmetic, because the diagonal would turn it into a statement true exactly when it is false. Provability is a formula, truth is not, so some truth is not reached.

38k1What a Truth Formula Would Be

A truth formula for arithmetic would be a formula True(x), with one free placeholder, such that for every statement φ of arithmetic, N ⊨ True(⌜φ⌝) ⇔ φ.

For some statements there is no difficulty. For the statements t = t′ with no placeholders, “the two terms have the same value” is a search formula, by the list-in-one-number technique: some list records the computation of both values. The same works for every bounded statement, since each is settled by a search that stops (4j). The trouble starts with everys and somes that are not kept below anything. 38a3’s clause for ∀x φ asks about every number at once, and the recursion needs the truth of every part of φ under every assignment: a table with endlessly many rows, not a number a formula could hold.

38k2The Liar, in Marks

Undefinable-truth technique: no formula of arithmetic is a truth formula for arithmetic.

\text{True}(x) \text{ is a truth formula} @@ suppose, aiming to refute
PA \vdash \lambda \Leftrightarrow \neg\text{True}(\ulcorner\lambda\urcorner) @@ the self-statement technique (38h2), with ψ(x) = ¬True(x)
N \models \lambda \Leftrightarrow \neg\text{True}(\ulcorner\lambda\urcorner) @@ N is a world of PA (38g2, 38c2)
N \models \text{True}(\ulcorner\lambda\urcorner) \Leftrightarrow \lambda @@ True is a truth formula, at φ = λ
N \models \lambda \Leftrightarrow \neg\lambda @@ swap, on the two lines above
\htmlClass{new}{\bot} \quad \blacksquare @@ 1d’s exactly-when turned into a clash, as 1b.4.4 did: λ and ¬λ cannot share a truth value

1b.4.4 met a statement in words that says of itself that it is not so, and refuted it: there is no such statement. The refutation here is the same, and now it says which part must go. The diagonal is a technique, proved. So the part that goes is the supposed truth formula.

38k3A Second Road to the Unreached

Prov(x) is a formula of arithmetic true of exactly the codes of the statements PA reaches. No formula is true of exactly the codes of the true statements. So the two collections are different. Every statement PA reaches is true (38g2). So some true statement is not reached.

\{\varphi : PA \vdash \varphi\} \text{ is picked out by } \text{Prov}(x) @@ 38h1, and its way back for PA
\{\varphi : N \models \varphi\} \text{ is picked out by no formula} @@ the undefinable-truth technique
\{\varphi : PA \vdash \varphi\} \ne \{\varphi : N \models \varphi\} @@ same members would make Prov a truth formula
\{\varphi : PA \vdash \varphi\} \subseteq \{\varphi : N \models \varphi\} @@ PA reaches only truths
\htmlClass{new}{\text{some true statement is not reached by } PA} \quad \blacksquare @@ a part that is not the whole has an outsider

This road gives no particular statement. 38i built one, U, and showed its denial is not reached either. This road needs no diagonal for ¬Prov. It needs the one for ¬True, and the fact that truth is not a formula. One road ends at a statement, the other at a size: what can be defined is a smaller collection than what is true.

38k4Truth One Level Up

38a3 defined truth in N, and the definition was not circular. It was written in the ladder’s own language, the language of sets. There N is a set, formulas are sets of pairs, and 4d’s recursion builds the truth function, from pairs (φ, s) to T or F, as one set. That set is a member of the world of sets, and the numbers are a small part of it.

\text{in sets: truth for arithmetic is a set, by 4d} @@ the recursion over formulas, with N as a member
\text{in arithmetic: no truth formula for arithmetic} @@ the undefinable-truth technique
\text{in sets: no truth formula for sets} @@ the same diagonal, with codes for formulas of ∈ (38g’s trick, in sets)
\htmlClass{new}{\text{truth for each language is defined in a richer one}} \quad \blacksquare @@ and never in itself

So each language can say what is true in a smaller one and not what is true in itself. The ladder has been doing this all along: every page defined truth for a collection of marks in words, a richer language than any of the marks it described.

The cellar · there if you want it

The accepted names

The undefinable-truth technique is Tarski’s undefinability theorem. λ is the liar sentence. Truth for statements with at most n alternations of quantifiers is definable, by a partial truth predicate of the same complexity; the full truth set is arithmetical at no level. Truth defined one level up is a metalanguage’s truth predicate for an object language. 38k3’s road is the proof of the first incompleteness theorem from undefinability.

Who said it first

Alfred Tarski proved undefinability in the monograph of 1933 on truth in formalized languages; Kurt Gödel had seen it in 1931 and noted it in a letter of that year. The levels answer to the liar is Bertrand Russell’s theory of types (1908) and Tarski’s hierarchy of languages; the rounds answer is Saul Kripke’s theory of truth (1975), with Anil Gupta, Hans Herzberger and Nuel Belnap’s revision theory (1980s); the both-true-and-false answer is dialetheism, argued by Graham Priest from 1979.

A proof that is not allowed

“The liar statement λ is true exactly when it is false. So arithmetic clashes.” Not allowed: λ was built from a supposed formula True, and the clash refutes the supposition. Without a truth formula there is no λ. Arithmetic, and PA, are untouched.
