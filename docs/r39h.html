39h · proof

Memory

The liar had a twin: this statement is true. If it is so, it is so, and if not, not. As a sameness it asks for a mark equal to itself, and both marks meet that, so the logic picks neither. Built as a ring of two not gates, the twin is a ring that cannot run, because the nots cancel in pairs. It rests, and the steep middle that kept the odd ring moving now drives the even ring to one end or the other and holds it there. Which end is whatever it was last made to be. That is a memory of one bit. This step proves it holds, then gives it two doors so that it can be written on purpose: two not-and gates in a ring, each with a spare input, so that a zero on one door sets the bit and a zero on the other clears it. Then a clock is added, so that the bit is taken in only at the instant the clock rises, and a row of such catches, all on one clock, holds a whole number at once. The odd ring keeps time, the even ring keeps a value, and the next steps need both.

Two nots in a ring rise as a whole and rest at either end, and each end holds: one bit. Two not-ands in a ring, with spare inputs, are a latch: a zero on one input sets it, a zero on the other clears it, and ones hold. Two latches, open in turn, catch a bit at the clock’s rise. A row of them is a register.

39h1An Even Ring Holds a Bit

The truth-teller in 39a’s arithmetic is x = x, which both marks meet. In wire it is a ring of two not gates, h = g ∘ g. 26·then5 found its three rests and named the gate-ring technique: an even ring holds one of two states. The difference here is the proof, by the techniques of this rung, and what it says about any even ring.

Even-ring technique: a ring of an even number of not gates with |g′(m)| > 1 rests at the middle and at two patterns of 1s and 0s; the middle pushes and the two patterns hold.

n \text{ even}:\ h = g \circ \cdots \circ g \text{ rises} @@ an even count of falls (39g2)
h(m) = m,\ \ h'(m) = g'(m)^n > 1 @@ the chain technique; |g′(m)| > 1
\text{near } 0:\ h(v) - v > 0;\ \text{at } m^-:\ h(v) - v < 0 @@ h is flat near the ends (39e2: slope near 0.0003) and steep at m
\text{a rest } r_0 \text{ below } m \text{ and } r_1 \text{ above, each with } |h'| < 1 @@ in-between values (12a) on each side
\htmlClass{new}{r_0 \text{ and } r_1 \text{ hold},\ m \text{ pushes}:\ \text{two states that keep}} \quad \blacksquare @@ the pull-together technique (22h3) at the ends; the middle-gain technique at m

Which state the ring is in is set by its history, not by its logic: x = x is true of both. When the power comes on the ring sits near m, noise tips it, and it falls to an end and stays. To use it, it must be told which end.

39h2A Latch, With Two Doors

Replace each not of the ring with a not-and, and give each a spare input: the doors s and r. The outputs are Q and its partner P, with Q = nand(s, P) and P = nand(r, Q). A not-and with one input at 1 is a not, since nand(1, y) = 1 − y.

Hold-row technique: with both doors at 1 the latch is an even ring and keeps its bit; s = 0 sets Q to 1, r = 0 clears Q to 0; both at 0 is not used.

s = r = 1:\ \ Q = 1 - P,\ \ P = 1 - Q @@ nand(1, y) = 1 − y: a ring of two nots, the even-ring technique
s = 0:\ \ Q = \mathrm{nand}(0, P) = 1 @@ 1 − 0 · P = 1, whatever P was
\text{then } P = \mathrm{nand}(r, 1) = 1 - r = 0 \text{ when } r = 1 @@ the partner follows
r = 0:\ \ P = 1,\ \ Q = \mathrm{nand}(s, 1) = 0 \text{ when } s = 1 @@ the same, the other way
\htmlClass{new}{s = r = 0:\ Q = P = 1:\ \text{not a bit; and on release both race}} \quad \blacksquare @@ so that row is kept out by design

Set, then hold: a 0 on s for a moment, then s back to 1, and Q stays 1. The moment of the 0 has been remembered. The row both-at-0 is the latch’s move to watch out for: it gives Q and P the same value, and when both doors open together the ring tips whichever way noise says.

39h3Catching a Bit at an Edge

Feed the doors from a data wire d and an enable wire e: s = nand(d, e) and r = nand(¬d, e). When e = 1, s = 1 − d and r = d, so Q follows d. When e = 0, both doors are 1, and Q holds. That is a gated latch: open while e is 1, shut while it is 0. It is still open for a whole stretch. To take a bit at one instant, put two in a row, the first open while the clock c is 0 and the second open while c is 1. This e is not 17e's number e.

Edge-catch technique: two gated latches in a row, the first enabled by not c and the second by c, take the value of d at the moment c rises from 0 to 1, and hold it until the next rise.

c = 0:\ \text{first latch open, follows } d;\ \text{second shut, holds} @@ e₁ = 1 − c = 1, e₂ = c = 0
c \text{ rises}:\ \text{first shuts on the last } d,\ \text{second opens} @@ the first holds what d was at the rise
c = 1:\ \text{second follows the first, which no longer moves} @@ changes of d now reach only the shut first latch
c \text{ falls}:\ \text{second shuts on that value, first opens} @@ the output still holds
\htmlClass{new}{\text{the output changes only at a rise, to } d \text{ as it was then}} \quad \blacksquare @@ every stretch of the clock checked

The clock is the odd ring of 39g, or a crystal steadied by one. Between rises the gates may wobble as they settle. At the rise, everything that has settled is caught at once. A design works if every path from one catch to the next settles in less than one period: 39i counts how long an adder takes for exactly this reason.

39h4A Row of Catches

Put n edge-catches side by side on one clock. Each holds one bit; together they hold a numeral in twos of n places (4i14).

Register-count technique: a row of n edge-catches on one clock holds any one of 2ⁿ patterns, and takes a new one only at a rise.

\text{each catch: } 2 \text{ states, held independently} @@ the edge-catch technique, one per place
2 \cdot 2 \cdots 2 = 2^n \text{ patterns} @@ the product technique (4k)
n = 64:\ \ 2^{64} \approx 1.8 \cdot 10^{19} @@ every number from 0 to 2⁶⁴ − 1 in twos
\htmlClass{new}{\text{a register of } 64 \text{ catches holds any number below } 2^{64}} \quad \blacksquare @@ the place-value technique in twos

A row of catches whose input is its own output plus 1 counts: at each rise it takes the next number. That needs an adder, which 39i builds. A memory of many rows, each with a number of its own to pick it out, is what 39j’s machine reads its list from.

The accepted names

A ring of two inverters is a bistable element; with two doors it is an SR latch (set–reset), here built of NANDs with doors active at 0. With data and enable it is a gated D latch, and two in a row, opened in turn by the clock, are a master–slave D flip-flop, which is edge-triggered. A row of flip-flops on one clock is a register. The undecided state of 39h.6.2 is metastability, and two flip-flops in a row are a synchronizer.

Who said it first

William Eccles and Frank Jordan built the trigger circuit, two valves in a ring holding one of two states, in 1918. Registers of such circuits held numbers in the ENIAC (1945). Static memory cells of six transistors, the even ring with two doors, have been the fast memory of chips since the 1960s. The latch’s undecided state was studied by Thomas Chaney and Charles Molnar in 1973, who showed that no catch can bound its deciding time.

A proof that is not allowed

“A latch stores a bit, so its output is a function of its inputs: Q = f(s, r).” Not allowed: on the row s = r = 1 both Q = 0 and Q = 1 are possible. Q is a function of the inputs and the latch’s past, which is what memory is. Rung 9’s functions give single values; a latch needs its history as one more input.
