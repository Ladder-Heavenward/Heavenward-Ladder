39h · proof

How long and how much room

A question a machine can answer is not yet a question anyone can answer. Rung thirty eight counted the steps of programs and sorted the counts into families; a count that grows like a power of the input’s length is one thing, a count that doubles with each extra letter is another, and the gap between them is the gap between a second and the age of the universe. This step turns those counts into classes of questions. The questions decided in a number of steps that is a power of the length are the ones called fast, and the class does not care which kind of machine counts. Then comes a stranger class: questions whose yes answers come with a short certificate that can be checked fast, though nobody knows how to find one fast. A whole crowd of everyday questions is in it, and in 1971 it was shown that one of them, whether a statement built from letters with and, or and not can be made true, holds all the others inside it. Whether that one is fast is open. What is not open: more time answers more questions, and room is cheaper than time, since halving a search can save almost all of the room it needs.

Fast means a power of the length, on any machine. A certificate class holds the questions whose yes answers can be checked fast; making a statement true holds them all. More time decides more. Room can be halved over and over: reaching one state from another needs only the square of the room of one state.

39h1Fast, on any machine

A machine runs within t(n) steps when on every input of length n it stops after at most t(n) steps. A set is fast when some machine decides it within some power of n, nᵏ steps for a fixed k. The fast sets form the class P. Balanced brackets are fast, by a walk with a counter; a list is sorted fast, by 38l, in about n log₂ n comparisons.

Power-stays technique: whether a set is fast does not depend on how many tapes the machine has, and a fast machine whose output is fed to a fast machine makes a fast machine.

k \text{ tapes, }\allowbreak \text{within } n^a \text{ steps} \Rightarrow \text{one }\allowbreak \text{tape, }\allowbreak \text{within }\allowbreak \text{about } n^a(n + n^a) @@ the tracks technique (39a3)
n^a(n + n^a) \le 2n^{2a} \text{ for } a \ge 1 @@ a power of n still
\text{first }\allowbreak \text{machine }\allowbreak \text{within } n^a\text{: }\allowbreak \text{its }\allowbreak \text{output }\allowbreak \text{has }\allowbreak \text{at }\allowbreak \text{most } n^a \text{ letters} @@ it writes at most one cell a step
\text{second, }\allowbreak \text{within } m^b \text{ on }\allowbreak \text{that }\allowbreak \text{output: }\allowbreak \text{at }\allowbreak \text{most } (n^a)^b = n^{ab} @@ 4g’s powers of powers
\htmlClass{new}{\text{a }}\allowbreak \htmlClass{new}{ \text{power }}\allowbreak \htmlClass{new}{ \text{of } n \text{, }}\allowbreak \htmlClass{new}{ \text{either }}\allowbreak \htmlClass{new}{ \text{way}} \quad \blacksquare @@ the class P is the same for every machine of 39a3

So P is not about a machine. It is about a growth family, 38k’s powers, kept apart from 38k’s doublings. A count of n¹⁰⁰ is fast by this line and useless by any clock, and a count of 1.0001ⁿ is slow by it and fine for every n anyone meets. The line is drawn at powers because powers stay powers when machines are swapped and run in a row, and because the questions that are fast in practice turned out to have small powers.

39h2Checking a certificate

A statement built from letters with ∧, ∨ and ¬, like (P ∨ Q) ∧ (¬P ∨ R) ∧ ¬Q, is satisfiable when some row of its 1e table makes it true. With n letters the table has 2ⁿ rows. But a row that works, P true, Q false, R true, is checked in one pass along the statement.

A set A is in NP when there are a fast checker C and a power p such that x is in A exactly when some string c no longer than p(|x|) makes C say yes on x # c. The string c is a certificate. Satisfiable statements are in NP, with a row as the certificate. So are maps whose regions can be given three colours with neighbours different, with the colouring as the certificate, and composite numbers, with a factor. Every fast set is in NP, with the empty certificate.

Certificate-search technique: every set in NP is decided within 2 to the power of a power of n steps.

x \text{ of }\allowbreak \text{length } n @@ given
\text{at most } 2^{p(n) + 1} \text{ strings } c \text{ no }\allowbreak \text{longer }\allowbreak \text{than } p(n) @@ 4k, strings of 0s and 1s of each length
\text{run } C \text{ on } x \# c \text{ for }\allowbreak \text{each, }\allowbreak \text{within } (n + p(n) + 1)^a \text{ steps} @@ C is fast
\htmlClass{new}{\text{at most } 2^{p(n)+1}(n + p(n) + 1)^a \text{ steps }}\allowbreak \htmlClass{new}{ \text{in }}\allowbreak \htmlClass{new}{ \text{all}} \quad \blacksquare @@ yes at the first c that works

That is 2ⁿ times something for satisfiability. It decides, and it is slow. Whether every set in NP is fast, whether P equals NP, is the question of 39·now2.

39h3One question holds them all

A set A fast-reduces to B when 39e1’s f is computed fast. Then a fast decider for B gives a fast one for A, by the power-stays technique. A set in NP that every set in NP fast-reduces to is NP-complete.

Tableau technique: every set in NP fast-reduces to the satisfiable statements.

C \text{ checks } A \text{ within } t = n^a \text{ steps; }\allowbreak \text{write }\allowbreak \text{its }\allowbreak \text{run }\allowbreak \text{as }\allowbreak \text{a }\allowbreak \text{table }\allowbreak \text{of } t \text{ rows of } t \text{ cells} @@ row i is the configuration after i steps (39a1)
\text{letters: } X_{i,j,s}\text{, “row } i\text{, cell } j \text{ holds } s\text{”, }\allowbreak \text{for }\allowbreak \text{marks }\allowbreak \text{and }\allowbreak \text{states} @@ about t² · |Γ ∪ Q| letters
\text{each }\allowbreak \text{cell }\allowbreak \text{holds }\allowbreak \text{exactly }\allowbreak \text{one: }\allowbreak \text{an }\allowbreak \text{or }\allowbreak \text{of }\allowbreak \text{its }\allowbreak \text{letters, }\allowbreak \text{and } \neg(X \land X') \text{ for }\allowbreak \text{each }\allowbreak \text{pair} @@ a fixed number of short pieces per cell
\text{row 0 is } x \# \text{ and }\allowbreak \text{then }\allowbreak \text{free }\allowbreak \text{cells }\allowbreak \text{for } c @@ the certificate is left to the row
\text{each }\allowbreak \text{window }\allowbreak \text{of } 2 \times 3 \text{ cells }\allowbreak \text{obeys }\allowbreak \text{the }\allowbreak \text{table} @@ the one-next technique: a cell is fixed by the three above it; a finite list of allowed windows
\text{some }\allowbreak \text{row }\allowbreak \text{holds }\allowbreak \text{the }\allowbreak \text{yes }\allowbreak \text{state} @@ one long or
\htmlClass{new}{\text{the }}\allowbreak \htmlClass{new}{ \text{statement }}\allowbreak \htmlClass{new}{ \text{is }}\allowbreak \htmlClass{new}{ \text{satisfiable} \iff \text{some } c \text{ makes } C \text{ say yes} \iff x \in A} \quad \blacksquare @@ about t² pieces, written fast from x

So satisfiability is NP-complete. If it is fast, every set in NP is fast. 39k carries it to colouring maps with three colours, and since then thousands of questions, from packing boxes to folding chains, have been proved NP-complete the same way. A fast method for any one of them would be a fast method for all.

39h4More time answers more

More-time technique: for each k, some set is decided within a power of n steps and by no machine within nᵏ steps.

D\text{: on } \langle M\rangle \# 0^m \text{ of }\allowbreak \text{length } n\text{, }\allowbreak \text{run }\allowbreak \text{U }\allowbreak \text{on } \langle M\rangle \# \langle M\rangle \# 0^m \text{ for } n^{k+1} \text{ steps} @@ a counter stops U; D is within a power of n
\text{if }\allowbreak \text{U }\allowbreak \text{shows }\allowbreak \text{that } M \text{ said }\allowbreak \text{yes, }\allowbreak \text{say }\allowbreak \text{no; }\allowbreak \text{otherwise }\allowbreak \text{say }\allowbreak \text{yes} @@ the opposite, as in 39d2
M \text{ decides } D\text{’s }\allowbreak \text{set }\allowbreak \text{within } n^k @@ suppose it
U \text{ needs }\allowbreak \text{at }\allowbreak \text{most } c_M n^k \text{ steps }\allowbreak \text{per }\allowbreak \text{run }\allowbreak \text{of } M\text{, and } c_M n^k \lt n^{k+1} \text{ once } n \gt c_M @@ the universal technique, with the padding 0ᵐ making n large
\text{on }\allowbreak \text{that }\allowbreak \text{input } D \text{ sees } M\text{’s }\allowbreak \text{answer }\allowbreak \text{and }\allowbreak \text{says }\allowbreak \text{the }\allowbreak \text{opposite} @@ M and D disagree
\htmlClass{new}{\bot} \quad \blacksquare @@ refute

The padding is the trick. D cannot beat M on short inputs, where U is slow; it beats M on one long enough input, and one is all it needs. The same diagonal, with 2ⁿ in place of nᵏ⁺¹, gives a set decided within 2ⁿ steps and not fast: the doublings outreach the powers. And the diagonal cannot tell P from NP. It works equally for machines given any free question, as 39d.5.3 did, and 39·now2 says why that matters.

39h5Room, saved by halving

A machine runs in room s(n) when it never uses more than s(n) cells. The sets decided in a power of n cells form the class PSPACE. Every set in NP is in it: try the certificates one at a time, reusing the same cells, so the room is p(n) for the certificate and the checker’s room, never 2 to the power p(n).

Halving-room technique: if a list of N states has a fast test of which state may follow which, then whether state u leads to state v is decided in room about (log₂ N)² cells times the room of one state.

\text{reach}(u, v, 1)\text{: } u = v \text{ or } v \text{ may }\allowbreak \text{follow } u @@ one test
\text{reach}(u, v, 2^k) \iff \text{some } w \text{ has }\allowbreak \text{reach}(u, w, 2^{k-1}) \land \text{reach}(w, v, 2^{k-1}) @@ a path of 2ᵏ steps has a middle state
\text{try each } w \text{ in }\allowbreak \text{turn; }\allowbreak \text{for }\allowbreak \text{each, }\allowbreak \text{check }\allowbreak \text{the }\allowbreak \text{halves }\allowbreak \text{one }\allowbreak \text{after }\allowbreak \text{the }\allowbreak \text{other, }\allowbreak \text{reusing }\allowbreak \text{their }\allowbreak \text{room} @@ 38m’s halving, with the halves done in a row, not side by side
\text{each }\allowbreak \text{level }\allowbreak \text{keeps } u, v, w\text{: }\allowbreak \text{three }\allowbreak \text{states; } \log_2 N \text{ levels} @@ a path between states need not be longer than N
\htmlClass{new}{\text{room: }}\allowbreak \htmlClass{new}{ \text{about } 3 \log_2 N \text{ states}} \quad \blacksquare @@ the time is enormous; the room is small

For a machine in room s, a state is a configuration, and there are about mˢ of them, so log₂ N is about s log₂ m: reaching is decided in room about s². That gives the named result that a machine allowed to guess its moves in room s needs no more than room s² without guessing. Room can be reused; time cannot. P sits in NP, NP in PSPACE, PSPACE in the sets decided within 2 to a power of n, and of those four steps only the first and last are known to differ.

The basement · there if you want it

The accepted names

Running within t(n) steps is time complexity, and the classes are TIME(t(n)), with P the union over k of TIME(nᵏ). The certificate classes are NP (nondeterministic polynomial time); a certificate is a witness. Satisfiability is SAT, fast reductions are polynomial-time (Karp) reductions, and the tableau technique is the Cook–Levin theorem. The more-time technique is the time hierarchy theorem, and the set decided within 2ⁿ and not fast shows P ≠ EXPTIME. The room classes are SPACE(s(n)) and PSPACE, and the halving-room technique gives Savitch’s theorem, NSPACE(s) ⊆ SPACE(s²).

Who said it first

Juris Hartmanis and Richard Stearns (1965) defined time classes and proved the hierarchy. Alan Cobham (1965) and Jack Edmonds (1965) proposed polynomial time as the mark of a feasible algorithm. Stephen Cook (1971) proved SAT NP-complete, and Leonid Levin found it independently in the Soviet Union (published 1973). Richard Karp (1972) gave 21 NP-complete problems, three-colouring among them. Walter Savitch proved his theorem in 1970. Manindra Agrawal, Neeraj Kayal and Nitin Saxena (2002) showed primes are in P; Vaughan Pratt (1975) had shown that primes have short certificates.

A proof that is not allowed

“Satisfiability needs 2ⁿ steps, since a statement with n letters has 2ⁿ rows and each row might be the one.” Not allowed: it proves that one method, trying rows, needs them. A cleverer method might never look at most rows. Every known method still takes about cⁿ steps for some c > 1 on its worst inputs, and that is evidence, not proof.
