17·∎ · conclusion

An area turns multiplying into adding

The area under 1/t from 1 to x is a function, ln, and it turns a product of inputs into a sum of outputs. Run backwards, it gives a function that is its own slope, and powers for every real exponent.

The conclusion · the rung's claim, in full, and its proof

This page opens once every question on 17g pˣ for any real x is ticked. The claim below is proved from the steps of this rung, so it waits for them.

What the rung set out to show

The survey of rung 17 promised to name the area function rung 16 left unnamed, the area under 1/t, and to show that it turns multiplying into adding. 17a defined ln x = ∫₁ˣ dt/t, proved that it is 0 at 1 and rises, and caught it between 1 − 1/x and x − 1. 17b found its slope, 1/x, by area-slope, and filled the table's missing entry. 17c proved by same-slopes that ln(xy) = ln x + ln y, with quotients and rational powers after it.

17d sent ln past every height, both ways, and made it a bijection from (0, ∞) onto ℝ. 17e named the function that runs it backwards, exp, and the number e = exp 1. 17f proved that exp is its own slope, and the only such function up to a constant factor. 17g defined pˣ = exp(x ln p) for every real x, and checked it against rung 8's powers. This page states the claim and joins those steps.

The claim, in full

The area under 1/t from 1 to x, named ln x, turns multiplying into adding: ln(xy) = ln x + ln y for all positive x and y.

For x > 0, let ln x = ∫₁ˣ dt/t.

Then ln has slope 1/x at every x > 0, and ln(xy) = ln x + ln y for all x, y > 0.

ln is a bijection from (0, ∞) onto ℝ.

The function that undoes it, exp, turns adding into multiplying: exp(x + y) = exp x · exp y.

exp is its own slope: exp′ = exp.

For p > 0 and every real x, pˣ = exp(x ln p) is rung 8's pˣ wherever rung 8 gave one, and pˣ⁺ʸ = pˣpʸ.

The proof

\ln'(x) = \tfrac1x \text{ for } x \gt 0 @@ area-slope (16b): 1/t is continuous on (0, ∞) (one-over-x-is-continuous); slope-of-log (17b)
\text{fix } y \gt 0;\ \ g(x) = \ln(xy) \text{ for } x \gt 0 @@ xy > 0, so g has a value
g'(x) = \tfrac{1}{xy}\cdot y = \tfrac1x = \ln'(x) @@ chain for slopes (13e): the inside xy has slope y
g(x) = \ln x + C \text{ on } (0, \infty) @@ same-slopes (14e): same slopes on an interval, same shape lifted
x = 1:\ \ \ln y = 0 + C @@ ln 1 = 0 (log-rises, 17a)
\htmlClass{new}{\ln(xy) = \ln x + \ln y} \quad \blacksquare @@ C = ln y, for each y: log-of-a-product (17c)
  
\ln 2^n = n\ln 2 \ge \tfrac{n}{2},\ \ \ln 2^{-n} \le -\tfrac{n}{2} @@ log-bounds (17a) gives ln 2 ≥ ½; log-of-a-power (17c)
\text{real } c,\ \tfrac{n}{2} \gt |c|:\ \ \ln 2^{-n} \lt c \lt \ln 2^n @@ counting-passes-any-real (8e) finds such an n
\text{some } x \in (2^{-n}, 2^n) \text{ has } \ln x = c @@ ln is continuous (slope-means-no-gap); in-between-value, general form (12a)
\text{no second input has } \ln = c @@ log-rises: two different inputs have different logs
\htmlClass{new}{\ln:\ (0, \infty) \to \mathbb{R} \text{ is a bijection}} \quad \blacksquare @@ log-onto-ℝ (17d)

So ln can be run backwards. exp x is the one positive number whose ln is x.

a = \exp x,\ \ b = \exp y:\ \ \ln a = x,\ \ \ln b = y @@ exp undoes ln (inverse-is-a-bijection, 9d)
\ln(ab) = x + y @@ the first part
\htmlClass{new}{\exp(x + y) = \exp x \cdot \exp y} @@ ab is the one positive number whose ln is x + y: adding-becomes-multiplying (17e)
\exp'(x) = \dfrac{1}{\ln'(\exp x)} = \dfrac{1}{1/\exp x} @@ inverse-slope (13l): ln is continuous and rises, and its slope 1/y is not 0
\htmlClass{new}{\exp'(x) = \exp x} \quad \blacksquare @@ slope-of-exp (17f)
  
p^x = \exp(x\ln p),\ \ p \gt 0 @@ ﹀ pˣ (17g), for every real x
r \text{ rational}:\ \ \exp(r\ln p) = \exp(\ln p^r) = p^r @@ log-of-a-power; exp undoes ln: powers-agree (17g)
p^{x+y} = \exp(x\ln p)\exp(y\ln p) = \htmlClass{new}{p^x p^y} \quad \blacksquare @@ spread on ℝ, then the third part: real-exponent (17g)

Every part leans on the first, and the first leans on two older techniques. Area-slope made 1/x a slope, and same-slopes turned equal slopes into one function lifted. The area did the rest.
