11b · proof

Sums and Products

If two functions are continuous at an input, so are their sum, their difference and their product, and so is their quotient when the bottom's value there is not 0. The proofs are rung 10's limit techniques, with the values standing where the limits stood. Each technique says a limit of a combination is the combination of the limits. Continuity says each limit is a value. So the combination's limit is the combination's value. This step proves all of it, once from 10c's techniques and once directly from the game. Then it settles a question rung 9 raised: one over the input is continuous wherever it is defined.

Continuity is a limit that equals a value. The limit techniques carry limits through adding, multiplying and dividing; the values ride along; so continuity rides along too, with one condition: never divide by a value that is 0.

11b1Values Ride Along

10c built the functions f + g, f − g, fg, cf, f/g and fⁿ out of f and g, each on its own domain, and proved that their limits are the sums, products and quotients of the limits. Continuous-sums technique: if f and g are continuous at w, then f + g and f − g are continuous at w, and so is cf for every real c.

f, g \text{ defined near } w;\ \ w \in \operatorname{dom} f \cap \operatorname{dom} g @@ the definition (11a), unpacked for each
f + g \text{ defined near } w;\ \ w \in \operatorname{dom}(f + g) @@ 10c's line: dom (f + g) = dom f ∩ dom g; reach min(r_f, r_g) by lesser-below-both
\lim_{x \to w} (f + g)(x) = \htmlClass{keep}{f(w)} + \htmlClass{keep}{g(w)} @@ limits-add (10c), with L = f(w) and M = g(w): each limit is a value
= \htmlClass{new}{(f + g)(w)} \quad \blacksquare @@ 10c's line for f + g, at the input w. It lands where it was headed

The difference is the same column with 10c's limits-subtract, and cf with constant-factor (its domain is dom f). Nothing new was proved: limits-add had done the work, and continuity only asked that the limits it was given be values.

11b2The Same, Directly From the Game

11a's continuity-unpacked lets the proof be played with the input included. It is a little simpler than limits-add's, because there is no input to leave out and no reach to stay inside. Every input of f + g is an input of both, so both promises apply to it.

\text{let } \varepsilon \gt 0;\ \text{call } \delta_1 \text{ for } f,\ \delta_2 \text{ for } g \text{ at the gap } \htmlClass{new}{\tfrac{\varepsilon}{2}} @@ continuity-unpacked for f and for g: a budget of half the gap each (10c)
\delta = \min(\delta_1, \delta_2);\ \ x \in \operatorname{dom}(f + g),\ |x - w| \lt \delta @@ the least of the two; x is an input of f and of g
\begin{gathered}|(f + g)(x) - (f + g)(w)|\\ = |(f(x) - f(w)) + (g(x) - g(w))|\end{gathered} @@ the line for f + g; negative-of-a-sum and middle-swap: regroup
\begin{gathered}\le |f(x) - f(w)| + |g(x) - g(w)|\\ \lt \tfrac{\varepsilon}{2} + \tfrac{\varepsilon}{2} = \htmlClass{keep}{\varepsilon} \quad \blacksquare\end{gathered} @@ triangle; both promises; same-direction-add

11b3Products and Powers

Continuous-products technique: if f and g are continuous at w, then fg is continuous at w, and so is fⁿ for every number n. fg is defined near w, with w an input, as for f + g. 10c's limits-multiply, with L = f(w) and M = g(w), gives lim_{x→w} (fg)(x) = f(w)g(w) = (fg)(w). For powers, 10c's power-limit gives lim fⁿ = f(w)ⁿ, which is fⁿ(w). Or run 4c's induction with continuous-products itself: f⁰ is the constant 1, continuous by lines-are-continuous, and f^S(n) = fⁿ · f. ∎

Played directly from the game, the product needs everything limits-multiply needed. The split f(x)g(x) − f(w)g(w) = f(x)(g(x) − g(w)) + g(w)(f(x) − f(w)) still has a wild factor, f(x), and bounded-near's first promise still tames it: |f(x)| < |f(w)| + 1 near w. The answer is still the least of three reaches. Continuity changes the target, not the work.

\delta_1:\ |f(x)| \lt |f(w)| + 1 @@ bounded-near, at the gap 1: the first promise
\delta_2:\ |g(x) - g(w)| \lt \tfrac{\varepsilon}{2(|f(w)| + 1)} @@ half the budget, over the ceiling of the other factor
\delta_3:\ |f(x) - f(w)| \lt \tfrac{\varepsilon}{2(|g(w)| + 1)} @@ the other half; |g(w)| + 1 is never 0
\delta = \htmlClass{keep}{\min(\delta_1, \delta_2, \delta_3)} @@ every promise at once, the input a included

11b4A Recipe, Assembled

The techniques say a product of continuous functions is continuous without playing a round. But each technique's column is also a recipe, and the recipes assemble, as 10g6 combined them. Take x³ at 2, as the product of f(x) = x and g(x) = x², with f(2) = 2 and g(2) = 4, and let the challenger name ε = 0.5.

\delta_1:\ |x| \lt |2| + 1 = 3 @@ bounded-near at the gap 1 for f(x) = x: line-limit's answer to 1 is 1
\delta_2:\ |x^2 - 4| \lt \tfrac{0.5}{2 \cdot 3} = \tfrac{1}{12} @@ budget over the ceiling of the other factor; square-limit's recipe at 2: min(1, (1/12)/5) = 1/60
\delta_3:\ |x - 2| \lt \tfrac{0.5}{2 \cdot 5} = 0.05 @@ the other budget, over |g(2)| + 1 = 5; line-limit: 0.05
\delta = \min(1, \tfrac{1}{60}, 0.05) = \htmlClass{keep}{\tfrac{1}{60}} @@ the least of several
\big(2 + \tfrac{1}{60}\big)^3 - 8 \approx 0.2017 \lt 0.5 @@ a check at the window's edge, as a number: it lands well inside

The recipe is cautious, as recipes are: the largest reach that wins here is near 0.04, more than twice 1/60. The proof never needed the largest; it needed one that works, named before any input is handed over, as 10g7's write-up named it. Continuity, proved by the technique, guaranteed that such a reach exists for every ε; the recipe shows one.

11b5Quotients, When the Bottom’s Value Is Not 0

Continuous-quotients technique: if f and g are continuous at w and g(w) ≠ 0, then f/g is continuous at w. The quotient's domain leaves out every input where g is 0. So two things must be checked before 10c's limits-divide can be used: that w is an input of f/g, and that f/g is defined near w.

g(w) \ne 0,\ \ \lim_{x \to w} g(x) = g(w) @@ given; g is continuous at w
\text{call } \delta_1:\ |g(x)| \gt \tfrac{|g(w)|}{2} \gt 0 @@ away-from-zero (10c), with M = g(w) ≠ 0: g is not 0 near w
f/g \text{ defined near } w,\ \text{reach } \min(r_f, r_g, \delta_1) @@ 10c's line for f/g: inputs of both where g is not 0
w \in \operatorname{dom}(f/g) @@ g(w) ≠ 0
\lim_{x \to w} \tfrac{f(x)}{g(x)} = \tfrac{f(w)}{g(w)} = \htmlClass{new}{(f/g)(w)} \quad \blacksquare @@ limits-divide with L = f(w), M = g(w) ≠ 0; the line for f/g at w

One-over-x-is-continuous technique: 1/x is continuous at every input, that is at every w ≠ 0; so 1/x is continuous. 1/x is the quotient of the constant 1 by x ↦ x, both continuous at w by lines-are-continuous, and the bottom's value at w is w ≠ 0: continuous-quotients. ∎ 10a's one-over-x-limit proved the same limit by hand, with a first promise |x − w| < |w|/2. Continuous-quotients did it with away-from-zero, which is that first promise in general.

Here rung 9's question about 1/x is answered, and the words need care. 1/x is continuous: at every one of its inputs it lands where it was headed. It is neither continuous nor discontinuous at 0, because 0 is not an input, and 11a's line asks nothing there. What 1/x does near 0, passing every bound on the right and below every bound on the left, 10f has already said. 11f gives such a place a name, a break, of the endless kind.

11b6One Side at a Time, and Many Inputs at Once

10e's sides-too proved limits-add, limits-subtract, limits-multiply, constant-factor, power-limit, away-from-zero, reciprocal-limit and limits-divide from one side. So each technique of this step may be carried out side by side. If f and g are continuous from the right at w, so are f + g, f − g, fg, cf and fⁿ, and so is f/g when g(w) ≠ 0. And on sets: if f and g are continuous on a set A of inputs of both, then so is f + g, and the rest. On an interval with ends, the ends are checked from the inside, by the one-sided forms. Continuous functions on an interval add, multiply and divide into continuous functions on that interval, wherever the bottom is not 0.

\tfrac{x^3 - 2x}{x^2 + 1} @@ x³ by continuous-products (powers of x, which is continuous by lines-are-continuous); 2x by continuous-sums; the difference by continuous-sums
x^2 + 1 \ge 1 \gt 0 @@ square-never-negative; order-and-arithmetic-agree: the bottom is never 0
\text{continuous at every real} @@ continuous-quotients at each a. So it is continuous
\lim_{x \to 1} \tfrac{x^3 - 2x}{x^2 + 1} = \tfrac{1 - 2}{1 + 1} = \htmlClass{keep}{-\tfrac12} @@ continuous at 1: the limit is the value (11a)
\tfrac{1}{x^2 - 4}:\ \text{continuous on } (-\infty, -2),\ (-2, 2),\ (2, \infty) @@ continuous-quotients at every input; the bottom is 0 only at ±2 (5i's difference-of-squares, zero-product)

11b7What Does Not Pass Back

The techniques run forward only. f + g can be continuous when neither f nor g is: with 11a's step u and 1 − u, the sum is the constant 1. fg can be continuous when neither factor is: u(x) · (1 − u(x)) is 0 at every real. And a product can be continuous when one factor is continuous and the other is continuous nowhere. x is continuous at 0, and q is continuous at no real (11a's nowhere-continuous). Yet x · q(x) is continuous at 0 (11a's continuous-at-one-point). The continuous factor's value at 0 is 0, and that 0 tames the wild one, as 10d's squeeze did.

One direction does pass back, for sums. If g and f + g are continuous at w, so is f, since f = (f + g) − g on the inputs of both, and continuous-sums applies to the difference. Turned about, that gives a refutation: a continuous function plus a discontinuous one is never continuous. If f is continuous at w, g is discontinuous at w, and f + g were continuous at w, then g = (f + g) − f would be continuous at w by continuous-sums: clash; refute. ∎ No such move works for products, because dividing by f needs f(w) ≠ 0, which is exactly what x · q(x) at 0 lacks.

11b9Running It Backwards

Handed a function built from continuous pieces by adding, taking away, multiplying and dividing, name the technique for each join and check the one condition: no bottom's value is 0 at the input. Handed a combination that is continuous, do not conclude that its pieces are; find out separately, or build a counterexample from u. Handed a sum known continuous and one summand known continuous, the other is continuous too. Found upward; written downward.
