14·∎ · conclusion

Slopes control heights

Know a function's slope at every input of an interval, and you know how its heights there can compare. Zero slope everywhere means one height, positive slope means climbing, and the same slopes mean the same function lifted.

The conclusion · the rung's claim, in full, and its proof

This page opens once every question on 14e same slopes, same shape lifted (+C) is ticked. The claim below is proved from the steps of this rung, so it waits for them.

What the rung set out to show

The survey of rung 14 promised a bridge from slopes, each a fact about one input, to heights across a whole interval. 14a proved flat-top: a slope at a top or a bottom is 0. It then cut the search for a greatest value down to a short list of candidates. 14b joined flat-top to rung 12's highest-and-lowest to prove level-ends: equal heights at the ends of a closed interval give slope 0 strictly between.

14c tilted level-ends into the mean value technique, average-slope: some slope inside equals the chord's slope. 14d spent it to prove that zero slope means flat, and that the sign of the slope decides how the heights are ordered. 14e proved that the same slopes on an interval mean the same function lifted. This page states the claim in full and lays those pieces end to end.

The claim, in full

On an interval, the change between any two heights is a slope the function really has between them, times the step.

Let f be continuous on [α, β], with a slope at every input of (α, β).

Then f(β) − f(α) = f′(c)(β − α) for some c with α < c < β.

If f′ is 0 at every input of an open interval, f is constant there.

If f is continuous on an interval and f′ is positive at every input inside it, f is increasing there. If f′ is negative there, f is decreasing.

If |f′(x)| ≤ K at every x in (α, β), then |f(y) − f(x)| ≤ K|y − x| for all x and y in [α, β].

If f and g have slopes at every input of an interval, and f′ = g′ there, then f = g + C there for some real C.

The proof

The first link is level-ends, proved on 14b from two techniques. In this column only, suppose also that f(α) = f(β).

\text{call } c_1, c_2 \in [\alpha, \beta]:\ f(c_2) \le f(x) \le f(c_1) \text{ on } [\alpha, \beta] @@ highest-and-lowest (12c): f is continuous on the closed interval
c_1 \in (\alpha, \beta) \;\lor\; c_2 \in (\alpha, \beta) \;\lor\; c_1, c_2 \in \{\alpha, \beta \} @@ either-way (7a), with three-way-order on ℝ
\text{an extreme inside: its slope is } 0 @@ it is a top or a bottom, with a slope there; flat-top (14a)
\text{both at the ends: } f \text{ is constant on } [\alpha, \beta] @@ f(α) = f(β), so the greatest and least values are equal
\htmlClass{new}{f'(c) = 0 \text{ for some } c \in (\alpha, \beta)} \quad \blacksquare @@ in the second case, constant-has-slope-0 with slopes-decided-near: level-ends (14b)

Now drop f(α) = f(β). Take the chord away from f, and what is left has level ends.

m = \dfrac{f(\beta) - f(\alpha)}{\beta - \alpha} @@ the chord's slope (13a); β − α is not 0
h(x) = f(x) - f(\alpha) - m(x - \alpha) @@ the helper of 14c: f with the chord taken away
h(\alpha) = 0 = h(\beta) @@ the first line, multiplied out
h \text{ continuous on } [\alpha, \beta],\ \ h'(x) = f'(x) - m \text{ inside} @@ continuous-sums (11b); slopes-add, slope-of-a-line, constant-has-slope-0
\text{call } c \in (\alpha, \beta):\ h'(c) = 0 @@ level-ends, the column above, for h
\htmlClass{new}{f(\beta) - f(\alpha) = f'(c)(\beta - \alpha)} \quad \blacksquare @@ f′(c) = m: average-slope (14c)

Take any two inputs x < y of the interval. f is continuous on [x, y], so the first part applies there. Where only slopes are given, slope-means-no-gap supplies the continuity at each input.

x \lt y:\ \ f(y) - f(x) = f'(c)(y - x),\ \ x \lt c \lt y @@ average-slope on [x, y]; c lies inside the interval
f' = 0:\ \ \htmlClass{new}{f(y) - f(x) = 0} @@ anything-times-zero: zero-slope-is-constant (14d)
f' \gt 0:\ \ \htmlClass{new}{f(y) - f(x) \gt 0} @@ sign-of-a-product (8g), with y − x > 0: slope-sign-order (14d)
f' \lt 0:\ \ f(y) - f(x) \lt 0 \quad \blacksquare @@ sign-of-a-product again

The interval is not decoration. Leave 0 out of the domain, and let f be 0 for x < 0 and 1 for x > 0. Then f has slope 0 at every input and is not constant. [−1, 1] is not inside its domain, and average-slope cannot be run across the gap.

x \lt y:\ \ |f(y) - f(x)| = |f'(c)|\,|y - x| @@ average-slope on [x, y], then size-of-a-product (8h). For x = y both sides are 0
\htmlClass{new}{|f(y) - f(x)| \le K\,|y - x|} @@ |f′(c)| ≤ K, since c is inside: slope-bound (14c)
d = f - g:\ \ d' = f' - g' = 0 \text{ on the interval} @@ slopes-add and constant-factor for slopes (13d)
d = C,\ \ \htmlClass{new}{f = g + C} \quad \blacksquare @@ zero-slope-is-constant: same-slopes (14e)

Every part rests on the one before it, down to highest-and-lowest, which spent the line’s no-holes. None of them names the input c. Each proves that it exists, and stops there.

What the rest of the rung adds

Each step and annex after the proof steps adds a line to the claim. A line appears here once you have finished its page.

  • 14f crest and trough: It reads the sign of the slope on each side of a critical point to decide top, bottom or neither, the first-slope test, and reads the same from the slope of the slope, the second-slope test.its line appears when you finish it.
  • 14g the bend and sketching: It reads the sign of f″ as the sign of the slope of f′, so f bends up or bends down. Then it sketches a graph from the signs of f′ and f″.its line appears when you finish it.
  • 14h optimising: It turns the best fare, the best order size or the best speed into a function of one choice, and finds the best value with the candidates or with a single critical point.its line appears when you finish it.
  • 14i when top and bottom both vanish, and growth races: It runs average-slope on two functions at once, which proves the slope-ratio technique for limits of the form 0/0. Then it says which of two functions outgrows the other.its line appears when you finish it.
  • 14·stat which guess makes the data most likely?: It finds by slopes that the share seen is the best guess, and that when the guess is held to a range the best guess can sit at an end, where the slope is not 0.its line appears when you finish it.
  • 14·phys what stays the same when things crash?: It shows that the total momentum of two colliding bodies has slope 0 through the contact, so zero-slope-is-constant keeps it, whatever the forces.its line appears when you finish it.
  • 14·chem how far apart do two joined atoms sit?: It reads the force between two atoms as minus the slope of their energy curve, so the bond's length is where that energy is least, at a bottom where flat-top says to look.its line appears when you finish it.
  • 14·bio why are cells so small?: It finds where the oxygen inside a living sheet is least, and when that least value reaches 0. That sets how thick a sheet fed through its skin can be.its line appears when you finish it.
  • 14·econ how much should a factory make?: flat-top and second-test set a factory's best output where the slope of revenue meets the slope of cost. A seller alone makes less than many would, and only a tax that changes the slope of cost moves the answer.its line appears when you finish it.
  • 14·logi should we order often or order big?: the slope is 0 at the bottom of the ordering cost, so the curve is nearly level there: an order half again too big costs only 8% more, and a cost guess off by a factor of 2 costs only 6%.its line appears when you finish it.

Slopes, each a fact about one input, now reach across a whole interval. You built that bridge yourself, and you have barely started to cross it.
