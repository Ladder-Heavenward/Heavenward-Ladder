40a · proof

Names for Numbers

39j’s machine runs numbers such as 191 and 509. Nobody reads a program like that, and adding one line moves every jump after it. This step gives each kind of instruction a word, each cell a name and each place a label. Then it shows that turning the words back into numbers is itself a program.

A word for each kind, a name for each cell, a label for each place. The assembler is a count and a table, and it changes nothing the program does.

40a1A Word for Each Kind

Write STOP for 0, LOAD for 1, ADD for 2, STORE for 3, SUB for 4, JZ (jump if zero) for 5 and JMP for 6. Then the line “LOAD 91” is the instruction 191, and “JZ 9” is 509.

Word-for-number technique: each word stands for exactly one first digit d, so a line “word n” names exactly one instruction number, 100d + n.

\text{LOAD } 91 @@ the word LOAD stands for the digit 1
100 \cdot 1 + 91 = 191 @@ the instruction-number technique of 39j1, run backwards
\htmlClass{new}{\text{LOAD } 91 \text{ is } 191} \quad \blacksquare @@ one line, one number

40a2Names for Cells, Labels for Places

A name stands for a cell: say x for cell 90, count for 91, product for 92 and one for 93. A label marks a line, written before it with a colon, and a jump names the label instead of a number. Here is 39j3’s program again:

\text{top: LOAD count} @@ cell 0: 191
\text{JZ done} @@ cell 1: 509
\text{LOAD product; ADD x; STORE product} @@ cells 2 to 4: 192, 290, 392
\text{LOAD count; SUB one; STORE count} @@ cells 5 to 7: 191, 493, 391
\text{JMP top} @@ cell 8: 600
\text{done: STOP} @@ cell 9: 000

A label is not a line. It takes no cell. It names the address of the line it stands before.

40a3The Assembler Is a Program

Turning words back into numbers takes two passes. The first pass counts lines and gives each label the count of lines before it. The second pass replaces each word by its digit and each name or label by its number.

Two-pass technique: the first pass fixes one address for each label, and the second turns each line into one number; so the assembled program is fixed by the words, and it runs exactly as the numbers it names would.

Each line becomes one number by the word-for-number technique, and each label one address, because the count of lines before a place is one number. So the assembler is a function from lists of lines to lists of numbers (9a). It is a program too, and 39j4 said a program may read another as data. This one reads a program and writes one.

40a4Moving a Line Moves No Label

Put one new line near the top of 39j3’s program. In numbers, every jump to a cell past it must be found and changed by hand. In words, nothing is changed: run the assembler again, and the first pass hands every label its new address.

That is the point of the names. A jump says where it goes by what is there, not by how far down it is, and the count is worked out each time.

The accepted names

The words are mnemonics. A program written in them is in assembly language, and the program that turns it into numbers is an assembler. A label is a symbolic address, and the method of this step is the two-pass assembler.
