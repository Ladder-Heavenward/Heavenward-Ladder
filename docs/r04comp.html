4·comp · computing

Can a row of switches add?

Can a row of switches add? On 1f each joining word was a machine on paper: feed in T or F, read off T or F. 1f also said that an early algebra of logic wrote those marks with the two marks that rung 3 would bring in as names. 3a promised that this page would show the two uses agree. It does, in a line: the mark of a statement is a set, and it is the set 0 or the set 1. Then the machines are built out of switches, and a handful of them, chained, add numbers written in twos. That is not a figure of speech: the device you are reading this on adds with circuits that descend from the one built below.

Write T as 1 and F as 0 and every table is arithmetic on 0 and 1. Adding two bits is itself a table: the sum bit says “exactly one”, the carry says “both”. So a chain of small machines, each passing its carry to the next, adds numbers of any length.

The marks of statements are the numbers 0 and 1

A statement has no number. But it does pick out a set: sift the set 1 = {0} by the statement, and you keep 0 when the statement is true and nothing when it is false.

From here on, for a statement P, names the set . Read it “the mark of P”.

Here “mark” is the old algebra's word, said of a set. From here on, “the mark of P” names this set. 0a's mark, a written sign such as ∈ or ∎, keeps its meaning, and what the word is said of says which.

If P is true, x ∈ ⟦P⟧ ⇔ x ∈ 1, so ⟦P⟧ = 1 by same-members. If ¬P is true, a member of ⟦P⟧ would bring P with it and clash, so ⟦P⟧ has no members and is ∅, which is 0. So for a settled statement, one whose row you can find, the mark is 0 or 1, and it is the row: T is 1 and F is 0. Marks technique (Boole's): for settled statements P and Q,

Each is checked row by row, the rows given by settledness. Here is the last one, which is the subtle one.

\text{row TT}:\ \ 1 + 1 \cdot 1 = 1 + 1 @@ P ∨ Q is true; one-changes-nothing: both sides are 1 + 1
\text{row TF}:\ \ 1 + 1 \cdot 0 = 1 + 0 @@ times-zero, plus-zero: both sides are 1
\text{row FT}:\ \ 1 + 0 \cdot 1 = 0 + 1 @@ zero-times, plus-zero, zero-plus: both sides are 1
\text{row FF}:\ \ 0 + 0 \cdot 0 = 0 + 0 @@ ¬(P ∨ Q) by neither: both sides are 0
\htmlClass{new}{\llbracket P \lor Q \rrbracket + \llbracket P \rrbracket \cdot \llbracket Q \rrbracket = \llbracket P \rrbracket + \llbracket Q \rrbracket} \quad \blacksquare @@ reason by cases, on the settled P and Q

The product of the marks is “and”. The sum of the marks counts how many are true, so “or” falls short of the sum by exactly the overlap, P · Q, on the row where both are true. A mark times itself is itself, 0 · 0 = 0 and 1 · 1 = 1, which is the say-it-again technique P ∧ P = P. That is the agreement 3a promised. The marks the old algebra fixed by tables and the sets named 0 and 1 obey the same techniques, because the marks are the sets. For a statement nobody has settled, ⟦P⟧ is still a set, a part of 1, but nobody can say whether it is 0 or 1; rung 7 settles every statement. The accepted name for this algebra of marks is Boolean algebra.

The inventor of that algebra proposed a system of signs whose symbols admit only the values 0 and 1. He said that its rules, axioms and processes would be exactly those of logic.

From here on, on this page, the letters A, B, C, … name marks, each 0 or 1. A joining word between marks names the mark of the statement it joins: A ∧ B is ⟦A = 1 ∧ B = 1⟧, ¬A is ⟦¬(A = 1)⟧, A ∨ B is ⟦A = 1 ∨ B = 1⟧.

On this page these capitals name marks, not statements (0a's habit) and not sets, and S, the sum bit below, is not 3a's S(x), which this page does not use. Between statements, ∧, ∨ and ¬ keep their meanings from 1b and 1c; between marks they are this shorthand.

Switches and wires

Some plain words first, because the machines are made of them. A wire is a path along which electricity can flow, as it flows to a lamp to light it. A wire is on when electricity is flowing along it and off when it is not; this page writes on as 1 and off as 0. A switch is a part that either lets electricity through (it is closed) or stops it (it is open). A relay is a switch that is closed by electricity flowing in another wire, so that one wire can work another. Nothing more about electricity is needed.

From here on, closed and open are also said of switches, as the electricians say them. 4c's closed set of pairs and 1b's opening of a supposition keep their meanings; what the word is said of says which.

A student's thesis made the point that a network of switches and these marks are the same object. Two switches one after the other let electricity through only when both are closed. Two side by side, each on its own path, let it through when either is. So every network of switches can be written as an expression. The expression can be simplified by the techniques, and the simpler expression is a cheaper network that does the same job. Among the thesis's worked examples was an adder for numbers written in twos.

A twist worth knowing, because it shows the techniques do not care about labels. The thesis wrote 0 for a closed switch and 1 for an open one, recording whether a path blocks the electricity. So in it, switches one after the other were + and side by side were ·, the other way about from here. Swap 0 and 1 everywhere and “and” trades places with “or”: that is 1g's not-through, in a new setting.

Gates

A gate is a machine with input wires and one output wire whose output is fixed by its inputs according to a table. This page uses five, each a table from 1f or built from them; in the pictures each gate's symbol carries its name.

  • NOT: one input, turned about. ¬A + A = 1.
  • AND: 1 only when both inputs are 1. Its mark is A · B.
  • OR: 1 when at least one input is 1. (A ∨ B) + A · B = A + B.
  • XOR: 1 when exactly one input is 1.
  • NAND: 0 only when both inputs are 1.

1c built the exclusive or for statements. On 0 and 1, is 1 when exactly one of A and B is 1. Read it “A exclusive or B”. And nand(A, B) is 0 only when both are 1:

XOR is 1f's exactly-when turned about: it says the inputs differ. Its sameness needs the overlap twice, since on the row where both are 1 it gives 0 and the sum gives 2. A claim about marks is checked by running every row.

(A \oplus B) + 2 \cdot A \cdot B \overset{?}{=} A + B @@ the claim
A = 0,\ B = 0:\ \ 0 + 0 = 0 + 0 @@ neither: XOR gives 0
A = 1,\ B = 0:\ \ 1 + 0 = 1 + 0 @@ exactly one: XOR gives 1
A = 0,\ B = 1:\ \ 1 + 0 = 0 + 1 @@ exactly one: XOR gives 1
A = 1,\ B = 1:\ \ 0 + \htmlClass{new}{2} = 1 + 1 @@ both: XOR gives 0, and the overlap counted twice makes up the 2. Every row agrees

And NAND's: nand(A, B) + A · B = 1, on every row.

Adding two bits is a table

Add two bits A and B. The answer is 0, 1 or 2, and in twos 2 is 10₂, a numeral of two bits. Call its left bit the carry C and its right bit the sum bit S. Then the arithmetic fact is A + B = 2 · C + S, and the four rows show that both columns are gates already built. A circuit that adds two bits this way, giving a carry and a sum bit, is called a half adder.

The carry column is AND and the sum column is XOR. So one XOR gate and one AND gate, fed the same two wires, make a two-bit adder. And it can be checked by the techniques instead of the rows, which is the move this page repeats. Two-bit-adder technique: A + B = 2 · (A · B) + (A ⊕ B). The right side is (A ⊕ B) + 2 · A · B by turn-about for plus, which is A + B by XOR's sameness. The machine's outputs, read as a numeral in twos, are the sum.

Three bits in, two out: the full adder

In a column of a longer sum there are three bits to add: a bit of each number, and the carry coming in from the column to the right. Three bits add to at most 3 = 11₂, still two bits out. So the job is a machine with

(the low marks “in” and “out” are parts of the names). You could build it from its 2³ = 8 rows, but there is a nicer road: two two-bit adders and one OR. The first adds A and B, giving a sum bit p and a carry g. The second adds p and the incoming carry, giving the final sum bit S and a carry q. Then Cout = g ∨ q. Full-adder technique: two two-bit adders and an OR gate add three bits, with A + B + Cin = 2 · (g ∨ q) + S. Its proof is two-bit-adder used twice and substituted into itself.

A + B + C_{\text{in}} = (\htmlClass{new}{2 \cdot g + p}) + C_{\text{in}} @@ two-bit-adder on A and B: A + B = 2 · g + p; the swap axiom
\phantom{A + B + C_{\text{in}}} = 2 \cdot g + (\htmlClass{keep}{p + C_{\text{in}}}) @@ regroup for plus
\phantom{A + B + C_{\text{in}}} = 2 \cdot g + (\htmlClass{new}{2 \cdot q + S}) @@ two-bit-adder on p and C_in
\phantom{A + B + C_{\text{in}}} = 2 \cdot (\htmlClass{new}{g + q}) + S @@ regroup for plus; spread for times over plus turned about
\phantom{A + B + C_{\text{in}}} = 2 \cdot (g \lor q) + S \quad \blacksquare @@ g and q are never both 1, so g · q = 0 and OR's sameness gives g ∨ q = g + q

The last line needs its reason. OR's sameness is (g ∨ q) + g · q = g + q, so g ∨ q is g + q exactly when g · q = 0. And it is: if g = 1 then A and B are both 1, so their sum bit p is 0, so q = p · Cin = 0. The two carries cannot both fire, and that licenses the OR gate. (It also means an XOR gate would do the same job there, since XOR and OR differ only on the row where both inputs are 1.) Toggle the inputs in the left picture and watch the carry out. It is 1 exactly when at least two of the three inputs are 1. The carry is a majority vote.

Four bits: the carry ripples

Now chain them. Line up four full adders, one per place, the ones on the right. Each place's carry out is wired into the next place's carry in, exactly as a carry moves left in 4h's columns. The carry into the ones place is 0; the carry out of the last place becomes a fifth bit of the answer. This is a ripple-carry adder, named for what the right picture shows: the twos place cannot finish until the ones place has. Count the ones place as place 0. Write Sₖ for the sum bit of place k, and cₖ for the carry into place k, so c₀ = 0. Here is 6 + 7, place by place.

A = 0110_2 = 6,\ \ B = 0111_2 = 7 @@ line up the places; the carry into the ones place is 0
\text{ones}:\ 0 + 1 + 0 = \htmlClass{new}{01_2} @@ S₀ = 1, carry 0
\text{twos}:\ 1 + 1 + 0 = \htmlClass{new}{10_2} @@ S₁ = 0, carry 1
\text{fours}:\ 1 + 1 + \htmlClass{keep}{1} = \htmlClass{new}{11_2} @@ the carried 1 arrives (teal): S₂ = 1, carry 1
\text{eights}:\ 0 + 0 + \htmlClass{keep}{1} = \htmlClass{new}{01_2} @@ S₃ = 1, carry 0
A + B = 01101_2 = 8 + 4 + 1 = 13 @@ read the sum bits, the carry out on the left: 6 + 7 = 13

Why it works, and not just for 6 and 7: every place obeys full-adder's sameness, and the places are worth powers of 2. Take two places and write A = 2 · A₁ + A₀ and B = 2 · B₁ + B₀ (4h's reading rule in twos). Multiply the twos place's sameness by 2 and add it to the ones place's sameness. The carry c₁ appears as 2 · c₁ on both sides: produced by the ones place and used by the twos place, worth the same to each. Cancel for plus cancels it. What is left is A + B + c₀ = 4 · c₂ + 2 · S₁ + S₀: the numbers on the left, the three-bit numeral c₂S₁S₀ on the right. Each further place adds one line and one more carry that cancels the same way, which is an induction on the number of places. Ripple technique: full adders chained place by place, each carry out wired to the next carry in, add two numerals in twos of any length, and the last carry out is the top bit of the sum.

Four bits name numbers up to 15, so a sum of two of them can need five bits. 9 + 8 = 17 = 10001₂, and the final carry out is 1. A machine that keeps only four bits would report 0001, which is 1. That is overflow, a real source of real mistakes. The fifth bit is how the machine says it happened.

One gate is enough

Five kinds of gate is four more than needed: everything can be built from NAND alone.

\mathrm{nand}(A, A) + A \cdot A = 1 @@ NAND's sameness, with the same wire fed into both inputs
\mathrm{nand}(A, A) + \htmlClass{new}{A} = 1 @@ A · A = A, since A is 0 or 1
\mathrm{nand}(A, A) = \neg A @@ ¬A + A = 1 too; cancel for plus cancels A: a NOT is one NAND
\neg n + n = 1 = A \cdot B + n,\ \ n = \mathrm{nand}(A, B) @@ NOT's sameness, with n for A; NAND's sameness, with turn-about for plus
\neg n = \htmlClass{new}{A \cdot B} = A \land B @@ cancel for plus cancels n: a NAND after a NAND is an AND, two in all

OR comes from not-through: A ∨ B = ¬(¬A ∧ ¬B) = nand(¬A, ¬B) = nand(nand(A, A), nand(B, B)), three NANDs. Marks are settled, so 1g's techniques may be used both ways here. Once NOT, AND and OR can be built, every table can be (the last section shows how), so NAND alone is universal. A logic with a single joining word was published in 1913, and the same thing had been noticed decades earlier in notes never published. Factories noticed for their own reason: one kind of gate, made in vast numbers, is cheaper than five kinds.

Running it backwards: from a table to a circuit

The designer's real job runs the other way. Someone hands over a column (“light the warning lamp when at least two of the three sensors fire”) and wants a circuit. 1f's recipe: for each row where the output is 1, write the and of that row's inputs, with a not on each input that is 0 in that row. Then join them with or. Take the full adder's carry out, which is 1 on the rows 011, 101, 110 and 111 (writing C for Cin, and A · B for A ∧ B):

\neg A \cdot B \cdot C \lor A \cdot \neg B \cdot C \lor A \cdot B \cdot \neg C \lor A \cdot B \cdot C @@ one and for each row with a 1
= \neg A \cdot B \cdot C \lor A \cdot \neg B \cdot C \lor \htmlClass{new}{A \cdot B} @@ the last two differ only in C: A · B · (¬C ∨ C) = A · B (1g's spread, either-way for a settled mark, units)
= \htmlClass{new}{A \cdot B \lor B \cdot C \lor A \cdot C} @@ the same move twice more, borrowing A · B · C, which A · B absorbs (1g's absorb, say-it-again)

“At least two of three” is A · B ∨ B · C ∨ A · C: three ANDs and an OR. It is a different circuit from the two-adders-and-an-OR version, and it computes the same table: two circuits, one column, as two names can name one number. Choosing between them is engineering (fewer gates, or a shorter path for the signal). Proving they agree is rewriting by the rulebook, or checking 2³ rows.

Who said it first

The early algebra of logic, and the marks 0 and 1 for statements, are George Boole’s. The student whose thesis turned switches into marks is Claude Shannon (1937). The logic with a single joining word is Henry Sheffer’s (1913); Charles Sanders Peirce had noticed the same thing decades earlier in notes he never published. The not-through techniques are De Morgan’s.

Boole proposed a system of signs whose symbols admit only the values 0 and 1, and said that its laws, axioms and processes would be exactly those of logic.

Boole, An Investigation of the Laws of Thought (1854), ch. II; paraphrase

Claude Shannon's point was that a network of switches and Boole's marks are the same object. Two switches one after the other let electricity through only when both are closed; two side by side, each on its own path, let it through when either is. So every network of switches can be written as an expression, the expression can be simplified by the techniques, and the simpler expression is a cheaper network that does the same job. Among his worked examples was an adder for numbers written in twos.

Shannon, A Symbolic Analysis of Relay and Switching Circuits, master's thesis, MIT, 1937; published 1938; paraphrase

The liar box, as a timer

0a set one sentence aside: “this sentence is false”. If it is so, it is not, and if it is not, it is. Built in wires, it is a not gate whose output is fed back into its own input: A = ¬A. No mark meets that sameness. 1 gives ¬1 = 0, and 0 gives ¬0 = 1. As a sameness to be settled once, it has no answer.

A real gate is not instant. It takes a moment, a few billionths of a second, to answer a change at its input. So the looped gate answers its own answer a moment late: 1, then 0, then 1, then 0, for as long as the power is on. It never settles, and it is not stuck either. It keeps time.

The liar box stands to so-or-not-so as a cycle: it is so and not so in turn, a moment each.

This is 0c's ledger cutting the other way. A description whose books do not balance is wrong, however carefully each sentence was deduced. And a sentence with no single mark, read once, can still have a steady pattern, read over time. A ring of an odd number of not gates is one of the plainest clocks a circuit can have.

The truth-teller box, as a memory

The liar has a twin: “this sentence is true”. If it is so, it is so, and if it is not, it is not. Built in wires, it is a gate that passes its input on unchanged, fed back into its own input: A = A. Both marks meet that sameness. As a sameness to be settled once, it has two answers, and nothing in the logic picks one.

So the wires pick. At the moment the power comes on, the loop sits balanced between 0 and 1, and the faint noise in any circuit tips it one way. Then it stays there. Its answer is set by its history, not by its logic.

The truth-teller box stands to so-or-not-so as a memory: it is whichever it was last made to be, for as long as the power is on.

The liar fits no mark and keeps time; the truth-teller fits every mark and keeps a value. 5d meets the same pair in dividing by 0: 1/0 has no answer, and 0/0 has every answer.

Accepted names

Working with statements through their marks is called Boolean algebra, after Boole. NAND is also called the Sheffer stroke.
