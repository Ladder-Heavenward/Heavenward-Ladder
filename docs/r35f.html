35f · proof

Is There a Size in Between?

The counting numbers are countable, and the line is larger. Is there a set of reals larger than the counting numbers and smaller than the line? Every set anyone draws seems to answer no. A set that holds a stretch of the line, however short, has the size of the whole line, and this step proves it. The question was asked plainly before the end of the nineteenth century, and it was put first on a famous list of problems for the twentieth. It turned out to be like choice. In one world where every axiom is true, there is no size in between. In another, there is. So the axioms the ladder has laid down, with all the others in the standard list, can neither prove the answer nor refute it. This step proves what can be proved here, names the two results that settle the question’s status, and says plainly that their proofs are far beyond this rung. What the answer is, if there is one, is still argued over.

A set of reals that holds an interval has the size of the line. The first point of the run that cannot be listed has a size between the counting numbers and the line, perhaps equal to the line. Whether it is equal is true in one world of the axioms and false in another, so the axioms do not decide it.

35f1The Sets You Can Draw

Every set of reals so far is countable or the size of ℝ. The question of this step, in marks: is there a set S of reals with ℵ₀ < |S| < 2^ℵ₀? One kind of set can be ruled out at once.

Interval-size technique: every set of reals that holds an interval with two different ends has the size of the line.

(u, v) \subseteq S \subseteq \mathbb R,\ \ u < v @@ S holds an open interval (a closed one holds an open one)
t(x) = \tfrac{x}{1 + |x|} \text{ sends } \mathbb R \text{ one-to-one onto } (-1, 1) @@ its backwards rule is y ↦ y/(1 − |y|) (9d)
x \mapsto \tfrac{u + v}{2} + \tfrac{v - u}{2}\,t(x) \text{ sends } \mathbb R \text{ one-to-one into } (u, v) @@ a stretch and a slide of (−1, 1)
|\mathbb R| \le |S| \text{ and } |S| \le |\mathbb R| @@ the line above, then S ⊆ ℝ with each member sent to itself
\htmlClass{new}{|S| = |\mathbb R| = 2^{\aleph_0}} \quad \blacksquare @@ the two-one-way technique (35d1) and the line-size technique (35e2)

So a set in between, if there is one, holds no interval. It is scattered, like the fractions, and yet too large to list. 35b’s irrationals hold no interval, and they are not in between: 35f.4.1 asks for their size. 35h builds a dust that holds no interval and has length 0, and finds its size.

35f2The First Size Past ℵ₀

35e3 found many points of the run of size ℵ₀. Not every point is countable. Held in trust here: there is a least point of the run that is not countable, and every part of it is countable or has its size. The proof gathers, with 29·cb3’s Replace, one point for each way of lining up a part of ℕ, and it needs a column comparing lined-up sets that this rung does not write. From here on, ω₁ names that point, and ℵ₁, aleph-one, marks its size: |A| = ℵ₁ says A is matched with ω₁.

Next-aleph technique: with choice, ℵ₀ < ℵ₁ ≤ 2^ℵ₀.

\omega \subseteq \omega_1,\ \ \omega_1 \text{ not countable} @@ ω₁ is a point past every number; it is not countable by its definition
\aleph_0 < \aleph_1 @@ a part goes into the whole; ω₁ is not matched with ω
|\mathbb R| \le |\omega_1| \text{ or } |\omega_1| \le |\mathbb R| @@ the any-two-sizes technique (35d3): choice
|\mathbb R| \le |\omega_1| \Rightarrow \mathbb R \text{ is matched with a part of } \omega_1 @@ its image, by the one-way map
\text{that part is countable, or of size } \aleph_1 @@ held in trust, above; ℝ is not countable (35b1)
\htmlClass{new}{\aleph_1 \le 2^{\aleph_0}} \quad \blacksquare @@ in either case; the line-size technique (35e2)

So the question becomes one line: is 2^ℵ₀ = ℵ₁? If so, there is no size in between, and every set of reals is countable or the size of the line. If not, ω₁ itself is matched with a set of reals that is in between.

35f3Neither Proved nor Refuted

6d1 showed how a world settles what proofs cannot do: if every axiom is true in a world and a statement is false there, no proof of the statement exists. Two worlds of 6d do this for 2^ℵ₀ = ℵ₁. The results are named here, and their proofs are much higher up the ladder.

In the described world, every axiom is true and 2^ℵ₀ = ℵ₁; in a world built by the 1963 method, every axiom is true and 2^ℵ₀ = ℵ₂, the size of the least point of the run larger than ω₁. So the axioms neither prove that there is no size in between, nor refute it.

\text{assume a proof of } 2^{\aleph_0} \ne \aleph_1 @@ aiming to refute
\text{it is true in every world where the axioms are} @@ the techs care nothing for the world (1e)
\text{in the described world they are true, and } 2^{\aleph_0} = \aleph_1 @@ the result of 1938, named
\htmlClass{new}{\text{no proof that there is a size in between}} @@ clash; refute
\text{in the 1963 world they are true, and } 2^{\aleph_0} = \aleph_2 @@ the result of 1963, named
\htmlClass{new}{\text{no proof that there is none}} \quad \blacksquare @@ the same column

In the described world (6d3) every set is described at some stage, and the reals all appear at stages that can be listed below ω₁: so there are only ℵ₁ of them. The 1963 method (6d6) makes new sets so alike that nothing in the old world can tell them apart. Add ℵ₂ new parts of ℕ that way, and the line grows to size ℵ₂, while ℵ₁ stays where it was. As with choice in 6d1, both results are relative: if the axioms are free of anything totally false, they stay so with either answer added.

35f4What Is Shown, and What Is Open

Sets of reals that hold an interval have the size of the line, and the axioms leave open whether any set lies between ℵ₀ and 2^ℵ₀.

  • Asked, 1878. Every endless set of reals is countable or the size of the line. Put first on a list of problems for the new century in 1900.
  • Shown, 1884. Every closed set of reals is countable or holds a dust like 35h’s, and so has the size of the line. The question has its answer for every set that is closed.
  • Shown, 1905. 2^ℵ₀ cannot be the size reached by a countable climb of smaller sizes, so it is not the first size past ℵ₀, ℵ₁, ℵ₂, … all together. 35·now gives the proof.
  • Shown, 1938. The described world: no size in between, and choice true.
  • Shown, 1963. The 1963 world: a size in between.
  • Shown, 1970. Almost any size not ruled out in 1905 can be the size of the line in some world of the axioms.
  • Open. Whether there is a fact of the matter, and if so, which new axiom should settle it. 35·now takes it up.

One side holds that sets are real, that the line has some one size whether or not the axioms reach it, and that the work is to find the right new axioms. The other holds that the axioms are all there is to it, that the question has an answer in each world and none outside, and that asking which world is the real one is like asking which geometry is the real one.

The basement · there if you want it

The accepted names

The statement 2^ℵ₀ = ℵ₁ is the continuum hypothesis, CH. ω₁ is the first uncountable ordinal, and ℵ₁ its cardinal. The held-in-trust fact of 35f2 is Hartogs’s construction of ω₁, with the fact that every uncountable subset of ω₁ has cardinality ℵ₁. The described world is Gödel’s constructible universe L; the 1963 method is Cohen’s forcing. The result of 1884 is the Cantor–Bendixson theorem; that of 1905 is König’s theorem on cofinality; that of 1970 is Easton’s theorem.

Who said it first

Georg Cantor stated the hypothesis in 1878 and tried to prove it for the rest of his life; in 1884, with Ivar Bendixson, he proved it for closed sets. David Hilbert put it first among the twenty-three problems of his Paris address of 1900. Julius König proved the 1905 limit. Kurt Gödel announced in 1938 that CH holds in the constructible universe, so it cannot be refuted. Paul Cohen proved in 1963 that it cannot be proved, inventing forcing, and received the Fields Medal for it in 1966. William Easton proved his result in 1970. Gödel argued in “What is Cantor’s continuum problem?” (1947, revised 1964) that CH has a definite answer and is probably false; Cohen later leaned to the view that it is neither true nor false in any absolute sense.

A proof that is not allowed

“The fractions have size ℵ₀ and the line 2^ℵ₀. A set in between would be a set larger than the fractions and smaller than the line. Every set of reals is a union of intervals and points. A union with an interval is the size of the line, and a union of points with no interval is countable. So there is none.” Not allowed: a set of reals need not be a union of intervals and countably many points. The irrationals and the dust of 35h are neither.
