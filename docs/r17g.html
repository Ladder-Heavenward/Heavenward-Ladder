17g · proof

pˣ for any real x

Rung 8 gave a meaning to a positive number raised to a fraction, and to nothing else: two raised to the square root of two had none. Log-of-a-power says the logarithm of a fractional power is the fraction times the logarithm, so the power is the exponential of that. That makes sense for every real power. This step takes it as the definition of a positive number raised to any real power. It checks that this is rung 8's power wherever rung 8 had one. And it proves that every exponent technique carries over. Then come the slopes: a number raised to the input has slope itself times the number’s logarithm, and the power rule holds for every real power. Last, the function that undoes raising a number to the input: the logarithm to that base.

A positive number raised to a power is the exponential of the power times the number’s logarithm. For fractions it is rung 8’s power. Powers add when their results multiply, multiply when one is raised to another, and pass across a product. A number raised to the input has slope itself times the number’s logarithm, and the power rule holds for every real power. The logarithm to a base is the logarithm divided by the base’s logarithm.

17g1The definition, and that it agrees

For p > 0 and every real x, pˣ = exp(x ln p) = ex ln p. p is the base and x the exponent, as in rung 8.

Powers-agree technique: for p > 0 and rational r, exp(r ln p) is rung 8's pʳ. With p = e, exp(x ln e) = exp x, so eˣ means what 17e said.

\ln(p^r) = r\ln p @@ log-of-a-power (17c); pʳ as in 8i
\exp(r\ln p) = \exp(\ln p^r) = p^r @@ inverse-is-a-bijection (9d): exp undoes ln

17g2The exponent techniques

Real-exponent technique: for p, q > 0 and all real x, y: pˣ⁺ʸ = pˣpʸ, p⁻ˣ = 1/pˣ, (pˣ)ʸ = pˣʸ, (pq)ˣ = pˣqˣ, and ln(pˣ) = x ln p.

\ln(p^x) = \ln\exp(x\ln p) = x\ln p @@ inverse-is-a-bijection; log-of-a-power is now true for every real x
p^{x+y} = e^{(x+y)\ln p} = e^{x\ln p}e^{y\ln p} = p^x p^y @@ adding-becomes-multiplying (17e)
p^{-x} = e^{-x\ln p} = 1/p^x @@ adding-becomes-multiplying
(p^x)^y = e^{y\ln(p^x)} = e^{yx\ln p} = p^{xy} @@ ﹀ pˣ with base pˣ, then the first line
(pq)^x = e^{x(\ln p + \ln q)} = p^x q^x \quad \blacksquare @@ log-of-a-product, then adding-becomes-multiplying

So pˣ > 0 always, p⁰ = 1 and p¹ = p. For p > 1, ln p > 0 and pˣ rises; for 0 < p < 1, ln p < 0 and pˣ falls; 1ˣ = 1.

17g4The log to any base

For p > 0, p ≠ 1, the function x ↦ pˣ is a bijection from ℝ to (0, ∞): it rises or falls, and takes every positive value, since ln does. The function that undoes it is logₚ, the log to base p: logₚ y is the x with pˣ = y, and logₚ is an operator, as ln is. log₁₀ is the base of the old printed tables. It has the accepted name the common log, often written log; ln is log base e.

Log-base-p technique: logₚ x = ln x / ln p; its techniques are log-of-a-product, log-of-a-quotient and log-of-a-power with logₚ in place of ln; and (logₚ x)′ = 1/(x ln p).

p^y = x \iff y\ln p = \ln x @@ real-exponent; ln is one to one (log-rises)
\htmlClass{new}{\log_p x = \tfrac{\ln x}{\ln p}} @@ ln p ≠ 0, since p ≠ 1
\log_p(xy) = \tfrac{\ln x + \ln y}{\ln p} = \log_p x + \log_p y @@ log-of-a-product; the others the same way
(\log_p x)' = \tfrac{1}{\ln p}\cdot\tfrac1x \quad \blacksquare @@ slope-of-log; constant-factor for slopes (13d)

Who said it first

Hilbert asked, among the problems he set for the new century, whether a power such as 2√2, an algebraic base raised to an irrational algebraic exponent, must always be transcendental, a number that is the root of no polynomial with whole-number coefficients.

David Hilbert, Mathematical Problems, the seventh (1900); paraphrase

In 17g.4.4, the one who asked is David Hilbert; the open problem about the primes is the Riemann hypothesis; the two who answered are Aleksandr Gelfond and Theodor Schneider. Base-ten logs are Henry Briggs’s.
