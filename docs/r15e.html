15e · proof

Areas Add, Scale, Split

15d found the area under the plainest line by a column of sums. The area under three times the input, plus two, would need another column, and every new function another. This step proves the rules that save the columns. The integral of a sum is the sum of the integrals. A constant factor comes out. An interval cut in two gives two integrals that add. A smaller function has a smaller integral. Each rule is proved on the boxes, one piece at a time, and then passed to the integral by gap-closes. Along the way the integral learns to count a function below the axis as negative.

On each piece, the least of a sum is at least the sum of the leasts, so the sums sandwich. A constant factor multiplies every height, and a negative one swaps least for greatest. A partition with the cut point in it splits into two. Heights in order give sums in order. The integral inherits all four.

15e1Adding

Areas-add technique: if f and g are integrable on [u, v], so is f + g, and ∫ᵤᵛ (f + g) = ∫ᵤᵛ f + ∫ᵤᵛ g. (From here on, the dx may be left off when the letter is clear.)

f(x) + g(x) \ge m_i(f) + m_i(g) \text{ on the } i\text{-th piece} @@ same-direction-add (8g): each is at least its inf
m_i(f + g) \ge m_i(f) + m_i(g),\ \ M_i(f + g) \le M_i(f) + M_i(g) @@ greatest-lower-bound: a lower bound is at most the inf; no-holes likewise
L(f, P) + L(g, P) \le L(f + g, P) \le U(f + g, P) \le U(f, P) + U(g, P) @@ order-and-arithmetic-agree with Δxᵢ > 0; add over i; lower-below-upper
\text{fix } \varepsilon;\ \text{call } P \text{ with both gaps} \lt \tfrac{\varepsilon}{2} @@ gap-closes for f and for g, then the common refinement (refining-tightens)
U(f + g, P) - L(f + g, P) \lt \varepsilon @@ the line before last, and same-direction-add
f + g \text{ is integrable} @@ gap-closes
\textstyle\int (f + g) \text{ and } \int f + \int g \text{ both lie in } [L(f, P) + L(g, P),\ U(f, P) + U(g, P)] @@ each integral lies between its sums
|\textstyle\int (f + g) - (\int f + \int g)| \lt \varepsilon \text{ for every } \varepsilon \gt 0 @@ two numbers in a window of width less than ε
\htmlClass{new}{\textstyle\int (f + g) = \int f + \int g} \quad \blacksquare @@ a difference smaller than every positive ε is 0: take ε to be the difference itself (three-way-order on ℝ)

15e2Scaling

Areas-scale technique: if f is integrable on [u, v] and c is a number, then cf is integrable and ∫ᵤᵛ cf = c ∫ᵤᵛ f. With 15e1’s areas-add, the integral keeps adding and stretching: ∫(f + g) = ∫f + ∫g and ∫cf = c∫f.

c \ge 0:\ \ m_i(cf) = c\,m_i(f),\ \ M_i(cf) = c\,M_i(f) @@ order-and-arithmetic-agree: multiplying by c ≥ 0 keeps every bound a bound
L(cf, P) = c\,L(f, P),\ \ U(cf, P) = c\,U(f, P) @@ spread for times over plus over the sum
c \lt 0:\ \ m_i(cf) = c\,M_i(f),\ \ M_i(cf) = c\,m_i(f) @@ negative-reverses-order (8g): a negative factor turns the order about, so the least becomes the greatest
L(cf, P) = c\,U(f, P),\ \ U(cf, P) = c\,L(f, P) @@ the boxes over f become the boxes under cf
U(cf, P) - L(cf, P) = |c|\,(U(f, P) - L(f, P)) @@ either case
\htmlClass{new}{\textstyle\int_u^v cf = c \int_u^v f} \quad \blacksquare @@ gap-closes for integrable; the sup and the inf pass through the factor, swapping when c < 0

15e3Splitting

Interval-cut-in-two technique: if u < c < v, then f is integrable on [u, v] exactly when it is integrable on [u, c] and on [c, v], and then ∫ᵤᵛ f = ∫ᵤᶜ f + ∫ᶜᵛ f.

\begin{aligned}&P \text{ a partition of } [u,\\ &\quad v] \text{ with } c \text{ among its points}\end{aligned} @@ any partition gains c by refinement, and refining-tightens only tightens it
P = P_1 \cup P_2,\ \ P_1 \text{ on } [u, c],\ P_2 \text{ on } [c, v] @@ the points up to c, and from c on
L(f, P) = L(f, P_1) + L(f, P_2),\ \ U \text{ likewise} @@ the same pieces, summed in two runs
\text{gap on } [u, v] = \text{gap on } [u, c] + \text{gap on } [c, v] @@ both gaps are never negative, so one is small exactly when both are
\text{integrable on } [u, v] \;\Leftrightarrow\; \text{on both halves} @@ gap-closes, each way
\htmlClass{new}{\textstyle\int_u^v f = \int_u^c f + \int_c^v f} \quad \blacksquare @@ both sides lie in [L(f, P), U(f, P)] for every such P; ε as in areas-add

From here on, ∫ᵤᵘ f = 0, and for u < v, ∫ᵛᵤ f = −∫ᵤᵛ f. Then interval-cut-in-two is true for any three points u, v, c of an interval where f is integrable, in any order.

15e4Order

Smaller-function-smaller-area technique: if f and g are integrable on [u, v] and f(x) ≤ g(x) for every x there, then ∫ᵤᵛ f ≤ ∫ᵤᵛ g. In particular, if m ≤ f(x) ≤ M on [u, v], then m(v − u) ≤ ∫ᵤᵛ f ≤ M(v − u).

g - f \ge 0 \text{ on } [u, v] @@ the hypothesis
m_i(g - f) \ge 0,\ \ L(g - f, P) \ge 0 @@ 0 is a lower bound; order-and-arithmetic-agree
\textstyle\int (g - f) \ge 0 @@ the integral is the sup of the lower sums, and one of them is ≥ 0
\textstyle\int g - \int f \ge 0 @@ areas-add, with areas-scale at c = −1
\htmlClass{new}{\textstyle\int f \le \int g} \quad \blacksquare @@ order-and-arithmetic-agree; the second claim is the first with constants, ∫ₐᵇ m = m(b − a) (15c)

One mathematician proposed that a figure traced in the plane be given a sign by the direction of its tracing, so that an area counts positive one way round and negative the other. Only then, he argued, do the formulas for adding and cutting figures work without exceptions.

15e5Below the Axis

15a's region was defined only for f ≥ 0. For an f that takes both signs, the integral still exists when f is integrable, and the rules say what it counts.

From here on, the positive part of f is f⁺(x) = f(x) where f(x) ≥ 0 and 0 elsewhere; the negative part is f⁻(x) = −f(x) where f(x) < 0 and 0 elsewhere. Then f = f⁺ − f⁻, and both parts are never negative. f⁺ and f⁻ are names, each for a function.

Parts-integrable technique: if f is integrable on [u, v], so are f⁺ and f⁻, and ∫ᵤᵛ f = ∫ᵤᵛ f⁺ − ∫ᵤᵛ f⁻. On any piece, two values of f⁺ are never further apart than the matching values of f. They are equal, or one is 0 and the other is no more than the gap. So Mᵢ(f⁺) − mᵢ(f⁺) ≤ Mᵢ(f) − mᵢ(f), and the gap test passes for f⁺ whenever it passes for f. Then f⁻ = f⁺ − f, and areas-add and areas-scale give the rest.

So ∫ᵤᵛ f is the area under f⁺, above the axis, minus the area under f⁻, which measures the part below the axis. Its accepted name is the signed area, or net area. The area between the graph and the axis, both parts counted positive, is ∫ᵤᵛ f⁺ + ∫ᵤᵛ f⁻.

Who said it first

Möbius proposed that a figure traced in the plane be given a sign by the direction of its tracing, so that an area counts positive one way round and negative the other, and argued that only then do the formulas for adding and cutting figures work without exceptions.

Möbius, Der barycentrische Calcul (1827); paraphrase
