40·comp · computing

What Did a Missing Check Cost?

40h said a type check catches values of the wrong kind before anything runs, and 40g said an invariant states what must stay true. This annex looks at two famous losses where such a check was missing, and asks which of the rung’s tools would have caught each.

A value outside its box, and a number in the wrong unit: each is a type that was not checked.

40comp1A Number Too Big for Its Box

In 1996 the first Ariane 5 rocket broke up about forty seconds after launch. Its guidance program turned a measure of sideways speed, held as a fraction with 64 bits, into a whole number of 16 bits. The faster new rocket gave a value too large for 16 bits, the conversion failed, and the guidance shut down.

The program had been carried over from the slower Ariane 4, where the value always fitted. The check that the value fitted was an invariant true on the old rocket and false on the new.

    Why was the check true on the old rocket and false on the new?

40comp2Two Teams, Two Units

In 1999 the Mars Climate Orbiter was lost as it reached Mars. One team’s program gave thruster impulse in pound-force seconds, and the other team’s program read the numbers as newton seconds. The craft flew too low.

Both programs handled numbers correctly. The fault was a unit, and a type that carried units, newton seconds as a type of its own, would have refused the step that joined them (40h2).

Question

  1. 40·comp.2.1understandWhy did both programs handle their numbers correctly?
    Which check would have refused the join?

40comp3Which Tool Catches What

A type catches a kind, such as a unit or a range of whole numbers. An invariant catches a promise the program must keep. A test catches only what its rows happen to try. Each of the two losses had passed tests.

Question

    Why did tests not catch either loss?

The accepted names

The Ariane 5 fault was an overflow in a conversion from floating point to integer. Types that carry units are units of measure, which some languages check. The failure reports of the European Space Agency (1996) and NASA (1999) give the details.
