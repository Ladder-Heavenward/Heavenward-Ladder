10c · proof

Limits add, multiply and divide

If one function heads to one value and another to a second, their sum heads to the sum of the values, their product to the product, and their quotient to the quotient, provided the second value is not 0. This step proves all three in full. The sum is quick: split the challenger's gap into two halves and give each function one. The product needs a trick you would not think of unless you were looking for it, adding and taking away the same amount, and an answer chosen as the least of three. The quotient needs a round of the game of its own, to keep the bottom away from 0 near the input. Then constants, powers and every polynomial follow. Substituting the input into a polynomial, or into a fraction of polynomials whose bottom is not 0 there, becomes a technique.

Split the gap into budgets, one for each piece; rewrite the difference so that each piece has a factor you can make small; tame any factor that is not small with a first promise; answer with the least of the reaches.

10c1Functions made from functions

To say “the sum heads to L + M” there must be a function called the sum. 9b had composing. This step needs the plainer ways of making functions: add the outputs, multiply them, divide them.

From here on, for functions f and g whose inputs and outputs are reals, and a real c: f + g, f − g and fg name the functions x ↦ f(x) + g(x), x ↦ f(x) − g(x) and x ↦ f(x)g(x), each on dom f ∩ dom g. cf names x ↦ c · f(x) on dom f. f/g names x ↦ f(x)/g(x) on {x ∈ dom f ∩ dom g : g(x) ≠ 0}. And for a number n, fⁿ names x ↦ (f(x))ⁿ on dom f, with 8f's powers of a real. The high n is a power of outputs: it is not 9·cb4's iterate, which carries a ring, and not 9d's f⁻¹. And fg is the product of outputs, never 9b's composite g ∘ f.

Each is a function by 4d's rule-makes-a-function. If f and g are both defined near w, with reaches r_f and r_g, then f + g, f − g and fg are defined near w with reach min(r_f, r_g), by lesser-below-both. For f/g that is not enough, since g may be 0 near w; away-from-zero below supplies what is missing. One more line, because the product's answer is the least of three reaches.

From here on, min(p, q, r) is short for min(min(p, q), r), and a longer list likewise, one real at a time: the least of several. By lesser-below-both, used once for each min, it is at most each real of the list, and it is positive when they all are.

10c2Limits add

Limits-add technique: if lim_{x→w} f(x) = L and lim_{x→w} g(x) = M, then lim_{x→w} (f + g)(x) = L + M. In plain words: the challenger names a gap, and you give each function half of it, a budget. Each answers with its own reach, and you answer with the least. Then the triangle inequality adds the two halves back together.

\text{let } \varepsilon \gt 0;\ \ \htmlClass{new}{\tfrac{\varepsilon}{2}} \gt 0 @@ speak of everything; half a positive is positive
\text{call } \delta_1:\ 0 \lt |x - a| \lt \delta_1 \Rightarrow |f(x) - L| \lt \tfrac{\varepsilon}{2} @@ lim f = L, at the gap ε/2
\text{call } \delta_2:\ 0 \lt |x - a| \lt \delta_2 \Rightarrow |g(x) - M| \lt \tfrac{\varepsilon}{2} @@ lim g = M, at the gap ε/2
\delta = \htmlClass{new}{\min(\delta_1, \delta_2, r)} @@ the least of several; r a reach on which f and g are both defined
\text{assume } 0 \lt |x - a| \lt \delta @@ x is in all three windows (lesser-below-both, at-most-is-a-partial-order on ℝ)
\begin{gathered}|(f + g)(x) - (L + M)|\\ = |\htmlClass{new}{(f(x) - L) + (g(x) - M)}|\end{gathered} @@ the line for f + g; negative-of-a-sum and middle-swap (8d): regroup
\le |f(x) - L| + |g(x) - M| @@ triangle (8h)
\lt \tfrac{\varepsilon}{2} + \tfrac{\varepsilon}{2} = \htmlClass{keep}{\varepsilon} \quad \blacksquare @@ both promises (same-direction-add); ½ + ½ = 1 (5f)

Read it backwards and you see how it was invented. The total had to be under ε; the triangle inequality splits the total into two pieces; so give each piece half. That is the method of this whole step, and of 10g: start from the inequality you want, rewrite it into pieces you control, then choose the reach that controls them all.

10c3Limits multiply: add and take away

Limits-multiply technique: if lim_{x→w} f(x) = L and lim_{x→w} g(x) = M, then lim_{x→w} (fg)(x) = LM. The difference f(x)g(x) − LM has no visible piece that is small. Make one, by adding and taking away the same amount, f(x)M. The middle pair is 0, so nothing changes but the look:

\begin{gathered}f(x)g(x) - LM\\ = f(x)g(x) \htmlClass{new}{- f(x)M + f(x)M} - LM\end{gathered} @@ add 0 in the form −f(x)M + f(x)M (negative on ℝ, plus-zero on ℝ)
= \htmlClass{keep}{f(x)\,(g(x) - M)} + \htmlClass{keep}{M\,(f(x) - L)} @@ spread on ℝ backwards on each pair; turn-about for times on ℝ
\begin{gathered}|f(x)g(x) - LM|\\ \le |f(x)|\,|g(x) - M| + |M|\,|f(x) - L|\end{gathered} @@ triangle; size-of-a-product

Now each piece is a product with a factor you can make small: |g(x) − M| and |f(x) − L|. The second piece is easy: its other factor |M| is fixed. The first is not: its other factor |f(x)| changes with x. Tame it with a first promise, as 10a tamed the leftover of x². Bounded-near technique: if lim_{x→w} f(x) = L, then there is a reach δ₁ with |f(x)| < |L| + 1 for every x in the neighbourhood of w of reach δ₁. Challenge with ε = 1 and call the answer δ₁. In that window |f(x) − L| < 1, and the reverse form of triangle gives |f(x)| − |L| ≤ |f(x) − L| < 1. ∎

\text{let } \varepsilon \gt 0 @@ speak of everything
\text{call } \delta_1:\ \ |f(x)| \lt \htmlClass{new}{|L| + 1} @@ bounded-near: the first promise tames the wild factor
\text{call } \delta_2:\ \ |g(x) - M| \lt \tfrac{\varepsilon}{2(|L| + 1)} @@ lim g = M at that gap: positive, since |L| + 1 > 0
\text{call } \delta_3:\ \ |f(x) - L| \lt \tfrac{\varepsilon}{2(|M| + 1)} @@ lim f = L at that gap: |M| + 1, never 0, even when M is 0
\begin{gathered}\delta = \htmlClass{new}{\min(\delta_1, \delta_2, \delta_3, r)};\ \\\ \text{assume } 0 \lt |x - a| \lt \delta\end{gathered} @@ the least of several; r a reach on which f and g are defined
|f(x)|\,|g(x) - M| \lt (|L| + 1) \cdot \tfrac{\varepsilon}{2(|L| + 1)} = \tfrac{\varepsilon}{2} @@ δ ≤ δ₁ and δ ≤ δ₂: multiply the two bounds (order-and-arithmetic-agree; non-negative factors)
|M|\,|f(x) - L| \le |M| \cdot \tfrac{\varepsilon}{2(|M| + 1)} \lt \tfrac{\varepsilon}{2} @@ δ ≤ δ₃; |M| < |M| + 1, so |M|/(|M| + 1) < 1 (positive-reciprocal on ℚ read in ℝ, order-and-arithmetic-agree)
|f(x)g(x) - LM| \lt \tfrac{\varepsilon}{2} + \tfrac{\varepsilon}{2} = \htmlClass{keep}{\varepsilon} \quad \blacksquare @@ the split's last line; same-direction-add

Look at what each reach did. δ₁ made a promise about f that had nothing to do with ε: it only made |f(x)| behave. δ₂ and δ₃ spent the budget, half each. But each half was divided by the size of the other factor, so that multiplying by that size gives back exactly ε/2. And the answer is the least of all of them, because every promise must be kept at once. Why |M| + 1 and not |M|? Because M may be 0, and ε/(2|M|) would then name nothing. Adding 1 costs nothing and keeps the bottom positive.

A well-known calculus book puts all the arithmetic of this proof into a technique about reals alone. If x is within min(1, ε/(2(|y₀| + 1))) of x₀, and y is within ε/(2(|x₀| + 1)) of y₀, then xy is within ε of x₀y₀. The limit technique is then that one, the definition, and the least of the reaches.

10c4Limits divide, when the bottom’s limit is not 0

A quotient f/g is fg's cousin with 1/g in place of g. So the work is in 1/g, and it has two parts. First, g must stay away from 0 near w, or 1/g is not even defined there. Away-from-zero technique: if lim_{x→w} g(x) = M and M ≠ 0, then there is a reach δ₁ with |g(x)| > |M|/2 for every x in the neighbourhood of w of reach δ₁; in particular g(x) ≠ 0 there.

|M| \gt 0,\ \ \text{challenge with } \htmlClass{new}{\varepsilon = \tfrac{|M|}{2}} @@ M ≠ 0 (8h); half a positive
\text{call } \delta_1:\ \ |g(x) - M| \lt \tfrac{|M|}{2} @@ lim g = M at that gap
\begin{gathered}|M| - |g(x)| \le |M - g(x)|\\ = |g(x) - M| \lt \tfrac{|M|}{2}\end{gathered} @@ the reverse form of triangle; size-of-a-negative
|g(x)| \gt |M| - \tfrac{|M|}{2} = \htmlClass{keep}{\tfrac{|M|}{2}} \gt 0 \quad \blacksquare @@ order-and-arithmetic-agree; so g(x) ≠ 0, since |0| = 0

This is 10b's sign-kept-near with sizes in place of signs. The second part is the game itself. Reciprocal-limit technique: if lim_{x→w} g(x) = M and M ≠ 0, then lim_{x→w} (1/g)(x) = 1/M. Here 1/g names the function x ↦ 1/g(x), the quotient of the constant 1 by g, defined near w by away-from-zero.

\left|\tfrac{1}{g(x)} - \tfrac{1}{M}\right| = \tfrac{|M - g(x)|}{|g(x)|\,|M|} = |g(x) - M| \cdot \htmlClass{keep}{\tfrac{1}{|g(x)|\,|M|}} @@ one bottom (fractions-of-rationals read in ℝ); size-of-a-product; size-of-a-negative. The leftover depends on g(x)
\delta_1 \text{ from away-from-zero}:\ \ \tfrac{1}{|g(x)|} \lt \tfrac{2}{|M|} @@ |g(x)| > |M|/2 > 0, and positive-reciprocal on ℚ turns the order
\text{so } \left|\tfrac{1}{g(x)} - \tfrac{1}{M}\right| \lt \htmlClass{new}{\tfrac{2}{M^2}}\,|g(x) - M| @@ order-and-arithmetic-agree; |M|·|M| = M² (size-squared)
\text{call } \delta_2:\ \ |g(x) - M| \lt \htmlClass{new}{\tfrac{M^2\varepsilon}{2}} @@ lim g = M at that gap: positive since M ≠ 0 (square-never-negative, positive-product on ℝ)
\begin{gathered}\delta = \min(\delta_1, \delta_2):\ \\\ \left|\tfrac{1}{g(x)} - \tfrac{1}{M}\right| \lt \tfrac{2}{M^2}\cdot\tfrac{M^2\varepsilon}{2} = \htmlClass{keep}{\varepsilon} \quad \blacksquare\end{gathered} @@ both promises; reciprocal on ℝ

It is 10a's one-over-x-limit again, one level up. There the inputs x were kept away from 0 by a first promise; here the outputs g(x) are, by away-from-zero. Limits-divide technique: if lim_{x→w} f(x) = L, lim_{x→w} g(x) = M and M ≠ 0, then lim_{x→w} (f/g)(x) = L/M. For x near w, (f/g)(x) = f(x) · (1/g)(x) (5c's line for dividing, read in ℝ). So f/g agrees near w with the product f · (1/g). Limits-multiply with reciprocal-limit gives L · (1/M) = L/M, and 10a's agreeing-near carries it over. ∎ Limits-add, limits-subtract, limits-multiply, constant-factor, power-limit, reciprocal-limit and limits-divide together are the limit techniques. Their accepted name is the limit laws: the rules for limits of sums, products and quotients.

The condition M ≠ 0 is not fussiness. When the bottom's limit is 0, the technique says nothing either way. (x² − 1)/(x − 1) has a bottom heading to 0 at 1, and still has a limit, 2, as 10a showed. 1/x has a bottom heading to 0 at 0 and has none, as 10e will show. The quotient technique is silent, and a 0/0 obtained by ignoring that silence is not an answer (10f).

10c5Constants, powers, polynomials

Everything else follows by stacking these. Constants: a constant function heads to its value (line-limit with m = 0). Constant-factor technique: lim_{x→w} (cf)(x) = cL when lim_{x→w} f(x) = L, by limits-multiply with the constant c. Limits-subtract technique: lim_{x→w} (f − g)(x) = L − M, since f − g = f + (−1)g, by constant-factor and limits-add. Power-limit technique: for every number n, lim_{x→w} fⁿ(x) = Lⁿ. By 4c's induction on n: f⁰ is the constant 1, heading to 1 = L⁰; and f^S(n) = fⁿ · f heads to Lⁿ · L = L^S(n) by limits-multiply and the hypothesis. ∎ With f(x) = x, which heads to w by line-limit, power-limit gives lim_{x→w} xⁿ = wⁿ for every n. 10a's square-limit is the case n = 2, now with no first promise in sight, because limits-multiply carries it.

Substitution technique: for a polynomial p, lim_{x→w} p(x) = p(w), for every real w; and for a rational function p/q with q(w) ≠ 0, lim_{x→w} p(x)/q(x) = p(w)/q(w). Write p(x) = Σ_{k≤n} u_k x^k (9g). Each term u_k x^k heads to u_k w^k, by power-limit and constant-factor. The sum heads to the sum of the limits, by limits-add and an induction on n with 9g's sum-one-more. So p heads to p(w). For p/q, limits-divide with q(w) ≠ 0. ∎

\lim_{x \to 2} \tfrac{x^3 - 3x + 1}{x + 1} @@ the bottom at 2 is 3, not 0: substitution's second half applies
= \tfrac{\htmlClass{new}{2^3 - 3 \cdot 2 + 1}}{\htmlClass{new}{2 + 1}} = \tfrac{3}{3} = \htmlClass{keep}{1} @@ substitute; arithmetic
\begin{gathered}\lim_{x \to -1} (x^2 + 4x)(2x + 5)\\ = \lim_{x \to -1}(x^2 + 4x) \cdot \lim_{x \to -1}(2x + 5)\end{gathered} @@ limits-multiply, then the names (10b)
= (1 - 4) \cdot 3 = \htmlClass{keep}{-9} @@ substitution on each factor

“Just substitute” was a habit. It is now a technique, with a condition: the bottom's value at w is not 0. Rung 11 gives the functions for which substituting always works a name of their own.

10c7Running it backwards

Handed a recipe such as min(1, ε/8, ε/4), read it: a first promise of 1, and two budgets, each a half of ε divided by the size of the other factor. Handed a limit of a combination, take it apart into the pieces the techniques know, check each condition (the bottom's limit not 0), and put it back. Handed a combination whose pieces have no limits, the techniques say nothing. Then you must play the game, or use the way round that 10d builds. Found upward; written downward.

Who said it first

The calculus book is Michael Spivak’s. The rules of 628 in 10c.4.4 are Brahmagupta’s; the astronomer five centuries later is Bhāskara II.

Spivak puts all the arithmetic of this proof into a lemma about reals alone: if x is within min(1, ε/(2(|y₀| + 1))) of x₀ and y is within ε/(2(|x₀| + 1)) of y₀, then xy is within ε of x₀y₀. The limit technique is then the lemma, the definition, and the least of the reaches.

Spivak, Calculus, ch. 5

Accepted names: the limit techniques are the limit laws (the sum, product and quotient laws, and so on); bounded-near says a function with a limit is locally bounded.
