30i · proof

Chance in One Function

Rung twenty-three stored a whole list of numbers in one function, and read the list back from the function’s slopes at zero. A count that depends on chance has a list too: the chance it is zero, the chance it is one, the chance it is two, and so on. Store that list, and one function holds everything about the count. Its slope at one gives the average. And when two independent counts are added, their functions simply multiply. This step uses that to answer a question first asked about family names in Victorian England: if each member of a family line has children by chance, how likely is it that the line dies out? The answer is a point where the function meets a straight line.

A whole-number chance variable is stored in its chance function, which gives back every chance and the average. Independent counts add by multiplying their chance functions, and a family line dies out with chance the least point where the function meets the line through zero at slope one.

30i1Storing the Chances

Let X take whole-number values 0, 1, 2, …, with pₖ = P(X = k). From here on, its chance function is the storing function (23j) of the list p₀, p₁, p₂, …:

G(s) = E sˣ = p₀ + p₁ s + p₂ s² + ⋯.

The sum settles for |s| ≤ 1, since |pₖ sᵏ| ≤ pₖ and the pₖ add to 1. Its accepted name is the probability generating function.

Chances-from-G technique: P(X = k) = G⁽ᵏ⁾(0)/k!, so two whole-number chance variables with the same chance function have the same chances. This is 23j’s read-back technique.

X = 1 \text{ with chance } p,\ 0 \text{ otherwise}:\ \ G(s) = 1 - p + ps @@ one coin, heads with chance p
X = \text{one fair die}:\ \ G(s) = (s + s^2 + \cdots + s^6)/6 @@ each face 1/6
X = \text{a rare count with average } \lambda:\ \ G(s) = \sum e^{-\lambda}\lambda^k s^k/k! = e^{\lambda(s - 1)} @@ 22j’s chances; the growth sum (23)

30i2The Average From the Slope

Average-from-G technique: E X = G′(1), meaning the number G′(s) heads to as s rises to 1.

G^{\prime}(s) = \sum_k k\,p_k\,s^{k-1} \text{ for } 0 \le s < 1 @@ term by term inside the reach (23e)
k\,p_k\,s^{k-1} \text{ rises to } k\,p_k \text{ as } s \text{ rises to } 1 @@ each term at least 0
\textstyle\sum_k k\,p_k\,s^{k-1} \to \sum_k k\,p_k = E\,X @@ rising-limit (30d1), with the counting size on 0, 1, 2, …
\htmlClass{new}{E\,X = G^{\prime}(1)} \quad \blacksquare @@ the average is the step-total (30g1)

Likewise G″(1) = E X(X − 1), so Var X = G″(1) + G′(1) − G′(1)². For the rare count, G′(s) = λe^(λ(s − 1)) and G″(s) = λ²e^(λ(s − 1)), so its average is λ and its spread is λ² + λ − λ² = λ: 22·stat’s spread equal to its average, now proved.

30i3Sums Multiply

Sums-multiply technique: if X and Y are independent whole-number chance variables, then GX+Y(s) = GX(s) GY(s).

s^{X + Y} = s^X s^Y @@ powers add (4g)
s^X \text{ and } s^Y \text{ independent} @@ each is built from X alone, or Y alone (30g3)
\htmlClass{new}{E\,s^{X+Y} = E\,s^X \cdot E\,s^Y} \quad \blacksquare @@ independent-averages-multiply (30g3)
  
n \text{ independent coins}:\ \ (1 - p + ps)^n @@ read back: P(k heads) = C(n, k) pᵏ(1 − p)ⁿ⁻ᵏ, 4·stat’s count
\text{rare counts } \lambda \text{ and } \mu:\ \ e^{\lambda(s - 1)}e^{\mu(s - 1)} = e^{(\lambda + \mu)(s - 1)} @@ a rare count with average λ + μ (chances-from-G)

So misprints on two pages, each a rare count, add to a rare count, as 22·stat found by summing. Here no sum is needed: the functions multiply, and read-back does the rest.

Anexact, yet rigorous · connections, not families

9a grouped things by how they connect, not by the family they came from. A chance law is known the same way. A count is a rare count because its chance function is e^(λ(s − 1)), whatever it counts: misprints, calls, crashes, or the sum of two rare counts.

A chance law is known by what its chance function does, not by where the count came from.

What the function does under adding is the law’s fingerprint. Two laws that multiply into the same function are the same law, however different their stories.

Calls to a help line in Victoria and calls to one in Portland are each rare counts. Is their total a rare count? What would you need to check, and what would you not?

30i4Will the Family Line Die Out?

One founder has children: a count with chance function G. Each child has children by the same law, independently, and so on down the generations. Zₙ is the number in generation n, with Z₀ = 1.

Dying-out technique: the line dies out with chance q, the least s in [0, 1] with G(s) = s.

E\,s^{Z_n} = \sum_j P(Z_{n-1} = j)\,G(s)^j = G_{n-1}\big(G(s)\big) @@ whole-chance (30f3) over Zₙ₋₁; j independent families multiply (30i3)
G_n = G \circ G \circ \cdots \circ G \ (n \text{ times}) @@ induction on n
q_n = P(Z_n = 0) = G_n(0) = G(q_{n-1}),\ \ q_0 = 0 @@ chances-from-G at k = 0
q_n \text{ rises and stays at most } 1 \Rightarrow q_n \to q,\ \ G(q) = q @@ G rises on [0, 1]; a climb under a ceiling (22a); G is continuous
r = G(r),\ r \ge 0 \Rightarrow q_n \le r \text{ for every } n \Rightarrow q \le r @@ q₀ = 0 ≤ r, and qₙ = G(qₙ₋₁) ≤ G(r) = r
\htmlClass{new}{P(\text{the line dies out}) = q,\ \text{the least root of } G(s) = s} \quad \blacksquare @@ dying out is the rising union of {Zₙ = 0}; rising sets (30d1)

G(1) = 1 always, so q ≤ 1. G bends upward on [0, 1]. If its slope at 1, the average number of children, is at most 1, the curve stays above the line until 1 and the line dies out with chance 1, unless every member has exactly one child. If the average is above 1, the curve crosses the line once before 1, and the line survives with chance 1 − q > 0.

The accepted names

The chance function is the probability generating function. The rare count is the Poisson distribution, and n coins give the binomial distribution. A family line in which each member has children by one law is a Galton–Watson branching process; the dying-out chance is the extinction probability. The cases with average below, at and above 1 are subcritical, critical and supercritical.

Who said it first

Abraham de Moivre used generating functions for dice in 1730, and Pierre-Simon Laplace made them a method in 1812. Francis Galton asked in 1873 why so many aristocratic family names die out, and Henry William Watson answered with the iterated generating function in 1874, though he wrongly concluded that every line dies out. Irénée-Jules Bienaymé had stated the correct answer in 1845, and Johan Steffensen gave the full proof in 1930.

A proof that is not allowed

“G(1) = 1, so s = 1 solves G(s) = s, so every family line dies out with chance 1.” Not allowed: the chance is the least root. When the average is above 1, a smaller root sits below 1, and that is the answer.
