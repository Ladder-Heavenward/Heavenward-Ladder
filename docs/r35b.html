35b · proof

The line cannot be listed

Rung 9 ran the diagonal on endless strings of zeros and ones: no list holds them all, because a string built to differ from each entry in one place is in no place. This step runs the same move on the line. Every real between zero and one has a decimal that never ends in endless nines, and two such decimals that differ in a digit are two different reals. So build a decimal that differs from the first real on the list in its first digit, from the second in its second digit, and so on. It is a real, and it is on no place of the list. The line is not countable. Then the last step’s list pays out. The algebraic reals can be listed and the line cannot, so some reals are not algebraic. The diagonal of the list of algebraic reals is one of them, and it can be computed digit by digit. And there is more. Every name anyone could write is a finite string of marks, so the named reals can be listed too, and most reals are left without a name of any kind.

Every list of reals misses one: change the nth digit of the nth entry, and keep away from nines. The algebraic reals have a list, so a real outside it exists, though the proof names none of the famous ones. Names can be listed, so almost every real has none.

35b1The diagonal, on the line

9a4’s diagonal technique: no list holds every function from ℕ to 2. Only one thing is new here. A real is not its digits, and two strings of digits can name one real: 0.1000… and 0.0999… are the same number. 8·cb5’s every-real-has-a-decimal technique repairs that. Each real x in [0, 1) has exactly one decimal 0.d₁d₂d₃… that never ends in endless 9s, and the digit rule gives it back. So a diagonal that uses no 9 and no 0 stays clear of the doubled names.

Unlisted-real technique: for every list x₀, x₁, x₂, … of reals in [0, 1), some real in [0, 1) is none of them.

x_n = 0.d_{n,1}\,d_{n,2}\,d_{n,3}\cdots @@ each entry’s decimal with no endless 9s (8·cb5)
e_k = 5 \text{ if } d_{k-1,k} \ne 5,\ \ e_k = 4 \text{ if } d_{k-1,k} = 5 @@ the kth digit of y differs from the kth digit of entry k − 1
y = 0.e_1\,e_2\,e_3\cdots \in [0, 1) @@ an endless decimal has a value (8·cb5’s endless-decimal technique); all its digits are 4 or 5
y\text{’s decimal is } 0.e_1e_2e_3\cdots @@ it has no 9 at all, so the digit rule gives these digits back
\text{assume } \htmlClass{new}{y = x_n} @@ to refute: y is listed at n
e_{n+1} = d_{n, n+1} @@ one real has one decimal with no endless 9s
\bot;\ \ \htmlClass{keep}{y \ne x_n \text{ for every } n} \quad \blacksquare @@ e_(n+1) was built to differ; refute; n was anything

So [0, 1) is not countable, and neither is ℝ, which holds it: a list of ℝ, with the entries outside [0, 1) struck out, would list [0, 1). 30a said that [0, 1] has more points than any list holds, and used it on trust in its basement. That is shown now. The line cannot be listed.

35b2Transcendental reals exist

23g3 held in trust that e and π are transcendental: roots of no polynomial with whole coefficients. Nothing on the ladder has yet shown that any real at all is transcendental.

Transcendentals-exist technique: some real is transcendental; the diagonal of a list of the algebraic reals in [0, 1) is one.

\text{the algebraic reals in } [0, 1) \text{ have a list } x_0, x_1, \ldots @@ the algebraic-list technique (35a4), with the entries outside [0, 1) struck out; not finite, since 1/2, 1/3, 1/4, … are among them
y = \text{its diagonal} @@ the unlisted-real technique
y \ne x_n \text{ for every } n @@ the same technique
\htmlClass{new}{y \text{ is not algebraic}} \quad \blacksquare @@ every algebraic real in [0, 1) is some xₙ

The proof is a recipe. Height by height, it says which roots to list and in what order; the digits of each root can be computed; and the nth digit of y needs only the first n entries. So y can be written out digit by digit, by a long and dull computation. What the proof does not do is name e or π. Those stay held in trust on 23g3. The rung knows that transcendental reals exist, and it has not shown that any famous number is one.

35b3Most reals have no name

9a4 listed the formulas: a formula is a finite string of marks from a finite stock, and such strings can be listed, shorter first. Any way of naming reals by strings, in any language, names at most countably many of them. List the strings, and put at each place the real its string names, if it names one. So the named reals are countable, and the line is not.

Countable-removed technique: if A cannot be listed and C is countable, then the part of A outside C cannot be listed. If the rest had a list, the countable-union technique (35a2), on two lists given, would list A. So the reals with no name cannot be listed, and the transcendental reals cannot be listed either. They are not a few strange exceptions. The algebraic reals, and the named ones, are the exceptions, and 30a2 already gives every countable set length 0.

A \text{ not countable},\ \ C \text{ countable},\ \ \text{assume } A \setminus C \text{ has a list} @@ to refute
A = C \cup (A \setminus C) @@ every member of A is in C or not (7d)
\text{two lists, of } C \text{ and of } A \setminus C,\ \text{both given} @@ if C is empty, A ∖ C is A
A \text{ has a list} @@ the countable-union technique (35a2), with no picking: the two lists are in hand
\htmlClass{new}{A \setminus C \text{ has no list}} \quad \blacksquare @@ clash with “A is not countable”; refute

The ladder can now say exactly what it means for most reals to have no name: the named ones can be listed, and what is left cannot. Which real is the first without a name? That question has no answer the ladder can give, because “the first real with no name” would be a name.

35b.4.5seam23g3 held in trust that e and π are transcendental. This step proves that transcendental reals exist and fill almost all of the line, by a list and a diagonal, without showing that any number anyone had met is one.
One side holds that a number exists in mathematics only when it can be built from the whole numbers in finitely many steps, and that a proof of “some real is transcendental” with no famous example says nothing. The other replies that the diagonal is a recipe, and the reals exist whether or not anyone writes them down.
Does the recipe for y satisfy the first side? Does a proof that most reals have no name satisfy it? Which side do you take, and what would change your mind?

The basement · there if you want it

The accepted names

A set that cannot be listed is uncountable. The unlisted-real technique is Cantor’s diagonal argument for the reals; the reroute of 35b.4.3 is his first proof, by nested intervals. The transcendentals-exist technique is Cantor’s proof of the existence of transcendental numbers. Reals that some finite description names are definable, or nameable; Borel called the others inaccessible. The real numbers whose digits a machine can compute are the computable numbers, and they too are countable.

Who said it first

Georg Cantor proved in 1874, in a paper on the algebraic numbers, that the line cannot be listed, by nested intervals, and so that transcendental numbers exist. Joseph Liouville had built the first explicit transcendental numbers in 1844 and 1851, by a different method that bounds how well an algebraic number can be approached by fractions. Cantor gave the diagonal in 1891, for strings of two letters. Leopold Kronecker, in Berlin, held that only what can be built from the whole numbers in finitely many steps exists, and opposed Cantor’s work; the remark “God made the integers, all else is the work of man” is reported of him, from a lecture of 1886. Émile Borel wrote of reals no finite description reaches in 1927. Alan Turing defined the computable numbers in 1936.

A proof that is not allowed

“Between any two reals there is a fraction (8e). So each real can be paired with a fraction just above it, and since the fractions are countable, so are the reals.” Not allowed: many reals are paired with the same fraction, so the pairing is not one-to-one, and nothing about the size of the reals follows.
