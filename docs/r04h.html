4h · support

Order

Rung 3 noticed that each named set is a member of every later one. That is the whole of “less than”, and this step makes it a definition: one number is less than another when it is a member of it. It then proves that this agrees with the other way of saying it: you can get from the smaller to the larger by adding something other than 0. It proves that any two numbers compare, exactly one of three ways. It proves that adding and multiplying keep order, so a product can be cancelled by a factor other than 0. A set of numbers you can check number by number has a least member as soon as it has a member. For any set of numbers, the most that can be said yet is that without a least member it has no members. And induction has a stronger form, which leans on every earlier case at once. Last, the moves with order that look right and are not.

One number is less than another when it is a member of it, which happens exactly when the larger is the smaller with something other than 0 added. Any two numbers compare. Order survives adding, and multiplying by anything but 0. A set of numbers you can check, with a member, has a least one, found by searching up from 0. And to prove a statement for a number you may assume it for every smaller number.

4h1Less than is membership

3b proved 4 = {0, 1, 2, 3}: the members of 4 are exactly the numbers named before it. 4c proved that every member of a number is a number (ℕ-is-transitive). It also proved that every number is a transitive set (numbers-are-transitive).

So inside a number sit exactly the numbers that come before it, and “comes before” can be read straight off ∈.

From here on, for numbers a and b, the statement means . Read it “a is less than b”.

From here on, means (“a is at most b”); means (“b is greater than a”); and means (“b is at least a”). Each of these is a statement, as a < b is.

Example: 2 < 4, because 2 ∈ {0, 1, 2, 3}. And 4 ≤ 4, because 4 = 4.

4h2What comes for free

The words less, more, smaller, larger, before, after, least and greatest have their meanings for numbers from here on, and only for numbers. A set that is not a number is neither less nor more than anything.

Several facts come for free from earlier rungs. Each number is less than its next one: p < S(p), by in-its-next. Nothing is less than 0, by the empty-set technique. No number is less than itself, by no-self-membership.

And less chains. Chain technique for less: if p is less than b and b is less than c, then p is less than c.

That is because c is a transitive set (numbers-are-transitive), so p ∈ b ∈ c gives p ∈ c. So 0 < 1 < 2 < 3 < 4 < S(4), as 3b's memberships said.

One founder of the subject defined the greater and the less through his chains: a number is greater than another when it lies in the chain that starts at the other's next one. With the sets this ladder takes as its numbers, that chain is simply membership, and less than is ∈.

4h3Less is adding: rightward

The other way to say “p is less than b” is “b is p with something other than 0 added”.

Less-is-adding technique: p is less than b exactly when b is p plus some number other than 0. In marks: p < b ⇔ ∃c ∈ ℕ (c ≠ 0 ∧ p + c = b).

Example: 1 < 3, and 3 = 1 + 2 with 2 ≠ 0.

Plan: prove the rightward direction first, by induction on b. In the step, split p < S(b) into p ∈ b or p = b, and find the c in each case.

\varphi(b):\ \forall a \in \mathbb N\,\big(a \lt b \Rightarrow \exists c \in \mathbb N\,(c \ne 0 \land a + c = b)\big) @@ the condition, with its gap at b
a \lt 0 \Rightarrow \dots @@ the base: a ∈ 0 clashes with the empty-set technique; everything permitted
\text{let } b \in \mathbb N;\ \text{assume } \varphi(b);\ \text{let } a \in \mathbb N,\ a \lt S(b) @@ the step opens
\qquad a \in b \lor a = b @@ ﹀ <; the next-membership technique
\qquad\quad \begin{aligned}&\text{case } a \in b:\ \ c \ne 0,\ a + c = b,\\ &\text{so } a + S(c) = S(b),\ S(c) \ne 0\end{aligned} @@ the hypothesis, using its some; plus-a-next and the swap axiom; next-never-empty
\qquad\quad \text{case } a = b:\ \ a + 1 = S(a) = S(b),\ \ 1 \ne 0 @@ the plus-one technique; the swap axiom; next-never-empty
\qquad \htmlClass{new}{\exists c \in \mathbb N\,(c \ne 0 \land a + c = S(b))} @@ show an example in each case; reason by cases

4h4Less is adding: leftward

Leftward: from c ≠ 0 and p + c = b, get p ∈ b.

Plan: write c as a next, then show p is in the next one after p + d, by a short induction on d.

Since c ≠ 0, zero-or-a-next and the remaining-option technique make c the next one after some number d. Then b = p + S(d) = S(p + d). So what is needed is that p ∈ S(p + d) for every d.

The base is p ∈ S(p + 0) = S(p), by in-its-next. For the step, if p ∈ S(p + d), then p ∈ S(S(p + d)) = S(p + S(d)), since S(p + d) ⊆ S(S(p + d)) by in-its-next.

Both directions together are less-is-adding.

4h5At most, and the next is not past

With c = 0 allowed, the same technique reads differently. At-most-is-adding technique: p is at most b exactly when b is p plus some number. In marks: p ≤ b ⇔ ∃c ∈ ℕ (p + c = b).

Its leftward direction splits c by zero-or-a-next. c = 0 gives p = p + 0 = b. c = S(e) gives p < b by less-is-adding.

From it comes a technique that is used constantly. Next-is-not-past technique: if p is less than b, then the next one after p is at most b. In marks: p < b ⇒ S(p) ≤ b.

Example: 1 < 3 gives S(1) ≤ 3, that is, 2 ≤ 3. And 2 < 3 gives 3 ≤ 3.

Proof: p + S(d) = b gives S(p) + d = S(p + d) = p + S(d) = b, by next-on-the-left for plus and plus-a-next, and so S(p) ≤ b by at-most-is-adding. No number sits strictly between p and its next one.

4h6Any two numbers compare

Any-two-compare technique: of two numbers, one is less than the other, or they are the same, and exactly one of these is true. In marks: exactly one of p < b, p = b, b < p is true. You know this one. Of any two piles, one is smaller or they are the same, and only one of those.

Example: for 2 and 3, only 2 < 3 is true. For 3 and 3, only 3 = 3.

Plan: “at least one” is an induction on the first number. “At most one” is 3a·f's techniques no-self-membership and no-loop.

\varphi(a):\ \forall b \in \mathbb N\,(a \lt b \lor a = b \lor b \lt a) @@ the condition, with its gap at a
0 + b = b,\ \text{so } 0 \le b,\ \text{so } \varphi(0) @@ the zero-plus technique; the at-most-is-adding technique; ﹀ ≤; add an option: the base
\text{let } a \in \mathbb N;\ \text{assume } \varphi(a);\ \text{let } b \in \mathbb N @@ the step opens
\qquad \text{case } b \lt a:\ \ b \in a \subseteq S(a),\ \text{so } b \lt S(a) @@ the in-its-next technique; ﹀ ⊆
\qquad \text{case } b = a:\ \ a \in S(a),\ \text{so } b \lt S(a) @@ the in-its-next technique; the swap axiom
\qquad \text{case } a \lt b:\ \ S(a) \le b,\ \text{so } S(a) \lt b \lor S(a) = b @@ the next-is-not-past technique; ﹀ ≤
\qquad \htmlClass{new}{S(a) \lt b \lor S(a) = b \lor b \lt S(a)} @@ add options; reason by cases, on the hypothesis used with b
\forall a \in \mathbb N\;\varphi(a) \quad \blacksquare @@ prove an if; speak of everything; the induction technique

At most one: p < b and p = b would give p ∈ p, which no-self-membership forbids. And p < b and b < p would be a loop, which no-loop forbids. So the three ways exclude each other, and exactly one is true.

4h7Order is settled

Notice what any-two-compare gives the ladder's logic. Settled-order technique: whether one number is less than another, and whether two numbers are the same, is always settled. In marks: p < b ∨ ¬(p < b), and p = b ∨ p ≠ b.

Neither is a use of 1f's either-way. Each comes from any-two-compare's “at least one”, which is an induction, and from no-self-membership and no-loop, which refute the other cases.

a \lt b \lor a = b \lor b \lt a @@ the any-two-compare technique, at least one: the induction above
\qquad \text{case } a \lt b:\ \ a \lt b \lor \neg(a \lt b) @@ add an option
\qquad \text{case } a = b:\ \ \text{assume } a \lt b @@ aiming to refute
\qquad\quad a \in a;\ \ \bot @@ ﹀ <; the swap axiom; the no-self-membership technique; clash
\qquad\quad \neg(a \lt b),\ \text{so } a \lt b \lor \neg(a \lt b) @@ refute; add an option
\qquad \text{case } b \lt a:\ \ \text{assume } a \lt b @@ aiming to refute
\qquad\quad a \in b \land b \in a;\ \ \bot @@ ﹀ <; join; the no-loop technique; clash
\qquad\quad \neg(a \lt b),\ \text{so } a \lt b \lor \neg(a \lt b) @@ refute; add an option
\htmlClass{new}{a \lt b \lor \neg(a \lt b)} \quad \blacksquare @@ reason by cases

The same three cases give p = b ∨ p ≠ b: the middle case is p = b, and in each outer case sameness would make a member of itself.

In 1f's word, sameness and order between numbers are settled: you can find their row. Every technique of 1f may be used both ways for statements built from them with ¬, ∧, ∨ and ⇒. And a case split on “p = b or not” is licensed for numbers without waiting for rung 7.

4h8At most is a part

One more reading of order. At-most-is-a-part technique: for numbers, p is at most b exactly when p is a part of b. In marks: p ≤ b ⇔ p ⊆ b.

Example: 2 ≤ 3, and {0, 1} ⊆ {0, 1, 2}.

Rightward, p < b gives p ⊆ b because b is transitive, and p = b gives p ⊆ b by self-part.

Leftward, split by any-two-compare. If b < p then b ∈ p ⊆ b, so b ∈ b, which no-self-membership forbids. When nothing is true, everything is permitted, so this case reaches p ≤ b as well, a note that goes when the case closes. The other two cases are p ≤ b.

So for numbers, ∈ is “less than” and ⊆ is “at most”. That is what 3b saw when it found each named set both a member and a part of each later one. Now it is proved for every number, as 3b said rung 4 would do.

4h9Adding keeps order

Keep-order technique for plus: adding the same number to both sides keeps the order. In marks: p < b ⇒ p + c < b + c. You already know it. If Ann is shorter than Ben, and both stand on the same box, Ann is still shorter.

Example: 1 < 2, so 1 + 3 < 2 + 3, that is, 4 < S(4).

Proof. By less-is-adding, b = p + d with d ≠ 0. Then b + c = (p + d) + c = (p + c) + d, by regroup for plus and turn-about for plus. So p + c < b + c by less-is-adding.

It runs the other way too. Suppose p + c < b + c, and split p and b three ways by any-two-compare. Then p = b would make p + c less than itself, and b < p would give b + c < p + c, a loop with what was given. So p < b.

4h10Multiplying keeps order

For multiplying, a factor of 0 wrecks everything, so first a technique about 0. No-zero-product technique: a product of two numbers, neither of them 0, is not 0. In marks: p ≠ 0 ∧ b ≠ 0 ⇒ p · b ≠ 0.

Proof. Write b = S(e) and p = S(f) by zero-or-a-next. Then p · b = (p · e) + S(f) = S((p · e) + f) by times-a-next and plus-a-next, and a next is never 0 (next-never-empty).

Now the keep-order technique for times: multiplying both sides by the same number, other than 0, keeps the order. In marks: p < b and c ≠ 0 give p · c < b · c.

Example: 1 < 2 and 2 ≠ 0, so 1 · 2 < 2 · 2, that is, 2 < 4.

a \lt b,\ \ c \ne 0 @@ given
b = a + d,\ \ d \ne 0 @@ the less-is-adding technique, using its some
b \cdot c = (a + d) \cdot c = (a \cdot c) + (d \cdot c) @@ the swap axiom; the spread technique for times over plus with turn-about for times (4g)
d \cdot c \ne 0 @@ the no-zero-product technique
\htmlClass{new}{a \cdot c \lt b \cdot c} \quad \blacksquare @@ the less-is-adding technique, leftward, with d · c as the witness

4h11Cancelling a product

And with keep-order for times, the cancelling 4g promised. Cancel technique for times: if products agree after multiplying by the same number, other than 0, they agreed before. In marks: c ≠ 0 and p · c = b · c give p = b.

Example: p · 2 = 3 · 2 gives p = 3.

Plan: split p and b by any-two-compare, and refute the two outer cases.

If p < b, then p · c < b · c by keep-order for times. Since p · c = b · c, by the swap axiom p · c is then less than itself, which no-self-membership forbids. If b < p, the same the other way about. Only p = b is left, and, since everything is then permitted, the other two cases give it as well.

4h12Strong induction

In an ordinary induction, the step from n to S(n) may lean on n alone. Sometimes the case at hand breaks into pieces that are not the number just before it but some earlier number. Strong induction lets you lean on every earlier case at once.

Strong induction technique: if, for every number n, φ is true at n whenever it is true at every number less than n, then φ is true at every number.

Plan: it is ordinary induction on a stronger statement: ψ(n), “φ is true at every number less than n”.

\psi(0):\ k \lt 0 \Rightarrow \varphi(k) @@ k ∈ 0 clashes with the empty-set technique; everything permitted: the base
\text{let } n \in \mathbb N;\ \text{assume } \psi(n) @@ the step opens
\qquad \varphi(n) @@ the given every, with n; carry through with ψ(n)
\qquad k \lt S(n) \Rightarrow k \lt n \lor k = n @@ the next-membership technique
\qquad\quad k \lt n:\ \varphi(k);\qquad k = n:\ \varphi(k) @@ ψ(n); the line above with the swap axiom
\qquad \htmlClass{new}{\psi(S(n))} @@ reason by cases; prove an if; speak of everything
\forall n \in \mathbb N\;\psi(n),\ \text{ and } n \lt S(n),\ \text{so } \htmlClass{new}{\varphi(n)} \quad \blacksquare @@ the induction technique; then ψ(S(n)) used with n, and in-its-next

There is no separate base in the statement, and there does not need to be. At n = 0, “φ at every number less than 0” says nothing, since nothing is less than 0. So the step at 0 must prove φ(0) with nothing to lean on.

The base is hidden inside the step, and a strong induction that forgets it is 4c's push-free row of dominoes.

4h13Reaching back two places

An example that needs it: every number is d + d or S(d + d) for some number d.

Plan: the cases 0 and 1 stand on their own; any other number reaches back two places.

The cases 0 = 0 + 0 and 1 = S(0 + 0) stand on their own. Any other number is S(S(m)) for some m, by zero-or-a-next used on it and then on the number before it. And m < S(S(m)) by in-its-next and chain for less, so strong induction lets you assume the claim for m.

If m = d + d, then S(S(m)) = S(S(d + d)) = S(d) + S(d), by plus-a-next and next-on-the-left for plus. If m = S(d + d), then S(S(m)) = S(S(d) + S(d)). Either way the claim is so for S(S(m)).

The step reached back two places, past the number just before, and that is what strong induction is for. (4j gives these two kinds of number their names.)

4h14Least members, and settled sets

From here on, for a set X of numbers, the statement “m is a least member of X” means .

Example: 2 is a least member of {2, 3}: 2 is in it, and 2 ≤ 2 and 2 ≤ 3.

A set has at most one: two least members m and m′ have m ≤ m′ and m′ ≤ m, and by any-two-compare's “at most one” they are the same. So it is “the” least member, when there is one.

How do you find it? The plain way is to search: is 0 in X? If not, is 1? If not, is 2? The first member you meet has nothing of X below it, and so it is the least.

That search asks, at each number, a question, “is n in X?”, and it needs an answer, yes or no, at every number. So the ladder names the sets for which the answer is always to be had.

From here on, for a set X of numbers, the statement “X is settled” means : whether a number is in it can be decided, number by number.

This is 1f's word “settled”, said now of a set: X is settled when each statement n ∈ X is settled in 1f's sense. Said of a statement, the word keeps 1f's meaning.

Most sets of numbers you meet are settled. A listed set, such as {2, 3}, is: n ∈ {2, 3} means n = 2 ∨ n = 3, and settled-order decides each part.

So is a sift of ℕ by a condition built from =, <, ≤, + and · with ¬, ∧, ∨ and ⇒. Sums and products of numbers are numbers (sums-are-numbers, products-are-numbers), and settled-order settles each sameness and each comparison. Settled statements joined by those marks are settled, by cases on each part's or.

4h15The search

Least-member technique: a settled set of numbers that has a member has a least member. You already use it: any group of people with someone in it has a youngest.

Plan: the proof is the search, written as an ordinary induction on the condition “either the least member is found, or nothing below n is in X”. Its accepted name is in the basement.

X \subseteq \mathbb N \text{ settled},\ \ \exists x\,(x \in X) @@ given. Write L for “X has a least member”
\psi(n):\ L \lor \forall k \lt n\,(k \notin X) @@ the condition: found it, or nothing below n is in X
\psi(0) @@ k < 0 clashes with the empty-set technique; everything permitted; add an option: the base
\text{let } n \in \mathbb N;\ \text{assume } \psi(n) @@ the step opens
\qquad \text{case } L:\ \ \psi(S(n)) @@ add an option
\qquad \text{case } \forall k \lt n\,(k \notin X) @@ the other side of ψ(n)
\qquad\quad n \in X \lor n \notin X @@ X is settled: use the every with n
\qquad\quad \text{case } n \in X;\ \text{let } x \in X @@ aiming at n ≤ x
\qquad\quad\quad x \lt n:\ \ x \notin X,\ \bot @@ any-two-compare on n and x; the case; clash
\qquad\quad\quad n \le x @@ everything permitted in that way; the other two ways are n ≤ x
\qquad\quad\quad L;\ \ \psi(S(n)) @@ n is a least member: join; speak of everything; show an example; add an option
\qquad\quad \text{case } n \notin X;\ \text{let } k \lt S(n) @@ aiming at k ∉ X
\qquad\quad\quad k \lt n \lor k = n;\ \ k \notin X @@ the next-membership technique; the case; the swap axiom
\qquad\quad\quad \psi(S(n)) @@ prove an if; speak of everything; add an option
\qquad \htmlClass{new}{\psi(S(n))} @@ reason by cases, each time

Look at the line where the column split on n ∈ X ∨ n ∉ X. That or was not invented; it was given, because X is settled. Without it the search has no way to know, at n, whether to stop.

Some least members, each of a settled set. The least member of {x ∈ 4 : x ≠ 0} is 1. The least member of the numbers greater than 2 is 3. For 3 is one of them, and any x with 2 < x has S(2) ≤ x by next-is-not-past.

ℕ's least member is 0, since 0 ≤ b for every b. And the technique has a partner that fails: ℕ has no greatest member, since every n has n < S(n).

4h16No least, no members

So for a set of numbers in general, a set picked out by some condition whose truth you cannot decide number by number, the ladder can prove less. Strong induction proves it at once.

No-least-no-members technique: a set of numbers with no least member has no members.

Plan: strong induction on “n ∉ X”, refuting n ∈ X at each n.

X \subseteq \mathbb N,\ \ \neg\exists m\,(m \text{ is a least member of } X) @@ given
\text{let } n \in \mathbb N;\ \text{assume } \forall k \lt n\,(k \notin X) @@ strong induction on φ(n): n ∉ X
\qquad \text{assume } n \in X;\ \text{let } x \in X @@ aiming to refute
\qquad\quad \begin{aligned}&x \lt n:\ x \notin X,\ \bot,\ \text{so } n \le x;\\ &x = n \text{ or } n \lt x:\ n \le x\end{aligned} @@ any-two-compare on n and x; the hypothesis; clash; everything permitted
\qquad n \text{ is a least member of } X;\ \ \bot @@ join; show an example; clash with the given
\qquad \htmlClass{new}{n \notin X} @@ refute
\forall n \in \mathbb N\;\; n \notin X \quad \blacksquare @@ the strong induction technique

No case split on n ∈ X was needed: the proof refutes n ∈ X instead of deciding it.

Turn no-least-no-members about with 1d's turn-and-deny technique for If, and it says: if X has a member, then it is not so that X has no least member. That is ¬¬(X has a least member), the full statement with a double negative in front. 1b left the step from ¬¬P to P out on purpose, and rung 7 removes the double negative.

So the ladder now has least members in two strengths. For settled sets it has the whole statement, by the search. For any set of numbers it has the statement one ¬¬ short.

4h18Running it backwards

Wanting p < b, look for the c ≠ 0 with p + c = b and cite less-is-adding, or exhibit p ∈ b directly.

Wanting p = b between numbers, any-two-compare lets you refute the other two ways: show p < b leads to something totally false, and b < p too.

Wanting to cancel, check that the thing cancelled is the same on both sides and, for a product, not 0.

Wanting a least member, check that the set is settled, start from a member and cite least-member. A listed set is settled, and so is a sift by a condition built from =, <, + and · with the joining marks. The search up from 0 is the column. For any other set, no-least-no-members is what you have.

Wanting φ(n) for every n when the step reaches back further than one place, use strong induction, and remember that its step at 0 has nothing to lean on. Found upward; written downward.

Who said it first

The founder is Richard Dedekind; the choice of sets for the numbers that makes less than membership is John von Neumann's.

Dedekind defined the greater and the less through his chains: a number is greater than another when it lies in the chain that starts at the other's next one. On von Neumann's choice of which sets are the numbers, that chain is simply membership, and less than is ∈.

Dedekind, Was sind und was sollen die Zahlen? (1888), on the greater and the less, trans. Beman, 1901; von Neumann, “Zur Einführung der transfiniten Zahlen” (1923)

Accepted names

Any-two-compare is the law of trichotomy, from the Greek for “a cutting in three”. The least-member technique, in its full form for every set of numbers, is the well-ordering principle, and ℕ is said to be well-ordered.
