Sets Collect Type, Bigness and Order

A set can collect by type, by bigness, or by order, alone or together. This step takes five things and collects them each way. A set keeps none of the order itself: same members, same set. So each order needs a keeper, and the ladder has two, pairs and nesting. The numbers of 3c are kept by nesting, and that is why one number can say both which place and how many.

Say what the set looks at: type, bigness or order. If it looks at an order, say what keeps it.

3e1Type

Take five things that are not sets: three cats, a, b and c, and two dogs, d and e. The set C = {a, b, c} collects the cats and leaves out the dogs. D = {d, e} collects the dogs.

Now gather the two: {C, D}. It holds all five pets, as types only. Its members are C and D, two of them; the pets are members of its members. It says nothing of how big any pet is, or which came first.

3e2Order of Joining

Say the pets joined the house in the order a, b, c, d, e. Then a is first, b second, c third, d fourth and e fifth.

The member that joined latest, whatever its place, is also called last. e is last now; if another pet joins, e is last no longer. When nothing will come after it, last is also called final.

Write the pets as a set, {a, b, c, d, e}, and the order is gone: by the same-members axiom it is {e, d, c, b, a} too. The listing shows an order; the set does not keep it. 3e4 says where an order is kept.

Question

  1. 3e2.1understandWhat is the difference between last and final?
    Why does {a, b, c, d, e} not keep the order of joining?

3e3Bigness Takes the Order

Put the same five pets in a line by size, largest first: say e, a, d, b, c. Once the set looks at bigness, bigness sets the order. e is first because it is largest, and c is last because it is smallest.

The members did not change. The order changed, because what the set looked at changed. So an order is not in the members: it comes from what is looked at.

3e4Where the Order Is Kept

A set has no order of its own: same members, same set (2d). An order needs a keeper. The ladder has two.

Pairs (2h). A pair (x, y) does keep which comes first. The bigness order is the set of pairs “x is bigger than y”: (e, a), (e, d), (a, d), and so on, one pair for each two pets.

Nesting (3c). The joining order is kept by the sets so far: {a}, {a, b}, {a, b, c}, {a, b, c, d}, {a, b, c, d, e}. Each is a part of the next, and a pet’s place is the first of these sets it is in.

The numbers of 3c are kept the second way. Each is the set of those before it and is a member and a part of the next (3c7). The order of the run is in its nesting, not in any listing.

3e5The Two Counts

“3rd base” is order: which place. “3 to 2” is bigness: how many on each side. They are two counts, and they answer two questions.

A number of the run answers both. 3 = {0, 1, 2}. As bigness, it has three members. As order, its members are exactly the numbers before it, so it comes after three of them. The run starts at 0, so the count of places before a number and the count of its members agree.

3e8Running It Backwards

Handed a collection, ask what it looks at: type, bigness or order. Handed an order, ask what keeps it: pairs or nesting. Handed “the third”, ask third by what. Handed a number of the run, read its place and its size from its members. Found upward; written downward.

Accepted names

How many members a set has is its cardinal number, or cardinality; which place a member holds in an order is its ordinal number. A set that keeps an order with it is an ordered set; the bigness order here is a strict order. The numbers of 3c, kept by nesting, are the finite von Neumann ordinals, and for them the cardinal and the ordinal agree.
