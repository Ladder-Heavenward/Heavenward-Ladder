2d · proof

Membership and Same Members

This step gives the rung its objects. A set is a gap many things fit, taken as one thing; its first axiom says there is one with nothing in it. Rung 1’s moves still work on sets, with rounder marks. A set is a thing whose whole nature is to have members, and “is a member of” gets a mark, the way “is the same thing as” did on 0b. Then comes the same-members axiom: if the same things are in each of two sets, then they are the same set. It is said in words, then in marks, then put to work. Every proof about sets ends by citing it, after a member has been chased through both descriptions. From it the step defines “subset”. It proves that every set is a subset of itself, and that sets are the same exactly when each is a subset of the other. And it insists, with a worked refusal, that being a member and being a subset are different things.

A set is nothing but its members. To show sets are the same, let a thing be anything and show it is in either exactly when it is in the other. Being in a set and being part of a set are different claims; the marks keep them apart.

2d1A Gap Many Things Fit

0a made statements with a gap, such as “… is furry”. Put the name of a cat in the gap, and the statement is so. “Cats are furry” fills that one gap with an awful lot of cats at once. So there is a kind of gap that many things can fit.

The things that fit, taken together as one thing, are a set. The everyday word is a collection. The things in it are its members. A set has its members and nothing else: no order among them, no arrangement, no history of how it was described. The people in a room are a set, and Zoe is a member of it. The colours a traffic light shows are a set, and amber is a member. Which colour lit first is no part of the set. A set is a thing in its own right, so a letter can name it. And 0b's sameness mark can stand between names of sets: u = v says that u and v are the same set, whatever names they go by.

Sometimes nothing fits the gap. No cat fits “… is a cat that can fly”. The rung lays that case down first, as its first axiom.

Empty-set axiom: there is a set with nothing in it. Without it, the tools of this rung would have nothing to work on: every one of them takes a set in, and 2e shows that a sieve needs a bowl.

It is held in trust, like every axiom: everything after it stands on it. 2e9 writes it in marks, 2e11 proves there is only one such set, and 2e12 gives it a mark of its own. The ladder will also call it 0. Rung 3 shows why that name fits.

Every way rung 1 changed and joined statements still works when the gap holds a set. The marks just get rounder, to show that sets are being talked about and not single names:

The tools of this rung, sift, gather and merge (2e, 2f), are rung 1's moves used again and again on sets. Simple moves, many inputs. The rules come in an order that keeps every member where it belongs.

A set is an object in the ladder's sense: a name whose relationships to other names can be proved. 0b gave the first operator. Operators and objects together are most of the mathematics ever done.

Sets on this rung are written in three ways, and it helps to see them all at once. Braces around a list name the set whose members are exactly what is listed: {cat, dog} is the set whose members are cat and dog (2d3 makes this exact). A set is a thing, so like any thing it takes a small letter: r for the people in the room, u and v for sets in general. A set whose members are all sets takes a curly capital, 𝒜 (2g2).

Example sets come in two kinds, and the ladder keeps them apart. A pictured set shows what sets are like; a built set shows that a set is there. A pictured set is made of everyday things, like the pets at home or the people in a room. It is written as if we had it, the way 0a let you name a cat before saying anything about cats, and no proof leans on it being there. A built set comes from this rung's tools (sift, gather, merge, power set), starting from the empty set of the empty-set axiom. Every line of its building carries a reason.

2d2The Mark for “is in”

“Is a member of” is said so often that it wants a mark, and here is the line that brings it in:

An example. Let r name the people in the room. Then Zoe ∈ r says Zoe is in the room's set. Membership is a statement in 0a's sense: so or not so, able to stand on a line with a reason beside it, able to be denied. The accepted name for a member is element, so Zoe ∈ r may also be read “Zoe is an element of r”. Its denial is common enough to want a mark too, exactly as ≠ did on 1b:

Every proof about ∉ begins by unpacking it into ¬(x ∈ u), and ends by packing it back. That is 1a7's rule, and the habit 1b7 made with ≠ carries over whole.

Ask of a lamp “is it on?” and 1 means on, 0 means off. Ask of a seat “is anyone in it?” and 1 means present, 0 means absent. The pairs (0 no / 1 yes, 0 off / 1 on, 0 passive / 1 active, 0 nothing / 1 thing, 0 absent / 1 present) are subsets of resultant guesses based on the parameters of the input or proof in question. For membership, the question is “is x in u?”: 1 when it is, 0 when it is not, as 1e1’s machines answer.

The mark was chosen by one of the inventors of these marks. It is a bent form of the Greek letter that begins the Greek word for “is”. You do not need the Greek letter; the mark is introduced here by its line, and that is all a mark ever needs.

2d5Sets With One Member, and Sets of Sets

The braces mark what belongs together, like brackets. Braces around a single name write a set with that thing as its only member. {cat} is an example: x ∈ {cat} ⇔ x = cat. Braces around braces write a set whose only member is itself a set. {{cat}} is an example. Its only member is {cat}; cat itself is not on its list. Sets can be members of sets; nothing in the word “set” forbids it, and the rung will lean on it constantly.

2d6Same Members, in Words

Here is the rung's axiom. If the same things are in each of u and v, then u and v are the same set. Said in another way: a set has no ingredients other than its members. Said in the way of one of the subject's founders: a set is completely settled once it is settled, for every thing whatever, whether that thing is in it or not.

The founder quoted in the rung 2 survey called the collection a whole made of “definite and separate objects”. Definite, so that of each thing it is settled whether it is in. Separate, so that a thing is in or not in, and being in again is nothing. So a set is how far it goes: which things it covers, and nothing else about it. The ladder calls this axiom the same-members axiom.

2d7Same Members, in Marks

“The same things are in each” is an every around an exactly-when, in 2b's spelling, and “then they are the same set” is 0b's mark. So:

Read it: for every thing x, x is in u exactly when x is in v; if that is true, u is v. Like 0b's axioms it is a pattern, fillable with any names of sets.

The other direction needs no axiom. Rows hold u = v. Let x be any member of u: by the swap axiom, x ∈ v; so every member of u is in v. Let x be any member of v: turn u = v about and swap, and x ∈ u; so every member of v is in u.

The plan, in one line: an every of a kind each way, use both on any x, join the ifs, pack the ⇔, speak of everything. So rows that hold u = v reach ∀x (x ∈ u ⇔ x ∈ v), and the axiom runs the other way. Read together, each gives the other, and only the leftward way was an axiom:

Same-members axiom: sets with the same members are the same set. It speaks of sets only. Nothing beneath it proves it. Without it, two sets with exactly the same members could still be different sets, and a sift could not name one set: “the fliers” would not pick anything out. It is the leftward arrow of the line just above.

A set u is part of a set v when everything in u is in v. Mike plays for the Bulls, and the Bulls play in the NBA. Read the NBA as its players. Then everyone on the Bulls is in the NBA, so the Bulls' set is part of the NBA's set. (2d13 reads the NBA another way.) The mark and its meaning:

The word subset is the technical word for “part of” in this sense, and it means exactly the every-around-an-if on the right of the line and nothing more. The mark is a statement with two gaps, the packed form of that every-around-an-if. Two examples:

In plain words, a subset is another list, every name on which is also on the first. You get every subset of a list by going down it once and deciding, for each name, keep or drop. Take the towns of a county. Each town is a member. “The towns on the river,” “the towns with a hospital,” and “the towns on the river with a hospital” are subsets, and the third is a subset of the other two. The whole list is a subset of itself, since nothing was dropped and nothing added. “Nothing else” is a subset too, as it is of every list.

Now the technique this step exists for. Sets are the same exactly when each is a subset of the other. The direction from inclusions to sameness is the same-members axiom dressed in ⊆. The direction from sameness to inclusions is the swap axiom and the self-part technique.

2d12In, and Part of: Keep Them Apart

The confusion everyone makes, and after this step should not: ∈ and ⊆ say different things. Cat is in {cat, dog}: a member, listed. {cat} is part of {cat, dog}: a subset, since its only member is a member. But {cat} cannot be in {cat, dog}: the members of {cat, dog} are cat and dog, and {cat} is neither. A cat is not a set, and {cat} is. Here it is in rows, with the facts about cats laid down as givens because the ladder cannot look at a cat.

Given: a cat is not a set, and a dog is not a set; they are animals. Given too: {cat} is a set, since braces write a set (2f builds it).

Rows hold the givens and {cat} ∈ {cat, dog}. Unpack the listing: {cat} = cat, or {cat} = dog. Set in the cases. In the case {cat} = cat, the swap axiom turns “{cat} is a set” into “cat is a set”. That clashes with the given: ⊥. In the case {cat} = dog, dog is a set in the same way: ⊥ again.

Both cases close, so the rows equal ⊥: {cat} ∈ {cat, dog} cannot stand beside the givens. Writing the denial, , is a box’s output, and 3a earns it.

Against that, {cat} ⊆ {cat, dog} is proved on the slides in a few short steps, and the contrast is the lesson. The marks look alike and the English (“in”, “part of”, “belongs to”, “is among”) blurs them; the definitions do not. A test you can always run: ∈ asks whether a thing is on the list. ⊆ asks whether every member of a thing is on the list, and so only makes sense of a set.

Keeping the container apart from its contents is the whole of it. A shelf with an empty box on it. The shelf’s list: “the box, and nothing else.” One member, the box. Two subsets: “the box” and “nothing else.” The box’s contents, as a list: “nothing else.” No members, one subset. The box and the shelf’s empty subset are not the same thing; one is a thing on a shelf and the other is where a list ends. The box is not nothing; the contents of the box are nothing. A thing can be in a list without being a list.

The old joke marks the error exactly. “If you have nothing in your pocket, I will eat my hat.” “Well sir, I have nothing in my pocket, right next to my matchbook.” Nothing is not next to the matchbook. “Nothing else” is where the list of the pocket’s contents ends, and the hat is safe.

2d13Bags Inside Bags

The same care applies to {{cat}}. Its only member is {cat}. So {cat} ∈ {{cat}}. The cat itself is not on the list of {{cat}}: rows that hold cat ∈ {{cat}} reach cat = {cat}, so the cat is a set, and that clashes. Nor can {{cat}} and {cat} be the same set: swapping them would put {cat} in {cat}, and the same clash follows. Bags inside bags: a bag holding a bag holding a cat is not a bag holding a cat.

Go back to 2d9's Mike, the Bulls and the NBA, and read the NBA as its teams this time. Then the Bulls are a member of the NBA. Mike is a member of the Bulls. But Mike is not a member of the NBA: he is not a team. He is a member of a member. Read the NBA as its players, and Mike is in it, and the Bulls are part of it. 2d14One in at the Bottom, Part of All the Way Up

Now a chain from further off. Dip a cup into Puget Sound, and treat each body of water as the set of its molecules. One molecule, m, is a member of the cupful. Every molecule of the cupful came from the Sound, so the cupful is part of the Sound. (2e shows why that step is free: the cup is a sift.) The Sound is part of the Salish Sea, and the Salish Sea, an inlet, is part of the Pacific. The Pacific is part of all the water on Earth. One ∈ at the bottom, then ⊆ all the way up, and the chain technique for part of carries m to the top:

Now try a chain of ∈ instead. The school is a member of the set of schools in the district, {Lincoln, Grant, Hill}. m is in the school, and the school is in that set. But m is not a school, so m is not a member of the set of schools.

A member of a part is a member; a member of a member, as a rule, is not. The English word “in” covers both, which is why the marks are kept apart.

Living things are sorted the same way, level inside level. A barn owl is a member of the barn owls. The barn owls are part of the owls, and the owls are part of the birds. Read each level as its animals, and each is part of the next, so the barn owl is a bird. Read each level as its kinds, and each kind is a member of the next. The owls come in two families, the barn owls and the typical owls, and neither is part of the other. Sorting things into kinds, and kinds into bigger kinds, is ∈ and ⊆ kept carefully apart.

Other ways the same marks are written

Mathematics writes some of these marks in more than one way, by subject and by century. Each one below means what the mark in this step means; know them on sight.

  • v ⊇ u and v ⊋ u say the same as u ⊆ v and u ⊊ v, turned about; u ∋ x says the same as x ∈ u.
  • Books split over ⊂: some mean ⊆ by it, others mean ⊊. The ladder never writes it; when you meet it, find out which the book means.

The accepted name

The axiom of 2d6 has an accepted name: extensionality. The name comes from an older distinction. A description has a meaning and a coverage. The meaning is called its intension; the coverage, its extension. Take “the colours a traffic light shows”. Its intension is that phrase. Its extension is red, amber and green. The axiom says that a set is its extension, and its intension is nothing to it. However you came to describe a set, if you covered the same things, you named the same set.

The ladder picks the name up again when it next matters, on rung 31.

Who said it first

The mark ∈ is Giuseppe Peano’s. The founder who put extensionality in one line is Richard Dedekind; the founder the survey quoted, with “definite and separate objects”, is Georg Cantor. The four old sentences and the syllogism Barbara are Aristotle’s.

Dedekind put it in one line: a system S is the same as a system T when every element of S is an element of T and every element of T is an element of S. Nothing else about a system, he said, counts toward which system it is.

Dedekind, Was sind und was sollen die Zahlen? (1888), §2–3, trans. Beman, 1901; paraphrase

How engineers set the pair

A doorbell button can be wired so that pressing it sends a 1: 1 means pressed, 0 means not. Another button can be wired the other way round, so that pressing it sends a 0. Same button, same two marks, opposite meanings. This is how engineers work. Whoever designs a circuit settles what each 1 and 0 answers before anything else is built, and writes it into the design. A signal where 1 means yes is called active-high; one where 0 means yes is called active-low. The marks carry nothing until the design says which question they answer. That is 2d2’s pairs at work: the parameters of the input decide the pair.
