25f · technique

Maps of the Plane

Rung twenty moved the plane by slides, turns, flips and stretches, and wrote each move with coordinates. With the new numbers most of those moves fit in one short line. Multiply by a number and add another: that turns, stretches and slides at once, and every such move has a centre it spins about, unless it is a pure slide. Then comes a move rung twenty never met. Taking one over a number turns the plane inside out. Points near the middle fly far away, far points crowd in near the middle, and the circle of size one stays where it is, flipped. That move bends straight lines into circles. Yet it never makes anything that is not a circle or a line. Put the two kinds of move together and you have the maps that send circles and lines to circles and lines, each fixed by four numbers. They need one extra point, far away, to land on, and that point was waiting for them since the day dividing by zero was refused.

Multiplying by a number and adding another turns, stretches and slides the plane. Taking one over a number turns it inside out, and sends circles and lines to circles and lines. A quotient of two such straight maps does both, and needs one far point to be defined everywhere.

25f1Turn, Stretch and Slide

From here on, a straight map is a map z ↦ az + b of the plane, with a ≠ 0. 20·cb8 read multiplying by a as 20j4’s turn and stretch, and adding b as a slide.

Straight-map technique: z ↦ az + b is the turn by a/|a|, then the stretch by |a|, then the slide by b; it multiplies every distance by |a| and keeps which way round every triangle goes. If a ≠ 1, it fixes exactly one point, z* = b/(1 − a), and it is the turn and stretch by a about z*.

a = |a|\,u,\ \ |u| = 1 @@ u = a/|a|; sizes multiply (25c1)
z \mapsto uz \text{ is a turn},\ \ z \mapsto |a|z \text{ a stretch},\ \ z \mapsto z + b \text{ a slide} @@ the turn-is-a-pair technique (20j1); a positive real is a stretch (20·cb8.1); adding pairs is a slide (20·cb8.1)
|(az + b) - (aw + b)| = |a|\,|z - w| @@ the product-size technique (25c1): a similarity with factor |a| (20a)
\text{turns and slides keep } D;\ \text{a stretch by } k > 0 \text{ multiplies it by } k^2 @@ 20g; D is a sum of products of two coordinates
az^* + b = z^* \iff z^*(1 - a) = b \iff z^* = \tfrac{b}{1 - a} @@ a ≠ 1: divide
az + b - z^* = az + (z^* - az^*) - z^* = a(z - z^*) @@ b = z* − az*
\htmlClass{new}{az + b = z^* + a(z - z^*)} \quad \blacksquare @@ slide z* to 0, turn and stretch by a, slide back
  
z^* = \tfrac{2}{1 - i} = \tfrac{2(1 + i)}{(1 - i)(1 + i)} = 1 + i @@ the straight-map technique; divide by the flip (20·cb8.4)
|i| = 1 @@ no stretch: an isometry
\htmlClass{new}{z \mapsto iz + 2 \text{ is the quarter turn about } 1 + i} \quad \blacksquare @@ check: 0 − (1 + i) = −1 − i, times i is 1 − i, plus 1 + i is 2

When a = 1 the map is a pure slide, and it fixes no point unless b = 0. So every straight map is a slide or a spin about one centre. The flips are the moves that are missing: z ↦ z̄ changes which way round a triangle goes, so it is no straight map. z ↦ a z̄ + b gives the rest.

25f2Inside Out

From here on, the circle swap is the map z ↦ z/|z|², for z ≠ 0. It keeps each point on its own ray from 0, and sends size r to size 1/r.

Inside-out technique: for z ≠ 0, 1/z = z̄/|z|², the flip of the circle swap of z. So z ↦ 1/z sends size r to size 1/r, swaps the inside and the outside of the circle |z| = 1, keeps that circle, sending each z on it to z̄, and undoes itself.

z\,\overline{z} = |z|^2 \ne 0 \Rightarrow \tfrac1z = \tfrac{\overline{z}}{|z|^2} @@ the flip technique (25a3); divide by |z|²
\tfrac{\overline{z}}{|z|^2} = \overline{\Big(\tfrac{z}{|z|^2}\Big)} @@ 1/|z|² is on the floor, its own flip
\tfrac{z}{|z|^2} \text{ is on the ray of } z, \text{ at size } \tfrac{1}{|z|} @@ a positive real times z is a stretch (20·cb8.1); sizes multiply (25c1)
|z| < 1 \iff \big|\tfrac1z\big| > 1,\ \ |z| = 1 \Rightarrow \tfrac1z = \overline{z} @@ size 1/|z|; and |z|² = 1
\htmlClass{new}{\tfrac{1}{1/z} = z} \quad \blacksquare @@ it undoes itself

So 2 goes to ½, 3i goes to −i/3, and 1 + i goes to (1 − i)/2. Points near 0 go far out, and far points come in near 0. The point 0 itself goes nowhere: 1/0 is still refused. The last footing gives it a place to go.

25f3Circles and Lines

Write z = x + iy. 18d found that x² + y² + Dx + Ey + F = 0 is a circle exactly when D² + E² − 4F > 0. Multiply through by a number A ≠ 0, and let A = 0 give the lines: the circles and the lines are exactly the sets A(x² + y²) + Bx + Cy + D = 0 with A, B, C, D real and B² + C² > 4AD.

Circle-or-line technique: z ↦ 1/z sends the points other than 0 of the set A(x² + y²) + Bx + Cy + D = 0 to the points other than 0 of the set D(u² + v²) + Bu − Cv + A = 0, where 1/z = u + iv. So it sends every circle or line to a circle or a line, and so does every straight map.

u + iv = \tfrac1z = \tfrac{x - iy}{x^2 + y^2},\ \ u^2 + v^2 = \tfrac{1}{x^2 + y^2} @@ the inside-out technique (25f2)
\tfrac{A(x^2 + y^2) + Bx + Cy + D}{x^2 + y^2} = A + Bu - Cv + D(u^2 + v^2) @@ divide each term by x² + y² ≠ 0
\text{the left side is } 0 \iff \text{the right side is } 0 @@ x² + y² ≠ 0
B^2 + (-C)^2 > 4DA \iff B^2 + C^2 > 4AD @@ the new set is again a circle or a line (18d)
\htmlClass{new}{\text{circles and lines go to circles and lines}} \quad \blacksquare @@ and straight maps keep them: a similarity (25f1) sends a circle to a circle, a line to a line

The swap of A and D tells which goes where. D = 0 means the set passes through 0. So a circle through 0 goes to a line not through 0, and back; a line through 0 goes to a line through 0; a circle missing 0 goes to a circle missing 0.

A = 0,\ B = 1,\ C = 0,\ D = -1 @@ x − 1 = 0
-(u^2 + v^2) + u = 0 @@ the circle-or-line technique
\htmlClass{new}{\big(u - \tfrac12\big)^2 + v^2 = \tfrac14} \quad \blacksquare @@ the circle with centre ½ and radius ½, through 0

The images are circles, but centres do not go to centres. The circle |z − 2| = 1 has its centre at 2, and its image has its centre at 2/3, not at ½. Only the circle as a whole is kept as a circle.

25f4Four Numbers, One Map

Four-number technique: for a, b, c, d in ℂ with ad − bc ≠ 0, the map z ↦ (az + b)/(cz + d) is a straight map when c = 0, and otherwise a straight map, then z ↦ 1/z, then a straight map. So it sends circles and lines to circles and lines. One such map after another is another, with ad − bc multiplied, and each has an undoing of the same kind, w ↦ (dw − b)/(−cw + a).

c = 0:\ \tfrac{az + b}{d} = \tfrac{a}{d}z + \tfrac{b}{d},\ \ ad \ne 0 @@ a straight map
c \ne 0:\ \tfrac{az + b}{cz + d} = \tfrac{a}{c} + \tfrac{bc - ad}{c}\cdot\tfrac{1}{cz + d} @@ put the right side over one bottom: a(cz + d) + bc − ad = c(az + b)
z \mapsto cz + d \mapsto \tfrac{1}{cz + d} \mapsto \tfrac{a}{c} + \tfrac{bc - ad}{c}\cdot\tfrac{1}{cz + d} @@ straight, inside out, straight: bc − ad ≠ 0
w = \tfrac{az + b}{cz + d} \iff z(cw - a) = b - dw \iff z = \tfrac{dw - b}{-cw + a} @@ cross-multiply; again da − bc ≠ 0
\tfrac{a'w + b'}{c'w + d'} \text{ at } w = \tfrac{az + b}{cz + d} = \tfrac{(a'a + b'c)z + (a'b + b'd)}{(c'a + d'c)z + (c'b + d'd)} @@ multiply top and bottom by cz + d
\htmlClass{new}{\text{the new } ad - bc \text{ is } (a'd' - b'c')(ad - bc) \ne 0} \quad \blacksquare @@ share out; the four cross terms cancel

One point has no image: the z with cz + d = 0. 5·cb2 sorted the pairs (p, q) into classes of equal fractions, and one class was left over, the class of (1, 0), a fraction with bottom zero. Here it earns a place. Add one far point, written ∞, to the plane. Let the map send −d/c to ∞ and ∞ to a/c, and let a straight map keep ∞. Then every four-number map is one-to-one from the plane with its far point onto itself, and the lines are the circles through ∞. Nothing is divided by zero: ∞ is a new point, not a number to compute with.

x \text{ on the floor} \Rightarrow |x - i| = |x + i| @@ x + i is the flip of x − i; a flip keeps size (25c1)
\Big|\tfrac{x - i}{x + i}\Big| = 1 @@ sizes multiply (25c1)
\text{upright part of } z > 0 \Rightarrow |z - i| < |z + i| @@ z is nearer to i than to −i: (y − 1)² < (y + 1)² when y > 0
\htmlClass{new}{\text{the floor goes to } |w| = 1,\ \text{the upper half to } |w| < 1} \quad \blacksquare @@ 0 ↦ −1, i ↦ 0, ∞ ↦ 1

The accepted names

A straight map z ↦ az + b with a ≠ 0 is a complex affine map, a direct similarity of the plane; its fixed point is its centre of similitude. The circle swap is inversion in the unit circle. The four-number maps are Möbius transformations, also called linear fractional transformations; the number ad − bc is their determinant. The far point is the point at infinity, and the plane with it is the extended complex plane, drawn as the Riemann sphere. The map z ↦ (z − i)/(z + i) is the Cayley transform.

Who said it first

Inversion in a circle was used by Jakob Steiner in the 1820s and published by Ludwig Immanuel Magnus in 1831. August Ferdinand Möbius studied the maps that keep circles in his theory of circle relations (1855). Bernhard Riemann pictured the plane with its far point as a sphere in the 1850s. Arthur Cayley gave his transform in 1846, for turns of space written as arrays of numbers.
