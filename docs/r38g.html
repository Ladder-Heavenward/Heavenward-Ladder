Numbers Smaller Than Every Fraction

The first slopes were taken with quantities “smaller than any number,” and for two centuries no one could say what such a quantity was. Rung 10 replaced them with limits. The finite-parts technique (38d) brings them back, honestly. Ask for a number c above 0 and below 1/n for every n, alongside every true statement about the line. Every finite part of that request has a world, so the whole has one. This step builds a line with numbers smaller than every fraction, carries every true statement to it, and takes a slope with one.

Add a name c and the statements 0 < c < 1/n, for every n, to all true statements of the line. Each finite part is met by a small enough real, so the whole has a world *ℝ. Every true statement of the line is true there; every finite number of *ℝ is infinitely near exactly one real, its standard part; and f′(x) is the standard part of (f(x + c) − f(x))/c.

38g1A Line With Room for More

T = \text{every true statement of } \mathbb R,\ \text{with a name for each real and each function} @@ the line’s full description
T \cup \{0 < c\} \cup \{c < \tfrac1n : n = 1, 2, \ldots\} @@ c below every fraction
\text{a finite part names only } c < \tfrac1N:\ \text{take } c = \tfrac{1}{N + 1} \text{ in } \mathbb R @@ every finite part has a world
\htmlClass{new}{\text{a world } {}^*\mathbb R \text{ of the whole, with } 0 < c < \tfrac1n \text{ for all } n} @@ finite parts (38d)

Small-number technique: there is an ordered world *ℝ in which every true statement of the line holds and which has a member c above 0 and below every 1/n. Then 1/c is above every number n.

38g2Carrying Statements Across

\forall x\,\forall y\ (x + y = y + x) \text{ holds in } {}^*\mathbb R @@ it is in T
\text{“every bounded set has a least upper bound” does not} @@ a statement about sets, not in T (38f3)
\text{a finite member } a \text{ of } {}^*\mathbb R:\ |a| < n \text{ for some } n @@ not endlessly large
\htmlClass{new}{\text{each finite } a \text{ is infinitely near exactly one real: } \operatorname{st}(a)} @@ the least upper bound of the reals below a, taken in ℝ (8c)

Standard-part technique: every statement true of the line, about its members and functions, is true of *ℝ; and every finite member of *ℝ differs from exactly one real by less than every fraction.

38g3A Slope With a Small Number

\dfrac{(x + c)^2 - x^2}{c} = \dfrac{2xc + c^2}{c} = 2x + c @@ c ≠ 0: dividing is allowed
\operatorname{st}(2x + c) = 2x @@ c is infinitely near 0
f^{\prime}(x) = \operatorname{st}\Big(\dfrac{f(x + c) - f(x)}{c}\Big) \text{ for every small } c \ne 0 @@ agrees with the limit of 10
\htmlClass{new}{\text{the old “smaller than any number” made exact}} @@ and every limit proof has a twin here

A slope is the standard part of a rise over a run by a number smaller than every fraction; the answer is the same for every such number, and it is the limit of rung 10. Proofs written this way are often shorter, and each one can be turned back into a limit proof.

The cellar · there if you want it

Accepted names

*ℝ is the hyperreal line, c an infinitesimal, st the standard part; carrying statements across is the transfer principle. The subject is nonstandard analysis.

Who said it first

Leibniz wrote with infinitesimals in 1684; Bishop Berkeley mocked them in 1734 as “ghosts of departed quantities.” Abraham Robinson made them exact in 1961 and wrote Non-standard Analysis in 1966.
