38g · proof

Formulas as Numbers

A formula is a finite string of marks, and a proof is a finite list of formulas. Rung four proved that every number other than zero has exactly one list of primes. So give each mark a number, and turn a string into one number by raising the primes in order to the numbers of its marks. Different strings get different numbers, and factoring a number gives its string back. A statement about formulas becomes a statement about numbers, and the language of arithmetic, which only speaks of numbers, can now speak of formulas without knowing it. Two things are needed for that to be useful. First, the axioms of arithmetic must be written down as a list of statements, so that proofs from them are objects too. Second, arithmetic, with nothing but adding and multiplying, must be able to say things like “the number in the third place of this list”. A trick with remainders does that. Then one technique says that every true statement of a certain simple shape, a some in front of a search that stops, is reached by the axioms. The next step points this machinery at the axioms themselves.

Each string of marks gets a number by prime powers, and factoring reads it back. The axioms of arithmetic are a list of statements. One number can hold a whole list, by remainders, so arithmetic can speak of codes, and every true statement made of a some in front of a bounded condition is reached by the axioms.

38g1A Number for Each String

Number the marks of the language of arithmetic: 0 is 1, S is 2, + is 3, · is 4, = is 5, ¬ is 6, ∧ is 7, ∨ is 8, ⇒ is 9, ∀ is 10, ∃ is 11, the left bracket is 12, the right bracket is 13, ⊥ is 14, and the placeholder xₖ is 15 + k. Write S t with no brackets, as S0, since S has one place, and write + and · between brackets: (t + s). The code of a string m₁ m₂ ⋯ mₖ is ⌜m₁ ⋯ mₖ⌝ = 2 to the number of m₁, times 3 to the number of m₂, and so on, with the kth prime to the number of mₖ.

Prime-code technique: different strings get different codes, and a string can be read back from its code.

\ulcorner m_1 \cdots m_k \urcorner = \ulcorner n_1 \cdots n_j \urcorner @@ suppose two strings share a code
\text{both are prime lists of one number} @@ a product of primes in order, each power at least 1
k = j \text{ and each prime has the same power on both sides} @@ the one-prime-list technique (4j)
\htmlClass{new}{m_i = n_i \text{ for every } i} \quad \blacksquare @@ each mark has its own number
  
\ulcorner 0 = 0 \urcorner = 2^1 \cdot 3^5 \cdot 5^1 = 2430 @@ marks 0, =, 0: numbers 1, 5, 1
\htmlClass{new}{\ulcorner S0 = S0 \urcorner = 2^2 \cdot 3^1 \cdot 5^5 \cdot 7^2 \cdot 11^1 = 20\,212\,500} \quad \blacksquare @@ marks S, 0, =, S, 0

A list of strings gets a code the same way, one level up: the list σ₁, …, σₖ has code 2 to the ⌜σ₁⌝, times 3 to the ⌜σ₂⌝, and so on. A line (S, R) is the list of S’s formulas followed by R, and a proof is a list of lines. So every proof has a code. The proof-check technique (38b3) reads the code back and checks it: whether a number is the code of a proof can be settled by a recipe that always stops.

38g2The Axioms of Arithmetic

Rung 4 proved its facts from sets. Here a few of them are written as the givens of a collection, PA, in the language of arithmetic:

  • ∀x ¬(S(x) = 0): 0 is nobody’s next (4b).
  • ∀x ∀y (S(x) = S(y) ⇒ x = y): different numbers have different nexts (4b).
  • ∀x (x + 0 = x) and ∀x ∀y (x + S(y) = S(x + y)): adding (4f).
  • ∀x (x · 0 = 0) and ∀x ∀y (x · S(y) = (x · y) + x): multiplying (4g).
  • For each formula φ(x), with perhaps other free placeholders: if φ(0), and ∀x (φ(x) ⇒ φ(S(x))), then ∀x φ(x). Induction (4c), one statement for each φ, each with an every in front for its other placeholders.

Each member is true in N, by rung 4, so N is a world of PA, and by the true-everywhere technique PA reaches only statements true in N. The list is endless, but whether a number codes a member of it is settled by a recipe: read the string back and compare it with the six lines and the pattern of the seventh.

Why is induction among the givens? Without it the collection stops short. Take the numbers with two extra members, ⋆ and ⋆′, each its own next, as 38c.5.4 asks. Let a number plus ⋆ be ⋆′, and fill in the rest to fit the six lines. That world makes the first six true and 0 + ⋆ = ⋆′, so ∀x (0 + x = x) is false there, and the first six alone never reach it. With induction, φ(x) = (0 + x = x) gives it in four lines.

0 + 0 = 0 @@ use an every, x + 0 = x with 0
0 + S(x) = S(0 + x) @@ use an every, the second adding line
\qquad \text{assume } 0 + x = x;\ \ 0 + S(x) = S(x) @@ swap, on the line above
\htmlClass{new}{\forall x\,(0 + x = x)} \quad \blacksquare @@ prove an if; speak of everything; induction for φ(x) = (0 + x = x)

38g3A List in One Number

A code is a product of prime powers, and the language of arithmetic has no mark for powers. It has + and ·. With them, “r is the remainder of u on division by d” is a formula: ∃q (q ≤ u ∧ u = q · d + r ∧ r < d), with every some kept below u. The trick is to store a whole list in two numbers through remainders.

List-in-one-number technique: for every finite list of numbers there are two numbers u and v such that the entry in place i of the list is the remainder of u on division by 1 + (i + 1) · v.

\text{list } t_0, \ldots, t_{n-1};\ \ m = 1 + \text{the largest of } n, t_0, \ldots, t_{n-1};\ \ v = m! @@ given; 4k’s factorial
d_i = 1 + (i + 1)v \text{ for } i < n;\ \ t_i < m \le v < d_i @@ each entry is small enough to be a remainder
p \text{ prime},\ p \mid d_i,\ p \mid d_j,\ i < j \Rightarrow p \mid (j - i)v @@ the divides-the-rest technique (4j), on dⱼ − dᵢ
\Rightarrow p \mid v @@ prime-divides-a-factor (4j); j − i is at most m, so it divides m!
\Rightarrow p \mid 1 @@ divides-the-rest, on dᵢ = 1 + (i + 1)v
\text{so no two of the } d_i \text{ share a prime} @@ refute: no prime divides 1
u, u' < D = d_0 \cdots d_{n-1} \text{ with the same remainders} \Rightarrow D \mid u - u' \Rightarrow u = u' @@ each dᵢ divides the difference; prime lists (4j); the difference is below D
\htmlClass{new}{\text{some } u < D \text{ has the remainders } t_0, \ldots, t_{n-1}} \quad \blacksquare @@ D numbers, D lists of remainders, no two numbers alike: every list is met (4k)
  
n = 3,\ \ m = 4,\ \ v = 4! = 24,\ \ d_0, d_1, d_2 = 25,\ 49,\ 73 @@ the recipe of the technique
u = 64\,827 @@ found by search below D = 89 425
\htmlClass{new}{64\,827 = 25 \cdot 2593 + 2 = 49 \cdot 1323 + 0 = 73 \cdot 888 + 3} \quad \blacksquare @@ the remainders are the list

So “y is 2 to the power x” is a formula: some u and v store the list 1, 2, 4, …, y, each entry twice the one before, with x + 1 entries. Every some after the first two is kept below a term. The same trick writes “x is the code of a formula” and “y is the code of a proof of the formula with code x”.

38g4True Searches Are Reached

Call a formula bounded when each of its everys and somes is kept below a term: ∀x (x < t ⇒ ⋯) or ∃x (x < t ∧ ⋯). 4j’s bounded-some technique showed that such a statement is settled, by a search that stops. A search statement is a bounded formula with somes in front: ∃y θ(y), θ bounded. “Some number is the code of a proof of φ” has that shape.

Search-reached technique: every search statement true in N is reached by PA.

N \models \exists y\,\theta(y) \text{, so } N \models \theta(\bar k) \text{ for some number } k @@ the clause for some (38a3)
\text{each term } t \text{ with no placeholder: } PA \vdash t = \bar n \text{, with } n \text{ its value} @@ induction on the term; the adding and multiplying lines, one step at a time
PA \vdash \neg(\bar m = \bar n) \text{ for } m \ne n @@ the two next lines, run min(m, n) times, then 0 is nobody’s next
PA \vdash \forall x\,(x < \bar n \Rightarrow x = \bar 0 \lor \cdots \lor x = \overline{n - 1}) @@ induction in PA, on n, from outside: one proof for each n
\text{a true bounded statement is reached} @@ induction on its building: each bounded every is n cases, each true bounded some names its example
\htmlClass{new}{PA \vdash \exists y\,\theta(y)} \quad \blacksquare @@ show an example, with k̄

The proof leans on N twice and on PA throughout: a true search has an example, and the example is a numeral that PA can work with. A false search statement is another matter. To reach its denial, PA would have to check every number, and the technique says nothing about that. 38i shows what goes wrong there.

The accepted names

The codes are Gödel numbers, and coding is Gödel numbering; ⌜φ⌝ is the Gödel number of φ. PA is Peano arithmetic, here in its first-order form, with induction as an axiom schema; without the schema the first six lines are close to Robinson arithmetic, Q, which has one more line, every number is 0 or a next. The list-in-one-number technique is Gödel’s β-function lemma, and its middle lines are the Chinese remainder theorem. Bounded formulas are Δ₀ formulas, search statements are Σ₁ sentences, and the search-reached technique is Σ₁-completeness.

Who said it first

Kurt Gödel numbered formulas by prime powers, and used the β-function to express sequences, in his paper of 1931, “On formally undecidable propositions of Principia Mathematica and related systems I”. Giuseppe Peano wrote the axioms of arithmetic in 1889, after Richard Dedekind’s analysis of 1888. Raphael Robinson isolated the weaker system Q in 1950. The remainder theorem is in the Chinese mathematical text of Sunzi, around the 4th century.

A proof that is not allowed

“The code of 0 = 0 is 2430, and 2430 is even. So 0 = 0 says that something is even.” Not allowed: the code is a name for the formula, chosen by a table. A different table gives a different number. What 0 = 0 says is fixed by 38a’s truth, and it is about 0. What the code makes possible is the other direction: a formula about numbers that is true of 2430 exactly when it is true of the formula 0 = 0.
