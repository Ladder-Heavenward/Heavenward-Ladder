3·∎ · conclusion

An Endless Collection Can Be One Object

The run 0, 1, 2, 3, and on never stops, yet all of it can sit inside one set. No tool builds that set; an axiom asks for it, and once you have it you can reason about the whole run at once.

The conclusion · the rung's claim, in full, and its proof

This page opens once every question on 3d inductive sets and the axiom of infinity is ticked. The claim below is proved from the steps of this rung, so it waits for them.

What the rung set out to show

The survey of rung 3 promised a run of sets that never stops, and asked whether everything the run produces can be gathered into one set. 3c gave the next one, S(x) = x ∪ {x}, the names 0 to 4, and the techniques next-membership, in-its-next, never-its-own-next and next-never-empty.

3d showed that a set you finish writing runs out, defined “inductive”, laid down the infinity axiom, and proved the named-sets-are-inductive technique. This page puts those together. An inductive set holds every entry of the run you name, and it never runs out of new next ones. A set you can write out does run out.

The claim, in full

There is a set that holds 0 and the next one after each of its members, so every entry of the endless run is a member of one object.

Let I be inductive: 0 ∈ I, and for every x, if x ∈ I then S(x) ∈ I.

There is such a set. That is the infinity axiom, laid down and not proved.

Then every entry of the run you name is a member of I: 0, 1, 2, 3, 4, S(4), and on.

And I never runs out: for every member x, S(x) is a member, S(x) is not x, and S(x) is not 0.

But a set you finish writing, such as {0, 1, 2, 3, 4}, is not inductive.

So I is one set, which rung 2's tools can sift, gather and take all the subsets of.

The Proof

The first part is the named-sets-are-inductive technique of 3d, carried one step past the names.

Let I be inductive: the infinity axiom gives such a set, and we call it I. By the named-sets-are-inductive technique, 0, 1, 2, 3 and 4 are in I. Unpack “inductive” and use its every with 4: if 4 is in I, then S(4) is in I. Carry the if through, and S(4) is in I.

Use the every again with S(4), and S(S(4)) is in I; and again. Whatever entry you reach by writing S enough times, the argument reaches it too, with a use-an-every and a carry-through at each step.

The second part says I never runs out, and never stalls on a set it has already passed through or on the start.

Let x be anything, and suppose x is in I, until we drop it. Unpack “inductive” and use its every with x: S(x) is in I. S(x) is not x, by never-its-own-next. S(x) is not 0, by next-never-empty, since 0 names ∅. Join the three. Drop the supposition: if x is in I, all three are true. Nothing was assumed about x, so this is true for every x.

The third part is why the axiom is needed. Take J = {0, 1, 2, 3, 4}. 3d showed S(4) ∉ J. Then J breaks the step part at 4, and the counterexample technique finishes it.

4 is in J: it is listed. S(4) is not in J. Suppose, until we drop it, that if 4 is in J then S(4) is in J. Carry that if through, and S(4) is in J. That clashes, so the if fails at 4. So 4 is an example where the if fails. By the counterexample technique, it is not so that for every x, if x is in J then S(x) is in J. That is the step part of “inductive”, so J is not inductive.

Nothing about 4 was used but that it is the member furthest along. Write out any set of entries, and the same argument, with its furthest member in place of 4, shows that it runs out. So no tool of rung 2, used and then stopped, gives an inductive set. The axiom asks for one, and once it is in hand it is a set like any other: you may sift from it, gather it, and take all its subsets.

One endless set, in hand. It is the first, and you are just getting started.
