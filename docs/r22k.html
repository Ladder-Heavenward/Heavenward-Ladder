22k · technique

How fast things grow

When two quantities both grow without end, it often matters less how big each is than which one wins in the long run. A recipe that takes a hundred times n steps beats one that takes n squared steps, once n is past a hundred. This step gives a way to say "grows no faster than" while ignoring fixed multiples and the first few values, and it ranks the usual kinds of growth: logs, then powers, then a fixed number raised to the nth power, then factorials. It ends with a fence around n factorial, the number of orders of n things.

Ignore fixed multiples and the first few values, and growth comes in ranks. Logs lose to powers, powers lose to powers of a fixed number, and those lose to factorials. n factorial lies between two simple powers.

22k1Grows no faster than

Stands on 10a (some and every) and 22a1 (heading to a limit).

From here on, f(n) = O(g(n)) (read "f is big O of g", or "f grows no faster than g") means: some C and some N make |f(n)| ≤ C·g(n) for every n ≥ N. And f(n) ~ g(n) (read "f and g grow alike") means f(n)/g(n) heads to 1.

O is a name for a promise with two numbers hidden in it, C and N, like 10a's ε and δ. The = in f = O(g) is not the = of rung 0: it does not turn about. n = O(n²) is true, and n² = O(n) is false. Read it as "is one of the functions that grow no faster than".

5n^2 + 3n + 7 \le 5n^2 + 3n^2 + 7n^2 = 15n^2 \ (n \ge 1) @@ each lower power is at most n² once n ≥ 1
\htmlClass{new}{5n^2 + 3n + 7 = O(n^2)} @@ C = 15, N = 1
\tfrac{5n^2 + 3n + 7}{5n^2} \to 1,\ \text{so } 5n^2 + 3n + 7 \sim 5n^2 @@ divide by n² (22h1)
n^2 \le C n \text{ for } n \ge N \Rightarrow n \le C \text{ for } n \ge N @@ false for n past C and N
\htmlClass{new}{n^2 \ne O(n)} \quad \blacksquare @@ no C and N can keep the promise

22k2The ranks of growth

Stands on 22k1, 22h2 (sequences to know by heart) and 17a (ln x ≤ x − 1).

Ranking technique: for any a > 0, b > 1 and power k, each of these over the next heads to 0: ln n, nᵏ (with k > 0), bⁿ, n!, nⁿ. So each grows no faster than the next, and the next does not grow no faster than it.

\ln n = \tfrac{2}{a}\ln n^{a/2} \le \tfrac{2}{a}\, n^{a/2} \Rightarrow \tfrac{\ln n}{n^a} \le \tfrac{2}{a}\, n^{-a/2} \to 0 @@ ln x ≤ x − 1 < x (17a)
\tfrac{n^k}{b^n} = n^k \big(\tfrac1b\big)^n \to 0 @@ 22h2, with r = 1/b
\tfrac{b^n}{n!} \to 0 @@ 22h2
\tfrac{n!}{n^n} = \tfrac{n}{n}\cdot\tfrac{n-1}{n}\cdots\tfrac{1}{n} \le \tfrac{1}{n} \to 0 @@ every fraction but the last is at most 1
\htmlClass{new}{\ln n \ll n^k \ll b^n \ll n! \ll n^n} \quad \blacksquare @@ the four lines above

From here on, f ≪ g (read "f is small beside g") means f(n)/g(n) heads to 0.

At n = 100, n³ is a million. 2ⁿ is about 1.27 × 10³⁰. A recipe of n³ steps finishes on a laptop in a second. A recipe of 2ⁿ steps would not finish if every atom in the earth were a computer working since the earth formed. The rank decides what can be done at all.

22k3A fence round n!

Stands on 22f1 (strips beside a curve), 17i (the area under ln) and 22k2.

Factorial-fence technique: e(n/e)ⁿ ≤ n! ≤ e·n·(n/e)ⁿ. Take ln, and n! becomes the sum ln 2 + ln 3 + ⋯ + ln n, which the strips of 22f1 fence with areas, the curve now rising.

\ln n! = \ln 2 + \ln 3 + \cdots + \ln n @@ ln of a product is the sum of the lns (17c)
\ln k \le \int_k^{k+1}\ln x\,dx @@ ln rises: each strip of height ln k lies under the curve (22f1, mirrored)
\ln 1 + \cdots + \ln(n-1) \le \int_1^n \ln x\,dx \le \ln 2 + \cdots + \ln n @@ add the strips from k = 1 to n − 1, under and over
n\ln n - n + 1 \le \ln n! \le n\ln n - n + 1 + \ln n @@ the area under ln is x ln x − x (17i); ln n! = ln((n − 1)!) + ln n
\htmlClass{new}{e\big(\tfrac{n}{e}\big)^n \le n! \le e\,n\big(\tfrac{n}{e}\big)^n} \quad \blacksquare @@ apply exp (17e)

At n = 10 the fence gives 1.23 million ≤ 10! ≤ 12.34 million, and 10! is 3 628 800. The fence is loose by a factor of n, here ten, but it already says what matters: n! grows like (n/e)ⁿ, give or take a factor much smaller. The full answer is n! ~ √(2πn)(n/e)ⁿ, which gives 3 598 696 at n = 10, off by less than one percent. It is stated here and proved on 23k.

The accepted names

O is big O notation, read "order of"; ≪ is often written with little o (f = o(g)); ~ is asymptotic equivalence. The ranking is called the hierarchy of growth rates. The full answer n! ~ √(2πn)(n/e)ⁿ is Stirling's formula.

Who said it first

Paul Bachmann introduced O in 1894 and Edmund Landau spread it from 1909, so O and o are sometimes called Landau symbols. Donald Knuth fixed their use in counting the steps of programs in 1976. Abraham de Moivre found that n! grows like a constant times √n (n/e)ⁿ, and James Stirling found the constant, √(2π), in 1730.
