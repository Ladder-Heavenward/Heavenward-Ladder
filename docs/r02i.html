2i · technique

Sets by Hand

The rung has its axioms and its techniques. This step is where the hands get fast. It draws sets as regions and shows that a drawing is a table you can see, so every technique of 2f can be checked by shading. It drills writing sets by a condition, including the shorthand for “everything of this form” and where that shorthand sifts from. It runs the techniques as a tool for simplifying an expression on purpose, a technique named per line, and marks where a step is licensed only for sets you can list. It draws products and relations as grids of pairs and reads a relation's properties off the grid. It builds, from the empty set and nothing else, the small sets the next rung starts from. It closes the rung, and says so at the end.

Draw a set as a region, read a region as a row. Write a set by naming what you sift from and what passes. Simplify by citing a technique per line. Lay pairs out in a grid and read a relation off it.

2i1A Region Is a Row

Draw a set t as a dashed border, and inside it draw regions for sets d, b, c that overlap. The regions cut t into pieces, and here is the point: each region is a row.

A thing in t is in d or not, in b or not, in c or not. That is exactly a row of 1e's table for the letters d, b, c. Example: the region where a thing is in d and b and not c is the row TTF.

2i2Shading an Expression

A set expression built with ∪, ∩, ∖ shades exactly the regions whose row makes its membership statement T. Example: (d ∩ b) ∖ c shades one region, the row TTF, and no other.

The membership statement is a joining of “x ∈ d”, “x ∈ b”, “x ∈ c” by ∨, ∧ and ¬. That is a compound statement in 1e's sense. Shading a region is reading its column at that row.

2i3Same Shading, Same Column

So expressions shade the same regions for every choice of d, b, c exactly when their membership statements have the same column. That is exactly when 1f has a technique between them.

The left picture lets you type a pair of expressions and see where they differ. A region marked ≠ is a row that convicts the claimed technique, and sets that fill that region are a counterexample.

2f's caveat, that a listed world settles every membership, carries over. A drawing is a world of listed things. For each thing you can see which regions it is in, so membership is settled, 1f's word. So in a drawing every technique may be used both ways, not-through for and included. The drawing proves nothing about sets you cannot list. It checks the shape of a technique, and it is the best counterexample hunter there is.

Their accepted name is Venn diagram. Here they are drawn as regions, which is all they are.

2i5Chasing a Member Through a Sift

Here is the first, chasing a member. Let y be anything. Unpack the sift: y is in {x ∈ t : φ(x) ∧ ψ(x)} exactly when y is in t, and φ(y) and ψ(y). By 1f's say-it-again and regroup, that is exactly when y is in t and φ(y), and y is in t and ψ(y). Pack the sifts: y is in the sift by φ, and in the sift by ψ. Pack ∩: y is in their intersection. This is true for everything, so by same-members the two sets are the same.

So in the left picture, where d is the sift of t by φ and b the sift by ψ, the region “in d and in b” is the sift by φ ∧ ψ, and so on. The drawing of the sets and the table of the conditions are the same object seen from either side.

2i8Practice, Both Ways

Practice, both ways. {a, e, i, o, u} is {x ∈ l : x is a vowel} with l the letters of the alphabet. It is also {the vowel of y : y ∈ {cat, bed, pig, dog, bus}}, a form that happens to produce each vowel exactly from its word. Two words with the same vowel would produce it twice, and the set would not notice. {Olympia, Salem, Sacramento} is {the capital of y : y ∈ {Washington, Oregon, California}}. It is also {x ∈ c : x is a state capital ∧ x is in Washington, Oregon or California}, with c the cities of North America, if the facts of geography bear that out, which the ladder cannot check and you can. Different descriptions, same members, same set, by 2d's axiom: that is why the practice is safe.

2i9Driving an Expression to Its Simplest

1f rewrote statements by citing a technique per line; 2f turned them into techniques about sets. Here they are as a tool. Take an expression and drive it to the simplest set it names, each step naming its technique. You will later drive an expression of a very different kind the same way. Each step is a sameness, and names its technique. Using a technique inside the whole is a move: 0b's swap axiom.

The plan for choosing a technique: look first for a part that units or say-it-again collapses. Then look for a spread to run backwards.

Take (d ∩ b) ∪ (d ∩ c) ∪ (d ∩ (b ∪ c)). Run the spread technique backwards on the first union: (d ∩ b) ∪ (d ∩ c) is d ∩ (b ∪ c). So the whole is a union of d ∩ (b ∪ c) with itself. By say-it-again, that is d ∩ (b ∪ c).

Take (d ∪ b) ∩ (d ∪ ∅). By units, d ∪ ∅ is d. So the whole is (d ∪ b) ∩ d. Turn the intersection about: d ∩ (d ∪ b). By absorb, that is d.

2i10Rewriting on Purpose

Take d ∖ (b ∪ (d ∖ d)). First, d ∖ d is ∅: nothing is both in d and not in d, by 1f's clash, and the one-empty-set technique names it. So the whole is d ∖ (b ∪ ∅). By units, that is d ∖ b.

And d ∖ b is also (d ∖ b) ∩ d. That is because d ∖ b is part of d (the sift-is-part technique), and a set shares all its members with a set it is part of. Here is why. If s ⊆ d, each member of s is in s and in d, so in s ∩ d. Each member of s ∩ d is in s. So s ∩ d = s, by the same-members axiom. That step is not simpler, but it is a rewriting you may want.

The last step shows the other use of techniques. They serve not only for simplifying, but for rewriting on purpose into a shape some later step needs, the way 1f grew a statement. Both directions of a both-ways technique are yours.

2i11The Step That Is Only for Listed Sets

Here is a sameness that looks like a technique and is only a part of one. Split a set by another: everything in d is, you would say, either outside b or inside b, so d = (d ∖ b) ∪ (d ∩ b). Chase a member and watch where it sticks.

From here on, ⇐ is ⇒ written the other way round: Q ⇐ P says just what P ⇒ Q says, and it claims nothing new.

Let x be anything. By merge-membership, and unpacking ∖ and ∩: x is in (d ∖ b) ∪ (d ∩ b) exactly when x is in d and not in b, or x is in d and in b. Run spread backwards, pulling the shared part out in front: x is in d, and x is not in b or is in b.

From the union to d is fine. Keep left: x is in d. That direction is a move for any sets. From d back to the union sticks. From x in d alone, you would need “x is not in b, or x is in b”. That is 1f's either-way, for settled statements only. For a listed b, you can look. For any b, it waits for rung 7.

So (d ∖ b) ∪ (d ∩ b) ⊆ d is a technique for any sets. The sameness is a technique for listed sets only, where membership in b is settled. In the picture it is true, because the picture is listed. On the endless sets of later rungs it is a question until rung 7 answers it. Knowing exactly which step is the settled-only step is the skill; the rest is bookkeeping.

2i12Products as Grids

2h8 laid a product out as a grid. Here is {p, q, r} × {x, y}:

xy
p(p, x)(p, y)
q(q, x)(q, y)
r(r, x)(r, y)

Every cell is a member of the product and every member is a cell; the grid is the listing. Turn the sets about and the grid turns about. {x, y} × {p, q, r} has a row for x and a row for y, and its cells are the pairs turned about, (x, p) and so on. None of them is a cell of the former grid, by the equal-pairs technique. The right picture lets you choose the sets and tap cells.

2i13Reading a Relation off Its Dots

A relation on a set d (2h11) is a choice of cells on the grid of d × d: dot the cells whose pairs are in. Read the properties off the dots.

A self-cell is a cell where the row and the column name the same thing.

Reflexive: every self-cell is dotted.

Symmetric: for every dotted cell, the cell with the row and column exchanged is dotted. The dots match across the self-cells.

Transitive: whenever the cell at row x column y and the cell at row y column z are dotted, so is the cell at row x column z. The shortcut is always there.

When all of them are true, the dots fall into blocks, and the blocks are the classes. List the members whose rows look alike and you have listed a class. 2h's picture does this on a household. Here is a worked reading on {ant, ape, bee} with “has the same initial as”.

The dotted cells are (ant, ant), (ant, ape), (ape, ant), (ape, ape) and (bee, bee). Reflexive: every self-cell is dotted. Check them one by one; an every over a list is an and, as 2j saw. Symmetric: the only dot off the self-cells, (ant, ape), has its match (ape, ant). Transitive: every step and further step has its shortcut. For instance, (ant, ape) and (ape, ant) give (ant, ant), which is in. The blocks are the classes: [ant] = {ant, ape} and [bee] = {bee}.

2i14Built From Nothing

Every tool needs a set to start from, and by 2e's axiom there is one, from which ∅ was sifted. From ∅ alone, by gather and power set, here is a short gallery. Each is written all the way down to braces, with the reason it exists.

∅ comes first. Sift a set by x ≠ x. There is a set with no members, by the empty-set axiom, and the one-empty-set technique names it.

{∅} is ∅ gathered with itself. It is not empty: ∅ is in it.

{∅, {∅}} is ∅ gathered with {∅}. Its two members differ: {∅} has a member, and ∅ has none.

{{∅}} is {∅} gathered with itself. It is not {∅}: ∅ is in {∅}, and ∅ is not in {{∅}}.

𝒫({∅}) is {∅, {∅}}: keep or drop the only member, ∅. By same-members, it is the same set as the gathering above.

The pair (∅, {∅}) is {{∅}, {∅, {∅}}}. Its left entry is ∅, in every member; its right entry is {∅}.

And ⋃{∅, {∅}} = {∅}: tipping out ∅ gives nothing, and tipping out {∅} gives the thing ∅.

Rung 3 takes the gathering {∅, {∅}} and asks what happens if you keep going. Everything it needs to ask that question has been built here.

2i16Where You Stand

You can say what a set is and when sets are the same. You can sift, gather, merge, and take all the subsets. You know that each tool needs a set in hand, and that by an axiom there is a set to start from. You can prove sets the same by chasing a member or by inclusions each way, and you can show with a witness that a sameness cannot stand. You can rewrite by the techniques, and you know which direction waits for rung 7. You can make order out of orderless things, lay out products as grids, read a relation's properties off its dots, and chop a set into classes. You know that nothing is a member of itself and that there is no set of everything, and why. That is the ordinary toolkit of collections, the one every mathematics book assumes without saying so, built here from the ground floor.

Now you can build and take apart collections.

Who said it first

The pictures of overlapping regions are John Venn’s (1880), building on diagrams Leonhard Euler had used in his letters a good deal earlier. Their accepted names are Venn diagrams and Euler diagrams.
