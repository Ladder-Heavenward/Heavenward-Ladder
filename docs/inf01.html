Why Do All the Diagonal Arguments Look Alike?

Why do all the diagonal arguments look alike? The ladder has run one argument five times. Rung 35 showed that the parts of a set outrun its members; rung 2 showed that no set holds exactly the things that are not members of themselves; rung 38 built a statement that speaks about itself, and then showed that truth for arithmetic cannot be defined; rung 41 showed that no machine decides whether machines stop. Each time something reads itself down a diagonal and takes the opposite. With arrows the five become one. If every function from A to B is named by a member of A, then every function from B to itself keeps some member of B fixed. Turn that about: a B with a function that keeps nothing fixed cannot have its functions named. The technique was stated in 1969; in 2003 a short account put a dozen paradoxes in one frame with it.

φ : A × A → B names every function from A to B when each g : A → B is φ(a, −) for some a. Fixed-point technique: then every f : B → B has a fixed point, f(b) = b. Proof: g(x) = f(φ(x, x)) is named, g = φ(a, −), and b = φ(a, a). Cases: B = {keep, drop}, f = not gives 35c1 and 2e14; B = truth values, f = not gives 38k2 and 41d2; the positive form gives 38h2.

inf1.1Naming Functions by Members

By 47f2’s pair-to-function technique, a function φ from A × A to B is the same thing as a function from A to the functions from A to B: fix the first input, a ↦ φ(a, −). φ names every function from A to B when each g : A → B is φ(a, −) for some a in A: every function has a name among the members of A.

Fixed-point technique: if φ : A × A → B names every function from A to B, then every function f from B to B has a fixed point, some b with f(b) = b.

g(x) = f(\varphi(x, x)) @@ read down the diagonal, then apply f
g = \varphi(a, -) \text{ for some } a \in A @@ φ names every function
g(a) = \varphi(a, a) \text{ and } g(a) = f(\varphi(a, a)) @@ evaluate both at a
\htmlClass{new}{b = \varphi(a, a) \text{ has } f(b) = b} \quad \blacksquare @@ the diagonal at the name of g

Turned about: if some f from B to B keeps nothing fixed, no φ names every function from A to B. Each old proof picks a B, a fixed-point-free f, and a would-be namer, and the four lines do the rest. The arrows carry the plan; what A is made of, sets or statements or machines, is let go.

inf1.2The Parts Outrun the Members

Take B = {1, 0}, keep and drop, and f = not, which swaps them and keeps nothing fixed. A function from A to B is a part of A by 4k10’s keep-or-drop function. A function F from A to the parts gives φ(x, y) = 1 exactly when y ∈ F(x).

B = \{1, 0\},\ f = \text{not},\ f(b) \ne b @@ nothing fixed
F \text{ onto the parts} \Rightarrow \varphi \text{ names every function } A \to B @@ parts are keep-or-drop functions (4k10)
g(x) = \text{not}\,\varphi(x, x) \text{ is the part } \{x : x \notin F(x)\} @@ the diagonal, taken opposite
\htmlClass{new}{\text{no } F \text{ from } A \text{ onto its parts}} \quad \blacksquare @@ the fixed-point technique, turned about

That is 35c1’s parts-outrun technique, and the part it builds, the members not in their own image, is g. Rung 35 found g by hand; the frame says where it comes from: f applied down the diagonal.

inf1.3The Outsider Set

Under the old rules every condition gave a set, so there would be a set U of all sets, and every part of U would be a member of U. Let A = U, B = {1, 0}, and φ(x, y) = 1 exactly when y ∈ x. Then every function from U to B, read as a part of U, is a set x in U with φ(x, −) its keep-or-drop function: φ names every function.

\varphi(x, y) = [\,y \in x\,] \text{ names every } U \to \{1, 0\} @@ under the old rules every part of U is a member
g(y) = \text{not}\,\varphi(y, y) = [\,y \notin y\,] @@ the diagonal, taken opposite: the outsider set
g = \varphi(r, -) \Rightarrow [\,r \in r\,] = [\,r \notin r\,] @@ the four lines
\htmlClass{new}{\text{no set } U \text{ whose parts are all its members}} \quad \blacksquare @@ not keeps nothing fixed

2e14’s outsider set is g, and r is its name. The sift axiom, which only sifts a set already in hand, is the repair: it stops φ from naming every function.

inf1.4The Statement About Itself

38h2’s self-statement technique uses the frame the other way, to build. A is the formulas with one placeholder, and B is the statements of arithmetic, read up to what PA reaches both ways. φ(D, E) puts the code of D into E; substitution makes every formula’s function a named one.

\varphi(D, E) = E(\ulcorner D \urcorner) @@ put the code of D into E
f(\chi) = \psi(\ulcorner \chi \urcorner) \text{ for a formula } \psi @@ the function from statements to statements to be fixed
g(D) = f(\varphi(D, D)) = \psi(\ulcorner D(\ulcorner D \urcorner) \urcorner) \text{ is named by a formula } D_0 @@ sub(x) is a recipe that always stops (38h2)
\htmlClass{new}{\delta = D_0(\ulcorner D_0 \urcorner)\text{: } PA \vdash \delta \Leftrightarrow \psi(\ulcorner \delta \urcorner)} \quad \blacksquare @@ the fixed point

Here no f fails to have a fixed point. Every ψ gets its δ, and that is the technique’s use: the frame guarantees a statement that says ψ of itself.

inf1.5Truth and Stopping

Two more cases take f = not and find that it would have a fixed point. If arithmetic had a truth formula True, then by 38h2 with ψ = not True there is δ with δ true exactly when not True(⌜δ⌝), and True says δ is true exactly when True(⌜δ⌝). So truth would be a fixed point of not. That is 38k2’s undefinable-truth technique.

For machines, A is the codes of machines and B = {stops, runs on}. A stop decider D would let a machine compute any column of 41d2’s table and flip it; the machine E that runs down the diagonal and does the opposite would be named by its own code ⟨E⟩.

\varphi(i, j) = \text{what machine } i \text{ does on code } j @@ the table of 41d2
D \text{ decides stopping} \Rightarrow g(j) = \text{opposite of } \varphi(j, j) \text{ is a machine’s behaviour} @@ flip the diagonal, using D
g = \varphi(\langle E \rangle, -) @@ machines name every such behaviour
\htmlClass{new}{\varphi(\langle E \rangle, \langle E \rangle) = \text{opposite of itself}} \quad \blacksquare @@ “opposite” keeps nothing fixed: no D

41d2’s no-stop-decider technique, and 38k2, are the same four lines with a different A.

A short history · told from more than one side

How we got here

The diagonal was first run on the real numbers in 1891, to show they cannot be listed. In the next thirty years the same shape appeared in the paradoxes of sets, in a statement about its own provability (1931), in undefinable truth (1933 and 1936) and in machines that cannot decide stopping (1936). Each was proved separately.

In 1969 the shape was stated once, with arrows, for any category in which functions of pairs are functions to functions: if every map is named, every map from B to B has a fixed point.

In 2003 a paper retold it for sets and functions, and fitted about a dozen paradoxes and results into it, from the liar to the limits of machines.

The accepted names

The fixed-point technique is Lawvere’s fixed-point theorem; a namer of every function is a point-surjective map A → BA; categories in which functions of pairs are functions to functions are cartesian closed. The positive form in arithmetic is the diagonal lemma; the never-stopping fixed point of adding one is the content of Kleene’s recursion theorem. The list of statements each saying the later ones are false is Yablo’s paradox (1993).

Who said it first

Georg Cantor, the diagonal for the reals (1891). Bertrand Russell, the outsider set (1901). Kurt Gödel (1931); Alfred Tarski, undefinable truth (1933, 1936); Alan Turing, stopping (1936). F. William Lawvere, “Diagonal arguments and cartesian closed categories” (1969). Noson Yanofsky, “A universal approach to self-referential paradoxes, incompleteness and fixed points” (Bulletin of Symbolic Logic, 2003).
