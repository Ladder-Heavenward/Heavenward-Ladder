The Simplex Method by Hand

The best corner proved that a corner of the allowed plans is best, and that there are finitely many corners. Checking them all is hopeless for a real plan: a hundred limits on fifty unknowns can have more corners than there are stars in the visible universe. The recipe that is used instead walks from corner to corner along the edges of the region, each step to a neighbouring corner that earns more, and stops when no neighbour does. This step does it by hand on the glass works of the best corner. Each limit gets a slack, the amount by which it is not yet tight, and the whole program is rewritten so that some unknowns are written in terms of the others. A step of the walk swaps one unknown for another, and a ratio test says which. At the end, the earnings are written as the best value less some amounts at least zero, and those amounts are the prices of the twin program, read off with no extra work. So the walk proves its own answer best. The step ends with what can go wrong: a region where the walk can circle without moving, and a start that is not allowed at all.

Add a slack to each limit, so limits become equations and every unknown is at least 0. A corner sets some unknowns to 0 and solves for the rest. A step lets one unknown with a positive coefficient rise until the first slack hits 0, and swaps the two. When no coefficient is positive, the corner is best, and the coefficients of the slacks are the twin’s prices. A rule of smallest names stops the walk from circling, and a first phase finds a start.

42n1Slacks and a First Corner

For each limit aᵢ · x ≤ bᵢ, the slack sᵢ = bᵢ − aᵢ · x. A plan is allowed exactly when every xⱼ and every sᵢ is at least 0. Write the slacks and the value z = c · x in terms of the x’s: that list of equations is a dictionary. The unknowns on the left are its kept unknowns; those on the right, set to 0, give its corner.

Slack-form technique: a dictionary whose constants are all at least 0 names a corner, by setting every unknown on the right to 0; and it holds for every plan, allowed or not, since it is the same equations rearranged.

s_1 = 4 - x @@ the door shop
s_2 = 12 - 2y @@ the window shop
s_3 = 18 - 3x - 2y @@ the glass shop
\htmlClass{new}{z = 0 + 3x + 5y;\ \ \text{corner } (0, 0),\ z = 0} \quad \blacksquare @@ x = y = 0 on the right; the constants 4, 12, 18 are at least 0

42n2A Step to a Better Corner

Pivot technique: if an unknown on the right of z has a positive coefficient, let it rise from 0 until the first kept unknown reaches 0; swap those two, rewriting the dictionary; the new constants are all at least 0, and z has not fallen. The first kept unknown to reach 0 is found by the ratio test: the least constant divided by the rate at which it falls.

y \text{ rises: } s_2 = 0 \text{ at } y = 6,\ s_3 = 0 \text{ at } y = 9 @@ ratios 12/2 and 18/2; s₁ does not fall
y = 6 - \tfrac12 s_2,\ \ s_3 = 6 - 3x + s_2,\ \ z = 30 + 3x - \tfrac52 s_2 @@ swap y and s₂; put y’s line into the others (27j’s row moves)
x \text{ rises: } s_1 = 0 \text{ at } x = 4,\ s_3 = 0 \text{ at } x = 2 @@ ratios 4/1 and 6/3; x enters, s₃ leaves
x = 2 - \tfrac13 s_3 + \tfrac13 s_2,\ \ s_1 = 2 + \tfrac13 s_3 - \tfrac13 s_2 @@ from s₃’s line
\htmlClass{new}{z = 36 - \tfrac32 s_2 - s_3;\ \ \text{corner } (2, 6)} \quad \blacksquare @@ no coefficient is positive: stop

Each dictionary is a corner, and each step goes along an edge of the region to a neighbouring corner: one tight limit is let go and another becomes tight. The walk visited three of the five corners. On a hundred limits it typically visits a few hundred out of more corners than can be counted.

42n3The Prices, Read Off

Last-row technique: when the walk stops, with z = z* − Σ rⱼxⱼ − Σ yᵢsᵢ and every r and y at least 0, the y’s are covering prices with b · y = z*; so the corner is best, by the price-bound technique.

c \cdot x = z^* - r \cdot x - y \cdot (b - A x) \text{ for every plan } x @@ the last dictionary holds for every plan (the slack-form technique), with s = b − Ax
c \cdot x = (A^{\mathsf T} y - r) \cdot x + (z^* - y \cdot b) @@ gather the terms
c = A^{\mathsf T} y - r \text{ and } z^* = y \cdot b @@ equal for every x, so the coefficients and the constants agree
A^{\mathsf T} y = c + r \ge c,\ \ y \ge 0 @@ every r at least 0
\htmlClass{new}{y \text{ covers and } b \cdot y = z^*} \quad \blacksquare @@ the price-bound technique: no plan earns more

The glass works stopped at z = 36 − 0 · s₁ − (3/2) s₂ − 1 · s₃: the prices (0, 3/2, 1) of 42g2, found by the walk with no extra work. So the walk, when it stops, proves the equal-prices technique for that program again, by a second road.

42n4When the Walk Stalls, and Where It Starts

A step can leave z where it was, when the leaving unknown’s constant is already 0: a corner where more than n limits are tight. Then the walk can circle through dictionaries of one corner for ever. Held in trust, as stated: choosing, among the unknowns that may enter, the one with the smallest name, and among those that may leave, again the smallest, never circles; that was proved in 1977. With that rule the dictionaries never repeat, and there are finitely many, so the walk stops, by 4l’s falling-measure technique read on the dictionaries not yet visited.

First-phase technique: if the dictionary at x = 0 has a negative constant, add one unknown x₀ ≥ 0 to every limit as aᵢ · x − x₀ ≤ bᵢ and maximise −x₀; the program has an allowed plan exactly when the best value is 0, and the last dictionary of that walk starts the real one. Large x₀ makes every limit loose, so a first corner of the new program is found with one step, and a plan with x₀ = 0 is an allowed plan of the old.

x + y \ge 2 \text{, written } -x - y \le -2:\ \ s = -2 + x + y @@ the constant −2: x = y = 0 is not allowed
-x - y - x_0 \le -2:\ \ s = -2 + x + y + x_0 @@ the first phase
x_0 \text{ enters until } s = 0:\ \ x_0 = 2 - x - y + s @@ one step to an allowed start
\htmlClass{new}{\text{then } x \text{ or } y \text{ enters, } x_0 \text{ leaves, and } -x_0 = 0 \text{ is best}} \quad \blacksquare @@ an allowed plan, such as (2, 0)

How many steps? On a shape found in 1972, of n unknowns and 2n limits, the walk with the steepest coefficient visits all 2ⁿ corners. On real programs it takes a small multiple of the number of limits. Recipes with a guaranteed polynomial cost were found in 1979 and 1984, and a reason for the walk’s speed in practice was proved in 2001.

The accepted names

The walk is the simplex method, a dictionary is a simplex dictionary (or tableau), kept unknowns are basic variables, and a corner named by one is a basic feasible solution. The ratio test keeps its name. A corner with more than n tight limits is degenerate, and circling is cycling; the rule of smallest names is Bland's rule (1977). The first phase is phase one of the two-phase method. The last-row technique reads the dual solution from the reduced costs.

Who said it first

George Dantzig devised the simplex method in 1947. Alan Hoffman found a program on which it cycles in 1951, and Robert Bland the rule that prevents it in 1977. Victor Klee and George Minty built the cube on which it visits every corner in 1972. Leonid Khachiyan gave the first polynomial recipe, the ellipsoid method, in 1979, and Narendra Karmarkar a practical one, an interior point method, in 1984. Daniel Spielman and Shang-Hua Teng explained the walk's speed in practice by smoothed analysis in 2001.

A proof that is not allowed

“Each step goes to a corner that earns more, and there are finitely many corners, so the walk stops at the best.” Not allowed twice over. A step may earn the same, not more, and then the walk can circle; that is what the smallest-name rule is for. And stopping is not the same as best: the walk stops when no neighbour earns more, and that the corner is then best is the last-row technique, not a fact about stopping.
