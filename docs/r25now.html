Which Numbers Never Escape?

Which numbers never escape? Take a number c of the plane. Start at 0, square, add c, and do it again with the answer, and again, for ever. For some c the answers run off past every bound. For others they stay near home for ever, settling, or circling, or wandering without rest. Sort every c in the plane into those two kinds, and mark the ones that stay. In 1980 computers first drew the marked set well, and the picture was a shock: a heart-shaped body with round buds, buds on the buds, hairs and spirals and tiny copies of the whole, at every scale anyone has looked. What makes the question hard is that no run can be watched for ever, and every picture is made of small squares, each holding endlessly many c. This page shows, with rung twenty-five’s sizes of products and roots in pairs and rung twenty-four’s states that hold, where the set lies, why a run that passes 2 has escaped for good, how the heart and its first bud are drawn exactly, why a picture cannot settle what the set looks like, what was proved in 1982, and what is still open.

On the line, the set is the stretch from minus two to one quarter, and past one quarter the run climbs because the rule’s own resting points have left the line as a flipped pair. In the plane, once a run passes two in size it can only grow, since squaring then outruns adding. Inside the heart a resting point pulls the run in, and the border of the heart is drawn by turning. Inside the first bud a cycle of two pulls instead. A picture tests each square once, at one point, for a few hundred steps, and so it proves only escapes. The set was proved to be in one piece. Whether it is in one piece close up, near every point, nobody yet knows.

25now1On the Line First

Write z₀ = 0 and z_(n+1) = z_n² + c. From here on, on this page, the run of c is z₀, z₁, z₂, and so on, and c stays home when its run has a ceiling on its size. With c = 1 the run is 0, 1, 2, 5, 26, and it escapes. With c = −1 it is 0, −1, 0, −1, and stays home. With c = i it is 0, i, −1 + i, −i, −1 + i, −i, and circles for ever. Start on the line, with c real.

z_{n+1} - z_n = z_n^2 - z_n + c = \big(z_n - \tfrac12\big)^2 + c - \tfrac14 @@ complete the square (8i)
c \gt \tfrac14 \Rightarrow z_{n+1} - z_n \ge c - \tfrac14 \gt 0 @@ each step climbs at least this much; the run escapes
z^2 - z + c = 0:\ z = \tfrac{1 \pm \sqrt{1 - 4c}}{2},\ \text{a flipped pair when } c \gt \tfrac14 @@ the rule’s resting points leave the line (25e)
-2 \le c \le \tfrac14:\ \ z \in [-\beta, \beta] \Rightarrow z^2 + c \in [c, \beta] \subseteq [-\beta, \beta],\ \ \beta = \tfrac{1 + \sqrt{1 - 4c}}{2} @@ β² + c = β; and β ≥ −c when −2 ≤ c ≤ ¼
\htmlClass{new}{\text{on the line, } c \text{ stays home exactly for } -2 \le c \le \tfrac14} \quad \blacksquare @@ 0 is in [−β, β]; and c < −2 escapes at once, as |z₁| = |c| > 2 (25·now.2)

Line technique: a real c stays home exactly when it lies from −2 to ¼, and past ¼ the run climbs because the rule’s resting points have become a flipped pair off the line. The last line leans on the next footing for c below −2. 24k found doublings along this stretch for the logistic rule. Here they are again: z ↦ z² + c is the logistic rule with its variable slid and stretched.

25now2Past 2, Gone for Good

Rung 25 gave two facts about sizes: |zw| = |z||w|, and |a + b| ≥ |a| − |b|. They are all a run needs.

|z| \gt 2,\ \ |z| \ge |c| @@ the run is out past 2, and past |c|
|z^2 + c| \ge |z^2| - |c| = |z|^2 - |c| @@ the triangle technique; the size of a product (25c)
\ge |z|^2 - |z| = |z|\,(|z| - 1) @@ |c| ≤ |z|
|z| = 2 + \varepsilon \Rightarrow |z_{n+1}| \ge (1 + \varepsilon)\,|z_n| \text{ and } |z_{n+1}| \gt 2 + \varepsilon @@ and so still past |c|
\htmlClass{new}{|z_{n + k}| \ge (1 + \varepsilon)^k\,|z_n|:\ \text{the run escapes}} \quad \blacksquare @@ induction on k (4c); (1 + ε)ᵏ passes every ceiling

Escape technique: if c stays home, then |c| ≤ 2 and every z_n of its run has |z_n| ≤ 2; one step past 2 proves escape. For |c| > 2, z₁ = c is already past 2 and past |c|. For |c| ≤ 2, a run that passes 2 is past |c| too. So the whole set lies in the disc of size 2 about 0, and a computer may stop any run the moment it passes 2.

25now3The Heart and Its First Bud

24k found that a resting point of a rule fed its own answers pulls nearby runs in when the rule’s slope there is less than 1 in size. In the plane the same holds: near a resting point z, the gap to it is multiplied by about 2z each step, and by the size of a product its size is multiplied by |2z|. A resting point of z ↦ z² + c is a root of z² − z + c, and in the plane there are always two.

z^2 + c = z,\ \ |2z| \lt 1 @@ a resting point that pulls
c = z - z^2,\ \ z = \tfrac12(\cos\theta + i\sin\theta) @@ the border: |2z| = 1, written out and round (21·cb20)
c = \tfrac12(\cos\theta + i\sin\theta) - \tfrac14(\cos 2\theta + i\sin 2\theta) @@ multiply-and-add: the turn doubles
(z^2 + c)^2 + c - z = (z^2 - z + c)(z^2 + z + c + 1) @@ multiply out: a cycle of two solves the second factor
\htmlClass{new}{\text{a two-cycle pulls when } |2z_1 \cdot 2z_2| = |4(c + 1)| \lt 1,\ \text{ that is } |c + 1| \lt \tfrac14} \quad \blacksquare @@ z₁z₂ = c + 1, the product of the roots; the size of a product (25c)

Heart-and-bud technique: the c whose resting point pulls fill a heart whose border is drawn by turning z round a circle of size ½; the c whose cycle of two pulls fill the disc of size ¼ about −1. The heart meets the line at ¼ (θ = 0) and at −¾ (θ = π). The bud touches it at −¾. Every bud has buds of its own, without end.

25now4A Picture Cannot Settle It

A picture tests one c in each small square, for N steps. If that run passes 2, that one c is proved to escape. If it does not, nothing is proved, even about that c: it may pass 2 at step N + 1. At c = ¼ + ε the run takes about π/√ε steps to escape, so c = 0.2501 survives 300 steps and still escapes.

\text{the middle passes 2 by step } N \Rightarrow \text{that } c \text{ escapes} @@ the escape technique: proved
\text{the middle stays under 2 for } N \text{ steps} \Rightarrow\ ? @@ nothing, for any N
c = 0.2501:\ \text{under 2 for } 300 \text{ steps, then escapes at step } 312 @@ about π/√0.0001 ≈ 314
\htmlClass{new}{\text{a picture proves escapes, and never proves staying home}}
Anexact, yet rigorous · the cloud

21a said that every measured value is a fence, and 24·now’s boxes reported only what held at every point of a box. A square of the picture is a box of endlessly many c. Its colour is a fact about one of them, after N steps.

A picture made of tested points proves only what was tested, and a square is not its middle.

So a black square says neither that its c stay home nor even that its middle does. A thread of the set thinner than a square may run through a white square and never be drawn. To prove anything about the set from a computer, the computer must work with whole boxes, as 24·now’s did, and report only what holds for every c in them.

A picture at 200 steps shows a small black speck, apart from the body, with white squares all round it. Which of these could you report: the speck is part of the set; some c near the speck escape; the speck is cut off from the body?

25now5What Is Proved, and What Is Open

The set is proved to be in one piece; whether it is in one piece close up, near every one of its points, is open.

  • Proved, 1982. The set is in one piece: no speck of it is cut off from the body, however the pictures look. The proof builds a map of the plane that straightens the set’s outside into the outside of a disc.
  • Proved, 1991 and 1998. Its border is as rough as a curve in the plane can be: on a measure of roughness built much higher up the ladder, it scores 2, as much as a solid patch.
  • Measured, not proved. Its area is about 1.506, found by counting squares and by sums. No proof pins even the second figure.
  • Open. Whether it is in one piece close up. A set can be in one piece and fail this: a comb of upright teeth at 1, ½, ⅓, and so on, with a spine along the floor and one more tooth at 0. Near the middle of the tooth at 0, every small disc holds bits of other teeth, cut off from it inside that disc. Proved since the 1990s at every point of the border except those where the set holds smaller copies of itself, inside copies, without end. Proved at some of those since, and open at the rest.
  • What it would give. If the set is in one piece close up, then every c inside it lies in a heart or a bud of its own, where some cycle pulls. On the line, the same claim was proved in 1997 (24·now).

The cellar · there if you want it

The accepted names

The set is the Mandelbrot set; the run of 0 is the critical orbit, and z ↦ z² + c the quadratic family. The heart is the main cardioid and the bud the period-2 bulb; the escape technique is the escape radius 2. A resting point that pulls is attracting, and a c with a cycle that pulls is hyperbolic. In one piece is connected; in one piece close up is locally connected, and the open question is the MLC conjecture. What it would give is the density of hyperbolicity. The roughness is Hausdorff dimension. The map of 1982 is a Riemann map, conformal, of the outside of the set onto the outside of a disc. The comb is the comb space.

Who said it first

Pierre Fatou and Gaston Julia studied rules fed their own answers in the plane in 1917–20, without pictures. Robert Brooks and Peter Matelski drew the set in 1978; Benoit Mandelbrot drew it better in 1980 and made it famous. Adrien Douady and John Hubbard proved it in one piece in 1982 and named it after Mandelbrot. Mitsuhiro Shishikura proved its border has dimension 2 (announced 1991, published 1998). Jean-Christophe Yoccoz proved it in one piece close up at many points in the early 1990s; Mikhail Lyubich, Jeremy Kahn and Dzmitry Dudko have extended it since. In 25·now.7.5, Mandelbrot at first took the specks for islands, or for dirt on the printout; Douady and Hubbard proved they are joined.
