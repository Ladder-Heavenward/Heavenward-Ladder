22e · proof

Compare with a geometric sum

Most endless sums have totals nobody can write down. You can still decide whether they settle, by laying them beside a sum you already understand. If every piece of yours is smaller than the matching piece of a sum that settles, yours settles too. If every piece is bigger than the matching piece of a sum that wanders, yours wanders. The best sum to lay beside is the one whose pieces shrink by the same factor each time, because rung fifteen found its total exactly. From that one comparison come two quick tests, one that looks at how each piece compares with the one before, and one that looks at roots of the pieces.

A sum of pieces that are never negative settles if its pieces stay under the pieces of a sum that settles, and wanders if they stay over the pieces of a sum that wanders. Laying a sum beside a sum that shrinks by a fixed factor gives two quick tests.

What this stands on, and where it goes

Stands on 22d (running totals, the tail), 15i (geometric sums), 22a (the climb technique). 22f lays sums beside areas.

22e1Lay it beside another

Stands on 22d1 (the climb technique for sums) and 22d4 (the tail technique).

Comparison technique: let 0 ≤ uₙ ≤ vₙ from some place on. If Σ vₙ settles, so does Σ uₙ. If Σ uₙ wanders, so does Σ vₙ. By the tail technique, start where the inequality starts.

0 \le u_n \le v_n \text{ for } n \ge 1 @@ after dropping the first few pieces (22d4)
u_1 + \cdots + u_n \le v_1 + \cdots + v_n \le \sum v_n @@ the running totals of v climb to their total
(u_1 + \cdots + u_n) \text{ climbs, with ceiling } \textstyle\sum v_n @@ no negative pieces
\htmlClass{new}{\textstyle\sum u_n \text{ settles, and } \sum u_n \le \sum v_n} \quad \blacksquare @@ the climb technique (22a2)

The second half is the first, turned about: if Σ vₙ settled, Σ uₙ would.

Ratio-of-pieces comparison: if uₙ, vₙ > 0 and uₙ/vₙ heads to a positive real, the two sums settle or wander together. Far out, uₙ lies between half and twice that real times vₙ, so each sum is under a multiple of the other.

22e2The ratio test

Stands on 22e1 and 15i (geometric sums).

Ratio test: let uₙ > 0 and uₙ₊₁/uₙ → q. If q < 1 the sum settles. If q > 1 it wanders. If q = 1 the test says nothing. When each piece is roughly q times the last, the sum behaves like a geometric sum with ratio a little more than q.

q < r < 1 @@ choose r between: (q + 1)/2 will do
\tfrac{u_{n+1}}{u_n} < r \text{ for } n \ge N @@ the ratios head to q < r
u_{N+j} < u_N r^j @@ induction (4b) on j
\textstyle\sum_j u_N r^j = \tfrac{u_N}{1 - r} @@ 15i, since 0 < r < 1
\htmlClass{new}{\textstyle\sum u_n \text{ settles}} \quad \blacksquare @@ comparison (22e1) and the tail technique

If q > 1, far out each piece is bigger than the one before, so the pieces do not head to 0 and the shrink technique (22d2) shows the sum wanders. If q = 1, look at Σ 1/n, which wanders, and Σ 1/n², which settles (22c2). Both have ratios heading to 1, so the test cannot tell them apart.

22e3The root test

Stands on 22e2 and 8 (roots of reals).

Root test: let uₙ ≥ 0 and the n-th root of uₙ head to q. If q < 1 the sum settles; if q > 1 it wanders; if q = 1 the test says nothing. If ⁿ√uₙ < r < 1 far out, then uₙ < rⁿ, and comparison with Σ rⁿ finishes it.

\sqrt[n]{u_n} \to q < r < 1 @@ choose r between
u_n < r^n \text{ for } n \ge N @@ raise both sides to the n-th power: powers keep order on positives
\htmlClass{new}{\textstyle\sum u_n \text{ settles}} \quad \blacksquare @@ comparison with 15i\'s Σ rⁿ

The root test is for pieces built from n-th powers, like (n/(2n + 1))ⁿ, where ratios would be messy. The ratio test is for pieces built from factorials, where roots would be messy.

22e4Settling in size

Stands on 22e1, 22d4 (the crowd technique for sums) and 8h (the triangle technique).

All three tests ask for pieces that are never negative. For a sum whose pieces change sign, look at their sizes first.

Settles-in-size technique: if Σ |uₙ| settles, then Σ uₙ settles too. Any block uₘ₊₁ + ⋯ + uₙ is at most |uₘ₊₁| + ⋯ + |uₙ| in size, by the triangle technique. So if the sizes crowd, the pieces crowd, and 22d4 finishes it.

From here on, Σ uₙ settles in size when Σ |uₙ| settles. Accepted name: the series converges absolutely.

The converse fails, and 22g is about exactly that: 1 − ½ + ⅓ − ¼ + ⋯ settles, but its sizes are the harmonic sum.

22e5Illegal moves

Stands on 22e1 to 22e4.

u_n \le v_n,\ \sum v_n \text{ settles} \Rightarrow \sum u_n \text{ settles}\,? @@ only if uₙ ≥ 0: uₙ = −1 is under every vₙ = 1/n²
\tfrac{u_{n+1}}{u_n} < 1 \text{ for every } n \Rightarrow \text{settles}\,? @@ the ratios must head to something below 1: 1/n has every ratio n/(n+1) < 1
\tfrac{u_{n+1}}{u_n} \to 1 \Rightarrow \text{wanders}\,? @@ the test is silent at 1: Σ 1/n² settles
\sum u_n \text{ settles} \Rightarrow \sum |u_n| \text{ settles}\,? @@ 1 − ½ + ⅓ − ⋯ (22g)

22e.4.5seamWhere one test fell silent, mathematicians built a finer one, and then a finer one still. A hope grew that some last test would decide every sum of pieces never negative. In 1828 a young mathematician answered a test of that kind by showing no test of its shape could work. Decades later others proved more: for every sum that wanders there is one that wanders more slowly, and for every sum that settles, one that settles more slowly.

The accepted names

The comparison technique is the comparison test, and the ratio-of-pieces comparison the limit comparison test. The ratio test is d’Alembert’s, the root test Cauchy’s. Settling in size is absolute convergence.

Who said it first

Jean le Rond d’Alembert used the ratio of successive pieces in 1768 for the binomial series. Augustin-Louis Cauchy proved both tests in his Cours d’analyse (1821) and showed the root test is the stronger: whenever the ratio test decides, the root test decides the same way. In 22e.4.5, the young mathematician is Niels Henrik Abel (1828), answering a test of Louis Olivier; Ulisse Dini (1867) showed that dividing each piece of a wandering sum by its running total gives one that wanders more slowly, and Paul du Bois-Reymond (1873) and Jacques Hadamard (1894) showed that no scale of comparison sums is the last.
