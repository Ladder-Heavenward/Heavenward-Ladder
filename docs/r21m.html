21m · technique

Running trig backwards

Given an angle, the circle tells you its coordinates. This step asks the question the other way: given a height, which angle has it? Because the waves repeat, many angles do, so you agree to answer from one stretch where each height comes only once. The answer for the cosine turns out to be the arc this rung began with. The slopes of these backward functions are simple fractions with no circle in sight, which is how the circle hides inside so much of calculus.

Cut each wave down to a stretch where it never repeats, and it can be run backwards. Running the cosine backwards gives the arc that started the rung. The backward functions have slopes made only of squares and roots.

21m1Cosine backwards is the arc

On 0 ≤ θ ≤ π, the cosine never repeats a value. Arc-is-arccos technique: running cos on [0, π] backwards gives the arc L of 21a: the angle whose cosine is x is L(x).

\cos\theta = x \iff L(x) = \theta \quad (0 \le \theta \le \pi) @@ ﹀ cos (21b1): the x with L(x) = θ
\htmlClass{new}{\arccos x = L(x) = \int_x^1 \frac{dt}{\sqrt{1 - t^2}}} \quad \blacksquare @@ the undoing of cos on [0, π], for −1 ≤ x ≤ 1

From here on, arccos x is the one θ in [0, π] with cos θ = x. It is also written cos⁻¹ x, where the −1 means “run backwards”, not “one over”.

21m2Sine and tangent backwards

Sin climbs on [−π/2, π/2], since its slope cos is positive inside; tan climbs on (−π/2, π/2) and takes every value. Arcsin-and-arctan technique: each has an undoing, arcsin from [−1, 1] onto [−π/2, π/2] and arctan from all numbers onto (−π/2, π/2); and arcsin x + arccos x = π/2.

\theta = \arccos x \Rightarrow \sin(\tfrac{\pi}{2} - \theta) = \cos\theta = x @@ the complement (21e3)
0 \le \theta \le \pi \Rightarrow -\tfrac{\pi}{2} \le \tfrac{\pi}{2} - \theta \le \tfrac{\pi}{2} @@ so π/2 − θ is in sin’s stretch
\htmlClass{new}{\arcsin x = \tfrac{\pi}{2} - \arccos x} \quad \blacksquare @@ the one angle there with sine x
\tan\theta \to \pm\infty \text{ at } \pm\tfrac{\pi}{2} @@ sin → ±1, cos → 0 from above: every number is reached, by the intermediate value technique (12a)

From here on, arcsin x (or sin⁻¹ x) is the one θ in [−π/2, π/2] with sin θ = x, and arctan x (or tan⁻¹ x) the one θ in (−π/2, π/2) with tan θ = x.

21m3The slopes backwards

Backward-slope technique: arcsin′ x = 1/√(1 − x²), arccos′ x = −1/√(1 − x²) and arctan′ x = 1/(1 + x²). No circle appears in the answers.

\arcsin' x = \frac{1}{\sin'(\arcsin x)} = \frac{1}{\cos(\arcsin x)} @@ inverse-slope (13l), for −1 < x < 1
\cos(\arcsin x) = \sqrt{1 - x^2} @@ the circle technique (21c); cos ≥ 0 on [−π/2, π/2]
\arctan' x = \frac{1}{\sec^2(\arctan x)} = \frac{1}{1 + x^2} @@ sec² = 1 + tan² (21c)
\htmlClass{new}{\arcsin' x = \tfrac{1}{\sqrt{1 - x^2}},\ \ \arctan' x = \tfrac{1}{1 + x^2}} \quad \blacksquare @@ and arccos′ = −arcsin′, by 21m2

Read the other way, as areas: ∫₀¹ dx/(1 + x²) = arctan 1 − arctan 0 = π/4. A fraction with no circle in it has π hidden in its area.

21m4Undoing, and undoing back

Stretch technique: arcsin(sin θ) = θ only when θ is in [−π/2, π/2]; elsewhere it is the one angle in that stretch with the same sine. The other way round, sin(arcsin x) = x for every x in [−1, 1], and is meaningless outside.

\arcsin(\sin\tfrac{5\pi}{6}) @@ 5π/6 is outside [−π/2, π/2]
= \arcsin(\sin(\pi - \tfrac{5\pi}{6})) = \arcsin(\sin\tfrac{\pi}{6}) @@ half turns (21e4): sin(π − θ) = sin θ
\htmlClass{new}{= \tfrac{\pi}{6}} \quad \blacksquare @@ π/6 is inside the stretch

The accepted names

arcsin, arccos and arctan are the inverse trigonometric functions; sin⁻¹, cos⁻¹ and tan⁻¹ are the same functions, and calculators label their keys that way. The chosen stretches are the principal values.

Who said it first

In 21m.4.5, the sum was found by Madhava of Sangamagrama in Kerala (c. 1400), with correction terms that speed it up, and again by James Gregory (1671) and Gottfried Leibniz (1674). John Machin used arctan(1/5) and arctan(1/239) in 1706 to reach a hundred places.
