40b · proof

Jumps Make Branches and Loops

39j3 already had a loop: a jump out when the count is zero, and a jump back to the top. This step names the three shapes a program needs, one after another, one or the other, and again and again. It writes each shape as jumps, and proves that the three are enough.

An if is one jump that skips; a while is a test at the top and a jump back at the bottom. Every flow chart can be rewritten in the three shapes.

40b1Choice Is a Skip

“If A is 0, do P, otherwise do Q” is written with two jumps: JZ yes; Q; JMP end; yes: P; end:.

Branch technique: in the if shape, exactly one of P and Q runs, and then the program goes on at end.

A is 0 or it is not. The jump if zero settles that by looking, as 39j1’s machine does. If A is 0, the run skips Q, runs P and reaches end. If not, it runs Q and the jump to end skips P. One path, either way.

40b2Repetition Is a Jump Back

“While A is not 0, do P” is written: top: JZ end; P; JMP top; end:. The test is at the top, so P may run no times at all. 39j3’s program has exactly this shape, with the count as A.

The shape has one way in, at top, and one way out, at end. Nothing jumps into the middle of it.

40b3Three Shapes Are Enough

Every flow chart of tests and actions can be rewritten using only sequence, if and while, with one extra cell. Number the boxes of the chart 1 to k, and keep the box to visit next in a cell called next. Each action box does its action and then sets next. Each test box sets next to one box or the other.

\text{next} \leftarrow 1 @@ start at the first box
\text{while next} \neq 0: @@ box 0 stands for stop
\quad \text{if next} = 1 \text{ then box 1; } \ldots \text{; if next} = k \text{ then box } k @@ a chain of ifs, one per box
\htmlClass{new}{\text{the same actions, in the same order}} \quad \blacksquare @@ each turn of the while does what the chart did at one box

Each turn of the while runs exactly the box the chart would have reached, by the branch technique on each if. So the runs agree, action for action.

40b4Why Shapes Beat Jumps

A program in the three shapes reads from top to bottom, and each piece has one way in and one way out. So a claim about a piece can be written beside it and proved piece by piece, which 40f and 40g do. A jump into the middle of a loop leaves no such seam.
