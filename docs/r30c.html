30c · proof

Slice the heights, not the inputs

Rung fifteen cut the inputs into strips and stood a rectangle on each. This step turns the knife the other way. It cuts the heights. For each height, it asks where the function stands above that height, and how big that set is. A cashier counting a till works the same way: not coin by coin in the order they came in, but all the quarters, then all the dimes, each pile times its value. A function whose height sets all have sizes is a sized function. Its total is the best that can be done from below with functions that take only a few values. For every curve rung fifteen could handle, the new total and the old area agree. But the new total also handles functions that rung fifteen could not, and it cannot see what happens on a set of size zero.

A sized function has sized height sets. Its total is the least upper bound of the totals of step functions below it, and for continuous functions this is rung fifteen’s area.

30c1Step functions and their totals

From here on, a step function takes finitely many values, each on a sized set: s = c₁ on A₁, …, cₙ on Aₙ, with the Aₖ separate and covering the line, and every cₖ ≥ 0. Its total is

∫ s dm = c₁ m(A₁) + ⋯ + cₙ m(Aₙ), with 0 · ∞ = 0.

Step-total technique: the total of a step function does not depend on how it is written, totals add, and a step function below another has a total no larger.

s = c_i \text{ on } A_i,\ \ t = d_j \text{ on } B_j @@ two step functions, or one written two ways
A_i \cap B_j \text{ sized, separate, cover the line} @@ sized-family (30b2)
\sum_i c_i\, m(A_i) = \sum_{i, j} c_i\, m(A_i \cap B_j) @@ countable-adding (30b3), finitely many pieces
s + t = c_i + d_j \text{ on } A_i \cap B_j \Rightarrow \textstyle\int (s + t) = \int s + \int t @@ total on the common pieces
s \le t \Rightarrow c_i \le d_j \text{ wherever } A_i \cap B_j \text{ is not empty} @@ compare piece by piece
\htmlClass{new}{\textstyle\int s\,dm \text{ is well made, adds, and keeps order}} \quad \blacksquare @@ the lines above

30c2Slicing the heights

From here on, a function f from the line to [0, ∞] is sized when every height set {f > t}, the set of x with f(x) > t, is sized. Its accepted name is measurable function.

Height-slices technique: continuous functions are sized, and sums, products and the least upper bound of a list of sized functions are sized.

f \text{ continuous} \Rightarrow \{f > t\} \text{ is open} @@ near a point above t, f stays above t (12a)
\{\sup_n f_n > t\} = \bigcup_n \{f_n > t\} @@ some fₙ is above t exactly when the least upper bound is
\{f + g > t\} = \bigcup_{q \text{ fraction}} \{f > q\} \cap \{g > t - q\} @@ a fraction fits between f(x) and t − g(x) (8e)
\{fg > t\} = \bigcup_{q > 0 \text{ fraction}} \{f > q\} \cap \{g > t/q\} \ \ (t \ge 0) @@ likewise, for f, g ≥ 0
\htmlClass{new}{\text{each is a countable union of sized sets}} \quad \blacksquare @@ sized-family (30b2)

So every function the ladder has met so far is sized, and so is every limit of a rising list of them. 10d’s q, with q = 1 on the fractions and 0 elsewhere, is sized: its height sets are the empty set, the fractions, or the whole line.

30c3The total of a sized function

From here on, for a sized f ≥ 0, its total is the least upper bound of the totals of step functions s with 0 ≤ s ≤ f:

∫ f dm = sup { ∫ s dm : s a step function, s ≤ f }.

The total over a sized set A is ∫A f dm = ∫ f · 1A dm, where 1A is 1 on A and 0 elsewhere. Its accepted name is the integral; f is integrable when its total is finite.

Total-from-below technique: every sized f ≥ 0 is the limit of a rising list of step functions below it.

s_n(x) = \min\big(n,\ \lfloor 2^n f(x) \rfloor / 2^n\big) @@ round f down to a multiple of 1/2ⁿ, and cap it at n
s_n = k/2^n \text{ on } \{k/2^n \le f < (k+1)/2^n\} @@ finitely many values, each on a sized set (30c2)
s_n \le s_{n+1} \le f @@ a finer rounding down is no lower
f(x) - s_n(x) \le 1/2^n \text{ once } n \ge f(x) @@ rounding loses less than one step
\htmlClass{new}{s_n(x) \to f(x) \text{ at every } x} \quad \blacksquare @@ and sₙ(x) → ∞ where f(x) = ∞

For f that takes both signs, write f = f⁺ − f⁻, with f⁺ = max(f, 0) and f⁻ = max(−f, 0). When ∫|f| dm is finite, ∫f dm = ∫f⁺ dm − ∫f⁻ dm.

Anexact, yet rigorous · two sizes of truth

2b set a claim about each one beside a claim about the crowd. The total is a crowd claim. It speaks of the whole function at once and can be blind to any one point. Change f on a set of size 0 and no step function’s total moves, so the total does not move.

A total is a claim about the whole function, and it cannot see what happens on a set of size 0.

So a claim can be true of f except on a size-0 set. That is a different size of claim from one true at every point. 10d’s q is 0 except on a size-0 set, and its total is 0.

Two thermometers log a day’s temperatures, and one of them glitches for an instant at noon. Do their totals over the day agree? Which claims about the day do they share, and which not?

30c4The new total meets the old area

Agrees-with-area technique: if f ≥ 0 is continuous on [u, v], its total over [u, v] is 15’s area ∫ᵤᵛ f(x) dx.

P:\ u = x_0 < x_1 < \cdots < x_n = v,\ \ m_i, M_i \text{ the least and most of } f \text{ on } [x_{i-1}, x_i] @@ a partition and its strips (15a)
s = m_i \text{ on each strip is a step function below } f @@ strips are sized (30b4)
L(f, P) = \textstyle\int s\,dm \le \int_{[u,v]} f\,dm @@ the total is a least upper bound
t \le f \text{ a step function} \Rightarrow t \le M_i \text{ on each strip} \Rightarrow \textstyle\int t \le U(f, P) @@ step-total keeps order (30c1)
L(f, P) \le \textstyle\int_{[u,v]} f\,dm \le U(f, P) \text{ for every } P @@ the lines above
\htmlClass{new}{\textstyle\int_{[u,v]} f\,dm = \int_u^v f(x)\,dx} \quad \blacksquare @@ exactly-one-between (15c)

So nothing rung fifteen built is lost. But 10d’s q, which has no area by rung fifteen (10d, 15c), has total 0 here. The new total measures more functions, and agrees with the old one wherever the old one works.

The basement · there if you want it

The accepted names

A sized function is a Lebesgue measurable function, and a step function is a simple function. The total is the Lebesgue integral, ∫ f dm or ∫ f dλ. “Except on a size-0 set” is “almost everywhere”, written a.e. Functions with ∫|f| finite are integrable, and the family of them is written L¹.

Who said it first

Henri Lebesgue described the idea in 1901 and gave it in full in his thesis of 1902. He later compared it to a shopkeeper who sorts the coins by value before counting them, where the old way counts them in the order they were handed over.

A proof that is not allowed

“q is 1 on the fractions, which are in every strip, so every upper sum is the strip’s length and the total of q is 1.” Not allowed: that reasons with rung fifteen’s upper sums, which q has no area for. The total slices heights: q = 1 on a set of size 0, so its total is 1 · 0 = 0.
