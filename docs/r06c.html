6c · proof

Finitely many needs no axiom

6b laid down the choosing axiom. It said in passing that a collection you can write out needs none of it: pick from each set in turn, one call per set. This step proves that for every collection you can count, by induction on how many sets it holds, with 4k's counting doing the work. The proof is short, but one line of it needs care. It is a case split on whether two members of the collection are the same set, and the ladder licenses it only because a finite set is settled. Then the step counts the choosing functions of a finite collection, which turns out to be a product. It ends with the place where the axiom earns its keep: collections that are infinite and have no rule. The tempting proof that “picks one, and so on” is taken apart there.

Lead one set out of the collection, pick from the rest by the induction hypothesis, name a member of the one led out, and put it back with its pick. One call per step, and as many calls as there are sets.

6c1Picking in turn, by hand

Take 𝒜 = {A₁, A₂, A₃} with A₁ = {ant, bee, cow}, A₂ = {cat, dog}, A₃ = {owl}, three different sets. Each has a member, so each can be called.

\text{call } p \in A_1,\ \ \text{call } q \in A_2,\ \ \text{call } r \in A_3 @@ use a some, three times: each set is non-empty
c = \{(A_1, p),\ (A_2, q),\ (A_3, r)\} @@ Pairing and union (2e), pairs (2g)
c \subseteq \mathcal A \times \textstyle\bigcup\mathcal A @@ each left entry in 𝒜; each right entry in its left entry, so in ⋃𝒜
A_1 \ne A_2,\ A_1 \ne A_3,\ A_2 \ne A_3 @@ same-members: ant is in A₁ only, cat in A₂ only, owl in A₃ only
\htmlClass{new}{c \text{ is a choosing function for } \mathcal A} @@ one pair per member, by the line above; each pick in its set
\exists c\,(c \text{ chooses for } \mathcal A) \quad \blacksquare @@ show an example; the three calls close, since the line mentions none of p, q, r

Notice the fourth line. Suppose two of the names A₁, A₂, A₃ had named the same set. Then the gathering would have given that set two pairs, possibly with two different picks, and c would not be a function. By hand, you look at the listing and see that the sets differ. In general you need to know, for any two members of the collection, whether they are the same set or not. The techs give that for free only in a settled world. 4k's finite-is-settled makes a finite set one: from X has n members, and x, y ∈ X, you may write x = y ∨ x ≠ y. That is the licence the general proof uses.

6c2The technique, and its base

In plain words: a collection with any number of members, each of them non-empty, has a choosing function, with no axiom. Finite-choice technique, in marks:

The shape is 4c's proof by induction. Name the condition first: φ(n) is the statement ∀𝒜 (𝒜 has n members ∧ ∀A ∈ 𝒜 (A is non-empty) ⇒ ∃c (c is a choosing function for 𝒜)), with n in its gap. The column proves ∀n ∈ ℕ φ(n), and that is the box's licence. It speaks of every collection, which a condition may do (4b). The base is short.

\text{let } \mathcal A \text{ have } 0 \text{ members} @@ let 𝒜 be anything; assume (the non-empty part is not needed)
\mathcal A \text{ is matched with } 0,\ \text{and } 0 \text{ names } \varnothing @@ ﹀ “has 0 members”; 3b's name
\quad \text{assume } A \in \mathcal A:\ A \text{ has a partner } k \in \varnothing @@ the matching pairs every member of 𝒜 with a member of 0
\quad \bot @@ the empty-set technique, clash
\forall A\,(A \notin \mathcal A),\ \text{so } \mathcal A = \varnothing @@ refute; speak of everything; one-empty-set with the empty-set technique
\htmlClass{new}{\varnothing \text{ is a choosing function for } \mathcal A} @@ the empty-collection technique (6b), and the swap axiom
\varphi(0) @@ show an example; prove an if; speak of everything

6c3The step: one set led out and put back

The step leads one set out, uses the hypothesis on the rest, and puts the set back with a pick. Here it is in four parts.

\text{let } n \in \mathbb N;\ \text{assume } \varphi(n) @@ the induction hypothesis
\text{let } \mathcal A \text{ have } S(n) \text{ members, each non-empty} @@ let 𝒜 be anything; assume
n \in S(n);\ \text{call } A \text{ the partner of } n;\ A \in \mathcal A @@ in-its-next; the matching gives n exactly one partner; use the some
\mathcal A \setminus \{A\} \text{ has } n \text{ members} @@ the lead-one-out technique (4k): lead one out
\text{each member of } \mathcal A \setminus \{A\} \text{ is non-empty} @@ ﹀ ∖: it is a member of 𝒜
\text{call } c' \text{ a choosing function for } \mathcal A \setminus \{A\} @@ φ(n), used with 𝒜 ∖ {A}; carry through; use the some
\text{call } a \in A @@ A is non-empty; use the some: the one new call of the step
\htmlClass{new}{c = c' \cup \{(A, a)\}} @@ Pairing, Union: the pick put back with its set
  
c \subseteq \mathcal A \times \textstyle\bigcup \mathcal A @@ merge-membership: a pair of c′ has its set in 𝒜 ∖ {A} ⊆ 𝒜 and its pick in that set; and a ∈ A ∈ 𝒜
\text{let } B \in \mathcal A;\ \ B = A \ \lor\ B \ne A @@ finite-is-settled (4k): 𝒜 has S(n) members, so sameness among its members is settled
\quad \text{case } B = A:\ (B, a) \in c,\ a \in B @@ the swap axiom; merge-membership; add an option
\quad \text{case } B \ne A:\ B \in \mathcal A \setminus \{A\},\ (B, c'(B)) \in c,\ c'(B) \in B @@ B ∉ {A} by the listing line; ︿ ∖; c′ chooses; c′ ⊆ c by merge-membership
\exists y\,((B, y) \in c \land y \in B) @@ show an example in each case; reason by cases
  
(B, y) \in c \ \land\ (B, z) \in c @@ assume two pairs with the same input
\text{each is in } c' \text{ or is } (A, a) @@ merge-membership and the listing: a proved or, not a split on “so or not so”
\quad \text{both in } c':\ y = z @@ c′ is a function
\quad (B, y) \in c',\ (B, z) = (A, a):\ B = A,\ (A, y) \in c' @@ equal-pairs; the swap axiom
\quad\quad A \in \mathcal A \setminus \{A\},\ \text{so } A \notin \{A\};\ \ A \in \{A\};\ \ \bot @@ c′'s inputs are in 𝒜 ∖ {A}; ﹀ ∖; the listing; clash
\quad\quad y = z @@ everything permitted
\begin{aligned}&\quad \text{the same with } y \text{ and } z \text{ turned about}\\ &\quad ;\ \ \text{both } (A, a):\ y = a = z\end{aligned} @@ the case above again; equal-pairs
\htmlClass{new}{y = z} @@ reason by cases
  
c : \mathcal A \to \textstyle\bigcup\mathcal A,\quad c(B) \in B \text{ for every } B \in \mathcal A @@ ︿ 4d's line for a function from the three parts; the value line
\exists c\,(c \text{ is a choosing function for } \mathcal A) @@ show an example; the calls for A, c′ and a close: the line mentions none of them
\varphi(S(n)) @@ prove an if; speak of everything
\forall n \in \mathbb N\,\varphi(n) \quad \blacksquare @@ the induction technique (4c)

6c4Counting the calls

Count the calls. The step makes one new call: a member of the set led out. Unfold the induction for a collection with 3 members and you get the three calls of the column above, one per set, made in turn. That is what the technique does: picking in turn always works, for any number of sets you can count. Induction lets one written proof cover every number at once, because each number's column is finite.

And look where the step split on “B = A or B ≠ A”. That is the kind of split the either-way principle would license for any statement, and that principle is rung 7's. Here the split is licensed by finite-is-settled, because the collection has S(n) members. Its members can be told apart, one from another, through their partners in S(n) and 4h's settled-order. The other split, in the last part, comes from merge-membership, a proved or. So finite-choice uses no choosing axiom and no either-way principle.

6c5How many ways to pick

6b found exactly two choosing functions for {{cat, dog}, {owl}}. The step of finite-choice shows why. Each choosing function for 𝒜 is a choosing function for 𝒜 ∖ {A} with one more pair (A, x), x ∈ A. And each such pair of a smaller function and a member of A gives one. Counting-pickings technique: if 𝒜 is finite, A ∈ 𝒜, A has s members, and 𝒜 ∖ {A} has q choosing functions, then 𝒜 has q · s choosing functions. The matching takes c to (c ∖ {(A, c(A))}, c(A)). Back, it takes (c′, x) to c′ ∪ {(A, x)}. The first is a choosing function for 𝒜 ∖ {A} by the same parts as finite-choice's step. So the choosing functions of 𝒜 are matched with the product of A and the set of choosing functions of 𝒜 ∖ {A}. That product has q · s members by 4k's stages-multiply. ∎ By induction on the number of sets, then, the count is the product of the sizes, one factor per set.

\{\{\text{ant}, \text{bee}, \text{cow}\},\ \{\text{cat}, \text{dog}\},\ \{\text{owl}\}\}:\quad 3 \cdot 2 \cdot 1 = \htmlClass{new}{6} @@ a factor for each set
\{\{1, 2\},\ \{2, 3\},\ \{3\}\}:\quad 2 \cdot 2 \cdot 1 = 4 @@ picks may coincide: 2 from both of the first two sets is allowed
\{\{\text{cat}, \text{dog}\},\ \varnothing\}:\quad 2 \cdot 0 = \htmlClass{new}{0} @@ times-zero (4g): agrees with empty-member, which said there is none
\varnothing:\quad \text{the empty product} = 1 @@ 4j: the empty list's product is 1; agrees with empty-collection, which said there is exactly one

The two edge cases of 6b fall out of the arithmetic: a factor 0 for ∅ in the collection, and the product of no factors, 1, for the empty collection. Rung 4's conventions were chosen well.

6c6Where the axiom adds something

Turn finite-choice about. Only-the-infinite-fails technique: a collection of non-empty sets with no choosing function is infinite.

\forall A \in \mathcal A\,(A \text{ non-empty}),\ \ \neg\exists c\,(c \text{ chooses for } \mathcal A) @@ given
\quad \text{assume } \exists n\,(\mathcal A \text{ has } n \text{ members});\ \text{call it } n @@ aiming to refute; use the some
\quad \exists c\,(c \text{ chooses for } \mathcal A) @@ the finite-choice technique, used with n and 𝒜; carry through
\quad \bot @@ clash
\htmlClass{new}{\neg\exists n\,(\mathcal A \text{ has } n \text{ members})} \quad \blacksquare @@ refute: 𝒜 is infinite (6b's line)

This ends in a denial, so it is honest without rung 7. Together with 6b, it marks out exactly where the axiom is needed. The collection must be infinite, and there must be no rule, no condition true of exactly one member of each set. Shoes have a rule; settled sets of numbers have one. Socks matched with ℕ have neither a rule nor a finite count. Even the axiom restricted to collections matched with ℕ cannot be proved; call it listed choosing. 6d shows a world where it fails, for socks.

6c7The trap in “and so on”

Here is the tempting argument that the axiom is not needed even for socks. Let 𝒦 be matched with ℕ, pair K_n for each number n. Let 𝒦_n = {K ∈ 𝒦 : the partner of K is less than n}, the first n pairs (a sift of 𝒦). 𝒦_n has n members, so finite-choice gives a choosing function for it. “So pick from the first pair, then the second, and so on, and you have picked from them all.”

\forall n\ \exists c\ (c \text{ chooses for } \mathcal K_n) @@ true: the finite-choice technique, for each n
\htmlClass{new}{\exists c\ \forall n}\ (c \text{ chooses from } \mathcal K_n) @@ illegal to conclude: ∃ and ∀ have swapped places. 2b's licensed-swap goes only the other way

The first line is a separate fact for each n, with a separate function for each n, made afresh by its own column of n calls. Nothing says the function for 𝒦₃ agrees with the function for 𝒦₄ on the first three pairs: the column for 𝒦₄ makes its own four calls. To glue them into one function you would have to pick, for every n at once, one of the functions that choose for 𝒦_n. That would be a choosing function for the collection of those sets of functions. That is the axiom again, in disguise. The words “and so on” smuggle in exactly the thing being avoided.

There is a second disguise, more dangerous because it looks like rung 4. “Define the picks by repeating: start with ∅, and at each step add a sock of the next pair.” 4d's recursion needs a step that is a function g, taking each stage to exactly one next stage. “Add a sock of K_n” is not a function: it fits two next stages. The step would need a function that takes each pair to one of its socks. That is a choosing function for 𝒦, the very thing wanted. Recursion builds endless runs only from steps that are rules.

6c9Running it backwards

Wanting a choosing function for a collection you can count, run finite-choice: say how many members it has, and the induction does the rest. For a written-out collection, make one call per set and check by same-members that the sets differ. Wanting to know how many there are, multiply the sizes (counting-pickings). Wanting to know whether the axiom is needed, ask two questions. Is the collection infinite (only-the-infinite-fails)? Is there a rule (6b)? Only a yes and a no call for the axiom. Seeing “and so on” in a proof, find the ∀∃ it hides and ask whether it has been swapped. Found upward; written downward.

Who said it first

The refusal to pick endlessly many times without a rule is Giuseppe Peano’s, in 1890.

Peano, proving a technique about differential equations, refused to make his argument by choosing a member from each of endlessly many classes. He remarked that one cannot apply an arbitrary law, one that assigns to a class some member of it, endlessly many times, and he arranged his proof to use a definite rule instead.

Peano, “Démonstration de l'intégrabilité des équations différentielles ordinaires”, Mathematische Annalen 37 (1890)

Accepted names

The either-way principle has the accepted name the law of excluded middle. The axiom restricted to collections in bijection with ℕ is called countable choice.
