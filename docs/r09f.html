9f · technique

Composing and Inverting by Hand

9b proved you may chain functions and 9d proved a bijection can be run backwards. This step is where your hands learn to do both fast, and on purpose. You build a function you want out of pieces you know. You take a formula apart into the chain that made it. And you undo a chain by undoing its links in reverse. Every undo here is made of techs you own: adding, multiplying, powers and roots. When a link uses an output twice, you keep part of its inputs first, as 9d did for squaring.

Compose inside out: the inside's output is the outside's input. Take a formula apart by finding the last thing done to the input: that is the outside, and what it was done to is the inside. Invert by undoing the links, last first.

9f1Composing by Hand: Inside Out

(g ∘ f)(x) is g(f(x)): do f, then hand its output to g (9b's composite-is-a-function). With numbers, peel from the inside, one layer per line. With formulas, substitute for the expression: wherever the outside's formula has its letter, put the whole inside formula, in brackets.

f(x) = x^2 + 1,\ \ g(x) = \sqrt x @@ g lives on x ≥ 0 (9e's natural domain)
(g \circ f)(x) = g(\htmlClass{new}{x^2 + 1}) = \sqrt{x^2 + 1} @@ substitute the inside for g's letter; every x, since x² + 1 ≥ 1
(f \circ g)(x) = f(\htmlClass{new}{\sqrt x}) = (\sqrt x)^2 + 1 @@ the other order: √x goes in for f's letter
\phantom{(f \circ g)(x)} = x + 1 \quad \htmlClass{keep}{\text{for } x \ge 0} @@ 8f's line: √x · √x = x, but only where √x names a real

The small print on the last line is the tempting move to check. f ∘ g can only be fed what g can be fed, so its domain is [0, ∞). And x ↦ x + 1 on all of ℝ has pairs, like (−4, −3), that f ∘ g lacks: different functions by pairs-fix-the-inputs. The rule for the domain of a composite is in its definition. Composite-domain technique: the natural domain of x ↦ g(f(x)) is {x ∈ dom f : f(x) ∈ dom g}. The formula g(f(x)) names a real exactly when f(x) does and g's formula names a real at it. ∎ So finding it is a small backwards problem: run the outside's condition back through the inside.

\sqrt{4 - x^2}:\ \ \text{outside } \sqrt{\ },\ \text{inside } 4 - x^2 @@ the outside accepts only reals ≥ 0
4 - x^2 \ge 0 @@ composite-domain: the inside's output must be an input of the outside
x^2 \le 4 @@ add x² to both sides (adding keeps order, 8g); 4 ≥ x² is x² ≤ 4 (4h's line for ≥)
|x| \le 2 @@ size-squared: |x|² = x²; powers-keep-order backwards, since |x| and 2 are ≥ 0
\htmlClass{new}{-2 \le x \le 2} @@ unpack-the-bars (8h): the domain is [−2, 2]

And do not confuse g ∘ f with g · f. The ring means “after”; the dot means “times”. (g · f)(x) = √x · (x² + 1) is a product, a third function again, with domain [0, ∞).

9f2Taking a Chain Apart: Find the Outside, Name the Inside r

Running composition backwards is reading a formula from the outside in. Ask: if I were computing this for a particular x, what would I do last? That last operation is the outside. Everything it was done to is the inside, and you call it r.

y = (3x - 1)^5 @@ the last thing done: raise to the fifth power
r = \htmlClass{new}{3x - 1},\ \ y = r^5 @@ the inside is what got raised
y = \tfrac{1}{x^2 + 4} @@ the last thing done: one over
r = \htmlClass{new}{x^2 + 4},\ \ y = \tfrac1r @@ the inside is the whole bottom
y = \sqrt{1 + (2x)^3} @@ three links: double; cube and add 1; root
r = 2x,\ \ s = 1 + r^3,\ \ y = \htmlClass{new}{\sqrt s} @@ peel one layer at a time; regroup for composing: the brackets of the chain don't matter

The decomposition is not unique, and that is a feature. (3x − 1)⁵ is also 3⁵(x − ⅓)⁵, by power-of-a-product read in ℝ: a different chain for the same function. A later rung asks you to work through a chain link by link (rung 13 does). Then you get to pick the cut that makes the work easy. Running forward again is the check. Substitute the inside back into the outside, and you must land on the formula you started with.

9f4Inverting a Chain: Undo in Reverse Order, or Swap and Solve

Socks then shoes; to undo, shoes off first. 9d's socks-and-shoes says it exactly: (g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹. The last link applied is the outside, so it comes off first.

f(x) = (2x - 3)^3 + 1 @@ the chain: double, take 3, cube, add 1
\text{undo: } \htmlClass{new}{\text{take } 1,\ \text{cube root},\ \text{add } 3,\ \text{halve}} @@ each link's undo, from the last link to the first (socks-and-shoes)
f^{-1}(x) = \tfrac{\sqrt[3]{x - 1} + 3}{2} @@ written as one formula, innermost undo first
f(2) = 1^3 + 1 = 2,\ \ f^{-1}(2) = \tfrac{1 + 3}{2} = \htmlClass{keep}{2} @@ there and back at a number (there-and-back)

The other route reads 9d's swapped-pairs as a recipe. The swapped pairs (v, u) are those with v = f(u). So write y = f(x), and solve for x by licensed techs (5g's adding-keeps-answers and multiplying-keeps-answers, read in ℝ by 8g). The answer x = h(y) names f⁻¹ = h. Each move peels the outermost link left, so the two routes always agree. Solving succeeds, with exactly one x for each y, precisely when f is a bijection onto the set of y you allow (swapped-pairs-function).

y = (2x - 3)^3 + 1 @@ the function as an equation in x and y
y - 1 = (2x - 3)^3 @@ adding-keeps-answers: add −1 to both sides
\sqrt[3]{y - 1} = 2x - 3 @@ cube roots of both sides: licensed, since cubing is a bijection of ℝ (odd-powers-keep-order)
\htmlClass{new}{x = \tfrac{\sqrt[3]{y - 1} + 3}{2}} @@ adding-keeps-answers by 3, multiplying-keeps-answers by ½: the same as undoing in reverse

The usual recipe is “swap x and y, then solve for y”. That is the same work with the letters exchanged at the start: the swapped pairs, written with x for the left entry as usual. The ladder solves for x and renames at the end, so no letter changes its job midway.

9f5When Two Inputs Share an Output: Keep Part, Then Invert

Solve y = (x − 2)² + 1 for x and you hit a fork at the square root. (x − 2)² = y − 1 has two answers when y > 1, namely 2 ± √(y − 1) (8i's ±). The fork is the failure of one-to-one, seen in the algebra: f(1) = f(3) = 2. So first decide which inputs to keep. Keep x ≥ 2, where the displacement x − 2 is never negative.

f(x) = (x - 2)^2 + 1 \text{ kept to } x \ge 2 @@ 9d's restriction; outputs y ≥ 1 (square-never-negative), every y ≥ 1 reached
y - 1 = (x - 2)^2 @@ adding-keeps-answers
\sqrt{y - 1} = \sqrt{(x - 2)^2} = |x - 2| @@ roots of both sides (both ≥ 0); size-squared
\phantom{\sqrt{y - 1}} = \htmlClass{new}{x - 2} @@ the bars come off because x ≥ 2 was kept: this is the line the keeping was for
x = 2 + \sqrt{y - 1} @@ adding-keeps-answers
f^{-1}(x) = 2 + \sqrt{x - 1} \text{ on } [1, \infty) @@ rename; domains-trade-places: the inverse's domain is f's range

Keep x ≤ 2 instead and the bars come off as 2 − x, giving 2 − √(x − 1). The tempting move to check is to take roots and write x − 2 = √(y − 1) with no comment. The honest root of a square is the absolute value; the keeping is what licenses dropping the bars.

9f6Fractions, Displacements, and Fractional Powers

Solving works on fractions too: clear the bottom, gather the x terms, factor x out, divide.

y = \tfrac{x + 1}{x - 2},\ \ x \ne 2 @@ the natural domain
y(x - 2) = x + 1 @@ multiplying-keeps-answers by x − 2, not 0 on the domain
yx - x = 2y + 1 @@ expand (spread on ℚ); adding-keeps-answers: add 2y − x to both sides, so the x terms stand on the left
x\,\htmlClass{new}{(y - 1)} = 2y + 1 @@ factor x out (spread on ℚ backwards)
x = \tfrac{2y + 1}{y - 1},\ \ y \ne 1 @@ multiplying-keeps-answers by (y − 1)⁻¹; at y = 1 the line reads 0 = 3, no answer
f^{-1}(x) = \tfrac{2x + 1}{x - 1} @@ rename; domain ℝ ∖ {1} = ran f (domains-trade-places)

Notice the domains trading places. f lives on x ≠ 2 and never outputs 1; f⁻¹ lives on x ≠ 1 and never outputs 2. That is swapped-pairs, again, and the fraction 9e found the range of.

Displacements and added amounts are links too. 9e showed g(x) = f(x − h) has the pair (u + h, v) whenever f has (u, v). Now see it as a chain: g = f ∘ d, with d(x) = x − h acting first. And f(x) + k is t ∘ f with t(y) = y + k acting last. So g(x) = (x − 2)³ + 5 is: take 2, cube, add 5. Its inverse undoes those last first: take 5, cube root, add 2. So g⁻¹(x) = ³√(x − 5) + 2. Check at 3: g(3) = 1 + 5 = 6, and g⁻¹(6) = 1 + 2 = 3.

A fractional power is itself a chain (8i): x^(p/q) is “the q-th root, then the p-th power”. So it inverts like any chain, and on x > 0 the undo is the reciprocal power. Take f(x) = 2x^(3/2) on [0, ∞): power 3/2, then double. Undo: halve, then power 2/3, so f⁻¹(x) = (x/2)^(2/3). Check with a number whose roots are easy: f(4) = 2 · (√4)³ = 16, and f⁻¹(16) = 8^(2/3) = (³√8)² = 4. 9·bio runs the three-quarters law backwards this way.

9f8Running It Backwards

Handed a chain: substitute inside out. Handed a formula: find the last operation, name the inside r, and repeat on r. Handed a function to invert: list its links, and check each is one-to-one on what it is fed (keep part if not). Then undo last first; or solve y = f(x) for x. Handed a claimed inverse: compose both ways at a number, then as formulas. Found upward; written downward.
