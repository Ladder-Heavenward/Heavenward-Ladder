28e · proof

Locally undoable

Rung 27 found that a grid can be undone exactly when its determinant is not zero. A curved map is harder: it bends space, and it may fold it over on itself far away. This step proves that if the best flat map of a curved map can be undone at a point, then the curved map itself can be undone near that point. The proof hunts for the answer by repeated small corrections, and rung 24’s shrinking map promises that the hunt ends at exactly one answer.

If a smoothly sloped map from lists of n numbers to lists of n numbers has an undoable slope grid at w, it can be undone on some patch around w, and the undoing is smoothly sloped, with the undone grid as its slope grid.

28e1Small slopes, small moves

Segment-bound technique: if φ is smoothly sloped on a ball, and every entry of its slope grid has size at most ε there, then |φ(x) − φ(x′)| ≤ nε |x − x′| for x, x′ in the ball. A ball is the set of points within a fixed length of a centre; with any two points it holds the segment between them.

g(t) = \varphi_i(x' + t(x - x')),\ \ 0 \le t \le 1 @@ one output, along the segment, which stays in the ball
\varphi_i(x) - \varphi_i(x') = g(1) - g(0) = g'(s) = \text{row}_i\,(x - x') @@ the average-slope technique (14c), and the roads-add technique (28c3); the row is taken at a point of the segment
|\varphi_i(x) - \varphi_i(x')| \le \sqrt{n}\,\varepsilon\,|x - x'| @@ the dot-bound technique (18b): the row has n entries of size at most ε
\htmlClass{new}{|\varphi(x) - \varphi(x')| \le n\varepsilon\,|x - x'|} \quad \blacksquare @@ square and add the n outputs

28e2Undoing near a point

Let f be smoothly sloped near w, from lists of n numbers to lists of n numbers, with b = f(w) and A = Df(w) undoable (det A ≠ 0, 27e). To solve f(x) = y for y near b, correct a guess x by the undone flat map:

\(\varphi_y(x) = x + A^{-1}\,(y - f(x)).\)

A point x is still under φy exactly when f(x) = y. Local-undo technique: there are balls U around w and V around b such that each y in V has exactly one x in U with f(x) = y.

D\varphi_y(x) = I - A^{-1}Df(x),\ \ D\varphi_y(w) = 0 @@ the chain-of-flat-maps technique (28c2); it does not depend on y
\text{entries of } D\varphi_y \le \tfrac{1}{2n} \text{ on the closed ball } |x - w| \le r @@ the partial slopes are continuous at w (28a1); choose r small
|\varphi_y(x) - \varphi_y(x')| \le \tfrac12 |x - x'| @@ the segment-bound technique (28e1)
|\varphi_y(x) - w| \le \tfrac12|x - w| + |A^{-1}(y - b)| \le \tfrac r2 + c\,|y - b| @@ φ_y(w) − w = A⁻¹(y − b); c from the stretch-bound technique (28c1) for A⁻¹
|y - b| < \tfrac{r}{2c} \Rightarrow \varphi_y \text{ sends the ball into itself} @@ the line above is then less than r
\htmlClass{new}{\text{exactly one } x \text{ in the ball with } f(x) = y} \quad \blacksquare @@ the shrinking-map technique (24c); its proof runs word for word with points and |·|, since crowding points settle place by place (12e)

28e3The undoing has a slope

Call the undoing g: for y in V, g(y) is the one x in U with f(x) = y. Undo-slope technique: g is smoothly sloped on V, and Dg(y) = Df(g(y))⁻¹.

|x - x'| \le |\varphi_y(x) - \varphi_y(x')| + |A^{-1}(f(x) - f(x'))| \le \tfrac12|x - x'| + c\,|f(x) - f(x')| @@ write x − x′ = φ_y(x) − φ_y(x′) + A⁻¹(f(x) − f(x′)); 28e2 and 28c1
|g(y) - g(y')| \le 2c\,|y - y'| @@ the line above with x = g(y), x′ = g(y′); so g is continuous
f(x + k) - f(x) = Df(x)k + s(k),\ \ k = g(y + h) - g(y) @@ the best flat map of f at x = g(y) (28b1)
k = Df(x)^{-1}h - Df(x)^{-1}s(k) @@ h = f(x + k) − f(x); Df(x) is undoable near w, since det is continuous and not 0 at w (27e)
\dfrac{|Df(x)^{-1}s(k)|}{|h|} \le c'\cdot 2c\,\dfrac{|s(k)|}{|k|} \to 0 @@ 28c1 for Df(x)⁻¹, and |k| ≤ 2c|h|
\htmlClass{new}{Dg(y) = Df(g(y))^{-1}} \quad \blacksquare @@ the leftover shrinks faster than h (28b1); its entries are continuous, by the stand-in grid (27g)

So near a point where the slope grid is undoable, the map is a change of coordinates: it can be run backwards, and backwards it is smooth too. The polar map (r, θ) ↦ (r cos θ, r sin θ) has det = r, so it is undoable near every point with r ≠ 0, though not on the whole plane: θ and θ + 2π land on the same point.

The basement · there if you want it

The accepted names

The local-undo and undo-slope techniques together are the inverse function theorem. A map that is one-to-one, smooth and has a smooth inverse is a diffeomorphism; a local one is a change of coordinates. The correction φy is a simplified Newton iteration, which keeps the first slope grid instead of updating it.

Who said it first

Joseph-Louis Lagrange and Augustin-Louis Cauchy used the idea for power series. Ulisse Dini proved the implicit and inverse function theorems for real functions in his lectures at Pisa, published in 1878. The proof by a contraction mapping follows Émile Picard’s method of successive approximation (1890) and Stefan Banach’s fixed point theorem (1922).
