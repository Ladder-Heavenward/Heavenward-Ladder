Why Infinity Is Chosen, Not Discovered

3d laid the axiom down rather than proving it, and said that nothing earlier on the ladder could prove it. That is a strong claim, and this step makes it good. It does not mean “nobody has found a proof yet”. It means that no proof can exist, and the way to show that is a move you met on 3a·f: build a world in which every earlier principle is true and the statement is false. If the earlier principles could prove the statement, the proof would run in that world too, since a proof uses nothing but the principles and the techs. Then the statement would be true there, and it is not. The world is built in layers from nothing, each layer all the subsets of the one before. Every set in it can be written out completely, and that is exactly why no set in it is inductive.

First, practice. Six footings work the start-and-step argument on the numbers of 3c, say how to find one, and say why describing the whole run gives out. Then the layers.

Build layers: the bottom is empty, and each layer is all the subsets of the layer below. Every earlier tool keeps you inside the layers; every step of membership drops you one layer; and the run of next ones steps down further than any layer allows. So the world has every earlier principle and no inductive set, and the axiom is not a consequence of anything before it.

3f1Start and Step

3c showed, set by set, that each named number is the set of those before it: four arguments, one for each name. Arguments of that kind share a shape. Check a claim for 0: that is the start. Then show that whenever the claim holds for a set u, it holds for S(u): that is the step. The step is one argument, with u a letter about which nothing is assumed but the claim.

Run the step once from the start and the claim holds for 1. Run it again and it holds for 2. Four runs reach 4, and each next one you go on to name is reached in one run more.

Start-and-step shape: if a claim holds for 0, and holding for u carries it to S(u), then it holds for 0, 1, 2, 3, 4, and for each next one you go on to name.

Saying it for the whole run in one line needs the run as a set, which 3d laid down and 4d puts to work. Until then the shape is used one number at a time, and that is all this step needs. Here it is on a small claim: 0 is in every number after 0.

0 \in S(0) @@ start: S(0) is named 1, and 1 = {0} (3c6)
0 \in S(u) \Rightarrow 0 \in S(S(u)) @@ step: S(u) is a part of its next (the in-its-next technique, 3c4)
0 \in 1,\ 0 \in 2,\ 0 \in 3,\ 0 \in 4 @@ the step, run from the start once for each name
\htmlClass{new}{0 \in S(u) \text{ for each } u \text{ of the run}} \quad \blacksquare @@ the start-and-step shape

3c7 read this off the listings: every number after 0 holds the least one, ∅, the set the run started from. Here it comes from the shape, with no listing written out.

3f2Members Are Parts

A second claim, whose step needs the claim it is carrying: every member of a number is also a part of it.

\forall y\,(y \in 0 \Rightarrow y \subseteq 0) @@ start: nothing is in 0, so each if has a false first half
y \in S(u) \Rightarrow y \in u \lor y = u @@ step: the next-membership technique (3c3)
y \in u \Rightarrow y \subseteq u \subseteq S(u) @@ the claim for u, then in-its-next and the chain technique for part of
y = u \Rightarrow y \subseteq S(u) @@ in-its-next again
\htmlClass{new}{y \in S(u) \Rightarrow y \subseteq S(u)} \quad \blacksquare @@ the two cases, joined

So every member of 0, 1, 2, 3 and 4 is a part of it, and so on for each next one. 2 ∈ 4, and 2 = {0, 1} ⊆ 4.

3f3No Number Is Its Own Member

Foundation (3a) already says that no set is its own member. The start-and-step shape gets it for the numbers of the run without foundation, and shows a step that needs help from outside its own claim.

0 \notin 0 @@ start: nothing is in 0
S(u) \in S(u) \Rightarrow S(u) \in u \lor S(u) = u @@ step: suppose it, until we drop it; next-membership
S(u) = u \Rightarrow u \in u @@ u ∈ S(u) by in-its-next, and S(u) is u
S(u) \in u \Rightarrow S(u) \subseteq u \Rightarrow u \in u @@ 3f2 for u, then u ∈ S(u)
u \in u \text{ clashes with } u \notin u @@ the claim for u
\htmlClass{new}{S(u) \notin S(u)} \quad \blacksquare @@ the supposition is refuted in both cases

The step did not close on its own claim. The second case needed 3f2, for the same u. 3f2 holds for each number of the run by its own start and step, so it is there to use.

3f4Starting Further Along

The start need not be 0. Fix a number m of the run and start at its next one. The shape then speaks of the numbers from the start on.

m \in S(m) @@ start: the in-its-next technique
m \in u \Rightarrow m \in S(u) @@ step: u is a part of S(u)
2 \in 3,\ 2 \in 4,\ 2 \in S(4) @@ m = 2, the step run from S(2) = 3
\htmlClass{new}{m \in u \text{ for each } u \text{ after } m} \quad \blacksquare @@ the start-and-step shape, started at S(m)

With 3f2, a member is a part as well: each number is a member and a part of every later one. 3c7 found this for the named sets and said rung 4 proves it for every entry at once. Here it holds one number at a time, as far as you go.

Practice, each by a start and a step:

  • Every member of a number is a number of the run.
  • Each number is a part of every later one.
  • A member of a member of a number is a member of it.

3f5Finding a Start and a Step

What to try first. Write the claim as a condition on one letter, P(u). Check P(0). Then suppose P(u), aim at P(S(u)), and unpack S(u) by next-membership: a member of S(u) is in u, or is u. That gives two cases, and each is usually short.

When the step will not close. The claim for u is too weak to carry itself. Prove a helper claim with its own start and step, as 3f3 used 3f2, or make the claim stronger. A stronger claim is harder to reach and easier to use.

A step alone proves nothing. Take the claim “there is something in u”. The step holds: u is in S(u), so S(u) always has something in it. The start fails: nothing is in 0. And the claim is false of 0. Check the start every time.

The shortcut, out of sequence. Inside the step you may use P(u), and nothing about S(u) but what you prove. Using P(S(u)) to reach P(S(u)) assumes what is to be shown.

3f6Where Description Gives Out

a = a leaves little room: one thing, the same as itself. Everything = everything leaves none at all: no world could fail it, so it says nothing about any world.

Every set built so far can be written out completely. ∅, {∅}, {0, 1}, {0, 1, 2}: each listing ends. The start-and-step shape reaches each number in a run of steps that ends, one number at a time.

A set holding the whole run could not be written out: its listing would not end. Describe it with the tools so far and the description starts to dissolve. Each line you write names one more entry of the run, and never the set that holds them all.

That is why infinity is laid down, not derived (3d). The rest of this step makes the claim exact: no derivation from rungs 0 to 2 is possible.

3f7What “cannot be proved” Means

Here is the idea in plain words. Suppose infinity could be argued from the axioms of rungs 0 to 2.

A world is a collection of things with a way of reading ∈ among them.

Take a world in which every one of those axioms is true. The argument would work inside that world too, because each of its techs carries true lines to true lines, whatever the letters name. So infinity would be true in that world.

Turn it round: to show a statement cannot be argued from some axioms, find a world where all of the axioms are true and the statement is not. 3a·f13 used this world-building move to show that foundation does not follow from the other axioms.

Saying, of every possible argument at once, that it fails is a claim about arguments as objects. The ladder earns it as a proof at 4a, in the cellar.

The world below is chosen so that both of these are so of it: every principle of rungs 0 to 2 is true, and no set in it is inductive. This step checks both, in words, carefully.

3f8Low Marks

Mathematicians use a small mark written low after a name to tell members of a family apart, and this step needs the habit.

From here on, a name may carry a small mark written low after it. The low mark is part of the name.

Examples: V, V₀, and V₁ are different names. VS(k) is the name whose low mark is S(k).

3f9The Layers

The layers, in words: the bottom layer has nothing in it; each layer above is all the subsets of the layer below. In marks, the rule for making the next layer from any layer you have:

Work the earliest ones out with 2g's keep-or-drop listing. The tools used are all-the-subsets, over and over, and nothing else.

V₀ is ∅, by the rule's start, and ∅ is named 0. V₁ is all the subsets of ∅. By 2g that is {∅}, which 3c named 1. V₂ is all the subsets of {0}. Keep or drop its only member, and you get ∅ and {0}. So V₂ = {0, 1}, which is 2.

V₃ is all the subsets of {0, 1}. Keep or drop each of the two members, and you get ∅, {0}, {1} and {0, 1}. So V₃ = {0, 1, {1}, 2}. Three of its members are the named sets 0, 1 and 2. The fourth, {1}, has no name: it is the first set in the layers that is not an entry of the run.

V₄ is all the subsets of V₃, found the same way. Among them is {0, 1, 2}, which is 3. 3 is in V₄ because its members 0, 1, 2 are all in V₃. It was not in V₃, because 2 was not in V₂.

3f10As Far Along as You Like

Each layer is a set you can write out completely by keep-or-drop. So is each of its members, and each member of those, down to ∅: the listing for V₄ is long but it ends. And you may go on: VS(4) = 𝒫(V₄) is a set the rule gives you, and 𝒫 of that, and on.

“All the layers at once”, as an object, is something else: it needs an axiom beyond the ladder's, which the ladder names only as history. This step does not need it. Everything below is said about the layers you have made, and is true for whichever layer you go on to make, by the same lines.

Saying it of every layer at once, in one line, needs induction and defining by repeating. Until 4d, this step says it one layer at a time and trusts that the same lines work for each new layer: the start-and-step shape of 3f1, run on layers.

From here on, the layered world is: the sets that are members of some layer.

The layered world is a way of talking, like “all sets” on 3a·f, not a set of its own. Nothing below treats it as one.

3f11Each Step of Membership Drops a Layer

Some facts about layers, each a short argument from 2g.

Each layer is inside the next. For instance, V₁ = {0} ⊆ V₂ = {0, 1}.

V₀ = ∅ ⊆ V₁, by the empty-part technique. And if Vk ⊆ VS(k), then 𝒫(Vk) ⊆ 𝒫(VS(k)) by the power-keeps-parts technique, which is VS(k) ⊆ VS(S(k)). That is a start and a step (3f1), the shape this step trusts for now. So, layer by layer as far as you make them, each is inside the next.

A member of a layer is a part of the layer below. That is what 𝒫 means: u ∈ VS(k) exactly when u ⊆ Vk. Example: 3 ∈ V₄, and 3 ⊆ V₃.

So the members of a member of VS(k) are all in Vk: each step of membership drops you a layer. Keep that drop in mind; it is the hinge of this step.

3f12Every Earlier Tool Stays Inside

One care comes first. When an axiom says “for every set”, read inside the world it says “for every set of the world”. When it says “there is a set”, it speaks of a set of the world. The checks below are made with that reading: each tool, fed sets of the world, hands back a set of the world.

Take any sets u and v of the world. Since each layer is inside the next, both are in a layer they share, Vk (whichever of their layers is further along). Now go tool by tool.

For example, 0 ∈ V₁ and 2 ∈ V₃, so both are in V₃. So {0, 2} ⊆ V₃, and {0, 2} ∈ V₄. Now the same in general.

  • Gather. u, v ∈ Vk, so {u, v} ⊆ Vk (listing, then pack ⊆), so {u, v} ∈ 𝒫(Vk) = VS(k). The gathering is in the world.
  • Sift. Say u ∈ VS(k), so u ⊆ Vk. Any sift of u is a subset of u (the sift-is-part technique), so a subset of Vk (the chain technique for part of), so a member of VS(k). Sifting stays inside, whatever the condition.
  • Merge. Say u ∈ VS(S(k)). Its members are in VS(k), so their members are in Vk; ⋃u is the set of those, so ⋃u ⊆ Vk, so ⋃u ∈ VS(k). Merging drops a layer and stays inside. Example: ⋃3 = 2, with 3 ∈ V₄ and 2 ∈ V₃.
  • All the subsets. Say u ∈ VS(k), so u ⊆ Vk. Then 𝒫(u) ⊆ 𝒫(Vk) = VS(k) by the power-keeps-parts technique, so 𝒫(u) ∈ VS(S(k)). Taking the subsets climbs a layer and stays inside.
  • A set exists. ∅ ∈ V₁. (Also 3c's S: S(u) = u ∪ {u} is a merge of a gathering, so it stays inside by the lines above.)
  • Same members. Sets u and v of the world with the same members are the same set: that is so of any sets whatever, so of these.

3f13Foundation, Inside the World

Foundation is true inside because every member of a world set is itself a world set: nothing of a world set is hiding outside the world. Here is the check.

Read inside the world, the foundation axiom says this. If a condition φ passes up to each set of the world whenever it is so of every member of that set, then φ is so of every set of the world. Suppose φ passes up inside the world.

Call the condition “if x is in the world, then φ(x)” φ-inside. φ-inside passes up for every set whatever. Let u be any set whose members all meet φ-inside, and suppose u is in the world (to prove an if). Every member of u is in the world, because a member of a set in a layer is in the layer below. Example: 3 ∈ V₄, so 2 ∈ V₃. So the ifs give φ of every member of u, and since φ passes up inside the world, φ(u). No case split on whether u is in the world is needed.

By the foundation axiom, used outside, φ-inside is so of every set. So φ is so of every set of the world.

And the techs of rungs 0 and 1 do not look at what the letters name. They were checked to carry what is true to what is true, whatever the row, and a world is only a way of fixing rows. 1e checked the joining words; the check for every and some is in the cellar. So every axiom of rungs 0 to 2, read inside the layered world, is true there.

3f14No Inductive Set in V₄

Now the other half of the check. Suppose some set I of the world were inductive. It is in some layer; take the case I ∈ V₄ to begin with, argued in full, and then see that the layer makes no difference.

Suppose, until we drop it, that I is in V₄ and I is inductive. By the named-sets-are-inductive technique, 0, 1, 2, 3 and 4 are all in I. Since I is in V₄, I is a part of V₃: that is what “all the subsets” means. So 4, a member of I, is in V₃.

Now 3 is in 4, and 4 is in V₃, so 4 is a part of V₂. So 3 is in V₂: a step of membership, a layer down. The same move with 2 in 3 puts 2 in V₁. Once more, with 1 in 2, it puts 1 in V₀. But V₀ is ∅, and nothing is in ∅. That clashes. So the supposition is refuted: no inductive set sits in V₄.

3f15The Layer Makes No Difference

The run of nexts steps down a layer at each step, and the layers run out.

The layer made no difference. Had I been in VS(4), the named-sets-are-inductive technique would have put S(4) in I. The argument would gain a step: S(4) ∈ V₄, then 4 ∈ V₃, and so down to ∅ exactly as before. For a layer further along, the argument gains a step for each layer further along. The named-sets-are-inductive technique reaches as far along the run as you like, and the run is nested as far as you like: 3c's in-its-next technique gives x ∈ S(x) at every step. Whichever layer you put I in, the run steps down through every layer beneath it and arrives at the empty one. So no set of the world is inductive, and in the layered world the axiom of infinity is false.

3f16The World Is Not a Set of the World

One point feels like a cheat until you see it is not. The layered world, taken as a whole, holds 0 and holds the next one after everything it holds: in that sense the whole world “is inductive”. But the world is not a set of the world. It is not a member of any layer; it is a way of talking, as “all sets” was on 3a·f. The axiom says there is a set that is inductive, and inside the world “set” means “member of some layer”. None of those is inductive. The world has the whole run in it, each entry in its turn, and no object that gathers the run up. That is the situation 3d described before the axiom: everything the run produces, and no set to hold it.

3f17No Proof Can Exist

Put the two halves together. In the layered world, every axiom of rungs 0 to 2 is true: that was the tool-by-tool check. And in the layered world, no set is inductive: that was the argument just given, for any layer.

Suppose, until we drop it, that someone has a proof of “some set is inductive” from those axioms. Read inside the world, it is still a proof. Its axioms are true there, and its techs care nothing for which world they are in. So its last claim is true there: some set of the world is inductive. That clashes with what was just shown. So the supposition is refuted, and no such proof exists. One world was enough; 3f19 says why no number of worlds does the other job.

3f18Independent, Not False

So the axiom of infinity is independent of what came before: not a technique of rungs 0 to 2.

“Independent” is narrow here. It means only that the axioms of rungs 0 to 2 cannot prove it. It does not mean apart from what came before: the argument used 3c’s next one, the start-and-step shape of 3f1, and the writing the earlier rungs built, and the axiom itself is stated in 3c’s marks. Whether rungs 0 to 2 could refute it is the further question of 3f.4.4.

Be clear what this result is not. It does not say the axiom is false. In the ordinary world of mathematics the axiom is taken, and every principle of rungs 0 to 2 is taken with it. Whether that world could ever lead to something totally false is a further question, and the step’s last standing question takes it up. The layered world shows only that the principles do not prove the axiom.

And the layered world is not a mistake to be avoided. It is a perfectly good world of sets, in which a great deal of mathematics can be done, with every entry of the run available and only the run itself missing as an object.

That is why the ladder says the axiom is chosen. You may work without it, and some mathematicians do, keeping every number and giving up the set of all of them. You may take it, and then the run is a set like any other, which you can sift, pair, take the subsets of, and quantify over. The ladder takes it. What follows from it is the subject of rung 4: the counting numbers as a set, induction as a technique about that set, and arithmetic built by repeating the next-one step.

3f19One World Kills a Proof; No Number Makes One

One world was enough to refute a proof. Now the other side. Nobody shows that a line is always so by checking worlds. After a thousand worlds in which it held, the next may fail it, and the worlds do not run out. 1e’s table could be finished, because two letters have four rows; the worlds a line with every and some may be read in cannot be listed at all.

That is what a proof is for. A proof speaks of every world at once without visiting one: its techs carry so to so whatever the letters name, which is what 3f17 leaned on. “Everything is the same as itself” fails in no world, and the reason is 2b5’s three-line argument, not a tour of the worlds. An argument in the margin that begins “take any world” and uses nothing about it is a proof in the margin’s language, and it is the only other road.

So the two tools divide the work. To show that a line follows from some axioms, prove it. To show that it does not, build one world where the axioms are so and the line is not, as 3f17 did. The same split holds for “always so” against “can fail”, and for “these say the same” against “these come apart” (2b20): yes needs every world, and only a proof reaches them all; no needs one. 4a writes the split out as a table once a proof is an object.

3f21Running It Backwards

Wanting “this statement is not a consequence of those axioms”, you build a world. Say what its sets are and how ∈ is read. Check each axiom inside it, tool by tool, each check a short argument that the tool hands back a set of the world. Find the statement failing there. Then refute a supposed proof, as the argument above does.

Wanting the layer a given set enters at, step down its memberships until you reach ∅, by the longest descent you can find. Then climb back up from ∅ ∈ V₁, a layer for each step, and the set enters at the layer you reach. The picture's left panel does this for you.

Wanting a set that a given layer cannot hold, take an entry of the run with a membership chain longer than the layer allows. For instance, V₄ cannot hold 4: 4 enters at the layer after V₄. Found upward; written downward.

Read inside the layered world, “every” means every set of the world, and “some” means some set of the world. Each tech of 2b still carries what is true to what is true.

  • To write ∀x P(x), a proof shows P(x) for an x about which nothing was assumed. Nothing was assumed, so the proof works for any set of the world, and ∀x P(x) is true there.
  • From ∀x P(x), any set t of the world gives P(t). It is one of the sets the every spoke of.
  • From P(t), with t a set of the world, ∃x P(x) is true there. The set t is the example.
  • From ∃x P(x), and a proof that any x with P(x) gives Q, where Q does not mention x, Q is true. The world holds an example, and the proof, run on it, gives Q.

So the techs of rung 1 work in any world, the layered one included. That is the check the class above says was made.

Who said it first

The founder is Richard Dedekind; the author of the first list of axioms is Ernst Zermelo.

Dedekind, having tried to prove that an endless collection exists, said in the same book that the numbers are free creations of the human mind, made in order to grasp the differences among things. Zermelo, some years later, wrote the existence of an endless set into his list of axioms without an attempted proof, and his list is the ancestor of the one this ladder uses.

Dedekind, Was sind und was sollen die Zahlen? (1888), preface and §66, trans. Beman, 1901; Zermelo, “Untersuchungen über die Grundlagen der Mengenlehre I”, 1908
