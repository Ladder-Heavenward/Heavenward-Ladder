30e · proof

Either Order

Rung twenty-eight added up a function over a region of the plane in two ways: across and then up, or up and then across. For continuous functions on rectangles, the two orders agreed. This step does the same for the new total. Sizes on the plane are built from rectangles, the way sizes on the line were built from intervals. Then a set in the plane is cut into slices, one for each place along the bottom edge, and its size is the total of the slices’ lengths. From that, a function that is never negative can be totalled in either order, always with the same answer. A function that takes both signs can be too, as long as the total of its size is finite. Without that, the two orders can disagree, and this step shows one that does.

A sized set in the plane has the total of its slices’ lengths for its size. So a function that is never negative, or whose size has a finite total, can be totalled in either order with the same answer.

30e1Sizes on the Plane

A rectangle A × B is the set of points (x, y) with x in A and y in B, for intervals A and B. Its size is m(A) · m(B).

From here on, the outer size of a set in the plane is the greatest lower bound of the totals of its covers by countably many open rectangles. A set in the plane is sized when it passes the split test with this outer size. The proofs of 30a and 30b go through word for word, with one change: where 30a1 chained intervals along a line, the plane cuts the rectangles of a finite cover along a common grid, and counts the cells. The plane’s sized sets form a sized family, size adds over countably many separate sized pieces, and every rectangle is sized with size m(A)m(B).

From here on these are the product sizes m₂ on the plane. Their accepted name is the product measure.

The slice of a set E in the plane at x is Eₓ, the set of y with (x, y) in E.

A countable union of rectangles is also a countable union of separate rectangles: take each new rectangle’s part outside the ones before it, which is finitely many rectangles.

30e2Size Is the Total of the Slices

Slices technique: if E is a sized set in the plane, then except on a size-0 set of x, the slice Eₓ is sized, x ↦ m(Eₓ) is sized, and m₂(E) = ∫ m(Eₓ) dx.

E = A \times B:\ \ m(E_x) = m(B) \text{ on } A,\ 0 \text{ off } A;\ \ \textstyle\int m(E_x)\,dx = m(A)m(B) @@ a rectangle
E = \text{separate rectangles } R_1, R_2, \ldots:\ \ m(E_x) = \sum_k m\big((R_k)_x\big) @@ countable-adding (30b3); rising-limit (30d1) on the partial sums

30e3Either Order

Either-order-sized technique: if f ≥ 0 is sized on the plane, then ∫∫ f dm₂ = ∫ ( ∫ f(x, y) dy ) dx = ∫ ( ∫ f(x, y) dx ) dy.

f = 1_E:\ \ \textstyle\int\!\!\int 1_E\,dm_2 = m_2(E) = \int m(E_x)\,dx = \int\big(\int 1_E(x, y)\,dy\big)dx @@ slices (30e2)
\text{the same with slices across, at each } y @@ the plane does not prefer x to y
f \text{ a step function}:\ \text{both orders add} @@ totals add (30d1)
f \ge 0 \text{ sized}:\ s_n \uparrow f \text{ steps} @@ total-from-below (30c3)
\textstyle\int s_n(x, y)\,dy \uparrow \int f(x, y)\,dy \text{ at each } x,\ \text{then } \int(\cdots)dx \uparrow \int(\int f\,dy)dx @@ rising-limit (30d1), twice
\htmlClass{new}{\textstyle\int\!\!\int f\,dm_2 = \int\big(\int f\,dy\big)dx = \int\big(\int f\,dx\big)dy} \quad \blacksquare @@ rising-limit, a third time, on the plane

When f takes both signs, split it as f⁺ − f⁻ (30c3). If ∫∫|f| dm₂ is finite, each part has a finite total, both orders agree for each, and the two take away. So f can be totalled in either order whenever the total of |f| is finite, and that can be checked in either order, because |f| ≥ 0.

This is 28h’s either-order, for every sized function that allows it.

30e4When the Orders Disagree

f = 1 \text{ on } [n, n+1]^2,\ \ f = -1 \text{ on } [n+1, n+2] \times [n, n+1],\ \ n = 0, 1, 2, \ldots @@ a staircase of squares, plus then minus
\text{fix } y \in [n, n+1]:\ \textstyle\int f(x, y)\,dx = 1 - 1 = 0 @@ one + square and one − square in that row
\textstyle\int\big(\int f\,dx\big)dy = 0 @@ every row totals 0
\text{fix } x \in [0, 1]:\ \textstyle\int f\,dy = 1;\ \ x \in [n+1, n+2]:\ \textstyle\int f\,dy = 1 - 1 = 0 @@ the first column has only the + square
\textstyle\int\big(\int f\,dy\big)dx = 1 @@ only the first column counts
\htmlClass{new}{0 \ne 1:\ \ \textstyle\int\!\!\int |f|\,dm_2 = \infty} \quad \blacksquare @@ endlessly many unit squares, so the technique does not apply

The accepted names

The product sizes are the product measure, m ⊗ m, or Lebesgue measure on ℝ². The slices technique is Cavalieri’s principle in its measure form. The either-order-sized technique is the Fubini–Tonelli theorem: Tonelli for f ≥ 0, Fubini when ∫|f| is finite.

Who said it first

Bonaventura Cavalieri compared solids by their slices in 1635. Guido Fubini proved the either-order theorem for Lebesgue integrals in 1907, and Leonida Tonelli gave the form for positive functions in 1909. The staircase of squares is a standard example since the early twentieth century.

A proof that is not allowed

“Each row of the staircase totals 0, so the whole staircase totals 0, so each column must total 0 too.” Not allowed: the whole staircase has no total, since ∫∫|f| is endless, so neither order is the total of anything.
