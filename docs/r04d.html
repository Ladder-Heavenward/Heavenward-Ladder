4d · proof

Defining by Repeating

Induction proves a statement about every number from a base and a step. This step does the same for definitions: it shows that a starting value and a technique for the next value fix exactly one thing at every number. First it has to say what that thing is. A function, on this ladder, is a set of pairs in which each input is paired with exactly one output; the step gives functions their marks and two small techniques. It is the first function the ladder builds, and the word keeps this meaning to the top. Then the recursion principle. For any set, any starting member and any step from the set to itself, there is exactly one function on the numbers that starts there and takes the step each time. The proof builds the function as the smallest closed set of pairs, the way 4b built the numbers as the smallest inductive set. Then it checks by induction that it really is a function. Last, what the principle can and cannot do, worked on a doubling, a cat and a dog, and the layers of 3f.

Say where to start and how to take each step. The pairs you are forced to have, starting from the start and taking the step, form a function on the numbers, and no other function starts there and takes that step.

4d1Defining by Repeating, in Words

Here is the kind of definition this step is for: “Adding 0 to a number changes nothing; adding the next one after b is taking the next one after what adding b gave.” It says what happens at 0. And it says how to get the answer at the next one from the answer at this one. It feels like enough. From 0 you get to 1, from 1 to 2, and on, so every number gets an answer.

But “and on” is the dots again, and the ladder does not accept dots as a reason. A definition is a statement that gives a name to a thing, and a name is honest only when exactly one thing fits. 2e named ∅ only after the one-empty-set technique showed there was exactly one empty set, and 4b named ℕ only after whichever-inductive-set.

So two questions need answers before anything can be defined by repeating. What kind of thing is being defined? And is there exactly one such thing that starts where you say and steps as you say? The first is answered with pairs. The second is a technique, proved with induction.

4d2A Function Is Its Pairs

Think of a technique that hands each thing in one set a thing in another: each person in a household and their mother; each number and its next one. Whatever the technique is, it leaves a trace: the pairs (input, output), a pair for each input. The ladder takes the trace as the thing itself, as 2h took a relation to be nothing but its pairs. A pair of words, to begin with: in a pair (x, y) belonging to such a set, x is the input and y the output.

From here on, the statement “f is a function from A to B” means: , and every member of A is paired by f with exactly one thing:

The = dividendDoing a verb is a function: double it, square it, paint it red. The last clause says that if x goes in twice, the same thing comes out both times, y = z. That is 0b's mark, carried through the verb: the same in, the same out.

Both parts have names that will be used as reasons: every input has an output, and no input has two. Together they make “exactly one”.

Some examples, with A = {cat, dog} and B = {owl, bat}. The set {(cat, owl), (dog, owl)} is a function from A to B: each input has exactly one output, and two inputs sharing an output is allowed. The set {(cat, owl)} is not: dog has no output. The set {(cat, owl), (cat, bat), (dog, bat)} is not: cat has both owl and bat. Each failure is a witness against a part, by 2b's counterexample technique.

The accepted name for A, the set the inputs come from, is the domain of f.

4d4Three Jobs for Brackets

Notice the jobs brackets now do on the ladder. In P(x), from 0a, they mark a statement with x in its gap. In S(x), from 3c, they hold the set a mark acts on. In f(x) they hold an input of a function, and f(x) names a thing.

S acts on any set, and only on sets: 3c built x ∪ {x} for a set x, so a cat, which is not a set, has no next one.

S is not a function in this sense. There is no set of all the pairs (x, S(x)), since its inputs would make a set of all sets, which 3a·f's no-set-of-all-sets forbids. What there is, is a function that agrees with S on the numbers, built in 4d6.

4d5Techniques Make Functions

Most functions on this rung come from a technique written with marks, like “the next one after n”. A mark for the technique itself:

From here on, means: whichever technique takes each x to t(x), where t(x) is a name written with x in it. Read it “x goes to t(x)”.

Such a technique is a statement about how to write, not a set. The mark x ↦ t(x) is an operator, a statement that produces t(x) when it is carried out on x. What turns it into a set is 2i's shorthand: the pairs {(x, t(x)) : x ∈ A}, short for a sift of A × B.

Makes-a-function technique: a technique that gives a member of B for every member of A makes a function from A to B. In marks: if t(x) names a member of B for every x ∈ A, then {(x, t(x)) : x ∈ A} is a function from A to B whose value at x is t(x).

The plan: the set of pairs is a sift of A × B, and then each part of “function” is checked.

Suppose t(x) names a member of B for every x in A. Written out, F is a sift of A × B: the pairs p with p = (x, t(x)) for some x in A. A sift is a part of what it sifts, so F is a part of A × B.

Every input has an output. Take x in A. Then t(x) is in B, so (x, t(x)) is in A × B. With x as the example, pack the sift: (x, t(x)) is in F.

No input has two. Suppose (x, y) and (x, z) are both in F. Unpack the sift for the first: (x, y) = (x′, t(x′)) for some x′ in A. By equal-pairs, x = x′ and y = t(x′). Swap: y = t(x). The same moves for z give z = t(x). Turn that about and chain: y = z.

Join the parts and pack “function”: F takes A to B, and its value at x is t(x).

4d7Same Outputs, Same Function

Another small technique.

Same-outputs technique: two functions from A to B that give the same output at every input are the same function.

It is the same-members axiom for functions, and it is how the uniqueness part of every definition by repeating is closed.

Suppose f and h both take A to B, and f(x) = h(x) for every x in A. Chase a member: suppose p is in f. f is a part of A × B, so p is a pair (x, y) with x in A.

The line for f(x) says y = f(x). The given every says f(x) = h(x). Chain them: y = h(x). By the line for h(x), (x, y) is in h, so p is in h. And p was anything, so f is a part of h.

The same moves, turned about, make h a part of f. By the double-inclusion technique, f = h.

4d8The Recursion Technique

In words, the recursion technique: take any set A, any member u of A, and any function g from A to itself. There is exactly one function f from the numbers to A with f(0) = u and, for every number n, f(S(n)) = g(f(n)).

The start says where f begins; the step g says how to get each value from the one before. From here on, “step” also names the function g of a definition by repeating. 4c's step of an induction, a statement, keeps its name there, and what the step belongs to says which.

Its accepted name is the recursion theorem, and defining by repeating is called definition by recursion.

Example: A = {cat, dog}, the start is cat, and g swaps cat and dog. Then f(0) = cat, f(1) = dog and f(2) = cat.

4d9Why Existence Is the Hard Part

“Exactly one” is a pair of claims, as always: there is such an f, and any such f and f′ are the same set. Uniqueness is an induction and same-outputs. Existence is the harder part, because it asks for a set, and the defining lines only say what the set must do. The defining lines are not a set any more than the step part of “inductive” was.

And there is a real chance of failure. Try the same lines on an inductive set I that carries cargo, in place of ℕ. They fix f(0), f(1), f(2) and so on along the run, and they say nothing at all about f({1}): {1} is no number's next, so no line reaches it. On I, the lines leave inputs without outputs. On ℕ, 4b's sift guarantees there is nothing for the lines to miss, and the proof below is where that guarantee is cashed.

One founder of the subject was the earliest to see that a definition by repeating needs a proof, and to give one. His technique says that a start and a step determine exactly one mapping of the number series. He proved it by building the mapping out of partial pieces, and checking by induction that they fit together.

4d10Closed Sets of Pairs

Fix A, u and g. The f you want is a set of pairs from ℕ × A. It must hold (0, u). And whenever it holds a pair (n, y), meaning f(n) = y, it must hold the pair (S(n), g(y)), meaning f(S(n)) = g(f(n)). Give the property a name:

From here on, a set of pairs is closed (for u and g) when and h is closed under :

“h is closed” is a statement about h.

“Closed” is to sets of pairs what “inductive” was to sets: a base part and a step part. (Inside h every y is a member of A, so g(y) makes sense.) Gather the closed ones into a set, by sifting all the subsets of ℕ × A, 2g's tool:

C has a member: ℕ × A itself. It holds (0, u), by zero-is-a-number and u ∈ A. And if (n, y) ∈ ℕ × A, then n is a number and y ∈ A. So S(n) is a number (next-of-a-number), and g(y) ∈ A (g takes A to A), and (S(n), g(y)) ∈ ℕ × A. Every pair is allowed, so nothing is missing. ℕ × A is far too big to be a function, of course, the way an inductive set with cargo was too big to be the numbers. So do what 4b did: keep the pairs that are in every closed set. That is, intersect them all.

4d11The Smallest Closed Set

The opening technique about f is the counterpart of 4b's smallest-inductive-set.

Smallest-closed-set technique: f is closed, and f is a part of every closed set of pairs. In marks: f is closed, and f ⊆ h for every closed h.

f is a part of every closed set. Let h be closed, so h is in C, and let p be in f. Unpack the sift: p is in every member of C. Use that with h: p is in h. So f is a part of h, just as lies-below put ℕ inside every inductive set.

f holds the starting pair. (0, u) is in ℕ × A, since 0 is a number and u is in A. And every closed h holds (0, u): that is its base part. So (0, u) is in every member of C. Pack the sift: (0, u) is in f.

f takes the step. Suppose (n, y) is in f. Then (S(n), g(y)) is in ℕ × A, as it was for ℕ × A above. Now take any closed h. (n, y) is in h, since f is a part of h. And h’s step part puts (S(n), g(y)) in h. So (S(n), g(y)) is in every member of C. Pack the sift: it is in f.

Last, f is a sift of ℕ × A, so a part of it. So f is a closed set of pairs from ℕ × A: f is in C, the smallest of them.

4d12Where Each Pair Comes From

The next technique is the counterpart of 4c's zero-or-a-next.

Where-each-pair-comes-from technique: every pair of f is the starting pair, or was made by the step from a pair of f.

Its proof is the trick that proved induction, done on pairs: sift f by the property, show the sift is closed, and smallest-closed-set puts f inside the sift.

Sift f by the property, and call the sift f′: the pairs of f that are the starting pair (0, u), or are (S(m), g(w)) for some pair (m, w) of f. A sift of f is a part of f, so f′ is a part of ℕ × A.

f′ holds the starting pair. (0, u) is in f, by smallest-closed-set, and it is the starting pair, so it passes by the first option.

f′ takes the step. Suppose (n, y) is in f′. Then (n, y) is in f, and smallest-closed-set puts (S(n), g(y)) in f. It was made by the step from a pair of f, namely (n, y), so it passes by the second option. It is in f′.

So f′ is closed, and f′ is in C. Smallest-closed-set says f is a part of every member of C, so f is a part of f′. Every pair of f passes.

No input has two outputs: ψ(n) is ∀y ∀z ((n, y) ∈ f ∧ (n, z) ∈ f ⇒ y = z). This is where different-nexts earns its place.

Base: suppose (0, y) ∈ f. Where-each-pair-comes-from says (0, y) is (0, u), so y = u by equal-pairs. Or it is (S(m), g(w)), so 0 = S(m), which clashes with next-never-empty, and everything permitted gives y = u as well. The same for z, so y = z.

Let n be a number, and suppose ψ(n): f pairs input n with at most one output. That is the induction hypothesis. Now suppose (S(n), y) and (S(n), z) are both in f.

Ask where (S(n), y) came from. By where-each-pair-comes-from, it is the starting pair (0, u), or it is (S(m), g(w)) for some pair (m, w) of f. If it is the starting pair, equal-pairs gives S(n) = 0, which clashes with next-never-empty, and the clash permits everything. Otherwise, call them m and w. Equal-pairs gives S(n) = S(m) and y = g(w). By different-nexts, n = m. So (n, w) is in f, and y = g(w).

The same moves for z give a pair (n, w′) of f with z = g(w′). Both w and w′ are outputs of f at input n, so the hypothesis says w = w′. Then y = g(w) = g(w′) = z.

So ψ(S(n)). With the base, the induction technique gives ψ(n) for every number n.

4d14One-to-One Is What It Needs

Look at the line that says n = m. Pairs with input S(n) each came from a pair with some input m. Different-nexts says that m can only be n, so both came from pairs with input n, and the hypothesis says those agree. If different numbers had the same next one, different values could arrive at the same input from different directions, and f would not be a function. One-to-one is exactly what definition by repeating needs.

So f : ℕ → A. The defining lines follow from smallest-closed-set and the line for f(x). (0, u) ∈ f, so f(0) = u. For a number n, (n, f(n)) ∈ f, so (S(n), g(f(n))) ∈ f by the step part, so f(S(n)) = g(f(n)).

4d15Exactly One

Suppose f and f′ both take ℕ to A, both start at u and both take the step g. Then f(n) = f′(n) for every number n, by induction. The base is f(0) = u = f′(0). The step is f(S(n)) = g(f(n)) = g(f′(n)) = f′(S(n)), where the middle move is the swap axiom with the hypothesis f(n) = f′(n). Then same-outputs says f = f′. That finishes recursion.

A habit of writing goes with it. A chain q = b = c says q = b and b = c, so q = c by the chain technique, as 0b's chains did. And a chain may run on over several lines, each beginning with =: each says that the left side of the first line is the same as what follows.

From here on, to define a function on the numbers it is enough to give its start and its step, citing recursion. The function that recursion gives may then be named, since exactly one fits.

That closes a flag the ladder has carried since 0a. 0a's language loop, a thing said in terms of itself, was stepped around on 0a and 0b and every step since, until this one. A definition by repeating is said in terms of itself, and here it is safe: each value is built from the one before, and the first from a start that is given. A loop with no start, like Zoe of Zoe, still fixes nothing, because no start is given for it.

Run-match technique: if two sets each have a start and a step for which definition by repeating works, there is exactly one function from the first to the second that sends start to start and keeps the step, and it runs backwards. Call the sets N and M, with starts z and y and steps s and t. Repeating on N from y with t gives f from N to M with f(z) = y and f(s(n)) = t(f(n)). Repeating on M gives f′ back. Then n ↦ f′(f(n)) sends z to z and keeps s, and so does n ↦ n; exactly one function does that, so they are the same. Likewise m ↦ f(f′(m)) is m ↦ m. ∎ As 4b4 found it does not matter which inductive set, it does not matter which set with a start and a step is used: any two are paired in exactly one way.

4d18The Layers, and What They Need

The last is the one rung 3 asked for. 3f built its layers by a start and a step: V₀ = ∅, and VS(k) = 𝒫(Vk), the next layer all the subsets of the layer below. It worked them out each in its turn, and wanted “the layer for every entry” as an object. As a recursion: start ∅, step x ↦ 𝒫(x). Recursion asks for a set A, a start u ∈ A, and a step g : A → A. The start is ∅. The step is the technique x ↦ 𝒫(x). Makes-a-function makes it a function from A to A, provided A holds 𝒫(x) whenever it holds x. So everything turns on A: a set that holds ∅ and holds all the subsets of each of its members.

Given such an A, recursion hands you exactly one V : ℕ → A with V(0) = ∅ and V(S(k)) = 𝒫(V(k)). Its values are 3f's layers: V(0) = ∅ = V₀, V(1) = 𝒫(∅) = V₁, and so on, line by line, as far as you write. The layers become a set of pairs, and “the layer for k” is V(k), for every number k at once.

And here is the catch, stated plainly. No line of the ladder supplies such an A. ℕ will not do, nor 𝒫(ℕ). 3f's layer V₃ = {0, 1, {1}, 2} has the member {1}, which is not a number, so V₃ is not a part of ℕ, and later layers stray further.

This is not a case of nobody having found the right A yet. If such an A existed, then V would exist. Merging all its values would give a set holding every set of 3f's layered world. Axioms of the ladder's kind cannot prove that such a set exists. That is known, but its proof is not on this rung, and nothing here leans on it.

Recursion is the tool 3f asked for; it needs a set to work in, and for the layers the ladder cannot supply one.

Early in the century before this one, two logicians each saw that, from the first list of axioms for sets, collections of this kind could not be shown to be sets. Each proposed an extra axiom, now called replacement. Roughly, it says: when a technique is applied to every member of a set, the results form a set. Much later it was shown again, by a new method, that the sets of 3f's layered world cannot be proved to form a set from the first list alone.

What induction does give, without any A, is a statement about every layer. For every number k, there is a set of pairs that starts with (0, ∅) and takes the step x ↦ 𝒫(x) up to k. The proof is an induction on k, adding a pair at each step with gather and merge. So 3f's “as far as you like” becomes “for every k”, a technique. That closes the flag 3f opened when it argued one layer at a time. “All the layers as an object” is a different thing, and it needs an axiom the ladder has not laid down. This rung does not lay it down; the arithmetic of 4f and 4g lives inside ℕ, where recursion has all it needs.

4d20Running It Backwards

Given a function on the numbers, can you find a start and step that make it? The start is f(0). A step g must have g(f(n)) = f(S(n)) for every n. So wherever a value repeats, the values after its repeats must agree.

Example: the values cat, dog, cat, dog have the step that swaps them. The values cat, cat, dog have none. g(cat) would have to be cat (from inputs 0 and 1) and dog (from inputs 1 and 2), and no input has two outputs.

So not every function on the numbers is made by a start and a step. Recursion makes exactly the ones whose next value depends only on the value before.

Wanting to show that a definition and another give the same function, you show the same start and the same step, and cite the recursion technique's uniqueness. Or you show the values agree by induction and cite same-outputs. Found upward; written downward.

Who said it first

The founder who first proved that a definition by repeating works, and whose matching of ℕ with a part of itself s makes an object, is Richard Dedekind. The two logicians who proposed replacement are Abraham Fraenkel and Thoralf Skolem; the first list of axioms is Ernst Zermelo’s; the new proof about the layered world is Adrian Mathias’s.

Dedekind was the earliest to see that a definition by repeating needs a proof, and to give one. His technique of definition by induction says that a start and a step determine exactly one mapping of the number series; he proved it by building the mapping out of partial pieces and checking by complete induction that they fit together.

Dedekind, Was sind und was sollen die Zahlen? (1888), §126, trans. Beman, 1901

Abraham Fraenkel and Thoralf Skolem each saw, early in the century before this one, that from Zermelo's axioms collections of this kind could not be shown to be sets, and each proposed an extra axiom, now called replacement. Roughly, it says: when a technique is applied to every member of a set, the results form a set. That the sets of 3f's layered world cannot be proved to form a set from Zermelo's axioms alone was shown again, by a new method, by Adrian Mathias.

Fraenkel, “Zu den Grundlagen der Cantor-Zermeloschen Mengenlehre” (1922); Skolem, “Einige Bemerkungen zur axiomatischen Begründung der Mengenlehre” (1922); Mathias, “Slim models of Zermelo set theory”, Journal of Symbolic Logic (2001)

The set A in f : A → B is the domain of f. The recursion technique is the recursion theorem; the extra axiom is the axiom schema of replacement, and with it Zermelo’s list becomes Zermelo–Fraenkel set theory.
