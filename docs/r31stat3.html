Why Would You Hold a Fit Back on Purpose?

Why would you hold a fit back on purpose? 31·stat found that a fit with many columns flatters itself on the data in hand. Worse happens when two columns say almost the same thing: the best fit gives them huge weights of opposite signs, and a tiny change in one number flips them. This page finds that wobble in a fit by rung 31’s closest point, tames it by charging for large weights, sees with rung 31’s axes exactly what the charge does, and picks the charge with data held back.

Least squares finds b making |y − Xb|² smallest. Add a charge λ|b|²: the best b solves (XᵀX + λI)b = Xᵀy. Along each axis of XᵀX, with stretch d², the plain fit is multiplied by d²/(d² + λ): weak axes, where columns nearly repeat, are shrunk almost to 0, and strong ones barely touched. Choose λ by the misses on data held back.

31stat32Charge for Large Weights

From here on, on this page, the charged fit makes |y − Xb|² + λ|b|² smallest, for a chosen λ > 0: misses cost, and so does size.

\text{slope 0 in every } b_j:\ X^{\mathsf T}(Xb - y) + \lambda b = 0 @@ partial slopes (28a)
(X^{\mathsf T} X + \lambda I)\, b = X^{\mathsf T} y @@ always undoable for λ > 0
\lambda = 1:\ b = (0.96,\ 0.99) @@ both gauges count, about equally
\htmlClass{new}{y_3 \to 6.3:\ b = (0.96,\ 1.00)} @@ the change barely shows

Charge technique: adding λ|b|² to the misses gives the fit (XᵀX + λI)b = Xᵀy, which always has one answer and moves little when the data move a little. The price is that it no longer makes the misses on the data in hand as small as possible.

31stat33What the Charge Does, Axis by Axis

XᵀX is symmetric, so it has square axes (31d): unit arrows u₁, u₂ at right angles that it only stretches, by d₁² and d₂².

X^{\mathsf T} X:\ d_1^2 \approx 60.6,\ \ d_2^2 \approx 0.0035 @@ the gauges together, and their difference
\text{plain fit along } u_i:\ c_i / d_i^2 @@ dividing by a tiny d² blows noise up
\text{charged fit along } u_i:\ c_i / (d_i^2 + \lambda) @@ the same with λ added
\htmlClass{new}{\text{ratio } \dfrac{d_i^2}{d_i^2 + \lambda}:\ 0.98 \text{ and } 0.003} @@ the weak axis is all but removed

Axis technique: the charge multiplies the plain fit along each square axis of XᵀX by d²/(d² + λ), keeping strong directions and silencing weak ones. The weak axis is the difference between the gauges, which the data barely measured; the charge stops the fit from guessing about it.

31stat34Choosing the Charge

λ = 0 is the plain fit; λ very large gives b near 0. Somewhere between, the fit predicts new data best. 31·stat’s held-back data find it.

\text{split the data into 5 parts} @@ at random
\text{for each } \lambda:\ \text{fit on 4 parts, measure misses on the fifth} @@ held-back data (31stat3)
\text{each part held back once; add the misses} @@ every value tested once
\htmlClass{new}{\text{choose the } \lambda \text{ with least held-back miss}} @@ refit on all the data with it

The charge trades a little bias for a lot less wobble, and held-back data say how much to trade. The fit on the data in hand always prefers λ = 0; only fresh data can show the gain.

31stat35A Different Charge Picks Columns

Charge the sum of the weights’ sizes, |b₁| + |b₂| + ⋯, instead of their squares. The corners of the region |b₁| + |b₂| ≤ t lie on the axes.

\text{squares: the region is round} @@ the best point is rarely on an axis
\text{sizes: the region is a diamond} @@ the best point is often at a corner
\text{at a corner, some weights are exactly } 0 @@ those columns drop out
\htmlClass{new}{\text{charging sizes chooses columns as it fits}} @@ with a hundred columns, keeps a few

Charging the squares shrinks every weight; charging the sizes sets some exactly to zero, choosing which columns matter. Both are ways of telling a fit that a simple answer is more likely than a wild one.

The cellar · there if you want it

Accepted names

Columns that nearly repeat are collinear. The charged fit with squares is ridge regression or Tikhonov regularisation; λ is the regularisation parameter; the trade is the bias-variance trade-off. Choosing λ with five held-back parts is 5-fold cross-validation. Charging the sizes is the lasso, and fitting by charging is regularisation in general.

Who said it first

Andrey Tikhonov used the charge for unsteady problems in 1943 and 1963; Arthur Hoerl and Robert Kennard named ridge regression in 1970. Robert Tibshirani introduced the lasso in 1996.
