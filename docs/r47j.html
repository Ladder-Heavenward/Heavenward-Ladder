47j · technique

Proofs Are Programs

Rung thirty nine wrote programs with nothing but making functions and applying them, and found that this bare calculus computes everything a machine can. Give each program a type, saying what it takes and what it gives, and forbid the programs whose types do not fit. What is left is a small language in which every program stops. Now set it beside the proofs of rung thirty seven, written as trees. A program from one type to another is built by supposing a member of the first and producing a member of the second. A proof of an if is built by supposing its first part and reaching its second. Applying a program to an input is using an if on a line. A pair is a join, and taking the first part of a pair is keeping one side of an and. The rules match one for one, and the detour that rung thirty seven cut out of proofs, building an if only to use it at once, is exactly one step of running a program. A proof is a program, a statement is a type, and proving is computing.

Types are built by arrows and pairs, and a program from one type to another is made by supposing a member of the first and building a member of the second. Read the arrow as if and the pair as and, and the typing rules are the moves of natural deduction: a proof is a program, and a statement with a proof is a type with a member. Cutting a detour from a proof is one step of running its program.

47j1Terms With Types

Start from 41b’s λ-calculus: terms are placeholders, λx. t (the function that takes x to t) and t s (t applied to s), and running a program puts s in for x: (λx. t) s becomes t with s in place of x. Now lay down types. Some base types, written A, B, C. If A and B are types, so are A → B, the functions from A to B, and A × B, the pairs. A typing x₁ : A₁, …, x_n : A_n ⊢ t : B says that, with those placeholders of those types, t has type B. The arrow → here joins two types; it keeps its 4d meaning for functions, and these are functions in 47f2’s sense.

The rules, one for each way of building. A placeholder has its own type. If, with x : A added, t : B, then λx. t : A → B. If t : A → B and s : A, then t s : B. If t : A and s : B, then ⟨t, s⟩ : A × B; and from p : A × B, fst p : A and snd p : B.

Typed-term technique: λf. λx. f (f x) has type (A → A) → (A → A) for every type A, and applied to a function and an input it runs that function twice.

f : A \to A,\ x : A \vdash f\,x : A @@ apply f to x
f : A \to A,\ x : A \vdash f\,(f\,x) : A @@ apply f again
f : A \to A \vdash \lambda x.\,f\,(f\,x) : A \to A @@ make a function of x
\vdash \lambda f.\,\lambda x.\,f\,(f\,x) : (A \to A) \to (A \to A) @@ make a function of f
(\lambda f.\,\lambda x.\,f(f\,x))\,S\,3 \to (\lambda x.\,S(S\,x))\,3 \to S(S\,3) = 5 @@ run it on next and 3: put S in for f, then 3 for x
\htmlClass{new}{\text{a term with a type, and its run}} \quad \blacksquare @@ the typing, then the computation

λx. x x, which 41b used to build programs that never stop, has no type: x would need a type A with A equal to A → B, and no type built by the rules is shorter than itself. Typed terms all stop when run; the proof is held in trust, much higher up the ladder.

47j2A Proof Is a Term

Read each type as a statement: A → B as A ⇒ B, A × B as A ∧ B. Then each typing rule is a move of 38b. Making λx. t from x : A ⊢ t : B is 38n’s box: suppose A, reach B, write A ⇒ B and drop the supposition. Applying t s is using an if: from A ⇒ B and A, B. A pair is a join, and fst and snd are keep either part.

Proofs-as-terms technique: a tree proof of B from suppositions A₁, …, A_n, using only if and and, is a term of type B with placeholders of types A₁, …, A_n, and every such term is such a proof; the term records the proof move by move.

p : P \times Q \vdash \mathrm{snd}\,p : Q,\ \ \mathrm{fst}\,p : P @@ suppose P ∧ Q; keep either part, twice
p : P \times Q \vdash \langle \mathrm{snd}\,p, \mathrm{fst}\,p \rangle : Q \times P @@ join
\vdash \lambda p.\,\langle \mathrm{snd}\,p, \mathrm{fst}\,p \rangle : (P \times Q) \to (Q \times P) @@ drop the supposition: an if
\text{the tree: } [P \wedge Q] \to Q,\ P \to Q \wedge P \to (P \wedge Q) \Rightarrow (Q \wedge P) @@ 38n1’s tree, the same moves in the same order
\htmlClass{new}{\text{the proof is the program that swaps a pair}} \quad \blacksquare @@ induction on the building, rule by rule, for every proof

The sum of 47d3 gives or. A + B has inl : A → A + B and inr : B → A + B, and a case term out of it: add an option, and cases worked inside the line. ⊥ is a type with no terms built by the rules, and ¬A is A → ⊥. So a statement is true in this calculus when its type has a member, and the member is the proof.

47j3A Detour Is a Step of the Run

38n3 called a detour a place in a tree where an if is built and at once used: suppose A, reach B, write A ⇒ B, then use it on a proof of A. Its detour-cut technique put the proof of A in place of the supposition, and the if disappeared. Read that as terms.

Detour-is-step technique: cutting a detour from a proof is one step of running its term: building an if and using it at once is (λx. t) s, and cutting it is putting s in for x.

\text{detour: } x : A \vdash t : B,\ \ \lambda x.\,t : A \to B,\ \ s : A,\ \ (\lambda x.\,t)\,s : B @@ build the if, then use it
\text{cut: put the proof } s \text{ of } A \text{ where the supposition } x \text{ was used} @@ the detour-cut technique (38n3)
(\lambda x.\,t)\,s \to t \text{ with } s \text{ in place of } x @@ one step of running the term (41b)
\mathrm{fst}\,\langle t, s \rangle \to t @@ the detour join, then keep the left part, cut the same way
\htmlClass{new}{\text{straightening a proof} = \text{running a program}} \quad \blacksquare @@ each kind of detour matches each kind of step

Now read it in a category. Types are the things, and terms with one placeholder, x : A ⊢ t : B, taken up to running, are the arrows A → B. A × B is a product, by 47d1’s pair-map shape, and A → B is 47f2’s function type, with the pair-to-function matching. A category with these two is the accepted kind for typed programs. What has no term is as telling. P ∨ ¬P, rung 7’s either-way principle, has no term in this calculus: a program would have to decide, for an unknown P, which side it can produce. ¬¬(P ∨ ¬P) has one, λk. k (inr (λp. k (inl p))). The calculus is the logic that refuses rung 7’s principle and keeps everything before it.

The accepted names

The calculus is the simply typed λ-calculus, with function, product and sum types; its terms all terminate (strong normalization). The proofs-as-terms technique is the Curry–Howard correspondence, or propositions-as-types; the detour-is-step technique matches cut elimination with β-reduction. A category of types and terms with products and function types is a cartesian closed category. The logic with no term for excluded middle is intuitionistic logic, and λk. k (inr (λp. k (inl p))) proves its double negation; adding control operators such as call/cc gives classical logic a reading as programs.

Who said it first

Alonzo Church gave the simply typed λ-calculus in 1940. Haskell Curry noticed in 1934, and again with Robert Feys in 1958, that the types of combinators are the axioms of implication. William Howard wrote the correspondence for natural deduction in a note circulated in 1969, published in 1980. Joachim Lambek tied it to cartesian closed categories in the early 1970s; Per Martin-Löf’s type theory (1972 onward) built mathematics on it. Timothy Griffin read call/cc as a classical proof in 1990. L. E. J. Brouwer refused excluded middle from 1908, and Arend Heyting wrote intuitionistic logic down in 1930.

A proof that is not allowed

“P ∨ ¬P has no term, so it is false.” Not allowed: having no term in this calculus says it has no proof by these moves. It is true in every world of 38a and every row of 1e’s tables; rung 7 adds it, and with it every proof of the ladder past rung 7. The calculus measures what can be proved with the side in hand, not what is true.
