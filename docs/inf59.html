∞59 · research front

Does Every Number Fall to 1?

Does every number fall to 1? Take a counting number. If it is even, halve it. If it is odd, treble it and add 1. Repeat. Start at 6 and the run goes 3, 10, 5, 16, 8, 4, 2, 1, and then 4, 2, 1 for ever. Start at 27 and it climbs as high as 9232 before it falls, and needs 111 steps to reach 1. The question was going round by the 1930s, and computers have now checked every start below a number with twenty two digits: all of them fall to 1. Nobody has proved that every number does. What can be proved is surprisingly much and surprisingly little. The odd and even steps of a run are a code for the starting number, read on a clock, and every code of a given length belongs to exactly one hour; so for most starts the run behaves like a fair coin, and a fair coin shrinks the number more often than it grows it. In 1976 that gave a proof that almost every number eventually falls below itself. A circle other than 4, 2, 1 would have to balance trebles against halvings so finely that the continued fractions of the ladder force it to be enormously long. In 2019 it was proved that almost every number falls below any bound that grows, however slowly, by finding a way of choosing starting numbers at random that the rule nearly keeps the same. And cousins of the rule, built from the same kind of steps on a clock, can run any machine, so that some questions about them no machine can decide. This page builds the rule on a clock, the parity code, the proof that most numbers dip, the length of a circle, the 2019 result told, the undecidable cousins, and ends with the question as open as it was.

T(n) = n/2 for even n, (3n + 1)/2 for odd. The first k parities of the run from n depend only on n mod 2ᵏ, and each of the 2ᵏ parity codes comes from exactly one hour. If a code has m odd steps with 3ᵐ < 2ᵏ, every large enough n with that hour falls below itself; the codes with 3ᵐ ≥ 2ᵏ are a share that tends to 0 (1976). A circle with k steps, m of them odd, needs 0 < k ln 2 − m ln 3 < m/(3x) at its least member x, so k/m sits very close to log₂ 3. Since 2019: almost every n falls below f(n) for any f tending to infinity. Cousins of T run any machine (1972).

inf59.1The Rule on a Clock

Every number is even or odd, and not both (4j’s even-or-odd technique). The rule: halve an even number; treble an odd one and add 1. After an odd step the result 3n + 1 is even, since odd times odd is odd (4j) and odd plus 1 is even, so the next step always halves. Folding that halving in gives the shortcut T(n) = n/2 for even n and T(n) = (3n + 1)/2 for odd n. Each step of T halves once. From 6: 3, 5, 8, 4, 2, 1, 2, 1, … The only circle known is 1, 2.

Clock-step technique: for every j ≥ 1, the hour of T(n) on the clock of 2ʲ depends only on the hour of n on the clock of 2ʲ⁺¹.

n' = n + 2^{j+1} t @@ the same hour as n on the clock of 2ʲ⁺¹ (43a)
n' \text{ and } n \text{ are both even or both odd} @@ they differ by an even number
\text{even: } T(n') = \tfrac{n}{2} + 2^j t @@ halving
\text{odd: } T(n') = \tfrac{3n + 1}{2} + 3 \cdot 2^j t @@ trebling, adding 1, halving
\htmlClass{new}{T(n') \equiv T(n) \pmod{2^j}} \quad \blacksquare @@ the difference is a multiple of 2ʲ either way

So one bit of the clock is spent at each step. Start at 27 with the full rule, three times and one: it climbs to 9232 and reaches 1 after 111 steps (by script); 41 of them are trebles. A run can wander far before it falls, and nothing in the rule says how far. Every start below 2⁷¹, about 2.4 × 10²¹, has been checked by computer and falls to 1 (2025).

The halve-or-treble rule is one map from the whole numbers to themselves, and a run is that map in a row with itself; the question is whether every run reaches the loop 1, 4, 2. By this footing, the map is also a map of clocks, from the clock of 2ʲ⁺¹ to the clock of 2ʲ, so the first k steps read only the hour of n on the clock of 2ᵏ. The parity code is ∞7.3’s map into the streams, read for k steps, with odd or even as the output. The plan is that code of k parities; the number itself, past its hour, is let go.

inf59.2The Parity Code

Write the parities of the run from n as a code: v₀ = 0 if n is even and 1 if odd, v₁ the same for T(n), and so on. The first k bits of the code are the parity code of n of length k.

Parity-code technique: the parity code of length k of n depends only on the hour of n on the clock of 2ᵏ, and the 2ᵏ hours give the 2ᵏ codes, each exactly once.

v_i \text{ is the parity of } T^i(n),\ \text{fixed by } T^i(n) \bmod 2 @@ the code, bit by bit
T^i(n) \bmod 2 \text{ is fixed by } n \bmod 2^{i+1} @@ the clock-step technique, i times
\text{so the first } k \text{ bits are fixed by } n \bmod 2^k @@ i ≤ k − 1
\text{the hours } r \text{ and } r + 2^k \text{ on the clock of } 2^{k+1} \text{ share their first } k \text{ bits} @@ induction on k: suppose each code of length k comes from one hour mod 2ᵏ
T^k(r + 2^k) = T^k(r) + 3^m @@ each step halves the added 2ᵏ once, and trebles it at each of the m odd steps
\htmlClass{new}{3^m \text{ is odd, so the } (k{+}1)\text{th bits differ: the two hours split the two codes}} \quad \blacksquare @@ 2ᵏ⁺¹ hours, 2ᵏ⁺¹ codes, one each

On the clock of 8: 0 → 000, 1 → 101, 2 → 010, 3 → 110, 4 → 001, 5 → 100, 6 → 011, 7 → 111. All eight codes, each once (checked to k = 15 by script). This is the same picture as 24k’s angle-doubling run, where each step reads off one binary digit and shifts the rest: here each step reads off one parity, and the clock of 2ᵏ is used up after k steps. The consequence is the one the rest of the page spends: for a start chosen at random among the hours of 2ᵏ, the k parities are k fair coin flips, independent of each other.

inf59.3Most Numbers Dip

Each odd step multiplies by a little more than 3/2, each even step by 1/2. With fair coins, half of each: a typical step multiplies by about √(3/2 · 1/2) = √(3/4) ≈ 0.866. So most runs should shrink. The proof makes this exact.

Dip technique: if the parity code of length k of n has m odd steps with 3ᵐ < 2ᵏ, and n is large enough, then some Tʲ(n) with j ≤ k is below n.

\text{suppose } T^j(n) \ge n \text{ for } j = 1, \ldots, k @@ no dip within k steps
\text{even step: } T(x) = \tfrac12 x;\ \ \text{odd: } T(x) = \tfrac32 x\,(1 + \tfrac1{3x}) \le \tfrac32 x\,(1 + \tfrac1{3n}) @@ every x along the way is at least n
T^k(n) \le n \cdot \tfrac{3^m}{2^k}\,(1 + \tfrac{1}{3n})^m @@ multiply the k steps
\tfrac{3^m}{2^k} < 1 \Rightarrow \tfrac{3^m}{2^k}(1 + \tfrac1{3n})^m < 1 \text{ once } n \text{ is large enough} @@ the second factor falls to 1 as n grows, m fixed
\htmlClass{new}{T^k(n) < n,\ \text{against the supposition}} \quad \blacksquare @@ so a dip comes within k steps

Most-dip technique: the share of starts below N that never fall below themselves tends to 0 as N grows. By the parity-code technique, among the hours of 2ᵏ the count of odd steps m is the number of heads in k fair flips, and a dip is forced when 3ᵐ < 2ᵏ, that is m/k below log₃ 2 ≈ 0.631. By the averages-settle technique the share of hours with m/k ≥ 0.631 heads to 0, since the average is ½. The codes with too many odd steps are 17.2% of the hours at k = 10, 4.0% at k = 40, 0.056% at k = 160 (by script). Every large start outside that share dips, so the share of starts that never dip is at most that, for every k.

Below a million, every start from 2 on dips: half at the first step (the even ones), a quarter at the second (n = 4t + 1, which goes to 6t + 2 and then 3t + 1), and the slowest, by script, takes 176 steps. Dipping is not falling to 1. But if every n ≥ 2 dips, induction on n (strong, as in 4h) gives that every number falls to 1. So the open question is exactly whether the share of starts that never dip, which tends to 0, is empty.

inf59.4A Circle Must Be Long

Suppose the run from some x returns to x after k steps of T, m of them odd, and x is the least number on the circle. Then 1, 2 is the circle with k = 2, m = 1. Any other circle would balance m trebles against k halvings almost exactly.

Cycle-balance technique: on a circle of k steps with m odd steps and least member x, 0 < k ln 2 − m ln 3 < m/(3x).

1 = \textstyle\prod_{\text{steps}} \tfrac{T(y)}{y} = \tfrac{3^m}{2^k} \textstyle\prod_{\text{odd } y} (1 + \tfrac1{3y}) @@ round the circle back to x; the step factors of inf59.3
\tfrac{2^k}{3^m} = \textstyle\prod_{\text{odd } y}(1 + \tfrac1{3y}) > 1 @@ m ≥ 1: a circle with no odd step only halves
\le (1 + \tfrac1{3x})^m @@ every y is at least x
0 < k\ln 2 - m\ln 3 \le m \ln(1 + \tfrac1{3x}) @@ take logarithms
\htmlClass{new}{0 < k\ln 2 - m\ln 3 < \tfrac{m}{3x}} \quad \blacksquare @@ ln(1 + t) < t for t > 0

Check on 1, 2: k = 2, m = 1, and 2/3 = 1 + 1/3 · 1/1, so 4/3 = 4/3 exactly. Dividing by m ln 2, the fraction k/m lies above log₂ 3 by less than 1/(3x ln 2). If no start below X is on a circle, then x ≥ X, and k/m must approximate log₂ 3 = [1; 1, 1, 2, 2, 3, 1, 5, 2, 23, …] from above to within 1/(3X ln 2). The convergent-bound technique of 43k says only fractions with large bottoms come that close. The fractions closest from above with a given size of bottom are the convergents and the fractions between neighbouring ones; searching them by script: with X = 2¹⁰ a circle needs m ≥ 41 and k ≥ 65 (65/41 is a convergent), with X = 2⁴⁰ k ≥ 17 087 915, and with the checked X = 2⁷¹, k ≥ 114 208 327 604 steps, m ≥ 72 057 431 991 of them odd.

inf59.5Almost Every Number, 2019

Dipping below n is a weak fall. The 2019 result asks the run from n to fall far: below f(n) for any f that grows to infinity, however slowly, f(n) = ln ln ln n for instance. Stated, not proved here: for every such f, almost every n, in a sense of “almost every” that weights n by 1/n, has some Tʲ(n) below f(n). The weighting by 1/n counts a start near N as worth as much as all the starts near 2N together; under it, a set of starts of share 0 is negligible.

The idea, told. Run the rule from a random start. After many steps, the run sits at a random place, and the trouble is that its law is not the law of a fresh random start, so the dip technique cannot be reapplied. The 2019 proof finds a way of choosing random starts, on the odd numbers and with the weights 1/n, whose law the rule keeps nearly the same over long stretches, close enough that the coins of inf59.2 can be used again and again along the run. Each reuse costs a little, and the costs add up to less than everything. The hard part, held in trust, is controlling the hours on the clocks of 3ᵏ that the trebles produce, by turnings on those clocks.

\text{a random hour of } 2^k:\ m = \text{heads in } k \text{ fair flips} @@ the parity-code technique
\operatorname{E}\,\big(\ln \tfrac{3^m}{2^k}\big) = \tfrac k2 \ln 3 - k\ln 2 @@ averages add; E m = k/2
\htmlClass{new}{= k \ln \tfrac{\sqrt 3}{2} \approx -0.144\,k} @@ each step shrinks by about 0.866 on average

So some hour has the product at most its average, by the some-outcome technique of ∞42, and most hours have it near the average by 30h. What no average can do is rule out one start whose coins come up odd too often for ever: a single exception has share 0. The 2019 result, like the 1976 one, is about almost every start, and the conjecture is about every one.

inf59.6Cousins No Machine Can Decide

T multiplies by a fraction that depends on the hour of n: by 1/2 on even hours, and by 3/2 with 1/2 added on odd ones. Allow any clock and any fractions, and the rules can compute. A simple family: a list of fractions; at each step, multiply n by the first fraction in the list that gives a whole number; stop when none does.

Fraction-list technique: the list 5/2, 5/3 takes 2ˣ 3ʸ to 5ˣ⁺ʸ: it adds.

2^x 3^y 5^z,\ x \ge 1 \mapsto 2^{x-1} 3^y 5^{z+1} @@ 5/2 is whole while a 2 is left
2^0 3^y 5^{z},\ y \ge 1 \mapsto 3^{y-1} 5^{z+1} @@ then 5/3, while a 3 is left
5^{z}:\ \text{neither fraction is whole} @@ stop
\htmlClass{new}{2^x 3^y \mapsto 5^{x+y}} \quad \blacksquare @@ each 2 and each 3 turned into a 5: 108 = 2² · 3³ goes to 5⁵ = 3125

Held in trust (1972): such lists, and rules of T’s kind with a clock and a fraction for each hour, can run every tape machine, so whether a run from a given start ever reaches a power of 2 is a question no machine decides, by 41d and the reduction-carries technique of 41e. In 2007 it was shown that whether every start of such a rule falls to 1 is undecidable too, and of the shape “for every start there is a step” that sits above the stopping question. None of this says anything about T itself. T is one rule, and its question has an answer; what the cousins show is that no method that works for every rule of its kind can find it.

Open questions · nobody has the answer yet

Open questions

These are open: the field is still asking them. There is no key; a good attempt is a reason, a guess, or a better question.

∞59.oq.1Does every counting number fall to 1 under the rule? Equivalently, does every n ≥ 2 dip below itself?
Why it is hard: every method on this page proves something about almost every start, and a single start that misbehaves is invisible to averages; a proof for every start would have to follow the run itself, and the cousins show that no method working for every rule of this kind can do that.
∞59.oq.2Is there a circle other than 1, 2? Any other circle has at least 114 208 327 604 steps, by the cycle-balance technique and the check to 2⁷¹; is there an argument that rules circles out altogether?
Why it is hard: the balance 2ᵏ ≈ 3ᵐ can be met as closely as wanted by large k and m, so the continued fractions bound the length but never close the door.
∞59.oq.3Is there a start whose run grows without end? The 2019 result says almost every run comes down near 1, but leaves room for a set of starts of share 0 that climb for ever.
Why it is hard: a run that climbs must have more than about 63% odd steps for ever, and nothing in the parity code forbids a single start from having that.
A short history · told from more than one side

How we got here

The rule is usually dated to 1937. It travelled by word of mouth, picking up a new name in almost every place it reached, which is why the cellar lists so many, and its runs, easy to compute and wild to look at, made it a favourite of the first people with computers to spare.

In 1976 and 1977 two papers, independently, proved that almost every number dips below itself, by the parity code and the coins of inf59.2. In 1972 a construction had shown that rules of the same family run any machine, so that the general question is undecidable, and that raised the question whether T’s own question might be one of the undecidable ones, against the reply that a single rule is not a family.

Computers pushed the checked range up decade by decade. The current check, to 2⁷¹, was published in 2025. The cycle bounds grew with the checked range, as inf59.4 shows they must: each larger check lengthens the shortest possible circle.

In September 2019 a paper posted online proved that almost every start falls below any slowly growing bound, and in December of that year a popular science magazine reported it as a huge result on a dangerous problem. It was published in a journal in 2022. Like the result of 1976, it says nothing about any single start, and the conjecture is about every one.

What is argued now is how the question could ever be closed. One view holds that the rule is a random-looking process that will yield only to a new idea about how the clocks of 2 and of 3 interact, the interaction the 2019 proof handled on average. Another keeps open that it may be true and not provable from the usual axioms, as the cousins make thinkable, though nothing has shown that either. This page has not revisited how either view is held today.

The accepted names

The question is the Collatz conjecture, also called the 3x + 1 problem, the Syracuse problem, Kakutani’s problem, Hasse’s algorithm and Ulam’s problem. T is the shortcut Collatz map; the parity code is the parity vector, and the parity-code technique says the map from n to its parity vector is a bijection on ℤ/2ᵏ, which in the limit is a conjugacy between T on the 2-adic integers and the shift map. Dipping below n is having a finite stopping time; the most-dip technique is the theorem of Terras and of Everett. The fraction lists are Conway’s FRACTRAN programs, and the rules with a clock and a fraction for each hour are generalized Collatz functions. The weighting by 1/n is logarithmic density. The 2019 result is Tao’s theorem that almost all Collatz orbits attain almost bounded values.

Who said it first

Lothar Collatz is credited with the problem, from 1937. Riho Terras (Acta Arithmetica 30, 1976) and C. J. Everett (Advances in Mathematics 25, 1977) proved that almost every number has finite stopping time. John Horton Conway showed that generalized Collatz functions can be undecidable (“Unpredictable iterations”, 1972), and Stuart Kurtz and Janos Simon showed the generalized problem Π⁰₂-complete (2007). Jeffrey Lagarias has kept the annotated bibliography of the problem. Terence Tao posted the almost-bounded-values result in September 2019 (arXiv 1909.03562), published in Forum of Mathematics, Pi (2022); Quanta Magazine reported it in December 2019. David Barina’s verification to 2⁷¹ appeared in the Journal of Supercomputing (2025). Shalom Eliahou gave the cycle bound 17 087 915 from a check to 2⁴⁰ (1993), the same number this page’s argument gives; Christian Hercher’s work on m-cycles (Journal of Integer Sequences, 2023) carries such bounds further.

A proof that is not allowed

“The average step multiplies by about 0.866, so every run shrinks to 1.” Not allowed: an average over starts says what most starts do, and nothing about one. The coins of inf59.2 are fair only for a start chosen at random; for a fixed start the parities are fixed, and the question is whether some fixed start keeps getting too many odd ones.
