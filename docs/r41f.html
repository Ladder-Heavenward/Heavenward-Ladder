Programs That Print Themselves

Can a program print its own text? It seems it must hold a copy of itself, and the copy must hold a copy, and so on without end. Rung zero met the way out, in words: fill a phrase’s gap with the phrase’s own quotation, and the statement speaks of itself without containing itself. Rung thirty seven did it in arithmetic: a formula fed its own code. This step does it with machines. A machine is built in two halves. The first half writes out the text of the second. The second half reads what is on the tape, works out the text of a machine that would write that, and puts it in front. The result is the text of the whole. Once a machine can get its own code, it can do anything with it: run it, compare it, do the opposite of a prediction about it. So the diagonal of the step on stopping becomes three lines, and a new limit comes out at once: no machine can list endlessly many programs that are each the shortest of their kind.

One half of a machine writes the other half’s code; the other half writes the code of a machine that would write what it reads. Together they print their own code. So every machine can be given access to its own code, which turns diagonal arguments into short programs.

41f1A Machine That Prints Its Own Code

For each string w there is a machine P_w that, on any input, erases it, writes w and stops: one row per letter of w. The function q(w) = ⟨P_w⟩ is computed: reading w, write the rows for each letter in turn. So a machine can turn any string into the code of a machine that prints that string.

Self-print technique: some machine, started on a blank tape, stops with its own code on the tape.

B\text{: }\allowbreak \text{read }\allowbreak \text{the }\allowbreak \text{tape, } \langle X\rangle\text{; }\allowbreak \text{compute } q(\langle X\rangle) = \langle P_{\langle X\rangle}\rangle\text{; }\allowbreak \text{write }\allowbreak \text{it }\allowbreak \text{in }\allowbreak \text{front} @@ q is computed; B ends with ⟨P_⟨X⟩⟩⟨X⟩
A = P_{\langle B\rangle} @@ A writes B’s code and stops; built after B, from B
SELF = A \text{ then } B @@ the machine that runs A, then B
\text{A leaves } \langle B\rangle\text{; }\allowbreak \text{B }\allowbreak \text{computes } q(\langle B\rangle) = \langle A\rangle\text{, }\allowbreak \text{and }\allowbreak \text{writes }\allowbreak \text{it }\allowbreak \text{in }\allowbreak \text{front} @@ A is P_⟨B⟩, by its building
\htmlClass{new}{\text{the }}\allowbreak \htmlClass{new}{ \text{tape }}\allowbreak \htmlClass{new}{ \text{reads } \langle A\rangle\langle B\rangle = \langle SELF\rangle} \quad \blacksquare @@ the code of a machine run in two parts is the two codes joined

Rung 0’s quotation trick is the same. A, a quotation, names B. B fills its gap with the quotation of what it was given. In a programming language the shortest such programs are one line. This one, in Python, prints exactly its own text: s='s=%r;print(s%%s)';print(s%s). The string s is A; print(s%s) is B, filling s’s gap with s’s quotation.

41f2Its Own Code, for Any Use

Own-code technique: for every machine T that reads a code and a string, there is a machine R such that R on any w does what T does on ⟨R⟩ # w.

R = A\,B\,T @@ three parts, run in turn
A = P_{\langle BT\rangle}\text{, run on } w\text{: write } \langle BT\rangle \text{ after } w @@ as in 41f1, now keeping w
B\text{: from } \langle BT\rangle \text{ compute } \langle P_{\langle BT\rangle}\rangle = \langle A\rangle\text{, }\allowbreak \text{and }\allowbreak \text{form } \langle A\rangle\langle BT\rangle \# w @@ q, then a rearrangement
\langle A\rangle\langle BT\rangle = \langle R\rangle @@ the code of three parts run in turn
\htmlClass{new}{T \text{ runs on } \langle R\rangle \# w} \quad \blacksquare @@ the last part of R

41f3Diagonals in Three Lines

With the own-code technique a machine may begin “get your own code”. The stopping question falls in three lines.

D \text{ decides } H;\ \allowbreak \ R\text{: get } \langle R\rangle\text{, run } D \text{ on } \langle R\rangle \# w\text{, }\allowbreak \text{do }\allowbreak \text{the }\allowbreak \text{opposite} @@ suppose D; R by the own-code technique
R \text{ stops }\allowbreak \text{on } w \iff D \text{ says } R \text{ does }\allowbreak \text{not }\allowbreak \text{stop }\allowbreak \text{on } w @@ R’s building
\htmlClass{new}{\bot} \quad \blacksquare @@ D is right about R

A machine is shortest when no machine with a shorter code computes the same function.

Shortest-unlisted technique: no machine lists endlessly many shortest machines.

L \text{ lists }\allowbreak \text{endlessly }\allowbreak \text{many }\allowbreak \text{shortest }\allowbreak \text{machines} @@ suppose it
R\text{: get } \langle R\rangle\text{; run } L \text{ until }\allowbreak \text{it }\allowbreak \text{lists }\allowbreak \text{some } C \text{ with }\allowbreak \text{a }\allowbreak \text{code }\allowbreak \text{longer }\allowbreak \text{than } \langle R\rangle\text{; }\allowbreak \text{then }\allowbreak \text{act }\allowbreak \text{as } C @@ the own-code technique; such a C comes, since only finitely many codes are as short as ⟨R⟩
R \text{ computes }\allowbreak \text{what } C \text{ computes} @@ R acts as C on every input
\langle R\rangle \text{ is }\allowbreak \text{shorter }\allowbreak \text{than } \langle C\rangle @@ the choice of C
\htmlClass{new}{\bot:\ C \text{ is }}\allowbreak \htmlClass{new}{ \text{not }}\allowbreak \htmlClass{new}{ \text{shortest}} \quad \blacksquare @@ against L’s list

So there are endlessly many shortest machines, one for each computed function at least, and no machine can find more than finitely many of them and know it. Proving that a program cannot be made shorter is, past a point, beyond every listed method.

The accepted names

A program that prints its own text is a quine, after the logician W. V. O. Quine, whose phrase “yields falsehood when preceded by its quotation” is the 0b.4.4 trick written out. The own-code technique is Kleene’s second recursion theorem, or the recursion theorem; 41f.5.3 is its fixed-point form, Rogers’s fixed-point theorem. The shortest-unlisted technique is that MIN_TM is not Turing-recognizable, and it is close to the result that the shortest description of a string, its Kolmogorov complexity, is not computable.

Who said it first

Stephen Kleene proved the recursion theorem in 1938. John von Neumann, in lectures of 1948 and 1949 published in 1966, built a machine that reproduces itself from a description of itself, with a copier and a builder, the A and B of this step, before the structure of DNA was known (1953). Douglas Hofstadter popularised the name quine in 1979. Andrey Kolmogorov (1965) and Gregory Chaitin (1966) defined the shortest description.

A proof that is not allowed

“R gets its own code by reading its table.” Not allowed: a machine cannot read its own table, only its tape. The own-code technique puts ⟨R⟩ on the tape by computing it, which is the whole point of A and B.
