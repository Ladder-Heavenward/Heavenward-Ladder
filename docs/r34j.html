34j · technique

Open Sets and Continuity by Hand

Checking that a set is open one ball at a time is slow, and checking that a map is continuous one point at a time is slower. This step gives the quick ways. A set cut out of the plane by strict inequalities between continuous functions is open, and one cut out by inequalities that allow equality is closed, so most sets met on a map or a graph can be sorted at a glance. Then three sets that every set carries with it: its inside, its closure and its edge, found by asking what every small open set about a point meets. Last, continuity checked on a base, and the quickest way to find a break: pull back one small open set and see whether a point of the edge sneaks into the pull-back.

If a function to the line is continuous, the points where it is above or below a number make an open set, and the points where it is at least, at most or equal to a number make a closed set. A point is on the edge of a set exactly when every open set about it meets both the set and its leftover. A map is continuous when the pull-back of each member of a base is open, so one bad pull-back of a small stretch shows a break.

34j1Open by a Strict Inequality

Strict-test technique: if g is a continuous map from a space X to the line, then the points with g > c, and those with g < c, are open; the points with g ≥ c, g ≤ c, and g = c are closed.

\{g > c\} = g^{-1}((c, \infty)) @@ a pull-back of an open stretch: open (34b2)
\{g < c\} = g^{-1}((-\infty, c)) @@ likewise
\{g \le c\} = X \setminus \{g > c\},\ \ \{g \ge c\} = X \setminus \{g < c\} @@ leftovers of open sets: closed
\htmlClass{new}{\{g = c\} = \{g \le c\} \cap \{g \ge c\} \text{ is closed}} \quad \blacksquare @@ the overlap of two closed sets is closed: its leftover is a union of two open sets
  
\{(x, y) : x^2 + y^2 < 1\} \text{ open} @@ g = x² + y² is continuous (11b); g < 1
\{(x, y) : 0 < x < 1,\ y > x^2\} \text{ open} @@ three strict tests: x > 0, x < 1, y − x² > 0; finitely many overlaps (34a2)
\{(x, y) : xy = 1\} \text{ closed} @@ g = xy, and g = 1
\htmlClass{new}{\{(x, y) : y \ge 0,\ x^2 + y^2 < 1\} \text{ neither}} @@ (0, 0) is in it with no ball inside it; (0, 1 − 1/n) settles at (0, 1), outside it

A hiker’s map of Mount Hood draws the line where the height is 1800 m. By the technique, that line is closed, the land above it is open, and the land at or above it is closed, as long as the height is continuous. A cliff is where it is not.

34j2Inside, Closure, Edge

Every part A of a space carries three sets. Its inside is the union of all open sets that lie in A: the largest open set in A. Its closure, from 34c4, is the set of points every open set about which meets A: the smallest closed set holding A. Its edge is the closure with the inside taken away.

Edge technique: a point is on the edge of A exactly when every open set about it meets both A and the leftover of A.

x \in \overline A \iff \text{every open } U \ni x \text{ meets } A @@ the closure, 34c4
x \notin \text{inside}(A) \iff \text{no open } U \ni x \text{ lies in } A @@ the inside is the union of open sets in A
\text{no open } U \ni x \text{ lies in } A \iff \text{every open } U \ni x \text{ meets } X \setminus A @@ not lying in A is meeting its leftover
\htmlClass{new}{x \in \text{edge}(A) \iff \text{every open } U \ni x \text{ meets } A \text{ and } X \setminus A} \quad \blacksquare @@ the edge is the closure minus the inside
  
A = [0, 1) \subseteq \mathbb R:\ \ \text{inside } (0, 1),\ \text{closure } [0, 1],\ \text{edge } \{0, 1\} @@ every stretch about 0 or 1 meets A and its leftover
A = \mathbb Q \cap [0, 1]:\ \ \text{inside } \emptyset,\ \text{closure } [0, 1],\ \text{edge } [0, 1] @@ every stretch holds fractions and non-fractions (8e)
A = \{y \ge 0,\ x^2 + y^2 < 1\}:\ \ \text{inside } \{y > 0,\ x^2 + y^2 < 1\} @@ the strict tests
\htmlClass{new}{\text{closure } \{y \ge 0,\ x^2 + y^2 \le 1\},\ \text{edge: the segment and the upper half of the circle}} @@ the closed tests; closure minus inside

34j3Continuity, Checked on a Base

Base-check technique: if ℬ is a base for the open sets of Y, a map f from X to Y is continuous exactly when the pull-back of every member of ℬ is open.

V \subseteq Y \text{ open} \Rightarrow V = \textstyle\bigcup_i B_i,\ B_i \in \mathcal B @@ a base (34b3)
f^{-1}(V) = \textstyle\bigcup_i f^{-1}(B_i) @@ x lands in V exactly when it lands in some Bᵢ
\htmlClass{new}{f^{-1}(V) \text{ is open}} \quad \blacksquare @@ a union of open sets is open; the other way, members of ℬ are open
  
f(x) = x^2:\ \ f^{-1}((1, 4)) = (-2, -1) \cup (1, 2) @@ open: no break shows; every stretch pulls back so, by the strict tests
f(x) = \text{the round-down of } x:\ \ f^{-1}((\tfrac12, \tfrac32)) = [1, 2) @@ not open at 1: a break at 1
f(x) = 1 \text{ for } x > 0,\ \ 0 \text{ for } x \le 0:\ \ f^{-1}((\tfrac12, \tfrac32)) = (0, \infty) @@ open; but f⁻¹((−½, ½)) = (−∞, 0], not open: a break at 0
\htmlClass{new}{X = \{1, 2, 3\},\ \mathcal T = \{\emptyset, \{1\}, \{1, 2\}, X\},\ \ f = 1 \leftrightarrow 3:\ \ f^{-1}(\{1\}) = \{3\}} @@ not open: f is not continuous from X to itself

A pull-back that is not open has a point with no room around it inside the pull-back. That point is where the break is. The step function above shows that one good pull-back is not enough: each small stretch has to be tried.

34j4A Base That Fits in One List

The fractions come near every real, and they fit in one list (30a2). How much of the line’s good behaviour comes from that alone? In a space X with a distance, call a part dense when every ball of X holds a point of it.

Listed-base technique: a space with a distance has a dense part that fits in one list exactly when it has a base that fits in one list. Then every part of it has a dense part that fits in one list, and every cover of it by open sets has a part that fits in one list and still covers.

\text{dense list } p_1, p_2, \ldots \Rightarrow \text{the balls round } p_n \text{ of radius } \tfrac1m @@ they fit in one list: for N = 1, 2, 3, … take those with m, n ≤ N, finitely many each time
x \in U \text{ open} \Rightarrow x \in \text{such a ball} \subseteq U @@ a ball of radius 2/m round x lies in U; some pₙ is within 1/m of x; so they are a base (34b3)
\text{base } B_1, B_2, \ldots \Rightarrow \text{one point from each } B_n @@ every ball holds some Bₙ, so those points are dense; the picking can be done down a list
\text{a part } Y:\ \text{one point of } Y \text{ from each } B_n \text{ that meets } Y @@ dense in Y, since the Bₙ ∩ Y are a base for Y (34b5)
\text{for each } B_n \text{ in some member, keep one} @@ from a cover: for each Bₙ that lies inside some member, keep one such member; that is a list of members
\htmlClass{new}{\text{the kept members still cover}} \quad \blacksquare @@ each x lies in a member U, and in some Bₙ inside U; the member kept for that Bₙ holds x

The line has such a base: the intervals with fraction ends. So do lists of n numbers, and so does the space of continuous functions on [0, 1] with the largest gap: the polynomials with fraction coefficients fit in one list and come near everything (31j2).

Not every space with a distance has one. Give any set that fits in no list the distance that is 1 between different points. Every point is then a ball of radius ½ by itself, so a dense part must be the whole set. The bounded lists of numbers, with the largest gap between lists as distance, fail in the same way: the lists of 0s and 1s are all at distance 1 from each other, and there are too many of them for a list (35b will count them).

The accepted names

The inside is the interior, int A; the closure is cl A or A with a bar; the edge is the boundary, ∂A, or frontier. The strict-test technique says that the sets {g > c} are open for continuous g: superlevel sets are open, level sets closed. A map with all {g > c} open is lower semicontinuous. A space with a countable dense part is separable; with a countable base, second countable; with countable subcovers, a Lindelöf space.

Who said it first

Interior, closure and boundary were in use for sets of the line by Georg Cantor in the 1880s, and for sets in general spaces by Felix Hausdorff in 1914. Kazimierz Kuratowski built spaces from the closure alone in 1922.

A proof that is not allowed

“{x² ≤ 1} is the pull-back of (−∞, 1] under a continuous map, so it is open.” Not allowed: (−∞, 1] is not open. Pull-backs of closed sets are closed, and of open sets open; continuity says nothing about a set that is neither.
