How Do Four Letters Spell Twenty Things?

How do four letters spell twenty things? A cell keeps its instructions in a long string written with four letters, and builds its proteins from twenty kinds of small piece, the amino acids. Somewhere between the string and the protein, a short run of letters has to stand for one piece. This page counts the runs of each length, finds the shortest length that is enough, reads each run as a number written with four digits, and then looks at the table the cell actually uses: more runs than pieces, so most pieces have several spellings, and three runs that mean stop.

Count the strings of length k over four letters by stages-multiply: 4 to the power k. Take the least k whose count reaches the number of things to name. Read a string as a numeral in base four, so each string has exactly one number. Then a table that gives every string a meaning is a function from the strings to the meanings; count each meaning’s strings, and the counts add to the whole.

4bio1Strings of Four Letters

The cell copies the part of its DNA it needs into RNA, a string over four letters: A, C, G and U. Machines in the cell read the RNA three letters at a time, from a fixed starting place, and each run of three, called a codon, stands for one amino acid or for stop.

From here on, on this page, a string of length k is a function from the places {1, …, k} to the letters {A, C, G, U}, as in 4d: one letter at each place. How many strings of length 3 are there? Pick the letter at place 1, then at place 2, then at place 3. Each stage has 4 choices, whatever was picked before.

\{1, 2, 3\} \to \{\text{A}, \text{C}, \text{G}, \text{U}\} @@ a codon is a function from 3 places to 4 letters
4 \cdot 4 \cdot 4 @@ the stages-multiply technique (4k), one stage a place
\htmlClass{new}{4^3 = 64} @@ the counted-functions technique (4k): m to the power n

The same count for every length: there are 4 to the power k strings of length k over four letters.

4bio2Why Three Letters

There are 20 amino acids, and the cell also needs a way to say stop. That is 21 things to name, at the least. Runs of one letter give 4 names, and runs of two give 16. Neither is enough.

\{k \in \mathbb{N} : 21 \le 4^k\} \text{ has the member } 3 @@ 21 ≤ 64
\text{it is settled at each } k @@ the settled-order technique (4h)
\text{so it has a least member} @@ the least-member technique (4h)
4^0 = 1,\ 4^1 = 4,\ 4^2 = 16, \text{ each } < 21 @@ k = 0, 1, 2 are not in it
\htmlClass{new}{3 \text{ is the least length that is enough}} @@ the least member

Length 3 is not just enough: it is far more than enough. 64 strings name 21 things, so most things get more than one string.

4bio3A Codon Is a Number in Base Four

Give the letters digits: A is 0, C is 1, G is 2, U is 3. Then a codon is a numeral with three digits in base four, and reads as a number the way 4i reads a tens numeral, with 4 in the place of ten.

\text{GCU} \to 2,\ 1,\ 3 @@ the digits
(2 \cdot 4 + 1) \cdot 4 + 3 @@ the reading technique (4i), base four: multiply by 4, add the digit
\htmlClass{new}{39} @@ 36 + 3

Base-four technique: each codon reads as exactly one number from 0 to 63, and each number from 0 to 63 is read from exactly one codon. The first half is 4i’s reading. The second is 4i’s split-by-a-base and one-split, with 4 for 10: split the number by 4 three times, and the three remainders are the digits.

So the codons are matched with the numbers below 64, which is one more way to count them.

4bio4The Table the Cell Uses

The cell’s table gives every codon one meaning, so it is a function from the 64 codons to 21 meanings: twenty amino acids and stop. It is not a matching. Six codons mean leucine; one, AUG, means methionine and also marks where reading starts; three, UAA, UAG and UGA, mean stop.

Sorting the codons by meaning puts each codon in exactly one pile, so the piles must add to 64. A count that did not add up would show a mistake in the table. The table uses every one of the 21 meanings, and gives most meanings more than one codon.

Chemistry reads the twenty as one statement. Each amino acid is a carbon holding an amine, a carboxylic acid, a hydrogen and one more part, R (9chem21). The twenty are twenty values of R.

4bio5Reading From the Right Place

The RNA has no gaps between codons. Where reading begins decides every codon after it. Starting one letter later reads a different run of codons, and two letters later, another. A fourth start, three letters later, reads the first again, less one codon.

\text{AUGGCUUAA} \to \text{AUG, GCU, UAA} @@ start at 1: methionine, alanine, stop
\text{start at } 2 \to \text{UGG, CUU} @@ tryptophan, leucine
\text{start at } 3 \to \text{GGC, UUA} @@ glycine, leucine
\htmlClass{new}{\text{the start counts by its remainder on division by } 3} @@ division with remainder (4j)

Lose one letter from the middle of the string, and every codon after it is read from the wrong place. A change of one letter can change one amino acid. A lost letter changes all the rest.

4bio7A Chain of U’s, and a Slipped Letter

The code is read three letters at a time from a fixed start (4bio5). That makes two sharp tests: a message of one repeated codon must make a protein of one repeated piece, and one extra letter must change every codon after it.

\text{UUU UUU UUU} \ldots \to \text{Phe Phe Phe} \ldots @@ one codon, one piece
\text{AUG UUU GGC AAA} \to \text{Met Phe Gly Lys} @@ 
\text{one A slipped in after AUG}: \text{AUG AUU UGG CAA A}\ldots \to \text{Met Ile Trp Gln}\ldots @@ every codon after it changes
\htmlClass{new}{\text{three slipped letters restore the frame after them}} @@ the code is read in threes

Reading-frame technique: one inserted or lost letter shifts every codon after it and scrambles the rest of the protein; inserting three shifts it back. Shown in a test tube: a cell extract given a message of nothing but U’s made a chain of nothing but one piece, phenylalanine, the first word of the code read.

Accepted names

The cell’s table is the genetic code, and the one most living things use is the standard code. Several codons with one meaning are called synonymous, and the code is called degenerate. AUG as the place where reading begins is the start codon; UAA, UAG and UGA are stop codons. A way of reading from a fixed start is a reading frame, and a lost or added letter causes a frameshift. Copying DNA into RNA is transcription, and reading RNA into protein is translation.

Who said it first

The first codon was read in 1961, when Marshall Nirenberg and Heinrich Matthaei showed that RNA made only of U builds a string of phenylalanine. The whole table was known by 1966.
