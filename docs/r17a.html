17a · proof

The log as an area

16f proved that no power has slope one over the input, and 16b proved that something does: the area function of one over the input. This step gives that area function a name and finds the first facts about it from rung 15's rules alone. It is 0 at 1, negative to the left of 1 and positive to the right, and it always rises. It is caught between two simple functions, one less one over the input below, and the input less one above. And any value of it can be squeezed between lower and upper sums as tightly as you like.

The logarithm of a positive number is the area under one over the input, from one out to that number. The logarithm of one is zero, and the logarithm rises. It stays between those two simple functions, by smaller-function-smaller-area on the stretch between one and the number.

17a1The definition

From here on, for x > 0, ln x = ∫₁ˣ dt/t. Its accepted name is the natural logarithm of x, read "el en of x" or "log x"; some books write log x. ln is an operator: carried out on x, it produces one number, an area.

1/t is continuous on (0, ∞) (11b's one-over-x-is-continuous). So it is integrable on every closed interval there (continuous-is-integrable), and ln x is a number for every x > 0. For x < 1 it is −∫ₓ¹ dt/t, by 15e's convention. At 0 and below, 1/t is not defined on the stretch from 1, and ln has no value.

17a2Sign and order

Log-rises technique: ln 1 = 0; ln x < 0 for 0 < x < 1; ln x > 0 for x > 1; and 0 < x < y gives ln x < ln y.

\ln 1 = \textstyle\int_1^1 \tfrac{dt}{t} = 0 @@ 15e: ∫ₐᵃ f = 0
0 \lt x \lt y:\ \ \ln y - \ln x = \textstyle\int_x^y \tfrac{dt}{t} @@ split-in-any-order (16a)
\tfrac1t \ge \tfrac1y \text{ on } [x, y] @@ t ≤ y and both positive; 8d
\textstyle\int_x^y \tfrac{dt}{t} \ge \tfrac{y - x}{y} \gt 0 @@ smaller-function-smaller-area (15e), its second form with m = 1/y
\htmlClass{new}{\ln x \lt \ln y} @@ so ln rises
x \lt 1 \Rightarrow \ln x \lt \ln 1 = 0;\ \ x \gt 1 \Rightarrow \ln x \gt 0 \quad \blacksquare @@ the last line with y = 1, then with x = 1

17a3Two bounds

Log-bounds technique: for every x > 0, 1 − 1/x ≤ ln x ≤ x − 1, with equality only at x = 1.

x \gt 1:\ \ \tfrac1x \le \tfrac1t \le 1 \text{ on } [1, x] @@ 1 ≤ t ≤ x
\tfrac{x - 1}{x} \le \ln x \le x - 1 @@ smaller-function-smaller-area, both sides; (x − 1)/x = 1 − 1/x
x \lt 1:\ \ 1 \le \tfrac1t \le \tfrac1x \text{ on } [x, 1] @@ x ≤ t ≤ 1
1 - x \le \textstyle\int_x^1 \tfrac{dt}{t} = -\ln x \le \tfrac{1 - x}{x} @@ smaller-function-smaller-area; the convention
\htmlClass{new}{1 - \tfrac1x \le \ln x \le x - 1} \quad \blacksquare @@ multiply by −1 (8d turns the order), the same two bounds; at x = 1 all three are 0

Equality away from 1 would need 1/t to equal one constant on a whole stretch, which it does not (log-rises's strict line, run on each bound). So the graph of ln lies strictly between the two curves except where all three meet, at 1.

17a4ln 2, squeezed

\tfrac12 \le \ln 2 \le 1 @@ log-bounds at x = 2
n = 10 \text{ equal pieces of } [1, 2]:\ \ L \approx 0.6688,\ \ U \approx 0.7188 @@ 15a: 1/t falls, so the least is at each right end
\ln 2 \approx 0.6931 @@ more pieces; the squeeze closes (continuous-is-integrable)
\ln \tfrac12 = -\textstyle\int_{1/2}^{1} \tfrac{dt}{t} @@ the convention; log-bounds gives −1 ≤ ln ½ ≤ −½

In 1649 a defender of an older work on the curve y = 1/x pointed something out. When the stretches along the axis grow in one fixed ratio, the areas over them grow by equal amounts. So the areas behave as the logarithms do in the first printed tables.

17a.4.5seamThe first logarithms were built in 1614 from two moving points, one steady and one slowing, as a device for turning products into sums. Two mathematicians found, thirty-five years later, that an area under the graph of 1/t does the same. The first table's numbers and the areas differ by a factor and a shift.
Which is the logarithm: the table that does the job, or the area that turns out to do it?

Who said it first

De Sarasa, defending Saint-Vincent’s work on the hyperbola, pointed out that when the stretches along the axis grow in one fixed ratio, the areas over them grow by equal amounts, so that the areas behave as the logarithms do in Napier’s tables.

Alphonse Antonio de Sarasa, Solutio problematis (1649); paraphrase

In 17a.4.5, the maker of the first tables is John Napier, and the two who found the hyperbola’s areas are Grégoire de Saint-Vincent and Alphonse Antonio de Sarasa.
