What Holds of the Set

Rung 2 gathered things into sets. This step carries the rules of deduction across to them: what holds of a set because of how it was made holds of each of its members.

What gathered a member into the set is true of the member. What is done to the whole set is done to each member.

2j1Grouped by a Shared Quality

A set made by a condition hands that condition to every member. 2d sifts the fliers out of a bowl of animals. Whatever is in the fliers flies, because flying is how it got in.

So a guess about the set is a guess about every member, made once. You never look at the members one by one.

2j2Done to the Whole, Done to Each

Something done to the whole set is done to every member. Move every bird in the cage to the garden, and this bird, which was in the cage, is in the garden. The move was made once, to the whole, and it reached each one.

This is 2b’s every at work: to speak of everything, speak of anything. A step taken for any member is taken for all of them.

Anexact, yet rigorous · the set that speaks for its members

A set carries its condition to every member. It looks at none of them, and it is right about each.

2j3Where It Stops

Not everything said of the set is said of its members. “The flock is large” does not make each bird large. A set’s size, or its shape, belongs to the set, and 2c keeps “is in” and “is part of” apart for this reason.

The rule carries what made the members members, and what was done to each. It does not carry what holds only of the whole.
