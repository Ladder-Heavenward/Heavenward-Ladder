Can a Qubit Be Protected Without Being Looked At?

Can a qubit be protected without being looked at? An ordinary computer guards its bits by keeping copies and taking a vote. A quantum computer cannot: a qubit cannot be copied, and looking at it to check destroys the very state it holds. Yet quantum computers do correct their errors. This page recalls why a qubit cannot be copied (41·phys), spreads one qubit over three as 44·comp spread a bit, asks only whether neighbours agree, fixes a flip without ever reading the qubit, and adds a second layer for the other kind of error.

Spread a|0⟩ + b|1⟩ into a|000⟩ + b|111⟩: not three copies, one state shared by three qubits. Then ask only whether qubits 1 and 2 agree, and whether 2 and 3 agree. Those two answers name which qubit flipped, while saying nothing about a and b. Flip it back. A second kind of error, a sign flip, needs the same trick turned sideways, nine qubits in all.

45comp1A Qubit Can’t Be Copied

Evita builds quantum computers. A qubit is an arrow of size one, a|0⟩ + b|1⟩, and reading it gives 0 with chance |a|² and 1 with chance |b|², after which the arrow is gone (41·phys). A copier that worked on every arrow would have to be linear and also square each input, which no linear map does.

\text{copy}(a|0\rangle + b|1\rangle) \text{ would be } (a|0\rangle + b|1\rangle)(a|0\rangle + b|1\rangle) @@ squares in a and b
\text{but a linear copier gives } a|00\rangle + b|11\rangle @@ from copying |0⟩ and |1⟩
\htmlClass{new}{\text{they differ unless } ab = 0:\ \text{no copier works on every qubit}} @@

From here on, on this page, a flip is the error that swaps |0⟩ and |1⟩ in one qubit, and a sign flip the error that changes b to −b.

45comp3Asking About Parity, Not Value

Reading any qubit would choose 0 or 1 and destroy a and b. Instead, measure only whether qubits 1 and 2 agree, and whether 2 and 3 agree. In both |000⟩ and |111⟩ every pair agrees, so the answer is the same for both parts, and the state is untouched.

\text{do 1 and 2 agree? do 2 and 3 agree?} @@ parities
\text{no error: yes, yes, for both } |000\rangle \text{ and } |111\rangle @@ 
\htmlClass{new}{\text{the answers carry no word about } a \text{ or } b} @@ so the state survives the asking

Parity-check technique: spread a qubit over several, and measure only whether neighbours agree; each pattern of answers names an error, and the same pattern comes from every part of the state, so the qubit itself is never read.

45comp4Fixing a Flip Without Reading the Bit

Suppose qubit 1 flips: a|100⟩ + b|011⟩. Now 1 and 2 disagree, 2 and 3 agree, in both parts alike.

1 and 2 agree?2 and 3 agree?flipped qubitfix
yesyesnonenothing
noyes1flip qubit 1
nono2flip qubit 2
yesno3flip qubit 3
\text{fails only if two or three flip: } 3p^2(1 - p) + p^3 = 3p^2 - 2p^3 @@ 
\htmlClass{new}{p = 0.01:\ \text{about } 0.0003} @@ thirty times safer than one bare qubit

The pattern of agreements names the flipped qubit, which is flipped back, and the qubit is restored without ever being read. On small quantum machines, an error deliberately applied to one of three qubits is named by the parity answers and undone, and the final qubit matches the start, as the table says.

45comp5Phase Flips Need a Second Layer

Qubits suffer a second error with no ordinary counterpart: a sign flip, b → −b. Every pair still agrees, so the three-qubit code cannot see it. But turned sideways, in the basis (|0⟩ ± |1⟩)/√2, a sign flip looks just like a flip.

\text{inner layer: each qubit spread over three against flips} @@ 
\text{outer layer: three such blocks, spread against sign flips in the sideways basis} @@ 
\htmlClass{new}{3 \times 3 = 9 \text{ qubits guard one against any single error}} @@

Guarding against both flips and sign flips needs two layers of parity checks, nine qubits for one; any error on one of them, of any kind, is named and fixed. Today’s machines use larger codes laid out on a grid, where each check involves only near neighbours, and keep a qubit alive longer than any of the qubits that hold it.

Accepted names

That no machine copies every qubit is the no-cloning theorem; the three-qubit code is the bit-flip code, the parity answers the syndrome, and the checks stabilizers. The nine-qubit code is the Shor code; grid codes are surface codes; the p below which codes help is the threshold.

Who said it first

The no-cloning theorem was shown by William Wootters and Wojciech Zurek, and by Dennis Dieks, in 1982; Peter Shor gave the nine-qubit code in 1995 (not yet revisited for the dates).
