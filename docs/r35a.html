35a · proof

Countable

Rung 4 counted a finite set by matching it with a number, and rung 3 noticed that the endless run can be matched with a part of itself that leaves something out. This step asks what matching says about endless sets. Two sets are the same size when they can be matched, and nothing else about them matters. A set is countable when it can be listed, one member at a time, with every member reached at some place. The even numbers can be listed, and so can the squares, though most numbers are neither. Then come sets that look far larger. The pairs of counting numbers fill a whole quarter of a grid, and a walk along its diagonals gives every pair a place. The fractions sit in every gap of the line, and they can be listed. The roots of all the polynomials with whole coefficients can be listed too, by giving each polynomial a height with only finitely many polynomials at each height. Every one of these lists is a matching with the counting numbers. The next step finds a set that no list can hold.

Listing a set is matching it with the counting numbers, once the repeats are struck out. Walk the grid of pairs along its diagonals and every pair gets one place. Give the fractions and the roots of polynomials a height, with finitely many at each height, and list them height by height.

35a1The same size, and countable

4k1 made matching exact, and 9c1 showed that a matching is a bijection. From here on, two sets A and B have the same size when they are matched, and |A| = |B| says so. The bars already name how far a number is from 0, and that meaning stays for numbers. With a set inside, the line |A| = |B| is a statement about matching and nothing more. For finite sets it is 4k’s count: |A| = |n| says A has n members. Rung 30’s sizes were lengths and chances, written m. This rung’s size is a count by matching, and the two can disagree: 30a2 gave the fractions length 0.

A list of a set A is a function L from ℕ onto A. Its entries L(0), L(1), L(2), … reach every member of A, and repeats are allowed. From here on, A is countable when it is empty or has a list. 30a used “countably many” for what a list can hold; this is that word made exact.

Thinning technique: a set with a list is finite or matched with ℕ.

L : \mathbb N \to A \text{ onto} @@ the list
K = \{n \in \mathbb N : L(n) \ne L(j) \text{ for every } j < n\} @@ keep the places where a member first appears (a sift, 2d)
L \text{ restricted to } K \text{ is a matching between } K \text{ and } A @@ each member’s places form a set of numbers with a member; its least place (7·cb4) is its one place in K
K \text{ finite} \Rightarrow A \text{ finite} @@ chain for matchings (4k1)
K \text{ not finite:}\ \ k_0 = \min K,\ \ k_{i+1} = \min\{k \in K : k > k_i\} @@ there is always a member above kᵢ, or K would be finite; each min by least-member-for-any-set (7·cb4)
i \mapsto k_i \text{ is a matching between } \mathbb N \text{ and } K @@ it climbs, so it is one-to-one; a member of K missed would sit below some kᵢ₊₁ and above kᵢ
\htmlClass{new}{A \text{ finite, or } |A| = |\mathbb N|} \quad \blacksquare @@ chain for matchings, twice

So the even numbers, the squares and the primes all have the size of ℕ. Each is a part of ℕ that is not finite, and listing itself in order is its list. 3c9 called a collection endless when it is matched with a part of itself that leaves something out, and 9c.4.4 asked whether there are as many squares as numbers. By matching there are, though the squares leave out almost every number. For endless sets, leaving members out need not make a set smaller.

35a2Pairs of numbers

Lay the pairs (m, n) of ℕ × ℕ out as a grid, m across and n up. A list that runs along the first row never reaches the second. Walk the short diagonals instead. Diagonal d holds the pairs with m + n = d, and there are d + 1 of them. Before it come diagonals 0 to d − 1, with 1 + 2 + ⋯ + d pairs in all. Write T(d) = 0 + 1 + ⋯ + d.

Pair-listing technique: the pairs of counting numbers are matched with ℕ by p(m, n) = (m + n)(m + n + 1)/2 + n.

d = m + n,\ \ T(d) = \tfrac{d(d+1)}{2} @@ the doubled-sum technique (4k8)
\text{diagonal } d \text{ holds the } d + 1 \text{ pairs } (d - n, n),\ n = 0, \ldots, d @@ m is fixed once d and n are
p \text{ sends diagonal } d \text{ onto } T(d), T(d) + 1, \ldots, T(d) + d,\ \text{one each} @@ p(d − n, n) = T(d) + n
T(d) + d + 1 = T(d + 1) @@ sum-one-more (4k7)
\text{the blocks } T(d), \ldots, T(d + 1) - 1 \text{ are separate and fill } \mathbb N @@ T(0) = 0 and T climbs by d + 1 at each step, so each number lies in exactly one block
\htmlClass{new}{p : \mathbb N \times \mathbb N \to \mathbb N \text{ is a matching}} \quad \blacksquare @@ one-to-one and onto on each block, and the blocks part ℕ

So (0, 0) is at place 0, (1, 0) at 1, (0, 1) at 2, (2, 0) at 3, and (2, 1) at T(3) + 1 = 7. A quarter of a grid, endless both ways, has the size of one of its rows.

Countable-union technique: if A₀, A₁, A₂, … are countably many sets, each with a member and each given a list Lₘ, their union has a list. Send the place k to Lₘ(n), where p(m, n) = k. Every member of the union is some Lₘ(n), so it is reached. The lists must be given. If each Aₘ is only known to have a list, picking one list for each m is choice, countably often (6b), as 30a2 spent it to pick covers.

35a3Integers and fractions

30a2 listed the fractions by levels. The difference here is that the list becomes a matching. The integers come first: send 0 to 0, then 1 to 1, −1 to 2, 2 to 3, −2 to 4, and on. In marks, z ↦ 2z − 1 for z > 0 and z ↦ −2z for z ≤ 0. It is one-to-one, and onto ℕ: the odd numbers come from the positive integers, the even ones from the rest.

Into-ℕ technique: a set that goes one-to-one into ℕ is countable. Its image is a part of ℕ. That part lists itself in order, and the thinning technique makes it finite or matched with ℕ. Run the one-to-one map backwards on its image (9d), and chain the matchings.

r = \tfrac{z}{q} \text{ in lowest terms},\ z \in \mathbb Z,\ q \ge 1 @@ each fraction has one such form (5b, 4j)
r \mapsto (\zeta(z), q) \in \mathbb N \times \mathbb N @@ ζ is the matching of ℤ with ℕ above
r \mapsto p(\zeta(z), q) \text{ is one-to-one into } \mathbb N @@ a chain of one-to-ones (9c3): the lowest form, ζ, then the pair-listing technique
\mathbb Q \text{ is not finite} @@ it holds every integer
\htmlClass{new}{|\mathbb Q| = |\mathbb Z| = |\mathbb N|} \quad \blacksquare @@ into-ℕ and thinning

The same chain lists the points of the plane with two fraction coordinates: pairs of fractions go one-to-one into pairs of numbers, and the pairs of numbers into ℕ. The fractions are dense, and in order they have no next member at all. Matching does not care about order.

35a4The algebraic reals

23g3 called a real algebraic when it is a root of a polynomial with whole coefficients, not all 0. Give the polynomial uₖxᵏ + ⋯ + u₁x + u₀, with uₖ ≠ 0, the height k + |uₖ| + ⋯ + |u₀|. A polynomial of height h has degree at most h, and each coefficient lies between −h and h. So only finitely many polynomials have height h.

Algebraic-list technique: the algebraic reals can be listed, so they are matched with ℕ.

\text{height } h:\ \text{at most } (2h + 1)^{h + 1} \text{ polynomials} @@ at most h + 1 coefficients, each one of 2h + 1 integers (stages-multiply, 4k6)
\text{each has at most } k \le h \text{ zeros} @@ the at-most-n-zeros technique (9g)
Z_h = \text{the zeros of the polynomials of height } h \text{ is finite} @@ finitely many finite sets, merged (separate piles, 4k5, as an at most)
\text{list } Z_1, \text{ then } Z_2, \text{ then } Z_3, \ldots,\ \text{each in increasing order} @@ any two reals compare (8b), so a finite set of reals has an increasing order with no picking
\text{every algebraic real is in some } Z_h @@ its polynomial has a height
\htmlClass{new}{\text{the algebraic reals have a list}} \quad \blacksquare @@ not finite: every integer is algebraic; so matched with ℕ, by thinning

Height 2 gives only 0, from x and −x. Height 3 adds −1 and 1. Height 4 adds −2, −1/2, 1/2 and 2. At height 5 come x² − 2 and x² − x − 1, and with them ±√2 and the two roots (1 ± √5)/2. Every root of every polynomial with whole coefficients turns up at some finite height. Most of these numbers have no name, and they still get a place.

The accepted names

Sets of the same size are equinumerous, or have the same cardinality; |A| is the cardinality of A. A set matched with ℕ is countably infinite, or denumerable; “countable” sometimes means only that. The pair-listing technique is the Cantor pairing function. The height of a polynomial is Cantor’s height. The result of 35a4 is that the algebraic numbers are countable, and the countable-union technique is the theorem that a countable union of countable sets is countable, which uses countable choice.

Who said it first

Galileo noticed in Two New Sciences (1638) that the squares can be paired with the numbers, and concluded that “equal”, “greater” and “less” do not apply to endless quantities. Bolzano’s Paradoxes of the Infinite (1851) took the pairing seriously. Dedekind made the matching with a part of itself the definition of an endless set (1888). Georg Cantor proved in 1874 that the algebraic numbers can be listed, in the same short paper that showed the line cannot be, and wrote the diagonal pairing of ℕ × ℕ in 1878. Without choice, a union of countably many pairs need not be countable; the sock world of 6d is the model.

A proof that is not allowed

“List ℚ in order of size, from the least fraction up.” Not allowed: there is no least fraction, and between any two there is another (8e), so “the next one” names nothing. The list of 35a3 is not in order of size, and does not need to be.
