24i · technique

Rate Statements Turned Into Algebra

A rate statement asks for a whole function at once. Multiply the unknown by a fading e^(−st) and add up all of it, from 0 to the far end, by 16i’s integrals to infinity: the result is a function of a new letter s. Under that change a slope becomes a multiplication by s, less the starting value, so a rate statement with its start becomes an equation of plain algebra. This step defines the change, finds it for the functions the model equations are made of, proves the slope rule by 16e’s parts, and solves 24h’s first model equation a second way, with its start built in.

F(s) = ∫₀^∞ e^(−st) f(t) dt. It sends 1 to 1/s and e^(at) to 1/(s − a) for s > a. A slope becomes s F(s) − f(0), a second slope s²F(s) − s f(0) − f′(0). So a rate statement with constant numbers in front, starts included, becomes an equation in F that is solved by dividing.

24i1A Fading Weight, Added to the Far End

Fade technique: for a function f on t ≥ 0 that grows no faster than some e^(ct), its transform F(s) = ∫₀^∞ e^(−st) f(t) dt exists for every s > c.

|f(t)| \le M e^{ct} \text{ for all } t \ge 0 @@ the growth bound
|e^{-st} f(t)| \le M e^{-(s-c)t} @@ the fade beats the growth when s > c
\int_0^\infty M e^{-(s-c)t}\,dt = \dfrac{M}{s-c} @@ an integral to infinity that settles (16i)
\htmlClass{new}{\text{the transform settles, by comparison}} \quad \blacksquare @@ a smaller positive integrand settles too (16i)

From here on, the transform of f is written F, or 𝓛f, and s is its letter. Every function of 24h has such a bound, so every one has a transform.

24i2The Transform of a Growth

\mathcal{L}\,e^{at} = \int_0^\infty e^{-(s-a)t}\,dt @@ the two exponents add (17e)
= \Big[\dfrac{-e^{-(s-a)t}}{s-a}\Big]_0^\infty = \dfrac{1}{s-a} @@ s > a, so the top end gives 0
a = 0:\ \mathcal{L}\,1 = \dfrac1s @@ the flat line
\htmlClass{new}{\mathcal{L}(\alpha f + \beta g) = \alpha F + \beta G} \quad \blacksquare @@ integrals add and scale (15e)

Growth-entry technique: 𝓛e^(at) = 1/(s − a) for s > a, and the transform of a sum of multiples is the same sum of multiples of transforms.

24i3A Slope Becomes a Multiplication

Slope-to-times technique: if f and f′ grow no faster than e^(ct), then for s > c, 𝓛f′ = s F(s) − f(0); and 𝓛f″ = s²F(s) − s f(0) − f′(0).

\int_0^\infty e^{-st} f^{\prime}\,dt = \big[e^{-st} f\big]_0^\infty + s\int_0^\infty e^{-st} f\,dt @@ parts (16e), u = e^(−st)
e^{-st} f(t) \to 0 \text{ as } t \to \infty @@ the bound, s > c
\mathcal{L}f^{\prime} = -f(0) + sF(s) @@ the bracket at 0 gives −f(0)
\htmlClass{new}{\mathcal{L}f^{\prime\prime} = s\,\mathcal{L}f^{\prime} - f^{\prime}(0) = s^2F - s f(0) - f^{\prime}(0)} \quad \blacksquare @@ the rule applied to f′

The starting values enter the transform on their own. That is the change’s gift: no constants to fit afterwards.

24i4The First Model Equation, Again

sY - y_0 = kY - \dfrac{kA}{s} @@ transform both sides; 𝓛A = A/s
Y(s - k) = y_0 - \dfrac{kA}{s} @@ collect Y: algebra only
Y = \dfrac{y_0}{s-k} - \dfrac{kA}{s(s-k)} = \dfrac{y_0 - A}{s-k} + \dfrac{A}{s} @@ split: −k/(s(s − k)) = 1/s − 1/(s − k)
\htmlClass{new}{y = A + (y_0 - A)e^{kt}} @@ read each piece back from the table, as 24h1 found

Reading back assumed that only one function has a given transform. That is true for the functions on this rung, and 24j proves the part it needs.

The cellar · there if you want it

Accepted names

The change is the Laplace transform; the growth bound makes f of exponential order; the slope rule is the differentiation theorem. Engineers write the letter s as a complex frequency and call F the function in the s-domain.

Who said it first

Pierre-Simon Laplace used such integrals for chances in 1812. Oliver Heaviside solved circuit equations by turning slopes into multiplications in the 1880s and 1890s, without proof; Thomas Bromwich and Gustav Doetsch set the method on Laplace’s integral in the early twentieth century.
