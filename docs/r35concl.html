35·∎ · conclusion

Infinities come in sizes

Matching is size. The pairs, the fractions and the algebraic reals can be listed, and the line cannot. The parts of every set outrun it. Two one-way matchings make a matching, sizes add and multiply, and the line has the size of the parts of the counting numbers. Whether a size lies between is left open by the axioms.

The conclusion · the rung's claim, in full, and its proof

This page opens once every question on 35f is there a size in between? is ticked. The claim below is proved from the steps of this rung, so it waits for them.

What the rung set out to show

The survey of rung 35 asked what matching says about endless sets. Two sets are the same size when they can be matched; the counting numbers cannot be matched with the line, and every set is smaller than its set of parts. The price is that the rung’s own question, whether a size lies between, is one the axioms leave open.

35a listed the pairs, the fractions and the algebraic reals. 35b showed the line has no list, and so found transcendental and unnamed reals. 35c showed the parts outrun the members of every set. 35d made two one-way matchings into one, and compared any two sizes with choice. 35e did the arithmetic of sizes and found the line’s. 35f asked for a size in between, and named the two results that leave it open. This page puts the claim together.

The claim, in full

A set with a list is finite or matched with ℕ. ℕ × ℕ, ℤ, ℚ and the algebraic reals are matched with ℕ. No list of reals holds every real, so the line is not countable, and some real is transcendental. For every set A, no function from A reaches every part of A, so |A| < |𝒫(A)| and there is no largest size.

If A goes one-to-one into B and B into A, then A and B are matched; with choice, any two sets compare. ℵ₀ + ℵ₀ = ℵ₀ · ℵ₀ = ℵ₀, and |ℝ| = |ℝ × ℝ| = |𝒫(ℕ)| = 2^ℵ₀. Different points of the run past ω can share the size ℵ₀. Every set of reals that holds an interval has the size of the line, and with choice ℵ₀ < ℵ₁ ≤ 2^ℵ₀. Whether 2^ℵ₀ = ℵ₁ is neither proved nor refuted by the axioms.

So the rung’s claim holds: infinities come in sizes, matching tells them apart, and the parts of every set outrun it. Two things are held in trust, both on 35f: the first point of the run that cannot be listed, with the sizes of its parts; and the results of 1938 and 1963, named and not proved.
