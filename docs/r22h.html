22h · technique

Sequences by hand

Most sequences you meet are made from functions you already know, so the tools for limits from the tenth rung work on them almost unchanged. A few sequences come up so often that it pays to know where they head by heart: a fraction raised to higher and higher powers, the nth root of n, a power of n against a power of a fixed number. And some sequences are made by feeding each answer back into a rule. Those settle when the rule pulls neighbours closer together, and the place they settle is a number the rule leaves alone.

Limits of functions far out give limits of sequences. A handful of standard sequences are worth knowing by heart. A rule fed its own answers settles when it pulls neighbours closer, and it settles at a point the rule does not move.

22h1From functions to sequences

Far-out technique for sequences: if f(x) heads to L as x heads past every bound, then f(n) heads to L. The window "x > M" contains every n > M. So 10c's sum, product and quotient techniques, and 10f's factor-and-cancel and conjugate, all work on sequences. And 11e: if uₙ heads to a and g is continuous at a, then g(uₙ) heads to g(a).

\tfrac{3n^2 + 1}{n^2 - 5} = \tfrac{3 + 1/n^2}{1 - 5/n^2} @@ divide top and bottom by n² (10f)
\to \tfrac{3 + 0}{1 - 0} = 3 @@ 1/n² heads to 0; the quotient technique (10c)
\sqrt{n+1} - \sqrt{n} = \tfrac{1}{\sqrt{n+1} + \sqrt{n}} @@ the conjugate (10f)
\htmlClass{new}{\sqrt{n+1} - \sqrt{n} \to 0} \quad \blacksquare @@ the bottom passes every bound

The far-out technique only runs one way. f(n) can settle while f(x) does not: sin(πx) heads nowhere as x grows, but sin(πn) is 0 for every n.

22h2Sequences to know by heart

Standard-sequences technique: for |r| < 1, rⁿ → 0; n^(1/n) → 1; for a > 0, a^(1/n) → 1; for any power k and |r| < 1, nᵏrⁿ → 0; for any x, xⁿ/n! → 0. The first is 15i2. The rest are below.

n^{1/n} = 1 + h_n,\ h_n \ge 0 @@ n ≥ 1, so its root is at least 1
n = (1 + h_n)^n \ge \tfrac{n(n-1)}{2}h_n^2 @@ one piece of the two-term-power expansion (4k); the rest are not negative
0 \le h_n \le \sqrt{\tfrac{2}{n-1}} @@ divide and take roots, for n ≥ 2
\htmlClass{new}{n^{1/n} \to 1} \quad \blacksquare @@ the squeeze (10d)
  
\tfrac{(n+1)^k |r|^{n+1}}{n^k |r|^n} = (1 + \tfrac1n)^k |r| \to |r| < 1 @@ the ratio of neighbours
\tfrac{|x|^{n+1}/(n+1)!}{|x|^n/n!} = \tfrac{|x|}{n+1} \to 0 @@ the same for xⁿ/n!
\htmlClass{new}{n^k r^n \to 0,\ \ x^n/n! \to 0} \quad \blacksquare @@ ratio test (22e2): the sums settle, so their pieces head to 0 (22d2)

Read together, these say powers of n lose to powers of a fixed number, and both lose to n!. 22k makes that a ranking.

22h3Rules fed their own answers

Pull-together technique: if g sends an interval I into itself, and |g(x) − g(y)| ≤ k|x − y| on I for one k < 1, then from any start in I, sₙ₊₁ = g(sₙ) settles, at the only L in I with g(L) = L. By 14c it is enough that |g'| ≤ k on I.

|s_{n+1} - s_n| \le k|s_n - s_{n-1}| \le \cdots \le k^n|s_1 - s_0| @@ apply the pull n times
|s_m - s_n| \le (k^n + \cdots + k^{m-1})|s_1 - s_0| \le \tfrac{k^n}{1-k}|s_1 - s_0| @@ m > n: add the steps; the geometric sum (15i)
s_n \text{ crowds, so settles at some } L @@ kⁿ → 0; the crowd technique (22c2)
L = \lim g(s_n) = g(L) @@ g is continuous, since it pulls (11e)
g(L') = L' \Rightarrow |L - L'| \le k|L - L'| \Rightarrow L = L' @@ k < 1
\htmlClass{new}{s_n \to L,\ g(L) = L,\ \text{and } L \text{ is the only one}} \quad \blacksquare @@ the lines above

Two rules to try by hand. sₙ₊₁ = (sₙ + 2/sₙ)/2 sends [1, 2] into itself with |g'| ≤ ½, so it settles at the L with L = (L + 2/L)/2, which is √2; from s₀ = 1 the third step is right to five places. And sₙ₊₁ = cos sₙ sends [0, 1] into itself with |g'| = |sin x| ≤ sin 1 < 0.85, so it settles at the one x with cos x = x, about 0.7391. A calculator pressed over and over finds it.

22h4Where a rule does not settle

A point g leaves alone is not always a place the sequence settles. Near such a point L, the slope g'(L) decides. If |g'(L)| < 1, starts near L are pulled in. If |g'(L)| > 1, they are pushed away.

L = 3.2L(1 - L) \Rightarrow L = 0 \text{ or } L = 0.6875 @@ the points g leaves alone
g'(x) = 3.2 - 6.4x,\ \ g'(0.6875) = -1.2 @@ the slope there is more than 1 in size: it pushes
0.5,\ 0.8,\ 0.512,\ 0.7995,\ 0.5129,\ 0.7995,\ 0.5130,\ \ldots @@ the run, to four places
\htmlClass{new}{\text{two threads settle, near } 0.5130 \text{ and } 0.7995; \text{ the sequence wanders}} \quad \blacksquare @@ two threads with different limits (22b3)

Turn the 3.2 up and the cycle of two splits into four, then eight, and past about 3.57 the run never repeats at all. A rule as short as this one can wander forever without passing any ceiling.

The accepted names

The pull-together technique is the contraction mapping principle (Banach fixed-point theorem, here on an interval). A point g leaves alone is a fixed point; attracting when |g′(L)| < 1, repelling when it is more than 1. The rule 3.2s(1 − s) is the logistic map; the splitting into 2, 4, 8 is period doubling, and the run that never repeats is called chaos. The square-root rule is the Babylonian method, a case of Newton's method.

Who said it first

The square-root rule is on Old Babylonian tablets and was written out by Heron of Alexandria. Stefan Banach proved the pull-together principle in full in 1922. Robert May drew attention to the logistic map in 1976, and Mitchell Feigenbaum found in 1975 that the doublings come at a rate that is the same for a whole family of rules.
