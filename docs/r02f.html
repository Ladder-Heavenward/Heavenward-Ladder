2f · support

Foundation

Every set this rung has built was built in stages. It started from the empty set, by gathering and merging and sifting and taking subsets, each new set made from sets already in hand. Nothing built that way is a member of itself, or a member of a member of itself, or the start of a chain of memberships that runs down forever. But nothing so far forbids such things. The axioms laid down would all be kept in a world that contained a set whose only member was itself. This step lays down an axiom that is false in such worlds, in words and in marks. Its form never splits a statement into “so or not so”: a condition that passes from the members of a set to the set itself is so of every set. From it the step proves the techniques the ladder needs. No set is a member of itself, no set is its own gathering, membership never loops, and there is no set of all sets. The last of these, no set of all sets, it proves again by another route. The earlier proof, the outsider sift (Russell's), needs no foundation at all, and the difference between the proofs is worth seeing. Last, it says why the axiom's more familiar form, which speaks of a member at the bottom, has to wait.

A condition that climbs from the members of a set to the set is so of every set. To forbid a loop, name the condition “in no such loop”, show that it climbs, and carry foundation through: it is so of every set.

What this stands on, and where it goes

Stands on 1b (refute), 1d (prove an if), 1e (∀, ∃, speak of everything, use an every, use a some), 2a (same-members), 2b (conditions and φ, sift, ∅, the outsider-set technique) and 2c (gather). Rung 3 leans on “a set is not its own gathering”; rung 4 leans on foundation, through “membership never loops”, to show that its step never lands where it has been; the tech “show it does not follow by building a world where it fails” returns on rung 3 and rung 6; the form of foundation with a member at the bottom waits for rung 7.

2f1The question the tools leave open

Stands on 2c (gather, merge), 2b (sift) and 2d (𝒫).

Could a set be a member of itself? Write u for it: u ∈ u. The tools never make one. Gathering builds {u, b} from u and b you already have, so {u, b} is newer than its members. Merge and sift and power set likewise take sets in hand and give a set back. Everything the rung has built sits in a stage above the stages of its members, with ∅ at the bottom.

But “the tools never make one” is not a proof that there is none. The axioms so far say what sets exist and when they are the same. They do not say that every set was made by the tools.

2f2The looped world

Stands on 2f1 (what the tools leave open) and 2a7 (the same-members axiom).

Picture a world containing an extra set, call it Ω, whose only member is Ω itself. Such a world would keep every axiom laid down so far. Ω = {Ω} is a perfectly good listing, the same-members axiom is content, and sifting and gathering inside such a world go on as before.

Exactly such a world was built late in the century before this one, and shown to be as consistent as the ordinary one. Call it the looped world. So nothing laid down so far can rule Ω out. If we want membership never to loop, we must say so, as an axiom.

From here on, Ω (the Greek letter omega, in its capital form) names that set of the looped world, whose only member is itself, wherever that world is spoken of. It is a name like any other letter.

Why want such an axiom? Because the ladder's objects, from rung 3 onward, are built in stages, and proofs about them climb the stages: what is so of the members is so of the set made from them. They need to know that the climbing reaches every set. No set may be left over, perched on a loop or on a chain that never stops going down. The claim that the climbing reaches every set is the axiom of foundation. It is also called the axiom of regularity.

2f3Passing up

Stands on 2b (conditions, φ) and 1h (vacuously true).

If a condition passes to a set whenever it is so of every member of that set, it is so of every set.

Take a condition φ, a statement with a gap in 2b's sense.

Say that φ passes up when, for any set u, if every member of u meets φ, then u meets φ too.

Example: for φ “x ∉ x”, passing up means: if no member of u is in itself, then u is not in itself.

Foundation says: a condition that passes up is so of every set, with none left over.

2f4Watching the climb

Stands on 2f3 (passing up).

Why lay it down? Here is the picture behind it, as motivation and not as proof: the axiom is laid down, never proved. Watch a condition that passes up climb. The empty set has no members, so “every member of ∅ meets φ” is true vacuously (1h's word), and since φ passes up, φ(∅) is so. Now {∅}: its only member meets φ, so {∅} does. Then {∅, {∅}}, and every set built from those, stage by stage. Each set the tools make is made from sets already reached, so it is reached too. A set the climb never reached would have to have a member never reached, and that member another, and so on down without stopping. That is a loop, or a chain that runs down forever. Foundation says there is no such set. Every set is reached.

A cat, which is not a set, has no members either, so in the climb it stands where ∅ stands.

Notice what the axiom never says. It never says of a statement that it is so or not so, and it names no member of any set. It is a statement about every set, and the proofs below are all of the same shape: name a condition, show that it passes up, and carry the axiom through.

2f5The axiom, in marks

Stands on 2f3 (passing up), 1e (∀) and 1d (if).

From here on, “φ passes up” means:

Read it “whenever every member of u meets φ, u meets φ”.

Read it: if φ passes up, then φ is so of every set. Like the sift axiom, it is a pattern, an axiom for each condition. The condition may mention other things you have, and may have its own every or some inside it.

2f6Using it: the hypothesis about the members

Stands on 2f5 (the axiom) and 1d (prove an if).

To use it, begin by naming the condition. Then prove that it passes up, by rung 1's shapes.

Write “let u be anything” and “suppose ∀x (x ∈ u ⇒ φ(x))”, and work inside until you reach φ(u). Then prove an if, and speak of everything.

Call the supposed line the hypothesis about the members. It speaks of the members of u, never of u itself.

Then carry the foundation axiom through, and use the every on whatever set you like.

There is no separate start. At ∅ the hypothesis about the members says nothing, so the passing up must prove φ(∅) with nothing to lean on. A proof that passing up is true at every u covers ∅ along with the rest.

2f7No set is a member of itself

Stands on 2f6 (using the axiom) and 1b (refute).

No-self-membership technique: no set is a member of itself.

The sketch. The condition is x ∉ x. If u were in u, u would be one of its own members, so the hypothesis about the members would say u ∉ u.

In order. Name the condition: x ∉ x. Let u be anything, and suppose every member of u is not a member of itself. Suppose, aiming to refute, that u ∈ u. Then u is one of u’s members, so by the hypothesis about the members, u ∉ u. Clash.

So drop the supposition: u is not a member of itself. That is true for any set u: if every member of u is not a member of itself, then u is not either. So the condition passes up. Carry the foundation axiom through: no set is a member of itself.

2f8What no-self-membership settles

Stands on 2f7 (no-self-membership) and 2b (the outsider sift).

Look at where the hypothesis about the members was used: with u itself, which is a member of u only inside the supposition being refuted. The passing up is pure rung 1; only the last line leans on the axiom. Nothing about u was used, so no set is a member of itself. In particular, sifting any set by “x ∈ x” now gives ∅: nothing passes. 2f9A set is not its own gathering

Stands on 2f7 (no-self-membership) and 2c1 (gather).

Rung 3 will need this one by name. Not-its-own-gathering technique: no set is its own gathering. In marks, u ≠ {u}. If u were {u}, then since u ∈ {u}, u would be a member of itself.

In order: u is in {u}, by the listing. Suppose u = {u}, until we drop it. Write u where {u} stood: u is in u. That clashes with the no-self-membership technique. Drop the supposition: u is not {u}.

For the empty set the not-its-own-gathering technique needed no foundation: ∅ ≠ {∅} by the same-members axiom backwards, since {∅} has a member and ∅ has none. For a set with members, the proof needs foundation. The looped world's Ω = {Ω} is exactly the counterexample that world allows.

2f10Membership does not loop

Stands on 2f6 (using the axiom) and 1e (an every inside a condition).

No-loop technique: no two sets are each a member of the other. The condition to climb is “x is in no such loop, with any partner”: ∀y ¬(x ∈ y ∧ y ∈ x). Suppose every member of u meets it, and suppose a loop u ∈ b ∈ u. Then b is a member of u, so b is in no loop with any partner, and in particular not with u. But b ∈ u and u ∈ b is exactly such a loop.

Here it is in order. Name the condition: x is in no loop with any partner. Let u be anything, and suppose every member of u meets the condition. Let b be anything. Suppose u ∈ b and b ∈ u, until we drop it.

b is in u, so b meets the condition: b is in no loop with any partner. Take u as the partner: not both b ∈ u and u ∈ b. But that is what we supposed, turned about. Clash. Drop the supposition: u and b are not in a loop.

b was anything, so u meets the condition. So the condition passes up. Carry the foundation axiom through: every set meets it. Use that every on u: u is in no loop with any partner. Use the every inside on b: not both u ∈ b and b ∈ u.

2f11Why every partner

Stands on 2f10 (no-loop).

Why the every over y inside the condition? Because the hypothesis about the members is used with b. What the hypothesis must say of b is that b is in no loop with u. But u is the set the condition was used on, not a fixed partner, so the partner must be free. The partner changes when the hypothesis is used, so the condition must speak of every partner.

A loop through more links is refuted the same way. Take u ∈ b ∈ c ∈ u. The condition is “x is in no loop of that shape”, with an every for each of the other links: ∀y ∀z ¬(x ∈ y ∧ y ∈ z ∧ z ∈ x). Use the hypothesis about the members with c, the link just inside u. That turns the loop round to start at c, and c ∈ u ∈ b ∈ c clashes with it.

A chain running down forever, … ∈ c ∈ b ∈ u, is refuted the same way once such a chain can be written as an object: the condition is “no chain runs down forever from x”. That waits for 4c, which writes a chain as an object, and 7·cb4 closes it. What proofs need now is the axiom as written, and the techniques no-self-membership, not-its-own-gathering and no-loop.

A set from which no chain of membership runs down forever has the accepted name well-founded.

2f12No set of all sets, by the outsider sift

Stands on 2b (the outsider sift) and 1e (use a some).

No-set-of-all-sets technique: no set has everything as a member. Suppose a set v with everything in it: ∀x (x ∈ v). With foundation the refutation is immediate: v is a thing, so v ∈ v, against the no-self-membership technique. But 2b already refuted v without foundation, by sifting the outsider condition inside v, and the earlier proof is the deeper one. Here it is in words, as the slides of 2b promised. 2c held “there is no set of everything” in trust, and with this argument that flag is closed.

Suppose some set has everything as a member, until we drop it. Call it v. Sift v by the outsider condition: r is the set of members of v that are not members of themselves. The sift is legal, since v is a set in hand.

Suppose r ∈ r, until we drop it. Then r passes the sift, so r ∉ r. Clash. Drop it: r ∉ r. But r is in v, since everything is. So r is in v and not in itself, and it passes the sift: r ∈ r. Clash again.

That clash does not mention v, so the some closes. Drop the first supposition: no set has everything as a member.

Only the word everything holds everything. No set holds all sets: sift it for sets not members of themselves, and it breaks. And “everything is everything” is true, but leaves no room to make guesses in.

2f13No set of all sets, by foundation, and what that shows

Stands on 2f12 and 2f7 (no-self-membership).

And by foundation. Suppose some set has everything as a member. Call it v. v is a thing, so v is in v. The no-self-membership technique says v is not in v. Clash. So no set has everything as a member.

The slides · no set of all sets, by foundation · ← → keys work

Now set them side by side. The proof by foundation is shorter and leans on an axiom. The proof by the outsider sift leans only on the sift axiom and the techs of rung 1. So “no set of all sets” does not need foundation.

Does “no set of all sets” follow from foundation? Yes, at once, as the second argument shows. Does foundation follow from it? No, and here is how to show that: build a world where “no set of all sets” is true and foundation is false.

The looped world is such a world. It has Ω = {Ω}, so foundation fails there: the condition x ∉ x passes up, by the techs alone, as no-self-membership's argument showed, and Ω breaks it. And it still has no set of all sets, because the outsider sift works there just as here.

By foundation no set is self-membered; “no set of all sets” speaks only of the universal one. Foundation is the stronger, and they come apart.

A consequence to carry: there is no “everything”. The collection of all sets is a way of talking, never a set, so it may not be sifted from and has no complement. Whenever a later page says “the set of all x such that…”, it will name the set it sifts from, or you will be able to supply it.

2f14The form with a bottom, and why it waits

Stands on 2f5 (the axiom), 1g (settled) and 1b (the withheld ¬¬P to P).

Most books state foundation another way, a way later given the name “Fundierung”, grounding: every set that has a member has a member that shares no member with it. Such a member is a bottom of the set: look inside it and you find nothing of the set.

Example: in {∅, {∅}}, ∅ is a bottom: nothing of the set is inside it. {∅} is not a bottom: ∅ is in {∅} and in the set.

Once every statement is true or false, the forms say the same thing. On this ladder that is not yet so. Rung 1 left out the tech from ¬¬P to P on purpose. The form with a bottom, laid down as an axiom, would bring it back by the side door. From it, for any statement P whatever, a short argument proves P ∨ ¬P, which rung 1's techs never give.

A bottom is a member picked out of a set, and picking it out is where the “so or not so” hides. So the ladder lays down the climbing form, from which everything this rung and the next ones need can be proved. The form with a bottom waits for rung 7.

For a world you can list, nothing has to wait. In the picture the memberships among the listed sets are given, line by line, so each one is settled in 1g's word. A bottom of a listed set can be found by looking. Start at any member, and if some member of the set is inside it, step to that one. With no loops, the steps run out at a bottom. Set theorists who keep rung 1's gap, among them the builder of the looped world, take foundation in the climbing form this step uses.

2f16Running it backwards

Stands on 2f1 to 2f14.

Wanting u ∉ u, you cite the no-self-membership technique. Wanting u ≠ {u}, the not-its-own-gathering technique. Wanting ¬(u ∈ b ∧ b ∈ u), the no-loop technique.

Wanting something new of the same kind, say that no u has u ∈ b ∈ c ∈ u, the skeleton is fixed. Name the condition: x is in no such loop, with an every for each other link. Let u be anything, and suppose the hypothesis about the members. Suppose the loop, and use the hypothesis with the link just inside u. Clash, refute, close, and carry the foundation axiom through.

The art is the condition. Choose it so that what the hypothesis says of a member is exactly what the refutation needs. When the hypothesis is used with a different set from the one the condition was named for, the condition needs an every over the part that changes.

Wanting to show that some principle does not follow from others, build a world where the others are true and it is false. That is a shape of argument, not a column, and the ladder will ask it of you again. Found upward; written downward.

Who said it first

The looped world is Peter Aczel’s (1988), built on his anti-foundation axiom. The form of foundation with a bottom is John von Neumann’s, later taken up by Ernst Zermelo under the name “Fundierung”. Among the set theorists who keep rung 1’s gap and take foundation in the climbing form are John Myhill and Aczel. The outsider sift is Bertrand Russell’s. The first to sort sets by whether their chains of membership end was Dmitry Mirimanoff:

Mirimanoff, in 1917, sorted sets into two kinds. In an ordinary set every chain of “is a member of”, followed downward, comes to an end. A set with a chain that never ends he called extraordinary, and he asked whether set theory should allow it.

Mirimanoff, “Les antinomies de Russell et de Burali-Forti et le problème fondamental de la théorie des ensembles” (1917); paraphrase

Accepted names

A set from which no chain of membership runs down forever is called well-founded.
