38·cb29 · newsflash for 29

A true sentence arithmetic cannot reach

Rung twenty nine played a game with ordinary numbers. Write a number in a base, read the digits in the next base up, and take one away. The number climbs for a long time, and yet the game always ends, because a label written with the run past the endless falls at every turn. That page played the game with two digits, and stated the full game without proving it: there every exponent is written in the base too, and every exponent of those, all the way down. It also said that the full game’s ending, a statement about counting numbers only, cannot be reached by induction over the counting numbers. Both can be said properly now. The full game gets labels that are towers of the run past the endless, the labels fall at every turn, and so every full game ends. That is a true statement of arithmetic. And it is not reached by the axioms of arithmetic: from it, those axioms would reach their own freedom from clash, which the last steps showed they cannot. Unlike the unreached statement of 38i, this one is not about proofs at all.

Write a number in full base b, bump every b to b + 1 and take one away. The label, every b read as ω, falls at every turn, so every full game ends. That is true, and the axioms of arithmetic do not reach it.

38·cb29.1The full game

Write n in full base b: as a sum of powers of b with counts below b, then each exponent the same way, and each exponent of those, until only numbers below b are left. In full base 2, 266 = 2^(2^(2 + 1)) + 2^(2 + 1) + 2. A bump puts b + 1 in place of every b, at every level. The full game from n starts in base 2: bump, take 1 away, write the result in full base 3, bump, take 1 away, and on.

4 = 2^2 @@ full base 2
3^3 - 1 = 26 = 3^2 \cdot 2 + 3 \cdot 2 + 2 @@ bump, take 1 away; full base 3
4^2 \cdot 2 + 4 \cdot 2 + 2 - 1 = 41 = 4^2 \cdot 2 + 4 \cdot 2 + 1 @@ bump, take 1 away
60,\ 83,\ 109,\ 139,\ 173,\ 211 @@ bases 5 to 10: 5²·2 + 5·2, then 6²·2 + 6 + 5, …
\htmlClass{new}{\text{the number climbs, and climbs much longer than in the two-digit game}} \quad \blacksquare @@ 29·cb3.5 listed the same start

29·cb3.5 stated, and did not prove, that the full game ends from every start. From 4 it takes 3 · 2^402 653 211 − 2 turns, a number with about 121 million digits.

38·cb29.2Labels in full

29·cb3.3 built ω·2, ω·3, … and gathered them into ω·ω with Replace. Write ω² for ω·ω, and ω^(k + 1) for ω^k · ω; one more Replace gathers them all into ω^ω, and the same moves give ω^(ω^ω), and every tower of ω’s of any height. The label of a number in full base b is its full-base writing with ω in place of every b. From 4 the labels run ω^ω, then ω² · 2 + ω · 2 + 2, then ω² · 2 + ω · 2 + 1.

Labels are compared as their writing says: first by the largest exponent, compared the same way; then by its count; then by what follows. Held in trust. That this comparison is membership between the points the labels name is proved by induction on the height of the labels, and the standing questions ask for its first cases.

Label-falls technique: at every turn of the full game, the label falls.

\text{a bump does not change the label} @@ the label reads every b as ω, and so does the label of the bumped number
n \text{ ends in a count } c > 0 \text{ of } b^0:\ \ c \to c - 1 @@ the last term of the label falls by one
n \text{ ends in } b^E \cdot k,\ E > 0:\ \ b^E \cdot k - 1 = b^E \cdot (k - 1) + (b^E - 1) @@ take 1 from the last power
b^E - 1 = (b - 1)\,b^{E-1} + \cdots + (b - 1) \text{, each exponent below } E @@ every term written below E, in full base b
\text{its label has every exponent below the label of } E @@ by induction on the height of E
\htmlClass{new}{\text{the label falls, however large } b \text{ is}} \quad \blacksquare @@ the first term that differs is smaller
  
5 = 2^2 + 1:\ \ \omega^\omega + 1 @@ base 2
27 = 3^3:\ \ \omega^\omega @@ base 3: 3³ + 1 − 1
\htmlClass{new}{255 = 4^3 \cdot 3 + 4^2 \cdot 3 + 4 \cdot 3 + 3:\ \ \omega^3 \cdot 3 + \omega^2 \cdot 3 + \omega \cdot 3 + 3} \quad \blacksquare @@ base 4: 4⁴ − 1. The number jumps from 27 to 255, and the label falls from ω^ω to a point below ω⁴

38·cb29.3Every full game ends

Full-game technique: every full game ends.

\text{the labels of a game, in order, are points of the run} @@ built from ω by 29·cb3’s moves and Replace (38·cb29.2)
\text{each label is a member of the one before} @@ the label-falls technique, with the comparison held in trust
\text{a run of points, each a member of the one before, stops} @@ the falling-run technique (29·cb3.4)
\htmlClass{new}{\text{the labels stop falling only at } 0 \text{, and the game ends}} \quad \blacksquare @@ a label that is not 0 always has a next turn

This is a statement about counting numbers: for every n, some k is the number of turns of the full game from n. The game is a recipe, so “the game from n ends at turn k” is a bounded condition of 38g’s kind, and the statement is an every in front of a search. Its proof went past the end of the run and spent Replace, twice over.

38·cb29.4Not reached by the axioms of arithmetic

Write E for the statement “every full game ends”, ∀n ∃k (the game from n ends at turn k). It is true in N.

PA \vdash \text{the game from } \bar 4 \text{ ends} @@ a true search statement: the search-reached technique (38g4)
PA \vdash \text{the game from } \bar n \text{ ends, for each number } n @@ the same, one proof for each n
PA \vdash E \Rightarrow \text{Con} @@ shown in 1982; held here, the proof is beyond the ladder
PA \nvdash \text{Con} @@ the no-self-certificate technique (38j3)
\htmlClass{new}{PA \nvdash E} \quad \blacksquare @@ else carry an if through would reach Con

So PA reaches each game’s ending, one game at a time, and does not reach that every game ends. The every in front is what is out of reach, as in 38i. Unlike U, E says nothing about proofs or codes: it is a statement about writing numbers in bases and taking one away. The proof of E went past every number, into points PA cannot speak of, and 1936’s proof of Con went the same way, along the same labels.

The basement · there if you want it

The accepted names

Full base b is hereditary base-b notation, and the full game is a Goodstein sequence; the full-game technique is Goodstein’s theorem. The labels are ordinals below ε₀, written in Cantor normal form; ε₀ is the least point gathering the tower ω, ω^ω, ω^(ω^ω), …. The comparison held in trust is the ordering of Cantor normal forms. PA ⊢ E ⇒ Con is part of the Kirby–Paris theorem, and E is equivalent over PA to the 1-consistency of PA.

Who said it first

Reuben Goodstein proved the theorem in 1944, by transfinite induction up to ε₀. Laurie Kirby and Jeff Paris proved in 1982 that it is not provable in Peano arithmetic, using non-standard models. Gerhard Gentzen proved the consistency of arithmetic by induction up to ε₀ in 1936, and showed in 1943 that PA proves transfinite induction up to every ordinal below ε₀ but not up to ε₀ itself. The length of the game from 4 was worked out later; it is 3 · 2^402 653 211 − 2.

A proof that is not allowed

\text{the label at each turn is a point} @@ fine
\text{induction on } n \text{ in PA: the game from } n \text{ ends} @@ not allowed: the step from n to n + 1 has no link; the game from n + 1 is not the game from n with one turn more
\text{so } PA \vdash E @@ would clash with the page
