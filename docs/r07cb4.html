7·cb4 · newsflash for 4h

The Least Member, for Any Set of Numbers

4h proved that a set of numbers has a least member when you can decide its membership number by number: search up from 0 and stop at the first member. For any other set it proved only no-least-no-members. A set with no least member has no members, which turned about gives “it is not so that it has no least member”. 4h said that rung 7 would remove the double negative. This page does, and collects what follows. Less-or-same is at last a well-order of the counting numbers, so 6e's caution is lifted. The shape “take a smallest counterexample” works for any condition. Taking the least picks from any collection of non-empty sets of numbers, with no choosing axiom. A finite set is in order on every part. Then the page brings back the form of foundation that 3a·f stated in words and set aside: every set with a member has a member that shares nothing with it. It proves this from set induction and either-way, and shows that it in turn proves either-way.

No least member would mean no members; so not not a least member; so a least member, by either-way, and nobody may know which number it is. A bottom member is a least member, for sets in general.

Where 4h stopped

Take any statement P, and the set X = {n ∈ ℕ : n = 5 ∨ (n = 2 ∧ P)}, a sift of ℕ. 5 is in it. Is 2? Exactly when P. Search up from 0. 0 is not in X, 1 is not, and at 2 the search asks “is 2 in X?” and cannot answer unless P is decidable. If P is the even-sum guess, the search stalls at 2 forever. 4h's least-member needs the set decidable, and this one is not known to be. No-least-no-members still applies: a set with no least member has no members, so this X, which has 5, is not without a least member. That is a double negative, and on rung 4 it was the end of the line.

A least member for every set of numbers

Least-member-for-any-set technique: every set of numbers that has a member has a least member. It is a proof by contradiction proper, 7e's shape, with 4h's no-least-no-members doing the work.

X \subseteq \mathbb N,\ \ e \in X @@ given: a set of numbers with a member, called e
\begin{aligned}&\text{suppose, for}\\ &\quad\text{contradiction, } \neg(X \text{ has a least member})\end{aligned} @@ the denial of what is wanted
\quad \forall n\,(n \notin X) @@ no-least-no-members (4h): no least member, no members
\quad e \notin X,\ \ \bot @@ use the every with e; clash with the given
\neg\neg(X \text{ has a least member}) @@ refute: this is where rung 4 stopped
\htmlClass{new}{X \text{ has a least member}} \quad \blacksquare @@ not-not-out (7d)

There is a second road, just as short. 4h's line calls X decidable when ∀n ∈ ℕ (n ∈ X ∨ n ∉ X). Either-way proves that line for every X, number by number. So every set of numbers is decidable in 4h's sense, and least-member applies to all of them. Both roads cite either-way once. Neither tells you which number is least. For the X above, split on P (7d): if P, the least member is 2; if ¬P, it is 5. With P the even-sum guess, the least member of X exists, and is 2 or 5, and nobody can say which. Least-member searched; least-member-for-any-set does not. 4h's flag on the double negative is closed.

ℕ is well-ordered, and a finite set is in order

6e defined a well-order as a partial order in which every non-empty part has a least member. It warned that ≤ had not yet been shown one, because least-member covered decidable parts only. ℕ-well-ordered technique: the numbers, in their own order, are well-ordered. In marks: ≤ is a well-order of ℕ. 6e showed ≤ is a partial order (reflexive by =, antisymmetric by any-two-compare, transitive by chain for less). A non-empty part of ℕ is a set of numbers with a member. Least-member-for-any-set gives it a least member. ∎ 6e's caution is lifted, and so is its table's last row: that flag of 6e is closed. Finite-order-on-every-part technique: if X has n members, the order finite-order built on X is a well-order. Finite-order gave a least member to every non-empty decidable part. By either-way, every part of X is decidable. ∎ That closes 6e's flag on the parts finite-order could not reach. So, on this ladder, a finite set is well-ordered with no choosing at all, and ℕ is well-ordered by its own order. The ℕ-well-ordered technique has the accepted name the well-ordering principle for the numbers: 6e's principle, said of ℕ and its own order.

Choosing by the least, from any sets of numbers

6b's least-chooses took the least member from each set of a collection of non-empty decidable sets of numbers. It said where it stopped: at undecided sets. Least-chooses-for-any-set technique: if every member of 𝒜 is a non-empty set of numbers, then 𝒜 has a choosing function, with no choosing axiom: take the least. Least-chooses's column runs unchanged, with least-member-for-any-set in the place of least-member. The sift by “m is the least member of A” has one output for every input, by least-member-for-any-set. No input has two, by 4h's at-most-one. ∎ The function picks 2 or 5 from the X above, and exists all the same. Either-way gives existence without a rule anyone can run. So this is a choosing function nobody can compute, built without the choosing axiom. The axiom was spent elsewhere: either-way was proved from it, on 7c. 6b's flag on least-chooses is closed.

An old method, called descent, runs the same way. Suppose some number has the bad property. Show that a smaller one must have it too; then a smaller one again, without end. But the numbers cannot go down forever, so no number has it.

Take a smallest counterexample

From here on, take a smallest counterexample is the shape for proving ∀n ∈ ℕ φ(n). Suppose ¬∀n ∈ ℕ φ(n). By not-every, the set {n ∈ ℕ : ¬φ(n)} has a member. By least-member-for-any-set it has a least member m. Then ¬φ(m) is so, and φ(k) is so for every k < m, and the proof finds a clash.

Worked: every number above 1 is a product of primes (a prime alone counts as a product of one). Suppose not, and take the least m above 1 that is not. m is not prime, or it would be a product of one prime. So m = c · d with 1 < c < m and 1 < d < m (4j's definition of prime and divisor-not-past). The factors c and d are smaller than m and above 1, so each is a product of primes. Put the two together, and m is one. Clash. ∎ 4j proved the same thing (prime-list) by strong induction, constructively. That is no accident: strong induction is the costume-off version of this shape. The smallest-counterexample proof needs either-way only to set itself up, by not-every and least-member-for-any-set. Turned around, by 7e's test, it is a strong induction, and strong induction needs no either-way at all. When the condition is decidable, as “is a product of primes” is, both roads are open. When it is not, only this one is.

Foundation's form with a bottom

3a·f laid down foundation as set induction: a condition that passes up from the members of a set to the set is so of every set. It stated in words another form, with a bottom, and set it aside. Laid down as an axiom, 3a·f said, it would prove P ∨ ¬P for any P. Here is the word, then the form, as a technique.

From here on, b is a bottom member of a set Y when : b is in Y, and nothing in b is in Y.

Bottom-member technique: for every set Y, if Y has a member, then Y has a bottom member.

\text{let } Y \text{ have a member; call it } e @@ let Y be anything; use the some
\text{suppose, for contradiction, } \neg\exists b\,(b \in Y \land b \cap Y = \varnothing) @@ the denial of what is wanted
\quad \forall b\,(b \in Y \Rightarrow b \cap Y \ne \varnothing) @@ not-some; then for b ∈ Y, assume b ∩ Y = ∅, join, clash, refute
\quad \varphi(x):\ x \notin Y.\ \ \text{let } x \text{ be anything; assume } \forall z\,(z \in x \Rightarrow z \notin Y) @@ name the condition (3a·f); the hypothesis about the members
\qquad \text{assume } x \in Y;\ \ x \cap Y \ne \varnothing @@ aiming to refute; the line above, used with x
\qquad z \in x \cap Y \Rightarrow z \in Y \land z \notin Y,\ \ \text{so } x \cap Y = \varnothing @@ ﹀ ∩; the hypothesis; clash; refute; the empty-set technique and one-empty-set
\qquad \bot @@ clash
\quad x \notin Y;\ \ \varphi \text{ passes up} @@ refute; prove an if; speak of everything
\quad \forall x\,(x \notin Y);\ \ e \notin Y;\ \ \bot @@ the foundation axiom (3a·f); use the every with e; clash
\neg\neg\exists b\,(b \in Y \land b \cap Y = \varnothing) @@ refute
\htmlClass{new}{\exists b\,(b \in Y \land b \cap Y = \varnothing)} \quad \blacksquare @@ not-not-out

Set induction did the climbing, as on 3a·f; either-way removed the last double negative. For sets of numbers, a bottom member is exactly a least member. Bottom-is-least technique: for a set X of numbers and b ∈ X, b ∩ X = ∅ exactly when b is the least member of X. For numbers, x ∈ b means x < b (4h's line). So b ∩ X = ∅ says no member of X is less than b. By any-two-compare, that says b ≤ x for every x ∈ X. ∎ So for sets of numbers bottom-member is least-member-for-any-set again: 3a·f's foreclosure and 4h's were one foreclosure. The flag 3a·f left on the bottom form is closed.

One more of 3a·f's flags closes here. 3a·f said a chain of memberships running down forever is refuted once such a chain can be written as an object, and 4d made that possible: a chain is a function f on ℕ with f(S(n)) ∈ f(n) for every n. Suppose there is one. Its values form a set, and the set is not empty, since f(0) is in it. By bottom-member, some value f(k) has no member in the set. But f(S(k)) is a member of f(k), and it is a value. That is a clash, so no chain of membership runs down forever. The flag 3a·f opened is closed.

The bottom form proves either-way

Now the other direction, which is why 3a·f set the bottom form aside. Bottom-gives-either-way technique: if every set with a member has a bottom member, then P ∨ ¬P, for any statement P. No either-way is used in the column.

\text{let } P \text{ be any statement};\ \ a = \{x \in 2 : x = 1 \lor P\} @@ speak of anything; Separation (2d)
1 \in a @@ the self-sameness axiom; add an option; 1 ∈ 2; ︿ the sift
\text{call } b \text{ with } b \in a \land b \cap a = \varnothing @@ the given, used with a; use the some
b = 0 \lor b = 1 @@ ﹀ the sift: b ∈ 2 = {0, 1} (3b); the listing, a proved or
\text{case } b = 0:\ \ 0 = 1 \lor P,\ \ 0 \ne 1,\ \ \htmlClass{new}{P} @@ the swap axiom; ﹀ the sift at 0; 7c's 0 ≠ 1; the remaining-option technique
\text{case } b = 1:\ \ 1 \cap a = \varnothing @@ the swap axiom
\quad \text{assume } P:\ \ 0 \in a,\ \ 0 \in 1,\ \ 0 \in 1 \cap a,\ \ \bot @@ 0 ∈ 2, add an option, ︿; 1 = {0}; ︿ ∩; the empty-set technique
\quad \htmlClass{new}{\neg P} @@ refute
P \lor \neg P \quad \blacksquare @@ add an option in each case; reason by cases; the call closes

So, given set induction, the bottom form and either-way prove each other. Set induction with either-way gives bottom-member, and bottom-member alone gives either-way. The two are now the same strength. Had 3a·f laid the bottom form down, it would have proved either-way on rung 2, and the ladder's gap would have closed before anyone could see it. One direction the ladder does not claim: does the bottom form give back set induction? Classically it does. But the usual proof gathers all the members of a set, all their members, and so on down, into one set. That needs the axiom 4d named only as history. The ladder keeps set induction as its axiom and has the bottom form as a technique.

Running It Backwards

Wanting a least member of a set of numbers, ask first whether the set is decidable. If so, search (least-member) and you will find it. If not, cite least-member-for-any-set and know that you may not find it. Wanting ∀n φ(n), try strong induction first. A smallest counterexample is the same proof in costume, and needs either-way only when φ cannot be checked. Wanting a bottom member, cite bottom-member; for sets of numbers, look for the least (bottom-is-least). Handed the bottom form as an axiom, expect to find either-way inside it (bottom-gives-either-way). Found upward; written downward.

Who said it first

Descent is Pierre de Fermat’s name for the method. The bottom form of foundation is Ernst Zermelo’s.

Fermat called his method infinite descent. Suppose some number has the bad property; show that a smaller one must have it too; then a smaller one again, without end. But the numbers cannot go down forever, he wrote, so no number has it.

Fermat, letter to Carcavi (August 1659); paraphrase

Accepted names

Descent is the method of infinite descent. A smallest counterexample is also called a minimal counterexample, and ℕ-well-ordered is the well-ordering principle for the numbers. The bottom form is the axiom of foundation, or regularity, in its usual statement; a bottom member is an ∈-minimal member. The either-way principle is the law of excluded middle.
