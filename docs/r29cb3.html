29·cb3 · newsflash for 3

Counting past the endless

Rung three built the run: start with nothing, take the next one, and take the next one again, without end. It laid down an axiom so that the whole run could be one set, and rung four sifted that set down to the counting numbers. But the next-one gesture does not care what it is given. Hand it the whole run, and it makes a set that comes after every number. Hand it that, and it makes another. This page follows the run past its own end. The first steps are free: each needs only the next one. The trouble comes when you try to gather a second endless run on top of the first. Sifting needs a set to sift from, and all the subsets of a set stay too close to the ground. The page builds a world in which every axiom the ladder has laid down is true and the doubled run is not a set, so no argument from those axioms can build it. Then it lays down one more axiom, the one rung four named only as history, and the doubled run, and rung four’s tower of layers, become sets at once. Last, it brings the endless back down to earth: a game played with ordinary numbers, whose numbers keep climbing for thousands of turns before they fall, is shown to end by counting down from past the endless.

Every point of the run is the set of the points before it. The whole run of counting numbers is a point too, and the next one after it is the first point past every number. Putting one more in front of the run gives back the same shape; putting it after gives a new one. All the points that are a number of steps past the run are sets, each one built by the next-one gesture. Gathering all of them into one set is something the axioms of rungs two, three and six cannot do. In a world built from the layers past the run, each of those axioms holds, and the doubled run is missing. The new axiom says that when a rule hands each member of a set exactly one thing, the things handed form a set. With it, the doubled run is the counting numbers merged with the set of points a number of steps past the run. In any collection lined up so that every part with a member has a least member, a run that keeps falling must stop. So a game that bumps the base and takes one away ends, even when its numbers climb for thousands of turns.

29·cb3.1Past the end of the run

Every number is the set of the numbers before it: 3 = {0, 1, 2}. ℕ is the set of all the numbers. So ℕ is shaped like a number too: it is the set of everything before it, with nothing last. Two facts of rung four make that exact. Every number is a transitive set (4c). And of two different numbers, one is a member of the other (4h, where less is membership).

From here on, a point of the run is a transitive set any two different members of which are lined up by membership: one is a member of the other. Every number is a point. ℕ is a point: it is transitive, since a member of a number is a number, and any two of its members compare. When ℕ is read as a point of the run, it is written ω.

\alpha \text{ a point} \Rightarrow S(\alpha) = \alpha \cup \{\alpha\} \text{ is transitive} @@ the transitive-next technique (4c)
x, y \in S(\alpha),\ x \ne y \Rightarrow x \in y \lor y \in x @@ both in α: α is a point; one is α itself: the other is in α
\alpha \in S(\alpha),\ \ \alpha \ne S(\alpha) @@ the in-its-next and never-its-own-next techniques (3b)
\omega \in S(\omega),\ \ S(\omega) \notin \omega @@ S(ω) ∈ ω would make ω ∈ ω, since ω is transitive: no set is a member of itself (3a·f)
\htmlClass{new}{S(\omega) \text{ is a point after every number, and is not a number}} \quad \blacksquare @@ every number is in ω, and ω ∈ S(ω)

One-past technique: the next one after a point of the run is a point, and the next one after ω is a point that comes after every number without being one. Write ω + 1 for S(ω), ω + 2 for S(ω + 1), and on. Each is built from the one before by gather and merge, as 3b built 4 from 3. Nothing new is asked: the run simply keeps going.

\text{line up } \mathbb N \text{ as } 1, 2, 3, \dots, 0 @@ every number but 0 in its usual order, then 0 last
\text{it has a last member, } 0;\ \ \omega \text{ has none} @@ the next one after any number is a larger number
\text{so it is shaped like } \omega + 1, \text{ not like } \omega @@ a matching that keeps the order must send a last member to a last member
\text{put a new member } \star \text{ in front: } \star, 0, 1, 2, \dots @@ match ⋆ with 0, and each number n with S(n)
\htmlClass{new}{\text{one in front gives the shape of } \omega \text{ again; one behind does not}} @@ 3c9’s matching with a part of itself

So adding one is not the same on the two sides once the run is endless. Line up ℕ with the even numbers first, 0, 2, 4, …, then the odd ones, 1, 3, 5, …. Every number is there once, and the shape is two endless runs, one after the other. That is the shape of ω + ω, if a set of that shape exists. This page asks whether it does.

29·cb3.2What Sift and Power can reach

ω + 1, ω + 2, ω + 3 are each a set. Is there a set holding all of them at once: the set ω + ω = ω ∪ {ω, ω + 1, ω + 2, …}? 3d answered a question of this kind for ω itself. It built a world in which every earlier axiom was true and no set was inductive. The same move works one storey up.

Carry 3d’s layers past the run. V_ω is the merge of all the layers V_k, one for each number k. Then V_(ω+1) = 𝒫(V_ω), V_(ω+2) = 𝒫(V_(ω+1)), and on. The world past the run is the sets that are members of some layer V_(ω+k). As in 3d, the world is a way of talking, not a set. It is described from outside, with the axiom this page lays down in 29·cb3.3, as 3d described its world from outside.

x \in V_{\omega+k+1} \iff x \subseteq V_{\omega+k} @@ that is what 𝒫 means (3d5); each layer is inside the next
y = \{z \in x : \varphi(z)\} \subseteq x \Rightarrow y \text{ is in the layer of } x @@ Sift stays inside: y is a part of the layer below x’s
\mathcal P(x) \subseteq \mathcal P(V_{\omega+k}) = V_{\omega+k+1} \text{ for } x \in V_{\omega+k+1} @@ Power stays inside: 𝒫(x) is in the next layer up
\{a, b\},\ \textstyle\bigcup x,\ \omega,\ \text{choosing functions} \text{ all stay inside} @@ gather and merge as in 3d6; ω ⊆ V_ω, so ω ∈ V_(ω+1); a set of pairs from a layer sits a few layers up
\omega + k \in V_{\omega+k+1},\ \ \omega + k \notin V_{\omega+k} @@ by induction on k: each point enters at its own layer, as 3d showed for numbers
\omega + \omega \in V_{\omega+k} \Rightarrow \omega + k \in V_{\omega+k-1} \subseteq V_{\omega+k} @@ a member of a member of the layer is in the layer below
\htmlClass{new}{\omega + \omega \text{ is in no layer of the world}} \quad \blacksquare @@ that clashes with the line before

Short-world technique: in the world past the run, every axiom of rungs two, three and six is true, every point ω + k is a set, and ω + ω is not; so those axioms cannot prove that ω + ω is a set. If they could, the argument would run in this world, and it would be false there.

Look at what is missing. Every piece of ω + ω is in the world: ω, and each ω + k. What fails is the gathering. Sift only picks from a set already in hand. Power makes a bigger set, but one layer up only. Neither can reach across an endless run of layers in one move. That is 4d’s catch again. 4d wanted one set holding ∅ and all the subsets of each of its members, and found no line of the ladder that supplies one.

29·cb3.3The axiom of replacement

A condition φ(x, y) is a rule on a set X when each member x of X has exactly one y with φ(x, y). The ladder now lays down what 4d named only as history.

In words: when a rule hands each member of a set exactly one thing, the things handed form a set. Its accepted name is the axiom of replacement. Sift picks things out of a set you have. Replace swaps each member of a set you have for something else. Neither makes a set from nothing.

\varphi(n, y):\ \exists f\ \big(f : S(n) \to \text{a set},\ f(0) = \omega,\ \forall j \in n\ f(S(j)) = S(f(j)),\ y = f(n)\big) @@ y is ω + n: a start ω, the step S, run n times
\forall n \in \omega\ \exists!\,y\ \varphi(n, y) @@ by induction on n, as 4d18 did for the layers: add one pair with gather and merge; two such f agree, by induction
R = \{\omega + n : n \in \omega\} \text{ is a set} @@ Replace, on the set ω, with the rule φ
\omega + \omega = \omega \cup R @@ merge (2e): every number, then every point a number of steps past ω
\htmlClass{new}{\omega + \omega \text{ is a point of the run}} \quad \blacksquare @@ transitive: members of ω + n are numbers or earlier ω + j; lined up: numbers before ω, and ω + i ∈ ω + j for i < j

Doubled-run technique: with Replace, ω + ω is a set and a point of the run: every number, then every point a number of steps past ω. The same lines run from any point α in place of ω, so α + ω is a set for every point α. From 0, adding ω again and again gives ω·2 = ω + ω, ω·3 = ω·2 + ω, and on. Replace once more, on the rule k ↦ ω·k, gathers them all into ω·ω.

\psi(n, y):\ y \text{ is the layer } V_n @@ 4d18: for every n there is a run of pairs from (0, ∅) by the step x ↦ 𝒫(x) up to n
\{V_n : n \in \omega\} \text{ is a set} @@ Replace, on ω, with the rule ψ
A = V_\omega = \textstyle\bigcup\{V_n : n \in \omega\} @@ merge
x \in A \Rightarrow x \in V_n \Rightarrow \mathcal P(x) \subseteq \mathcal P(V_{n-1}) = V_n \Rightarrow \mathcal P(x) \in V_{n+1} \subseteq A @@ for n ≥ 1; x ∈ V₀ cannot happen
\htmlClass{new}{\varnothing \in A,\ \ \forall x \in A\ \ \mathcal P(x) \in A} @@ the set 4d.4.4 asked for

So one line pays two old flags. The layers of 3d become one set, and the doubled run is a set. Most of the mathematics of these twenty-nine rungs never needed it: every set the ladder has built so far sits in the world past the run.

29·cb3.4Counting down from past the endless

Climbing the run past ω takes an axiom. Coming down takes none. 7·cb4’s bottom-member technique says that every set with a member has a member none of whose members is in the set. For a set of points of the run, that bottom member is its least member, since points are lined up by membership. So the points of the run, read with membership as less, form a well-order (6e).

\alpha_0 \ni \alpha_1 \ni \alpha_2 \ni \cdots,\ \ \text{each } \alpha_{n+1} \in \alpha_n @@ a run of points that keeps falling, one for each number (9·cb4)
Y = \{\alpha_n : n \in \omega\} \text{ has a member} @@ the values of the run form a set (9a); α₀ is in it
\beta = \alpha_m \text{ a bottom member of } Y @@ the bottom-member technique (7·cb4)
\alpha_{m+1} \in \beta \text{ and } \alpha_{m+1} \in Y @@ the run falls at m
\htmlClass{new}{\text{no run of points falls for ever}} \quad \blacksquare @@ a clash with “nothing in β is in Y”

Falling-run technique: a run of points of the run, each a member of the one before, cannot go on for ever; it stops after some number of steps. The same bottom member gives induction past the endless. If a statement holds at a point whenever it holds at every point before it, it holds at every point: a point where it failed would sit in a set of failures with a bottom member, and the statement would hold at that bottom. Its accepted name is transfinite induction.

The fall can be long. From ω, one step can land on any number at all, say a million, and then it takes a million more steps. No number bounds how long a fall from ω takes. Every fall still ends.

29·cb3.5Back down into counting numbers

Here is a game played with ordinary numbers. Write a number with two digits in some base b: n = d·b + c, with d and c below b. Each turn, read the same two digits in base b + 1, then take 1 away. Then do it again in base b + 2, and on. Does the number ever reach 0?

99 = 9\cdot10 + 9 \to 9\cdot11 + 9 - 1 = 9\cdot11 + 8 = 107 @@ the first turn: base 10 becomes base 11
c \gt 0:\ (d, c) \to (d, c - 1) @@ the base grows, the low digit drops
c = 0:\ (d, 0) \to (d - 1,\ b) \text{ in base } b + 1 @@ d·(b + 1) − 1 = (d − 1)(b + 1) + b
\text{label } \omega\cdot d + c:\ \ \omega\cdot d + (c - 1) \in \omega\cdot d + c,\ \ \omega\cdot(d - 1) + b \in \omega\cdot d @@ each turn the label falls, however large the new digit b is
\htmlClass{new}{\text{every game ends}} \quad \blacksquare @@ the falling-run technique

Base-bump technique: in the two-digit game the label ω·d + c falls at every turn, so the game ends, however much the number itself grows on the way. Starting from 99 in base 10, the number climbs for 2550 turns, to 5119, before it falls. It reaches 0 after 10 229 turns, in base 10 239. The labels never climb. Each time the top digit drops, the low digit jumps to the size of the base, and the label drops from somewhere past ω·(d − 1) to a point just past it. Its count is a counting number; only the reason it ends lives past the endless.

3 = 2^1 + 1,\ \text{label } \omega + 1 @@ base 2; the base is read as ω
3^1 + 1 - 1 = 3 = 3^1,\ \text{label } \omega @@ base 3
4^1 - 1 = 3,\ \text{label } 3 @@ base 4: 3 is one digit, and the label falls from ω to a number
3, 2, 1, 0 @@ bases 5, 6 and 7
\htmlClass{new}{\text{five turns: } \omega + 1,\ \omega,\ 3,\ 2,\ 1,\ 0} @@ down from the transfinite into counting numbers

In the full game every exponent is written in base b too, and every exponent of those, and the base is bumped everywhere at once. From 4 = 2², the numbers run 4, 26, 41, 60, 83, 109, 139, 173, and on. Stated here, not proved: the full game ends from every start, by labels past ω·ω that fall at every turn. From 4 it takes a number of turns with about 121 million digits. And the fact that it ends, a statement about counting numbers only, cannot be proved by induction over the counting numbers alone. Its proof has to count past the endless.

The accepted names

A point of the run is a (von Neumann) ordinal; ω is the first infinite ordinal, and ω + 1, ω + ω = ω·2 and ω·ω = ω² follow it in ordinal arithmetic, where 1 + ω = ω ≠ ω + 1. An ordinal of the form S(α) is a successor ordinal; ω and ω·2 are limit ordinals. The layers are the cumulative hierarchy, and the world past the run is V_(ω+ω), a model of Zermelo set theory with the axiom of choice. The axiom Replace is the axiom schema of replacement; with it Zermelo’s list becomes Zermelo–Fraenkel set theory, ZF, and with the choosing axiom ZFC. The falling-run technique is the well-foundedness of the ordinals, and the induction past the endless is transfinite induction. The full base-bump game is the Goodstein sequence, and the two-digit game a weak Goodstein sequence. That the full game ends is Goodstein’s theorem; that it cannot be proved by induction over the counting numbers alone is the Kirby–Paris theorem: it is not provable in Peano arithmetic.

Who said it first

Georg Cantor counted past the endless with his transfinite numbers from 1883. John von Neumann gave each ordinal as the set of those before it in 1923. Ernst Zermelo published his list of axioms in 1908. Abraham Fraenkel and Thoralf Skolem each proposed replacement in 1922, with the set of ℕ, 𝒫(ℕ), 𝒫(𝒫(ℕ)), … as the example Zermelo’s list could not reach; Zermelo took replacement into his list in 1930. Reuben Goodstein proved his game ends in 1944, and Laurie Kirby and Jeff Paris showed in 1982 that the counting numbers’ induction cannot. In 29·cb3.7.5, the statement about games is Borel determinacy: Harvey Friedman showed in 1971 that it needs replacement, and Donald Martin proved it in 1975.
