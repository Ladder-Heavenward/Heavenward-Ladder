Proving a Loop by Hand

40g proved loops whose invariants were handed over. This step is the hand method for finding one and checking it, on a loop that adds 1 to n.

Loosen the goal into a guess, check the three duties, mend the guess if one fails, and name the number that falls.

40k1Loosen the Goal

The loop: s ← 0; i ← 0; while i ≠ n: i ← i + 1; s ← s + i. The goal is s = n(n + 1)/2. Replace the n the loop works toward by the name it moves, i, and guess I: s = i(i + 1)/2.

40k2Three Duties

Start: s = 0 and i = 0 give 0 = 0. Keep: carry I backwards through the body (40f2) and check it follows from I. Finish: I and i = n give the goal.

s = i(i + 1)/2 @@ I, after the body
s + i = i(i + 1)/2 @@ back through s ← s + i
s + (i + 1) = (i + 1)(i + 2)/2 @@ back through i ← i + 1
i(i + 1)/2 + (i + 1) = (i + 1)(i + 2)/2 @@ it follows from I: factor out i + 1
\htmlClass{new}{\{I \wedge i \neq n\}\ \text{body}\ \{I\}} \quad \blacksquare @@ the turn keeps I

40k3The Falling Number

n − i falls by 1 each turn. It is a whole number only while i ≤ n, so add i ≤ n to the invariant, and check the three duties again: it starts true, each turn keeps it because the test said i ≠ n, and it ends with i = n.

40k4When a Duty Fails

A failed duty means the guess was too weak or too strong. Too weak, and the keep or finish duty fails: add what the turn needs, as i ≤ n was added. Too strong, and the start fails: drop what the start cannot give.
