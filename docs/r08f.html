8f · proof

Two Has a Square Root on the Line

Rung 5 proved that no fraction squares to 2. This step proves that a real does. The candidate is the least upper bound of the reals at least 0 whose squares are below 2. If its square were below 2, a small step up would still square below 2, so it would not be an upper bound. If its square were above 2, a small step down would still square above 2, so it would not be least. Only one possibility is left. Every step size comes from 8e: one over some counting number is below any positive real. Then the same argument, with a technique that bounds powers, gives every positive real a square root, a cube root, and roots of every order. Among them is the twelfth root of 2, the equal step of a tuned piano.

Take the least upper bound of what falls short. Too small, and a step up still falls short; too big, and a step down is still too big. So it is exactly right.

8f1Powers of a Real, and Two Techniques About Squares

From here on, for a real α and a number k, α^k names p(k), where p : ℕ → ℝ is the one function with p(0) = 1 and p(S(k)) = p(k) · α (4d's recursion). Read it “α to the power k”. α² is αα. Every fraction is a real, through 8d's naming line, so this also names the powers of a fraction. The power is an operator, a statement with two gaps, a real and a number, and its result is a real.

4g's techniques powers-add-their-counts (α^(b + c) = α^b α^c) and power-of-a-power ((α^b)^c = α^(bc)) are techniques for reals too. So is 5h's power-of-a-product ((αβ)^k = α^k β^k). The same inductions prove them, since they used only regrouping and commuting: regroup for times on ℝ and turn-about for times on ℝ. Square-never-negative technique: for every real x, 0 ≤ x². By three-way on ℝ: if x = 0, x² = 0. If x is positive, x² is positive by positive-product on ℝ. If −x is positive, x² = (−x)² by two-negatives, positive. ∎ Powers-keep-order technique: 0 ≤ x < y and n ≥ 1 ⇒ xⁿ < yⁿ. By induction from n = 1: xⁿ⁺¹ = xⁿ · x ≤ xⁿ · y < yⁿ · y. The first step is by order-and-arithmetic-agree's second part (or equality, when x = 0). The second is true because y is positive and xⁿ < yⁿ. ∎ With three-way-order on ℝ it runs backwards too: for non-negative x and y, xⁿ < yⁿ ⇒ x < y, and xⁿ = yⁿ ⇒ x = y.

8f2The Proof, in Full

Root-of-two technique: there is a positive real σ with σ² = 2. Let S = {x ∈ ℝ : 0 ≤ x ∧ x² < 2}, sifted from ℝ.

\htmlClass{new}{\sigma^2 = 2},\ \ \sigma \text{ positive} \quad \blacksquare @@ the remaining-option technique twice (1c), with the two refutations; 1 ≤ σ

Read where the two halves got their power. No-holes gave σ. Counting, through everyday-counting-passes, gave steps small enough not to overshoot. In the first half it gave a step up so small that the square rises by less than the room left below 2. In the second it gave a step down so small that the square falls by less than the room above 2. And the comparison of 8b, through three-way-order on ℝ, said that once two cases are refuted the third is true. Over the fractions every line survives except the fourth of the setting. The fractions whose squares are below 2 have no least fractional upper bound (8c's no-least-fraction-bound), so there is no σ to begin with.

8f3The Square Root, and Its Mark

One-root technique: for non-negative x and y, x² = y² ⇒ x = y, by powers-keep-order run backwards. Square-root technique: for a real u ≥ 0 there is a real x ≥ 0 with x² = u. For u = 0 take x = 0. For positive u, run root-of-two's columns with u in place of 2. S = {x : 0 ≤ x ∧ x² < u} has the member 0, and the upper bound max(1, u) (8b's max): a member above it would have x² > x · 1 = x > u. Every other line is root-of-two's, with d = u − σ² or σ² − u. In the second half σ is positive because σ² > u > 0. ∎

From here on, for a real u ≥ 0, √u names the one real x ≥ 0 with x² = u (the techniques square-root and one-root). Read it “the square root of u”, or “root u”. So √u · √u = u, and √u ≥ 0. The mark √ is an operator with one gap, and its result is a real.

Its partner −√u squares to u too, by two-negatives. By 5i's same-squares (read in ℝ) nothing else does: x² = u ⇒ x = √u ∨ x = −√u. Hole's-cut-is-√2 technique: 8a's α = {r ∈ ℚ : r < 0 ∨ r² < 2} is √2. By members-are-the-fractions-below (8a), a fraction r is in √2 exactly when r < √2 on the line. If r < 0, it is, since √2 is positive. If 0 ≤ r, then r < √2 ⇔ r² < 2, by powers-keep-order each way. So √2 and α have the same members, and by same-members they are the same. ∎ So 8a's foreclosure completes, and the flag it left for this step is closed. The cut that 8a built at 5f's hole multiplies by itself to give exactly 2, and by hole-is-no-fraction's-cut it is irrational. √2 is irrational.

The inventor of cuts closed his essay by observing that, on this footing, one obtains for the first time a real proof that √2 · √3 = √6. That, he said, had never yet been established.

His example is now a two-line exercise. (√2 √3)² = (√2)²(√3)² = 2 · 3 = 6 by power-of-a-product, and √2 √3 ≥ 0 by positive-product on ℝ. So √2 √3 = √6 by one-root. That is the uniqueness method: show both sides are non-negative and have the same square. 8i turns it into a habit.

8f4Roots of Every Order

For a cube root, (σ + h)³ has more terms than square-of-a-sum's three. One technique bounds them all. Power-bound technique: for reals σ ≥ 0 and 0 < h ≤ 1, and every number n, (σ + h)ⁿ ≤ σⁿ + h((σ + 1)ⁿ − σⁿ).

n = 0:\ \ 1 \le 1 + h(1 - 1) @@ the base: both sides 1 (power-zero, anything-times-zero)
\text{assume } (\sigma + h)^n \le \sigma^n + h c_n,\ \ c_n = (\sigma + 1)^n - \sigma^n \ge 0 @@ the induction hypothesis; c_n ≥ 0 by powers-keep-order (or 0 at n = 0)
(\sigma + h)^{n+1} \le (\sigma + h)(\sigma^n + h c_n) @@ power-of-a-next; order-and-arithmetic-agree's second part, σ + h positive
= \sigma^{n+1} + h\sigma^n + h\sigma c_n + h^2 c_n @@ spread on ℝ, turn-about for times on ℝ
\le \sigma^{n+1} + h(\sigma^n + \sigma c_n + c_n) @@ h² ≤ h, times c_n ≥ 0; spread on ℝ
\sigma^n + (\sigma + 1)c_n = (\sigma + 1)^{n+1} - \sigma^{n+1} @@ spread on ℝ; power-of-a-next; the rules
\htmlClass{new}{(\sigma + h)^{n+1} \le \sigma^{n+1} + h\,c_{n+1}} \quad \blacksquare @@ the step; the induction technique

Roots-of-every-order technique: for a positive real u and a number n ≥ 1, there is a positive real x with xⁿ = u, and only one non-negative such x, by powers-keep-order. Let S = {x : 0 ≤ x ∧ xⁿ < u}. It has the member 0 and the upper bound max(1, u), since for x ≥ 1, xⁿ ≥ x (induction). σ = sup S. Too small: suppose σⁿ < u. Let c = (σ + 1)ⁿ − σⁿ, which is positive. Take h = 1/k below both 1 and (u − σⁿ)/c. Power-bound gives (σ + h)ⁿ < u, so σ + h ∈ S: a clash. Too big: suppose σⁿ > u. Then σ is positive; take h = 1/k below σ, 1, and (σⁿ − u)/(σ + 1)ⁿ. Power-bound at the base σ − h gives σⁿ ≤ (σ − h)ⁿ + h((σ − h + 1)ⁿ − (σ − h)ⁿ) ≤ (σ − h)ⁿ + h(σ + 1)ⁿ. So (σ − h)ⁿ > u, and σ − h is a smaller upper bound, by powers-keep-order: a clash. Three-way-order on ℝ leaves σⁿ = u. ∎

From here on, for a real u ≥ 0 and a number n ≥ 1, ⁿ√u names the one real x ≥ 0 with xⁿ = u. Read it “the n-th root of u”. ²√u is written √u; ³√u is read “the cube root of u”.

A root written with the mark √ is called a radical, and n is its index.

An aside, which nothing else in this step uses. A piano in equal temperament has twelve equal steps between neighbouring keys, and the twelve stack to exactly 2. The annex 6·phys shows that no fraction does it. Roots-of-every-order says a real does: , whose twelfth power is exactly 2. 8·cb6 computes it and tunes the bass.

8f6Running It Backwards

Wanting a real with a property of squares or powers, take the least upper bound of what falls short. Refute too small and too big with a step 1/n from everyday-counting-passes. Wanting to prove two expressions with roots are the same, show both are non-negative and have the same square (or n-th power): one-root. Handed a fraction r and asked whether it is below √u, compare r² with u, if r ≥ 0 (powers-keep-order). Found upward; written downward.
