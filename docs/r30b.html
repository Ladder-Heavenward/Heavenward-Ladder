30b · proof

The sets that have sizes

The last step found a set that no size can measure. So the ladder needs a test that tells the good sets from the bad. The test is a knife. Take any set at all and cut it with the set you are testing, into the part inside and the part outside. If the outer sizes of the two parts always add back to the outer size of the whole, the knife cuts cleanly, and the set you tested has a size. This step shows that the sets passing the test are closed under taking what is left over and under joining countably many. On them, outer size adds exactly over countably many separate pieces. And every interval passes. That is enough to measure every set you are ever likely to meet.

A set has a size when it splits every set’s outer size exactly. Such sets survive leftovers and countable unions, outer size adds exactly over them, and every interval is one of them.

30b1The split test

From here on, a set A of reals is sized when, for every set E of reals,

m*(E) = m*(E ∩ A) + m*(E ∖ A).

E ∩ A is the part of E inside A, and E ∖ A the part outside. The test is the split test. Its accepted name is measurable.

Split-test technique: A is sized when m*(E ∩ A) + m*(E ∖ A) ≤ m*(E) for every E, and then so is the set of reals outside A.

E = (E \cap A) \cup (E \setminus A) @@ every point of E is inside A or outside it
m^*(E) \le m^*(E \cap A) + m^*(E \setminus A) \text{ always} @@ outer-adds-at-most (30a2), with two pieces
\text{so only } \le \text{ the other way needs checking} @@ the two together give =
E \cap A^{c} = E \setminus A,\ \ E \setminus A^{c} = E \cap A @@ Aᶜ is the set of reals outside A
\htmlClass{new}{A \text{ sized} \iff A^{c} \text{ sized}} \quad \blacksquare @@ the test is the same two pieces, swapped

A set of outer size 0 is sized: E ∩ A sits inside A, so m*(E ∩ A) = 0, and E ∖ A sits inside E.

30b2Countably many sized sets

Sized-family technique: if A₁, A₂, … are sized, so is their union, and so is the part of the line outside any one of them.

m^*(E) = m^*(E \cap A) + m^*(E \setminus A) @@ split E by A
m^*(E \setminus A) = m^*\big((E \setminus A) \cap B\big) + m^*\big(E \setminus (A \cup B)\big) @@ split E ∖ A by B
m^*\big(E \cap (A \cup B)\big) \le m^*(E \cap A) + m^*\big((E \setminus A) \cap B\big) @@ E ∩ (A ∪ B) is those two pieces; outer-adds-at-most
\htmlClass{new}{m^*\big(E \cap (A \cup B)\big) + m^*\big(E \setminus (A \cup B)\big) \le m^*(E)} \quad \blacksquare @@ the lines above; split-test (30b1)

So finite unions of sized sets are sized, and so are finite intersections and differences, by taking what is left over (30b1). Next, countably many.

B_1 = A_1,\ \ B_n = A_n \setminus (A_1 \cup \cdots \cup A_{n-1}) @@ separate sized pieces with the same union U
m^*\big(E \cap (B_1 \cup \cdots \cup B_n)\big) = m^*(E \cap B_1) + \cdots + m^*(E \cap B_n) @@ split by Bₙ each time; induction on n
m^*(E) \ge m^*(E \cap B_1) + \cdots + m^*(E \cap B_n) + m^*(E \setminus U) @@ B₁ ∪ ⋯ ∪ Bₙ is sized; E ∖ U sits inside its outside
m^*(E) \ge \sum_n m^*(E \cap B_n) + m^*(E \setminus U) \ge m^*(E \cap U) + m^*(E \setminus U) @@ let n grow (22a); outer-adds-at-most (30a2)
\htmlClass{new}{U = A_1 \cup A_2 \cup \cdots \text{ is sized}} \quad \blacksquare @@ split-test (30b1)

30b3Size adds over countably many pieces

From here on, the size of a sized set A is m(A) = m*(A). On sized sets the asterisk is dropped.

Countable-adding technique: if A₁, A₂, … are sized and separate, m(A₁ ∪ A₂ ∪ ⋯) = m(A₁) + m(A₂) + ⋯.

m^*\big(E \cap (A_1 \cup \cdots \cup A_n)\big) = \sum_{k \le n} m^*(E \cap A_k) @@ 30b2, with Bₖ = Aₖ, since they are already separate
E = A_1 \cup A_2 \cup \cdots:\ \ m(E) \ge \sum_{k \le n} m(A_k) \text{ for every } n @@ a bigger set is not smaller (30a2)
m(E) \ge \sum_k m(A_k) @@ let n grow (22a)
m(E) \le \sum_k m(A_k) @@ outer-adds-at-most (30a2)
\htmlClass{new}{m(A_1 \cup A_2 \cup \cdots) = m(A_1) + m(A_2) + \cdots} \quad \blacksquare @@ both ways
Anexact, yet rigorous · the ledger

1a kept exact books on stuff that nobody watched piece by piece. Size now keeps the same books on sets. Cut a sized set into countably many separate sized pieces, and every scrap of its size is entered once: none is made, and none is lost.

Size keeps exact books over countably many separate pieces, and a set that would break the books is left out of them.

The set V of 30a is the entry the ledger refuses. Its slid copies would make the books come out wrong whatever V were given, so the ledger leaves V out rather than let the books fail.

The fractions in [0, 1] are countably many points, each of size 0. What total size do the books give them, and what is left for the rest of [0, 1]?

30b4Every interval has a size

Intervals-sized technique: every interval is sized, and its size is its length.

A = (a, \infty),\ \ E \text{ any set},\ \ \varepsilon > 0 @@ if m*(E) is ∞ there is nothing to prove
I_1, I_2, \ldots \text{ cover } E,\ \ \sum \ell(I_k) \le m^*(E) + \varepsilon @@ ﹀ “outer size” (30a1)
I_k \cap A,\ \ I_k \setminus A \text{ are intervals},\ \ \ell(I_k \cap A) + \ell(I_k \setminus A) = \ell(I_k) @@ cut each interval at a
m^*(E \cap A) + m^*(E \setminus A) \le \sum \ell(I_k \cap A) + \sum \ell(I_k \setminus A) + 2\varepsilon @@ fatten each piece a little to make it open; cover-total
\le m^*(E) + 3\varepsilon @@ the line before
\htmlClass{new}{(a, \infty) \text{ is sized}} \quad \blacksquare @@ ε was any positive number; split-test (30b1)

Then (−∞, b] is sized as what is left over, (a, b] = (a, ∞) ∩ (−∞, b] is sized, and every other interval differs from one of these by a point or two. Its size is its length, by the cover-total technique.

From here on, the sized sets of the line, with their size m, are called the line’s sizes. Their accepted name is measure on the line. Every open set is a countable union of intervals with fraction ends, so it is sized. Every closed set is what is left over from an open one, so it is sized too.

The basement · there if you want it

The accepted names

A sized set is a Lebesgue measurable set, and the split test is Carathéodory’s criterion. The sized-family technique says the measurable sets form a σ-algebra. Countable adding is countable additivity, and the line’s sizes are Lebesgue measure. Sets made from intervals by countably many unions and leftovers are the Borel sets.

Who said it first

Henri Lebesgue defined measurable sets in 1902 by comparing a set’s outer measure with the outer measure of its complement. Constantin Carathéodory gave the split test in 1914, and it is the form used everywhere since, because it works for every kind of size, not only length.

A proof that is not allowed

“Every set of reals is a union of intervals of length 0, the single points; intervals are sized; so every set is sized.” Not allowed: the sized-family technique joins countably many sets, and most sets of reals have more points than any list.
