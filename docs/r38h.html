38h · proof

A sentence about itself

Rung one met a statement that says of itself that it is not so, and refuted it. Rung two met the set of all sets that are not members of themselves, and found there is no such set. Rung thirty five ran down the diagonal of a list and built a real number the list had missed. Each time something was made to speak of itself, and each time the result was a refusal. This step makes arithmetic speak of itself, and this time the result is not a refusal but a statement. First, “some number is the code of a proof of this formula” becomes a formula of arithmetic, built from the checks a recipe makes. Then comes the diagonal. Take any property a formula can have. There is a statement of arithmetic that is true exactly when its own code has that property. It contains no word for “this”. It is an ordinary statement about numbers, and the number it speaks of happens to be its own code.

Provability from the axioms of arithmetic is a formula of arithmetic. And for any formula with one free place, some statement is reached as equivalent to that formula applied to its own code.

38h1Provability as a formula

Each check of 38b3’s proof-check recipe asks about a number y and the places of the list it codes: is this place a given of PA, is that one moved from these earlier ones by this move. With the list-in-one-number technique each check is a formula, and each of its somes is kept below y. Put them together and they give a bounded formula Proof(y, x): “y is the code of a proof from PA whose foot is the statement with code x”.

Held in trust until rung 40. Writing Proof(y, x) out in full takes pages, and every piece is one of 38b3’s checks, written in remainders. Rung 40 builds machines and proves once for all that every recipe that always stops can be written as such a formula. Here the formula is used, and the flag stays open there.

From here on, Prov(x) is the search formula ∃y Proof(y, x): “the statement with code x is reached by PA”. For a statement φ, write ⌜φ⌝ also for the numeral of its code, so Prov(⌜φ⌝) is a statement.

Provable-mark technique: if PA reaches φ, then PA reaches Prov(⌜φ⌝).

PA \vdash \varphi \text{, by a proof with code } k @@ given; every proof has a code (38g1)
N \models \text{Proof}(\bar k, \ulcorner \varphi \urcorner) @@ Proof says what the recipe checks, and the recipe says yes
PA \vdash \text{Proof}(\bar k, \ulcorner \varphi \urcorner) @@ the search-reached technique (38g4): a true bounded statement
\htmlClass{new}{PA \vdash \text{Prov}(\ulcorner \varphi \urcorner)} \quad \blacksquare @@ show an example, with k̄

The other way needs N. If PA reaches Prov(⌜φ⌝), then Prov(⌜φ⌝) is true in N, since PA reaches only truths about N (38g2). So some actual number codes a proof of φ, and PA reaches φ. For a collection that reaches false statements about numbers this second argument fails, and 38j meets such a collection.

38h2Putting a formula’s own code into it

Take a formula with code n and one free placeholder x₀. Put the numeral n̄ in for x₀. The result is a statement; let sub(n) be its code. Reading the string back, putting the numeral in, and coding again is a recipe that always stops, so “y = sub(x)” is a search formula Sub(x, y), and PA reaches Sub(n̄, m̄), with m = sub(n), and that m is the only y with Sub(n̄, y). The second half is part of rung 40’s flag.

Self-statement technique: for every formula ψ(x₀) with one free placeholder, there is a statement δ such that PA reaches δ ⇔ ψ(⌜δ⌝).

D(x_0) = \exists y\,(\text{Sub}(x_0, y) \land \psi(y)) @@ “the result of putting x₀ into the formula with code x₀ has ψ”
n = \ulcorner D(x_0) \urcorner,\ \ \delta = D(\bar n) @@ the diagonal: the formula fed its own code
\text{sub}(n) = \ulcorner \delta \urcorner @@ δ is exactly D with n̄ put in for x₀
PA \vdash \delta \Leftrightarrow \exists y\,(\text{Sub}(\bar n, y) \land \psi(y)) @@ δ is that formula, written out
PA \vdash \forall y\,(\text{Sub}(\bar n, y) \Leftrightarrow y = \ulcorner \delta \urcorner) @@ Sub says sub, and sub(n) = ⌜δ⌝
\htmlClass{new}{PA \vdash \delta \Leftrightarrow \psi(\ulcorner \delta \urcorner)} \quad \blacksquare @@ swap, under the some, with the line above

δ does not contain its own code. It contains the numeral of n, the code of D, and a description, “put this into itself”, whose result is δ. 35b built a real off the diagonal of a list: at place n, look at the nth entry. 2d sifted the sets that are not members of themselves. The diagonal here is the same move, with formulas in place of entries.

38h3Statements about themselves

Any property a formula can express gives its own δ. Three are worth naming.

\psi(x) = \text{“}x \text{ is even”}:\ PA \vdash \delta_1 \Leftrightarrow \ulcorner \delta_1 \urcorner \text{ is even} @@ δ₁ is true exactly when its own code is even: it is, since every code has a power of 2 (38g1)
\psi(x) = \text{Prov}(x):\ PA \vdash \delta_2 \Leftrightarrow \text{Prov}(\ulcorner \delta_2 \urcorner) @@ “I am reached”: a standing question of 38j asks whether it is
\htmlClass{new}{\psi(x) = \neg\text{Prov}(x):\ PA \vdash \delta_3 \Leftrightarrow \neg\text{Prov}(\ulcorner \delta_3 \urcorner)} \quad \blacksquare @@ “I am not reached”: 38i

1b.4.4 refuted a statement that says of itself that it is not so. δ₃ says of itself something else: that it is not reached. Truth and reaching are different, so δ₃ need not clash. 38i finds out what it is, and 38k comes back to the statement that would say of itself that it is not true.

The basement · there if you want it

The accepted names

Proof(y, x) is the proof predicate, written Prf or Pf; Prov(x) is the provability predicate. The provable-mark technique is the first Hilbert–Bernays–Löb derivability condition. The self-statement technique is the diagonal lemma, or fixed-point lemma; δ is a fixed point of ψ. δ₃ is the Gödel sentence; δ₂ is Henkin’s sentence. That every recipe that always stops is expressible by a Σ₁ formula, held in trust here, is the representability of recursive functions.

Who said it first

Kurt Gödel built the Gödel sentence in 1931 by a diagonal construction for one formula; Rudolf Carnap stated the diagonal lemma in general in 1934. Leon Henkin asked in 1952 whether the sentence that says “I am provable” is provable; Martin Löb answered in 1955.

A proof that is not allowed

“Let δ be the statement ¬Prov(⌜δ⌝).” Not allowed as a definition: to write δ, its code must already be known, and its code depends on δ. The self-statement technique avoids the circle by building δ from D, whose code is fixed first. It gives a statement reached as equivalent to ¬Prov(⌜δ⌝), not one that is that string.
