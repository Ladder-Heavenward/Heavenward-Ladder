35e · proof

Arithmetic of sizes

Rung 4 added counts by putting separate piles together, multiplied them by choosing in stages, and raised them to powers by counting functions. None of that needed the piles to be finite, only the sets themselves. So sizes add, multiply and raise to powers in exactly the same way, with matching doing the work. The size of the counting numbers gets a mark of its own. Then the arithmetic turns strange. That size plus itself is itself, and so is that size times itself. Two raised to it is the size of all the parts of the counting numbers, and that is the size of the line: the line, the parts of the fractions and the endless strings of zeros and ones are all matched. The plane, two whole lines, has the size of one. Last, the step sets sizes beside the run past the endless from rung 29. The points of that run are orders, and many different orders have one size. Past the finite, size forgets the order, and the order knows more.

Sizes add as separate copies put side by side, multiply as pairs, and raise to powers as functions. The counting numbers’ size plus itself, and times itself, is itself. Two to that size is the size of the line, and of the plane. Different points of the run can have one size.

35e1Adding and multiplying sizes

Write A ⊔ B for (A × {0}) ∪ (B × {1}): a copy of A and a copy of B, kept separate even when A and B share members. From here on, for sets A, B and C, the statement |C| = |A| + |B| says that C is matched with A ⊔ B. The statement |C| = |A| · |B| says that C is matched with A × B. And |C| = |B|^|A| says that C is matched with the set of functions from A to B. For finite sets these are 4k5’s separate piles, 4k6’s stages and 4k9’s counted functions. Matched sets give matched copies, pairs and functions, so each statement says the same whichever matched sets are used.

From here on, ℵ₀ marks the size of ℕ: |A| = ℵ₀ says that A is matched with ℕ. Read it “aleph-null”. ℵ, aleph, is the first letter of the Hebrew alphabet, and the low 0 marks it as the first of a family that 35f continues.

Aleph-sums technique: ℵ₀ + ℵ₀ = ℵ₀, ℵ₀ · ℵ₀ = ℵ₀, and n + ℵ₀ = ℵ₀ for every number n.

(k, 0) \mapsto 2k,\ \ (k, 1) \mapsto 2k + 1 @@ ℕ ⊔ ℕ onto ℕ: even places for the first copy, odd for the second (4j’s even-or-odd: one way only)
\htmlClass{new}{\aleph_0 + \aleph_0 = \aleph_0} @@ a matching
(m, k) \mapsto p(m, k) @@ the pair-listing technique (35a2)
\htmlClass{new}{\aleph_0 \cdot \aleph_0 = \aleph_0} @@ a matching of ℕ × ℕ with ℕ
(j, 0) \mapsto j \text{ for } j < n,\ \ (k, 1) \mapsto n + k @@ n ⊔ ℕ onto ℕ: the n first, then the copy of ℕ moved up by n
\htmlClass{new}{n + \aleph_0 = \aleph_0} \quad \blacksquare @@ a matching

So ℵ₀ cannot be undone. There is no number x with x + ℵ₀ = ℵ₀ that makes subtraction work: every number x does it. Sizes past the finite add and multiply, and they do not take away.

35e2Two to the aleph-null is the line

2^ℵ₀ is the size of the functions from ℕ to 2. 4k10 matched those functions with the parts of a set by keep or drop, and since rung 7 every part is settled. So 2^ℵ₀ = |𝒫(ℕ)|, and 35c2 showed it is more than ℵ₀.

Line-size technique: the line has the size of the parts of ℕ: |ℝ| = 2^ℵ₀.

x \mapsto x,\ \ \mathbb R \to \mathcal P(\mathbb Q) @@ a real is a cut, a set of fractions (8a); different reals are different sets
\mathcal P(\mathbb Q) \text{ matched with } \mathcal P(\mathbb N) @@ carry each part through the matching of ℚ with ℕ (35a3)
s \mapsto 0.e_0e_1e_2\cdots,\ \ e_n = 5 \text{ if } n \in s,\ 4 \text{ if not} @@ 𝒫(ℕ) one-to-one into ℝ (35c2)
|\mathbb R| \le |\mathcal P(\mathbb N)| \text{ and } |\mathcal P(\mathbb N)| \le |\mathbb R| @@ the first two lines chained, and the third
\htmlClass{new}{|\mathbb R| = |\mathcal P(\mathbb N)| = 2^{\aleph_0}} \quad \blacksquare @@ the two-one-way technique (35d1)

Plane-as-line technique: the plane has the size of the line: |ℝ × ℝ| = |ℝ|. The parts of ℕ in pairs are matched with single parts: (s, t) ↦ {2n : n ∈ s} ∪ {2n + 1 : n ∈ t}, the first part on the evens and the second on the odds. So 2^ℵ₀ · 2^ℵ₀ = 2^ℵ₀. Match each coordinate of a point with a part of ℕ, and the plane is matched with the line. A line and a square, and a cube too, have one size. Whether such a matching can be continuous is the question of 35i.

35e3Sizes against orders

29·cb3 ran past the end of the counting numbers: ω, then ω + 1, ω + 2, and on, then with Replace ω + ω and ω·ω. As points of the run they are all different. ω + 1 has a last member and ω has none, so no matching that keeps the order joins them (29·cb3.1). As sizes, a matching need not keep the order.

Countable-points technique: ω + n, ω + ω and ω·ω are all of size ℵ₀, though no two of them are the same point.

\omega + n = \omega \cup \{\omega, \omega + 1, \ldots, \omega + (n - 1)\} @@ the one-past technique, n times (29·cb3.1)
|\omega + n| = \aleph_0 + n = \aleph_0 @@ the aleph-sums technique
\omega + \omega = \omega \cup \{\omega + k : k \in \omega\} @@ the doubled-run technique (29·cb3.3)
|\omega + \omega| = \aleph_0 + \aleph_0 = \aleph_0 @@ k ↦ ω + k matches ℕ with the second run
\omega\cdot\omega \text{ has the members } \omega\cdot k + n,\ \text{one for each pair } (k, n) @@ Replace on k ↦ ω·k, then merge (29·cb3.3)
\htmlClass{new}{|\omega\cdot\omega| = \aleph_0\cdot\aleph_0 = \aleph_0} \quad \blacksquare @@ the pair-listing technique

For the numbers, order and size agree: different numbers are different sizes, by 4k4’s one-count technique. Past ω they come apart. A point of the run is an order, and size is what is left when the order is forgotten. Many points share the size ℵ₀. Is every point of the run countable? 35f answers.

35e.4.5seam6e.4.5 asked whether the parts of the numbers can be put in a line in which every collection of them with a member has a first. The line is matched with those parts (35e2). With choice, the line can be lined up so that every part with a member has a least member (7·cb6), and then it is shaped like some point of the run. Its size is the size of that point.
In 1904 a lecture claimed a proof that the line cannot be lined up this way; within a day the proof was found to rest on a false result and was withdrawn. Weeks later choice was used to prove the opposite.
Which point of the run would the line be shaped like? Can a lining-up that nobody can describe give the line a place in the run? What would have followed had the lecture been right?

The basement · there if you want it

The accepted names

|A| + |B|, |A| · |B| and |B|^|A| are cardinal addition, multiplication and exponentiation; A ⊔ B is the disjoint union. ℵ₀ is aleph-null (or aleph-zero), the least infinite cardinal. 2^ℵ₀ is the cardinality of the continuum, often written 𝔠. Points of the run are ordinals, and their sizes cardinals; ω + 1 and ω are different ordinals of the same cardinality. The interleaving of 35e.4.3 is Cantor’s.

Who said it first

Georg Cantor defined the arithmetic of sizes and introduced the alephs in 1895, in the first part of his Contributions to the Founding of the Theory of Transfinite Numbers. He proved in 1877 that the square and the line have one size, and wrote to Dedekind: “I see it, but I do not believe it.” Julius König gave the 1904 Heidelberg lecture claiming the continuum cannot be well-ordered; Ernst Zermelo published the well-ordering theorem from choice later that year. The joke that choice is obviously true, well-ordering obviously false, and Zorn’s lemma no one knows, is Jerry Bona’s.

A proof that is not allowed

“ℵ₀ · ℵ₀ = ℵ₀, so by induction ℵ₀ · ℵ₀ · ⋯ = ℵ₀ for endlessly many factors, and ℵ₀^ℵ₀ = ℵ₀.” Not allowed: induction gives ℵ₀ⁿ = ℵ₀ for every number n, one n at a time, and says nothing about endlessly many factors at once. The functions from ℕ to ℕ cannot be listed.
