13m · technique

Homing in on a root with tangent lines, and how errors spread

13k's linearization stands in for a function near a point. This step gives it two jobs. The first: to find where a function is 0, find where its tangent line is 0 instead; that lands near, so do it again from there. For a polynomial the new error is a constant times the square of the old one, exactly. So the number of correct places roughly doubles at every step: this step proves it. The second job: you measured something, with an error, and put it through a formula. How large is the error in the answer? About the slope times the error in, and, for a power, the power times the error in as a part of the whole.

From a guess, walk down the tangent line to where it is 0: the next guess is the old guess less its value divided by its slope. To carry a small error through a formula, multiply it by the formula's slope.

13m1Walk down the tangent line

Say it in words first. You want a real r with f(r) = 0, and you have a guess x₀ near it. You cannot solve f(x) = 0; that is the whole trouble. But you can solve “the tangent line at x₀ is 0”, because a linear function with a slope other than 0 is 0 at exactly one input. Near x₀ the line and the function are nearly the same (13k's nearby-line-error), so where the line is 0 should be near where the function is. Call it x₁, and do it again.

y - f(x_0) = f'(x_0)\,(x - x_0) @@ the tangent line at the guess (13k)
0 - f(x_0) = f'(x_0)\,(\htmlClass{new}{x_1} - x_0) @@ where it is 0: put y = 0, and call that input x₁
x_1 - x_0 = -\dfrac{f(x_0)}{f'(x_0)} @@ multiplying-keeps-answers by f′(x₀)⁻¹: licensed only when f′(x₀) ≠ 0; turn the sides about (T)
x_1 = \htmlClass{keep}{x_0 - \dfrac{f(x_0)}{f'(x_0)}} @@ adding-keeps-answers

From here on, in this step, for f with a slope other than 0 at x, N(x) names x − f(x)/f′(x), the tangent step from x. The guesses x₀, x₁, x₂, ⋯ are 9·cb4's sequence with start x₀ and step N, for as long as no slope along the way is 0: xₙ₊₁ = N(xₙ).

Read the step as: the new guess is the old guess less the value over the slope. f(x₀)/f′(x₀) is how far along the line you must walk to lose all your value: the value, divided by how much value you lose per step of input.

13m2√2 by the averaging step

N(x) = x - \dfrac{x^2 - 2}{2x} @@ f(x) = x² − 2, f′(x) = 2x (polynomial-slope)
= \dfrac{2x^2 - x^2 + 2}{2x} @@ one bottom (5h)
= \htmlClass{new}{\tfrac12\Big(x + \dfrac{2}{x}\Big)} @@ split: the halfway real between x and 2/x

A Greek book on measuring, from the first century, finds a root of 720 this way. It takes 27, whose square is near 720, and divides 720 by 27 to get 26⅔. It takes the halfway number of the two, 26⅚, whose square differs from 720 by only a thirty-sixth. And it says that the same step, begun again from the new number, gives a closer one.

The averaging step is two thousand years older than the tangent step. If x is too large, then 2/x is too small, since their product is exactly 2. So √2 lies between them: take the halfway real. (161/6)² = 25921/36 = 720 + 1/36: the old book's “a thirty-sixth”, checked. Now run it from 1 in fractions, so nothing is rounded. A bar over digits, as in , is 8·cb5's mark: the block under the bar repeats without end.

x_1 = \tfrac12\big(1 + 2\big) = \tfrac32 = 1.5 @@ off by about 0.086
x_2 = \tfrac12\big(\tfrac32 + \tfrac43\big) = \tfrac{17}{12} = 1.41\overline{6} @@ off by about 0.0025
x_3 = \tfrac{577}{408} = 1.4142156\cdots @@ off by about 0.0000021
x_4 = \tfrac{665857}{470832} = \htmlClass{new}{1.41421356237}469\cdots @@ off by about 0.0000000000016; √2 = 1.41421356237309⋯

Count the correct places: 1, 3, 6, 12. Each step roughly doubles them. Compare 12e's bisection: each halving buys about a third of a place. 12 places of √2 from the trap [1, 2] take 40 halvings, since 2⁴⁰ = 1 099 511 627 776 is the first power of 2 past 10¹² (halvings-width). The tangent step took four. Bisection adds places; the tangent step multiplies them.

13m3Why the places double

For the averaging step the reason is one line of 5i's square-of-a-difference:

N(x) - \sqrt2 = \dfrac{x^2 + 2}{2x} - \sqrt2 = \dfrac{x^2 - 2\sqrt2\,x + 2}{2x} @@ one bottom; (√2)² = 2
= \htmlClass{new}{\dfrac{(x - \sqrt2)^2}{2x}} @@ square-of-a-difference turned about: the displacement pattern, squared

The new error is the old error squared, divided by 2x, about 2.8 near √2. And for any x > 0 it is never negative, so after the first step every guess is above √2. The same happens for every polynomial, and the proof is 9g's factor technique with 13c's product rule.

Polynomial-guess-error technique: for a polynomial, each new error is the old error squared, times a factor. Precisely: let f be a polynomial with a zero r, and q the polynomial with f(x) = (x − r)q(x) (factor). Wherever f′(x) ≠ 0, N(x) − r = (x − r)² · q′(x)/f′(x).

N(x) - r = (x - r) - \dfrac{f(x)}{f'(x)} = \dfrac{(x - r)\,f'(x) - f(x)}{f'(x)} @@ the line for N; one bottom
f'(x) = q(x) + (x - r)\,q'(x) @@ product for slopes on (x − r)q(x), with slope-of-a-line: (x − r)′ = 1
(x - r)f'(x) - f(x) = (x - r)q(x) + (x - r)^2 q'(x) - (x - r)q(x) @@ substitute for the expression; spread on ℝ
= \htmlClass{new}{(x - r)^2\,q'(x)} @@ negative on ℝ: the (x − r)q(x) cells cancel
N(x) - r = \htmlClass{keep}{(x - r)^2 \cdot \dfrac{q'(x)}{f'(x)}} \quad \blacksquare @@ fractions-of-rationals

For x² − 2 with r = √2, q is x + √2 and q′ is 1, which gives the averaging step's line. For x³ − 2 with c = ∛2, q is x² + cx + c² and q′ is 2x + c, so N(x) − c = (x − c)²(2x + c)/(3x²). And at r itself, product for slopes gives f′(r) = q(r) and f″(r) = 2q′(r), so near r the factor q′(x)/f′(x) heads to f″(r)/(2f′(r)): 13d's second slope sets the constant.

Places-double technique: once a guess is close enough, each new guess about doubles the number of correct places. Precisely: Let f, r, q be as in polynomial-guess-error. Let d > 0 be a distance. Suppose that on [r − d, r + d] there are bounds |q′(x)| ≤ C and |f′(x)| ≥ m > 0. Here m is a bound, not a slope. Put K = C/m. Suppose |x₀ − r| ≤ d and K · |x₀ − r| ≤ ½. Then every guess xₙ lies in [r − d, r + d]. And K · |xₙ − r| ≤ (K · |x₀ − r|)^(2ⁿ).

e_n = |x_n - r| @@ a step name for the n-th error
e_{n+1} = e_n^2 \cdot \dfrac{|q'(x_n)|}{|f'(x_n)|} \le \htmlClass{new}{K\,e_n^2} @@ polynomial-guess-error, size-of-a-product; the bounds are true since xₙ is in [r − d, r + d] (the hypothesis)
e_{n+1} \le (K e_n)\,e_n \le \tfrac12 e_n \le d @@ K eₙ ≤ K e₀ ≤ ½ by the hypothesis; so xₙ₊₁ stays in [r − d, r + d]
K e_{n+1} \le (K e_n)^2 \le \big((K e_0)^{2^n}\big)^2 = \htmlClass{keep}{(K e_0)^{2^{n+1}}} \quad \blacksquare @@ multiply by K; powers-keep-order; the hypothesis; power-of-a-power (2ⁿ · 2 = 2ⁿ⁺¹); induction

For x² − 2 on [1, 2]: q′ = 1, so C = 1; f′(x) = 2x ≥ 2, so m = 2; K = ½. From x₀ = 3/2, K e₀ = ½ · 0.0858 ≈ 0.043, so K e₃ ≤ 0.043⁸, which is below 10⁻¹⁰. Three steps are guaranteed ten places, and the run above shows twelve. The exponent 2ⁿ is the doubling. For a function that is not a polynomial there is no factor to factor with. The same bound is true near a zero where the slope is not 0; that is held in trust until 14c proves it.

13m4Cube roots, and choosing the start

For ∛2, f(x) = x³ − 2 and f′(x) = 3x², so N(x) = (2x + 2/x²)/3: a weighted halfway real of x, x and 2/x², whose product is 2. From 1: 4/3, then 91/72 ≈ 1.2639, then 1.25993⋯, then 1.2599210500⋯, against ∛2 = 1.2599210499⋯. The errors run about 0.073, 0.004, 0.000012, 0.00000000012: squaring, as polynomial-guess-error says. Starting from 1 wastes a step; from 5/4 you have eight places after two steps. Choosing the start is part of the skill, as choosing the base was on 13k.

13m5The oldest working, and a later one

The inventor of the tangent step described it in a manuscript written in 1669 and printed only in 1711, and he did not use slopes at all. His example was y³ − 2y − 5 = 0. He put in a guess plus a small unknown, and set aside every piece with its square or more.

y = 2 + p @@ 2 is close: 8 − 4 − 5 = −1
(2 + p)^3 - 2(2 + p) - 5 = p^3 + 6p^2 + 10p - 1 @@ two-term-power (row 3 of 4k's table), then collect
10p - 1 = 0 \;\Rightarrow\; p = 0.1,\ \ y = 2.1 @@ the pieces with p² or more set aside
y = 2.1 + q:\ \ q^3 + 6.3q^2 + 11.23q + 0.061 = 0 @@ again, on the new equation
q = -\dfrac{0.061}{11.23} \approx -0.0054,\ \ \htmlClass{new}{y \approx 2.0946} @@ the zero is 2.0945514⋯

Read the line 10p − 1 with 13k's eyes. The −1 is f(2) and the 10 is f′(2) = 3 · 4 − 2. What the manuscript kept is f(2) + f′(2)p, the linearization, and solving it is one of N's steps: 2 − (−1)/10 = 2.1. What it set aside is the linearization's error E(p), which nearby-line-error controls in the limit. Nothing on this ladder is set aside for being small. A book of 1690 went back to the first equation with each improved guess, instead of building a new one. That is the loop as written above. In 1740 the method was stated for general equations, in the language of fluxions. Its accepted name is Newton’s method: the tangent step, taken again and again.

13m6Where it fails

12e's bisection could not fail once it held a trap: the trap always held a zero. The tangent step has no trap. It trusts the tangent line, and the tangent line can mislead in three ways.

x^2 - 2 \text{ from } 0:\ \ f'(0) = 0 @@ a level tangent line is never 0: N(0) names nothing (nothing-times-0-is-1)
x^2 - 2 \text{ from } 0.1:\ \ N(0.1) = \tfrac12(0.1 + 20) = 10.05 @@ nearly level: it lands far away (the averaging step recovers; most functions do not)
x^3 - 2x + 2 \text{ from } 0:\ \ N(0) = 0 - \dfrac{2}{-2} = 1 @@ f(0) = 2, f′(0) = −2
N(1) = 1 - \dfrac{1}{1} = \htmlClass{new}{0} @@ back where it started: 0, 1, 0, 1, ⋯ for ever. The zero is near −1.7693; from −2, N gives −1.8
\sqrt[3]{x}:\ \ N(x) = x - \dfrac{x^{1/3}}{\frac13 x^{-2/3}} = x - 3x = \htmlClass{new}{-2x} @@ 13h's slope of the cube root (and its chain for x < 0); fraction-exponent. From 1: −2, 4, −8, 16, every step twice as far

The cube root's only zero is 0, where it has no slope (13e). Every step doubles the distance and changes the side; no start but 0 itself works. So the working rule is the engineers': trap first, then sharpen. Bisect until the trap is small and the slope inside it is far from 0. Then hand over to the tangent step for the last places.

Running it backwards: given a step, find the equation it hunts. N(x) = ½(x + 5/x) has the same shape as the averaging step, so it hunts √5. A fixed point says it too: N(x) = x exactly when f(x)/f′(x) = 0, that is, f(x) = 0. Here x = ½(x + 5/x) gives 2x = x + 5/x, then x = 5/x, then x² = 5.

13m7The second job: how errors spread

Take as given that a body dropped from rest falls x = ½gt² metres in t seconds, with g ≈ 9.8 m/s². You time a fall at t = 2.0 s, and your stopwatch is good to 0.1 s either way. The distance is 4.9 · 4 = 19.6 m. How sure are you of it? Say it in words. An error in the measurement is a change Δt of input. The output changes by the slope times Δt, plus 13k's error E(Δt), which divided by Δt heads to 0.

x = 4.9\,t^2,\ \ t = 2.0,\ \ \Delta t = \pm 0.1 @@ the formula and the measurement, in metres and seconds
x'(t) = 9.8\,t = 19.6 \ \text{m/s} @@ the slope at the measured input (power for slopes, constant-factor for slopes)
\Delta x = \htmlClass{new}{19.6 \cdot 0.1} + E = 1.96 + E @@ 13k: the value here plus the slope times the change, plus the error
x(2.1) = 21.609,\ \ x(1.9) = 17.689 @@ the ends: 2.009 above and 1.911 below 19.6
E = 4.9\,(\Delta t)^2 = 0.049 @@ the cell with two Δt's (13g), the same either way

So the distance is 19.6 m give or take about 2 m. The cell with two changes, 0.049, is small beside 1.96; that is when the estimate is good.

From here on, the relative error of a measured value x with error Δx is Δx/x. It is the error as a part of the whole, often written as a percent (5h). Likewise Δy/y for an output.

So 0.1 s in 2.0 s is a relative error of a part in 20, or 5%; 1.96 m in 19.6 m is a part in 10, or 10%. The square doubled the relative error, and the slope says why. Tracking how an input's error spreads to an output is called propagation of error.

13m8Relative errors through powers and products

Relative-errors technique: through a power, the relative error is multiplied by the power. Precisely: let y = c · xⁿ with c ≠ 0, n a fraction and x > 0. Then the ratio of relative errors (Δy/y)/(Δx/x) heads to n as Δx → 0. It is (Δy/Δx) · (x/y). Δy/Δx heads to c n x^(n−1) by fraction-power for slopes and constant-factor for slopes. Times x/(c xⁿ) that is n, by fraction-exponent. So a square doubles the relative error, a cube triples it, a square root halves it, and the constant c does not matter at all.

P = \dfrac{V^2}{R},\ \ R = 4\ \Omega,\ \ V = 12.0 \pm 0.1\ \text{V} @@ given: a resistor of R ohms at V volts uses power P = V²/R watts; here P = 36 W
\dfrac{\Delta V}{V} = \tfrac{0.1}{12} \approx 0.83\% \;\Rightarrow\; \dfrac{\Delta P}{P} \approx \htmlClass{new}{1.67\%} @@ relative-errors with n = 2: about ±0.6 W (12.1²/4 = 36.6025, 11.9²/4 = 35.4025)
B = 70\,M^{3/4}:\ \ \dfrac{\Delta M}{M} = 4\% \;\Rightarrow\; \dfrac{\Delta B}{B} \approx \htmlClass{new}{3\%} @@ given: an animal of mass M kg uses energy at a rate B = 70M^(3/4); n = ¾; the 70 does not matter
t = \sqrt{2x/g}:\ \ \dfrac{\Delta x}{x} = 2\% \;\Rightarrow\; \dfrac{\Delta t}{t} \approx \htmlClass{new}{1\%} @@ n = ½: a root halves the relative error

And for a product, product for slopes gives (uv)′/(uv) = u′/u + v′/v: the relative errors of the factors add. So a part in 48 of one factor and a part in 630 of the other give about a part in 45 of the product, since 1/48 + 1/630 ≈ 1/45. 13l's xy = 1 is the same fact turned round: y′/y = −1/x · 1. So x and 1/x carry equal and opposite relative errors (n = −1).

13m9Running it backwards

Running it backwards is the question an experimenter asks: how good must my measurement be? If the energy use B must be known to within 3%, the mass must be known to within 4%, because the power is ¾: divide the error you can bear by the power. If the fall's distance must be known to 1%, the time must be known to ½%.

13m10Illegal moves

x_{n+1} = x_n - \dfrac{f'(x_n)}{f(x_n)}\,? @@ upside down: the walk is value over slope. For x² − 2 from 1 it gives 1 − 2/(−1) = 3, not 3/2
\Delta x = (\Delta t)^2\,? @@ squaring the error: that is only the cell with two changes, 0.01 times 4.9. The slope carries the error: 1.96
\dfrac{\Delta x}{x} = \Big(\dfrac{\Delta t}{t}\Big)^2\,? @@ 5% would become 0.25%. The power multiplies the relative error (relative-errors); it does not raise it
\begin{aligned}&\text{the tangent step from}\\ &\quad\text{any start finds the zero}\,?\end{aligned} @@ x³ − 2x + 2 from 0 cycles; the cube root runs away. Trap first
\Delta y = f'(x)\,\Delta x \text{ for a large } \Delta x\,? @@ the estimate is only as good as the linearization: for x = 4.9t² with Δt = 1, E = 4.9, not small beside 19.6

That completes the rung's rules of slopes. Sums, products, quotients, powers with fractions and chains of any length each have a slope you can find, with a reason beside every line. The tangent line turns a slope into an estimate, and the tangent step turns the estimate into a zero. You can run each rule backwards, and you know where each one stops: at a joint whose pieces arrive with different slopes, at a discontinuity, and where the slope is 0.

Who said it first

The averaging step is Heron’s, from his Metrica; the tangent step is Isaac Newton’s, from De analysi (written 1669, printed 1711). The book of 1690 is Joseph Raphson’s Analysis aequationum universalis, and the statement of 1740 is Thomas Simpson’s. The three-quarter-power law for an animal’s energy use, B = 70M^(3/4), is Kleiber’s law. The mathematician of question 13m.4.4 is Arthur Cayley.

Heron, in the Metrica, finds a root of 720 by taking 27, whose square is near it, dividing 720 by 27 to get 26⅔, and taking the halfway number of the two, 26⅚, whose square differs from 720 by only a thirty-sixth; and he says that the same step, begun again from the new number, gives a closer one.

Heron of Alexandria, Metrica I.8 (first century); paraphrased

Accepted names: the tangent step is Newton’s method, or the Newton–Raphson method; the averaging step is the Babylonian method, or Heron’s method.
