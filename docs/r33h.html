33h · technique

Separation of variables by hand

The proof steps separated one rule with one kind of end: a rod held at 0 at both ends. Real rods are not so obliging. A pipe wrapped in lagging lets no heat out of its ends at all. A bar laid between a furnace and a cold wall has one end hot and the other cold. A plate has four edges, and only one of them is warm. Each asks for the same three moves, done by hand: find the still state that the ends want, take it away so that the ends become 0, then separate what is left into shapes and fade or grow each one. Which shapes come out depends on the ends. Ends held at a temperature give sines, ends sealed against heat give cosines, and a plate gives a shape that grows from one edge to the other instead of fading in time. The worked runs here are checked twice, once by the series and once by a symmetry that needs no series at all.

Sealed ends give cosine shapes, with the average kept forever. Ends at two temperatures are handled by taking away the straight line between them. A plate warm on one edge is a sum of sines along that edge, each growing toward it from the opposite edge.

33h1Sealed ends

A rod of length L wrapped so that no heat crosses its ends has u_x(0, t) = u_x(L, t) = 0: the flow −Ku_x is 0 there. The lines of the cooling-shape technique (33a2) run again with X′(0) = X′(L) = 0. Now λ = 0 is allowed, with X = 1, and λ > 0 needs X = cos(√λ x) with sin(√λ L) = 0.

Sealed-rod technique: on a rod with both ends sealed, u = a₀/2 + Σ a_n e^(−κ(nπ/L)²t) cos(nπx/L), with a_n = (2/L)∫₀ᴸ f cos(nπx/L); and the average temperature a₀/2 never changes.

X^{\prime}(0) = 0 \Rightarrow X = A\cos(\sqrt\lambda\,x) @@ the steady swing (24h): the sine part has slope √λ at 0
X^{\prime}(L) = 0 \Rightarrow \sqrt\lambda = \tfrac{n\pi}{L},\ \ n = 0, 1, 2, \ldots @@ sin(√λ L) = 0; n = 0 is the constant shape
\text{the cosines are perpendicular, with numbers } (n\pi/L)^2 \ge 0 @@ the swap-by-parts technique holds with sealed ends too: the end terms −p y′z vanish (33f)
\tfrac{d}{dt}\textstyle\int_0^L u\,dx = \kappa\big(u_x(L, t) - u_x(0, t)\big) = 0 @@ the slope under the total, the rule, then 16c
\htmlClass{new}{\tfrac1L\textstyle\int_0^L u\,dx = \tfrac{a_0}{2} \text{ for every } t} \quad \blacksquare @@ the books are closed at both ends
  
f = 100 \text{ on } [0, L/2),\ \ 0 \text{ on } (L/2, L] @@ two copper half-rods at 100 °C and 0 °C pressed together and wrapped
a_0 = \tfrac{2}{L}\textstyle\int_0^{L/2} 100\,dx = 100 @@ the average is 50
a_n = \tfrac{2}{L}\textstyle\int_0^{L/2} 100\cos\tfrac{n\pi x}{L}\,dx = \tfrac{200}{n\pi}\sin\tfrac{n\pi}{2} @@ 0 for even n
\htmlClass{new}{u = 50 + \tfrac{200}{\pi}\Big(e^{-\kappa\pi^2t/L^2}\cos\tfrac{\pi x}{L} - \tfrac13 e^{-9\kappa\pi^2t/L^2}\cos\tfrac{3\pi x}{L} + \cdots\Big)} \quad \blacksquare @@ the sealed-rod technique

The rod settles at 50 °C, the average, and it reaches it as a single cosine sinking into the level: hotter at one end, cooler at the other, by less every second.

33h2Ends at two temperatures

A bar has u(0, t) = A and u(L, t) = B for every t. The straight line s(x) = A + (B − A)x/L meets both ends and has s″ = 0, so it is a still answer.

Shift-to-the-line technique: u is the answer with ends A and B and start f exactly when w = u − s is the answer with ends 0 and start f − s; so u = s + Σ b_n e^(−κ(nπ/L)²t) sin(nπx/L), with b_n the sine coefficients of f − s.

w_t = u_t,\ \ w_{xx} = u_{xx} - s^{\prime\prime} = u_{xx} @@ s does not move with t, and s″ = 0
w(0, t) = A - A = 0,\ \ w(L, t) = B - B = 0 @@ the line meets both ends
w(x, 0) = f(x) - s(x) @@ the start, shifted
\htmlClass{new}{u = s + \textstyle\sum b_n e^{-\kappa(n\pi/L)^2t}\sin\tfrac{n\pi x}{L}} \quad \blacksquare @@ the fading-series technique for w; the one-future technique says there is no other u
  
f = 20,\ \ A = 100,\ \ B = 0 @@ a bar at room temperature has one end put to 100 °C and the other to 0 °C
f - s = -80 + 100\tfrac{x}{L} @@ 20 − (100 − 100x/L)
b_n = \tfrac{2}{L}\textstyle\int_0^L \big(-80 + 100\tfrac{x}{L}\big)\sin\tfrac{n\pi x}{L}\,dx = \tfrac{40\,((-1)^{n+1} - 4)}{n\pi} @@ parts once for the x term
\htmlClass{new}{b_1 = -\tfrac{120}{\pi},\ \ b_2 = -\tfrac{100}{\pi},\ \ b_3 = -\tfrac{40}{\pi}} \quad \blacksquare @@ −120/(nπ) for odd n, −200/(nπ) for even n

After a time much longer than L²/(κπ²), the bar is the straight line from 100 to 0, and the gap below it is one sine arch of depth (120/π)e^(−κπ²t/L²), sinking.

33h3A plate warm on one edge

A still rectangular plate, 0 ≤ x ≤ W and 0 ≤ y ≤ H, is held at 0 on three edges and at g(x) on the top edge y = H. Separate a still state: u = X(x)Y(y) with Δu = 0 gives X″/X = −Y″/Y = −λ. The sides x = 0 and x = W at 0 give X = sin(nπx/W), as on 33a2. Then Y″ = (nπ/W)²Y with Y(0) = 0, so Y = sinh(nπy/W), with sinh z = (e^z − e^(−z))/2 as on 29j.

Warm-edge technique: if g has sine coefficients b_n with Σ|b_n| settling, the one still state is u = Σ b_n sin(nπx/W) sinh(nπy/W) / sinh(nπH/W). Each term is balanced, is 0 on three edges, and on the top edge is b_n sin(nπx/W). The one-still-state technique (33d3) says there is no other.

W = H = 1,\ \ g = 100 @@ a square plate, its top edge held at 100 °C, the others at 0 °C
b_n = \tfrac{400}{n\pi} \text{ for odd } n,\ \ 0 \text{ for even } n @@ the sine coefficients of 100 on [0, 1]
u(\tfrac12, \tfrac12) = \textstyle\sum_{\text{odd } n} \tfrac{400}{n\pi}\,\tfrac{\sinh(n\pi/2)}{\sinh(n\pi)}\,\sin\tfrac{n\pi}{2} @@ the warm-edge technique at the centre
= 25.37 - 0.38 + 0.01 - \cdots @@ the terms shrink like e^(−nπ/2)/n
\htmlClass{new}{u(\tfrac12, \tfrac12) = 25} \quad \blacksquare @@ checked without the series, below

Turn the square a quarter turn at a time. The four plates, each with a different edge at 100 and the rest at 0, add up to a plate with every edge at 100, whose one still state is 100 everywhere. By the quarter turns, the four have the same value at the centre. So each has 25 there. The series, summed, agrees. The top edge’s jump to 0 at the corners makes Σ|b_n| fail to settle; inside the plate the factors sinh(nπy/W)/sinh(nπH/W) shrink so fast that it does not matter.

The accepted names

Sealed ends are Neumann (or insulated) boundary conditions, and held ends are Dirichlet conditions; the cosine series is the Fourier cosine series. The straight line s is the steady-state solution, and taking it away is homogenising the boundary conditions. The plate problem is the Dirichlet problem for Laplace’s equation on a rectangle; the quarter-turn argument is superposition with symmetry. sinh is the hyperbolic sine.

Who said it first

Joseph Fourier worked the sealed ring and the bar with fixed end temperatures in his Théorie analytique de la chaleur (1822), and the plate warm on one edge is his rectangular lamina, solved by the same sum. The symmetry check for the square is old folklore of the subject, set as an exercise in many textbooks.
