40·now · research front

How Long Can a Tiny Machine Run?

How long can a tiny machine run? 7·then named the longest run of a stopping machine with n states, BB(n), proved it is a number, and reported that BB(5) is 47 176 870, settled in 2024 by a group of mostly volunteers with a proof a machine checked. It left two things for later: why no machine can work BB(n) out for every n, and how a finite question about machines this small could take sixty years. This page answers both with the tools of this rung. BB grows past every function a machine computes, because a machine that knew it could decide stopping. Settling five states meant sorting every five-state table into stops and never stops, the hand catches of 40j run by the hundred million, with new kinds of catch for the machines the old ones missed. And past some size the question leaves mathematics as we have it: there is a machine of fewer than eight hundred states that stops exactly when the usual axioms of mathematics clash, so those axioms cannot say whether it stops, nor what BB is at its size. In between sit six-state machines whose stopping turns on old puzzles about halving and tripling that nobody can solve.

No machine computes BB, since a machine that did would decide stopping. The five-state value was settled by listing every table and catching each non-stopper with a proof of a few known shapes, the last a set of tape patterns that the machine can never leave. A machine that searches the axioms for a clash runs for ever and its running cannot be proved from those axioms, so BB at its size escapes them.

40now2Sorting Every Five-State Table

To prove BB(5) = 47 176 870 it is enough to find one five-state machine that stops after exactly that many steps, which was found in 1989, and to prove that every other five-state machine either stops sooner or never stops. The tables were not listed one by one. They were grown: start with a table with no rows, run it, and add a row only when the machine reaches a state and mark with none, trying each choice. Tables that differ only by renaming states are grown once. That left about 181 million machines to sort.

Most were sorted by the catches of 40j: a configuration seen twice, a march into blank tape. Others needed a stronger catch, 4l’s kept-statement technique applied to sets of tapes.

Closed-patterns technique: if a set of configurations holds the start, holds the next of each of its members, and holds no configuration whose state is a stop state, then the machine never stops.

\text{the }\allowbreak \text{set: }\allowbreak \text{tapes } (10)^k \text{ with } A \text{ on }\allowbreak \text{the }\allowbreak \text{blank }\allowbreak \text{after }\allowbreak \text{them, }\allowbreak \text{and } (10)^k1 \text{ with } B \text{ after, }\allowbreak \text{for } k \ge 0 @@ a pattern for every moment

\htmlClass{new}{\text{it }}\allowbreak \htmlClass{new}{ \text{never }}\allowbreak \htmlClass{new}{ \text{stops}} \quad \blacksquare @@ the kept-statement technique (4l): every configuration of the run is in the set

For the hard machines the set was found by a machine: a pattern machine with no memory, of 40g1, whose accepted strings are the allowed tapes. Checking that a pattern set is closed is a finite check. A handful of machines needed proofs of their own. In 2024 the whole sorting, with every catch, was written for a proof checker of the small-kernel kind of 38·now and checked: the five-state answer rests on the core, not on the volunteers’ programs.

40now3A Machine Past the Axioms

Let T be a collection of axioms, holding PA, settled by a recipe and true in N; the usual axioms of sets are one, read in arithmetic. Let M_T be the machine that runs down the list of T’s proofs and stops if it finds a proof of 0 = 1.

Axioms-outrun technique: M_T never stops; T does not reach that M_T never stops; and if M_T has n states, T reaches no true statement of the form BB(n) = k.

T \text{ true in } N \Rightarrow T \text{ reaches }\allowbreak \text{no } 0 = 1 \Rightarrow M_T \text{ never }\allowbreak \text{stops} @@ true-everywhere (38c)
\text{“} M_T \text{ never }\allowbreak \text{stops”} \iff \text{Con}_T\text{, }\allowbreak \text{reached }\allowbreak \text{in }\allowbreak \text{PA} @@ the search-graph technique (40b3) writes M_T’s run in arithmetic
T \nvdash \text{Con}_T @@ the no-self-certificate technique (38j), run for T in place of PA, with the same proof
T \vdash BB(n) = k \Rightarrow T \text{ runs } M_T \text{ for } k \text{ steps }\allowbreak \text{and }\allowbreak \text{reaches }\allowbreak \text{that }\allowbreak \text{it }\allowbreak \text{has }\allowbreak \text{not }\allowbreak \text{stopped} @@ a true bounded statement: search-reached (38g4)
\htmlClass{new}{\Rightarrow T \vdash \text{“} M_T \text{ never }}\allowbreak \htmlClass{new}{ \text{stops”}:\ \bot} \quad \blacksquare @@ so T reaches no BB(n) = k

BB(n) is still one number, by 7·then and rung 7’s either-way principle. T cannot find it. Such machines have been built small: for the usual axioms of sets, a machine with fewer than 750 states, as 7·then reported, and the records keep falling. For arithmetic itself the known machines are smaller still. Somewhere between 5 and a few hundred states, the question of how long a tiny machine can run leaves every collection of axioms anyone uses.

40now4Six States and an Old Puzzle

Take a number. If it is even, halve it; if odd, triple it and add 1. Does every start reach 1? From 7 it takes 16 steps. From 27 it takes 111 steps and climbs as high as 9232 on the way. Every start below about 2.95 × 10²⁰ has been checked, and nobody can prove it for every start.

27 \to 82 \to 41 \to 124 \to 62 \to 31 \to 94 \to 47 \to \cdots @@ odd: 3n + 1; even: n/2
\text{highest }\allowbreak \text{value }\allowbreak \text{on }\allowbreak \text{the }\allowbreak \text{way: } 9232 @@ reached at step 77
\htmlClass{new}{\text{reaches } 1 \text{ after } 111 \text{ steps}} \quad \blacksquare @@ checked by running it

In 2024 the same volunteers found a six-state machine that stops exactly when a run of a rule much like this one, halving and multiplying by three halves, ever has more odd values than twice its even ones. Whether that ever happens is open, and the chances, read as 30h’s settling averages, say it almost surely never does. So BB(6) cannot be settled without settling a question of this old kind. In 2025 a six-state machine was shown to stop only after more than 2↑↑↑5 steps, 7·then’s arrows, so BB(6) is past that. Two states hold 6 steps, three 21, four 107, five 47 million; six lies beyond any number written with fewer than three arrows.

Open: BB(6); whether some six-state machine’s stopping is beyond the usual axioms; and the smallest n for which BB(n) is. The bet of most who work on it is that the answer to the last is far below 750.

The cellar · there if you want it

The accepted names

Growing tables row by row is tree normal form enumeration. The catches are deciders: cyclers, translated cyclers, backward reasoning, bouncers, and the closed-patterns technique is the method of closed tape languages, or co-CTL, with finite automata reduction. The proof checker was Coq, now named Rocq. M_T is a consistency-searching machine, and the axioms-outrun technique is the independence of BB values from ZF. The halving and tripling rule is the Collatz conjecture, or 3n + 1 problem; machines like the six-state one are called cryptids, and that one is Antihydra.

Who said it first

Heiner Marxen and Jürgen Buntrock found the five-state champion in 1989. The bbchallenge collaboration, started by Tristan Stérin in 2022, finished the proof in 2024, with the Coq proof led by the contributor known as mxdys; the paper appeared in 2025. Adam Yedidia and Scott Aaronson (2016) built a machine of 7918 states whose stopping ZF cannot decide; later work by Stefan O’Rear and others brought it below 750. Lothar Collatz posed the 3n + 1 question in 1937. The bound 2↑↑↑5 for BB(6) was found in 2025 by the contributor known as mxdys.

A proof that is not allowed

“The five-state champion stops after 47 176 870 steps, and the others we ran for a hundred million steps did not stop, so BB(5) = 47 176 870.” Not allowed: a machine not stopped after a hundred million steps may stop later. Each non-stopper needs a catch that proves it never stops, and the 2024 proof gave one for every machine.
