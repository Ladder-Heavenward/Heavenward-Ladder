40·now · research front

Can a Machine Check the Proof?

Every proof on the ladder is checked by a reader. A proof assistant is a program that checks each step of a proof itself, by rules like 40f’s. This annex looks at what has been proved this way, and what it costs.

Write the proof so a machine can check every step. Then trust only the small checker, not the large proof.

40now1A Small Checker

A proof assistant holds a small core that checks each step against a fixed list of rules. The proof may be huge, and machines may help write it, but only the core decides. So the trust needed shrinks to the core, which is small enough for people to read.

40now2A Compiler Proved Right

A C compiler has been built together with a machine-checked proof of 40j’s demand: every run of the compiled program is a run of the source. The proof is far longer than the compiler.

40now3A Kernel Proved Right

In 2009 a team proved, by machine, that the kernel of an operating system, the part that runs every other program, does what its precise description says. The cost was many years of work for a program of about ten thousand lines.
