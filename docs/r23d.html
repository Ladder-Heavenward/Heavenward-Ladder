23d · proof

Settling Everywhere at Once

Think of a list of curves instead of a list of numbers. At each input, the heights of the curves form a list, and that list may settle. If it settles at every input, the places it settles draw a new curve. You might expect the new curve to inherit what the old ones share, such as having no breaks. It need not. Curves with no breaks can settle, input by input, onto a curve with a jump, because near the jump they settle more and more slowly. This step finds the stronger kind of settling that rules this out: settling everywhere at once, with one stage that works for every input. That kind does pass on having no breaks, and power sums settle that way inside their reach.

A list of curves can settle at every input and still lose what the curves had in common. Settling everywhere at once means one stage works for every input. It keeps curves without breaks, and power sums settle that way inside their reach.

23d1Settling at Each Point

From here on, a list of functions f₁, f₂, f₃, … on a set D settles at each point to f when, for every x in D, the list of reals fₙ(x) settles at f(x). Accepted name: pointwise convergence.

f_n(x) = x^n \text{ on } [0, 1] @@ each fₙ is continuous (11d: a polynomial)
0 \le x < 1 \Rightarrow x^n \to 0;\ \ x = 1 \Rightarrow x^n = 1 @@ 15i2: rⁿ heads to 0 for |r| < 1
f(x) = 0 \text{ for } x < 1,\ \ f(1) = 1 @@ the list settles at each point
\htmlClass{new}{\text{each } f_n \text{ is continuous; } f \text{ is not, at } 1} \quad \blacksquare @@ lim_{x→1⁻} f(x) = 0 ≠ f(1) (10e, 11a)

Written as a sum, (1 − x) + (x − x²) + (x² − x³) + ⋯ has running totals 1 − xⁿ. Every piece is continuous, and the total jumps at 1. A great book of 1821 claimed that a sum of continuous pieces is always continuous. This sum shows the claim needs something more. The rest of this step finds what.

23d2Settling Everywhere at Once

From here on, fₙ settles everywhere at once to f on D when for every ε > 0 there is N such that every n ≥ N and every x in D have |fₙ(x) − f(x)| < ε. Accepted name: uniform convergence.

Set the two side by side. At each point: for every ε and every x there is an N, which may depend on x. Everywhere at once: for every ε there is one N, which then works for every x. Only the order of "every x" and "some N" has changed. 10a warned that swapping that order changes the claim.

\varepsilon = \tfrac14,\ \text{any } N,\ n = N @@ the challenge
x_n = (\tfrac12)^{1/n} < 1 @@ a root of ½ is below 1
|f_n(x_n) - f(x_n)| = \tfrac12 - 0 = \tfrac12 \ge \tfrac14 @@ the answer fails at xₙ
\htmlClass{new}{x^n \text{ does not settle everywhere at once on } [0, 1]} \quad \blacksquare @@ no N answers ε = ¼
0 \le x \le r < 1 \Rightarrow |x^n - 0| \le r^n @@ but on [0, r] the worst point is r
\htmlClass{new}{x^n \to 0 \text{ everywhere at once on } [0, r]} \quad \blacksquare @@ choose N with rᴺ < ε (15i2)

23d3At Once Keeps Continuity

Kept-continuity technique: if each fₙ is continuous at w and fₙ settles everywhere at once to f near w, then f is continuous at w. Split ε in three.

\varepsilon > 0;\ \text{choose } n \text{ with } |f_n(x) - f(x)| < \tfrac{\varepsilon}{3} \text{ for every } x @@ settling everywhere at once
\text{choose } \delta \text{ with } |x - w| < \delta \Rightarrow |f_n(x) - f_n(w)| < \tfrac{\varepsilon}{3} @@ fₙ is continuous at w (11a)
|f(x) - f(w)| \le |f(x) - f_n(x)| + |f_n(x) - f_n(w)| + |f_n(w) - f(w)| @@ the triangle technique (8h), twice
\htmlClass{new}{|x - w| < \delta \Rightarrow |f(x) - f(w)| < \varepsilon} \quad \blacksquare @@ each of the three is under ε/3

The first line spends "everywhere at once": one n that is good at x and at w together. Settling at each point would give an n for x and another for w, and no single fₙ to compare through.

23d4A Comparison Test for Settling at Once

At-once comparison technique: if |fₖ(x)| ≤ Mₖ for every x in D and every k, and Σ Mₖ settles, then Σ fₖ settles everywhere at once on D.

\textstyle\sum f_k(x) \text{ settles in size for each } x @@ comparison with ΣMₖ (22e1)
\Big|\textstyle\sum_{k \le n} f_k(x) - \sum_k f_k(x)\Big| = \Big|\sum_{k > n} f_k(x)\Big| \le \sum_{k > n} M_k @@ the tail, bounded with no x left in it
\textstyle\sum_{k > n} M_k \to 0 @@ the tail of a sum that settles (22d)
\htmlClass{new}{\textstyle\sum f_k \text{ settles everywhere at once on } D} \quad \blacksquare @@ one N for every x
  
0 < r < R,\ |x - w| \le r \Rightarrow |u_k(x-w)^k| \le |u_k| r^k @@ the worst point is at distance r
\textstyle\sum |u_k| r^k \text{ settles} @@ r is inside the reach (23c2)
\text{the power sum settles everywhere at once on } [w - r, w + r] @@ the at-once comparison technique
\htmlClass{new}{\text{a power sum is continuous at every } x \text{ with } |x - w| < R} \quad \blacksquare @@ kept continuity (23d3), with r between |x − w| and R

23d5Illegal Moves

\text{each } f_n \text{ continuous, } f_n \to f \text{ at each point} \Rightarrow f \text{ continuous}\,? @@ xⁿ on [0, 1] (23d1)
\text{settles everywhere at once on } [0, r] \text{ for each } r < 1, \text{ so on } [0, 1)\,? @@ one N for each r is not one N for all; xⁿ fails on [0, 1)
\textstyle\sum x^k \text{ settles everywhere at once on } (-1, 1)\,? @@ only on [−r, r] with r < 1; near ±1 the tails do not shrink together
\forall x\ \exists N \text{ is the same as } \exists N\ \forall x\,? @@ 10a: swapping turn A and turn E changes the claim

The accepted names

Settling at each point is pointwise convergence; settling everywhere at once is uniform convergence. The kept-continuity technique is the uniform limit theorem; the at-once comparison technique is the Weierstrass M-test.

Who said it first

Augustin-Louis Cauchy's Cours d'analyse (1821) stated that a sum of continuous functions is continuous. Niels Henrik Abel, in 1826, gave a sum of sines with a jump as an exception in a footnote. Philipp Ludwig von Seidel and George Stokes (both 1847) found the missing condition, and Karl Weierstrass made uniform convergence a standard tool in his Berlin lectures from the 1860s. In 23d.4.5, the course is Cauchy's and the footnote Abel's. Cauchy added the missing condition himself in 1853. Imre Lakatos (Proofs and Refutations, 1976) read the condition as born from the counterexample; Abraham Robinson (1966) and Lakatos later argued that Cauchy's infinitely small quantities made his claim true as he meant it.
