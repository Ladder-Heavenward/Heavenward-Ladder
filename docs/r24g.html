24g · technique

The integrating factor

Many rules on rates say that a quantity changes by a push from outside, less a share of itself. Salt in a tank rises with the brine poured in and falls with the share that drains out. A rule like that is straight in the height: the height appears once, multiplied by something that may depend on the input, and never squared or inside a root. Such a rule usually does not part, so the last step cannot solve it. One trick does. Multiply the whole rule by a growth function chosen so that the left side becomes the slope of a single product. Then one area finishes the job. The trick is the same one that proved growth at its own rate has one solution, and it proves just as much here: one solution, and it lasts as long as the rule makes sense. Every solution is then one solution plus a fading copy of the start.

A rule straight in the height is solved by multiplying it by one growth function, which turns the left side into the slope of a product. One area then gives the only solution, on the whole stretch where the rule makes sense. Every solution is one solution plus a solution of the rule with no push.

24g1A factor that makes a product

A rule is straight in y when it can be written y′ + p(x)y = q(x): y appears once, times a function of x alone, and y′ appears alone. y′ + 2xy = x is straight in y. y′ = xy² is not.

Multiplying-factor technique: let p and q be continuous on an open interval J holding x₀, and P(x) = ∫ from x₀ to x of p; then y′ + p(x)y = q(x), y(x₀) = y₀ has exactly one solution on the whole of J, y(x) = e^(−P(x))(y₀ + ∫ from x₀ to x of e^(P(t))q(t) dt). The factor is μ = e^P. Accepted name: the integrating factor.

\mu = e^{P},\ \ \mu' = p\,\mu,\ \ \mu > 0,\ \ \mu(x_0) = 1 @@ the chain rule; P′ = p (16b); P(x₀) = 0
(\mu y)' = \mu y' + p\mu y = \mu\,(y' + py) @@ the product rule (13c)
y \text{ solves the rule} \Rightarrow (\mu y)' = \mu q \Rightarrow \mu(x)y(x) - y_0 = \int_{x_0}^{x} \mu q @@ evaluating by antiderivatives (16c)
y = e^{-P}\big(y_0 + \textstyle\int_{x_0}^{x} e^{P}q\big) \text{ on } J @@ divide by μ, never 0: any solution is this one
\mu y = y_0 + \textstyle\int_{x_0}^{x} \mu q \Rightarrow \mu(y' + py) = (\mu y)' = \mu q,\ \ y(x_0) = y_0 @@ the slope of an area is the height (16b): this one is a solution
\htmlClass{new}{\text{exactly one solution on the whole of } J} \quad \blacksquare @@ the two lines above
  
P = x^2,\ \ \mu = e^{x^2} @@ p = 2x
(e^{x^2}y)' = xe^{x^2} @@ the factor makes a product
e^{x^2}y = \int_0^x te^{t^2}\,dt = \tfrac12\big(e^{x^2} - 1\big) @@ substitution (16d); the start gives 0 at x = 0
\htmlClass{new}{y = \tfrac12\big(1 - e^{-x^2}\big) \text{ on the whole line}} \quad \blacksquare @@ divide by e^{x²}; put back: y′ = xe^{−x²} and x − 2xy = xe^{−x²}

This is 24a3's proof with a push added: there k was constant and q was 0. No tameness was asked for and no "for a while" was needed. A straight rule fixes its solution on every stretch where p and q are continuous.

24g2By hand, and where the solution lives

The recipe: write the rule as y′ + p(x)y = q(x), dividing by whatever stands in front of y′. Find P and the factor e^P. Write (e^P y)′ = e^P q. Take the area, use the start, divide by e^P. Put the answer back.

Whole-stretch technique: a solution of a straight rule lives on the whole open interval J holding x₀ on which p and q are continuous; it can run off only at an end of J. Unlike y′ = y², it never runs off inside J.

y = e^{-P}\big(y_0 + \textstyle\int_{x_0}^{x} e^{P}q\big) \text{ is defined and continuous on } J @@ the multiplying-factor technique (24g1); P and the area are continuous on J
\text{on each closed } [x_0, x_1] \subset J,\ y \text{ is bounded} @@ bounded on a closed interval (12b)
\htmlClass{new}{y \text{ passes no ceiling inside } J} \quad \blacksquare @@ a run-off, as in 24e2, can come only at an end
  
y' + \tfrac{2}{x}\,y = x,\ \ J = (0, \infty) @@ divide by x; p = 2/x breaks at 0, and J must hold the start 1
P = 2\ln x,\ \ \mu = x^2,\ \ (x^2y)' = x^3 @@ e^{2 ln x} = x² for x > 0 (17e)
x^2 y = 1 + \tfrac{x^4 - 1}{4} @@ the area from 1 to x; the start gives 1
\htmlClass{new}{y = \tfrac{x^2}{4} + \tfrac{3}{4x^2} \text{ on } (0, \infty)} \quad \blacksquare @@ it runs off at 0, the end of J where p breaks

Dividing by what stands in front of y′ is not a formality. That function was x, and at x = 0 the rule reads 2y = 0: it has no slope in it at all. The solution cannot cross that line, and the technique says so by giving a J that stops there.

24g3One solution plus the rule with no push

Call y′ + p(x)y = 0 the bare rule of y′ + p(x)y = q(x): the same rule with the push q taken away.

One-plus-bare technique: if yₚ solves y′ + py = q on J, the solutions on J are exactly yₚ + Ce^(−P), one for each real C. Any one solution, however it was found, gives all the others.

y \text{ solves the rule} \Rightarrow u = y - y_p \text{ solves } u' + pu = q - q = 0 @@ subtract the two rules
(e^{P}u)' = e^{P}(u' + pu) = 0 @@ the factor, as in 24g1
e^{P}u = C \Rightarrow y = y_p + Ce^{-P} @@ zero slope means flat (14d)
(y_p + Ce^{-P})' + p\,(y_p + Ce^{-P}) = q - pCe^{-P} + pCe^{-P} = q @@ put back: every C gives a solution
\htmlClass{new}{\text{the solutions are exactly } y_p + Ce^{-P}} \quad \blacksquare @@ both ways
  
y_p = a\sin x + b\cos x \Rightarrow y_p' + y_p = (a - b)\sin x + (a + b)\cos x @@ try a swing of the same period (21g)
a - b = 1,\ a + b = 0 \Rightarrow a = \tfrac12,\ b = -\tfrac12 @@ match the sin and cos parts
y = \tfrac12(\sin x - \cos x) + Ce^{-x} @@ the one-plus-bare technique, with P = x
\htmlClass{new}{|y - y_p| = |C|e^{-x} \to 0} \quad \blacksquare @@ every solution forgets its start and settles into one swing

Two things are worth seeing. Guessing yₚ is honest: the put-back technique checks it, and the one-plus-bare technique does the rest. And when p is a positive constant, the bare part fades like e^(−px), so after a while the start no longer shows. A room heated and cooled on a daily cycle, a circuit driven by an alternating push, a tank fed a varying brine: each settles into the rhythm of its push.

The basement · there if you want it

The accepted names

A rule straight in y is a linear first-order differential equation. The multiplying factor is the integrating factor; the bare rule is the homogeneous equation; yₚ is a particular solution, and yₚ + Ce^(−P) the general solution. The fading bare part is the transient, and the swing left over is the steady state. The rule in the build standing question is a Bernoulli equation.

Who said it first

Jakob Bernoulli posed the rule of the build standing question in 1695. Gottfried Leibniz reduced it to a straight rule in 1696, and Johann Bernoulli solved straight first-order rules in general in 1697. Leonhard Euler made multiplying factors a general method in the 1730s and in his textbook on integration of 1768.
