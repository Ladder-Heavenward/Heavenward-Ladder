16b · proof

Its slope is the height

16a showed that the area function never jumps: a bound on the height bounds how fast the area can change. This step asks how fast it does change. Move the edge a little way to the right, and the area gains the integral of the function over that short stretch. Divide by the stretch’s width, and the result is an average height over the stretch, caught between the least and greatest heights there. If the function does not jump at the edge, those both close in on its height at the edge as the stretch shrinks. So the slope of the area is the height. The proof is short. What it costs is that the function does not jump at the one point.

The area gained, divided by the width, is the average height over the stretch. It differs from the height at the edge by at most the largest gap between heights on the stretch and the height at the edge. Because the function does not jump there, that gap shrinks to nothing. So the slope of the area function at the edge is the height of the function there.

16b1The first fundamental technique

Area-slope technique (the fundamental theorem of calculus, first part): let f be integrable on every closed interval inside an interval I, let p be in I, and let F(x) = ∫ₚˣ f(t) dt. If f is continuous at a point c inside I, then F has a slope at c, and F′(c) = f(c). At an end of I that belongs to I, the same is true with the slope from one side.

\text{fix } \varepsilon \gt 0;\ \text{call } \delta \gt 0:\ |t - c| \lt \delta \Rightarrow |f(t) - f(c)| \lt \tfrac{\varepsilon}{2} @@ f is continuous at c (11a), at ε/2; shrink δ so [c − δ, c + δ] lies in I
0 \lt |h| \lt \delta:\ \ F(c + h) - F(c) = \textstyle\int_c^{c+h} f(t)\,dt @@ split-in-any-order (16a)
f(c) \cdot h = \textstyle\int_c^{c+h} f(c)\,dt @@ the integral of a constant (15c), with 15e's convention if h < 0
\tfrac{F(c+h) - F(c)}{h} - f(c) = \tfrac1h \textstyle\int_c^{c+h} \big(f(t) - f(c)\big)\,dt @@ areas-add and areas-scale (15e); spread for times over plus
\big|\textstyle\int_c^{c+h} (f(t) - f(c))\,dt\big| \le \tfrac{\varepsilon}{2}|h| @@ area-bound (16a) on the stretch between c and c + h, where |t − c| ≤ |h| < δ
\Big|\tfrac{F(c+h) - F(c)}{h} - f(c)\Big| \le \tfrac{\varepsilon}{2} \lt \varepsilon @@ divide by |h| > 0
\htmlClass{new}{F'(c) = f(c)} \quad \blacksquare @@ 13a's line: the chord slopes have limit f(c) as h → 0; at an end, h of one sign only (13f)

Its accepted name is the fundamental theorem of calculus, first part. The fraction in the middle line has a plain reading: the area gained over the stretch, divided by the stretch's width, is the average height of f there, in 15f's sense. Continuity says that on a short enough stretch every height is near f(c), and so is any average of them.

16b2Every continuous function has an antiderivative

Antiderivative-exists technique: if f is continuous on an interval I and p is in I, then F(x) = ∫ₚˣ f(t) dt is an antiderivative of f on I.

\begin{aligned}&f \text{ is integrable on}\\ &\quad\text{every closed interval inside } I\end{aligned} @@ continuous-is-integrable (15f): continuous on a closed interval
F'(x) = f(x) \text{ for every } x \text{ in } I @@ area-slope at every x, from one side at an end
\htmlClass{new}{F \text{ is an antiderivative of } f \text{ on } I} \quad \blacksquare @@ 14e's line

Rung 14 asked, given the slope at every input, what was the function, and could only say that any two answers differ by a constant. Now there is always an answer, if the slope given is continuous. It may not be a function anyone can write with powers and roots; it is always the area function.

16b3The other end, and a moving end

\textstyle\int_x^q f(t)\,dt = -\int_q^x f(t)\,dt @@ 15e's convention
\htmlClass{new}{\tfrac{d}{dx}\textstyle\int_x^q f(t)\,dt = -f(x)} @@ area-slope for the area function from q; constant-factor for slopes (13d)
H(x) = \textstyle\int_p^{g(x)} f(t)\,dt = F(g(x)) @@ g has a slope at x, f is continuous at g(x)
\htmlClass{new}{H'(x) = f(g(x)) \cdot g'(x)} @@ chain for slopes (13e) with outside F, whose slope is f by area-slope
\text{e.g. } \tfrac{d}{dx}\textstyle\int_0^{x^3} \sqrt{1 + t^2}\,dt = \sqrt{1 + x^6} \cdot 3x^2 @@ g(x) = x³; √(1 + t²) is continuous (11c, 13e's √)

Moving-end technique: if f is continuous on an interval I, p is in I, and g has a slope at x with g(x) in I, then (d/dx) ∫ₚ^{g(x)} f(t) dt = f(g(x)) · g′(x). The lines above prove it.

16b4Where f jumps

f = u,\ p = 0:\ \ F(x) = 0 \ (x \le 0),\ x \ (x \gt 0) @@ 16a
\text{from the right at 0: } \tfrac{h - 0}{h} = 1;\ \text{from the left: } \tfrac{0 - 0}{h} = 0 @@ the slopes from each side (13f) differ
F \text{ has no slope at } 0 @@ two-side-slopes (13f)
s(t) = 1 \ (t = 0),\ 0 \ (t \ne 0):\ \ \textstyle\int_0^x s = 0 \text{ for every } x @@ one point changes no area: the piece holding it shrinks by everyday-counting-passes
F = 0,\ \ F'(0) = 0 \ne 1 = s(0) @@ F has a slope at 0, and it is not s(0)

Both ways of failing are possible. At a jump, the area function has a joint and no slope. At a single point raised off the graph, the area function has a slope, and it ignores the raised point. Area-slope promises nothing at either.

16b.4.4seamA teacher of geometry proved in 1670, by a figure, that the line touching the area curve meets the axis where the first curve's height says it should. He never used it to find an area. In 1916 a historian argued that this teacher, and not the two usual inventors, was the true discoverer of the calculus. Most historians since have said that a technique nobody computes with is not yet the calculus.
Is a technique discovered when it is first proved, or when someone first sees what it is for?

Who said it first

Barrow drew a curve and, beneath it, a second curve whose height at each point was the area under the first up to there. He showed by a figure that a certain line touching the second curve met the axis where the first curve’s height said it would.

Barrow, Lectiones geometricae (1670), Lecture X, §11; paraphrase

In 16b.4.4, the teacher is Isaac Barrow; the historian is J. M. Child, and the two usual inventors are Newton and Leibniz.
