27d · proof

Matrices as Maps

A straight map is fixed by what it does to a few vectors. Send each measuring direction somewhere, and adding and stretching decide the rest. So a straight map between lists of numbers can be written as a grid: one column for where each direction goes. Doing one map after another becomes a way of multiplying grids. And the maps that can be undone form a group, of the kind rung 19 studied.

A straight map from lists of n numbers to lists of m numbers is a grid of m rows and n columns. Doing one map after another is multiplying their grids, and the maps that can be undone form a group.

27d1Columns Are Where the Directions Go

Write e₁, …, eₙ for the lists of n numbers with a single 1, in place 1, …, n. A grid A of m rows and n columns, with entry aᵢⱼ in row i and column j, acts on a list x by (Ax)ᵢ = aᵢ₁x₁ + ⋯ + aᵢₙxₙ. Accepted name: a matrix.

Columns technique: every straight map L from lists of n numbers to lists of m is x ↦ Ax for exactly one grid A, whose column j is L(eⱼ).

x = x_1e_1 + \cdots + x_ne_n @@ the eⱼ build every list (27b3)
L(x) = x_1L(e_1) + \cdots + x_nL(e_n) @@ L keeps mixes (27c1)
(Lx)_i = a_{i1}x_1 + \cdots + a_{in}x_n,\ \ a_{ij} = (L(e_j))_i @@ read off place i
A e_j = \text{column } j \text{ of } A @@ only xⱼ = 1 is not 0
\htmlClass{new}{L = A \text{ and } A \text{ is unique}} \quad \blacksquare @@ two grids that agree on every eⱼ have equal columns

27d2Doing One After Another

Product-is-doing technique: if B is a grid with n columns and k rows, and A has k columns and m rows, then doing B and then A is the grid AB, whose column j is A times column j of B: (AB)ᵢⱼ = aᵢ₁b₁ⱼ + ⋯ + aᵢₖbₖⱼ.

x \mapsto A(Bx) \text{ is straight} @@ each of the two keeps adding and stretching
\text{its column } j \text{ is } A(Be_j) = A(\text{column } j \text{ of } B) @@ the columns technique (27d1)
\big(A(Be_j)\big)_i = \textstyle\sum_{l} a_{il}\,b_{lj} @@ the action of A on the list Beⱼ
\htmlClass{new}{(AB)_{ij} = \textstyle\sum_l a_{il}b_{lj},\ \ (AB)x = A(Bx)} \quad \blacksquare @@ the grid of a map is unique (27d1)

Since doing maps one after another is grouping-free, so is the product: (AB)C = A(BC), with no sums to check. It is not turn-about. The quarter turn after the flip across y = x is not the flip after the quarter turn, as rung 20 found with moves. So multiplying grids is running maps in a row: B and then A run in a row to AB.

27d3The Maps That Can Be Undone

A square grid A is undoable if some grid A⁻¹ has AA⁻¹ = A⁻¹A = I, where I is the grid of doing nothing, with 1 down its middle and 0 elsewhere.

Undoable-group technique: the undoable grids with n rows and n columns form a group under the product; and a square grid is undoable as soon as it loses only 0.

(AB)(B^{-1}A^{-1}) = A(BB^{-1})A^{-1} = AA^{-1} = I @@ grouping-free (27d2); socks and shoes, 19c
I \text{ undoable},\ (A^{-1})^{-1} = A @@ ﹀ A⁻¹, read both ways
\text{grouping-free, a neutral grid, an undo for each} @@ the three demands of a group (19a)
A \text{ loses only } 0 \Rightarrow A \text{ reaches every list} @@ lost plus reached (27c2), with equal dimensions
\Rightarrow x \mapsto Ax \text{ has a straight undo, with a grid} @@ its undo keeps adding and stretching; the columns technique
\htmlClass{new}{\text{the undoable } n \times n \text{ grids form a group}} \quad \blacksquare

The accepted names

A grid is a matrix, an m × n matrix when it has m rows and n columns; doing nothing is the identity matrix I. The product AB is matrix multiplication. An undoable matrix is invertible (or non-singular), with inverse A⁻¹. The undoable n × n real matrices form the general linear group, GL(n, ℝ).

Who said it first

James Joseph Sylvester named the matrix in 1850. Arthur Cayley defined the product as the composition of maps in 1858, and noted that it is not commutative.
