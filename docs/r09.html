Rung 9 · theory

Making functions

Back on 4c you met a function in passing: a set of pairs in which every input has exactly one output. It was built for one job, defining by repeating, and the page said the full theory would wait. This rung is that theory. It takes the one-sentence definition as the whole truth about what a function is, and shows how much follows from it. It shows how to chain functions, when two inputs may share an output, and when every output is reached. It shows when a function can be run backwards, and how to draw one.

You have used functions for years: a price tag, a vending machine, a recipe that doubles. This rung is less about what you know and more about what you can now do with it. Every tool is already on your belt. The work is in putting them to use.

A function hands you single values: put in one input, get back its one output. That is how questions within the series get asked one value at a time. Techniques that make a claim about every input at once come later, from the rates between functions.

A function is nothing but its pairs, one output for each input. Chain them and the brackets do not matter; ask the same two promises of the outputs and you learn when the pairs can be turned around.

What it means to say each input has exactly one output

Think of a register of births: each child is entered with exactly one mother. Some mothers appear many times, and some women not at all. But no child is entered twice with different mothers, and no child is missing. That shape, a pairing in which every member of one collection is matched with exactly one member of another, is what mathematics calls a function. The collection the pairs start from holds the inputs, and what each is paired with is its output.

The claim of this rung is that this shape is all a function is. A function is not a formula, not a machine, not a rule you can follow. It is a set of pairs, and the only thing it promises is about inputs: each input appears in exactly one pair, a some glued to an at-most-one (9a2). Everything else on this rung is what follows from that sentence, with the tools of rungs 2, 4 and 8.

Saying it this way has a cost and a payoff. The cost is that a function need not have a formula. You can pair the counting numbers with 0s and 1s in any way at all. 9a proves that most such pairings could never be written as a formula, however long, by the diagonal argument, which fits in a dozen lines. The payoff is that you always know exactly what you have. Two functions are the same when they have the same pairs, by rung 2's same-members axiom, and for no other reason. Two different formulas can describe the same function, and the same formula on different inputs describes different functions.

Where it comes from

The word dates from the end of the seventeenth century, and for a long time it meant a formula. A textbook of analysis of 1748 defined a function as an expression made out of a varying quantity and fixed numbers. That served for about a century. Then the formulas ran out. Mathematicians studying heat and sound needed to say what could be built from endlessly many simple pieces. The results had sudden jumps that no single expression seemed to describe. In 1837 one of them cut the knot: let anything count, so long as each input gets a single output, by whatever means, with or without a formula. Another, writing on the numbers in 1888, put it most plainly of all. He called it a law that gives each member of a collection a definite thing, and he used it to build the counting numbers. That is the sense this ladder has used since 4c: each input gets a single output, by whatever means.

The ladder already has every tool this needs. Pairs and products are 2e's. A function is 4c's. The real numbers, with their order, their arithmetic and their roots, are rung 8's. So no axiom is laid down on this rung. What is new is a way of handling functions as objects in their own right: chaining them, comparing them, turning them around.

The principles, in plain words

The rung proves six things, in this order. First, a function from one set to another is a set of pairs in which each member of the first set appears in exactly one pair, and no formula is required (9a2). Second, composing two functions is doing one and then the other (9b1). Third, in a chain of three the brackets do not matter (9b3).

Fourth, the two promises asked of the outputs give one-to-one, onto and bijection, which is 4j's matching (9c1). Fifth, a function can be run backwards exactly when it is a bijection, and then by one function only (9d3). Sixth, that function is the original pairs with their entries swapped (9d1).

Three things follow from these alone. The order of composing matters: socks then shoes is not shoes then socks (9b2). In the picture, a set of pairs is a function exactly when each column holds one of them (9e2). And a function that uses an output twice can be kept to part of its inputs and then run backwards: so squaring, kept to the reals that are not negative, is undone by 8f's square root (9d4). That is why the square root of a number is never negative: it was chosen that way, when the inputs were kept.

What you can do because you know it

You can tell at once whether something is a function, and if not, which promise it breaks. You can build new functions out of old ones. You can take a function apart into the chain that made it, and undo a chain by undoing its links in the reverse order. You can say exactly when an inverse exists, and when one does not, repair the function by keeping part of its inputs. You can prove two descriptions describe the same function, or find the single input where they part company.

The technique pages make the hands fast. 9e builds the plane: the set of all pairs of reals, drawn with the left entry read across and the right entry read up. It is a picture of two orders at once, and nothing of shape is meant; distance and the rest of geometry wait for rung 18. A function of reals is a set of such pairs, so its picture, its graph, is the function itself. 9e reads the standard families. There is the kind whose output climbs by the same amount for every step of the input. There are the powers, one over the input, the square root, and the absolute value. 9f is composing and inverting by hand, with the inside of a chain named r. 9g is polynomials, the functions made with adding and multiplying alone. Each zero is a factor, and long division works as it did for whole numbers on 4i. Two polynomials agreeing at enough inputs are the same. For large inputs the highest power decides everything, said with order alone. A fraction of polynomials is undefined where its bottom is 0, and splits into simple pieces.

The science pages aim this at the world. 9·phys follows an old experimenter who made position a function of time. He defined steady motion and steadily growing speed with great care, and found the falling distances growing as the odd numbers 1, 3, 5, 7. The page proves his rule for the distance from his definition, using nothing but rung 4's sums and rung 8's counting-passes-any-real. 9·bio follows the finding that an animal's resting energy use goes with its mass to the power three quarters. It works it with ratios of powers: what happens when you multiply the mass by ten, or by a thousand, and how to pin an exponent down with whole-number comparisons. And 9·cb4 goes back to 4c's recursion. A sequence is a statement that names a function on the counting numbers, and the recursion principle becomes a sentence about two chains of functions agreeing. Adding, multiplying and powers turn out to be one gesture, repeating a function, done three times over. With rung 7's either-way principle in hand, it also proves something 4c could not. A run of numbers that never goes up must eventually stand still, though nobody may be able to say when.

That is the first of what functions will do in your hands. The ladder has seen only the tip of it.

Anexact, yet rigorous. Beside the proofs, 9a carries a green box: connections, not families. A thing is defined twice: by its family, and by what it does to whatever passes through it.

And 9·chem asks whether every gas follows the same rule: the gas law is one function of several inputs, holding all but one gives this rung's familiar shapes, and equal volumes hold equal counts because no input names the gas. It carries a box on connections, not families.

What it costs

Nothing new is laid down. Every function on this rung is a set built by rung 2's tools, and every principle is proved. The price is a habit of care. A formula with a division in it has small print: “where the bottom is not 0”. A cancellation can quietly remove an input. An inverse written with a high −1 is not one over anything. And a set of pairs that looks like a function in a few drawn dots may not be one at all. At the end of the rung you will know what it means to say each input has exactly one output, and what you can do because you know it.

Who said it first

The word function is Leibniz’s. The textbook of 1748 is Euler’s Introduction to the Analysis of the Infinite. The mathematician who cut the knot in 1837 was Peter Gustav Lejeune Dirichlet, and the one writing on the numbers in 1888 was Richard Dedekind, in Was sind und was sollen die Zahlen?

Dirichlet said that if to each value of one quantity there corresponds a single value of another, the second is a function of the first. He added that it does not matter whether one rule governs the whole stretch, or whether the dependence can be written with the operations of arithmetic at all.

Dirichlet, “Über die Darstellung ganz willkürlicher Functionen durch Sinus- und Cosinusreihen”, Repertorium der Physik 1 (1837)
