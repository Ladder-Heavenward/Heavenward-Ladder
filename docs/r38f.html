38f · proof

Worlds That Say the Same Things

Statements cannot pin a world down by its size (38e). Sometimes they pin it down at one size: every listed world of the statements has the same shape. Then they settle every question in their language. The fractions and the line, ordered, look different: one has holes, one has none. Yet no statement about order alone tells them apart. This step matches any two listed dense orders by going back and forth, and turns one shape at one size into a collection that reaches every statement or its denial.

Two listed orders, each dense with no first or last member, can be matched by adding one member at a time, alternately from each side. So every listed world of those statements has one shape. A collection with only endless worlds and one listed shape reaches φ or ¬φ for every φ.

38f1Back and Forth

a_0, a_1, \ldots \text{ and } b_0, b_1, \ldots @@ list both (38e)
\text{odd turns: take the first unmatched } a,\ \text{find a } b \text{ in the same gap} @@ dense and endless: the gap is never empty
\text{even turns: the same, from } B \text{ to } A @@ so no member is skipped
\htmlClass{new}{\text{every member is matched; order is kept}} @@ one shape: the fractions’ shape

Back-and-forth technique: any two listed orders that are dense and have no first or last member are matched by an order-keeping matching; each step needs only finitely many matched members and a gap to fill.

38f2One Shape Settles Every Question

\text{suppose neither } \varphi \text{ nor } \neg\varphi \text{ is reached from } G @@ aiming at a clash
G \cup \{\varphi\},\ G \cup \{\neg\varphi\} \text{ both have worlds} @@ reached-if-true-everywhere (38d)
\text{both have listed endless worlds} @@ the countable-world technique (38e)
\htmlClass{new}{\text{one shape: the same world makes } \varphi \text{ true and false}} @@ a clash

One-shape technique: if a collection in a listed language has only endless worlds, and all its listed worlds have one shape, then it reaches every statement or its denial.

38f3The Fractions and the Line Agree

(\mathbb Q, <) \text{ and } (\mathbb R, <) \text{ are dense with no ends} @@ both are worlds of the order statements
\text{the order statements settle every question} @@ one shape (38f1, 38f2)
\text{so } \mathbb Q \text{ and } \mathbb R \text{ make the same statements true} @@ about order alone
\htmlClass{new}{\text{no statement about order says “no holes”}} @@ it needs “every bounded set,” a statement over sets (38n)

The fractions and the line satisfy exactly the same statements about order, though one has holes and the other has none; the difference lies in a statement about sets of members, which 38n’s language allows and this one does not.

Accepted names

Back and forth is Cantor’s back-and-forth argument; one listed shape is ℵ₀-categoricity; one shape gives completeness by the Łoś-Vaught test. Worlds making the same statements true are elementarily equivalent; the order statements are the theory DLO.

Who said it first

Georg Cantor matched the dense orders in 1895; Jerzy Łoś and Robert Vaught gave the test in 1954.
