38f · proof

Numbers Past Every Numeral

Write 0, then the next one after 0, then the next after that, and keep going. Each number you reach has a name in marks, a numeral, and every number of rung four is reached that way. Now take every statement in marks that is true of the numbers, and ask whether some other world makes all of them true and also holds a member past every numeral. The finite-parts technique says yes at once: any finite list of demands “past this numeral” is met by a large enough number. So there is a world where every true statement of arithmetic is true, and still some members are larger than every number you could ever write down. The step looks at the shape of such a world, and finds that the ordinary numbers cannot be picked out inside it by any formula at all, though induction holds there for every formula. Then the same trick is run on the line, and gives a world with numbers smaller than every positive real and yet not zero. The infinitely small quantities that rung thirteen refused are back, this time with a proof that they are safe.

The true statements of arithmetic have a world with a member past every numeral, and no formula can pick out the numerals in it. Run on the line, the same technique gives infinitely small members, and the slope of rung thirteen is the nearest real to a ratio of them.

38f1A Member Past Every Numeral

The numeral of a number n is the term S(S(⋯S(0)⋯)) with n marks S, written n̄. In N the value of n̄ is n, so every member of N is the value of a numeral. Write x < y as shorthand for ∃z (x + S(z) = y), 4h’s less-is-adding in marks. Let T be the collection of every statement of the language of arithmetic true in N.

Past-every-numeral technique: some world makes every statement of T true and holds a member greater than the value of every numeral.

T' = T \cup \{\bar n < c : n \text{ a number}\} \text{, with a new name } c @@ one demand for each number
\text{a finite part of } T' \text{ holds } \bar n_1 < c, \ldots, \bar n_k < c @@ and some members of T, all true in N
N \text{, with } c \text{ meaning } 1 + \max(n_1, \ldots, n_k) \text{, makes the finite part true} @@ less-is-adding (4h): each nᵢ is less than it
T' \text{ has a world } M @@ the finite-parts technique (38d4)
\htmlClass{new}{M \models T \text{ and the value of } c \text{ is above the value of every numeral}} \quad \blacksquare @@ the demands n̄ < c, all true in M

M is not matched with N. A matching that carries the marks sends 0 to 0 and S to S, so it sends the value of each numeral to the value of the same numeral. Then c’s value would have to go to some number n, and n̄ < c would be false in N’s copy. So the statements of T, every one of them true in both, cannot tell the two worlds apart, and the worlds are not matched. That is 38a4’s question, answered.

38f2The Shape of the New World

Every statement true in N is true in M. In N every number other than 0 is a next, so in M too. So c has a member just before it, c − 1, and one after, c + 1, and so on both ways. Call the members a numeral’s value away from c its block. A block runs both ways without end, shaped like the integers of rung 5, and every member of it is past every numeral.

Block technique: below every block past the numerals there is another, and above every one there is another.

N \models \forall x\,\exists y\,(x = y + y \lor x = S(y + y)) @@ even or odd (4j)
c = d + d \text{ or } c = d + d + 1 \text{ in } M \text{, for some member } d @@ the same statement is true in M
d \text{ is past every numeral} @@ if d were below n̄, c would be below the numeral of 2n + 1
c - d = d \text{ or } d + 1 \text{, past every numeral} @@ so c is not a numeral’s value away from d
\htmlClass{new}{d \text{ is in a block below } c\text{’s, and } c + c \text{ in one above}} \quad \blacksquare @@ c + c − c = c, past every numeral

So there is no first block past the numerals and no last one. A world of arithmetic starts with the numbers, a copy of N, and then goes on with endlessly many copies of the integers, none of them first. Between any two blocks there is another, by the same halving of their sum.

38f3Induction Cannot See the Numerals

For every formula φ(x), the statement “if φ(0), and φ(x) gives φ(S(x)) for every x, then φ(x) for every x” is true in N: that is 4c’s induction. So it is in T and true in M as well. Induction holds in M for every formula. Yet M has members no run from 0 by next ever reaches.

Numerals-unpicked technique: no formula of arithmetic is true in M of exactly the values of the numerals.

\varphi(x) \text{ true in } M \text{ exactly at the values of the numerals} @@ suppose, aiming to refute
M \models \varphi(0) @@ 0 is the value of the numeral 0̄
M \models \forall x\,(\varphi(x) \Rightarrow \varphi(S(x))) @@ the next of a numeral’s value is the value of the next numeral
M \models \forall x\,\varphi(x) @@ induction for φ, true in N, so in T, so true in M
M \models \varphi(c) \text{, though } c \text{ is past every numeral} @@ use an every
\htmlClass{new}{\bot} \quad \blacksquare @@ clash with the first line; refute

4b sifted the numbers out as what is in every inductive set: a condition about sets. The marks of arithmetic speak of numbers only. Inside M the numerals form a set seen from outside, as in 38e4, and no formula of the language can be its sift. 4e.4.4 found a world where induction fails. This one is subtler: induction never fails, and still the world is not N.

38f4Infinitely Small, and Honest

Run the same technique on the line. Take a language with a name r̲ for every real r, a function mark for every function from reals to reals, and a relation mark for every relation on reals. Let T be every statement of it true in R. Add a name ε and the demands 0 < ε and ε < r̲ for every positive real r. A finite part names finitely many positive reals, and the least of them, halved, meets it. So the finite-parts technique gives a world *R of T with a member ε above 0 and below every positive real: infinitely small.

Every statement true of the reals, in this rich language, is true in *R. A member of *R lying between two reals is finite, and two members are infinitely close when their difference is 0 or infinitely small.

Nearest-real technique: every finite member of *R is infinitely close to exactly one real.

y \text{ finite: } r_1 < y < r_2 \text{ for reals } r_1, r_2 @@ given
A = \{r \text{ real} : r < y\} \text{ has a member and is bounded by } r_2 @@ 8c: it has a least upper bound s, a real
\text{for every real } \eta > 0:\ s - \eta \in A \text{ and } s + \eta \notin A @@ s is the least upper bound
s - \eta < y \le s + \eta \text{, so } |y - s| \le \eta \text{ for every positive real } \eta @@ the order of *R, true as in R
\text{two reals infinitely close to } y \text{ differ by a real that is 0 or infinitely small} @@ the difference of two reals is a real
\htmlClass{new}{y \text{ is infinitely close to } s \text{, and to no other real}} \quad \blacksquare @@ no real above 0 is infinitely small

Shadow-slope technique: if f has a slope at x, then for every infinitely small ε, the ratio (f(x + ε) − f(x))/ε is infinitely close to f′(x).

\text{for each real } \eta > 0 \text{ there is a real } \delta > 0 \text{ with } \forall h\,(0 < |h| < \delta \Rightarrow |\tfrac{f(x+h) - f(x)}{h} - f'(x)| < \eta) @@ the slope as a limit (13a, 10a): for each η, a statement of the rich language, true in R
\text{the same statement is true in } {}^*R @@ it is in T
0 < |\varepsilon| < \delta @@ ε is infinitely small, δ a positive real
|\tfrac{f(x+\varepsilon) - f(x)}{\varepsilon} - f'(x)| < \eta \text{ for every real } \eta > 0 @@ use an every, with ε
\htmlClass{new}{\tfrac{f(x+\varepsilon) - f(x)}{\varepsilon} \text{ is infinitely close to } f'(x)} \quad \blacksquare @@ the difference is below every positive real

For f(x) = x², the ratio is (2xε + ε²)/ε = 2x + ε, and its nearest real is 2x. Rung 13 divided by h and then let h head to 0, because dividing by something that is 0 is forbidden (5e) and dividing by something that is not 0 leaves it in the answer. Here ε is not 0, the division is allowed, and the nearest real throws away exactly what is left over.

The accepted names

A world of the true statements of arithmetic that is not matched with N is a non-standard model of arithmetic; its members past the numerals are non-standard numbers, and the numerals’ values are the standard part. The shape found in 38f2 is the order type ω + (ω* + ω)·η, with η the order type of the fractions, for a countable model. The numerals-unpicked technique says the standard cut is not definable, a form of overspill. *R is the hyperreal line; infinitely close is written ≈; the nearest real is the standard part, st(y). The method is non-standard analysis. Carrying a statement from R to *R is the transfer principle.

Who said it first

Thoralf Skolem built a non-standard model of arithmetic in 1934, by a direct construction. Abraham Robinson built non-standard analysis in 1960 and published it in his book of 1966; his first paper on it appeared in 1961, and the infinitesimals of Leibniz became members of a world with a proof behind them. The ghosts of departed quantities are George Berkeley’s, in The Analyst (1734).

A proof that is not allowed

“For every number n, the statement n̄ < c is true in M. So by induction, the statement ‘every x is less than c’ is true in M, and c is past itself.” Not allowed: induction in M runs over formulas of the language, and “x is a numeral’s value” is no such formula (38f3). The statements n̄ < c are endlessly many separate statements, and no single formula of the language says all of them.
