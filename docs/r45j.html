45j · proof

News Without a Leader

One machine learns something, and all should know it soon, with no machine in charge and no list of who knows what. This step spreads the news by chance alone, and counts the rounds.

Tell a random other each round. While few know, the count doubles; once most know, the unknowing fraction squares.

45j1Tell or Ask a Random Other

Each round, each machine picks one other machine at random. In pushing, a machine that knows tells the one it picked. In pulling, a machine that does not know asks the one it picked. No machine holds a list, and no machine is in charge.

45j2Doubling While Few Know

While few machines know, almost every push reaches a machine that did not know. So the number who know nearly doubles each round, and reaches half of n after about log₂ n rounds (39l’s halving, run backwards).

45j3Squaring Once Most Know

Squaring-pull technique: if a fraction u of machines do not know, and each asks one machine chosen at random, then the expected fraction still not knowing after the round is u².

A machine stays ignorant only if it did not know and asked one that did not know: chance u · u (41i). From u = 1/2 the fraction goes 1/4, 1/16, 1/256: the exponent doubles each round, so it falls below 1/n after about log₂ log₂ n more rounds.

45j4No One in Charge

Each machine sends one message a round, and there is no leader to fail. A few dead machines slow the spread a little and do not stop it, since a random pick rarely lands on them twice.
