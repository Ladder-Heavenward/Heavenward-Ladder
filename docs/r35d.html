35d · proof

Two one-way matchings make a matching

A one-to-one map from one set into another is half a matching. It pairs every member of the first set with a different member of the second, and may leave some of the second unpaired. Call it a one-way matching. Suppose there is a one-way matching each way, from the first set into the second and from the second into the first. Must the two sets be matched? For finite sets, counting says yes at once. For endless sets nothing can be counted, and the two maps can tangle. This step untangles them. Start from the members of the first set that the second map misses, and follow where the two maps send them, back and forth, for ever. The members caught on that endless chase are sent across by the first map. Everyone else is sent back along the second. The result is a matching, and the proof picks nothing. So the order on sizes behaves: no bigger each way means the same size. The step ends with a harder question. Must any two sets compare at all? With choice, they must.

Follow the members the second map misses, back and forth through both maps. Send the ones caught on that chase across by the first map, and the rest back by the second. That is a matching, and nothing was picked. With choice, any two sets compare.

35d1Back and forth

35c2 wrote |A| ≤ |B| for “A goes one-to-one into B”. It chains: one-to-ones compose (9c3), so |A| ≤ |B| and |B| ≤ |C| give |A| ≤ |C|. What it lacked was the step back: from no bigger each way to the same size.

Two-one-way technique: if A goes one-to-one into B and B goes one-to-one into A, then A and B are matched.

f : A \to B,\ \ g : B \to A,\ \text{both one-to-one} @@ the two one-way matchings
C_0 = A \setminus g[B],\ \ C_{n+1} = g[f[C_n]] @@ start where g misses; then across by f and back by g; a definition by repeating (4d); g[B] is the image of B
C = C_0 \cup C_1 \cup C_2 \cup \cdots @@ every member caught on the chase
h(x) = f(x) \text{ if } x \in C,\ \ h(x) = g^{-1}(x) \text{ if } x \notin C @@ x ∉ C means x ∉ C₀, so x = g(y) for exactly one y (9d)
h \text{ one-to-one: } f(x) = g^{-1}(x') \text{ with } x \in C_n,\ x' \notin C \Rightarrow x' = g(f(x)) \in C_{n+1} @@ the only case to check; f and g⁻¹ are one-to-one on their own; it clashes with x′ ∉ C
h \text{ onto: } y \in B,\ \ g(y) \notin C \Rightarrow h(g(y)) = y @@ if g(y) ∉ C, y is reached through g⁻¹
g(y) \in C \Rightarrow g(y) \in C_{n+1},\ \text{so } g(y) = g(f(x)),\ x \in C_n,\ y = f(x) = h(x) @@ g(y) ∉ C₀, since C₀ misses g[B]; g is one-to-one
\htmlClass{new}{h : A \to B \text{ is a matching}} \quad \blacksquare @@ one-to-one and onto

No line picks anything. C is built by repeating, h by cases on x ∈ C (7d). So |A| ≤ |B| and |B| ≤ |A| give |A| = |B|, in every world of the axioms, with or without choice.

35d2Closed against open

Are [0, 1] and (0, 1) the same size? One goes into the other by doing nothing. The other way, x ↦ (1 + x)/3 sends [0, 1] one-to-one into [1/3, 2/3], inside (0, 1). The two-one-way technique says they are matched. Run the chase and it builds the matching.

f(x) = x \text{ from } (0, 1) \text{ into } [0, 1],\ \ g(x) = \tfrac{1 + x}{3} \text{ from } [0, 1] \text{ into } (0, 1) @@ here A = (0, 1) and B = [0, 1]
C_0 = (0, 1) \setminus [\tfrac13, \tfrac23] = (0, \tfrac13) \cup (\tfrac23, 1) @@ where g misses
C_1 = g[C_0] = (\tfrac13, \tfrac49) \cup (\tfrac59, \tfrac23) @@ f does nothing, then g
\text{every } x \in C \text{ stays; every } x \notin C \text{ goes to } 3x - 1 @@ h is f on C, and g⁻¹ off it
\htmlClass{new}{h(\tfrac13) = 0,\ \ h(\tfrac23) = 1} \quad \blacksquare @@ 1/3 and 2/3 are in no Cₙ: the two ends of [0, 1] are reached

Sizes do not see ends. A closed interval and an open one, a line and a stretch of it, the line and half of it: wherever two one-way matchings can be written, the sets are matched, whether or not anyone can write the matching down.

35d3Must any two sizes compare?

For numbers, of two one is at most the other (4h). Is that so for sizes? Given any A and B, must A go one-to-one into B or B into A? Nothing in the last footing says so. The two maps had to be given.

Any-two-sizes technique: with choice, for any sets A and B, A goes one-to-one into B or B goes one-to-one into A.

\text{order pairs } (X, m): X \subseteq A,\ m : X \to B \text{ one-to-one} @@ the partial one-way matchings; (X, m) below (X′, m′) when m ⊆ m′
\text{a chain has an upper bound: the union of its } m @@ any two in a chain agree where both are defined, so the union is a function, and one-to-one
(X, m) \text{ maximal} @@ the maximal-member principle, from choice (7·cb6)
X \ne A \text{ and } m[X] \ne B \Rightarrow \text{a larger pair} @@ add one more pair, (u, v), with u ∉ X and v ∉ m[X]
X = A:\ \ m : A \to B \text{ one-to-one} @@ one case
m[X] = B:\ \ m^{-1} : B \to A \text{ one-to-one} @@ the other: m⁻¹ runs backwards (9d), onto X ⊆ A
\htmlClass{new}{|A| \le |B| \text{ or } |B| \le |A|} \quad \blacksquare @@ by not-not-out, the two cases are the only ones

So with choice, sizes line up: any two compare, and by the two-one-way technique, no bigger each way is the same. The cost is real. The way back holds too, and 35d.4.4 asks for it: if any two sets compare, every set can be lined up, and so choice is true. 6e found three faces of one principle, and comparing sizes is a fourth.

35d4Illegal moves

h = f \text{ everywhere}\,? @@ off the chase, h runs g backwards
\text{onto maps each way give a matching, with no picking}\,? @@ to run an onto map back one-to-one, pick one input for each output: choice

Standing questions

Harder questions that rely on your own making. The step is complete without them; the rung's angel wings need them.

35d.4.1buildBuild a matching between these two sets that you can write in one line for each x. Send 1 to 1/2, 1/2 to 1/3, 1/3 to 1/4, and every other x to itself. Prove it is a matching.
Run the chase of 35d1 with f(x) = x/2 and g(x) = x, and compare.
35d.4.2edgeFind which lines of the two-one-way proof use that f and g are one-to-one, and what breaks in each when one of them is not.
Could the proof run with f one-to-one and g only onto?
35d.4.3rerouteProve the two-one-way technique with no chase. Show that Φ keeps inclusion, S ⊆ S′ ⇒ Φ(S) ⊆ Φ(S′). Let C be the union of every S with S ⊆ Φ(S), and show Φ(C) = C.
Build the matching from this C, and find which line uses the parts of A as a set (2f).
35d.4.4converseWith choice, any two sizes compare. Turn it round: suppose any two sets compare. Show that every set A goes one-to-one into some point of the run (29·cb3), when that point is too large to go into A.
What would that give for lining up A, and so for choice?
35d.4.5seamThe two-one-way proof spends no choice. The any-two-sizes proof spends it in one line.
One side holds that comparison of sizes is so plainly true that it is evidence for choice: an axiom earns its place by the clean results it gives. The other holds that a principle that names no matching, and gives sets that cannot be described, cannot be made true by being convenient.
Is a clean consequence evidence for an axiom? Which consequence of choice on the ladder so far would you least want to lose, and which would you most like to be rid of?

The accepted names

The two-one-way technique is the Cantor–Schröder–Bernstein theorem. The chase C is the set of points whose backward orbit starts outside g[B]. The reroute of 35d.4.3 is the proof by a fixed point of a map that keeps inclusion, the Knaster–Tarski fixed point theorem. The any-two-sizes technique is the comparability of cardinals, or the trichotomy of cardinals; that it implies choice is Hartogs’s theorem.

Who said it first

Georg Cantor stated the two-one-way technique in 1887 and could not prove it without the well-ordering of every set. Richard Dedekind proved it in 1887 and did not publish; Ernst Schröder published a proof with a gap in 1896, and Felix Bernstein, a student of Cantor, gave a full proof in 1897. Julius König gave the chase of 35d1, in pictures of chains, in 1906. Friedrich Hartogs proved in 1915 that the comparability of all sizes gives choice.

A proof that is not allowed

“f is one-to-one into B, so |A| ≤ |B|. g is one-to-one into A, so |B| ≤ |A|. Two numbers each at most the other are equal (4h), so |A| = |B|.” Not allowed: |A| and |B| are not numbers, and |A| ≤ |B| is a statement about maps. 4h’s technique speaks of numbers only. The whole of 35d1 is the work that line skips.
