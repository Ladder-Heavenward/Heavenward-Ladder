40l · technique

Compiling by Hand

40j proved that compiling shape by shape keeps the runs. This step does it by hand, from a short program to 39j’s numbers.

A cell for each name, a pattern for each shape, a count for each label, then run both and compare.

40l1A Cell for Each Name

The program: s ← 0; while n ≠ 0: s ← s + n; n ← n − 1. Give n cell 90 and s cell 91, and keep 1 in cell 92 and 0 in cell 93, since 39j’s machine adds and takes away only cells.

Question

  1. 40l1.1understandWhy do 1 and 0 need cells of their own?
    Which cells hold the names?

40l2A Pattern for Each Shape

x ← y + z becomes LOAD y; ADD z; STORE x. while x ≠ 0 becomes top: LOAD x; JZ end; the body; JMP top; end:, which is 40b2’s shape.

Question

  1. 40l2.1understandWhat pattern does an assignment become?
    What pattern does a while become?

40l3Count, Then Write Numbers

0{:}\ \text{LOAD zero; } 1{:}\ \text{STORE s} @@ 193, 391
2{:}\ \text{top: LOAD n; } 3{:}\ \text{JZ done} @@ 190, 511
4\text{ to }6{:}\ \text{LOAD s; ADD n; STORE s} @@ 191, 290, 391
7\text{ to }9{:}\ \text{LOAD n; SUB one; STORE n} @@ 190, 492, 390
10{:}\ \text{JMP top; } 11{:}\ \text{done: STOP} @@ 602, 000

The first pass of 40a3 gives top the address 2 and done the address 11.

Question

  1. 40l3.1understandWhich addresses do top and done get?
    Why is JZ done the number 511?

40l4Run Both

From n = 3 the source gives s = 3 + 2 + 1 = 6. The numbers take 2 turns to start, 9 turns for each of the three rounds, and 3 turns at the end to test, jump and stop: 32 turns, leaving 6 in cell 91. The runs agree, as 40j2 promised.

Question

  1. 40l4.1understandHow many turns does the compiled program take from n = 3?
    What does the source leave in s?

40l5Moves to Watch Out For

\text{JZ top}\,? @@ <span class="vd vd-p">outside the plan</span> the test leaves the loop when n is 0; it must jump to done
\text{leave out JMP top}\,? @@ <span class="vd vd-p">outside the plan</span> then the body runs once and falls through to done

Question

  1. 40l5.1understandWhy does JZ jump to done, not top?
    What happens without JMP top?
