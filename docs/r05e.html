5e · proof

Zero, negatives, and the forbidden division

5d proved twelve techniques for the fractions. This step turns around and treats the rules as the starting point: it asks what they force, using nothing else. Anything times 0 is 0. A negative times a positive is the negative of the product, and two negatives multiply to the product of the positives. A factor other than 0 can be cancelled, and a product is 0 only when a factor is. And no number multiplied by 0 gives 1, so 0 has no reciprocal, and dividing by 0 has no answer to give. Because each proof uses only the rules, each technique works in every collection that obeys them. And the last one cannot be patched: any attempt to give 0 a reciprocal breaks one of the rules, and the step shows which.

Use only the twelve techniques, one per line. A technique proved this way works wherever the rules are true; a patch that contradicts it must give up a rule.

5e1The rules as the starting point

On 5d the twelve techniques were techniques about pairs. Here they are the only premises. Every line below cites one of them by name, or the swap axiom. Or it cites a technique proved from them in this step or on 5d (one-negative, the negative is the only one, was proved from the rules alone). No line looks inside a fraction at its pairs. That is the point. What follows works for ℚ, and for any other collection that obeys the twelve techniques: any with an adding, a multiplying, a 0, a 1, negatives, reciprocals and a meaning for positive. Rung 8 builds another such collection, and everything here will work there with no new proof.

Checking w·0 = 0 for fractions on pairs would take one line: (p · 0)/(q · 1) is 0/q, which is 0. But that would only say it of the fractions. The column below says it of anything that obeys the rules, and that difference is what makes the last section of the step possible.

5e2Anything times zero is zero

The idea in words: 0 is 0 + 0, so w·0 is w·0 + w·0 by the spreading rule. A thing that equals itself added to itself can only be 0, as adding its negative to both sides shows. Anything-times-zero technique: w · 0 = 0.

0 + 0 = 0 @@ plus-zero on ℚ, with 0 in the place of w
w \cdot 0 = w \cdot (\htmlClass{new}{0 + 0}) @@ the swap axiom: the right-hand 0 swapped by the line above, turned about
\phantom{w \cdot 0} = \htmlClass{new}{w \cdot 0 + w \cdot 0} @@ spread on ℚ
w \cdot 0 + (-(w \cdot 0)) = (w \cdot 0 + w \cdot 0) + \htmlClass{new}{(-(w \cdot 0))} @@ the swap axiom: the same thing added on the right of each side
0 = (w \cdot 0 + w \cdot 0) + (-(w \cdot 0)) @@ negative on ℚ, on the left
\phantom{0} = w \cdot 0 + (w \cdot 0 + (-(w \cdot 0))) @@ regroup for plus on ℚ
\phantom{0} = w \cdot 0 + 0 @@ negative on ℚ
\phantom{0} = \htmlClass{new}{w \cdot 0} @@ plus-zero on ℚ
w \cdot 0 = 0 \quad \blacksquare @@ the turn-about technique

And 0 · w = 0 by turn-about for times on ℚ. Look at which rules the column used: plus-zero on ℚ, spread on ℚ, negative on ℚ, regroup for plus on ℚ, and nothing else. Not the order rules, not the reciprocal, not even turn-about for times on ℚ. That list will matter at the end of the step.

5e3Negatives

Negative-out technique on ℚ: (−w)b = −(wb). In words: (−w)b and wb add to 0, so (−w)b is the negative of wb, because the negative is the only thing that adds to wb to give 0.

ab + (-a)b = ba + b(-a) @@ turn-about for times on ℚ, twice
\phantom{ab + (-a)b} = b(a + (-a)) @@ spread on ℚ, turned about
\phantom{ab + (-a)b} = b \cdot 0 @@ negative on ℚ
\phantom{ab + (-a)b} = \htmlClass{new}{0} @@ the anything-times-zero technique
(-a)b = \htmlClass{new}{-(ab)} \quad \blacksquare @@ the one-negative technique (5d), with ab in the place of w

Negative-of-a-negative technique: −(−c) = c. (−c) + c = 0 by negative on ℚ, so c is the one thing that adds to −c to give 0: c = −(−c), by one-negative. ∎ Now the rule everyone is told and almost no one is shown. Two-negatives technique: (−w)(−b) = wb.

(-a)(-b) = -(a(-b)) @@ the negative-out technique on ℚ, with −b in the place of b
\phantom{(-a)(-b)} = -((-b)a) @@ turn-about for times on ℚ, inside
\phantom{(-a)(-b)} = -(\htmlClass{new}{-(ba)}) @@ the negative-out technique on ℚ, inside
\phantom{(-a)(-b)} = -(-(ab)) @@ turn-about for times on ℚ, inside
\phantom{(-a)(-b)} = \htmlClass{new}{ab} \quad \blacksquare @@ the negative-of-a-negative technique

Nobody decreed that a negative times a negative is positive. The spreading rule forces it: (−w)b and wb must add to 0, because their sum is b times w + (−w), which is b times 0. Give up the answer “positive” and you give up the spreading rule, or the rule that a number and its negative add to 0. On pairs, 5b's multiplying rule had the same answer built in, for the same reason: it was read off the spreading of products.

An astronomer writing in India in the seventh century set out rules for fortunes and debts, quantities above and below nothing, and for zero itself. A debt multiplied by a debt is a fortune, and a debt taken from zero is a fortune. His is among the earliest known treatments of zero and of negative quantities as numbers with rules of their own.

A novelist, remembering his schooling, wrote that he asked his teachers why a minus times a minus makes a plus. No one could give him a reason he could accept, and he came to suspect they did not know one.

5e4Cancelling, and zero products

Cancel technique for times on ℚ: if wc = bc and c ≠ 0, then w = b.

ac = bc,\ \ c \ne 0 @@ given
(ac)c^{-1} = (bc)c^{-1} @@ the swap axiom: each side times c⁻¹, which exists because c ≠ 0
a(cc^{-1}) = b(cc^{-1}) @@ regroup for times on ℚ, on each side
a \cdot 1 = b \cdot 1 @@ reciprocal on ℚ: here c ≠ 0 is used
\htmlClass{new}{a = b} \quad \blacksquare @@ times-one on ℚ

Cancelling is multiplying by a reciprocal, and the condition c ≠ 0 is exactly the condition for the reciprocal to exist. That one line is the whole of the next section in miniature. Zero-product technique: if wb = 0, then w = 0 or b = 0. The case split it needs is licensed by the rules themselves. Three-way on ℚ says w = 0, or w is positive, or −w is positive. In the last two cases w ≠ 0, since “exactly one”. So w = 0 or w ≠ 0, with no help from rung 7.

ab = 0 @@ given
a = 0 \ \lor\ a \ne 0 @@ three-way on ℚ: its three-way or, the last two options giving a ≠ 0
\text{case } a = 0:\ \ a = 0 \lor b = 0 @@ add an option
\text{case } a \ne 0:\ \ b = 1 \cdot b = (a^{-1}a)b @@ times-one on ℚ; reciprocal on ℚ, since a ≠ 0
\qquad = a^{-1}(ab) = a^{-1} \cdot 0 = \htmlClass{new}{0} @@ regroup for times on ℚ; the given; anything-times-zero
\qquad a = 0 \lor b = 0 @@ add an option
a = 0 \lor b = 0 \quad \blacksquare @@ reason by cases

5e5No number times zero is one

Nothing-times-0-is-1 technique: there is no c with c · 0 = 1. In symbols, .

\text{assume } c \cdot 0 = 1 @@ aiming to refute; the some used
c \cdot 0 = 0 @@ the anything-times-zero technique
\htmlClass{new}{1 = 0} @@ the techniques turn-about and chain
1 \ne 0 @@ times-one on ℚ
\bot @@ clash
\neg\exists c\,(c \cdot 0 = 1) \quad \blacksquare @@ refute; the some closes

So 0 has no reciprocal, and since dividing by b is multiplying by b⁻¹ (5c's line), w/0 names nothing. Reciprocal on ℚ's “w ≠ 0” is not a gap in the list that a cleverer list would fill. It is a technique that the gap cannot be filled. 5c met the first face of this, when a pair with denominator 0 wrecked the sorting of pairs; this is the second face, met inside the rules.

Most books stop here. They lay it down as a mandate, “you cannot divide by 0”, or agree with the calculator that it is “undefined”, and move on. The ladder does not stop. It takes the question all the way down, until the answer stands back on the ground the ladder built.

Now ask the question itself. w/b asks for the x with b · x = w. Sift those x out of ℚ (2d): {x ∈ ℚ : b · x = w}. When b ≠ 0 the sift has exactly one member, w · b⁻¹. Drop the braces, and the answer is a number again.

\{x \in \mathbb Q : 2 \cdot x = 6\} = \{3\} @@ one member: drop the braces, and 6/2 names 3
\{x \in \mathbb Q : 0 \cdot x = 1\} = \varnothing @@ anything-times-zero: no x passes
\htmlClass{new}{\{x \in \mathbb Q : 0 \cdot x = 0\} = \mathbb Q} \quad \blacksquare @@ anything-times-zero: every x passes

Dividing by 0 does not quietly fail: it throws the answer out of the numbers and up into the sets of numbers. The answer to 1/0 is the set with nothing in it. The answer to 0/0 is the whole of ℚ. Neither has braces to drop, so neither is a number of ℚ. The question was fair. Its answer lives one level up, among the subsets of ℚ (2f): empty at one end, everything at the other.

So “w/0 names nothing” is exact in one direction and too modest in the other. 1/0 names no number. 0/0 names every number at once, and so no one of them.

Rung 1’s tables can judge each sift, with one row for each x in ℚ. For 6/2, “2 · x = 6” is so in exactly one row, and a column with exactly one row that is so names a number. For 1/0, “0 · x = 1” is the totally false, ⊥, in every row. For 0/0, “0 · x = 0” is ⊤ in every row: always so. An “and” of the two keeps only what both let through, and ∅ ∩ ℚ = ∅ (2e): ⊥ again.

So in a column the two fail in opposite ways. Suppose 1/0 is some number x. Then 0 · x = 1, and the column has reached ⊥. From ⊥ any statement may be written (1b10), so the column can now prove anything, and what it proves is worth nothing. The supposition was not so. Suppose instead that x is 0/0. Then the line 0 · x = 0 is ⊤. It holds whatever x is, so it tells the column nothing about x. 1/0 says too much; 0/0 says nothing.

So the answer to “what is 1/0?” is not a number. It is a verdict: the statement is false. And a statement with b in a bottom is false in every row where b is 0. So 3/(x − 2) = 1 carries ¬(x = 2) with it before it is even solved, because the row x = 2 is ⊥ already. ¬(x = 2) is also written x ≠ 2. The full answer is built from the ground up as one statement: ¬(x = 2) ∧ x = 5. Nothing here works around a ban. The denial is part of the answer.

5e6Why no patch works

Suppose someone wants dividing by 0 badly enough to add something new: a thing, call it u, with u · 0 = 1, and keep all twelve techniques. Then nothing-times-0-is-1 refutes it at once, and that used only anything-times-zero and times-one on ℚ. And anything-times-zero used only plus-zero on ℚ, spread on ℚ, negative on ℚ and regroup for plus on ℚ. So the patch must give up one of those, or times-one on ℚ. Which? Watch anything-times-zero's column with u in the place of w:

u \cdot 0 = 1 @@ the patch
u \cdot 0 = u \cdot (0 + 0) @@ the swap axiom, with plus-zero on ℚ: logic, not a rule of arithmetic
\phantom{u \cdot 0} = u \cdot 0 + u \cdot 0 = 1 + 1 @@ spread on ℚ, at u; then the patch, twice
1 = 1 + 1 @@ the techniques turn-about and chain
1 + (-1) = (1 + 1) + (-1) = 1 + (1 + (-1)) @@ the swap axiom; regroup for plus on ℚ
0 = 1 + 0 = \htmlClass{new}{1} @@ negative on ℚ; plus-zero on ℚ: against times-one on ℚ

Every rule used after the second line is a rule about ordinary numbers, 1 and −1, which nobody proposes to change. The only rule applied to u itself is spread on ℚ, the spreading rule. So there are exactly two ways out. Either spreading fails at u: u · (0 + 0) is not u · 0 + u · 0. Then no expression with u in it can be expanded, which is most of what 5i does. Or 1 = 0, and then every number is 0, since w = w · 1 = w · 0 = 0 by times-one on ℚ, the swap, and anything-times-zero. A collection with one member and nothing to count. There is no third way: the line u · 0 = u · (0 + 0) is the swap axiom, which is logic.

Other patches fare no better.

  • Zero over zero is zero. The same astronomer, in the same chapter as his rules for debts, said so. If 0 had a reciprocal 0⁻¹, then 0/0 = 0 · 0⁻¹ would be 0 by anything-times-zero, as he said. And it would be 1 by reciprocal on ℚ. So his answer is exactly what anything-times-zero forces of a reciprocal for 0, and the same column shows that reciprocal makes 1 = 0.
  • Name it 0. Some calculating systems simply define w/0 to be 0. That keeps all twelve techniques, because reciprocal on ℚ speaks only of w ≠ 0. But it answers nothing: 5c's reading of w/b, “the one x with bx = w”, fails at once, since 0 · (1/0) = 0 · 0 = 0 and not 1. It is a new name for an old number, not a reciprocal.
  • Let the pairs in. 5c showed that admitting the pair (0, 0) makes the relation glue every fraction to every other. Admitting only (1, 0) does no better, since (1, 0) times (0, 1), by the rule for ·, is (0, 0). The patch breaks the construction before any rule can be checked.

So division by zero is called undefined: no answer can be given to it without making 1 = 0.

Anexact, yet rigorous · laws with a known exception rate

A rule about real things comes with its range, and with the direction it fails outside that range. “Water flows downhill” is true until the water is a thin film on glass. Then it creeps up the sides, and the failure is part of the rule. A rule like this is called a law.

A law is a statement that names a regularity measured in the world. It holds within a known range, and inside that range it misses at a known rate.

A law is half axiom and half technique. In an argument it sits where an axiom sits. You lay it down, and the techniques you build on it are only as good as it is. An axiom is earned from above, by what breaks without it. A technique is earned by proof, from axioms. A law is earned by measuring, case after case, so it can always be asked for its evidence and its range. The words or marks written for a law describe the regularity. The regularity itself is out in the world, and the world can still surprise the description.

This page met an edge of the same kind at 5e5, and built it rather than decreed it. Every rational but 0 has a reciprocal. At 0 the rule fails, and the rules themselves say which way. Asked as a sift, “0 times what is 1?” finds no answer: the set with nothing in it. “0 times what is 0?” finds every answer: the whole of ℚ. Either way the answer leaves the numbers and goes up into the sets of numbers.

That is the direction of the failure, and knowing it makes the failure useful. A column that meets it reaches ⊥, the totally false, and the verdict is a statement: ¬(x = 2). It joins the answer as one more part of the guess.

A mandate would have stopped at “undefined”. This page took the edge all the way down instead. It stayed true to the anexactitude of dividing by 0, and to the rigor of its induction.

Keep an eye on the two ideas dividing by 0 has offered here: no answer at all, and every answer at once. Neither is the end of the road. The edge is not where the work stops. A result is a tool, not a wall.

State the rule, its range, and the direction it fails past the edge.

An exception does not kill a rule. It marks an edge, and a rule whose edges you know is stronger than one never tested at its edges.

5e7Illegal moves

A worked “proof” that 2 = 1, which hides the first slip below, is in the basement.

ac = bc \Rightarrow a = b \text{ with } c = 0\,? @@ cancel for times on ℚ needs c ≠ 0: 2 · 0 = 1 · 0. Every “proof” that 1 = 2 hides a division by 0
xx = x \Rightarrow x = 1\,? @@ cancelling x loses x = 0. zero-product does it honestly: xx − x = x(x − 1) = 0 gives x = 0 or x = 1

-(a + b) = -a + b\,? @@ the negative of a sum is the sum of the negatives: −(a + b) = (−a) + (−b), by one-negative
a \cdot 0 = a\,? @@ anything-times-zero: a · 0 = 0. Adding 0 changes nothing; multiplying by 0 changes everything to 0
0^{-1} \text{ with } 0 \cdot 0^{-1} = 1 @@ nothing-times-0-is-1: no such thing, in any collection obeying the rules

5e8Running it backwards

Wanting to show some product is 0, look for a factor that is 0, or a factor that spreads over a sum that is 0 (anything-times-zero, spread on ℚ). Wanting a sign: count the negatives, using negative-out on ℚ for one and two-negatives for two. Wanting to cancel: first show the factor is not 0, and say so on the line, or split into cases with zero-product. Seeing a patch for dividing by 0: run it through anything-times-zero's column, and the rule it breaks will be the first line it cannot cite. Found upward; written downward.
