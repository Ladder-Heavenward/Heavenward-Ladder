Writing for the Machine

Rung 39 built a machine that follows a list of numbers. Nobody writes a program in numbers. This rung climbs from the numbers to a language with names, shapes and calls. Then it proves what a program in that language does, with rung 4’s induction and rung 1’s rules.

Name the numbers; write in three shapes; prove each shape by its rule, each loop by what it keeps and a number that falls; and translate so that every run is kept.

The class · read it through, then go to 40a

What it means to say it

To say that a program is written for the machine is to say this. It is a list of steps in names and shapes that the machine’s numbers can carry out, and the steps make a promise that can be proved.

Every flow chart can be written with sequence, choice and repetition. A program’s promise {P} c {Q} is earned by one rule for each shape. A loop is proved by what it keeps and by a whole number that falls. A program in words is turned into the machine’s numbers by a translation that keeps every run. The rung proves it.

Where it comes from

The first stored-program machines were programmed in numbers. Words and labels came first, then languages that read like algebra, then the rules that prove programs right.

The principles, in plain words

The rung proves six things.

First, words and labels name the machine’s numbers, and a program of two passes turns them back with nothing changed (40a).

Second, three shapes are enough: one after another, one or the other, and again and again (40b).

Third, a name in a program holds a value that changes, and a call keeps its way back and its own names on a pile (40c, 40d).

Fourth, a function that calls itself is proved by induction and stops when a whole number falls, and a loop the same way, by what it keeps (40e, 40g).

Fifth, a program’s promise is a triple, earned shape by shape, and types rule out values of the wrong kind before anything runs (40f, 40h).

Sixth, data is built by repeating, and so are the translations that carry a language down to the numbers and keep every run (40i, 40j).

What follows

With those, the techniques work by hand. 40k proves a loop by finding what it keeps, and 40l compiles a program to the numbers of rung 39.

What you can do because you know it

You can write a program in shapes, say what it promises, and prove the promise. You can say why it stops. And you can follow it all the way down to the switches.

What it costs

Nothing new is laid down. The rung spends rung 4’s induction and least members, rung 1’s rules and 39’s machine.
