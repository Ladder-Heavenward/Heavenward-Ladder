10d · proof

The squeeze

10c's techniques need limits to start from. Some functions offer nothing to start with. 9a's strange function is 1 at every fraction and 0 at every irrational. It cannot be drawn, it has no formula to rewrite, and, as this step proves, it has no limit anywhere. Yet the input times that function heads to 0 at 0. The tool is the squeeze. Trap the function, near the input, between two functions that head to the same value. Then it is forced to head there too, whatever it does in between. The step proves the squeeze, then two handy forms of it, then uses them on the strange function and on a root.

Find a function below and a function above, near the input, both heading to one value. The target that holds them both holds everything between.

What this stands on, and where it goes

Stands on 10a (the definition, lesser-below-both, line-limit), 10b (two-targets), 10c (constant-factor, the least of several), 8h (unpack-the-bars, size-of-a-product, sandwich), 8e (fraction-between, everyday-counting-passes), 8f (√, powers-keep-order), 9a (the function q; r + √2/n irrational). 10f squeezes when no rewrite works; rung 12 and rung 21 squeeze again.

10d1The squeeze

Stands on 10a (the definition), 10a5 (lesser-below-both) and 10b4 (limits keep order).

In plain words first. Near w, a function f sits between a lower function g and an upper function h, and both g and h head to the same L. Then f heads to L. The challenger's gap keeps g and h in their targets; f, caught between, has nowhere else to be. Squeeze technique: if there is a reach r with g(x) ≤ f(x) ≤ h(x) for every x in the neighbourhood of w of reach r (all three defined there), and lim_{x→w} g(x) = L and lim_{x→w} h(x) = L, then lim_{x→w} f(x) = L. Its accepted name is the squeeze theorem, also called the sandwich theorem.

\text{let } \varepsilon \gt 0;\ \text{call } \delta_1 \text{ for } g,\ \delta_2 \text{ for } h @@ speak of everything; both limits at the gap ε
\delta = \htmlClass{new}{\min(\delta_1, \delta_2, r)};\ \ \text{assume } 0 \lt |x - a| \lt \delta @@ the least of several (10c): all three windows at once
L - \varepsilon \lt g(x) @@ |g(x) − L| < ε, unpacked by unpack-the-bars (8h): keep the left part
h(x) \lt L + \varepsilon @@ |h(x) − L| < ε, unpacked: keep the right part
L - \varepsilon \lt g(x) \le \htmlClass{keep}{f(x)} \le h(x) \lt L + \varepsilon @@ the trap, since δ ≤ r
L - \varepsilon \lt f(x) \lt L + \varepsilon @@ at-most-is-a-partial-order on ℝ: < then ≤ gives <, twice
|f(x) - L| \lt \varepsilon \quad \blacksquare @@ unpack-the-bars, packed; prove an if; speak of everything

Notice what the column never used: any value of f. It knows f only through the trap. That is why the squeeze works on functions with no formula, and why it is the tool of last resort when rewriting fails. Notice too that the trap is needed only near w. What f, g and h do far from w, or at w itself, is never consulted.

10d2Two forms you will use more than the technique

Stands on 10d1, 10c (constant-factor) and 8i (conjugates).

Most traps are built from a size. Squeezed-to-0 technique: if there is a reach r with |f(x)| ≤ h(x) for every x in the neighbourhood of w of reach r, and lim_{x→w} h(x) = 0, then lim_{x→w} f(x) = 0. By unpack-the-bars, |f(x)| ≤ h(x) is −h(x) ≤ f(x) ≤ h(x); −h heads to −0 = 0 by constant-factor; squeeze. ∎

And the commonest size of all is the input's own distance. First a small fact: lim_{x→w} |x − w| = 0. Here ||x − w| − 0| = |x − w| < δ, so δ = ε wins (the size of a size is itself, by 8h). Squeezed-by-distance technique: if there are a real C ≥ 0 and a reach r with |f(x) − L| ≤ C · |x − w| for every x in the neighbourhood of w of reach r, then lim_{x→w} f(x) = L.

\lim_{x \to w} C\,|x - w| = C \cdot 0 = 0 @@ the small fact, then constant-factor (10c)
|f(x) - L| \le C\,|x - a| \ \ \text{near } a @@ the hypothesis
\lim_{x \to w} \big(f(x) - L\big) = \htmlClass{new}{0} @@ squeezed-to-0, with f − L for f and C|x − w| for h
\lim_{x \to w} f(x) = L \quad \blacksquare @@ ﹀ both lines: |(f(x) − L) − 0| and |f(x) − L| are the same distance

Squeezed-by-distance is the bound a linear function always gives (|(mx + b) − (mw + b)| = |m||x − w|), so it is line-limit again. But it also works for functions that only obey such a bound. Here is one. √(x + 4) at 0, heading to 2.

\sqrt{x + 4} - 2 = \tfrac{(\sqrt{x + 4} - 2)(\sqrt{x + 4} + 2)}{\sqrt{x + 4} + 2} @@ times 1, as 8i's conjugate: √(x + 4) + 2 ≥ 2 > 0 for x ≥ −4
= \tfrac{\htmlClass{new}{(x + 4) - 4}}{\sqrt{x + 4} + 2} = \tfrac{x}{\sqrt{x + 4} + 2} @@ difference-of-squares (5i) on the top; √(x + 4)² = x + 4 (8f)
|\sqrt{x + 4} - 2| = \tfrac{|x|}{\sqrt{x + 4} + 2} \le \htmlClass{new}{\tfrac12}\,|x - 0| @@ size-of-a-product; the bottom is at least 2, so its reciprocal is at most ½ (positive-reciprocal on ℚ)
\lim_{x \to 0} \sqrt{x + 4} = 2 @@ squeezed-by-distance with C = ½ and reach 4: the function is defined on [−4, ∞), which holds the neighbourhood of 0 of reach 4

10d3A function nobody can draw

Stands on 10d2, 9a5 (q) and 8e (fraction-between).

9a's q is 1 at every fraction and 0 at every irrational. Both kinds are in every neighbourhood of every real. The fractions are there by 8e's fraction-between. The irrationals are there because, as 9a showed, r + √2/n is irrational for every fraction r and number n ≠ 0. And everyday-counting-passes makes √2/n as small as you like. So in any window, however narrow, q takes both values 0 and 1. Heads-nowhere technique: for every real w and every real L, q does not head to L at w.

\lim_{x \to w} q(x) = L @@ assume, to refute (no either-way principle needed)
\varepsilon = \tfrac12;\ \ \text{call } \delta @@ challenge with one half; use the some
r \in \mathbb Q,\ \ a \lt r \lt a + \delta @@ fraction-between (8e): a fraction between two reals
n \ne 0 \text{ with } \tfrac{\sqrt2}{n} \lt a + \delta - r;\ \ t = r + \tfrac{\sqrt2}{n} @@ everyday-counting-passes on the positive (a + δ − r)/√2; positive-reciprocal on ℚ
r \lt t \lt a + \delta,\ \ t \text{ irrational} @@ order-and-arithmetic-agree; 9a's technique
q(r) = \htmlClass{new}{1},\ \ q(t) = \htmlClass{new}{0} @@ the definition of q, by cases
|1 - L| \lt \tfrac12 \;\land\; |0 - L| \lt \tfrac12 @@ r and t are both in the window: carry the promise through twice; join
\bot @@ two-targets (10b) with values 1 and 0: 2 · ½ = 1 = |1 − 0|
\neg\big(\lim_{x \to w} q(x) = L\big) \quad \blacksquare @@ refute; then speak of everything: every L, every w

So q has no limit anywhere: the some of 10b's ∃! fails, at every real. Now multiply it by x. Every output of q is 0 or 1, so |q(x)| ≤ 1 and |x · q(x)| = |x| |q(x)| ≤ |x| (size-of-a-product). That is a trap: squeezed-to-0 with h(x) = |x|, which heads to 0 at 0 by the small fact. So lim_{x→0} x · q(x) = 0. A function that is wild everywhere, tamed at one point by a factor that heads to 0 there. At any other point w it is still wild: near w ≠ 0, x · q(x) is near w at fractions and is 0 at irrationals. Likewise 1 + x² · q(x) sits between 1 and 1 + x², both heading to 1 at 0, so it heads to 1 there.

10d4Numbers squeezed

Stands on 10d1, 8f (squares keep order) and 8·cb5 (cut-offs).

The squeeze is older than functions. 8f trapped √2 between decimals: 1.4142 < √2 < 1.4143, because 1.4142² = 1.99996164 and 1.4143² = 2.00024449. 8·cb5 made it endless: the k-th cut-off c_k of a decimal and c_k + 10^(−k) trap its real for every k. Each trap is a squeeze with numbers in place of functions, and 10f turns that into a statement about sequences: the cut-offs head to the real. What this step adds is that the same trap works when the thing trapped is a whole function, near an input.

10d5What the squeeze cannot do

Stands on 10d1 and 10d3.

The traps must head to the same value. q itself sits between the constants 0 and 1, which head to 0 and to 1. Those are two different values, and the squeeze says nothing. That is just as well, since q has no limit. The traps must be in place on a whole neighbourhood, not at a few inputs: a function that is below x² at the fractions and wild at the irrationals is not trapped. And the trap must be ≤ on both sides; one side alone proves nothing (q ≥ 0 and 0 → 0, yet q heads nowhere).

10d6The squeeze with the techniques

Stands on 10d2, 10c (limits add) and 10b (sides).

A squeeze rarely works alone. Most wild functions are a tame part plus a wild part, and the techniques of 10c handle the sum once the squeeze has handled the wild part. Take x · q(x) + 3x + 2 at 0: the wild part x · q(x) heads to 0 (above), the tame part 3x + 2 heads to 2 (line-limit), and limits-add gives 2. Or take (x³ + x · q(x))/(1 + x²) at 0. The top heads to 0 + 0 = 0 (power-limit, the squeeze, limits-add). The bottom heads to 1 (substitution), so limits-divide gives 0. The habit is to split off what the techniques can do and squeeze only what they cannot.

f(x) = (x - 2)^2 \cdot q(x) + 5 \text{ near } 2 @@ the wild factor q is bounded; the tame factor (x − 2)² heads to 0 at 2
|f(x) - 5| = (x - 2)^2\,|q(x)| \le \htmlClass{new}{(x - 2)^2} @@ size-of-a-product; |q(x)| ≤ 1; (x − 2)² ≥ 0 (square-never-negative)
(x - 2)^2 \to 0 \text{ at } 2 @@ substitution (10c): substitute 2
\lim_{x \to 2} f(x) = \htmlClass{keep}{5} @@ squeezed-to-0, with f − 5 for f; then ﹀, as in squeezed-by-distance

The squeeze also works side by side, as 10e will need. Squeeze-for-sides technique: if g(x) ≤ f(x) ≤ h(x) for every x with w < x < w + r, and g and h head to L from the right at w, then f heads to L from the right at w; likewise from the left. Squeeze's column, with the half-window w < x < w + δ in place of the neighbourhood. ∎ So one trap on one side is enough for a one-sided limit. 0 ≤ √x ≤ √x is no help. But 0 ≤ x · q(x) ≤ x for x > 0 gives x · q(x) heading to 0 from the right, with no help from the left at all.

And squeezed-by-distance, the commonest form, has a sharper reading. A bound |f(x) − L| ≤ C|x − w| on a reach r hands you the answer outright, δ = min(r, ε/C) (or any δ when C = 0). For √(x + 4) at 0, C = ½ and r = 4 give δ = min(4, 2ε). A squeeze is a recipe in disguise.

10d7Illegal moves

Stands on 10d1 to 10d6.

0 \le q(x) \le 1 \;\Rightarrow\; q \text{ has a limit}\,? @@ the traps head to 0 and to 1: no squeeze. heads-nowhere says there is none
q(x) \ge 0 \text{ and } 0 \to 0 \;\Rightarrow\; q \to 0\,? @@ one trap is not a squeeze: ε = ½ and t = 1 at fractions beat it
\text{trap at the fractions only}\,? @@ the hypothesis is “for every x near a”. Inputs left out of the trap are free
\text{“x · q(x) heads to 0, so q heads to 0”}\,? @@ the factor x did the work. Without it, heads-nowhere
\text{read q's value off a drawing}\,? @@ every drawn input is a finite decimal, a fraction. q is not what any drawing shows
|f(x) - 2| \le 3|x - 1| \text{ at } x = 1.1,\ 1.01,\ 1.001\,? @@ three inputs prove nothing: the bound must be true on a neighbourhood

10d8Running it backwards

Stands on 10d1 to 10d6.

Wanting lim f = L with no rewrite in sight: write f(x) − L as a product with one factor you can bound and one that heads to 0, then cite squeezed-to-0. Wanting a trap for a wild factor: bound its outputs by a constant (|q(x)| ≤ 1) and let a tame factor do the shrinking. Wanting to refute a limit for a wild function: find two kinds of input in every window with outputs a fixed distance apart, as heads-nowhere did. Found upward; written downward.

Who said it first

The paper of 1829 is Peter Gustav Lejeune Dirichlet’s, and q is known as Dirichlet’s function. In 10d.4.4, the ancient book is Archimedes’ Measurement of a Circle; the one who summed indivisible lines is Bonaventura Cavalieri, and his critic is Paul Guldin.

Dirichlet described such a function at the end of a paper of 1829, as an example of a function his methods could not handle: one that takes one value at the fractions and another at the irrationals, so that it jumps between the two in every stretch, however short.

Dirichlet, “Sur la convergence des séries trigonométriques qui servent à représenter une fonction arbitraire entre des limites données”, Journal für die reine und angewandte Mathematik 4 (1829)
