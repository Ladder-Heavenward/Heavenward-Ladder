40h · proof

Types Catch Mistakes Before Running

On 39’s machine everything is a number, so nothing stops a program adding a truth value to a count. This step gives each name a type, and shows that a check made by reading the program once, never running it, rules out a whole kind of mistake.

A type is the set a name may hold. Check every step’s types by reading, and no run ever hands an operation a value it does not take.

40h1What a Name May Hold

A type is a set of values (2d): the whole numbers, the two truth values, the strings of letters. Writing x : number says x may hold only whole numbers. Each operation says which types it takes and which it gives: + takes two numbers and gives a number, and ∧ takes two truth values and gives one.

40h2Checking Without Running

Each expression gets a type from its parts, by the lists of its operations. A step x ← e passes when e’s type is x’s type, and an if or a while passes when its test is a truth value. A program passes when every step does. The check reads each line once and never runs anything.

Type-check technique: if a program passes the check and every name starts with a value of its type, then no run ever hands an operation a value outside the types it takes.

The proof is induction on the steps of a run. At the start every name holds a value of its type. Each step, having passed the check, works out e from values of the right types, so e’s value is of e’s type, which is x’s type. So after the step every name still holds a value of its type.

40h3What a Check Cannot See

The check passes x ← y / z when z holds 0: both sides are numbers. It passes a loop that never stops. So types rule out one kind of mistake, a value of the wrong kind, and leave the rest to 40f’s promises and 40e’s measures.

40h4Types Look Like Statements

A type with a member is like a statement that can be shown: the member is the showing. A function from type A to type B is like an if: give it an A and it makes a B. Rung 47 makes this exact, as proofs are programs (47j).

The accepted names

This is a static type system. The type-check technique is type soundness, often put as “well-typed programs cannot go wrong”. Types as statements is the Curry–Howard correspondence, which 47j builds.
