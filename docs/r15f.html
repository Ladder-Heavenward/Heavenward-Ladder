15f · proof

Every Continuous Curve Has an Area

15c's test asks, for every small gap, for one partition whose upper and lower sums differ by less than that gap. For a continuous function, each piece’s gap is the difference between two values of the function on the piece, and continuity says that values at nearby inputs are close. So narrow pieces should do. But continuity at an input gives a window whose width depends on the input, and the windows might shrink toward nothing somewhere, as they do for one over the input near 0. The proof needs one width that serves every input of the interval at once. On a closed interval there is one, and it is found the way 12b found a bound: not by walking, but by going straight to a least upper bound.

For each gap, the inputs up to which one width serves have a least upper bound. There, continuity gives a window that carries some width past it. So the bound is the right end, and one width serves the whole interval. Cut finer than that width, and every piece’s gap is small, so the upper and lower sums are as close as you like.

15f1One Width for the Whole Interval

From here on, f is uniformly continuous on a set A when for every ε > 0 there is δ > 0 such that all s, t in A with |s − t| < δ have |f(s) − f(t)| < ε. Its accepted name is uniformly continuous.

The difference from continuity at each input is the order of the choices. Continuity: for each input c and each ε there is a δ, which may depend on c. Uniform continuity: for each ε there is a δ that serves every pair at once. For x on any interval, δ = ε does. For 1/x on (0, 1], none does. The inputs 1/n and 1/(n + 1) are 1/(n(n + 1)) apart, closer than any δ for large n, and their values are 1 apart.

Evenly-continuous technique: if f is continuous on [u, v], then f is uniformly continuous on [u, v]. Its accepted name is the Heine–Cantor theorem.

\text{fix } \varepsilon \gt 0 @@ to find one δ for all of [u, v]
B = \{x \in [u, v] : \exists \delta \gt 0\ \forall s, t \in [u, x]\ (|s - t| \lt \delta \Rightarrow |f(s) - f(t)| \lt \varepsilon)\} @@ the inputs up to which one width serves (Separation, 2e)
u \in B @@ on [u, u] the only pair is u, u, and |f(u) − f(u)| = 0 < ε; any δ
\htmlClass{new}{\sigma = \sup B},\ \ u \le \sigma \le v @@ no-holes (8c): B has a member, and v is an upper bound. The one completeness line
  
\text{call } \delta_0:\ t \in [u, v] \land |t - \sigma| \lt \delta_0 \Rightarrow |f(t) - f(\sigma)| \lt \tfrac{\varepsilon}{2} @@ closed-interval-continuity (12a) at σ, with ε/2
\text{call } x \in B,\ \ \sigma - \tfrac{\delta_0}{2} \lt x \le \sigma,\ \ \text{with its } \delta_1 @@ σ − δ₀/2 is not an upper bound of B, since σ is the least
y = \min(\sigma + \tfrac{\delta_0}{2},\ v),\ \ \delta_2 = \min(\delta_1,\ \tfrac{\delta_0}{2}) @@ a little past σ, and a width for both stretches
\text{let } s \le t \text{ in } [u, y],\ \ t - s \lt \delta_2 @@ to show |f(s) − f(t)| < ε
\text{case } t \le x:\ \ s, t \in [u, x],\ t - s \lt \delta_1 @@ x ∈ B with δ₁; δ₂ ≤ δ₁
\text{case } x \lt t:\ \ \sigma - \tfrac{\delta_0}{2} \lt t \le \sigma + \tfrac{\delta_0}{2} @@ x < t ≤ y
\qquad \sigma - \delta_0 \lt t - \delta_2 \lt s \le t @@ δ₂ ≤ δ₀/2
\qquad |f(s) - f(t)| \le |f(s) - f(\sigma)| + |f(\sigma) - f(t)| \lt \varepsilon @@ both s and t are within δ₀ of σ; triangle (8h); ε/2 + ε/2
y \in B,\ \text{with } \delta_2 @@ the two cases
  
y \le \sigma @@ σ is an upper bound of B
y \ne \sigma + \tfrac{\delta_0}{2},\ \ \text{so } y = v @@ σ + δ₀/2 > σ; min is one of the two
v \in B @@ the line above
\begin{aligned}&\htmlClass{new}{\exists \delta \gt 0\ \forall s, t \in [u, v]\ (|s - t| \lt \delta }\\ &\quad \htmlClass{new}{\Rightarrow |f(s) - f(t)| \lt \varepsilon)} \quad \blacksquare\end{aligned} @@ since v ∈ B; ε was any

The proof is bounded-on-a-closed-interval's again, with “a bound up to x” replaced by “a width up to x”. Completeness was spent once, at σ. Continuity was spent once, at σ, with ε/2. As in bounded-on-a-closed-interval, the closed interval was used twice: to have the left end in B, and to have the right end in the interval, so that σ is an input where f is continuous.

15f2The Squeeze Closes

Continuous-is-integrable technique: if f is continuous on [u, v], then f is integrable on [u, v].

\text{fix } \varepsilon \gt 0;\ \ \eta = \tfrac{\varepsilon}{2(v - u)} @@ the gap allowed on each piece
\text{call } \delta:\ |s - t| \lt \delta \Rightarrow |f(s) - f(t)| \lt \eta @@ evenly-continuous, with η
\text{call } n:\ \tfrac{v - u}{n} \lt \delta;\ \ P = \text{equal partition} @@ everyday-counting-passes (8e)
m_i = f(s_i),\ \ M_i = f(t_i),\ \ s_i, t_i \text{ in the } i\text{-th piece} @@ highest-and-lowest (12c) on each piece: the least and greatest are reached
|s_i - t_i| \le \tfrac{v - u}{n} \lt \delta,\ \ M_i - m_i \lt \eta @@ the call of δ
U(f, P) - L(f, P) = \textstyle\sum (M_i - m_i)\Delta x_i \lt \eta(v - u) = \tfrac{\varepsilon}{2} \lt \varepsilon @@ order-and-arithmetic-agree; the widths add to v − u
\htmlClass{new}{f \text{ is integrable on } [u, v]} \quad \blacksquare @@ gap-closes (15c)

So every polynomial (11d) is integrable on every closed interval, and so is √x on [0, v], and 1/x on any [u, v] with 0 < u. The area under each of these exists, whether or not anyone can yet say what number it is. 15e's bound for ∫₀¹ x² held the integrability of x² in trust, and this line closes that flag.

The first to prove this argued as follows. If a function stays continuous between two bounds, the sum of its values times the small differences of the input settles on a fixed number as the differences shrink. That is true whatever the way of dividing. He took that number as the definition of the integral.

15f3The Mean Value of a Function

From here on, for f integrable on [u, v], its average value there is (1/(v − u)) ∫ᵤᵛ f. Its accepted name is the average value, or mean value, of f on [u, v].

Average-height technique: if f is continuous on [u, v], some c in [u, v] has f(c) = (1/(v − u)) ∫ᵤᵛ f. Its accepted name is the mean value theorem for integrals.

m = f(s),\ \ M = f(t),\ \ \text{the least and greatest on } [u, v] @@ highest-and-lowest (12c)
m(v - u) \le \textstyle\int_u^v f \le M(v - u) @@ smaller-function-smaller-area (15e), with f integrable by continuous-is-integrable
m \le \tfrac{1}{v - u}\textstyle\int_u^v f \le M @@ order-and-arithmetic-agree, v − u > 0
\htmlClass{new}{\exists c\ \ f(c) = \tfrac{1}{v - u}\textstyle\int_u^v f} \quad \blacksquare @@ in-between-value, general form (12a) between s and t: a continuous f takes every value between f(s) and f(t)
  
\text{average-slope: } \tfrac{F(v) - F(u)}{v - u} = F'(c) @@ the average slope is a slope somewhere
\text{average-height: } \tfrac{1}{v - u}\textstyle\int_u^v f = f(c) @@ the average height is a height somewhere
2x + 1 \text{ on } [0, 2]:\ \ \textstyle\int_0^2 = 4 + 2 = 6,\ \ \text{average } 3 @@ 15d, 15c, areas-add, areas-scale
2c + 1 = 3,\ \ c = 1 @@ the input where the height is the average

The two techniques have the same shape, and the same numbers here. x² + x has slope 2x + 1, rises by 6 over [0, 2], and its average slope 3 is reached at 1. Whether that agreement is an accident is the next rung's question.

15f4Continuity Is Enough, Not Needed

An increasing function need not be continuous, and every increasing f on [u, v] is integrable. The collapse of 15a5, run on any increasing f (15a.4.4), gives U − L = (f(v) − f(u))(v − u)/n for n equal pieces, below any ε for n large enough. An increasing function can jump at endlessly many inputs, and still has an area.

Who said it first

Cauchy argued that if a function stays continuous between two bounds, the sum of its values times the small differences of the input settles on a fixed number as the differences shrink, whatever the way of dividing; and he took that number as the definition of the integral.

Cauchy, Résumé des leçons sur le calcul infinitésimal (1823), twenty-first lecture; paraphrase

Accepted names: the evenly-continuous technique is the Heine–Cantor theorem, after Eduard Heine and Georg Cantor. In the closer, the proof of 1823 is Augustin-Louis Cauchy’s, the lectures of 1854 are Peter Gustav Lejeune Dirichlet’s, and the proof of 1872 is Heine’s.
