16h · technique

Substitution and parts by hand

Taking a slope is a procedure: apply the rules in order and the answer comes out. Finding an antiderivative is a search. 16d and 16e give two techs, and the table gives the places to stop; this step is about choosing. Which inside should get the new letter? Which factor should be the one whose slope is taken in parts? When does one tech set up the other? The step gathers the signs to look for, and works a run of examples by hand. It ends with a tech that uses parts on an integral to express it through a smaller one of the same kind. Then a whole list of areas comes out of one line.

Look for an inside whose slope is a factor, and give it the new letter. If there is none, look for a power of the input times something easy to undo, and use parts with the power as the one whose slope is taken. If an inside is a straight line, naming it and solving back for the input turns anything into powers. Check every answer by its slope.

16h1Signs to look for

\text{a straight inside } kx + m @@ substitution, r = kx + m, and write x = (r − m)/k wherever x is left over

16h2Substitution, with ends and with x left over

Stands on 16h1 and 16d (the bookkeeping in d's).

\textstyle\int_0^2 \tfrac{x}{(x^2 + 1)^2}\,dx:\ \ r = x^2 + 1,\ dr = 2x\,dx @@ r runs from 1 to 5
= \tfrac12\textstyle\int_1^5 r^{-2}\,dr = \tfrac12\big(-\tfrac1r\big)\Big|_1^5 = \tfrac12\big(1 - \tfrac15\big) = \tfrac25 @@ substitution for areas; negative-powers backwards
  
\textstyle\int \tfrac{x}{\sqrt{x + 1}}\,dx:\ \ r = x + 1,\ dr = dx,\ x = r - 1 @@ x > −1

16h3Parts twice, both moves, and a completed square

Stands on 16h2, 16e (parts) and 3 (completing the square).

\textstyle\int_0^1 x^2 (1 - x)^3\,dx:\ \ f = x^2,\ g' = (1 - x)^3,\ g = -\tfrac{(1 - x)^4}{4} @@ straight-inside
= 0 + \tfrac12\textstyle\int_0^1 x(1 - x)^4\,dx @@ parts for areas; the bar is 0 at both ends
= \tfrac12 \cdot \tfrac{1}{30} = \tfrac{1}{60} @@ 16e's first example; areas-under-xᵐ(1 − x)ⁿ agrees: 2! 3!/6!
  
\textstyle\int_0^1 x^3 (x^2 + 1)^{1/2}\,dx:\ \ r = x^2 + 1,\ x^2 = r - 1,\ x\,dx = \tfrac12 dr @@ x³ dx = x² · x dx
= \tfrac12\textstyle\int_1^2 (r - 1) r^{1/2}\,dr = \tfrac12\big(\tfrac25 r^{5/2} - \tfrac23 r^{3/2}\big)\Big|_1^2 @@ split; the table
= \tfrac12\big(\tfrac25 \cdot 4\sqrt2 - \tfrac23 \cdot 2\sqrt2 - \tfrac25 + \tfrac23\big) = \tfrac{2\sqrt2 + 2}{15} @@ 2^{5/2} = 4√2, 2^{3/2} = 2√2; parts with f = x² gives the same
  
\textstyle\int \tfrac{x^4 + 2}{x^2}\,dx = \int (x^2 + 2x^{-2})\,dx @@ divide each term by x² (rung 3); x ≠ 0
= \tfrac{x^3}{3} - \tfrac{2}{x} + C,\ \ \text{on } x \gt 0 \text{ or on } x \lt 0 @@ the table; 16f's gap at 0
\textstyle\int \tfrac{x^3 - 1}{x - 1}\,dx = \int (x^2 + x + 1)\,dx = \tfrac{x^3}{3} + \tfrac{x^2}{2} + x + C @@ difference-of-powers (13h): x³ − 1 = (x − 1)(x² + x + 1); on x > 1 or x < 1
  
x^2 - 2x + 5 = (x - 1)^2 + 4 @@ rung 3's algebra: complete the square
\textstyle\int \tfrac{x - 1}{(x^2 - 2x + 5)^2}\,dx:\ \ r = (x - 1)^2 + 4,\ dr = 2(x - 1)\,dx @@ the square shows r ≥ 4, so nothing is undefined
= \tfrac12\textstyle\int r^{-2}\,dr = -\tfrac{1}{2r} + C = -\tfrac{1}{2(x^2 - 2x + 5)} + C @@ substitution for areas; negative-powers backwards

Completing the square does not always finish the job. ∫ dx/((x − 1)² + 4) has no factor x − 1 to become dr, and no entry in the table fits it. Its area function exists by antiderivative-exists.

16h4One integral through a smaller one

Stands on 16h3 and 4c (induction).

Who said it first

Wallis, working through tables of such areas by interpolation and pattern, wrote that he had followed the numbers where they led, trusting the pattern beyond the cases he could compute, and called the method induction, though not in the sense of a proof.

Wallis, Arithmetica infinitorum (1656); paraphrase

In 16h.4.5, the procedure of 1969 is Robert Risch’s, and its accepted name is the Risch algorithm.
