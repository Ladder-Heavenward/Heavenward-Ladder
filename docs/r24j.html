24j · technique

The logistic equation solved

The seventeenth rung met a population that grows at a rate set by its size, slowed by the share of room already taken. It found the S-shaped curve, and the moment of fastest growth at half the ceiling. But it worked under a quiet assumption: that the population stays between nothing and the ceiling, so that its logarithms make sense. It never showed that the curve is the only one the rule allows, and it waved at starts above the ceiling. This step pays all of that. The rule is tame, so the curve is the one solution, and it can never touch the ceiling. Every start is solved, including the ones that fall and the ones that run off. Turned upside down, the rule becomes the cooling rule, and that gives a way to read the ceiling from three counts. And walked forward a year at a time, the same rule can refuse to settle at all.

The logistic rule is tame, so its S-shaped curve is the only solution from its start, and it never touches the ceiling. Every start has a formula. Turned upside down, the population cools toward one over the ceiling, and three counts at equal times fix the whole curve. Taken a year at a time, the rule settles only if the yearly growth is not too strong.

24j1One solution, and it never touches the ceiling

17·bio solved P′ = rP(1 − P/K) “while 0 < P < K”. It used ln P and ln(K − P), which need both to be positive. So it found one solution that stays between, and left open whether a solution could reach K, or whether another curve could share the start. Both are closed here.

Stays-between technique: for P′ = rP(1 − P/K) with r, K > 0 and 0 < P₀ < K, exactly one solution passes through (0, P₀). It is P = K/(1 + Ce^(−rt)) with C = (K − P₀)/P₀, it exists for every real t, and it never touches 0 or K.

F(P) = rP\big(1 - \tfrac{P}{K}\big),\ \ F'(P) = r\big(1 - \tfrac{2P}{K}\big),\ \ |F'(P)| \le r\big(1 + \tfrac{2B}{K}\big) \text{ for } |P| \le B @@ a slope ceiling on every bounded strip: tame (24d1)
P = 0 \text{ and } P = K \text{ are resting lines} @@ F(0) = F(K) = 0
0 < P(t) < K \text{ wherever a solution from } (0, P_0) \text{ exists} @@ the resting-line technique (24f3): a solution that starts off a resting line never touches it
P = \tfrac{K}{1 + Ce^{-rt}},\ \ C = \tfrac{K - P_0}{P_0} > 0 @@ now 17·bio's steps are licensed: the logistic-solution technique
\tfrac{K}{1 + Ce^{-rt}} \text{ has a slope for every } t \text{ and obeys the rule, from } P_0 @@ the bottom is above 1; the put-back technique (24f2)
\htmlClass{new}{\text{that curve, for every } t, \text{ is the only solution, and stays between } 0 \text{ and } K} \quad \blacksquare @@ any solution agrees with it while both exist (the drift technique, 24d3)

The ceiling is approached and never reached, as 17·bio's illegal moves said. Now there is a reason that does not lean on the formula: the ceiling is itself a solution, and two solutions of a tame rule never meet.

24j2Every start

Every-start technique: for every start P₀ ≠ 0, the one solution of P′ = rP(1 − P/K) through (0, P₀) is P = K/(1 + Ce^(−rt)), C = (K − P₀)/P₀, wherever 1 + Ce^(−rt) > 0. A start above K falls to K; a start below 0 runs off to minus infinity at t = ln(−C)/r. A start at 0 stays at 0.

P = \tfrac{K}{1 + Ce^{-rt}} \Rightarrow P' = \tfrac{rKCe^{-rt}}{(1 + Ce^{-rt})^2} @@ the chain rule (13e)
rP\big(1 - \tfrac{P}{K}\big) = r\,\tfrac{K}{1 + Ce^{-rt}}\cdot\tfrac{Ce^{-rt}}{1 + Ce^{-rt}} = P' @@ 1 − P/K = Ce^{−rt}/(1 + Ce^{−rt})
P(0) = \tfrac{K}{1 + C} = P_0 \iff C = \tfrac{K - P_0}{P_0} @@ the start
P_0 > K:\ -1 < C < 0,\ \ 1 + Ce^{-rt} > 0 \text{ for } t \ge 0,\ \ P \to K \text{ from above} @@ e^{−rt} ≤ 1 and heads to 0
P_0 < 0:\ C < -1,\ \ 1 + Ce^{-rt} = 0 \text{ at } t^* = \tfrac{\ln(-C)}{r} > 0 @@ the bottom reaches 0 going forward
\htmlClass{new}{P_0 < 0:\ P \to -\infty \text{ as } t \to t^*,\ \text{a run-off as in 24e2}} \quad \blacksquare @@ the formula is the one solution while it lasts (24d3)

A start above K also runs off, backward in time, at t = ln(−C)/r < 0. A herd of 8000 elk on range that holds 5000, with r = 0.3 a year, has C = −0.375. It falls to 5457 in five years. Run the rule backward and it would have been infinite 3.27 years before the count, which says only that the rule cannot have held back then. A negative population has no meaning; it is here because the rule does not know that, and its run-off is the same as y′ = y²'s.

24j3Turned over, the population cools

Reciprocal-cooling technique: if P solves P′ = rP(1 − P/K) and is never 0, then u = 1/P solves u′ = −r(u − 1/K): u closes on 1/K as a drink cools toward its room, and the gap u − 1/K shrinks by the factor e^(−rT) in every stretch of time T.

u = \tfrac1P,\ \ u' = -\tfrac{P'}{P^2} = -\tfrac{r}{P} + \tfrac{r}{K} = -r\big(u - \tfrac1K\big) @@ the chain rule (13e); put in the rule
u - \tfrac1K = \big(u_0 - \tfrac1K\big)e^{-rt} @@ the own-rate technique (24a3) on the gap
u_2 - c = q\,(u_1 - c),\ \ u_3 - c = q\,(u_2 - c),\ \ c = \tfrac1K,\ q = e^{-rT} @@ three counts, T apart
q = \tfrac{u_3 - u_2}{u_2 - u_1} @@ subtract the two lines
(u_2 - c)^2 = (u_1 - c)(u_3 - c) @@ both sides equal q²(u₁ − c)²
\htmlClass{new}{\tfrac1K = \tfrac{u_1u_3 - u_2^2}{u_1 + u_3 - 2u_2},\ \ r = -\tfrac{\ln q}{T}} \quad \blacksquare @@ multiply out; the u² terms on both sides cancel

So three counts at equal times fix K and r, and with them the whole curve. Try it on the United States census, sixty years apart: 3.929 million in 1790, 23.192 million in 1850, 92.228 million in 1910. The technique gives K ≈ 199 million and r ≈ 0.0313 a year. The curve through those three counts gives 149.5 million for 1950; the census found 151.3 million. It gives 191.9 million for 2020; the census found 331.4 million.

Nothing in the mathematics failed. Three counts always fix a logistic curve exactly, whatever the population is doing. The fit to 1950 is a fact about the curve. The claim that the curve is a law of growth is a separate claim, and the counts after 1950 refuted it. The seam standing question returns to this.

24j4Walking the rule a year at a time

Many animals and plants breed once a year, so a census is a list, one count a year, and the rule becomes a forward walk with h = 1: Pₙ₊₁ = Pₙ + rPₙ(1 − Pₙ/K). The smooth rule always settles at K from any start between. The walk need not.

Logistic-walk technique: forward steps of size h on P′ = rP(1 − P/K) pull starts near K in when 0 < hr < 2, and push them away when hr > 2. Written in x = hrP/((1 + hr)K), the walk is xₙ₊₁ = μ·xₙ(1 − xₙ), with μ = 1 + hr.

g(P) = P + hrP\big(1 - \tfrac{P}{K}\big),\ \ g(K) = K @@ one forward step (24i1); K is left alone
g'(P) = 1 + hr - \tfrac{2hrP}{K},\ \ g'(K) = 1 - hr @@ the slope of a polynomial (13)
|1 - hr| < 1 \iff 0 < hr < 2 @@ 22h4: below 1 in size pulls in, above 1 pushes away
P = cx,\ c = \tfrac{(1 + hr)K}{hr}:\ \ x_{n+1} = (1 + hr)x_n - \tfrac{hr\,c}{K}x_n^2 = (1 + hr)\,x_n(1 - x_n) @@ divide one step by c
\htmlClass{new}{x_{n+1} = \mu\,x_n(1 - x_n),\ \ \mu = 1 + hr} \quad \blacksquare @@ the lines above

With hr = 2.2 the walk is 22h4's rule sₙ₊₁ = 3.2sₙ(1 − sₙ), whose run splits into two threads. A population that breeds once a year and grows fast can swing between a high year and a low year forever, with nothing outside it changing. The smooth rule cannot do that: by 24j1 it climbs to K and stays below. 24k follows the yearly rule further.

24j.4.5seamIn 1920 two biologists fitted the logistic curve to the United States censuses from 1790 to 1910, found it fit closely, and called it a law of population growth. In 1940 a mathematician showed that curves from quite different rules fit the same records, and many records of other populations, just as closely.
This step showed that any three counts fix a logistic curve exactly. Was the close fit evidence for the law, or only for the curve? What would a law of growth have to do that a close fit to past counts cannot?

The basement · there if you want it

The accepted names

The logistic rule is the logistic (Verhulst) equation; K is the carrying capacity and r the intrinsic rate of increase. The solutions P = 0 and P = K are its equilibria. The substitution u = 1/P is the standard way to solve a Bernoulli equation. The three-counts formula is a method of fitting from three equally spaced points. The yearly walk, in x, is the logistic map, and the rule P′ = rP ln(K/P) of the build standing question is the Gompertz equation.

Who said it first

Pierre-François Verhulst proposed the rule in 1838 and named its curve the logistic in 1845. Raymond Pearl and Lowell Reed found it again in 1920, fitted it to the census and called it a law. William Feller showed in 1940 that other S-shaped curves fit the same data as well. Benjamin Gompertz proposed his rule in 1825, for human mortality. Robert May showed in 1976 how wild the yearly version can be.
