Pairs in Order

A set has no order: the set of Ann and Ben is the set of Ben and Ann. Yet the ladder will need things that come in an order constantly: a sender and a recipient, an input and an output, a left entry and a right entry. Can orderless tools make order? There is a trick that stuck, and it is built from gather alone. This step builds it, and proves the technique that makes it an order: if two such pairs are the same set, their left entries are the same and so are their right entries. Then it builds what the ladder makes out of pairs. Products are all the pairs you can make from here and from there. Relations are sets of pairs, and are all that “is a parent of” amounts to. Then come the properties a relation can have. Last come sameness relations with their classes: the device by which mathematics says “count these as the same” and manufactures new objects out of old ones.

To put one thing before another, write the first alone, and again beside the second. To say how things stand to one another, write the set of pairs that stand so. To treat things as the same, check that the sameness looks back, chains, and is so of each thing, then work with the classes.

2g1Order Out of Orderless Things

Ann texts Ben. The text has a sender and a receiver, and “Ann texts Ben” is not “Ben texts Ann”. A set cannot record that: {Ann, Ben} = {Ben, Ann} by the same-members axiom, since the same people are in each. So we want an object that says “Ann, then Ben”, and that differs from the object saying “Ben, then Ann”. Here is the trick that stuck: put the earlier thing in alone, and again beside the later one.

From here on, means: . Read it “the pair t then b”; t is its left entry and b its right entry.

(t, b) is called the ordered pair of t and b. The mark is a name, packed from two gatherings and a third around them.

2g2Round Brackets, Three Jobs

2g3The Pair Tells Ann From Ben

Watch the trick tell Ann from Ben.

Given: Ann ≠ Ben. They are two people. Unpack the pairs. (Ann, Ben) is {{Ann}, {Ann, Ben}}. (Ben, Ann) is {{Ben}, {Ben, Ann}}. {Ann} is listed in the first, so it is a member of (Ann, Ben).

Put {Ann} ∈ (Ben, Ann) in a row beside the givens. By the listing, {Ann} is {Ben} or {Ann} is {Ben, Ann}. Set in the cases. If {Ann} = {Ben}: Ann is in {Ann}, so by the swap axiom Ann is in {Ben}, so Ann = Ben, which clashes with the given. If {Ann} = {Ben, Ann}: Ben is in that set, so Ben is in {Ann}, so Ben = Ann, the same clash turned about. Both cases close, so the rows equal ⊥: {Ann} cannot stand as a member of (Ben, Ann).

So rows that hold (Ann, Ben) = (Ben, Ann) equal ⊥: the swap axiom would carry {Ann} from the first pair into the second, and that cannot stand. The pairs cannot be the same set. Writing that as (Ann, Ben) ≠ (Ben, Ann) is 3a’s output.

2g4Reading a Pair Back

Reading a pair back: the left entry is the thing in every member of the pair. The right entry is the other thing in the member that has two things in it: the one that is not the left entry. If no member has another thing in it, the right entry is the left entry again. For (Cal, Cal) the pair is {{Cal}, {Cal, Cal}} = {{Cal}, {Cal}} = {{Cal}}, by 1f's say-it-again technique inside the listings, and both entries are Cal. That looks odd and is harmless; the technique below covers it.

2g5Equal Pairs Have Equal Parts

Here is what makes the trick an order.

Equal-pairs technique: if two pairs are the same set, their left entries are the same and their right entries are the same.

In marks: if (t, b) = (c, d), then t = c and b = d. Nothing else about the definition matters. Any other definition with this property would serve.

The plan. {t} is in the right-hand set, and that gives t = c. With t written for c, {t, b} is in the right-hand set, and that gives b = d. Every case split comes from an or that was proved, and none from asking “is it or isn’t it”.

Rows hold (t, b) = (c, d). Unpack the pairs: {{t}, {t, b}} = {{c}, {c, d}}. {t} is listed on the left, so it is a member of the left set. By the swap axiom, it is a member of the right set too. By the listing, {t} = {c} or {t} = {c, d}.

By cases. If {t} = {c}: t is in {t}, so t is in {c}, so t = c. If {t} = {c, d}: c is in {c, d}, so c is in {t}, so c = t. Turned about, t = c. Either way, t = c.

2g6The Right Entries

Now the right entries. Since t = c, write t where c stood: {{t}, {t, b}} = {{t}, {t, d}}. {t, b} is listed on the left, so it is in the right. So {t, b} = {t} or {t, b} = {t, d}. By cases again.

First case: {t, b} = {t}. Then b is in {t}, so b = t. Now {t, d} is listed on the right, so it is in the left: {t, d} = {t} or {t, d} = {t, b}. In the first, {t, d} = {t} outright. In the second, {t, d} = {t, b} and {t, b} = {t}; chain: {t, d} = {t}. So d is in {t}, and d = t. Chain b = t with t = d: b = d.

Second case: {t, b} = {t, d}. Then b is in {t, d}, so b = t or b = d. If b = d, that is the line we want. If b = t, write t for b: {t, d} = {t, t}. By say-it-again, {t, t} = {t}. Chain: {t, d} = {t}. So d is in {t}, d = t, and chained, b = d. Either way, b = d.

So in every case b = d. Join it with t = c: the left entries are the same, and the right entries are the same.

2g7The Shape of the Argument

Read the shape of the argument. Every or came from “this set is a member of that listed set, so it is one of the things listed”. Every case closed with the same line, so reasoning by cases could close them. No line asked whether a pair's two entries are the same or not; that split would be 1f's either-way, which the ladder does not grant for arbitrary things. The technique is cited as equal-pairs from now on. Once you have it you may forget the braces and think of (t, b) as “t then b”, which is the whole point of the construction. Everything the ladder builds with order stands on this argument.

2g9Order Matters in a Product

Order matters. (cat, red) = (red, cat) cannot stand: the equal-pairs technique would give cat = red, and cat ≠ red.

So u × b and b × u cannot be the same set whenever both have a member and u ≠ b. If either is empty, both products are ∅, and then they are the same set.

Its accepted name: the Cartesian product.

2g10Products Exist

Does the product exist? The tools must make it, and here is how. Products-exist technique: for any sets u and b, there is the set u × b. Every pair (x, y) with x ∈ u and y ∈ b is already a member of a set we can build. The product is a sift from that set.

One example first. The pair (cat, red), from {cat, dog} and {red, blue}, is {{cat}, {cat, red}}. Both {cat} and {cat, red} are parts of {cat, dog, red, blue}.

Let x be any member of u and y any member of b: fresh names. By merge-membership, x and y are both in u ∪ b. So {x} and {x, y} are parts of u ∪ b, since each of their members is x or y. Pack 𝒫: {x} and {x, y} are both in 𝒫(u ∪ b).

So both members of the pair (x, y) are in 𝒫(u ∪ b), and the pair is a part of 𝒫(u ∪ b). Pack 𝒫 again: (x, y) is in 𝒫(𝒫(u ∪ b)). So every pair from u and b is already in one set we have.

Sift that set by the condition “is a pair with left entry in u and right entry in b”. The sift loses nothing, and it keeps exactly those pairs. That sift is u × b.

Union, all-the-subsets applied again, and sift: every product on the ladder stands on this sift, and you will never need to think about it again.

2g12Three Properties

Small letters for relations, since they are sets, which are things. The mark x r y is a statement with two gaps, packed from a membership. These properties come up constantly, each an every about the pairs, and each easy to see on a grid:

  • reflexive: ∀x (x ∈ u ⇒ x r x). Every thing stands in the relation to itself. “Has the same mother as” is reflexive; “is a parent of” is not.
  • symmetric: ∀x ∀y (x r y ⇒ y r x). If x r y is true, so is y r x. “Has met” is symmetric; “is a parent of” is not.
  • transitive: ∀x ∀y ∀z (x r y ∧ y r z ⇒ x r z). A step and a further step can be taken as a step. “Is an ancestor of” is transitive; “is a friend of” is not: your friend's friend may be a stranger to you.

2g13Which Relations Have Which

Sameness has every property on the list: the self-sameness axiom is reflexive, the turn-about technique symmetric, the chain technique transitive. “Lives in the same town as” has them all. “Is an ancestor of” is transitive and neither of the others. “Has met, or is the same person as” is reflexive and symmetric and not transitive: you have met Ann, and Ann has met Ben, and you may never have met Ben. The picture lets you build a relation on a household and test each property, and when a property fails it points at the pair that is missing.

2g16Classes Never Partly Overlap

Classes-never-overlap technique: two classes are either the same or share nothing at all. They never partly overlap.

The plan. Rows hold that two classes share a member. Show that the things naming them are equivalent. Then show each class is part of the other, and use double-inclusion.

Rows hold c ∈ [x] and c ∈ [y]. Unpack the classes: c ∼ x and c ∼ y. By symmetric, x ∼ c. By transitive, with c ∼ y: x ∼ y.

Now let z be any member of [x]: a fresh case. Unpack the class: z is in u, and z ∼ x. By transitive, with x ∼ y: z ∼ y. Pack the class: z is in [y]. Back at the margin: every member of [x] is in [y], so [x] ⊆ [y].

The same argument with x and y exchanged, using y ∼ x by symmetric, gives [y] ⊆ [x]. By double-inclusion, [x] = [y].

2g17Partitions

And every thing is in some class, its own, by reflexive: x ∼ x, so x ∈ [x]. Put these together and the classes chop u into pieces that do not overlap and together cover u. Such a chopping is called a partition of u.

The connection between a relation and a partition runs backwards too. Take any pieces that do not overlap and cover u. Then “lies in the same piece as” is reflexive, symmetric and transitive, and its classes are exactly the pieces. A sameness relation and a partition are descriptions of the same thing, as the slides show.

2g19Running It Backwards

Given a set that is a pair, find its entries. The left entry is in every member. If there is a member with another thing in it, that thing is the right entry; if not, the right entry is the left entry again. Given a sameness of pairs, you have a sameness of left entries and of right entries at once: that is the equal-pairs technique, cited, not reproved. Given a relation to test, hunt for a missing pair. Look for a thing without its self-pair, a pair without its turned-about pair, or a step and a further step without the shortcut. A missing pair kills the property, by the counterexample technique. Given classes, read the relation back as “in the same class as”. Given a relation, build the classes by sifting u by “∼ x” for each x. Then check with the classes-never-overlap technique that they do not partly overlap. Found upward; written downward.

Other ways the same marks are written

Mathematics writes some of these marks in more than one way, by subject and by century. Each one below means what the mark in this step means; know them on sight.

  • The pair (t, b) is also written ⟨t, b⟩, and u × b is called the Cartesian product.
  • For a relation r, the set of left entries of its pairs is called its domain, and the set of right entries its range.

Who said it first

The pair {{t}, {t, b}} is Kazimierz Kuratowski’s (1921), and its accepted name is the Kuratowski ordered pair.

Accepted names

A sameness relation is an equivalence relation, and its classes are equivalence classes.

The product u × b is the Cartesian product.
