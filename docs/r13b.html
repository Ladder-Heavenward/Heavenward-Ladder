13b · proof

A slope means no gap

The change in a function's output is its chord slope times the change of input. If the chord slopes head to a real, and the change of input heads to 0, their product heads to 0: the output lands where it was headed. So a function with a slope at an input is continuous there. This step proves it, one move per line. It turns it about, to show that a discontinuity means no slope. Then it shows it does not run backwards. A function can be continuous at an input and have no slope there. And a function can have a slope at one input and be continuous at no other.

Write the change in the output as the chord slope times the change in the input. The first heads to the slope, the second to 0. So the change in the output heads to 0, and the function is continuous there.

13b1The rise is the chord slope times the run

Stands on 13a (the slope at a point) and 10c (limits multiply).

For h ≠ 0, the chord slope is the rise over the run, so the rise is the chord slope times the run. That is all the proof needs: multiply and divide by the same real other than 0.

Slope-means-no-gap technique: if f has a slope at w, then f is continuous at w. In the accepted words: differentiable at w implies continuous at w.

\text{call } r:\ f \text{ defined on } (w - r, w + r) @@ the hypothesis of 13a's line for f′(w)
0 \lt |h| \lt r \;\Rightarrow\; f(w + h) - f(w) = \htmlClass{new}{\dfrac{f(w + h) - f(w)}{h}} \cdot h @@ multiply and divide by h: regroup for times on ℝ, reciprocal on ℝ, times-one on ℝ, licensed because h ≠ 0
\lim_{h \to 0} \dfrac{f(w + h) - f(w)}{h} = \htmlClass{keep}{f'(w)} @@ the hypothesis: f has a slope at w
\lim_{h \to 0} h = 0 @@ line-limit (10a): the linear function h ↦ h heads to its value at 0
\lim_{h \to 0} \big(f(w + h) - f(w)\big) = f'(w) \cdot 0 = \htmlClass{new}{0} @@ limits-multiply (10c), with agreeing-near: the change agrees with the product at every h ≠ 0. anything-times-zero read in ℝ
\lim_{h \to 0} f(w + h) = \htmlClass{keep}{f(w)} @@ limits-add (10c): add back the constant f(w), which heads to itself (line-limit)
\lim_{x \to w} f(x) = f(w) @@ two-ways-to-write-a-limit (13a)
f \text{ is continuous at } w \quad \blacksquare @@ 11a's line: w is an input, f is defined near w, and the limit is the value

The fifth line is worth a name of its own, because 13c and 13e each spend it in the middle of a proof.

Change-heads-to-0 technique: if f has a slope at w, then Δf = f(w + h) − f(w) heads to 0 as h → 0. It is slope-means-no-gap's fifth line.

Notice what made it work. The chord slopes head to a real, so they cannot run off. The run h is heading to 0. A product of something that stays put with something heading to 0 heads to 0. Notice also what was not used: nothing about any input but w, and nothing about which real the slope is. A slope of 0 or of a million does the same work here.

13b2A second road, with a recipe

Stands on 13b1, 10c (bounded-near) and 10d (squeezed-by-distance).

Slope-means-no-gap's column used the slope only through a limit technique. A second road uses it through a bound, and hands back a recipe for 11a's game.

Slope-bounds-change technique: if f has a slope at w, then there is a reach r₁ > 0 such that, with C = |f′(w)| + 1, every x with |x − w| < r₁ has |f(x) − f(w)| ≤ C|x − w|.

\text{call } r_1:\ 0 \lt |h| \lt r_1 \Rightarrow \Big|\dfrac{f(a + h) - f(a)}{h}\Big| \lt \htmlClass{new}{|f'(a)| + 1} @@ bounded-near (10c), for the chord slopes, which head to f′(a); r₁ no more than f's reach
|f(a + h) - f(a)| \le \big(|f'(a)| + 1\big)\,|h| @@ size-of-a-product (8h): the size of the change is the size of the chord slope times |h|; keep-order for times on ℚ read in ℝ. At h = 0 both sides are 0
|f(x) - f(a)| \le C\,|x - a| \text{ for } |x - a| \lt r_1 \quad \blacksquare @@ x = a + h, as in two-ways-to-write-a-limit: slope-bounds-change
\lim_{x \to a} f(x) = f(a) @@ squeezed-by-distance (10d): squeezed by the distance, with C. Then 11a's line: slope-means-no-gap by a second road

The squeeze carries its own recipe, as 10d said of squeezed-by-distance: δ = min(r₁, ε/C) wins 11a's game at w. For x² at 1, the chord slope is 2 + h, which is below 3 in size whenever |h| < 1. So r₁ = 1, C = 3, and δ = min(1, ε/3). That is 10a's recipe for x² at w, min(1, ε/(1 + 2|w|)), at w = 1, found again from the slope. A slope at w is more than continuity at w: near w, the change is at most a fixed multiple of the distance.

13b3Turned about: a discontinuity means no slope

Stands on 13b2 and 1d (turn and deny).

By 1d's turn-and-deny, slope-means-no-gap turned about says: if w is an input of f, f is defined near w, and f is not continuous at w, then f has no slope at w. That is the direction you use most. If a function has a discontinuity at an input, 11f's name, do not compute the chord slopes there. There is nothing for them to head to. But it is worth seeing what they do.

u \text{ at } 0,\ \ h \gt 0:\ \ \dfrac{u(h) - u(0)}{h} = \dfrac{1 - 1}{h} = 0 @@ 11a's step u: 0 for x < 0, 1 for x ≥ 0. From the right the chords are level
u \text{ at } 0,\ \ h \lt 0:\ \ \dfrac{u(h) - u(0)}{h} = \dfrac{0 - 1}{h} = \htmlClass{new}{-\dfrac{1}{h}} @@ from the left the rise is −1 for every h: it refuses to shrink
-\tfrac{1}{h} \text{ passes every bound as } h \to 0^- @@ 10f's line, with δ = 1/M for M > 0: at h = −0.1 it is 10, at h = −0.01 it is 100
\text{no limit from the left, so no slope at } 0 @@ passing-every-bound (10f), then two-sides-agree (10e). slope-means-no-gap turned about says it at once: u has a jump at 0
H_3 \text{ at } 1:\ \ \dfrac{H_3(1 + h) - 3}{h} = \dfrac{(2 + h) - 3}{h} = \htmlClass{new}{1 - \dfrac{1}{h}} @@ 11a's H₃: (x² − 1)/(x − 1) = x + 1 off 1, with the value 3 at 1. The rise heads to −1, not 0
1 - \tfrac1h \text{ passes below every bound as } h \to 0^+ @@ at h = 0.1 it is −9; at h = −0.1 it is 11. No slope: the stray value is a discontinuity
\lfloor x \rfloor \text{ at } 2,\ \ h \lt 0:\ \ \dfrac{1 - 2}{h} = -\dfrac{1}{h} @@ 11f's round-down: a jump of size 1 at 2, and the same escape from the left

In each case the rise refuses to shrink: it heads to something other than 0, or stays at −1. Divided by a run heading to 0, it runs off. A slope is a promise that the rise shrinks at least as fast as the run, and a discontinuity breaks that promise.

13b4Not backwards

Stands on 13b3, 11a7 (continuous-at-one-point) and 1d (affirming the consequent).

The converse of slope-means-no-gap would say: continuous at w, so a slope at w. That is 1d's illegal move, affirming the consequent, and it is refuted by one function. Rung 10 and rung 11 already built it.

Continuous-without-slope technique: x · q(x), with 9a's function q, is continuous at 0 and has no slope at 0.

x\, q(x) \text{ is continuous at } 0 @@ continuous-at-one-point (11a): |x q(x)| ≤ |x|, squeezed
\dfrac{h\, q(h) - 0 \cdot q(0)}{h} = \htmlClass{new}{q(h)} \quad (h \ne 0) @@ anything-times-zero; regroup for times on ℝ, reciprocal on ℝ: the chord slope at 0 is q itself
q \text{ heads nowhere at } 0 @@ heads-nowhere (10d): every window holds a fraction, where q is 1, and an irrational, where q is 0
x\, q(x) \text{ has no slope at } 0 \quad \blacksquare @@ agreeing-near: the chord slope agrees with q on a neighbourhood of 0, so it has no limit either

The function lands at 0, squeezed by |x|. But its chords from 0 have slope 1 when h is a fraction and slope 0 when h is irrational, and every window around 0 holds both kinds. The rise shrinks, but it does not shrink at a rate. 13f gives a second refutation with no wild function in it: |x| at 0, whose chords have slope 1 on one side and −1 on the other.

13b5A slope at one input says nothing about the others

Stands on 13b4 and 10d (squeeze).

Multiply by x once more, and the chord slopes are squeezed too.

Slope-at-0-only technique: x² · q(x) has slope 0 at 0.

\dfrac{h^2 q(h) - 0}{h} = \htmlClass{new}{h\, q(h)} \quad (h \ne 0) @@ anything-times-zero; the chord slope at 0
|h\, q(h)| \le |h| @@ size-of-a-product (8h), with |q(h)| ≤ 1, since q(h) is 0 or 1
\lim_{h \to 0} h\, q(h) = \htmlClass{keep}{0} @@ squeezed-to-0 (10d), with the trap |h|, which heads to 0
f'(0) = 0 \quad \blacksquare @@ 13a's line for the slope

Yet x² · q(x) is continuous at no input other than 0. At w ≠ 0, run 11a's continuous-at-one-point column with r² in place of r. Take ε = w²/8. In any window, of reach at most |w|/2, there is a fraction r, with |r| > |w|/2 and so r² > w²/4. There is also an irrational t, where the value is 0. Two outputs more than 2ε apart cannot both be within ε of the value at w (two-targets). So, by slope-means-no-gap turned about, x² · q(x) has a slope at 0 and at no other input. A slope at w is a fact about w, as continuity was. It does not spread to a neighbourhood.

13b7Running it backwards

Stands on 13b1 to 13b5.

Handed a function and an input, look first for a discontinuity: a bottom that is 0, a place where the formula changes with different heights arriving, a stray value. If there is a discontinuity at an input, there is no slope, and you are done (slope-means-no-gap turned about). If there is none, the question is open, and only the chord slopes can settle it. Handed a slope, you have continuity at that input for free, and nothing at any other. Found upward; written downward.

Who said it first

9a’s function q, 1 at the fractions and 0 elsewhere, is Dirichlet’s function. In question 13b.4.4 the proof of 1806 is André-Marie Ampère’s, the function of 1872 is Karl Weierstrass’s, and the one who turned away in fright is Charles Hermite, writing to Thomas Stieltjes.

Accepted names: slope-means-no-gap is “differentiable implies continuous”.
