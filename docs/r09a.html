9a · proof

A function is its pairs

4d built a function to do one job: defining by repeating. Here the same definition becomes the whole story. A function from one set to another is a set of pairs, each with its left entry in the first set and its right entry in the second. Each member of the first set is the left entry of exactly one of them. That sentence fixes which inputs a function has and which outputs it uses. It fixes when two functions are the same. And it says nothing at all about formulas. The step proves each of those. It ends with the diagonal argument: most functions have no formula that could ever be written down.

Each input appears in exactly one pair. The pairs fix the inputs and the outputs used; the same pairs make the same function, however the function was described.

9a14d’s definition, and what “exactly one” says

4d's line reads: f is a function from A to B when three things are true. f ⊆ A × B. Every member of A is paired by f with something (every input has an output). And nothing is paired with two things (no input has two). It is written f : A → B, with f(x) naming the one thing paired with x. Nothing in this step replaces those lines. What it adds is a mark for “exactly one”, so that the two parts can be said as one, and then the consequences.

From here on, ∃!x P(x) means ∃x P(x) ∧ ∀x ∀y (P(x) ∧ P(y) ⇒ x = y). Read it “there is exactly one x with P(x)”. The ! is part of the mark: it is not 4k's factorial n!. ∃!x ∈ a P(x) is short for ∃!x (x ∈ a ∧ P(x)), as 4b's shorthand. Like 2b's ∃, the mark ∃! makes a statement: it is packed shorthand for the some and the at-most-one written out above.

The first half is 2b's some; the second says any two things that pass are the same thing. So “exactly one” is a some joined to an at-most-one, and it is used by keeping either part. One-output technique: for f ⊆ A × B, these three say the same thing: (i) every input has an output and no input has two; (ii) ∀x ∈ A ∃!y ((x, y) ∈ f); (iii) each member of A is the left entry of exactly one member of f. (i) and (ii) are the same lines regrouped. ∃! unpacks into the some and the at-most-one, and 2b's techs pass an every through an and. The step from (ii) to (iii) is where pairs earn their keep:

a \in A;\ \ \text{call } b \text{ with } (a, b) \in f @@ (ii), keep the some; a member of f with left entry a
p, p' \in f \text{ with left entry } a @@ assume, to show at most one member
p = (a, c),\ \ p' = (a, c') @@ f ⊆ A × B: each member is a pair, ﹀ ×
c = c' @@ (ii), keep the at-most-one part
\htmlClass{new}{p = p'} @@ the swap axiom: (a, c) = (a, c′) from c = c′
\text{back: } (a, c), (a, c') \in f \Rightarrow (a, c) = (a, c') @@ (iii)'s at-most-one: two members with left entry a are one member
c = c' \quad \blacksquare @@ equal-pairs (2g): equal pairs, equal parts; that is (ii)'s at-most-one

The way back needed equal-pairs: two pairs with the same left entry that are the same pair have the same right entry. That is why 2g proved equal pairs have equal parts before anything else. Form (iii) is the one in this rung's title: each input appears in exactly one pair.

9a2Domain, codomain, range

A set of pairs carries its own entries inside it. The pair (x, y) is {{x}, {x, y}}, so x is in {x}, which is in the pair, which is in f. Two unions, ⋃⋃f, gather every entry of every member of f. That gives a set to sift the inputs and the outputs from.

From here on, for a set of pairs f, dom f names {x ∈ ⋃⋃f : ∃y ((x, y) ∈ f)} and ran f names {y ∈ ⋃⋃f : ∃x ((x, y) ∈ f)}. Read them “the domain of f” and “the range of f”. When f : A → B, A is the domain of f, and every member of A is an input. B is a codomain of f: a set the outputs are allowed to land in.

Pairs-fix-the-inputs technique: if f : A → B, then dom f = A, and ran f = {f(x) : x ∈ A} ⊆ B. The set {f(x) : x ∈ A} is 2h's shorthand, sifted from B.

x \in A \Rightarrow (x, f(x)) \in f @@ 4d's line for f(x)
x \in \{x\} \in (x, f(x)) \in f,\ \text{so } x \in \textstyle\bigcup\bigcup f @@ 2g's line for the pair; 2e's ⋃ twice, show an example each time
\htmlClass{new}{x \in \operatorname{dom} f} @@ ︿ the sift: ∃y, with f(x) as the example
x \in \operatorname{dom} f:\ \ \text{call } y,\ (x, y) \in f \subseteq A \times B @@ ﹀; use the some
(x, y) = (u, v),\ u \in A;\ \ \text{so } x = u \in A @@ ﹀ × (2g), then equal-pairs
\htmlClass{keep}{\operatorname{dom} f = A} \quad \blacksquare @@ an inclusion each way: double-inclusion (2c)

The range part is the same chase with the right entries. y ∈ ran f gives (x, y) ∈ f for some x. So x ∈ A by the domain part, and y = f(x) by 4d's line. And f(x) ∈ B is 4d's fact. So the domain of a function is a fact about its pairs, and so is its range. The codomain is not. Codomain technique: if f : A → B and B ⊆ B′, then f : A → B′; and f : A → ran f. The first: f ⊆ A × B ⊆ A × B′, and the two promises speak only of inputs. The second: f ⊆ A × ran f by pairs-fix-the-inputs, and the promises are unchanged. So a codomain is a choice, made when you write f : A → B, and the same set of pairs has many of them. The range is the least: every codomain contains it. 9c's word “onto” depends on that choice, and you will see why it is worth keeping.

9a3Same pairs, same function

A function is a statement that names a set, so by 2c's same-members axiom two functions are the same exactly when they have the same members. For functions that comes out as a test you can run. Equal-functions technique: for f : A → B and g : C → D, f = g exactly when A = C and f(x) = g(x) for every x ∈ A. 4d's same-outputs was the leftward half, for functions with the same A and B. Equal-functions needs no shared codomain, and goes both ways.

f = g \Rightarrow A = \operatorname{dom} f = \operatorname{dom} g = C @@ rightward: pairs-fix-the-inputs twice; the swap axiom at the middle
f = g \Rightarrow f(a) = g(a) @@ the swap axiom on the name “f(a)”; a was anything
A = C,\ \forall a\ f(a) = g(a);\ \ p \in f @@ leftward: assume; chase a member of f
p = (a, b),\ a \in A,\ b = f(a) @@ f ⊆ A × B; 4d's line for f(a)
b = g(a),\ \text{so } p = (a, g(a)) \in g @@ the hypothesis; a ∈ C by A = C; 4d's line for g
\htmlClass{new}{f = g} \quad \blacksquare @@ the same chase from g to f; then same-members (2c)

So a function is fixed by its inputs and its values, and by nothing else. How the values were found does not enter. That is the licence for every rewrite you will ever make to a formula: you are choosing another description of the same pairs. Take F, G : ℝ → ℝ with F(x) = x² and G(x) = (x + 1)² − 2x − 1. By 5i's square-of-a-sum read in ℝ, (x + 1)² = x² + 2x + 1, and collecting leaves x², at every real x. Same domain, same values: F = G, by equal-functions.

And the test cuts the other way. Let H : ℝ ∖ {1} → ℝ with H(x) = (x² − 1)/(x − 1), and J : ℝ → ℝ with J(x) = x + 1. Factoring the top by difference-of-squares gives (x − 1)(x + 1). Cancelling x − 1 is honest wherever x − 1 ≠ 0, so H(x) = J(x) at every input H has. But 1 ∈ dom J and 1 ∉ dom H. So by pairs-fix-the-inputs the domains differ, and H ≠ J: J has the pair (1, 2) and H has no pair with left entry 1. The cancellation was legal at every x but one, and that one is exactly the input H lacks. Likewise x ↦ x² on ℝ and x ↦ x² on [0, ∞) are two functions with one formula: different domains, different pairs. A formula is not a function until its inputs are named.

9a4No formula is required

For a century after 1748 “function” meant “formula”, as the survey told. The definition you are using says nothing of the kind, and here are four functions that show what that freedom buys.

First, any pairing at all. By 4k's counted-functions, a set with 3 members has 2³ = 8 functions to 2 = {0, 1}. One of them is {(cat, 1), (dog, 0), (owl, 1)}. There is nothing to compute: the function is the list. Second, a function on the reals defined by cases. Let q : ℝ → ℝ take x to 1 if x is rational (8a's word: x = r* for some fraction r), and to 0 if not. 7d's licence to define by cases on any statement makes this name honest, and rule-makes-a-function makes it a function. So q(7/5) = 1, and q(√2) = 0, since √2 is irrational (hole's-cut-is-√2 and hole-is-no-fraction's-cut). This function was given in 1829 as an example of what a function might be. Between any two reals there is a fraction (fraction-between), and an irrational too. (Take r + √2/n, for a fraction r between them and n large by everyday-counting-passes. It is irrational, or √2 would be a fraction.) So its values jump back and forth in every stretch of the line, however short. Third, a function nobody can evaluate. Let c : ℝ → 2 take every real to ⟦G⟧, 7b's mark of the even-sum guess G. By every-mark-is-a-bit, ⟦G⟧ is 0 or 1. So c is a function with exactly one output at each input, the same output everywhere, and no one alive can tell you what it is.

Fourth, and strongest: most functions have no formula at all. Let 𝒟 name the set of functions from ℕ to 2, sifted from 𝒫(ℕ × 2) by 4d's condition (6b's curly capitals: a collection of sets). Imagine a list of members of 𝒟, one for each number. It is a function F : ℕ → 𝒟, with F(n) the member listed at n. Diagonal technique: for every F : ℕ → 𝒟 there is a d ∈ 𝒟 with d ≠ F(n) for every number n.

d(n) = 1 \text{ if } F(n)(n) = 0,\ \ d(n) = 0 \text{ if not} @@ a definition by cases on a decidable statement: F(n)(n) ∈ 2, so “= 0” is decidable by settled-order (7d's licence would allow any statement; none is needed)
d \in \mathcal D @@ rule-makes-a-function: each d(n) is in 2
n \in \mathbb N;\ \ \text{assume } \htmlClass{new}{d = F(n)} @@ to refute: suppose d is the function listed at n
d(n) = F(n)(n) @@ the swap axiom, at the input n
F(n)(n) = 0:\ \ d(n) = 1 \ne 0 @@ the first case: next-never-empty gives 1 ≠ 0
F(n)(n) = 1:\ \ d(n) = 0 \ne 1 @@ the second case, by the listing of 2 = {0, 1}
\bot;\ \ \htmlClass{keep}{d \ne F(n)} \quad \blacksquare @@ clash in each case; refute; n was anything

d differs from the function listed at 0 at the input 0, from the one listed at 1 at the input 1, and so on down the diagonal of the table of values. No list indexed by the counting numbers holds every function from ℕ to 2. No case split on an undecided statement was used; the column is constructive. Now the moral, said in words. A formula is a statement written as a finite string of marks drawn from a finite stock, so formulas can be listed one per number. List the shortest first, and strings of the same length in the order of their marks, as 6d listed its descriptions. Put at n the function the n-th formula names, if it names a member of 𝒟, and the function with every value 0 otherwise. Diagonal hands you a d no formula names. The ladder makes “formula” exact only much later; the argument needs no more than “a finite string of marks”. Its accepted name is Cantor’s diagonal argument, for the diagonal of the table it reads.

Anexact, yet rigorous · connections, not families

A family name is an average. “Oak” covers every oak that ever grew, and no single oak is the average oak. The same wood is a tree, a plank and a fire: its family name stays put, and what it does changes. This step defines a function the second way, by what it does. A function is its pairs, what it does to each input, and not its formula or its name. 9a3's F and G are written differently and have the same pairs. They are one function.

Define a thing twice: by its family, and by what it does to whatever passes through it.

A claim about cases you have not seen needs both. The family says what to expect; the connections say where the expectation is met.

“Squaring” on ℕ and “squaring” on ℤ share a name and a formula. Are they the same function?

Anexact, yet rigorous · the universe, again

3c counted the cells of the universe: finite at every tick, and never done. Now count something else: what the cells are doing. Number the cells in the order they arrive, 0, 1, 2, and so on. Give each cell one of two states, 0 or 1, hot or cold. A whole history of the universe is then a function from ℕ to 2. It is a member of 𝒟.

The diagonal technique says no list holds every member of 𝒟. So no list holds every history. The cells can be counted, though they never stop; the ways they can turn out cannot be counted at all.

A triangle shows the same split. Cut it into three corner triangles and throw out the middle. Cut each corner the same way, and again, forever. At each stage the pieces are finite: 3, then 9, then 27. The stages can be counted. But a point of the finished figure is an endless list of choices: which corner, then which corner of that, and on. That is a function from ℕ to 3, and the diagonal runs on those just as well. The pieces at each stage are counted; the points are past counting.

The universe runs both ways at once. Its extent is finite and calculable at every tick, and it never stops. Its variety of states can be described, by the rule that makes each next one, and it can never be counted. That is why 1a's ledger keeps totals: stuff, push and order. Totals can be estimated. The arrangements outrun every count.

At every stage the triangle has finitely many pieces, and there are only as many stages as numbers. Where do the extra points come from?

9a6Running it backwards

Wanting to show a set of pairs is a function from A to B: check it is a part of A × B. Then for each input find an output. Then show any two outputs of one input are the same. Wanting to refute it: one input with no output, or one with two. Wanting f = g: compare domains (pairs-fix-the-inputs), then values at an arbitrary input (equal-functions). Wanting f ≠ g: one input in one domain and not the other, or one input with different values. Wanting a function with no formula: list some and run the diagonal. Found upward; written downward.

Who said it first

The textbook of 1748 is Euler’s. The function q, 1 on the rationals and 0 elsewhere, is Dirichlet’s, from 1829. The diagonal argument is Georg Cantor’s, from 1891. 6d’s listed descriptions follow Kurt Gödel.

Euler defined a function of a varying quantity as an expression put together in any way from that quantity and from numbers or fixed quantities. The definition served for a century and still describes what most people picture.

Euler, Introductio in analysin infinitorum (1748), vol. I, ch. 1, §4

Cantor showed that from any list of endless sequences of two letters one can write down a sequence that differs from the first at its first place, from the second at its second place, and so on, so that it appears nowhere in the list. He drew from it that some collections are too large to be counted off one by one.

Cantor, “Über eine elementare Frage der Mannigfaltigkeitslehre”, Jahresbericht der Deutschen Mathematiker-Vereinigung 1 (1891)

The triangle with its middles thrown out, forever, is Sierpiński’s triangle (Wacław Sierpiński, 1915). The cell size and tick are the Planck length and Planck time.

Spivak opens his chapter on functions by calling the idea the most important in mathematics, offers “a rule” as a first description, and shows functions no reasonable rule produces. By the chapter's end he replaces “rule” by the definition used here: a collection of pairs in which no two different pairs have the same first member.

Spivak, Calculus, ch. 3

Accepted names: the function q is the Dirichlet function; the diagonal technique is Cantor’s diagonal argument; the two-primes guess is Goldbach’s conjecture.
