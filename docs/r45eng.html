What Do Switches, Hubs and Routers Do?

The links of 45a are made of boxes that pass messages along. This annex says what three kinds of box do, and why each was needed, from rung 42’s graphs and 45c’s handshake.

A hub repeats to everyone, a switch learns where each address lives, and a router chooses a path between networks.

45eng1A Hub Repeats

A hub copies every signal it gets to every other port. All the machines on it share one wire, and two that send at once garble each other. Each must notice the clash and try again after a random wait, as 45c resends.

45eng2A Switch Learns

Learning-switch technique: a switch that writes down the port each sender’s address arrived on sends every later message for that address only out of that port.

Until it has seen an address, it sends that message to every port, as a hub would. Once it has, the message goes one way, and other ports are free for other talk at the same time.

Switches joined in a loop would pass a message to everyone round and round for ever. So they agree on a tree (42b) through the links and switch off the rest, since a tree has exactly one path between any two points.

45eng3A Router Finds Paths

A router joins networks, and picks for each message the next router on a shortest path, by the methods of 42k. Routers trade what they know of the map, so each learns the paths without a central list.

The layers then stack: the link moves bits between neighbours, the internet layer carries numbered messages from network to network with no promise of arrival, and the transport layer adds 45c’s handshakes and resends on top.

The accepted names

The link layer is usually Ethernet. The loop-breaking tree is built by the spanning tree protocol. The internet layer is IP, and the transport layer is TCP, together TCP/IP. Routers trade maps by link-state or distance-vector routing.
