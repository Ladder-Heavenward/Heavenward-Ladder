8i · technique

Roots, Powers and the Quadratic Formula

8f gave every positive real a root of every order. This step puts them to work. First the hands: moving radicals around legally and getting them out of a bottom. Then powers with integers below zero and fractions in the high place, defined so that the old exponent techniques keep working, and proved well defined. Then the one rewriting that opens every quadratic, run forward, backward and on letters until it becomes the formula that solves them all. With it comes the exact condition under which a quadratic has no answer on the line.

A root is a statement that names the one non-negative real whose power gives back what you started with: prove samenesses by checking powers. To open a quadratic, add the missing piece, the square of half the middle coefficient, so that the square term and the middle term become one square, less a constant.

8i1Radicals: Prove by Powers

A root is fixed by two facts: it is not negative, and its power gives back the original (8f's one-root and roots-of-every-order). So to prove two expressions with roots are the same, show both are not negative and have the same power. Here is the method on the commonest technique. Roots-go-through-products technique: for reals u, v ≥ 0, √u √v = √(uv).

a, b \ge 0 @@ the technique needs this; watch where it is used
(\sqrt a\,\sqrt b)^2 = (\sqrt a)^2(\sqrt b)^2 @@ power-of-a-product (read in ℝ, 8f)
= \htmlClass{new}{ab} @@ each root squared gives back what it is the root of
\sqrt a\,\sqrt b \ge 0 @@ a product of non-negatives (positive-product on ℝ, or a factor is 0)
\htmlClass{new}{\sqrt a\,\sqrt b = \sqrt{ab}} \quad \blacksquare @@ one-root: the one non-negative real whose square is ab

The same lines give √u/√v = √(u/v) for v > 0, and ⁿ√u ⁿ√v = ⁿ√(uv). And √(u²) = |u|, by 8h's size-squared: for u = −3 it is 3. Square roots never name a negative. x² = 9 has the two answers 3 and −3, but √9 is 3 only. For odd orders a negative has a root too:

From here on, for an odd number n and a real a < 0, ⁿ√a names −ⁿ√(−a). It is the only real x with xⁿ = a. Such an x must be negative, and −x is then the n-th root of −a (signs-come-out, powers-keep-order). So ³√(−8) = −2.

Tidying: pull square factors out, √12 = √4 √3 = 2√3. Then like radicals collect like like terms (5i): √50 + √18 = 5√2 + 3√2 = 8√2. To clear a root from a bottom, multiply by 1 in a useful form: 1/√2 = √2/2. For a sum or difference, multiply top and bottom by the same two terms with the sign between them changed. (The second is called the conjugate of the first.) Then 5i's difference-of-squares kills the root:

\dfrac{1}{\sqrt3 - 1} @@ a root in the bottom
= \dfrac{1}{\sqrt3 - 1}\cdot\htmlClass{new}{\dfrac{\sqrt3 + 1}{\sqrt3 + 1}} @@ multiply by 1 (times-one on ℝ); √3 + 1 is not 0
= \dfrac{\sqrt3 + 1}{(\sqrt3)^2 - 1^2} = \htmlClass{new}{\dfrac{\sqrt3 + 1}{2}} @@ difference-of-squares (5i); (√3)² = 3

8i2Powers Below Zero, and Fractions in the High Place

4g's high place held numbers. Extend it so that 4g's techniques keep working. If u^(−k) is to obey u^(−k) u^k = u⁰ = 1, it must be the reciprocal of u^k:

From here on, for a real u ≠ 0 and a number k, u^(−k) names (u^k)⁻¹. With k = 1 this is 5c's mark u⁻¹ (which 5c called one mark, not a power): now the two readings agree.

Whole-exponent techniques: for reals u, v ≠ 0 and integers m, n: u^m u^n = u^(m + n), (u^m)^n = u^(mn), (uv)^n = u^n v^n. Split on the signs of m and n. When both are numbers it is powers-add-their-counts, power-of-a-power and power-of-a-product. A negative exponent turns a power into a reciprocal, and 5h's reciprocal-of-a-product ((bk)⁻¹ = b⁻¹k⁻¹, read in ℝ) moves the reciprocal through the product. When the signs differ, cancel the common factors with reciprocal on ℝ. ∎ Now fractions. If u^(1/q) is to obey (u^(1/q))^q = u, it must be the q-th root.

From here on, for a positive real u and a rational x = p/q, with p an integer and q a positive integer, u^x names (q√u)^p. Read it “u to the power x”. With q = 1 it is the integer power above.

A rational is a class of pairs, so the name must not depend on the pair: 5·cb2's well defined. Fractional-powers-defined technique: if p/q = p′/q′, then (q√u)^p = (q′√u)^(p′).

pq' = p'q @@ cross-multiplying (5c): cross-multiplying
\big((\sqrt[q]a)^p\big)^{qq'} = \big((\sqrt[q]a)^q\big)^{pq'} = a^{pq'} @@ whole-exponent techniques: rearrange the exponents; (q√a)^q = a
\big((\sqrt[q']a)^{p'}\big)^{qq'} = a^{p'q} = a^{pq'} @@ the same, with q′; the first line
\text{both are positive} @@ a power of a positive real is positive (positive-product on ℝ, positive-reciprocal on ℚ)
\htmlClass{new}{(\sqrt[q]a)^p = (\sqrt[q']a)^{p'}} \quad \blacksquare @@ equal qq′-th powers of positives are the same (powers-keep-order backwards)

Fraction-exponent techniques: for positive reals u, v and rationals x, y: u^x u^y = u^(x + y), (u^x)^y = u^(xy), (uv)^x = u^x v^x. Each goes by the same method. Both sides are positive; raise both to a common bottom's power, and use the whole-exponent techniques. ∎ So the exponent techniques of 4g now work with any fraction in the high place, for a positive base. With the whole-exponent techniques, their accepted name is the laws of exponents. Worked, root first to keep the numbers small:

8^{2/3} = (\sqrt[3]{8})^2 = 2^2 = \htmlClass{new}{4} @@ the definition; 2³ = 8
27^{-2/3} = (\sqrt[3]{27})^{-2} = 3^{-2} = \htmlClass{new}{\tfrac19} @@ the definition with p = −2; then the reciprocal
a^{1/2}\,a^{1/3} = a^{1/2 + 1/3} = \htmlClass{new}{a^{5/6}} @@ fraction-exponent techniques: add the exponents, as fractions (5h)
\sqrt[3]{x^2} = x^{2/3},\ \ \tfrac{1}{\sqrt x} = x^{-1/2} @@ backwards, for x > 0: radicals into powers

Keep fractional powers for positive bases. Without that the techniques contradict each other. Suppose (−8)^(1/3) meant −2. Since 2/6 = 1/3, (−8)^(2/6) would have to be the same, yet ((−8)²)^(1/6) = 64^(1/6) = 2. Odd roots of negatives are written as roots, with the line above.

8i3Completing the Sameness

5i's square-of-a-sum says (x + h)² = x² + 2hx + h². So x² + bx is the start of the square of x + b/2, missing only the last piece (b/2)².

From here on, completing the sameness is the tech x² + bx = (x + b/2)² − (b/2)². Adding (b/2)² makes x² + bx + (b/2)² the square of x + b/2, by square-of-a-sum. Its accepted name is completing the square. The name is traditional, and here it means exactly x² + bx + (b/2)², the product (x + b/2)(x + b/2), and no shape.

In ninth-century Baghdad, the book whose title gave the word “algebra” solved “a square and ten of its roots make thirty-nine” by a recipe. Halve the number of roots, giving five. Multiply it by itself, twenty-five. Add it to thirty-nine, sixty-four. Take the root, eight. Take away the half, five. Three remains. The book justified it with a drawing, which needs the geometry of rung 18. The arithmetic alone is the tech above.

x^2 + 6x + 5 @@ the question: one square plus a constant
= (x^2 + 6x \htmlClass{new}{+ 9}) \htmlClass{new}{- 9} + 5 @@ half of 6 is 3, and 3² = 9: add it and take it away
= \htmlClass{new}{(x + 3)^2} - 4 @@ square-of-a-sum backwards
2x^2 + 12x + 7 = 2(x^2 + 6x) + 7 @@ with a leading number, factor it out of the x terms only
= 2\big[(x + 3)^2 - 9\big] + 7 = \htmlClass{new}{2(x + 3)^2 - 11} @@ complete inside; spread on ℝ: the −9 becomes −18

Now (x + 3)² − 4 says what x² + 6x + 5 hides. Since (x + 3)² ≥ 0 (square-never-negative), the sum is never below −4, and it is −4 exactly at x = −3. And x + 3 is the displacement x − (−3) (8h): the square measures how far x is from −3. In general the completed form t(x − h)² + k says that the value at x = h is k. For t > 0 no value is below k; for t < 0 none is above. Backward is just expanding: (x − 2)² + 3 = x² − 4x + 7. Doing both directions on one expression is the best check there is.

8i4The Quadratic Formula, One Move per Line

From here on, a formula also means a name written in marks with letters in it, such as b² − 4tc, which names a real once its letters name reals. 5·chem's formula, what is in one molecule, keeps its meaning. What the word is said of says which.

From here on, x = p ± q is short for x = p + q ∨ x = p − q. Read “±” as “plus or minus”. And for a quadratic tx² + bx + c with t ≠ 0, b² − 4tc is its discriminant.

Quadratic-formula technique: for reals t, b and c with t ≠ 0 and b² − 4tc ≥ 0, tx² + bx + c = 0 exactly when x = (−b ± √(b² − 4tc))/(2t). The lines below prove it, each move licensed both ways.

ax^2 + bx + c = 0,\quad a \ne 0 @@ the general quadratic equation
x^2 + \tfrac ba x + \tfrac ca = 0 @@ multiply by 1/a: licensed, a ≠ 0 (multiplying-keeps-answers)
x^2 + \tfrac ba x = -\tfrac ca @@ add −c/a (adding-keeps-answers)
x^2 + \tfrac ba x \htmlClass{new}{+ \tfrac{b^2}{4a^2}} = \tfrac{b^2}{4a^2} - \tfrac ca @@ half of b/a is b/(2a); add its square to both sides
\htmlClass{new}{\big(x + \tfrac{b}{2a}\big)^2} = \tfrac{b^2 - 4ac}{4a^2} @@ completed; one bottom 4a² on the right (fractions-of-rationals)
\big|x + \tfrac{b}{2a}\big| = \tfrac{\sqrt{b^2 - 4ac}}{|2a|} @@ roots of both sides, needing b² − 4ac ≥ 0: √(y²) = |y| (size-squared); √ of a quotient
x + \tfrac{b}{2a} = \htmlClass{new}{\pm}\tfrac{\sqrt{b^2 - 4ac}}{2a} @@ ﹀ the bars: two cases; the sign of 2d is swallowed by ±
x = \htmlClass{new}{\dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}} @@ add −b/(2a)

Every move is licensed both ways, except taking roots, which needs b² − 4tc ≥ 0. So if the discriminant is positive, there are two answers; if it is 0, one; if it is negative, none on the line. At 0 there is one, since ± adds and takes away 0. When it is negative there are none, because the left side of the completed line is a square, never negative (square-never-negative), and the right side is negative. Check every answer by two facts read off the formula. The two answers add to −b/t and multiply to c/t (5i's sum-and-product, run backwards). Example: x² − 2x − 1 = 0 gives x = (2 ± √8)/2 = 1 ± √2. Check: they add to 2, and multiply to 1 − 2 = −1, by difference-of-squares. And 3x² + 2x − 1 = 0 gives (−2 ± 4)/6: 1/3 and −1.

8i5Squaring Adds Strangers; Disguised Quadratics

To solve √(x + 3) = x − 3, square both sides. 5g's licence table said squaring gains answers. From p = q you get p² = q², but p² = q² gives only |p| = |q|. So check every answer in the original.

\sqrt{x + 3} = x - 3 @@ the question
x + 3 = x^2 - 6x + 9 @@ square both sides (gains answers: note to check); square-of-a-difference
x^2 - 7x + 6 = 0;\ \ (x - 1)(x - 6) = 0 @@ collect; factor (sum-and-product)
x = 1:\ \sqrt4 = 2 \ne -2 @@ check: a stranger. A root is never negative
\htmlClass{new}{x = 6}:\ \sqrt9 = 3 = 3 @@ check: it stands

Some equations are quadratics in costume. In x⁴ − 5x² + 4 = 0, x² appears twice, once squared. Name the inside r: r = x², so r² − 5r + 4 = 0, (r − 1)(r − 4) = 0, r = 1 or 4. Substitute for the expression: x² = 1 or x² = 4. So x = ±1 or x = ±2. Fractional powers undo by the reciprocal power. x^(3/2) = 8, for x > 0, gives x = 8^(2/3) = 4, by the fraction-exponent techniques. Check: 4^(3/2) = (√4)³ = 8.

8i7Running It Backwards

Handed two answers r and s, the quadratic x² − (r + s)x + rs = 0 has them (sum-and-product). Handed a completed form, expand it; handed a sum, complete it. Wanting a root out of a bottom, multiply by the conjugate. Wanting it into the bottom, do the same to the top. Wanting u^x for a fraction x, take the root first, then the power. Found upward; written downward.
