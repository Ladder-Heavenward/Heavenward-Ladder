8g · technique

Inequalities

An equation pins a number down; an inequality fences off a stretch of the line. You solve both by changing both sides, but the licences for “less than” are not the licences for “the same as”. Some carry over unchanged, one turns the order about, and a few that feel natural are simply wrong. In this step every rule is derived from the line's order, read as “the difference is positive”, so that you know why each is true and can rebuild any you forget. Then the hands get fast: linear inequalities, products charted sign by sign in tables, fractions with the unknown in the bottom, and proofs that an inequality is so for every allowed number.

“One number is less than another” means “the second less the first is positive”. Every move across “less than” is a fact about what keeps a positive number positive.

8g1One definition, three techniques

On the line, α < β was defined as α ⊆ β with α ≠ β. 8d's order-and-arithmetic-agree showed it is the same as “β − α is positive”, the reading 5d gave for fractions. That reading is the one for hands. Three techniques carry everything. Three-way on ℝ: every real is 0, positive, or the negative of a positive, exactly one. Positive-sum on ℝ: positive plus positive is positive. Positive-product on ℝ: positive times positive is positive. Unpack < into “something is positive”, use positive-sum on ℝ or positive-product on ℝ, then pack it back. Learn that rhythm and you need memorise nothing.

From here on, unknowns range over ℝ unless a step says otherwise. The solution set of a condition φ on x is {x ∈ ℝ : φ(x)}, and 5g's words (unknown, answer, solve, licensed) are read with ℝ in place of ℚ. Adding-keeps-answers and multiplying-keeps-answers are techniques in ℝ too, by the same columns.

8g2The rules, each derived

Adding the same real keeps the order (keep-order for plus on ℚ, read in ℝ): (q + s) − (p + s) = q − p, the same positive difference. So you may add or subtract anything on both sides of an inequality, as with an equation. Multiplying by a positive keeps it (keep-order for times on ℚ, read in ℝ): qs − ps = (q − p)s, positive times positive. Chaining (at-most-is-a-partial-order on ℝ): p < q and q < s give p < s, since s − p = (s − q) + (q − p). Same-direction-add technique: p < q ∧ s < t ⇒ p + s < q + t, since (q + t) − (p + s) = (q − p) + (t − s), by positive-sum on ℝ. The one people misremember gets a column of its own. Negative-reverses-order technique: p < q ∧ s < 0 ⇒ qs < ps.

a \lt b,\ \ c \lt 0 @@ given
b - a \text{ positive},\ \ -c \text{ positive} @@ unpack both: c < 0 means 0 − c = −c is positive (order-and-arithmetic-agree)
(b - a)(-c) \text{ positive} @@ positive-product on ℝ
(b - a)(-c) = -bc + ac = \htmlClass{new}{ac - bc} @@ spread on ℝ; signs-come-out (8d); turn-about for plus on ℝ
\htmlClass{new}{bc \lt ac} \quad \blacksquare @@ pack back: ac − bc is positive

Two more follow at once. Reciprocals of positives turn the order about: 0 < p < q ⇒ 1/q < 1/p (positive-reciprocal on ℚ, read in ℝ: multiply by the positive 1/(pq)). Squares of non-negatives keep it: 0 ≤ p < q ⇒ p² < q² (powers-keep-order). And one about products of many factors, which drives every chart below. Sign-of-a-product technique: a product of reals none of which is 0 is positive exactly when an even number of them are negative. By induction on the number of factors. A positive factor leaves the sign alone (positive-product on ℝ). A negative one changes it (signs-come-out, negative-of-a-negative). And each is one or the other (three-way on ℝ). ∎

8g3Answers as stretches of the line

The solution set of an inequality is a sift of ℝ. Writing {x ∈ ℝ : −2 < x < 3} every time is slow, so:

From here on, for reals c < d: (c, d) names {x ∈ ℝ : c < x < d}; [c, d] names {x ∈ ℝ : c ≤ x ≤ d}. [c, d) and (c, d] keep the end with the square bracket and drop the one with the round bracket. (c, ∞) names {x ∈ ℝ : c < x}, [c, ∞) names {x : c ≤ x}, (−∞, d) names {x : x < d}, (−∞, d] names {x : x ≤ d}, and (−∞, ∞) is ℝ. Each is called an interval. The mark ∞, read “infinity”, is not a number. It only says “no end on this side”, so it always takes a round bracket.

The round-bracket interval (c, d) is written like 2g's pair (c, d). What surrounds it says which is meant. A pair is a thing, an interval is a set of reals, and on this ladder an interval is always introduced as one. Pieces are joined by ∪, 2e's union of two sets.

Likewise [c, d] is written like 5b's class [m, n] of a pair of numbers. Between reals it is this interval, and 5b's class keeps its meaning between numbers. The word interval is new to sets of reals: 6·phys's interval between two notes, a ratio, keeps its meaning. And “square bracket” and “round bracket” are only the names of the marks [ ] and ( ). No shape is meant, and 5f's square, a product, keeps its one meaning.

8g4Linear inequalities

Solve as an equation, and turn the order about whenever you multiply by a negative.

5 - 3x \lt 11 @@ the question
-3x \lt 6 @@ add −5 to both sides: order kept (keep-order for plus on ℚ)
\htmlClass{new}{x \gt -2} @@ multiply by −⅓, a negative: turned about (negative-reverses-order)
x \in (-2, \infty) @@ as an interval

Check with a number on each side: x = 0 gives 5 < 11, true; x = −3 gives 14 < 11, false. Ten seconds, and it catches every forgotten turn. Run it backwards. Suppose you want an inequality whose answer is x > −2 and that needs a turn. Start from the answer, multiply by a negative and turn (x > −2 gives −4x < 8), then add anything (1 − 4x < 9). A double inequality is two at once, and the same move goes to all three parts:

-1 \le 2x + 3 \lt 7 @@ two inequalities sharing a middle
-4 \le 2x \lt 4 @@ add −3 to all three parts
\htmlClass{new}{-2 \le x \lt 2} @@ multiply all three by ½, a positive: kept
x \in [-2, 2) @@ square bracket where ≤, round where <

8g5Sign charts, as tables

For anything with x in more than one place, ask a sign question instead. Put everything on one side, factor (5i), and use sign-of-a-product: the product's sign is fixed by how many factors are negative. Each factor x − r, 5i's displacement pattern without its square, is negative before r and positive after it (add −r to both sides of x < r). So mark where each factor is 0. Between those places every factor keeps its sign, so read the product's sign in each stretch by counting negatives. Lay it out as a table, a column per stretch.

x^2 - x - 6 \lt 0 @@ the question: 0 on one side
(x - 3)(x + 2) \lt 0 @@ factor (5i's sum-and-product): −3 and 2 multiply to −6, add to −1
x < −2x = −2−2 < x < 3x = 3x > 3
x + 2−0+++
x − 3−−−0+
product+0−0+

The answer is the stretch where the product is negative: (−2, 3). The places where it is 0 are left out, because 0 < 0 fails. Three refinements. First, a squared factor such as (x − 1)² never changes sign: it is positive on both sides of 1 and 0 at 1 (square-never-negative). So (x − 1)²(x + 3) > 0 is so for x > −3 except at 1: (−3, 1) ∪ (1, ∞). Second, a factor in a bottom counts for sign exactly like one on top, since 1/y has the sign of y (positive-reciprocal on ℚ). But where it is 0 the expression names nothing, so that place is never in the answer. Third, with single factors only, the sign changes at every zero, so once one stretch is known the rest alternate. x³ − 4x ≥ 0 is x(x − 2)(x + 2) ≥ 0, with signs −, +, −, + across the four stretches from the left, and the answer is [−2, 0] ∪ [2, ∞).

A quadratic that will not factor is often positive everywhere. x² − 2x + 3 has no whole numbers multiplying to 3 and adding to −2 (5i's whole-answers). But square-of-a-difference read backwards gives x² − 2x + 3 = (x − 1)² + 2. That is at least 2, since (x − 1)² ≥ 0 by square-never-negative. So x² − 2x + 3 < 0 has the empty solution set, and x² − 2x + 3 > 0 has all of ℝ.

8g6The unknown on the bottom: the classic trap

Solve (x − 1)/(x + 2) ≥ 0. The tempting move multiplies both sides by x + 2 and gets x − 1 ≥ 0, so x ≥ 1. That loses half the answer. It multiplies by a real whose sign is unknown, and for x < −2 it is negative, so the order should have turned. Try x = −3: (−4)/(−1) = 4 ≥ 0, true, yet −3 ≥ 1 is false. The chart does it right:

x < −2x = −2−2 < x < 1x = 1x > 1
x − 1 (top)−−−0+
x + 2 (bottom)−0+++
fraction+none−0+

Answer: (−∞, −2) ∪ [1, ∞). It is round at −2, where the bottom is 0 and the fraction names nothing. It is square at 1, where the fraction is 0 and ≥ lets 0 in. A second honest road multiplies both sides by (x + 2)². That is positive whenever x ≠ −2, so the order is kept: (x − 1)(x + 2) ≥ 0 with x ≠ −2.

8g7Proving an inequality, not solving one

Sometimes the job is to show an inequality is so for every allowed x. The most useful single technique for this is square-never-negative: a square is never negative. Take “for every x > 0, x + 1/x ≥ 2”. Multiplying by x is legal here, because x is given positive, and it can be undone by multiplying by 1/x.

x + \tfrac1x \ge 2 @@ what we want, for x > 0
\Leftrightarrow\ x^2 + 1 \ge 2x @@ multiply by x, positive: kept, and undone by 1/x (keep-order for times on ℚ each way)
\Leftrightarrow\ x^2 - 2x + 1 \ge 0 @@ add −2x
\Leftrightarrow\ \htmlClass{new}{(x - 1)^2 \ge 0} @@ square-of-a-difference backwards: true for every x (square-never-negative)

Read it upward for the proof: start from (x − 1)² ≥ 0, certainly true, and run each line backwards. Every arrow goes both ways, which is what makes the column honest. The two sides are equal only at x = 1. The same trick gives p² + q² ≥ 2pq for all reals, from (p − q)² ≥ 0. With 8f's roots it gives (p + q)/2 ≥ √(pq) for all p, q ≥ 0, from (√p − √q)² ≥ 0, with equality only when p = q. The middle of two non-negative numbers is never below the root of their product. The accepted name for (p + q)/2, the middle of p and q, is their arithmetic mean.

8g8Illegal moves

x^2 \lt 3x,\ \text{so } x \lt 3\,? @@ divided by x, sign unknown: (−∞, 3) wrongly holds −1, where 1 < −3 fails. Honest: x(x − 3) < 0, so (0, 3)
-3 \lt 2,\ \text{so } 9 \lt 4\,? @@ squaring keeps order only from 0 up (powers-keep-order)
x^2 \gt 4,\ \text{so } x \gt 2\,? @@ loses x = −5. (x − 2)(x + 2) > 0: x < −2 or x > 2

8g9Running it backwards

Handed a solution set, build an inequality with it. An interval (c, d) is (x − c)(x − d) < 0. Its outside is the same product > 0. A single excluded place r comes from a squared factor (x − r)² > 0. Wanting a turn in the solution, put a negative coefficient on x. Wanting to prove an inequality for every x, move everything to one side and look for a square. Found upward; written downward.
