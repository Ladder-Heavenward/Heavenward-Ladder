Points on a Cubic Over a Clock

The chord technique uses only adding, multiplying and undoing, so it works on a prime clock as well as on fractions. There the curve has finitely many points, and counting them is a question about squares: for each x, the curve has two points if x³ + ax + b is a nonzero square, one if it is 0, none otherwise (43f). The count is always near p + 1, within 2√p. This step counts the points of a curve on the clock of 17, bounds the count, and finds a curve whose points are a group of prime size.

N = 1 + Σₓ (1 + (f(x) ∕ p)), with f(x) = x³ + ax + b and the far point counted once. Half the values are squares (43f1), so N is near p + 1; the bound is |N − (p + 1)| ≤ 2√p. On the clock of 17, y² = x³ + 2x + 2 has 19 points, a prime, so every point but O reaches all of them.

43m1Counting by Squares

\text{nonzero squares on 17: } 1, 2, 4, 8, 9, 13, 15, 16 @@ eight of sixteen (43f1)
x = 0:\ f = 2,\ \text{a square: } (0, 6), (0, 11) @@ two points
\text{nine } x \text{ give squares, eight do not, none give } 0 @@ check each of 0 to 16
\htmlClass{new}{N = 1 + 2\cdot 9 = 19} @@ with the far point

Point-count technique: on the clock of p, the number of points of y² = f(x), with the far point, is p + 1 + Σₓ (f(x) ∕ p); each nonzero square gives two points, 0 gives one.

43m2Near p + 1

\textstyle\sum_x (f(x) \,/\, p) \text{ adds } p \text{ signs } \pm 1 \text{ or } 0 @@ half the units are squares
\text{if the signs were coin tosses: about } \sqrt p @@ root-n (30n1)
|N - (p + 1)| \le 2\sqrt p @@ proved, not a guess
\htmlClass{new}{p = 17:\ 19 - 18 = 1 \le 2\sqrt{17} \approx 8.2} @@ well inside

Near-count technique: a curve y² = x³ + ax + b with no repeated zero on the clock of p has between p + 1 − 2√p and p + 1 + 2√p points. The signs behave like coin tosses, and the bound is exactly root-n with a factor 2.

43m3A Group of Prime Size

\text{the chord technique on the clock: a group of 19 points} @@ as on fractions (43l2)
19 \text{ is prime: every part-group has size } 1 \text{ or } 19 @@ a part’s size divides the whole’s (19d)
P = (5, 1):\ P, 2P, \ldots, 19P = O \text{ reach every point} @@ any point but O
\htmlClass{new}{\text{from } kP \text{, finding } k \text{ is believed slow for big } p} @@ the secret of 44·crypt

The points of a cubic over a prime clock form a group of size near p; when that size is prime, every point but O reaches all the others by adding itself. Counting points on such curves, prime by prime, is how the open question of 43l is tested.

Accepted names

The bound is Hasse’s theorem; the sum of signs uses the Legendre symbol; the group is E(𝔽_p). Every count in the range occurs, by Deuring’s theorem. Finding k from kP is the elliptic curve discrete logarithm problem.

Who said it first

Emil Artin guessed the bound in his thesis of 1924; Helmut Hasse proved it in 1933; Max Deuring settled which counts occur in 1941.
