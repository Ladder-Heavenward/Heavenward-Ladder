25d · proof

Every Polynomial Has a Root

On the line, some polynomials have no root at all. Adding one number whose square is minus one gave every quadratic its roots. This step proves far more: every polynomial, of any degree, with any complex numbers in front, has a root among the new numbers. Nothing more needs to be added, ever. The proof finds the input where the polynomial is smallest in size, and shows that a smallest size which is not zero can always be pushed lower. So the smallest size is zero, and there is the root.

Every polynomial that is not constant has a root in the new numbers. So it splits into one line factor for each power, and has exactly as many roots as its degree, counted with repeats.

25d1Far Out, the Top Term Wins

From here on in this step, p(z) = u₀ + u₁z + ⋯ + uₙzⁿ with n ≥ 1 and uₙ ≠ 0, and the uₖ are any complex numbers.

Far-out technique: if |z| ≥ R, with R = max(1, 2(|u₀| + ⋯ + |uₙ₋₁|)/|uₙ|), then |p(z)| ≥ |uₙ||z|ⁿ/2. Far from 0, the polynomial is as large as its top term, halved.

|p(z)| \ge |u_n z^n| - |u_0 + \cdots + u_{n-1}z^{n-1}| @@ the second half of the plane triangle (25c2)
|u_0 + \cdots + u_{n-1}z^{n-1}| \le (|u_0| + \cdots + |u_{n-1}|)\,|z|^{n-1} @@ the triangle; |z|ᵏ ≤ |z|ⁿ⁻¹ when |z| ≥ 1
\le \tfrac12 |u_n|\,|z|\,|z|^{n-1} = \tfrac12|u_n||z|^n @@ |z| ≥ R ≥ 2(|u₀| + ⋯ + |uₙ₋₁|)/|uₙ|
\htmlClass{new}{|p(z)| \ge \tfrac12|u_n||z|^n \text{ for } |z| \ge R} \quad \blacksquare @@ the first line, less the bound

So the size of p(z) heads past every ceiling as z moves away from 0, in every direction. The smallest sizes, if there is a smallest, live inside some disc.

25d2A Lowest Size on a Disc

Lowest-size technique: some z₀ in ℂ has |p(z₀)| ≤ |p(z)| for every z in ℂ. Rung 12 found lowest values on a closed interval of the line. The same argument works on a closed disc, one part at a time.

\rho = \max\!\big(R,\ (2|u_0|/|u_n|)^{1/n}\big),\ \ D = \{z : |z| \le \rho\} @@ a disc big enough for 25d1
|z| > \rho \Rightarrow |p(z)| \ge \tfrac12|u_n|\rho^n \ge |u_0| = |p(0)| @@ 25d1; the choice of ρ
m = \inf\{|p(z)| : z \in D\} @@ a set of reals ≥ 0 has a greatest lower bound (no holes, 8)
z_k \in D \text{ with } |p(z_k)| < m + \tfrac1k @@ m + 1/k is not a lower bound
z_{k_j} \to z_0,\ |z_0| \le \rho @@ floor parts, then upright parts, have settling threads (22b); |z| ≤ ρ is kept in the limit
|p(z_{k_j}) - p(z_0)| \le C|z_{k_j} - z_0| \to 0,\ \text{so } |p(z_0)| = m @@ the value fence (25c3); both bounds squeeze to m
\htmlClass{new}{|p(z_0)| \le |p(z)| \text{ for every } z \in \mathbb{C}} \quad \blacksquare @@ inside D by the choice of m; outside, by line 2, since 0 is in D

The proof did not say where z₀ is. It only showed that the least size is reached somewhere. That is enough for the next footing.

25d3Not Lowest, Unless Zero

Push-down technique: if p(z₀) ≠ 0, some z has |p(z)| < |p(z₀)|. Near z₀, the polynomial is p(z₀) plus a first term that can be pointed straight back at 0.

p(z_0 + h) = p(z_0)\,(1 + c\,h^k + h^{k+1}q(h)),\ c \ne 0,\ k \ge 1 @@ share out the powers of z₀ + h; divide by p(z₀); c is the first coefficient that is not 0
-\tfrac{|c|}{c} = \cos\theta + i\sin\theta,\ \ u = \cos\tfrac{\theta}{k} + i\sin\tfrac{\theta}{k} @@ a number of size 1 has a turn (21·cb20.1)
u^k = -\tfrac{|c|}{c},\ \ c\,(tu)^k = -|c|\,t^k \text{ for } t > 0 @@ multiply and add: kth power of the turn (21·cb20.2)
|1 + c(tu)^k + (tu)^{k+1}q(tu)| \le 1 - |c|t^k + t^{k+1}Q @@ the triangle (25c2); |q| ≤ Q on |h| ≤ 1 (25c3); 0 < t ≤ 1, |c|tᵏ < 1
< 1 \ \text{ when } t < |c|/Q @@ t^{k+1}Q < |c|tᵏ
\htmlClass{new}{|p(z_0 + tu)| < |p(z_0)|} \quad \blacksquare @@ sizes multiply (25c1)

The key line is the third. Because every number has kth roots in ℂ, you can choose the direction u so that the first change, c(tu)ᵏ, points exactly against 1. On the line that fails: for x² + 1 at 0 the first change is +t² and no real direction makes it negative. That is why the line has polynomials with no root.

25d4Every Polynomial Has a Root

Root technique: every polynomial of degree n ≥ 1 with complex numbers in front has a root in ℂ; and p(z) = uₙ(z − r₁)(z − r₂)⋯(z − rₙ) for some r₁, …, rₙ in ℂ. So it has n roots, counted with repeats, and no others.

|p(z_0)| \le |p(z)| \text{ for all } z @@ the lowest-size technique (25d2)
p(z_0) \ne 0 \Rightarrow \text{some } |p(z)| < |p(z_0)| @@ the push-down technique (25d3)
p(z_0) = 0 @@ the two lines above cannot both hold otherwise
p(z) = p(z) - p(z_0) = \textstyle\sum u_k(z^k - z_0^k) = (z - z_0)\,p_1(z) @@ each zᵏ − z₀ᵏ has the factor z − z₀ (25c3)
p_1 \text{ has degree } n-1 \text{ and top coefficient } u_n @@ the top term of uₙ(zⁿ − z₀ⁿ)
\htmlClass{new}{p(z) = u_n(z-r_1)\cdots(z-r_n)} \quad \blacksquare @@ repeat on p₁, n times in all
p(w) = 0 \Rightarrow w = r_j \text{ for some } j @@ a product of numbers is 0 only if one is (5e, in the field ℂ)

So ℂ is the end of the road for roots. The line needed i for x² + 1. Once i is in, every polynomial, even one with i itself in front, already has all its roots. No further numbers are needed for any polynomial at all.

25d.4.5seamA writer of 1746 proved this step’s claim by pushing down, much as 25d3 does, and took it for granted that a least size is reached. Others assumed that a polynomial of degree n has n roots of some kind, and proved only that those roots are of the form a + bi. A young mathematician, in his thesis of 1799, objected to both: one had left a hole, and the other calculated with roots before knowing they exist. His own first proof, drawn with curves, had a hole of its own, filled only in 1920.
Which objection is fair?
This step’s proof shows that a root exists, and never finds where. Is a proof that cannot find the root as good as one that can?

The accepted names

The root technique is the fundamental theorem of algebra; a field in which every polynomial has a root is algebraically closed. The push-down technique is d’Alembert’s lemma (or Argand’s inequality). The lowest-size technique is the extreme value theorem on a closed disc, a compact set.

Who said it first

Albert Girard claimed in 1629 that a polynomial of degree n has n roots. Jean le Rond d’Alembert gave a flawed proof in 1746. Carl Friedrich Gauss criticized the earlier attempts in his 1799 thesis and gave four proofs in his life, the first with a gap of its own. Jean-Robert Argand published the proof by least size in 1806 and 1814; Augustin-Louis Cauchy made it rigorous in 1821.

In 25d.4.5, the writer of 1746 is d’Alembert, the others include Euler (1749) and Lagrange (1772), and the young mathematician is Gauss. The hole in Gauss’s first proof, about how a curve crosses a circle, was filled by Alexander Ostrowski in 1920. Proofs that find the root step by step, and the question whether that matters, come much higher up the ladder.
