A Falling Run Proves Arithmetic Safe

Arithmetic cannot prove itself clash-free (38l). It can be proved clash-free from outside, by something it cannot reach: a falling run of points up to ε₀ (35g). Give each proof of a clash in arithmetic a point below ε₀. Show how to turn it into another proof of a clash with a smaller point. Since a run of points cannot fall for ever (29·cb3), there was no proof of a clash. This step labels proofs with points, lowers the label, and finds where the outside strength lies.

Cut-free fails in arithmetic, because induction is a hidden cut. Gentzen gave each proof a point below ε₀ and a rewrite that lowers it while keeping a clash at the foot. So a proof of a clash gives an endless falling run: impossible. Arithmetic proves the falling run for each point below ε₀, but not for all of them at once.

38r1Induction Is a Hidden Cut

\dfrac{F(a), G \Rightarrow D, F(a + 1)}{F(0), G \Rightarrow D, F(t)} @@ the induction move
\text{its marks } F \text{ need not be parts of the foot} @@ like a cut
\text{cuts on these marks cannot all be pushed out} @@ cut-free fails (38q)
\htmlClass{new}{\text{cuts can still be lowered, at the price of a bigger label}} @@ the label is a point, not a number

In arithmetic induction behaves like a cut that cannot be removed, so cut-free proofs are not available; what can be done is to trade cuts for a lower point.

38r2Labels Below ε₀

\text{each line gets a point below } \varepsilon_0 @@ built from the labels above it in base ω (35g3)
\text{a cut stacks labels as } \omega^{\alpha} @@ cuts cost a power of ω
\text{a rewrite of a proof of } \Rightarrow \text{ gives a proof of } \Rightarrow \text{ with a smaller label} @@ Gentzen’s reduction
\htmlClass{new}{\text{a proof of a clash would start an endless falling run of points}} @@ impossible (29·cb3)

Falling-label technique: if every run of points below ε₀ falling at each step must stop, then arithmetic is clash-free; the proof uses only finite rewriting of finite proofs, plus that one fact about points.

38r3Where the Strength Lies

\text{for each } \alpha < \varepsilon_0:\ \text{arithmetic proves runs below } \alpha \text{ stop} @@ by induction, nested
\text{runs below } \varepsilon_0 \text{ stop: not provable in arithmetic} @@ else it proves itself clash-free (38l)
\text{the base-bump game ends: true, by the labels of 29·cb3} @@ its labels fall below ε₀
\htmlClass{new}{\text{the base-bump game ends: not provable in arithmetic}} @@ a statement about numbers alone

Arithmetic is clash-free if falling runs below ε₀ stop; arithmetic proves this for every smaller point but not for ε₀ itself, and so cannot prove that the base-bump game always ends. ε₀ measures exactly how strong arithmetic is.

The cellar · there if you want it

Accepted names

This is Gentzen’s consistency proof for Peano arithmetic (PA), by transfinite induction up to ε₀; ε₀ is the proof-theoretic ordinal of PA. The base-bump game is the Goodstein sequence; its unprovability is the Kirby-Paris theorem.

Who said it first

Gerhard Gentzen proved arithmetic clash-free in 1936 and showed in 1943 that arithmetic cannot prove induction up to ε₀. Reuben Goodstein’s game is from 1944; Laurie Kirby and Jeff Paris proved it unprovable in 1982.
