38c · proof

What Is Provable Is True

Rung four proved that whatever a proof reaches from true givens is true, and it proved it the way the tables check a tech: fix a way things could be, and walk down the lines. That proof spoke of “a world where the givens are true” in words, and its moves for every and some were checked in words too. Now worlds are objects and the moves are a closed list, so the old proof can be run exactly, for every language at once. Most of it is the old proof again. Three moves need new care: swapping a term for a term, speaking of everything, and using a some. Each is safe only because of the condition the last step put on it, and this step shows where each condition is spent. The result turns a world into a witness. Every time the ladder has shown that some axioms cannot reach a statement, by building a world, it was using this one technique, before it was proved.

Each move of the calculus keeps what is true in a world. So a statement reached from some givens is true in every world where the givens are true, and a world where they are true and a statement is false shows the statement cannot be reached.

38c1A Line Kept in a World

A line (S, R) holds in a world M when every assignment that makes every formula of S true in M makes R true in M. 4a15 checked lines “wherever all of S is true”; this is that check, with 38a’s truth under an assignment in place of a row of a table.

Move-keeps technique: each move of the calculus, fed lines that hold in a world, writes a line that holds in that world.

\text{join, keep, add an option, cases, carry through, prove an if, refute, clash, everything permitted, not-not out} @@ as in 4a15: one table row at a time, now one assignment at a time (38a3)
\textit{swap: } s \text{ makes } t = t' \text{ and } \varphi(t) \text{ true} \Rightarrow t, t' \text{ have one value, so } \varphi(t') \text{ is true} @@ the value of a term is all that φ(t) sees of t, when t is not caught (38b2)
\textit{speak of everything: } (S, \varphi(y)) \text{ holds},\ y \text{ free in no formula of } S @@ given
\quad s \text{ makes } S \text{ true; change } s \text{ at } y \text{ to any member } u \text{: still makes } S \text{ true} @@ the free-places technique (38a3): y is not free in S
\quad \text{so } \varphi(y) \text{ is true when } y \text{ is sent to any } u \text{, and } \forall x\,\varphi(x) \text{ is true under } s @@ the line holds; the clause for every
\textit{use a some: } s \text{ makes } \exists x\,\varphi(x) \text{ true, so some } u \text{ makes } \varphi \text{ true} @@ the clause for some
\quad \text{change } s \text{ at } y \text{ to } u \text{: } S \text{ and } \varphi(y) \text{ are true, so } R \text{ is} @@ the second line holds; y is free in none of S, R, ∃x φ
\htmlClass{new}{\text{and changing } s \text{ back at } y \text{ leaves } R \text{ true}} \quad \blacksquare @@ the free-places technique again: y is not free in R

Each condition of 38b2 was spent at one line. Without “y free in no formula of S”, changing s at y could make S false, and the line would say nothing about the new assignment. Without “y not free in R”, changing s back could change R.

38c2True in Every World

True-everywhere technique: if G reaches φ, then φ is true in every world of G. In marks: G ⊢ φ gives G ⊨ φ.

M \text{ a world of } G,\ \ L \text{ a proof from } G \text{ with foot } (\varnothing, \varphi) @@ given
\text{a given line holds: its formula is in } G \text{, true in } M \text{, or } t = t @@ M is a world of G; every term has one value
\text{a supposed line } (S, R) \text{ with } R \in S \text{ holds} @@ R is one of the formulas made true
\text{a moved or dropped line holds when the lines it leans on hold} @@ the move-keeps technique (38c1)
\text{every line of } L \text{ holds in } M @@ induction on line numbers (4c)
\htmlClass{new}{(\varnothing, \varphi) \text{ holds, so } M \models \varphi} \quad \blacksquare @@ nothing to make true; φ is a statement

From here on, G is clash-free when G does not reach ⊥: 6d’s “free of anything totally false”. Its accepted name is consistent.

World-means-clash-free technique: a collection of statements that has a world is clash-free. If G reached ⊥, ⊥ would be true in a world of G, and ⊥ is true in none.

38c3A World as a Witness

Turn the technique round. If some world of G makes φ false, then G does not reach φ. 3f built a world to show infinity cannot be argued from rungs 0 to 2. 6d described two worlds for choice. 29c built the disc plane for the parallel postulate, and 29·cb3.2 the world past the run for ω + ω. Each of those arguments leaned on this technique before it was proved. Now it is proved, for every language and every G at once.

G:\ \forall x\,\forall y\,\forall z\,(x \circ (y \circ z) = (x \circ y) \circ z),\ \forall x\,(x \circ e = x),\ \forall x\,\exists y\,(x \circ y = e) @@ 19’s techniques for moves, in a language with ∘ and a name e
M:\ \text{the six matchings of } \{1, 2, 3\} \text{ with itself, } \circ \text{ composing, } e \text{ the identity} @@ composing keeps matchings (9c); brackets don’t matter (9b)
M \models G @@ each matching has its run backwards (9d)
p = \text{swap } 1, 2;\ \ q = \text{swap } 2, 3:\ \ (p \circ q)(1) = 2,\ \ (q \circ p)(1) = 3 @@ do q then p, against p then q
M \models \neg\forall x\,\forall y\,(x \circ y = y \circ x) @@ one pair is enough
\htmlClass{new}{G \nvdash \forall x\,\forall y\,(x \circ y = y \circ x)} \quad \blacksquare @@ the true-everywhere technique, turned round

The technique says only no. A world can show that a statement is not reached. It cannot show that one is. Whether every statement true in every world of G is reached from G is a different question, and it has an answer: 38d.

38c4Reached and Necessary Are One

3b2 defined □P: every box you could open on the givens reaches P. 38c2 defined G ⊨ φ: φ is true in every world of G. This page has proved one way between them, and the next page proves the other. By the true-everywhere technique, what is reached is true in every world. By 38d’s reached-if-true-everywhere technique, what is true in every world is reached. So for any G in a listed language, G ⊢ φ exactly when G ⊨ φ.

Reached-is-necessary technique: for a collection G and a statement φ in a listed language, G ⊢ φ exactly when G ⊨ φ. In 3b’s marks, □φ under the givens G is one property with two faces: every box reaches φ, and every world of G makes φ true.

The rung’s whole account of worlds comes to this line. 3f, 6d and 29c each built a world to show that a statement was not reached; this footing says why a world is enough, and why nothing less than a world would be. A statement reached from G cannot fail in any world of G, and a statement not reached must fail in some.

The cellar · there if you want it

The accepted names

The true-everywhere technique is the soundness theorem for first-order logic: if Γ ⊢ φ then Γ ⊨ φ. A line that holds in a world is a valid sequent there. A clash-free collection is consistent; the world-means-clash-free technique is the step from satisfiable to consistent. Showing a statement is not provable by a model in which it fails is the method of models, used for independence proofs.

Who said it first

Soundness was taken for granted long before it was stated; it is the easy half of the completeness theorem, and Kurt Gödel proved both halves in his thesis of 1929. Eugenio Beltrami’s model of 1868 for the hyperbolic plane, the world behind 29c, was the first independence proof by a model. Rung 19’s rules for moves are the axioms of a group; the six matchings of {1, 2, 3} form the smallest group in which order matters, the symmetric group S₃.

A proof that is not allowed

“In every world I have tried, x · y = y · x is true whenever the axioms of arithmetic are. So they reach it.” Not allowed: trying worlds is guessing from cases, and the true-everywhere technique runs only the other way. That the axioms do reach x · y = y · x is true, and it is shown by a proof, by induction, as rung 4 showed it.
