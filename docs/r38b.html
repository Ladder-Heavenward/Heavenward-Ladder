38b · proof

Proofs as objects

Rung four already made a proof an object: a list of lines, each line a pair of the suppositions it stands under and the statement it says, each one given, supposed, moved or dropped. What it left loose was the list of moves. Any tech the ladder had earned could be cited, and the ladder had earned hundreds. This step closes the list. Each joining word and each of every and some gets two moves, one that makes it and one that uses it, and sameness gets the two it has had since rung 0. One more move, from rung 7, takes off two nots. That short list is the whole calculus. Every technique on statements the ladder has proved since the ground floor can be reached with it, and once reached, it can be used as a single line again. Two of the moves come with a condition about names, and the step shows what goes wrong without it. Then the calculus is looked at from outside: whether a list is a proof can be checked by a recipe that always stops, and all the proofs can be listed one after another.

A short list of moves, two for each mark, is the whole calculus of proof. Whether a list of lines is a proof can be checked by a recipe, so proofs and the statements they reach can be listed.

38b1The moves, one pair to a mark

Fix a language (38a). A proof from G is 4a9’s list of lines (S, R), with S a finite collection of formulas, R a formula, and each line given, supposed, moved or dropped. What changes is only this: a moved or dropped line must use one of the moves below, and no other.

  • = : self-sameness, the line t = t for any term t; swap, from t = t′ and φ(t), write φ(t′) (0b).
  • ∧ : join makes it; keep left and keep right use it (1c).
  • ∨ : add an option makes it; cases uses it, and drops the two suppositions (1c, 2a).
  • ⇒ : prove an if makes it, and drops its supposition (3a); carry an if through uses it (1d).
  • ¬ : refute makes it, and drops its supposition (3a); clash uses it: from φ and ¬φ, write ⊥ (1b).
  • ⊥ : everything permitted: from ⊥, write any formula (1b). And not-not out: from ¬¬φ, write φ (7d).
  • ∀ : speak of everything makes it; use an every, from ∀x φ(x) write φ(t), uses it (2b).
  • ∃ : show an example, from φ(t) write ∃x φ(x), makes it; use a some uses it, and drops its supposition (2b, 4a9).

From here on, G ⊢ φ, read “G reaches φ”, means: some proof from G has the foot (∅, φ). 4a’s basement gave the mark as an accepted name; here it is laid down for this calculus. The list is short, and it is all there is. Every other technique the ladder has proved on statements is now a proof in the calculus, and the next technique says that citing it costs nothing.

Derived-move technique: a move reached once by a proof in the calculus may be used as one line, and a proof that uses it can be rewritten as a proof that does not.

\text{line } k \text{ of } L \text{ is } (S, \psi), \text{ cited as a derived move from lines } (S, \varphi_1), \ldots, (S, \varphi_m) @@ given: a proof K reaches ψ from φ₁, …, φₘ, standing under nothing else
\text{add } S \text{ to the suppositions of every line of } K @@ the more-suppositions technique (4a14)
\text{each given line } \varphi_i \text{ of } K \text{ becomes a citation of the line of } L \text{ that holds it} @@ that line stands under S, a part of S (4a10)
\text{put the lines of } K \text{ in place of line } k \text{ and number them again} @@ every citation still points to a line above it
\htmlClass{new}{\text{the new list is a proof in the calculus, with the same foot}} \quad \blacksquare @@ one derived line at a time, induction on how many (4c)
  
P \Rightarrow Q @@ given
\qquad \text{assume } \neg Q @@ supposed
\qquad\qquad \text{assume } P @@ supposed
\qquad\qquad Q @@ carry an if through
\qquad\qquad \bot @@ clash, with ¬Q
\qquad \neg P @@ refute: P leaves
\htmlClass{new}{\neg Q \Rightarrow \neg P} \quad \blacksquare @@ prove an if: ¬Q leaves

3a proved turn-and-deny with boxes. The proof above is the same proof, and every move in it is on the list. So 3a’s technique is a derived move, and the calculus may cite it in one line.

38b2Fresh names

Two moves carry a condition. Speak of everything takes (S, φ(y)) to (S, ∀x φ(x)) only when the placeholder y is free in no formula of S and in no given used above. Use a some takes (S, ∃x φ(x)) and (S with φ(y) added, R) to (S, R) only when y is free nowhere else: not in S, not in R, not in ∃x φ(x).

2b said it in words: what makes a case “anything” is that the argument used nothing about it. The condition is that statement, checked by looking at the marks.

Use an every and swap carry a quieter condition: the term put in must not be caught. Putting t in for x in φ is allowed when no placeholder of t would fall inside an every or a some of φ that binds it.

\forall x_0\,(P(x_0) \land Q(x_0)) @@ given
P(x_1) \land Q(x_1) @@ use an every, with x₁
P(x_1) @@ keep left
\htmlClass{new}{\forall x_0\,P(x_0)} \quad \blacksquare @@ speak of everything: x₁ is free in no supposition and in no given
  
\text{assume } x_0 = 0 @@ supposed
x_0 = 0 @@ the supposed line
\forall x_0\,(x_0 = 0) \text{ ?} @@ speak of everything, refused: x₀ is free in the supposition
\htmlClass{new}{\text{without the condition: } (x_0 = 0) \Rightarrow \forall x_0\,(x_0 = 0) \text{, then } \forall x_1\,\big((x_1 = 0) \Rightarrow \forall x_0\,(x_0 = 0)\big)} @@ then use an every with 0, and carry it through on 0 = 0: ∀x₀ (x₀ = 0), false in N

38b3A recipe checks a proof

A proof is a finite list of finite strings. Each move compares a line with lines above it, mark by mark. So checking is the kind of work 4l called a recipe: a state, a start, a stop test, a move and an output.

Proof-check technique: whether a finite list of lines is a proof from a finite collection G can be settled by a recipe that always stops.

\text{read each formula of each line in its one way} @@ the one-reading technique (38a1): a recipe can parse
\text{line } k:\ \text{is it given, supposed, moved or dropped?} @@ four checks, each against G, S, or the lines numbered before k
\text{a moved or dropped line: try each move on each choice of earlier lines it may lean on} @@ finitely many moves, finitely many earlier lines (38b1)
\text{each try compares finitely many marks, and checks the fresh-name conditions} @@ 38b2: a placeholder is free or not, read off the string
\text{the count of lines left to check falls by one each round} @@ the falling-measure technique (4l)
\htmlClass{new}{\text{the recipe stops, and says yes exactly when the list is a proof}} \quad \blacksquare @@ the kept-statement technique (4l): lines checked so far are good

Proof-listing technique: if G can be listed, the proofs from G can be listed one after another, and so can the statements they reach.

\text{the marks can be listed: } m_0, m_1, m_2, \ldots @@ finitely many shared marks, and the placeholders x₀, x₁, …
\text{the finite strings of marks can be listed} @@ by 35a: finite lists from a listed set can be listed
\text{the finite lists of strings can be listed} @@ the same, once more
\text{at round } n \text{, check the first } n \text{ lists against the first } n \text{ members of } G @@ the proof-check technique, each check stops
\htmlClass{new}{\text{every proof from } G \text{ turns up at some round, and so does its foot}} \quad \blacksquare @@ a proof uses finitely many givens

The listing finds φ if some proof reaches it. If none does, it runs for ever and never says so. Telling the two apart is a different question, and 3·comp held it for later: rung 40 asks it of machines.

The basement · there if you want it

The accepted names

The calculus is natural deduction for classical first-order logic with equality. The making moves are introduction rules and the using moves elimination rules: ∧-introduction, ∨-elimination, ⇒-introduction (which discharges an assumption), and so on. Everything permitted is ex falso quodlibet, or ⊥-elimination; not-not out is double-negation elimination; carry an if through is modus ponens. A derived move is a derived or admissible rule. The fresh-name condition is the eigenvariable condition, and the quieter condition is that the term be free for the variable: substitution that avoids capture. A set that can be listed by a recipe is recursively enumerable; the proof-listing technique says the theorems of a listed theory form such a set.

Who said it first

Gerhard Gentzen and Stanisław Jaśkowski each published natural deduction in 1934, Gentzen in “Investigations into logical deduction”, where the pairs of introduction and elimination rules first appear. Earlier calculi, Frege’s of 1879 and Hilbert’s of the 1920s, had many axioms and one or two rules. Lewis Carroll’s dialogue “What the Tortoise Said to Achilles” (1895) is the story behind 38b.5.5.
