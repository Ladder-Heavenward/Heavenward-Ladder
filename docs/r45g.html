45g · proof

Agreement Despite Crashes

Many machines hold copies, and they must agree on one value even if some crash. This step gives the one counting fact that every working method rests on, and the technique that says why none is perfect.

Any two majorities share a machine, so what one majority accepted the next will hear. But with no bound on delay, no fixed method is sure to finish.

45g1What Agreement Asks

Each machine proposes a value. Three demands: every machine that decides decides the same value; the value decided was proposed by someone; and every machine that does not crash decides in the end.

45g2Any Two Majorities Meet

Majority-overlap technique: of n machines, any two sets each holding more than n/2 of them share at least one machine.

So if a majority has accepted a value, any later majority contains a machine that knows it. Working methods use this as follows. A leader with a numbered ballot first asks a majority what they have accepted. It must then propose the value from the highest ballot it hears of. Finally it asks a majority to accept. Two leaders cannot have different values chosen, because their majorities meet. Leaders elected for numbered terms by majority vote, one vote per machine per term, are at most one per term for the same reason.

45g3No Fixed Method Always Decides

In the model without bounds, if even one machine may crash, no fixed method meets all three demands in every run. This footing states the technique and the shape of its proof, which is long.

Call a state open when runs from it can still end in either value. Some start state is open, by a row of starts that differ in one machine’s proposal, together with 45b3: that machine may be the one that crashes. From an open state, a message can always be held back long enough that the next state is open again. Slow-or-dead is what makes the holding back look like a crash. So a run exists that stays open for ever, and never decides.

45g4The Ways Around

Real systems give up a little. They keep the first two demands always, and finish whenever the network behaves for long enough, so they never decide wrongly but may stall. Or they use chance, and finish with chance 1. The technique forbids only a fixed method that is sure to finish in every run.

The accepted names

The demands are agreement, validity and termination. The technique of 45g3 is the FLP impossibility result, named for Fischer, Lynch and Paterson. Methods built on majority-overlap include Paxos, Raft, Zab and Viewstamped Replication. An open state is called bivalent.
