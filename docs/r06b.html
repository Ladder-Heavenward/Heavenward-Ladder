6b · proof

Picking One From Every Box

Inside a proof you can already pick: 2b's tech for using a some names one member of a set that has a member. This step makes picks into an object. It says exactly what it means for a set to have a member. It gives a name to collections of sets. And it defines a choosing function: a function that takes each set of a collection to a member of that set. Then it lays down the axiom that such a function always exists when every set in the collection has a member. Before and after the axiom it shows when you do not need it: when a rule does the picking. “Take the left shoe” does this for shoes, and “take the least” does it for settled sets of numbers. And it shows what the rule-free case looks like: socks.

A choosing function is one object holding one pick from every set. With a rule, a sift builds it. Without a rule, the axiom says it exists and says nothing about which member it took.

6b1Picking One, Inside a Proof

2b's tech for using a some runs like this. From a line ∃x P(x), write “call such a thing b”. Open a supposition of P(b) with b a name not in use. Reason with b, and close when you reach a line that does not mention b. That tech is a pick: it names one thing with the property, and says nothing about which one. If there are many, b is any of them, and the proof must work whichever it is. That is why the closing line may not mention b.

Two things limit this kind of picking. The pick lives only inside its call: after the close, b names nothing. And one call names one thing: a proof that wants a hundred picks makes a hundred calls, and a proof is finitely many lines. To hold many picks at once, after the calls have closed, you need an object that holds them: a set of pairs, each set with its pick. That object is a function in 4d's sense, and the question of this rung is when it exists.

6b2Having a Member

Everything here is about sets that have something in them. The ladder needs to say this the right way round.

From here on, a set A is non-empty when it has a member: . Read it “A is non-empty”, or “A has a member”.

Why not write A ≠ ∅? Because the two are not interchangeable by the techs. One direction is easy and the other is not. Non-empty technique: a non-empty set is not ∅; and a set that is not ∅ is, at least, not without a member. In marks: from ∃x (x ∈ A), A ≠ ∅; from A ≠ ∅, ¬¬∃x (x ∈ A).

The axiom below is laid down for sets with a member, so that every pick could at least be made by a call.

6b3Collections of Sets

A collection is written with a curly capital, as 2g set out: , or names a set whose members are sets.

For a collection 𝒜, 2f's union ⋃𝒜 is the set of everything in any member of 𝒜. If A ∈ 𝒜 and x ∈ A, then x ∈ ⋃𝒜, by 2f's line with A as the example. So ⋃𝒜 is a set big enough to hold every pick from every member, which is what the next line needs.

6b4A Function That Picks

From here on, for a collection 𝒜, a choosing function for 𝒜 is a function from 𝒜 to ⋃𝒜 with c(A) ∈ A for every A ∈ 𝒜. Read c(A) as “c's pick from A”. In marks:

Its accepted name is a choice function.

Unpacked through 4d's lines, a choosing function is a set of pairs (A, x) with A ∈ 𝒜 and x ∈ ⋃𝒜. In it, every member of 𝒜 is the left entry of exactly one pair, and the right entry of each pair is in its left entry. A worked case. Let 𝒜 = {{cat, dog}, {owl}}, where cat, dog and owl are different animals. Then ⋃𝒜 = {cat, dog, owl}, and

c_1 = \{(\{\text{cat}, \text{dog}\}, \text{cat}),\ (\{\text{owl}\}, \text{owl})\} @@ a set of two pairs (Pairing, 2h)
c_1 \subseteq \mathcal A \times \textstyle\bigcup\mathcal A @@ each pair has its left entry in 𝒜 and its right entry in ⋃𝒜
\{\text{cat}, \text{dog}\} \ne \{\text{owl}\} @@ same-members: cat is in the first, and not in the second, since cat ≠ owl
\begin{aligned}&\text{every input has an}\\ &\quad\text{output; no input has two}\end{aligned} @@ each member of 𝒜 is the left entry of one pair only, by the line above
c_1(\{\text{cat}, \text{dog}\}) = \htmlClass{new}{\text{cat}} \in \{\text{cat}, \text{dog}\},\quad c_1(\{\text{owl}\}) = \text{owl} \in \{\text{owl}\} @@ 4d's value line; the listings
c_1 \text{ is a choosing function for } \mathcal A \quad \blacksquare @@ ︿ the line

The other one is c₂, which picks dog from {cat, dog}. There are no more: a choosing function must pick owl from {owl}, and has two members of {cat, dog} to choose between. 6c counts choosing functions in general.

Two edge cases decide a lot. If ∅ is in the collection, there is no choosing function, because there is nothing to pick from ∅. Empty-member technique: if ∅ ∈ 𝒜, then 𝒜 has no choosing function.

\varnothing \in \mathcal A @@ given
\quad \text{assume } \exists c\,(c \text{ is a choosing function for } \mathcal A) @@ aiming to refute
\quad \text{call such a thing } c @@ use a some
\quad c(\varnothing) \in \varnothing @@ ﹀; use the every with ∅
\quad c(\varnothing) \notin \varnothing @@ the empty-set technique
\quad \bot @@ clash; the some closes, since ⊥ does not mention c
\htmlClass{new}{\neg\exists c\,(c \text{ is a choosing function for } \mathcal A)} \quad \blacksquare @@ refute

And if the collection itself is empty, there is exactly one choosing function, the empty set. Empty-collection technique: the empty set is a choosing function for the empty collection. In marks: ∅ is a choosing function for ∅. ∅ ⊆ ∅ × ⋃∅ by empty-part. The lines “every input has an output” and “c(A) ∈ A for every A ∈ ∅” are everys over a subject with no members, so they are empty truths. (That is 2j's word: assume A ∈ ∅, and clash with the empty-set technique; when nothing is true, everything is permitted. The permitted line goes when the supposition is dropped, and only the empty if remains.) And no pair is in ∅ to have a second output. ∎

6b5The Axiom

In plain words: for any collection of sets, each of which has a member, there is one object that holds a pick from each, all at once. That is, there is a choosing function. In marks:

With the collection fixed and its members non-empty, the heart of it is short:

This is the choosing axiom. From here on the ladder lays it down, as 3d laid down the infinity axiom. 6d shows why it has to be laid down rather than proved, and why it cannot be refuted either. Without it, a choice from endlessly many sets, with no rule to follow, could never be made, and 6d shows exactly what is lost.

Look at what the axiom says and does not say. Like the infinity axiom, it asserts that something exists, and builds nothing. It does not say which member c takes from any set. A proof uses it the way it uses any some. It writes “call such a function c”, with c a fresh name, reasons with c, and closes on a line that does not mention c. Every tool of rung 2 said exactly what was in its result. This one says only that c(A) is in A. That is the whole difference, and the whole controversy.

On this rung no proof leans on the axiom to reach its last line. Where a step states something with the axiom in it, it says so, and 6e proves its two working forms as statements about the axiom, not with it.

6b6Rules That Pick: Shoes

Before the axiom is needed, look at the cases where it is not. In this step's everyday examples, a pair of shoes means what a shop means: the set of its two shoes, {l, r}, one left and one right. That is not 2h's pair (l, r), and the step writes it with braces to keep them apart. Let 𝒮 be a collection of pairs of shoes, as many as you like, and write L(x) for “x is a left shoe”. The shop supplies two facts as given lines. (g1) Every member of 𝒮 has a left shoe in it. (g2) Only one.

Left-shoes technique: 𝒮 has a choosing function, built by a sift, with no axiom.

c = \{(A, x) \in \mathcal S \times \textstyle\bigcup\mathcal S : x \in A \land L(x)\} @@ Separation, written with 2i's shorthand
\text{let } A \in \mathcal S;\ \text{call } x \text{ with } x \in A \land L(x) @@ (g1); use a some
x \in \textstyle\bigcup \mathcal S,\ \ \htmlClass{new}{(A, x) \in c} @@ 2f's line for ⋃, with A as the example; ︿ the sift: every input has an output
(A, x) \in c \land (A, y) \in c \;\Rightarrow\; x = y @@ ﹀ the sift twice; (g2): no input has two
c : \mathcal S \to \textstyle\bigcup\mathcal S,\quad c(A) \in A @@ ︿ 4d's line for a function; the value line, and the sift unpacked
c \text{ is a choosing function for } \mathcal S \quad \blacksquare @@ ︿; speak of everything. No axiom was used

The proof never asked how many pairs there are. One condition, L(x), did every pick at once, and by Separation the sift by that condition is a set: the function. That is what a rule is: a condition that, in each set of the collection, is so of exactly one member.

This is a new job for 4d's word. There a rule, x ↦ t(x), is a piece of writing that names an output for each input. Here a rule for a collection is a condition. Both stand; what the rule is for says which.

From here on, a set X is infinite when it is not finite:

4k showed that ℕ is infinite.

Matched-with-ℕ technique: a set matched with ℕ is infinite. Assume X has n members. X is matched with n, and with ℕ. Turn the second matching about (turn-about for matchings) and join (chain for matchings). Then ℕ is matched with n, so ℕ has n members, against 4k. Refute; the some closes. ∎ So “endlessly many pairs of shoes” has a meaning: a collection 𝒮 matched with ℕ, pair A_n for each number n. Left-shoes covers it with no change.

6b7Rules That Pick: Least Members

The ladder owns a second rule. 4h's least-member gives a least member to a settled set of numbers that has a member. And 4h showed a set of numbers has at most one. Least-chooses technique: if every member of 𝒜 is a non-empty settled set of numbers, then 𝒜 has a choosing function, with no axiom: take the least.

c = \{(A, m) \in \mathcal A \times \textstyle\bigcup\mathcal A : m \text{ is the least member of } A\} @@ Separation, 2i's shorthand
\text{let } A \in \mathcal A;\ A \text{ has a least member } m @@ given: A settled and non-empty; the least-member technique (4h); use the some
m \in A,\ \ m \in \textstyle\bigcup\mathcal A,\ \ \htmlClass{new}{(A, m) \in c} @@ ﹀ “least member”; 2f's ⋃ line; ︿ the sift
(A, m) \in c \land (A, m') \in c \;\Rightarrow\; m \le m' \land m' \le m @@ ﹀ the sift, and “least member” for each, used with the other
\phantom{(A, m) \in c \land (A, m') \in c} \;\Rightarrow\; m = m' @@ 4h: at most one least member (any-two-compare: not both m < m′ and m′ < m)
c \text{ is a choosing function for } \mathcal A \quad \blacksquare @@ ︿, as in left-shoes. No axiom was used

So from {4, 9}, from the even numbers above 7, and from the nonzero multiples of 3, c picks 4, 8 and 3. It would pick from a collection matched with ℕ just as well. The rule fails in three places, and each is instructive.

  • Integers. {x ∈ ℤ : x < 0} has no least member. For any x in it, x − 1 is in it and x − 1 < x (5d's order, 5f's keep-order for plus on ℚ). “Take the least” answers nothing there. 6b.3.1 mends the rule.
  • Fractions. {x ∈ ℚ : 0 < x ∧ x < 1} has no least member. For x in it, x · ½ is in it and smaller, since x − x · ½ = x · ½ is positive (5f). 6b.4.1 builds a rule of another kind.
  • Unsettled sets. Least-member needs the set settled. For a set of numbers whose membership cannot be decided number by number, 4h had only no-least-no-members. No least member means no members, which turned about gives only ¬¬(A has a least member). So “take the least” is not yet a rule for every set of numbers; 7·cb4 returns to it.

6b8Socks

Now a collection 𝒦 of pairs of socks, each member a set {s, s′} of two socks made alike. Here the given line is the opposite of the shop's: whatever you can say of one sock of a pair, you can say of the other. A rule would be a condition that is so of exactly one sock in each pair. By the given line, any condition is so of both socks of a pair or of neither. So there is no rule.

With a few pairs on the bed you can still pick. Call a sock of the first pair s₁, a sock of the second s₂, and so on to the last. Then gather the pairs of sets and picks. 6c proves this works for any finite collection. With 𝒦 matched with ℕ, a column runs out of calls before it runs out of pairs. The choosing axiom now says a choosing function for 𝒦 exists. Call it c. Then c(K) is a sock of K, for every pair K. That is all anyone can say: not which sock, for any pair. 6d builds a world in which every other principle is true and 𝒦 has no choosing function at all. That is why the axiom is needed.

6b10Running It Backwards

Wanting a choosing function for a collection, ask first for a rule: a condition that is so of exactly one member of each set. If you find one, sift, as left-shoes and least-chooses did, and no axiom is used. If the collection is written out, pick by hand, one call per set (6c). If neither, by the axiom there is one, and your proof must work whichever member it took. Wanting to show a collection has none, look for ∅ in it (empty-member). Handed a function and asked whether it chooses, check the three parts. It must be a set of pairs from 𝒜 × ⋃𝒜. It must have exactly one pair for each member of 𝒜. And each right entry must be in its left entry. Found upward; written downward.

The accepted names

The choosing axiom is the axiom of choice, and a choosing function is a choice function.

Who said it first

The axiom was introduced by Ernst Zermelo in 1904. The boots and socks are Bertrand Russell’s.

Zermelo, introducing the principle, took it that for any collection of non-empty parts of a set one may imagine each part assigned one of its own members, and that this principle, used without comment in many places, could serve as the foundation of his proof that every set can be put in order.

Zermelo, “Beweis, dass jede Menge wohlgeordnet werden kann”, Mathematische Annalen 59 (1904)

Russell's millionaire bought a pair of socks every time he bought a pair of boots, until he had endlessly many of each. To choose one boot from each pair, choose all the left boots. With socks, Russell observed, no principle of selection suggests itself, and unless we assume the axiom we cannot be sure there is any collection consisting of one sock out of each pair.

Russell, Introduction to Mathematical Philosophy (1919), ch. XII (Russell's name for the axiom is the multiplicative axiom)
