9·cb4 · newsflash for 4c

Recursion revisited: sequences

4c proved the principle every later definition by repeating has leaned on: a start and a step fix exactly one function on the counting numbers. It had to be proved with the bare definition of a function, because the theory of functions did not exist yet. Now it does. A sequence is a statement that names a function on the counting numbers. The recursion principle becomes a sentence about two chains of functions agreeing. And repeating a function a given number of times turns out to be the one gesture behind adding, multiplying and powers. With rung 7's either-way principle in hand, the page ends with something 4c could not prove. A sequence of numbers that never goes up must, at some point, stand still for ever, though nobody may be able to say when.

A start and a step give exactly one sequence: each term is the step done to the term before, so any term is the step done that many times to the start. Adding, multiplying and powers are the steps “next one”, “add a number” and “times a number”, each done again and again.

What this calls back to, and what it stands on

Calls back to 4c (recursion, the function s, same-outputs, closed sets, the layers and their catch), with 4e and 4f (adding, multiplying and powers by recursion), 4h (counted-recursion, lists, low marks, the dots). Stands on 4g (next-is-not-past, any-two-compare), 7·cb4 (least-member-for-any-set), 7d (definitions by cases), 9a (equal-functions, ran), 9b (composite-is-a-function, regroup for composing, identity). Rung 10 asks where sequences of reals are headed.

The class · read it through, then work the picture and the slides

An old book of arithmetic set a puzzle about rabbits. A pair is put in an enclosure. Each month every pair old enough bears a new pair, and a new pair is old enough after a month. How many pairs are there after a year? Each month’s count is found from the two before it.

A sequence is a statement that names a function on ℕ

From here on, a sequence of members of A is a function u : ℕ → A. Its value at n is its n-th term, written u_n with 4h's low mark, as 4h wrote the entries of a list. When a sequence is in hand it may be written u₀, u₁, u₂, ⋯. The dots stand for its terms, which the function supplies, as 4h's dots did for a list. They are writing for a sequence already given, never a tool that makes one.

From here on, “term” is also said of a sequence. 5h's terms of a sum, the pieces joined by +, keep their meaning.

A list stops; a sequence does not: 4h's lists were functions on {1, ⋯, k}, and a sequence is a function on all of ℕ. You have met many. 4c's s is the sequence 1, 2, 3, ⋯ (its n-th term is S(n)). 4c's d is 0, 2, 4, ⋯. 4j's running sums are sequences, and so are 8f's powers of a real. 8·cb5's endless decimal was a sequence of digits counted from 1. 9c's words apply to sequences as to any function. s is one-to-one; the sequence cat, dog, cat, dog, ⋯ of 4c is not, and its range is {cat, dog}.

The recursion principle, in this rung's language

4c's recursion says: for a set A, a member p of A and a function g : A → A, there is exactly one f : ℕ → A with f(0) = p and f(S(n)) = g(f(n)) for every number n. Read the second condition with 9b's ring. On the left, f(S(n)) is f after s, at n. On the right, g(f(n)) is g after f, at n. So the condition says two chains of functions agree at every input. Recursion-restated technique: for p ∈ A and g : A → A there is exactly one sequence f : ℕ → A with f(0) = p and f ∘ s = g ∘ f.

f \circ s = g \circ f @@ the claim about the step, as a sameness of functions ℕ → A
\;\Leftrightarrow\; \forall n \in \mathbb N\ \ (f \circ s)(n) = (g \circ f)(n) @@ equal-functions (9a): both have domain ℕ
\;\Leftrightarrow\; \forall n \in \mathbb N\ \ \htmlClass{new}{f(S(n)) = g(f(n))} @@ composite-is-a-function (9b) on each side; s(n) = S(n)
\begin{aligned}&\text{so recursion-restated is recursion,}\\ &\quad\text{word for word} \quad \blacksquare\end{aligned} @@ existence and uniqueness both carried; 4c's same-outputs was equal-functions's leftward half

Two roads from n agree. Go up a step with s, then read the term with f. Or read the term with f, then take a step with g. You land on the same member of A. That is all “defining by repeating” ever meant, and recursion-restated says it in one line.

9h's two kinds of step are, in this language, the sequences with u_(n+1) = u_n + d and u_(n+1) = u_n · b: arithmetic, with common difference d, and geometric, with common ratio b. Given by its start and step, a sequence is said to be defined recursively, by a recurrence; given by a formula in n, explicitly.

Doing a function n times

The step g is applied once per number. Gather the repetitions into functions of their own.

From here on, for g : A → A and a number n, g^∘n names the n-th iterate of g. It is the function A → A fixed by recursion on the set of functions from A to A (a sift of 𝒫(A × A)), with start g^∘0 = id_A and step g^∘S(n) = g ∘ g^∘n. Read it “g done n times”. The ring in the high place marks an iterate, not 4f's power: g^∘2 is g ∘ g, and never g times g.

The step h ↦ g ∘ h is a function on that set by composite-is-a-function and rule-makes-a-function, so recursion applies. Sequence-is-the-iterates technique: the sequence of recursion-restated is n ↦ g^∘n(p). By induction: at 0, g^∘0(p) = id_A(p) = p = f(0). If g^∘n(p) = f(n), then g^∘S(n)(p) = g(g^∘n(p)) = g(f(n)) = f(S(n)), by composite-is-a-function and the hypothesis. ∎ Iterates obey 4f's techniques for powers, with ∘ in place of times. Iterates-turn-about technique: g ∘ g^∘m = g^∘m ∘ g. Iterates-add technique: g^∘(m + n) = g^∘m ∘ g^∘n.

g^{\circ(m + S(n))} = g^{\circ S(m + n)} @@ 4e's plus-a-next: m + S(n) = S(m + n)
\phantom{g^{\circ(m + S(n))}} = g \circ g^{\circ(m + n)} @@ the iterate's step
\phantom{g^{\circ(m + S(n))}} = g \circ (g^{\circ m} \circ g^{\circ n}) @@ the induction hypothesis
\phantom{g^{\circ(m + S(n))}} = (\htmlClass{new}{g \circ g^{\circ m}}) \circ g^{\circ n} @@ regroup for composing (9b)
\phantom{g^{\circ(m + S(n))}} = (\htmlClass{new}{g^{\circ m} \circ g}) \circ g^{\circ n} @@ iterates-turn-about
\phantom{g^{\circ(m + S(n))}} = g^{\circ m} \circ (g \circ g^{\circ n}) = \htmlClass{keep}{g^{\circ m} \circ g^{\circ S(n)}} \quad \blacksquare @@ regroup for composing; the iterate's step. Base n = 0: identity and plus-zero

Iterates-turn-about is a short induction of the same kind (base identity on both sides; step regroup for composing and the hypothesis). Iterates-multiply technique: (g^∘m)^∘n = g^∘(m · n), by induction on n with iterates-add and 4f's times-a-next. These are 4f's powers-add-their-counts and power-of-a-power, with ∘ for times and iterates for powers. Brackets in a chain don't matter, so each proof is 4f's, word for word.

The ladder of operations is one gesture

4e defined p + q as f_p(q), the sequence with start p and step s. 4f defined p · q with start 0 and step y ↦ y + p, and p^q with start 1 and step y ↦ y · p. By sequence-is-the-iterates, each is an iterate run on its start. Ladder-of-operations technique: for numbers p and n, with t_p(y) = y + p and m_p(y) = y · p on ℕ: p + n = s^∘n(p), p · n = t_p^∘n(0), and p^n = m_p^∘n(1). Each defining sequence of rung 4 is the one recursion-restated gives for its start and step (uniqueness). Sequence-is-the-iterates names its terms. ∎

Each rung of the ladder is the rung below, done n times, and each starts at the do-nothing of the operation it repeats: 4f's table, now one sentence. And the techniques come along. Iterates-add at g = s says s^∘(m + n)(p) = s^∘m(s^∘n(p)). That is (p + n) + m = p + (m + n), once turn-about for plus turns m + n about. 4c named a function by the sequence it lists; this page names the gesture that makes it.

Two cautions from 4c stand. The step must be a function from a set to itself. S is not a function (no set holds all its pairs: 2f's no-set-of-all-sets), though its restriction s to ℕ is. And the layers V_k of 3c, with step x ↦ 𝒫(x), are a sequence only if some set A holds every layer and 𝒫 of each of its members. No line of the ladder supplies one. Each layer can be built, as far along as you like. All of them as one sequence needs an axiom the ladder names only as history.

With every statement true or false

4h let a step split into cases only on a decidable statement, so that the rule named one thing. 7d lifted the restriction: a step may now split on any statement. Let G be the even-sum guess (7c), and g(n) = S(n) if G, n if ¬G. Recursion-restated gives a sequence from 0: it is 0, 1, 2, ⋯ if G is true, and 0, 0, 0, ⋯ if not. It is a perfectly good function, by 9a, and nobody can tell you its third term.

The either-way principle also proves something about sequences of numbers that rung 4 could not. First, what rung 4 could. No-endless-descent technique: there is no sequence of numbers with u_S(n) < u_n for every n. Suppose one. Prove by induction on k that k ≤ u_n for every n. At 0 it is 4g's 0 ≤ u_n. And if k ≤ u_S(n) < u_n, then S(k) ≤ u_n by next-is-not-past. Take k = S(u₀): S(u₀) ≤ u₀, against u₀ < S(u₀). Refute. ∎ No either-way was used: a refutation, as 7e said of every descent. The descents on 4i and on 7e were this technique in costume.

Now let the sequence merely never go up. Never-rising-stands-still technique: if u_S(n) ≤ u_n for every n, there is an N with u_n = u_N for every n ≥ N.

\operatorname{ran} u = \{u_n : n \in \mathbb N\},\ \ u_0 \in \operatorname{ran} u @@ 9a's range: a set of numbers with a member
\text{call } m \text{ its least member};\ \ m = u_N \text{ for some } N @@ least-member-for-any-set (7·cb4), which leans on either-way; ﹀ ran
n \ge N \Rightarrow u_n \le u_N @@ induction from N: each step never goes up (chain for less for ≤)
n \ge N \Rightarrow u_N = m \le u_n @@ m is least in ran u, and u_n ∈ ran u
\htmlClass{new}{u_n = u_N} \text{ for every } n \ge N \quad \blacksquare @@ any-two-compare: ≤ both ways is sameness; the call closes

The column cannot be made to name N. Let u_n be 1 if every even number from 4 up to 2n + 4 is a sum of two primes, and 0 otherwise. Each term is decidable, by 4i's bounded-some. The sequence never rises: once a counterexample appears, every later term is 0. Never-rising-stands-still says it stands still from some N on. If the even-sum guess is true it stands still at 1 from N = 0. If false, it drops to 0 at the first counterexample and stays. Which, and where, nobody knows. 7·cb4's least member had the same character: the either-way principle gives existence without an address. And never-rising-stands-still is about numbers. The never-rising sequence of reals 1, ½, ⅓, ⋯ never stands still, since 1/S(n) ≠ 1/S(S(n)). Where such a sequence of reals is headed is the question rung 10 makes exact.

Running it backwards

Handed a sequence: ask whether each term depends only on the one before. If so, name the start and the step, and recursion-restated and sequence-is-the-iterates say it is n ↦ g^∘n(p). cat, cat, dog has no step, as 4c said. Handed a technique about iterates: prove it as 4f proved its technique about powers, with regroup for composing where 4f used regroup for times. Handed a sequence of numbers that never rises: never-rising-stands-still says it stands still, and least-member-for-any-set is the reason. If it strictly falls, no-endless-descent says it cannot go on. Found upward; written downward.

Who said it first

The old book with the rabbit puzzle is Fibonacci’s Liber Abaci, and the counts it gives are the Fibonacci numbers. The descent on 4i is Fermat’s; the one on 7e is Tennenbaum’s.

Fibonacci set a puzzle about rabbits. A pair is put in an enclosure; each month every pair old enough bears a new pair, and a new pair is old enough after a month. How many pairs are there after a year? Each month’s count is found from the two before it.
