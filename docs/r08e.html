8e · proof

Counting Passes Any Real

However large a real number is, some counting number is larger. The Greeks made a version of this a condition for two amounts to be compared at all. On the line it is a technique. The usual proof is by contradiction, through a least upper bound, and rung 7 is what licenses its last step. With cuts there is also a direct road. This step walks both, then asks 7f's question about which says more. The everyday form follows: one over some counting number is below any positive real. And from it, or more quickly from the cuts themselves, between any two different reals there is a fraction.

If the counting numbers had a ceiling, they would have a lowest ceiling; one step below it some number sits, and one step past that number breaks through.

8e1The Claim, and the Proof by Contradiction

Counting-passes-any-real technique: counting eventually passes any real. In marks, where n, a number, names a real by 8d's naming line:

The Technique's accepted name is the Archimedean property.

The oldest geometry book that has come down whole defines two amounts as having a ratio to one another when each, taken enough times, can exceed the other. There it is a definition, which sorts the amounts that can be compared from those that cannot. A later Greek used the same idea as an assumption.

On the line nothing has to be assumed. Here is the usual proof, by contradiction proper (7f), with no-holes doing the work.

\text{let } \alpha \in \mathbb R;\ \ \text{suppose } \neg\exists n \in \mathbb N\,(\alpha \lt n) @@ speak of anything; supposition for contradiction
\forall n \in \mathbb N\,(n \le \alpha) @@ not-some (2b); three-way-order on ℝ (8b): ¬(α < n) is n ≤ α
S = \{n^{*} : n \in \mathbb N\}:\ 0^{*} \in S,\ \alpha \text{ bounds } S @@ 2i's shorthand, a sift of ℝ; the line above
\sigma = \sup S @@ no-holes (8c)
\sigma - 1 \lt \sigma @@ order-and-arithmetic-agree (8d): add σ to −1 < 0
\neg(\sigma - 1 \text{ is an upper bound of } S) @@ if it were, σ ≤ σ − 1, since σ is least: clash by three-way-order on ℝ
\text{call } n \in \mathbb N \text{ with } \sigma - 1 \lt n @@ not-every, bounded form (7e); three-way-order on ℝ; use the some
\sigma \lt n + 1 @@ order-and-arithmetic-agree: add 1
n + 1 = S(n) \in \mathbb N,\ \text{so } n + 1 \le \sigma @@ plus-one (4f), next-of-a-number (4b); σ is an upper bound of S
\bot @@ three-way-order on ℝ: σ < n + 1 and n + 1 ≤ σ
\htmlClass{new}{\exists n \in \mathbb N\,(\alpha \lt n)} \quad \blacksquare @@ refute: ¬¬; not-not-out (7e); α was anything

The shape is worth remembering, because rung 8 uses it again. A least upper bound σ is approached from below by members of the set. So σ − 1 is beaten by some member, and that member, pushed one step, beats σ. Every proof of the form “if it were bounded, take the least bound, and step past it” runs this way.

8e2The Costume Off

7f taught a test: if the supposition is used once, at the end, the proof may be direct underneath. Here something better is true. With cuts there is a direct proof that uses neither the supposition nor no-holes.

\text{call } b \in \mathbb Q \text{ with } b \notin \alpha @@ cut (ii) for α
r \in \alpha \Rightarrow r \lt b;\ \ \text{so } \alpha \le b^{*} @@ members-below-non-members; chase; ︿ ⊆
\text{call } n \text{ with } b \lt n \cdot 1 @@ counting-passes-fractions (8d), with w = 1
b^{*} \lt n^{*} @@ fractions-keep-order (8a)
\htmlClass{new}{\alpha \lt n} \quad \blacksquare @@ at-most-is-a-partial-order on ℝ and three-way-order on ℝ; the naming line

Which says more? The direct column hands you n: find a fraction α misses, and count past it. The column through sup proves only that some n exists. On this ladder both are correct. The direct one is better, and it is available because a cut carries a fraction it misses. The sup proof has a different virtue: it works in any regular number system with no holes, however its members were built. That is why it is the usual one.

8e3The Everyday Form: 1/n Gets Below Anything Positive

Everyday-counting-passes technique: for every positive real α there is a number n ≠ 0 with 1/n < α. α⁻¹ is a real (reciprocal on ℝ). Counting-passes-any-real gives n with α⁻¹ < n. n is positive, since α⁻¹ is positive (positive-reciprocal on ℚ's column, read in ℝ: it used only the rules). And positive-reciprocal on ℚ's second part, read in ℝ, turns α⁻¹ < n into 1/n < α. ∎ A further technique is worth saying aloud: there is no positive real below every 1/n. The line has no infinitely small positive members. If α were positive and below every 1/n, everyday-counting-passes would give an n with 1/n < α, a clash.

8e4A Fraction Between Any Two Reals

Fraction-between technique: if α < β, there is a rational r with α < r < β. With cuts, the first road is short. So ℚ is said to be dense in ℝ.

\text{call } s \in \beta \text{ with } s \notin \alpha @@ witness-for-less (8b)
\alpha \le s^{*} @@ members-below-non-members: every member of α is below s
\text{call } t \in \beta \text{ with } s \lt t @@ cut (iv) for β
s^{*} \lt t^{*},\ \ t^{*} \lt \beta @@ fractions-keep-order; members-are-the-fractions-below (8a)
\htmlClass{new}{\alpha \lt t \lt \beta} \quad \blacksquare @@ at-most-is-a-partial-order on ℝ, three-way-order on ℝ; the naming line

The second road is the one every book gives, and the one 8·cb5 uses for decimals, because it says what the fraction's bottom can be. Choose n with 1/n < β − α (everyday-counting-passes), and look at the multiples of 1/n. They step along the line in steps smaller than the gap, so one of them must land inside it.

1/n \lt \beta - \alpha @@ everyday-counting-passes, with β − α positive (order-and-arithmetic-agree)
\text{call } N \in \mathbb N \text{ with } -N \lt \alpha @@ counting-passes-any-real for −α; order-and-arithmetic-agree: add α − N
X = \{j \in \mathbb N : \alpha \lt \tfrac{j}{n} - N\} \text{ has a member} @@ counting-passes-any-real gives M > α; j = (M + N) · n works
\text{call its least member } j;\ \ j \ne 0 @@ least-member-for-any-set; 0 ∉ X, since −N < α (three-way-order on ℝ)
\tfrac{j - 1}{n} - N \le \alpha \lt \tfrac{j}{n} - N @@ j − 1 ∉ X by leastness (zero-or-a-next); three-way-order on ℝ
r = \tfrac{j}{n} - N \le \alpha + \tfrac1n \lt \beta @@ order-and-arithmetic-agree: add 1/n; the first line
\htmlClass{new}{\alpha \lt r \lt \beta} \quad \blacksquare @@ the two lines above

Between the hole's cut of 8a and 99/70, the second road takes n = 13860 and lands on 19601/13860. Between 7/5 and the hole's cut it takes n = 71 and lands on 100/71. The picture runs it for any pair. Both roads agree on the lesson. The fractions are scattered everywhere on the line, and still, by 8a's hole-is-no-fraction's-cut, they leave places only the new numbers fill.

8e6Running It Backwards

Wanting a number above a real, find a fraction the cut misses and count past it. Wanting a small step, everyday-counting-passes. Wanting a fraction strictly between two reals, the cuts give one at once (witness-for-less, then (iv)). Wanting one with a chosen bottom n, take the first multiple of 1/n past the lower real. Handed a proof that some number exists, ask whether it says which: the sup road does not, the cut road does. Found upward; written downward.

Who said it first

Euclid defines two magnitudes as having a ratio to one another when each, taken enough times, can exceed the other. For him it is a definition, which sorts the amounts that can be compared from those that cannot; Archimedes later used the same idea as an assumption.

Euclid, Elements V, Definition 4, after Heath's translation (1908)

The inventor of 8e.4.4 is Gottfried Wilhelm Leibniz, whose calculus used infinitely small quantities.

Accepted names: counting-passes-any-real is the Archimedean property: ℝ is Archimedean. Fraction-between says ℚ is dense in ℝ.
