6a · proof

The Price of Free

Each rung has opened with a way of building logic: 0a the name and the statement, 1a the line, 2a rows, 3a boxes, 4a the proof, 5a the line read by its operator. This rung is about the one move the ladder lays down instead of earning, picking from infinitely many sets at once. Before that move, this step looks at the moves that come for free: an option, an if, everything permitted, a 0, a 1, and a 1 in disguise. None of them changes what a line claims, so why conjure them? And what do they cost?

A free move changes the shape, not the claim. The cost of free is your attention, and what that cost gets you is room to work.

6a1Free for the Taking

An axiom does not have to be proven. It is laid down, and it earns its place from above, by what breaks without it. Some moves are free in the same way: each writes something the line already holds, so no technique has to pay for it in truth.

Each was earned already: the option at 1c6, both ifs at 3a9, everything permitted at 1b10, the 0 at 4f3, the 1 at 4g7, x⁰ at 4g4, and x/x at 5h1. A free move costs nothing in truth. It still has a price, and this step is about the price, and about why anyone would conjure up a move that changes nothing.

6a2An Option, for Free

From x, write x ∨ y, for any y at all. The or is true, because one of its options is.

The price is the news of which. The or no longer says that x holds; it says x or y, and nothing on the line can get x back out of it without cases. So the option is conjured only when an or is what you need, such as the input of a technique that takes an or, or a goal whose outermost mark is ∨ (4e3).

6a3An If, for Free

From x, write y ⇒ x, for any y. 3a9 earned it with a box: suppose y; x is still in reach; close the box.

There is a second free if, the other way round. From ¬x, write x ⇒ y, for any y at all. Here it does not matter whether y is true or not, because the condition is already false. 3a9 earned this one too: suppose x; it clashes with ¬x; when nothing is true, everything is permitted, so y; close the box. An if made true this way, by a false condition, is an empty truth.

The move inside that box is free as well: when nothing is true, everything is permitted. From ⊥, write y, for any y (1b10). It costs nothing because the line it works on is already totally false.

The price is that the if is empty. The first is true because its promise is already kept, so it says nothing about y. The second is true because its condition can never be met, so it can never be carried through at all. Each is conjured when a technique asks for an if and the line already holds its result, or already denies its condition.

6a4Zero and One, for Free

x = x + 0 and x = x · 1 name one number on both sides. Neither changes the number; each changes the shape of the line.

The shape is the point. x + 3 · x has no technique that gathers it as it stands. Write x as x · 1, and spread run backwards gathers it: x · 1 + 3 · x = (1 + 3) · x = 4 · x. A free move changes nothing the line claims. It changes the shape, so that a technique can take hold.

1 is free to write as x⁰, too, by 4g4’s start: a power with count 0 is 1. That is how a lone number joins a run of powers: 3 + 2 · x + x² is 3 · x⁰ + 2 · x¹ + 1 · x², each term a number times a power of x.

The price here is only foresight: the 1 is worth writing only when you know which technique it is for.

6a5One, in Disguise

x/x is 1, so multiplying by it is free: 1/x · x/x = x/x². It is the same number, written over x².

Why conjure it: 5h3 adds fractions over one denominator. 1/x + 1/x² has two. Make them one: 1/x + 1/x² = x/x² + 1/x² = (x + 1)/x².

At x = 0 the free 1 is 0/0. 5e5 found that 0/0 has every answer, and 4·comp built that box in wires: the truth-teller box, a memory that retains whatever it was last made to be. So x/x = 1 still conforms at 0; there it holds the 1 the line set, as a memory holds a value. 1/0 is the other box, the liar, with no answer, and it was in the line before the free move came. Neither box is to be feared. Each is a mechanic, and electronics lives in both. What they ask for is attention: know which box the line is in at x = 0.

6a6How and Why We Conjure

Nobody writes x · 1 by accident. The move is found backwards, as 4e12 found proofs: look at the shape the next technique needs, then ask what free move turns the line into that shape. Then write it forwards, the free move first.

The cost of free is your attention, and what that cost gets you is room to work. The option asks you to keep in mind that the line no longer says which; the empty if, that it says nothing about y; 0, 1 and x⁰, the shape you are after; x/x, which box the line is in at x = 0.

6a7The Biggest Free Move

Picking is a free move too. When a set has a member, a proof may name one: let t be a member, a fresh name, as 2a did. One pick costs nothing, and finitely many are paid for one at a time (6c).

Infinitely many picks at once, one from every box, have no technique to pay for them. So they are laid down: the axiom of choice (6b). Its price is the rest of this rung: a world where it fails (6d), and sets from which no rule can pick.

6a8Moves to Check

  • Calling multiplying both sides by x a free move. It is not: at x = 0 it turns the line into 0 = 0, the memory box, which holds every answer, so what the line claims has changed (5h6).
  • Treating an added option as if it said which: from x ∨ y, writing y.
  • Carrying a free if through without its condition: from y ⇒ x, writing y.

Accepted names

0 is the identity element for plus, and 1 the identity element for times: each changes nothing. Multiplying by x/x is often called multiplying by a clever form of one. Adding an option is or-introduction, or disjunction introduction. The free if from a result you have is the logicians’ verum ex quodlibet, “a truth from anything”; the free if from a denied condition is an empty truth (the accepted word is vacuously true), and the move behind it is ex falso quodlibet.
