40j · technique

Machines that read a tape, by hand

The step on stopping proved that no machine sorts every machine into stops and never stops. It did not say that a person, or a machine, cannot sort a particular one. This step does the sorting by hand, on small machines, the way the volunteers who settled the five-state question did it by the million. First, run a machine and write down each configuration on its own line, until it stops. Then the ways a machine shows it will never stop: it comes back to a configuration it has been in, or it marches off into blank tape doing the same thing at each new cell. A machine that never steps left can always be sorted, and the step proves why. Last, the diagonal argument itself, run on a table of four machines and four codes, with a would-be decider to defeat. Every catch here is a pattern that some machines show. No finite stock of patterns catches them all, and that is what the step on stopping proved.

Run a machine one configuration to a line. A configuration seen twice means never stopping; so does a march into blank tape that comes back to the same state. A machine that only steps right is sorted by running it a fixed number of steps. And the diagonal, run on a small table, finds the row every decider misses.

40j1A run, one line at a time

For this step the tape is endless both ways, which 40a3’s tracks argument showed adds no reach, and the marks are 0 and 1 with 0 the blank, as in 7·then. Write a configuration as the stretch of tape that is not blank, with the state written just before the cell the head is on.

Trace-line technique: to run a machine by hand, write one configuration a line, find the row of the table for the state and the mark after it, and write the next line by changing that one cell, moving the state one place, and renaming it.

40j2Two ways to see it never stops

The first way is 3·comp’s back-again technique, with the one-next technique: a configuration seen twice comes round again for ever. The bounded-room technique of 40g4 said a machine that stays in r cells must show this within q · r · mʳ steps.

The second way catches a machine whose tape keeps growing, which never repeats a configuration.

Blank-march technique: if the machine is in state q on a blank cell with only blanks to its right, and later is again in state q on a blank cell with only blanks to its right, further right, having never stepped left of the first of those cells, then it never stops.

40j3A machine that only steps right

One-way technique: if a machine with q states never steps left, then on an input of length n it stops within n + q steps or never stops.

\text{every }\allowbreak \text{step }\allowbreak \text{is }\allowbreak \text{R, }\allowbreak \text{so }\allowbreak \text{after } n \text{ steps }\allowbreak \text{the }\allowbreak \text{head }\allowbreak \text{is }\allowbreak \text{past }\allowbreak \text{the }\allowbreak \text{input} @@ it moves one cell a step
\text{from }\allowbreak \text{then }\allowbreak \text{on }\allowbreak \text{it }\allowbreak \text{reads }\allowbreak \text{only }\allowbreak \text{blanks, }\allowbreak \text{so }\allowbreak \text{its }\allowbreak \text{next }\allowbreak \text{state }\allowbreak \text{depends }\allowbreak \text{on }\allowbreak \text{its }\allowbreak \text{state }\allowbreak \text{alone} @@ the one-next technique, with the mark always blank
\text{among }\allowbreak \text{the }\allowbreak \text{states }\allowbreak \text{at }\allowbreak \text{steps } n, n + 1, \dots, n + q\text{, }\allowbreak \text{two }\allowbreak \text{are }\allowbreak \text{the }\allowbreak \text{same} @@ q + 1 moments, q states: pigeonhole
\text{from }\allowbreak \text{the }\allowbreak \text{first }\allowbreak \text{of }\allowbreak \text{them }\allowbreak \text{the }\allowbreak \text{states }\allowbreak \text{cycle, }\allowbreak \text{and }\allowbreak \text{each }\allowbreak \text{is }\allowbreak \text{a }\allowbreak \text{state }\allowbreak \text{it }\allowbreak \text{did }\allowbreak \text{not }\allowbreak \text{stop }\allowbreak \text{in} @@ if it had stopped, it stopped by step n + q
\htmlClass{new}{\text{not }}\allowbreak \htmlClass{new}{ \text{stopped }}\allowbreak \htmlClass{new}{ \text{by }}\allowbreak \htmlClass{new}{ \text{step } n + q \Rightarrow \text{never}} \quad \blacksquare @@ run n + q steps, and look

So stopping is decided for machines that only step right, by a run of fixed length. This is the shape of every catch: a family of machines with a bound on how long a stopper can take. The stopping set is not decided because no such bound works for every machine, and 40·now finds how fast the bound must grow.

40j4The diagonal, on a small table

Four machines: M₀ stops at once; M₁ never stops; M₂ stops exactly when its input has an even number of letters; M₃ stops exactly when its input begins with 0. Their codes have 23, 30, 41 and 56 letters, and every code begins with 0 (40c1).

Flip-diagonal technique: a machine that, on the code of machine i, stops exactly when machine i does not stop on its own code differs from every machine of the table at that machine’s own column.

A would-be decider D₀ answers “stops” exactly when a code has an even number of letters. Build E from D₀ as in 40d2, and suppose ⟨E⟩ has an odd number of letters. D₀ says E does not stop on ⟨E⟩, so E stops on ⟨E⟩: D₀ is wrong there. Had ⟨E⟩ been even, D₀ would say it stops, and E would loop. Either way the input ⟨E⟩ # ⟨E⟩ is the one it gets wrong.

The basement · there if you want it

The accepted names

A configuration seen twice marks a cycler; a march into blank tape marks a translated cycler, the names the busy beaver project used for its first deciders. The two-state machine of 40j1 is the two-state busy beaver champion. A machine that only moves right is a one-way, or right-moving, Turing machine, and the one-way technique says its halting problem is decidable. Catches of this kind, each correct for every machine it accepts and silent on the rest, are deciders, partial ones.

Who said it first

Tibor Radó (1962) posed the busy beaver question; Shen Lin and Radó (1965) settled the three-state case by sorting every machine by hand and by computer, with catches like these. The cycler and translated-cycler deciders were named in the bbchallenge project, begun in 2022, which settled the five-state case in 2024.

A proof that is not allowed

“The machine’s tape has grown for 500 steps and its head keeps moving right, so it is marching and never stops.” Not allowed: the blank-march technique needs the same state on fresh blanks twice, with no step left of the first. A machine can move right for 500 steps and then turn back and stop.
