40j · proof

One Language Runs Another

The shapes of this rung are not 39’s machine’s numbers. Something must carry them down. This step gives two ways: run the program from its words, or translate it into numbers once and for all.

An interpreter runs a program held as data; a compiler translates it. The translation is right when every run of the result is a run of the source.

40j1An Interpreter Reads a Program as Data

Hold the program as a tree of shapes (40i), and hold the state beside it. The interpreter looks at the shape on top, does it, and moves on: for x ← e it works out e and changes x; for a while it checks the test and either runs the body again or leaves. This is 39j4’s program as data, read by another program.

40j2A Compiler Translates

A compiler turns each shape into 39j’s instruction numbers. An assignment becomes loads, adds and a store. An if becomes 40b1’s skip, and a while becomes 40b2’s test and jump back, each with its parts compiled inside.

Compiling-keeps-runs technique: if each shape, compiled from compiled parts, runs as the shape does, then every compiled program runs as its source does.

The proof is shape-induction (40i3) over the program. Assignments are the start case. A row, an if or a while is the step, assuming its parts compile right.

40j3The First One Is Written Below

A compiler is a program, so it can be written in the language it compiles and compile itself. But the first compiler cannot compile itself, because nothing yet runs it. It must be written in something that already runs: assembly, which 40a’s assembler turns to numbers.

40j4Keep the Runs, Not the Form

Two programs that leave the same final state from every start are the same for every purpose a run can see, though their words differ. A compiler must keep that sameness, not the words, so two right compilers may give different numbers for one program.

The accepted names

An interpreter runs source; a compiler translates it to machine code. Writing a compiler in its own language is bootstrapping, and the technique of 40j2 is compiler correctness. One program that runs every program from its code is the universal machine, which 41c builds.
