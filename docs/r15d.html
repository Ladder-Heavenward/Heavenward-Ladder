15d · proof

The Area Under x, Worked to the End

The definition of the integral asks about every partition at once, and gap-closes asks for one partition per gap. Neither yet has given a single number for anything but constants and steps. This step computes the first: the region under the line where up equals across, from 0 to 1. With equal pieces, the lower and upper sums are sums of whole numbers, and 4k's doubled-sum adds them in one line. The lower sums come out just below a half, the upper sums just above, and the gap is one over the number of pieces. Nothing but a half survives every cut.

With equal pieces, the boxes under the line climb in equal steps, and doubled-sum adds them to just under a half. The boxes over add to just as far above a half. The integral is caught between for every number of pieces, and only a half is.

15d1Squeezed for Every n

Squeezed-for-every-n technique: if a number I satisfies |I − c| ≤ k/n for every whole n ≥ 1, with k ≥ 0 fixed, then I = c.

\text{suppose } I \ne c @@ for contradiction (7f)
\alpha = \tfrac{|I - c|}{k + 1} \gt 0 @@ |I − c| > 0 by three-way on ℝ; k + 1 > 0
\text{call } n:\ \tfrac1n \lt \alpha @@ everyday-counting-passes (8e)
|I - c| \le \tfrac{k}{n} \lt \tfrac{k + 1}{n} \lt (k + 1)\alpha = |I - c|;\ \ \bot @@ the hypothesis at this n; order-and-arithmetic-agree; three-way-order on ℝ
\htmlClass{new}{I = c} \quad \blacksquare @@ refute; three-way on ℝ

15d2The Sums for y = x

P_n:\ x_i = \tfrac{i}{n},\ \ \Delta x_i = \tfrac1n @@ the equal partition of [0, 1] into n pieces
m_i = \tfrac{i-1}{n},\ \ M_i = \tfrac{i}{n} @@ x is increasing: its least on a piece is at the left end, its greatest at the right
L_n = \textstyle\sum_{i=1}^{n} \tfrac{i - 1}{n} \cdot \tfrac1n = \tfrac{1}{n^2} \sum_{j=0}^{n-1} j @@ order-and-arithmetic-agree and spread for times over plus to bring out 1/n²; j = i − 1
= \tfrac{1}{n^2} \cdot \tfrac{(n-1)n}{2} = \htmlClass{new}{\tfrac12 - \tfrac{1}{2n}} @@ doubled-sum (4k): twice 0 + 1 + ⋯ + m is m(m + 1)
U_n = \tfrac{1}{n^2} \textstyle\sum_{i=1}^{n} i = \tfrac{n(n+1)}{2n^2} = \htmlClass{new}{\tfrac12 + \tfrac{1}{2n}} @@ doubled-sum again
U_n - L_n = \tfrac1n @@ the gap

Area-under-x technique: x is integrable on [0, 1], and ∫₀¹ x dx = ½.

\text{fix } \varepsilon \gt 0;\ \ \text{call } n:\ \tfrac1n \lt \varepsilon @@ everyday-counting-passes
U(x, P_n) - L(x, P_n) = \tfrac1n \lt \varepsilon @@ the gap
\text{x is integrable on } [0, 1];\ \ \text{call its integral } I @@ gap-closes (15c)
L_n \le I \le U_n \text{ for every } n @@ I is the sup of the lower sums and the inf of the upper sums
\tfrac12 - \tfrac{1}{2n} \le I \le \tfrac12 + \tfrac{1}{2n},\ \ |I - \tfrac12| \le \tfrac{1}{2n} @@ the two sums; unpack-the-bars (8h)
\htmlClass{new}{\textstyle\int_0^1 x\,dx = \tfrac12} \quad \blacksquare @@ squeezed-for-every-n with k = ½

So the region under y = x from 0 to 1 has area ½: half the box [0, 1] × [0, 1]. A picture suggests the half by a half turn of the box about its middle point, (½, ½), which carries the part below the graph onto the part above. A half turn is a move that rung 20 studies, and none of the three area axioms says that moving a set keeps its area. The squeeze needed no move.

One mathematician computed the ratio of 0 + 1 + 2 + ⋯ + n to n + n + ⋯ + n, all n + 1 terms equal to n, for one n after another. He found it always a little more than one half, by a part that shrinks as n grows. With endlessly many terms, he said, the ratio is exactly one half.

15d4A Falling Body

v(t) = at \text{ from rest, for } 0 \le t \le T @@ given: a velocity that grows steadily from rest, by a each second
\text{lower sum: } \textstyle\sum a\tfrac{i-1}{n}T \cdot \tfrac{T}{n} = aT^2(\tfrac12 - \tfrac{1}{2n}) @@ the same doubled-sum line, scaled by aT²
\text{upper sum: } aT^2(\tfrac12 + \tfrac{1}{2n}) @@ the gap is aT²/n
\textstyle\int_0^T at\,dt = \tfrac12 aT^2 @@ squeezed-for-every-n
\text{distance covered by } T:\ x(T) = \tfrac12 aT^2 @@ given: such a body covers ½aT² by time T. The same number: distance is the area under velocity

The distance a body covers can be squeezed the same way: between n speeds times n short times, from below and from above. Those are the lower and upper sums of that steady velocity. An old figure for falling compared amounts that this rung calls areas. Here they are.

Who said it first

Wallis computed the ratio of 0 + 1 + 2 + ⋯ + n to n + n + ⋯ + n, all n + 1 terms equal to n, for one n after another, and found it always a little more than one half, by a part that shrinks as n grows; with endlessly many terms, he said, the ratio is exactly one half.

Wallis, Arithmetica infinitorum (1656), Proposition 1 to 3; paraphrase

The mathematician of the standing question is John Wallis, and the philosopher is Thomas Hobbes. The old figure for falling is Galileo’s, from Two New Sciences (1638).
