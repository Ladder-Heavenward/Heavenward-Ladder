2a · proof

Membership and same members

This step gives the rung its objects. A set is a gap many things fit, taken as one thing; its first axiom says there is one with nothing in it. Rung 1’s moves still work on sets, with rounder marks. A set is a thing whose whole nature is to have members, and “is a member of” gets a mark, the way “is the same thing as” did on 0b. Then comes the same-members axiom: if the same things are in each of two sets, then they are the same set. It is said in words, then in marks, then put to work. Every proof about sets ends by citing it, after a member has been chased through both descriptions. From it the step defines “subset”. It proves that every set is a subset of itself, and that sets are the same exactly when each is a subset of the other. And it insists, with a worked refusal, that being a member and being a subset are different things.

A set is nothing but its members. To show sets are the same, let a thing be anything and show it is in either exactly when it is in the other. Being in a set and being part of a set are different claims; the marks keep them apart.

What this stands on, and where it goes

Stands on 0b (=, the axioms self-sameness and swap), 1b (¬, ≠, refute), 1c (∧, ∨, cases), 1d (⇒, ⇔) and 1e (∀, the every-around-an-if skeleton), with the shapes of 1i. Every later page of the rung ends its proofs with the same-members axiom; 2b builds the earliest set; 2d gathers all the subsets into a set of their own.

2a1A gap many things fit

Stands on 0a (a name for anything, a statement with a gap), 0b (= between names) and rung 1 (the ways to change and join statements).

0a made statements with a gap, such as “… is furry”. Put the name of a cat in the gap, and the statement is so. “Cats are furry” fills that one gap with an awful lot of cats at once. So there is a kind of gap that many things can fit.

The things that fit, taken together as one thing, are a set. The everyday word is a collection. The things in it are its members. A set has its members and nothing else: no order among them, no arrangement, no history of how it was described. The people in a room are a set, and Ann is a member of it. The colours a traffic light shows are a set, and amber is a member. Which colour lit first is no part of the set. A set is a thing in its own right, so a letter can name it. And 0b's sameness mark can stand between names of sets: u = v says that u and v are the same set, whatever names they go by.

Sometimes nothing fits the gap. No cat fits “… is a cat that can fly”. The rung lays that case down first, as its first axiom.

Empty-set axiom: there is a set with nothing in it.

It is held in trust, like every axiom: everything after it stands on it. 2b9 writes it in marks, 2b11 proves there is only one such set, and 2b12 gives it a mark of its own. The ladder will also call it 0. Rung 3 shows why that name fits.

Every way rung 1 changed and joined statements still works when the gap holds a set. The marks just get rounder, to show that sets are being talked about and not single names:

The tools of this rung, sift, gather and merge (2b, 2c), are rung 1's moves used again and again on sets. Simple moves, many inputs. The rules come in an order that keeps every member where it belongs.

A set is an object in the ladder's sense: a name whose relationships to other names can be proved. 0b gave the first operator. Operators and objects together are most of the mathematics ever done.

Sets on this rung are written in three ways, and it helps to see them all at once. Braces around a list name the set whose members are exactly what is listed: {cat, dog} is the set whose members are cat and dog (2a3 makes this exact). A set is a thing, so like any thing it takes a small letter: r for the people in the room, u and v for sets in general. A set whose members are all sets takes a curly capital, 𝒜 (2d2).

Example sets come in two kinds, and the ladder keeps them apart. A pictured set shows what sets are like; a built set shows that a set is there. A pictured set is made of everyday things, like the pets at home or the people in a room. It is written as if we had it, the way 0a let you name a cat before saying anything about cats, and no proof leans on it being there. A built set comes from this rung's tools (sift, gather, merge, power set), starting from the empty set of the empty-set axiom. Every line of its building carries a reason.

2a5Sets with one member, and sets of sets

Stands on 2a3 (the listing line).

The braces mark what belongs together, like brackets. Braces around a single name write a set with that thing as its only member. {cat} is an example: x ∈ {cat} ⇔ x = cat. Braces around braces write a set whose only member is itself a set. {{cat}} is an example. Its only member is {cat}; cat itself is not on its list. 2a6Same members, in words

Stands on 2a1 (a set has nothing but its members).

Here is the rung's axiom. If the same things are in each of u and v, then u and v are the same set. Said in another way: a set has no ingredients other than its members. Said in the way of one of the subject's founders: a set is completely settled once it is settled, for every thing whatever, whether that thing is in it or not.

The founder quoted in the rung 2 survey called the collection a whole made of “definite and separate objects”. Definite, so that of each thing it is settled whether it is in. Separate, so that a thing is in or not in, and being in again is nothing. So a set is how far it goes: which things it covers, and nothing else about it. The ladder calls this axiom the same-members axiom.

2a12In, and part of: keep them apart

Stands on 2a9 (⊆), 2a3 (listing) and 1c (cases).

The confusion everyone makes, and after this step should not: ∈ and ⊆ say different things. Cat is in {cat, dog}: a member, listed. {cat} is part of {cat, dog}: a subset, since its only member is a member. But {cat} is not in {cat, dog}: the members of {cat, dog} are cat and dog, and {cat} is neither. A cat is not a set, and {cat} is. Here is the refusal, written out, with the facts about cats laid down as givens because the ladder cannot look at a cat.

Given: a cat is not a set, and a dog is not a set; they are animals. Given too: {cat} is a set, since braces write a set (2c builds it).

Suppose, until we drop it, that {cat} ∈ {cat, dog}. Unpack the listing: {cat} = cat, or {cat} = dog. Take the cases. If {cat} = cat, the swap axiom turns “{cat} is a set” into “cat is a set”. That clashes with the given: ⊥. If {cat} = dog, then in the same way dog is a set: ⊥ again.

So, by cases, ⊥. Drop the supposition: it is refuted. Pack the mark: .

Against that, {cat} ⊆ {cat, dog} is proved on the slides in a few short steps, and the contrast is the lesson. The marks look alike and the English (“in”, “part of”, “belongs to”, “is among”) blurs them; the definitions do not. A test you can always run: ∈ asks whether a thing is on the list. ⊆ asks whether every member of a thing is on the list, and so only makes sense of a set.

2a13Bags inside bags

2a14One in at the bottom, part of all the way up

Stands on 2a10 (subsets chain) and 2a12 (in and part of).

Now a chain from further off. Dip a cup into Puget Sound, and treat each body of water as the set of its molecules. One molecule, m, is a member of the cupful. Every molecule of the cupful came from the Sound, so the cupful is part of the Sound. (2b shows why that step is free: the cup is a sift.) The Sound is part of the Salish Sea, and the Salish Sea, an inlet, is part of the Pacific. The Pacific is part of all the water on Earth. One ∈ at the bottom, then ⊆ all the way up, and the chain technique for part of carries m to the top:

Now try a chain of ∈ instead. The school is a member of the set of schools in the district, {Lincoln, Grant, Hill}. m is in the school, and the school is in that set. But m is not a school, so m is not a member of the set of schools.

A member of a part is a member; a member of a member, as a rule, is not. The English word “in” covers both, which is why the marks are kept apart.

Living things are sorted the same way, level inside level. A barn owl is a member of the barn owls. The barn owls are part of the owls, and the owls are part of the birds. Read each level as its animals, and each is part of the next, so the barn owl is a bird. Read each level as its kinds, and each kind is a member of the next. The owls come in two families, the barn owls and the typical owls, and neither is part of the other. Sorting things into kinds, and kinds into bigger kinds, is ∈ and ⊆ kept carefully apart.

2a17Running it backwards

Stands on 2a11 (double inclusion) and 1i12 (find it backwards, write it forwards).

Wanting u = v for sets, you know the last step is the same-members axiom carried through, or the double-inclusion technique. So the step before reaches ∀x (x ∈ u ⇔ x ∈ v), or the inclusions each way. An every opens with “let x be anything”; an exactly-when wants an if each way; an if supposes its hypothesis. So the argument will contain the steps “suppose x ∈ u … so x ∈ v” and “suppose x ∈ v … so x ∈ u”. The middle of each is where the descriptions of the sets are unpacked until they meet. Wanting u ⊆ v, you need only the first of those two pieces, “suppose x ∈ u … so x ∈ v”. Wanting ¬(u ⊆ v), you want a counterexample: a thing in u that is not in v, shown, then the counterexample technique. Found from the goal back; written from the givens forward.

Other ways the same marks are written

Mathematics writes some of these marks in more than one way, by subject and by century. Each one below means what the mark in this step means; know them on sight.

  • v ⊇ u and v ⊋ u say the same as u ⊆ v and u ⊊ v, turned about; u ∋ x says the same as x ∈ u.
  • Books split over ⊂: some mean ⊆ by it, others mean ⊊. The ladder never writes it; when you meet it, find out which the book means.

The accepted name

The axiom of 2a6 has an accepted name: extensionality. The name comes from an older distinction. A description has a meaning and a coverage. The meaning is called its intension; the coverage, its extension. Take “the colours a traffic light shows”. Its intension is that phrase. Its extension is red, amber and green. The axiom says that a set is its extension, and its intension is nothing to it. However you came to describe a set, if you covered the same things, you named the same set.

The ladder picks the name up again when it next matters, on rung 31.

Who said it first

The mark ∈ is Giuseppe Peano’s. The founder who put extensionality in one line is Richard Dedekind; the founder the survey quoted, with “definite and separate objects”, is Georg Cantor. The four kinds of sentence and the syllogism Barbara are Aristotle’s.

Dedekind put it in one line: a system S is the same as a system T when every element of S is an element of T and every element of T is an element of S. Nothing else about a system, he said, counts toward which system it is.

Dedekind, Was sind und was sollen die Zahlen? (1888), §2–3, trans. Beman, 1901; paraphrase
