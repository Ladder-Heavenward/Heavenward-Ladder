2b · proof

Sifting, and a set to start from

2a said what a set is and when sets are the same. This step builds. The tool is sifting: from a set you have and a condition, the set of those members that pass. It is the tool everyone uses when they write “the set of all things such that…”. The small print in it is that the sifting happens inside a set you already have, and that is what keeps the whole subject from falling over. The step also notices that a tool which makes sets from sets makes nothing from nothing. So it lays down the axiom that there is a set, and sifts from it the set with no members. That turns out to be the same set whichever set you began with. At the end it shows the outsider-set argument (Russell's): what happens when you sift from nothing, written out move by move until something totally false, with no step that this ladder has withheld.

To pick out members, name the set you are picking from and the condition they must pass. Sifting keeps or drops; it never adds. Sift with a condition nothing passes and you have the empty set, the only set with no members.

What this stands on, and where it goes

Stands on 0a (statements with a gap), 1b (⊥, refute, when nothing is true, everything is permitted), 1d (⇔), 1e (∃, use a some) and 2a (∈, listing, same-members, ⊆, the double-inclusion technique). 2c defines the common members of sets by sifting; 2d proves ∅ is part of every set; 2f runs the outsider-set argument again against a set of all sets; rung 3 starts its endless run from ∅.

2b1Picking things out, in plain words

Stands on 2a (a set and its members).

This step is about picking things out. You do it all day. From the clothes in a drawer, you pick the clean ones. From the people in a class, you pick the ones who walk to school. Each time you need a collection you already have. You also need a test that each member passes or fails. What comes out is the members that pass.

A kitchen sieve does the same. Pour in the flour, and the lumps stay behind. A sieve never makes flour. It only keeps some of what you poured in. A sieve is this step's tool, and the step calls it sifting.

Sifting keeps the members of a set you already have that pass a test, and it never adds anything.

The marks look harder than the idea. Here is one:

It is read “the set of x in u such that x can fly”. The braces mean a set, as on 2a. The x is a blank that runs through the members of u, one at a time. The colon is read “such that”. After it comes the test.

Let u be {cat, dog, owl}. The test runs on each member in turn. The cat can't fly, so it is dropped. The dog can't fly, so it is dropped too. The owl can fly, so it is kept. The result is {owl}.

2b2A condition

Stands on 2b1 (a test on each member) and 0a (a statement with a gap).

The step writes the test as φ(x), with a Greek letter, phi: the first Greek letter on the ladder. That letter means “some test, any test at all”. It works like a blank on a form: φ(x) is the test with x written in the blank.

0a had statements with a gap: “… is asleep”, written P(x) with the gap shown. Put a name in the gap and you have a statement. When such a statement-with-a-gap is used to pick things out, the ladder calls it a condition. Examples: “x can fly”, “x is red”, “x ∈ b”, “x ≠ cat”, “∃y (y is a child of x)”. A condition is built from nothing but rung 1's joining words, 0b's =, 2a's ∈, and everyday words. It says of the thing in its gap something that is so or not so. Rung 1 wrote statements with gaps as P, Q, R. A condition that is to be any condition whatever is the one the sifting tool accepts. For it the ladder uses a letter from another alphabet, so that it is never confused with a particular statement:

From here on, (the Greek letter phi, in its small form) stands for any condition: a statement with a gap. is that condition with x in its gap.

For example, if φ(x) is “x can fly”, then φ(owl) is “owl can fly”, which is so, and φ(cat) is “cat can fly”, which is not. Back to the rule: nothing is assumed about φ except that, for each thing put in its gap, the result is a statement. The letter x in φ(x) is a placeholder in 1e's sense: it names nothing and may be renamed.

2b3The empty set, in plain words

Stands on 2b1 (sifting) and 2a (a set is nothing but its members).

Now a strange case. Sift with a test nothing passes, such as “is not itself”. Everything is itself, so nothing is kept. You are left with a set that has no members. It is called the empty set.

Is there only one empty set? An empty cup and an empty bucket are different things, because each is made of something besides what is inside it. A set is made of nothing but its members (2a). So any empty set has the same members as any other, which is none, and they are the same set.

Why did 2a1 lay down an axiom that the empty set exists? Because sifting needs a set to pour in. With nothing in the sieve, nothing comes out. The empty-set axiom puts one set in hand, and 2b9 writes it in marks. Any other set would sift down to it too, with “is not itself”.

2b5The sift tool

Stands on 2b2 (a condition φ) and 1c (and: keep, join).

Here is the tool, in words: from a set u and a condition φ, the set of those members of u of which φ is true. In marks:

From here on, means: the set whose members are exactly the members of u that pass φ:

Read the colon as “such that”: “the set of x in u such that φ of x”. The x before the colon is the placeholder, and it runs through u. The condition after the colon has that same letter in its gap.

The sift axiom says the sifted set exists. The “from here on” line says who its members are. The mark {x ∈ u : φ(x)} is a name: it names the one set the sift picks out. By 2a's same-members axiom, only one set has those members.

A thing is in the sifted set exactly when it is in u and passes. That is an and. To use a membership in a sifted set, keep either part. To make one, join.

2b6The fliers among cat, dog and owl

Stands on 2b5 (the sift tool) and 2a3 (the listing line).

The fliers among cat, dog and owl, with the facts about flying laid down as given, since the ladder cannot watch an owl.

Given: the cat cannot fly, the dog cannot fly, and the owl can fly. The sift axiom gives this set; call it fliers:

Is the owl in fliers? The owl is the owl, by the self-sameness axiom, so add an option and pack the listing: the owl is in {cat, dog, owl}. The owl can fly: keep that part of the given. Join the two, and pack the sift:

Is the cat in fliers? Suppose, until we drop it, that it is. Unpack the sift and keep the right part: the cat can fly. That clashes with the given: ⊥. Drop the supposition; it is refuted: . The same steps run for the dog: suppose the dog is in fliers; unpack and keep the right part: the dog can fly; that clashes with the given; refute.

So fliers has owl as a member, and neither cat nor dog. By 2a's listing line and the same-members axiom, fliers = {owl}: the slides finish that. The habit to take from this: a sift is used by unpacking its membership into an and, and made by joining.

2b7Sifts worth knowing by sight

Stands on 2b5 (the sift tool) and 0b (self-sameness).

Some sifts worth knowing by sight:

A condition everything passes gives the set back, since x = x is the self-sameness axiom for any x.

A sift can run on a set whose members are sets: {s ∈ b : cat ∈ s} picks out the members of b that have cat in them.

A sift can mention other sets you have: {x ∈ u : x ∈ v} is the members u and v share, and 2c gives it a mark.

What a condition may not do is mention the set being built, since that set is not yet in hand.

2b8Sifting never adds

Stands on 2b5 (the sift tool) and 2a9 (⊆).

Sift-is-part technique: whatever the condition, the sifted set is part of the set you sifted. This is the technique to cite when someone expects a sift to produce something that was not there to keep.

The plan: wanting the sift ⊆ a, the last step packs ⊆; before it is an every; so open with y anything.

Let a be any set and φ any condition. Take y, anything at all. Suppose this:

Unpack the sift: y ∈ a and φ(y). Keep the left part: y ∈ a.

Drop the supposition: we have proved an if. y was anything, so speak of everything, and pack the mark: .

2a's cup of seawater was a sift all along. The cup takes exactly the molecules of the Sound that are in a certain place: cupful = {x ∈ Sound : x is in the cup}. So the sift-is-part technique gives cupful ⊆ Sound with no further work. A cup is a sift: it keeps what passes, and what it keeps was already there.

So {x ∈ {cat, dog} : x can fly} is not {owl}, whatever the owl can do. No flier was in {cat, dog} to keep, so nothing passes, and the result is a set with no members at all. Which raises the question of what that set is, and whether there is such a thing.

2b9A set to start from

Stands on 2b8 (sifting needs a set) and 1e (a some).

Look at what the tool needs. Sifting takes a set in. Every tool of this rung does: 2c's gather takes things you have, its merge takes a set of sets, 2d's tool takes a set. The tools make sets from sets, and with nothing in hand they make nothing. The techs of rung 1 never produce an object either; they reason about objects you have. And 2a's listing only writes a set you have. So without 2a1, nothing would say that there is any set at all. Mathematics does not pretend otherwise. 2a1 laid down an axiom that does not build but simply asserts. In marks:

From here on, “the empty-set axiom” is this axiom, in these marks.

It is the smallest start there could be: one set, with nothing in it. Some books lay down instead only that some set exists, and sift the empty set out of it, as 2b10 does for any set. With sifting in hand, the two come to the same thing. The ladder starts from the empty one, because it is the first thing the rung needs. (Rung 3 will lay down an axiom that asserts another set exists, a particular and endless one.)

2b10Every set sifts to the empty set

Stands on 2b9 (the empty-set axiom), 2b5 (the sift) and 1e (every).

Empty-sift technique: any set, sifted by “is not itself”, gives a set with no members. The argument:

Let a be any set at all, with nothing else assumed. Sift a by the condition “is not itself”, and call the result e: .

Take y, anything at all, and suppose y ∈ e. Unpack the sift: y ∈ a and y ≠ y. Keep the right part, and unpack ≠: y is not y. But y = y, by the self-sameness axiom. That clashes: ⊥. So y ∈ e is refuted: y ∉ e.

y was anything, so speak of everything: nothing is in e.

a was any set, so this holds for every set.

This makes no new set appear: the empty-set axiom already gave one. It shows that every set leads down to a set with no members, by one sift. 2b11 shows that it is always the same one.

2b11The only set with no members

Stands on 2b10 (a set with no members), 2a7 (the same-members axiom) and 1b (when nothing is true, everything is permitted).

One-empty-set technique: two sets with no members are the same set.

The argument that they are the same uses the tech “when nothing is true, everything is permitted”, and it is the standard use of that tech. A thing cannot be in e. So if you suppose it is, you reach something totally false. Since nothing is then true, everything is permitted: you may say that it is in e′, for as long as the supposition stands.

Here it is. Suppose nothing is in e and nothing is in e′. Aim at the same-members axiom. Take x, anything at all.

Suppose x ∈ e. Nothing is in e, so x ∉ e. Unpack ∉: that clashes, ⊥. Everything is permitted, so x ∈ e′. Drop the supposition: if x ∈ e, then x ∈ e′. The line x ∈ e′ goes with the supposition. Only the if leaves, and an empty if is all the same-members axiom asks for. The same steps, with e and e′ exchanged, give: if x ∈ e′, then x ∈ e.

Join the two ifs and pack: . x was anything, so speak of everything. The same-members axiom then gives e = e′.

2b12A name for the empty set

Stands on 2b11 (only one set has no members).

There is a set with no members, and no other. So it may be given a name of its own:

From here on, means: the set with no members. Read it “the empty set”.

Empty-set technique: nothing is a member of the empty set. In marks, .

The empty-set technique is the empty-set argument of footing 2b10, read for ∅; the one-empty-set technique is why “the” is the right word. Every argument that mentions ∅ uses them, in one of two ways. Either “x ∉ ∅, so supposing x ∈ ∅ is totally false”, or “this set has no members, so it is ∅”. In particular {x ∈ u : φ(x)} = ∅ exactly when no member of u passes φ; the slides prove the fliers among {cat, dog} come to ∅ that way.

A word on the mark. It is a letter from the Danish and Norwegian alphabet, chosen by a group of French mathematicians who wrote under one shared pen name. One of them said he had taken it from the Norwegian he knew. It is not the Greek letter phi, which stands for a condition in this step, and it is not a mark from any later rung. Treat it as the mark its line makes it: a name, for one set.

2b13The illegal sift

Stands on 2b5 (the sift needs a set to sift from).

Here is the sift that looks most harmless and is not allowed: “the set of all cats”. It is written {x : x is a cat}, with nothing after the x to sift from. The sift axiom says nothing of it, and no tool of the rung builds it. If you want the cats, you must say which set's cats: the cats among the animals in the zoo, {x ∈ z : x is a cat}. Saying which set's cats seems pedantic in life. In mathematics it is the difference between a subject that stands and a subject that falls, and the argument that shows it is short enough to run in full.

2b14The outsider set

Stands on 2b13 (the illegal sift), 1d (⇔) and 1b (refute).

Early in the century before this one, a logician had completed a foundation for arithmetic. Its rules allowed a set to be formed from any condition at all, with no set to sift from. A younger logician wrote to him with a question. Take the condition “x ∉ x”, is not a member of itself. Most sets pass it: {cat} is not a member of {cat}, since its only member is a cat. The old rules allow the set r of all things that pass. Is r a member of itself?

Outsider-set technique: no set has as its members exactly the things that are not members of themselves.

Here is what happens, in the techs of rung 1 and nothing else.

Suppose, until we drop it, that there is such a set. Use the some: call it r. So for every x, x ∈ r exactly when x ∉ x. Use that every on r itself: .

Now suppose, inside, that r ∈ r. Keep the rightward direction and carry it through: r ∉ r. Unpack ∉: that clashes, ⊥. So r ∈ r is refuted: r ∉ r.

Now keep the leftward direction and carry it through, on what we just proved: r ∈ r. That clashes with r ∉ r: ⊥. The ⊥ does not mention r, so it stands outside the some.

Drop the first supposition: it is refuted. .

Look at what the argument did not do. It never asked “is r in r, or not?” and split into cases; that would be 1g's either-way, which this ladder does not grant for a statement like this. It supposed r ∈ r, refuted it, and then used the refutation to carry the other direction through. Both sides of the final clash were proved. The outsider-set argument (Russell's) needs nothing that rung 1 withheld.

2b15The sift inside a set

Stands on 2b14 (the outsider-set technique) and 2b5 (the sift axiom).

Now set the outsider-set technique beside the sift tool. The old rules said: for any condition, there is the set of all things that pass. With the condition x ∉ x that gives exactly the r the technique refutes. So the old rules prove ⊥, and when nothing is true, everything is permitted: every statement, so and not so alike. The author of the foundation, with great generosity, wrote back that the argument had shaken the ground he meant to build on.

All the water on Earth is the top of 2a's cup chain: every body of water in it is part of it. But its members are molecules, not sets. A set of everything has no such top to sift from.

The sift axiom says instead: for any condition and any set u you have, there is the set of members of u that pass. Run the same sift inside a set:

From here on, a small letter written low after a name, as in rᵤ, makes a new name that recalls the first. It claims nothing.

So rᵤ = {x ∈ u : x ∉ x} is the outsider set made inside u. The same steps now give rᵤ ∉ rᵤ. The second clash needed rᵤ ∈ u for free; inside u that is not given, so the clash refutes rᵤ ∈ u instead: the set you sifted from does not contain its own outsider set. Nothing totally false; a technique. 2f runs that version, and draws from it that there is no set of all sets.

The accepted word for what the outsider set did to the old rules is paradox, from the Greek for “contrary to expectation”.

2b17Running it backwards

Stands on 2b5 (the sift) and 2b12 (∅).

Wanting y ∈ {x ∈ u : φ(x)}, you know the step before is y ∈ u ∧ φ(y), so you want both of those, and join. Wanting y ∉ {x ∈ u : φ(x)}, you suppose the membership, unpack it, and need a clash with either part: either you have y ∉ u, or you have ¬φ(y). Wanting s = ∅, you have two routes. You can show s has no members, that is, for any y, y ∉ s, and cite the one-empty-set technique. Or you can show inclusions each way. The direction ∅ ⊆ s is free by everything-permitted (held in trust here; 2d writes it out), and the direction s ⊆ ∅ is the real work. Found from the goal back; written from the givens forward.

Other ways the same marks are written

Mathematics writes some of these marks in more than one way, by subject and by century. Each one below means what the mark in this step means; know them on sight.

  • {x ∈ u : φ(x)} is also written with a bar, {x ∈ u ∣ φ(x)}. Either form is set-builder notation.
  • \varnothing is also written {}.

Who said it first

The logician whose foundation fell is Gottlob Frege; the younger logician who wrote to him, in 1902, is Bertrand Russell. The author of the ancestor list of axioms, who assumed an empty set outright, is Ernst Zermelo (1908). The French group with the shared pen name is Bourbaki; the member who chose ∅ from the Norwegian he knew is André Weil.

Accepted names

The outsider-set technique is Russell’s paradox; the outsider set is the Russell set. The old unrestricted rule is unrestricted comprehension. The sift axiom is the axiom of separation, or of subsets.
